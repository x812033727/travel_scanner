## 主張與來源

- 社區活動頁缺漏、試用清單與退出安排均原創，命令只供讀者理解格式，沒有執行安裝、更新、停用、刪除或帳戶授權。
- 文章對象是 Claude Code，不是 Codex 或 Cowork 外掛；不使用本次工具環境作為 Claude 實測證據。
- local/user/project 為設定範圍，不是本機隔離保證；命令 hook 具有使用者權限，Skill allowed-tools 也需審閱。
- 依查閱當日文件處理 reload：新版選單可自動重載，其他變動依提示；非互動 MCP 連線限制仍存在，不概括強制重開或保證全部即時生效。
- install、update、disable、uninstall 的 --scope local 語法依官方參考；更新版本判斷受 manifest、市集及來源版本影響，沒有推薦未審查的具名外掛。
