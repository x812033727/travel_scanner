# 紙底版型範例：守則只寫一次（測試用範例）

這支只用來看紙底版型（`docs/videos/PAPER.md`）：`theme: "paper"` 的米白底與墨黑字、每張底下的
關鍵句帶（`keys`／`key`）、`big` 的大數字卡（`numeral`）、`bullets`／`steps`／`compare` 的圖示
（`icon`），以及 `terminal` 用 `typing: "human"` 一個字一個字打出來的指令。

終端機畫面上的指令與輸出都是 2026-10-01 在站主的 Windows 電腦上真的執行的結果（Claude Code
2.1.285），與 `tools/video/templates/terminal/fixtures/claude-code/` 相同，沒有改寫。

## 觀眾看完能做到的事

知道 CLAUDE.md 是一份放在資料夾裡、每次對話開頭都會先讀的守則，並能寫出自己的第一份。
