# 兩站原創生活分享批次 10

## Why

依使用者核定的兩站標題盤點計畫，製作全部不重複主題。總表：`docs/content-research/two-site-life/catalogue.json`。

## Definition of done

- [x] 本批每篇都有原創正文、1600×900 封面、SVG 圖解、官方來源及查證日。
- [x] ingest、限定 slug lint、逐張圖片 QA 與相關測試通過。
- [x] 交付可匯入內容包；未執行正式站匯入、發布或部署。

## Steps

- [x] `youtube-payment-tax-info` — YouTube 收款設定：AdSense 付款資料與稅務表單查核。必寫：收款資格與帳戶、稅務身分、官方表單與資料保護。
- [x] `affiliate-marketing-basics` — 聯盟行銷怎麼運作：連結、揭露與成效核對。必寫：合作流程、追蹤限制、揭露與退貨。
- [x] `website-income-models` — 網站如何產生收入：廣告、合作與自有產品的成本表。必寫：收入模型、維運成本、驗證需求。
- [x] `taiwan-company-registration` — 台灣成立公司前的準備：名稱、地址與申請順序。必寫：公司商業差異、官方申請管道、登記後事項。
- [x] `web-design-project-workflow` — 網頁設計怎麼開始：需求、內容與驗收的完整順序。必寫：需求訪談、學習資源、原型與驗收。
- [x] `website-information-architecture` — 網站架構怎麼畫：從內容清單到導覽與頁面關係。必寫：內容盤點、導覽分組、任務驗證。
- [x] `responsive-layout-basics` — 響應式與自適應網站：從手機閱讀安排版面。必寫：版面策略、斷點與內容、跨裝置測試。
- [x] `web-layout-hierarchy` — 網頁排版的資訊層級：留白、對齊與閱讀順序。必寫：網格與層級、間距、操作與閱讀。
- [x] `portfolio-case-study` — 作品集網站怎麼整理：用案例呈現問題與成果。必寫：案例結構、平台選擇、證據與聯絡。
- [x] `ui-ux-learning` — UI 與 UX 入門：介面、任務與使用者研究。必寫：職責與方法、學習路徑、實作練習。
- [x] `design-thinking-practice` — 設計思考怎麼練：從訪談到可測試的小原型。必寫：問題定義、想法與原型、測試回饋。
- [x] `wireframe-prototype-testing` — 線框圖與原型怎麼用：先驗證流程再修視覺。必寫：保真度、互動任務、回饋與迭代。
- [x] `website-color-system` — 網站配色怎麼建立：色相、明度與可讀性。必寫：配色關係、對比與心理假設、實際驗收。
- [x] `rgb-cmyk-export` — RGB 與 CMYK 怎麼選：螢幕、印刷與檔案輸出。必寫：色彩模式、轉換限制、輸出交接。
- [x] `brand-identity-logo-brief` — 品牌識別怎麼規劃：CIS、標誌與網站色彩。必寫：品牌需求、視覺識別、使用規範。
- [x] `logo-design-tools-budget` — Logo 設計怎麼準備：工具、字標與交付費用。必寫：原創與商標、生成工具限制、字標及交付。
- [x] `font-license-web-typography` — 中英文字型怎麼挑：閱讀、授權與網頁載入。必寫：字型搭配、授權檢查、網頁載入。
- [x] `licensed-assets-workflow` — 商用圖庫與圖示怎麼找：授權、作者與使用紀錄。必寫：圖片圖示3D素材、授權條件、素材清單。
- [x] `image-formats-compression` — WebP、JPEG 與 PNG 怎麼選：用內容決定格式與壓縮。必寫：格式用途、品質比較、尺寸與檔案。
- [x] `figma-design-basics` — Figma 設計入門：Frame、元件與協作交接。必寫：基本結構、可重用元件、交接。
