# 兩站原創生活分享批次 11

## Why

依使用者核定的兩站標題盤點計畫，製作全部不重複主題。總表：`docs/content-research/two-site-life/catalogue.json`。

## Definition of done

- [x] 本批每篇都有原創正文、1600×900 封面、SVG 圖解、官方來源及查證日。
- [x] ingest、限定 slug lint、逐張圖片 QA 與相關測試通過。
- [x] 交付可匯入內容包；未執行正式站匯入、發布或部署。

## Steps

- [x] `figma-plugin-assets` — Figma 外掛怎麼挑：圖庫、圖示與檔案權限。必寫：素材授權、外掛權限、協作與效能。
- [x] `figma-ai-design-workflow` — Figma AI 功能怎麼評估：設計生成、資料與交接。必寫：實際功能查證、生成與設計系統、MCP與權限。
- [x] `ai-design-prompt-workflow` — 用 AI 協助 UI 設計：從需求提示到可驗證的介面。必寫：提示輸入、設計假設、可用性驗證。
- [x] `css-layout-basics` — CSS 入門：選取器、盒模型與版面安排。必寫：語法、Padding Margin Border、實作驗收。
- [x] `sass-scss-workflow` — Sass 與 SCSS 怎麼用：變數、模組與編譯流程。必寫：編譯關係、模組管理、輸出驗證。
- [x] `lottie-web-animation` — 網頁 Lottie 動畫：載入、控制與減少動態效果。必寫：檔案與播放器、效能、無障礙。
- [x] `website-404-recovery` — 404 頁面怎麼設計：說明狀況並幫讀者繼續走。必寫：正確狀態、替代路徑、錯誤追蹤。
- [x] `landing-page-cta` — 一頁式銷售頁怎麼設計：訊息、證據與行動按鈕。必寫：資訊順序、CTA、表單與成效。
- [x] `canva-design-workflow` — Canva 製作圖文：範本、版面與輸出品質檢查。必寫：編輯與品牌素材、付費界線、輸出。
- [x] `eagle-asset-library` — Eagle 素材庫怎麼整理：標籤、版本與授權一起管理。必寫：檔案收納、檢索、授權與備份。
- [x] `wix-first-website` — Wix 架站指南：編輯網站、選擇方案與網址。必寫：網站建立、方案功能查證、發布與退出。
- [x] `lovable-first-project` — Lovable 製作網站：需求、資料連線與交付驗收。必寫：功能與費用查證、資料權限、測試與部署。
- [x] `ai-site-search-design` — 網站 AI 搜尋怎麼規劃：內容索引、回答與搜尋紀錄。必寫：檢索與引用、權限與隱私、Notion紀錄設計。
- [x] `immersive-translate-guide` — 沉浸式翻譯怎麼設定：網頁、文件與內容校對。必寫：供應商與權限、網頁PDF影片、術語與校對。
- [x] `transcription-desktop-tools` — 逐字稿工具怎麼用：MacWhisper 與 Whisper 桌面工作流。必寫：現行工具查證、本機與雲端、字幕校對。
- [x] `adobe-podcast-audio` — Adobe Podcast 音訊處理：降噪前後應該檢查什麼。必寫：上傳與限制、語音處理、保留原始檔。
- [x] `obs-screen-recording` — OBS 螢幕錄影入門：畫面來源、音軌與錄製驗收。必寫：場景與來源、聲音路由、檔案檢查。
- [x] `premiere-editing-basics` — Premiere 影片剪輯：素材整理、時間軸與輸出。必寫：試用與方案查證、剪輯操作、交付設定。
- [x] `course-video-editing` — 教學影片怎麼剪：旁白、示範畫面與學習節奏。必寫：課程腳本、畫面同步、字幕與驗收。
- [x] `frameio-video-review` — Frame.io 影片審稿：版本、時間碼與客戶回饋。必寫：分享權限、逐格回饋、版本交付。
