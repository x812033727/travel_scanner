# 兩站原創生活分享批次 07

## Why

依使用者核定的兩站標題盤點計畫，製作全部不重複主題。總表：`docs/content-research/two-site-life/catalogue.json`。

## Definition of done

- [x] 本批每篇都有原創正文、1600×900 封面、SVG 圖解、官方來源及查證日。
- [x] ingest、限定 slug lint、逐張圖片 QA 與相關測試通過。
- [x] 交付可匯入內容包；未執行正式站匯入、發布或部署。

## Steps

- [x] `google-site-kit-setup` — Site Kit 串接 Google 工具：權限、資料與驗證流程。必寫：服務連接、管理權限、資料與追蹤重複。
- [x] `google-trends-research` — Google Trends 找題目：相對熱度、地區與季節判讀。必寫：比較尺度、地區季節、選題限制。
- [x] `ahrefs-research-workflow` — Ahrefs 研究網站：從關鍵字、連結到內容機會。必寫：資料涵蓋、查詢任務、指標限制。
- [x] `semrush-research-workflow` — Semrush 規劃內容：關鍵字、競爭頁面與追蹤清單。必寫：研究步驟、專案與追蹤、資料解讀。
- [x] `ubersuggest-keyword-workflow` — Ubersuggest 查關鍵字：把建議詞整理成內容計畫。必寫：詞庫與競爭頁面、難度限制、選題驗證。
- [x] `similarweb-traffic-estimates` — Similarweb 流量估計怎麼讀：比較市場而不誤判小網站。必寫：估計資料、比較條件、樣本限制。
- [x] `dataforseo-api-basics` — DataForSEO 適合誰：資料 API、查詢成本與工作流。必寫：API用途、請求與費用、與介面工具比較。
- [x] `seo-tool-selection` — SEO 工具怎麼配：查詢任務、資料差異與預算分配。必寫：任務矩陣、數據差異、重複訂閱。
- [x] `search-results-clickthrough` — 搜尋結果頁怎麼看：SERP 版位、CTR 與曝光變化。必寫：結果頁構成、CTR計算、分群比較。
- [x] `yahoo-search-visibility` — Yahoo 搜尋能見度怎麼檢查：來源、收錄與流量判讀。必寫：現行搜尋來源、網站收錄、成效比較。
- [x] `ai-search-geo-content` — AI 搜尋時代的內容整理：SEO、GEO 與 AEO 怎麼配合。必寫：搜尋與回答差異、內容可驗證性、能見度觀察。
- [x] `ai-search-tools-measurement` — AI 搜尋曝光怎麼量：提示問題、引用與工具限制。必寫：評估問題集、引用與grounding、重複觀察。
- [x] `llms-txt-evaluation` — llms.txt 是什麼：整理內容索引前要知道的限制。必寫：提案用途、建立與維護、不保證抓取引用。
- [x] `zero-click-search-strategy` — 搜尋沒有點擊怎麼辦：用讀者任務重新看流量價值。必寫：零點擊情境、品牌與轉換、量測限制。
- [x] `knowledge-graph-entities` — 知識圖譜與網站實體：把品牌、產品與作者資訊說清楚。必寫：實體關係、資料一致性、結構化資料。
- [x] `ecommerce-product-seo` — 商品頁 SEO：規格、變體與購買問題怎麼整理。必寫：商品資訊、變體網址、結構化資料。
- [x] `marketing-plan-small-business` — 小店行銷計畫怎麼寫：目標、受眾與每月檢查。必寫：目標拆解、通路預算、檢查週期。
- [x] `marketing-mix-models` — 4P、7P 與 4C 怎麼用：從產品清單改成顧客問題。必寫：模型差異、服務情境、落地行動。
- [x] `stp-persona-research` — STP 與人物誌：用訪談資料決定服務誰。必寫：市場分群、目標選擇、人物誌證據。
- [x] `customer-journey-funnel` — 顧客旅程與行銷漏斗：找出讀者在哪一步離開。必寫：接觸點、漏斗量測、改善假設。
