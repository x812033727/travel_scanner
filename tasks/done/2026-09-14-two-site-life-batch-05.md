# 兩站原創生活分享批次 05

## Why

依使用者核定的兩站標題盤點計畫，製作全部不重複主題。總表：`docs/content-research/two-site-life/catalogue.json`。

## Definition of done

- [x] 本批每篇都有原創正文、1600×900 封面、SVG 圖解、官方來源及查證日。
- [x] ingest、限定 slug lint、逐張圖片 QA 與相關測試通過。
- [x] 交付可匯入內容包；未執行正式站匯入、發布或部署。

## Steps

- [x] `woocommerce-wishlist` — WooCommerce 願望清單：收藏、分享與庫存提示。必寫：訪客會員儲存、TI Wishlist設定、資料與庫存。
- [x] `woocommerce-quote-request` — WooCommerce 詢價流程：商品需求到正式報價。必寫：詢價表單、YITH設定、報價與購物車區分。
- [x] `woocommerce-order-email` — WooCommerce 訂單信怎麼改：YayMail、內容與寄送驗收。必寫：信件情境、模板客製、不同客戶端檢查。
- [x] `woocommerce-order-operations` — WooCommerce 出貨工作流：通知、明細與列印。必寫：Order Notify與訂單狀態、列印單據、資料核對。
- [x] `woocommerce-tax-settings` — WooCommerce 稅金設定：含稅標價、運費與顯示方式。必寫：商店設定與稅務義務分界、含稅未稅、訂單核對。
- [x] `online-course-platform-choice` — 線上課程放哪裡：代管平台與自架網站的取捨。必寫：內容與付款需求、LMS外掛、學生體驗。
- [x] `wordpress-booking-system` — WordPress 預約系統：時段、確認信與取消規則。必寫：時間與容量、預約外掛選擇、通知及取消。
- [x] `independent-store-marketplace` — 自架商店還是電商平台：從商品、流量與維運成本判斷。必寫：平台與自架責任、顧客資料、通路取捨。
- [x] `seo-learning-roadmap` — SEO 入門學習順序：先讓網站可讀，再看流量與成效。必寫：搜尋流程、學習資源、改善優先順序。
- [x] `search-crawlers-explained` — 搜尋爬蟲與 AI 爬蟲：網站管理者該怎麼辨識與管理。必寫：抓取與索引差別、robots指令、記錄檔辨識。
- [x] `crawl-budget-diagnosis` — 網站抓取效率怎麼看：重複網址、伺服器與更新頻率。必寫：抓取需求、重複網址、記錄與改善。
- [x] `technical-seo-checklist` — 技術 SEO 檢查順序：抓取、索引、呈現與網站結構。必寫：技術稽核範圍、錯誤分級、驗收方式。
- [x] `on-page-seo-workflow` — 頁面 SEO 怎麼做：從讀者問題到標題與段落結構。必寫：頁面意圖、內容組織、WordPress設定。
- [x] `seo-search-intent` — 搜尋意圖怎麼判斷：把關鍵字變成真正要回答的問題。必寫：意圖判讀、結果頁觀察、內容任務。
- [x] `seo-keyword-research` — 關鍵字研究工作流：需求清單、長尾詞與選題優先序。必寫：關鍵字來源、Google規劃工具、需求與轉換。
- [x] `seo-content-cannibalization` — 文章互搶排名怎麼辦：辨識重複意圖與整併內容。必寫：重複意圖、保留與合併、成效追蹤。
- [x] `seo-title-writing` — 文章標題怎麼寫：讓搜尋讀者看懂範圍與用途。必寫：標題資訊、誇大承諾、搜尋標題差異。
- [x] `seo-content-quality` — SEO 文章品質檢查：來源、實用細節與內容維護。必寫：研究流程、原創附加價值、更新與校對。
- [x] `seo-trust-sensitive-topics` — 網站如何建立可信度：作者、資料來源與高風險主題。必寫：EEAT概念、YMYL範圍、查證責任。
- [x] `seo-agency-selection` — SEO 與 GEO 公司怎麼評估：服務範圍、證據與驗收。必寫：提案與報價比較、地域服務查證、成果與保證迷思。
