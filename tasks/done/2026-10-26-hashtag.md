# 影片說明欄的 hashtag 把泰文母音與聲調符號刪掉

## Why

`hashtagsFrom` in `tools/video/core/metadata.mjs` keeps only `[\p{L}\p{N}_]`, so it drops combining marks (`\p{M}`). Thai vowels and tone marks are combining marks, so the Thai description of every video ends with garbled hashtags: the tag 「ซานาดะ ยูกิมูระ」 becomes `#ซานาดะยกมระ`. The review of the `curio-s13-v2` Thai captions found it on 2026-10-26; every Thai description the tool composed has the same problem, and the same goes for any script that uses combining marks (Hindi, Vietnamese written with combining diacritics).

## Definition of done

- [ ] Thai (and other combining-mark) tags keep every mark in their hashtag.
- [ ] Existing behavior for Latin, CJK and punctuation stays the same.

## Steps

- [x] Keep `\p{M}` in the hashtag character class.
- [x] Add a Thai case to `metadata.test.mjs`.

## How to verify

`node --test tools/video/core/metadata.test.mjs`

## Notes

- Packages already built before the fix need `package` re-run so their Thai descriptions pick up the fixed hashtags.
