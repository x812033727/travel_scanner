# 偶的江湖 全系列路線圖：17 項待站主決定的事（生父、冥棺、超量季、支線第四部、主角缺席等）

## Why

《偶的江湖》全系列路線圖（`docs/videos/series-plans/ou-de-jianghu/saga/README.md`）把主線排成 65 季 780 集、外傳 2 季 24 集，但合併與缺漏檢查留下 17 項只有站主能決定的事，清單在路線圖最後一節「需要站主決定的事」。決定之前，第三季以後的分集細綱不能開寫：生父、冥棺、超量季與主角缺席都會改到季級的事件。

## Definition of done

- [x] 路線圖最後一節的 17 項，每一項都有站主的決定（採用建議、改成別的、或明確不做），寫在本票 Notes。
- [x] 路線圖、`saga/roadmap.json`、`saga/names.json` 依決定更新；標「建議，待站主核准」的字樣改成定案或刪除。
- [x] 若決定做支線第四部，另開一張票做外傳第三季的時代企劃。

## Steps

- [x] 把 17 項逐項問站主（可以一次問完，附路線圖的建議）。
- [x] 依決定改路線圖與兩個 JSON；重跑名字掃描（不得出現原作人名與「霹靂」字樣）。
- [x] 回填各時代企劃的季號與跨期生死（第 11、13 項）要等第三季以後真的開寫細綱時，在那一期的企劃包裡做，不在本票。
