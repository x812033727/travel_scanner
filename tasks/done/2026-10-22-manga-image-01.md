# 動態漫畫等級 manga：全靜圖零片段、旁白說書、image-01 邊角裁切，三分鐘爽文試片

## Why

站主 2026-10-22 丟了 youtu.be/0r9ZmCt-BtQ（桃桃爱漫画，爽文旁白「动态漫画」，1 小時 49 分，每 3–4 秒換一張動漫靜圖加慢推，沒有角色動作）問能不能用 MiniMax 的貼圖方式做這種漫劇，並定了：不用海螺，圖片用 image-01，先出樣張再試片。樣張（`~/mokaair-work/videos/_audition/image01-anime-20261022/`，20 張 US$0.07）過關：帶設定圖當 `subject_reference` 時同一角色六個場景臉髮疤一致；不帶參考每張換人；雙人鏡頭只能帶一張臉，第二人會走樣；約三成的圖在邊角長小字或假簽名，兩張自帶上下黑邊。

現有的漫劇流程差三件事才做得出這種片：

1. 最低的畫面等級 `stills` 仍允許一成片段，撰稿模型被提示詞叫去「把片段留給最大的高潮」，所以一定會買片段；而且單集漫劇（`one-off`）的表單根本沒有畫面等級，作品列預設 `clips`，series.json 不帶等級，lint 與提示詞都不會管它。
2. 撰稿模型寫的是角色對白劇，不是旁白說書：參考片是旁白帶故事、角色只講短句。
3. image-01 的邊角小字沒有人裁：`media/trim.mjs` 只裁平坦的紙邊，不裁長在畫面邊緣的字。

## Definition of done

- [ ] 後台「新的漫劇」與一鍵合集表單都能選「動態漫畫」等級；選了的作品 series.json 帶 `visual_tier: "manga"`，劇本裡任何一鏡寫成 clip 都被 lint 擋下，`clips` 階段一秒片段都不買。
- [ ] manga 等級的撰稿提示詞寫明：旁白說書、每 3–5 秒一張新圖、角色台詞短、雙人同框少、每鏡 still 加運鏡且運鏡輪替。
- [ ] manga 等級的關鍵影格在 judge 之後、進 manifest 之前，四邊各裁掉 4%（`trim.mjs` 的 inset）再放回原尺寸，和紙邊裁切同一條路。
- [ ] 報價、admin 五語字串、BINGE.md 的等級表都有 manga 一列；migration 0137 把 `ck_video_drama_series_tier` 放寬到四個值。
- [ ] 站上用「新的漫劇」發起一支三分鐘、anime-2d、manga 等級的原創都市爽文旁白試片（image-01 是現在的全站圖片模型，不用指定），成片核准後語言面板勾八語 CC。
- [ ] 旁白聲音：站主聽過試聽頁（`~/mokaair-work/videos/_audition/manga-narrator-20261022/index.html`，八個 Gemini 聲音 × 兩種語氣）後選一組，寫進漫劇分頁的旁白聲音。

## Notes

- 樣張怎麼出的：scratchpad 的 `draw.mjs`（副本在樣張資料夾）直接 import `tools/video/media/client.mjs` 送 `submitImage`，借 `curio-h07` 當 slug；站上 media status 的圖片選擇本來就是 minimax/image-01。image-01 只收一張 `role: "character"` 參考、提示詞含 negative 要 < 1500 字、只畫 1K；22 送 1 次 MiniMax ReadTimeout。
- 參考頻道念的是別人的小說；我們用原創前提。角色一致性的前提是設定圖當參考，所以 manga 等級仍走有角色的漫劇路（look → 設定圖 → 關鍵影格），不是解說片那條無角色的路。
- 為什麼是新等級而不是把 `stills` 改成零片段：`stills` 的「最多一成」已經有作品在用（品牌故事固定 `stills`），而且合集報價靠它。
- 為什麼單集表單也要等級：三分鐘試片走 `one-off`（一份故事聖經＋劇本關卡），而 `one-off` 的 series.json 原本不帶任何合集欄位，等級到不了 lint 和撰稿。
