# 兩站原創生活分享批次 04

## Why

依使用者核定的兩站標題盤點計畫，製作全部不重複主題。總表：`docs/content-research/two-site-life/catalogue.json`。

## Definition of done

- [x] 本批每篇都有原創正文、1600×900 封面、SVG 圖解、官方來源及查證日。
- [x] ingest、限定 slug lint、逐張圖片 QA 與相關測試通過。
- [x] 交付可匯入內容包；未執行正式站匯入、發布或部署。

## Steps

- [x] `elementor-forms-addons` — Elementor 表單與外掛：從收件需求決定擴充範圍。必寫：表單動作、第三方擴充、相容性驗收。
- [x] `divi-site-building` — Divi 建站流程：全域樣式、範本與維護方式。必寫：版型編輯、擴充需求、雲端版型與維護。
- [x] `divi-mobile-type-layout` — Divi 手機版排版：欄位順序、字型與閱讀動線。必寫：視覺與閱讀順序、字型載入、各寬度驗收。
- [x] `divi-portfolio-child-theme` — Divi 作品集與子主題：整理作品並保留客製修改。必寫：作品集分類、子主題用途、更新測試。
- [x] `divi-subscription-sharing` — Divi 訂閱與分享元件：Bloom、Monarch 的使用時機。必寫：訂閱流程、分享元件、隱私與效能。
- [x] `blocksy-theme-setup` — Blocksy 主題設定：從網站識別到手機導覽。必寫：外觀客製、頁首頁尾、區塊與響應式。
- [x] `avada-business-site` — Avada 製作形象網站：模板匯入後該修改什麼。必寫：模板內容替換、全域樣式、更新與效能。
- [x] `newspaper-editorial-site` — Newspaper 主題架設內容網站：分類首頁與閱讀頁設計。必寫：文章分類、首頁模組、閱讀與效能。
- [x] `themeforest-license-purchase` — ThemeForest 購買前檢查：授權、支援與更新範圍。必寫：產品授權、支援期限、憑證與更新。
- [x] `woocommerce-store-launch` — WooCommerce 開店流程：商品、結帳與測試訂單。必寫：商店設定、主題選擇、訂單驗收。
- [x] `woocommerce-theme-extension-choice` — WooCommerce 主題與外掛：先畫購物流程再選工具。必寫：購物任務、相容性、YITH與主題驗收。
- [x] `woocommerce-product-types` — WooCommerce 商品怎麼建：實體、數位與可變商品。必寫：商品類型、尺寸顏色、分類與庫存。
- [x] `woocommerce-product-information` — WooCommerce 商品頁：描述分頁、輪播與購物判斷。必寫：產品資訊、媒體展示、無障礙與速度。
- [x] `woocommerce-payments-shipping` — WooCommerce 金流物流怎麼串：付款、出貨與狀態驗收。必寫：綠界及RY整合、回呼通知、物流狀態。
- [x] `woocommerce-paypal-setup` — WooCommerce 串接 PayPal：帳戶、測試付款與退款。必寫：商家帳戶與串接、交易幣別、退款驗收。
- [x] `woocommerce-shipping-rules` — WooCommerce 運費規則：地區、重量與免運門檻。必寫：運送區域、條件優先序、邊界測試。
- [x] `woocommerce-checkout-fields` — WooCommerce 結帳欄位：地址選單與資料最小化。必寫：地址格式、欄位客製、付款物流相容性。
- [x] `woocommerce-member-checkout` — WooCommerce 要不要強制登入：訪客結帳與會員體驗。必寫：購物阻力、會員需求、帳號復原。
- [x] `woocommerce-promotions-coupons` — WooCommerce 折扣怎麼設：折價券、滿額與疊加檢查。必寫：券種條件、促銷互斥、結帳試算。
- [x] `woocommerce-loyalty-points` — WooCommerce 紅利積分：累積、折抵與退款規則。必寫：點數生命週期、折抵限制、取消訂單處理。
