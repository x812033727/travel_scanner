# 兩站原創生活分享批次 08

## Why

依使用者核定的兩站標題盤點計畫，製作全部不重複主題。總表：`docs/content-research/two-site-life/catalogue.json`。

## Definition of done

- [x] 本批每篇都有原創正文、1600×900 封面、SVG 圖解、官方來源及查證日。
- [x] ingest、限定 slug lint、逐張圖片 QA 與相關測試通過。
- [x] 交付可匯入內容包；未執行正式站匯入、發布或部署。

## Steps

- [x] `swot-tows-action-plan` — SWOT 與 TOWS：把優劣勢分析變成行動清單。必寫：內外部證據、策略配對、優先序。
- [x] `pestle-business-scan` — PESTLE 怎麼分析：把外部變化整理成經營風險。必寫：環境面向、可查證指標、策略連結。
- [x] `ansoff-growth-options` — 安索夫矩陣怎麼用：市場與產品擴張的四種選擇。必寫：成長方向、能力缺口、小規模驗證。
- [x] `bcg-portfolio-review` — BCG 矩陣怎麼看：產品組合分析的用途與限制。必寫：矩陣假設、資料基準、資源分配。
- [x] `porter-five-forces` — 五力分析怎麼做：理解競爭與議價能力。必寫：產業界線、五種力量、策略與限制。
- [x] `business-models-b2b-d2c` — B2B、B2C 與 D2C：客戶、銷售流程與行銷重點。必寫：採購角色、通路責任、內容與銷售週期。
- [x] `omo-channel-integration` — OMO 與 O2O 怎麼做：把門市、網站與會員流程接起來。必寫：線上線下接點、資料同意、服務驗收。
- [x] `martech-tool-stack` — 行銷工具怎麼整合：從資料流程減少重複訂閱。必寫：需求矩陣、資料流與權限、整合成本。
- [x] `content-marketing-calendar` — 內容行銷怎麼排：讀者問題、素材與更新節奏。必寫：內容目的、編輯日曆、回顧維護。
- [x] `marketing-copywriting` — 行銷文案怎麼寫：說清楚價值、條件與下一步。必寫：資訊層級、情境範例、主張證據。
- [x] `brand-tone-vibe-marketing` — 品牌語氣與氛圍行銷：讓內容一致又能回答問題。必寫：語氣與視覺、情境一致性、效果驗證。
- [x] `social-media-planning` — 社群內容怎麼安排：主題、互動與維護界線。必寫：平台任務、內容配比、回覆規則。
- [x] `ugc-word-of-mouth` — UGC 與口碑行銷：徵求心得、取得授權與回應負評。必寫：內容授權、真實評價、揭露與回覆。
- [x] `influencer-collaboration` — 網紅合作怎麼評估：KOL、KOC 與合作驗收。必寫：受眾適配、合作範圍、資料與成果。
- [x] `short-video-marketing` — 短影音企劃：Reels 的腳本、製作與成效回顧。必寫：訊息與腳本、拍攝剪輯、成效指標。
- [x] `marketing-agency-contract` — 行銷與廣告代操怎麼委託：帳號、費用與交付成果。必寫：服務分工、帳號資產、費用及驗收。
- [x] `paid-vs-organic-marketing` — SEO 與付費廣告怎麼配：需求、時程與預算取捨。必寫：搜尋與社群廣告差異、自然流量、整體配置。
- [x] `google-ads-first-campaign` — Google 搜尋廣告入門：關鍵字、素材與轉換檢查。必寫：投放流程、搜尋詞與素材、轉換驗證。
- [x] `google-ads-budget` — Google 廣告預算怎麼算：競價、實際支出與代操費。必寫：預算與競價、計費範圍、費用拆分。
- [x] `google-pmax-evaluation` — Performance Max 怎麼評估：目標、素材與自動投放界線。必寫：活動用途、素材與資料、成果解讀。
