# 兩站原創生活分享批次 09

## Why

依使用者核定的兩站標題盤點計畫，製作全部不重複主題。總表：`docs/content-research/two-site-life/catalogue.json`。

## Definition of done

- [x] 本批每篇都有原創正文、1600×900 封面、SVG 圖解、官方來源及查證日。
- [x] ingest、限定 slug lint、逐張圖片 QA 與相關測試通過。
- [x] 交付可匯入內容包；未執行正式站匯入、發布或部署。

## Steps

- [x] `meta-ads-first-campaign` — Meta 廣告入門：Facebook、Instagram 與 Threads 的設定檢查。必寫：帳號與版位、素材規格、轉換追蹤。
- [x] `dcard-advertising-basics` — Dcard 廣告怎麼準備：受眾、素材與成效判斷。必寫：官方管道、素材與政策、量測。
- [x] `line-ads-basics` — LINE 廣告適合什麼需求：帳號、版位與轉換規劃。必寫：現行產品名稱、投放需求、成效追蹤。
- [x] `chatgpt-ads-status` — ChatGPT 廣告怎麼查：開放地區、官方規則與品牌準備。必寫：推出狀態查證、廣告與回答分界、可驗證準備。
- [x] `marketing-metrics-roi-roas` — ROI、ROAS 與廣告成本：用同一筆訂單算清楚。必寫：公式與分母、毛利退貨、指標限制。
- [x] `ga4-site-measurement` — GA4 網站量測入門：資料串流、事件與安裝驗收。必寫：追蹤安裝、事件設計、重複與漏記。
- [x] `ga4-sessions-engagement` — GA4 工作階段與互動：跳出率、離開頁該怎麼讀。必寫：指標定義、版本差異、分群分析。
- [x] `google-tag-manager-setup` — Google Tag Manager 上手：標籤、觸發條件與發布紀錄。必寫：容器權限、預覽測試、版本與回復。
- [x] `utm-link-conventions` — UTM 參數怎麼命名：讓活動來源能比較。必寫：命名規則、連結驗證、個資與一致性。
- [x] `short-url-management` — 短網址怎麼用：目的地、追蹤與失效風險。必寫：轉址服務選擇、品牌連結、存續管理。
- [x] `microsoft-clarity-review` — Microsoft Clarity 看什麼：熱點圖、錄影與隱私設定。必寫：資料遮罩、觀察任務、樣本與行為假設。
- [x] `google-business-profile` — Google 商家檔案怎麼管理：資格、資訊與評價回覆。必寫：資格與驗證、營業資訊、評價與權限。
- [x] `email-newsletter-planning` — 電子報怎麼開始：訂閱同意、內容與寄送指標。必寫：名單來源、訂閱退訂、工具選擇。
- [x] `kit-newsletter-setup` — Kit 電子報工作流：訂閱表單、分眾與自動信。必寫：表單與同意、分眾條件、發送驗收。
- [x] `mailchimp-wordpress-newsletter` — Mailchimp 接 WordPress：MC4WP 表單與名單同步。必寫：訂閱流程、名單同步、退訂與重複。
- [x] `brevo-newsletter-account` — Brevo 電子報與帳戶管理：寄件驗證、名單與停用處理。必寫：寄件身分、名單品質、申訴及復原。
- [x] `sms-marketing-consent` — 簡訊行銷怎麼規劃：同意、時機與退訂流程。必寫：名單授權、訊息範圍、發送與退訂。
- [x] `social-chatbot-workflow` — 社群聊天機器人：Manychat、Chatfuel 與真人接手流程。必寫：平台現況、觸發與回覆、權限和真人接手。
- [x] `adsense-site-preparation` — 網站申請 AdSense 前：內容、政策與版位準備。必寫：官方資格、原創內容、廣告設定與驗收。
- [x] `wordpress-ad-placement` — WordPress 文章廣告怎麼放：Ad Inserter 與閱讀體驗。必寫：版位選擇、載入與手機、政策驗收。
