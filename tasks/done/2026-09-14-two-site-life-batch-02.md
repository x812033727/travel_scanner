# 兩站原創生活分享批次 02

## Why

依使用者核定的兩站標題盤點計畫，製作全部不重複主題。總表：`docs/content-research/two-site-life/catalogue.json`。

## Definition of done

- [x] 本批每篇都有原創正文、1600×900 封面、SVG 圖解、官方來源及查證日。
- [x] ingest、限定 slug lint、逐張圖片 QA 與相關測試通過。
- [x] 交付可匯入內容包；未執行正式站匯入、發布或部署。

## Steps

- [x] `fastcomet-wordpress-setup` — FastComet 主機怎麼評估：資源、備份與 WordPress 安裝。必寫：資源限制、備份責任、安裝驗收。
- [x] `managed-hosting-comparison` — WordPress 主機比較怎麼做：用同一張需求表評估供應商。必寫：同基準比較、測試方法與限制、續約成本。
- [x] `wordpress-local-development` — 在電腦建立 WordPress 測試站：MAMP 與上線前準備。必寫：本機環境、資料匯出、測試站隔離。
- [x] `wordpress-admin-basics` — WordPress 後台怎麼用：內容、外觀與管理員的工作分界。必寫：後台導覽、角色權限、修改前紀錄。
- [x] `wordpress-posts-pages` — WordPress 文章與頁面怎麼分：建立內容與選擇網址。必寫：文章頁面差別、編輯與摘要、發布檢查。
- [x] `wordpress-taxonomy-navigation` — WordPress 分類、標籤與選單：讓讀者找到下一篇。必寫：分類標籤、導覽排序、永久連結變更。
- [x] `wordpress-widgets-sidebar` — WordPress 側邊欄與小工具：安排資訊與固定區塊。必寫：區塊與傳統小工具、固定元素、手機遮擋檢查。
- [x] `wordpress-themes-plugins-install` — 安裝 WordPress 主題與外掛：來源、更新與停用流程。必寫：安裝方法、相容性、回復與移除。
- [x] `wordpress-blog-build` — 用 WordPress 建立個人部落格：從分類到第一篇文章。必寫：個人網站架構、版型與閱讀、文章工作流。
- [x] `wordpress-business-site` — 小公司形象網站怎麼做：服務頁、信任資訊與詢問流程。必寫：服務頁結構、品牌資訊、聯絡轉換。
- [x] `wordpress-theme-selection` — WordPress 佈景主題怎麼選：閱讀、編輯與長期維護。必寫：區塊與傳統主題、可攜性、實際驗收。
- [x] `wordpress-page-builder-choice` — WordPress 頁面編輯器怎麼選：區塊、版型與維護負擔。必寫：編輯需求、相容性、移除後結果。
- [x] `wordpress-website-backup` — WordPress 備份怎麼做：檔案、資料庫與還原演練。必寫：備份範圍、異地保留、UpdraftPlus與WPvivid還原驗收。
- [x] `wordpress-host-migration` — WordPress 換主機不換網域：搬站、測試與 DNS 切換。必寫：資料移轉、預覽測試、切換與回復。
- [x] `wordpress-domain-migration` — WordPress 換網域：轉址、搜尋訊號與郵件一起檢查。必寫：網址替換、轉址對照、搜尋與郵件驗收。
- [x] `wordpress-local-to-live` — 把本機 WordPress 搬上網：檔案、資料庫與網址替換。必寫：本機匯出、正式環境差異、網址與媒體驗證。
- [x] `wordpress-com-migration` — 從 WordPress.com 搬到自架站：內容、媒體與網址交接。必寫：免費付費差異、內容匯出與匯入、媒體及轉址驗收。
- [x] `domain-registrar-transfer` — 網域換註冊商：移轉鎖、授權碼與 DNS 保持運作。必寫：移轉資格、授權碼流程、郵件與解析確認。
- [x] `wordpress-migration-aftercare` — 搬站之後檢查什麼：搜尋流量、舊主機與續約收尾。必寫：切換觀察、舊服務停用時點、備份保留。
- [x] `wordpress-reset-safely` — WordPress 重置前先分清楚：內容、主題設定與整站還原。必寫：重置影響、測試站操作、還原計畫。
