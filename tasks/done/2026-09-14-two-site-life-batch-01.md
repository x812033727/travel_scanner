# 兩站原創生活分享批次 01

## Why

依使用者核定的兩站標題盤點計畫，製作全部不重複主題。總表：`docs/content-research/two-site-life/catalogue.json`。

## Definition of done

- [x] 本批每篇都有原創正文、1600×900 封面、SVG 圖解、官方來源及查證日。
- [x] ingest、限定 slug lint、逐張圖片 QA 與相關測試通過。
- [x] 交付可匯入內容包；未執行正式站匯入、發布或部署。

## Steps

- [x] `website-cms-choice` — CMS 與架站平台怎麼選：從更新方式決定網站的家。必寫：內容更新頻率、託管責任、可攜性與遷移成本。
- [x] `wordpress-first-site` — 第一次架設 WordPress：從測試站到公開網站。必寫：主機網域關係、安裝流程、上線前檢查。
- [x] `wordpress-com-org-choice` — WordPress.com 與自架 WordPress：維護、費用與掌控權怎麼取捨。必寫：代管與自架責任、外掛限制查證、退出與備份。
- [x] `website-budget-worksheet` — 架站預算怎麼編：把首年、續約與維護分開算。必寫：成本項目、續約時間表、需求縮減。
- [x] `website-maintenance-routine` — 網站維護要做什麼：備份、更新與故障回報的日常安排。必寫：維護範圍、責任與頻率、驗收紀錄。
- [x] `hosting-types-explained` — 共享主機、VPS 與雲端代管：小網站的選擇順序。必寫：隔離與管理責任、資源指標、擴充條件。
- [x] `domain-registration-guide` — 買網域前先做的功課：名稱、持有人與續約管理。必寫：註冊商與所有權、續約成本、網域移轉。
- [x] `namecheap-domain-setup` — Namecheap 網域設定：註冊後如何連到網站與信箱。必寫：網域持有人、DNS記錄、驗證解析。
- [x] `gandi-domain-management` — Gandi 網域管理：註冊、DNS 與續約檢查。必寫：網域註冊、DNS託管、移轉與續約。
- [x] `dns-records-troubleshooting` — DNS 設定怎麼查：從 A、CNAME 到郵件紀錄。必寫：解析流程、紀錄用途、故障定位。
- [x] `https-certificate-setup` — 讓網站使用 HTTPS：憑證、轉址與混合內容檢查。必寫：憑證與加密、部署與更新、HTTP轉址。
- [x] `domain-hosting-renewal` — 網域或主機到期會怎樣：續約與停用前的檢查表。必寫：網站與郵件影響、資料匯出、到期與贖回。
- [x] `bluehost-wordpress-setup` — Bluehost 架站流程：購買前確認，到安裝後驗收。必寫：方案需求、WordPress安裝、網站驗收。
- [x] `bluehost-domain-billing` — Bluehost 網域與帳務問題：加購、付款與續約逐項確認。必寫：首購續費、網域兌換資格、付款錯誤處理。
- [x] `cloudways-wordpress-setup` — Cloudways 建站：伺服器、應用程式與帳戶驗證。必寫：計費單位、帳戶驗證、應用與網域連接。
- [x] `cloudways-ssl-setup` — Cloudways 的 HTTPS 檢查：DNS、憑證與續期。必寫：解析前提、憑證安裝、續期與轉址。
- [x] `hostinger-wordpress-setup` — Hostinger 架站教學：把第一個 WordPress 網站整理好。必寫：主機購買檢查、安裝與內容配置、上線驗收。
- [x] `hosting-com-wordpress-setup` — hosting.com 架站入門：從舊 A2 名稱到目前的服務選擇。必寫：品牌沿革查證、主機需求、WordPress部署。
- [x] `siteground-wordpress-setup` — SiteGround 建站與搬站前要確認的事情。必寫：主機選擇、測試環境、備份與遷移。
- [x] `hostgator-wordpress-setup` — HostGator 架站指南：安裝、網域連線與交接。必寫：帳戶與網域、安裝、維護責任。
