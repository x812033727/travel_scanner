# 後台營運中心驗收矩陣與 CI

## Why

The existing browser suite intercepted most administrator API calls, so a broken
server-side authorization probe, stale response contract, or real API 4xx/5xx could
still leave CI green. The operations center also needs one source-of-truth page and
role matrix across desktop and mobile layouts.

## Definition of done

- [x] The isolated runtime authenticates the server-rendered admin layout and exposes
      the backend navigation, capability, allowlist and health contract.
- [x] Playwright covers all 19 owner pages, seven role navigation sets, direct-link
      403 boundaries, URL-persisted drawers/filters, safe mutations and Pixel 7 touch
      target/overflow behavior.
- [x] A separate opt-in full-stack suite uses real PostgreSQL/Redis/API/Web endpoints
      without browser API interception and fails on first-party document/API errors.
- [x] Both suites are wired into the existing isolated and full-stack CI jobs.

## Steps

- [x] Add the bearer-aware owner/role bootstrap fixture used by Server Components.
- [x] Add deterministic first-party fixtures for users, audit, database and deployment
      reads, while allowing only explicitly asserted safe writes.
- [x] Add real owner page-registry and disposable viewer role-boundary journeys.
- [x] Add desktop and Pixel 7 layout assertions and production-build coverage.

## How to verify

- `node --check tools/e2e-runtime-api.mjs`
- `npm run typecheck:web`
- `npx eslint e2e/admin-operations.spec.ts e2e/admin-operations-full-stack.spec.ts`
- `npm run build:web`
- `PLAYWRIGHT_SERVE_BUILD=true npx playwright test e2e/admin-operations.spec.ts --workers=1`
  (PowerShell environment syntax locally): 4 passed, 4 project-specific skips.
- CI runs `e2e/admin-operations-full-stack.spec.ts` against its isolated real stack
  with `ADMIN_OPERATIONS_E2E=1`; no `page.route` API interception exists in that spec.

## Notes

The acceptance matrix found and drove fixes for an unnamed mobile menu control, a
24px mobile brand link, a user-drawer runtime state regression, and `schema_info`
contract drift. Local dev validation also exposed a corrupt copied `.next` cache;
moving both caches outside `apps/web` restored clean Tailwind output. The final
production build and production-served isolated matrix pass. Real mutations remain
limited to disposable CI users and the isolated CI database; production is never a
target.
