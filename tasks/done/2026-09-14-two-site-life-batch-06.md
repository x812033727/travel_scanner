# 兩站原創生活分享批次 06

## Why

依使用者核定的兩站標題盤點計畫，製作全部不重複主題。總表：`docs/content-research/two-site-life/catalogue.json`。

## Definition of done

- [x] 本批每篇都有原創正文、1600×900 封面、SVG 圖解、官方來源及查證日。
- [x] ingest、限定 slug lint、逐張圖片 QA 與相關測試通過。
- [x] 交付可匯入內容包；未執行正式站匯入、發布或部署。

## Steps

- [x] `web-design-agency-brief` — 找網頁設計公司前：需求書、報價與交付清單。必寫：需求與外包流程、交付資產、驗收及維護。
- [x] `seo-backlinks-outreach` — 站外 SEO 與反向連結：取得引用與辨識不當操作。必寫：連結價值、自然曝光、垃圾連結風險。
- [x] `seo-domain-authority` — 網站權重分數怎麼看：工具指標與搜尋表現的差別。必寫：第三方指標、比較邊界、改善方向。
- [x] `google-ranking-history` — Google 搜尋更新怎麼理解：熊貓、企鵝與蜂鳥留下的原則。必寫：歷史定位、現行官方說明、內容與連結檢查。
- [x] `google-search-console-workflow` — Search Console 怎麼看：驗證網站、提交頁面與找問題。必寫：驗證與提交、索引檢查、成效判讀。
- [x] `sitemap-website-submission` — 網站地圖怎麼規劃：收錄哪些網址、如何提交與維護。必寫：sitemap範圍、提交與讀取、索引限制。
- [x] `canonical-url-guide` — Canonical 網址怎麼設：處理重複頁面與搜尋訊號。必寫：重複網址、canonical選擇、驗證衝突。
- [x] `redirects-301-302` — 301 與 302 轉址：搬頁、改網址與避免轉址鏈。必寫：永久暫時轉址、對照清單、狀態驗收。
- [x] `website-www-subdomains` — www、子網域與子目錄：網站網址結構怎麼決定。必寫：DNS與路由、內容分區、網址一致性。
- [x] `hreflang-language-sites` — 多語系網站的 hreflang：語言對照、canonical 與錯誤檢查。必寫：語言地區碼、雙向對照、缺頁與索引。
- [x] `structured-data-basics` — 結構化資料怎麼加：從可見內容到搜尋驗證。必寫：schema類型、JSON-LD與可見內容、測試及限制。
- [x] `open-graph-sharing` — 網站分享預覽怎麼修：Open Graph 標題、圖片與快取。必寫：OG欄位、圖片裁切、平台快取。
- [x] `image-seo-workflow` — 網站圖片怎麼處理：尺寸、替代文字與搜尋可讀性。必寫：圖片壓縮與命名、alt、Smush與上傳流程。
- [x] `core-web-vitals-diagnosis` — Core Web Vitals 怎麼改善：從真實使用資料找瓶頸。必寫：LCP INP CLS、實驗室與真實資料、改善驗收。
- [x] `pagespeed-performance-review` — PageSpeed Insights 分數怎麼讀：量測網站速度的正確順序。必寫：測試條件、診斷與分數、改善前後比較。
- [x] `website-cache-cdn` — 網站快取與 CDN：更新沒出現時該清哪一層。必寫：快取層級、CDN用途、更新失效檢查。
- [x] `wordpress-performance-plugins` — WordPress 加速外掛怎麼用：快取、圖片與功能衝突。必寫：WP Rocket與NitroPack範圍、基準量測、快取排除。
- [x] `lazy-loading-images` — 圖片延遲載入怎麼設：讓重要內容先顯示。必寫：首屏優先、載入時機、尺寸保留。
- [x] `amp-website-decision` — 網站還需要 AMP 嗎：先比較維護成本與讀者體驗。必寫：目前支援查證、效能與替代方案、退出驗收。
- [x] `seo-plugin-selection` — WordPress SEO 外掛怎麼選：Rank Math、Yoast 與實際需求。必寫：功能與付費界線、資料遷移、設定相容性。
