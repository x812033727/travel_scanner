# MiniMax 配音不設網站月字數上限

## Why

站主（2026-11-13）決定奇聞檔案局每集八語配音都用 MiniMax，重錄的集數也一樣。
`video_speech_minimax_monthly_character_limit` 預設 300,000 字，一集八語約 6 萬字，
一個月只夠四集多，配音會在月中被網站自己擋下（429 video_speech_budget_exhausted）。
MiniMax M Plan 本身已有每 5 小時與每週的用量窗，站主要網站這層不要再限制。

## Definition of done

- [x] 預設值改成 0：照 `reserve_azure_speech_characters` 的規則，0 只計數、不阻擋；
      `/api/v1/video/speech/status` 回 `minimax_monthly_limit: 0`，影片工具顯示
      "minimax: no monthly limit"（tools/video/tts/cli.mjs 與 dubs/cli.mjs 已這樣解讀 0）。
- [x] 仍可用 `VIDEO_SPEECH_MINIMAX_MONTHLY_CHARACTER_LIMIT` 設一個數字恢復上限。

## How to verify

```bash
cd apps/api && uv run pytest tests/test_video_speech_minimax.py
```

部署後 `node tools/video/cli.mjs dub --slug <slug> --locale en --dry-run` 印出
`minimax: no monthly limit`。若主機 `.env` 自己設了這個變數，要把那行拿掉才會生效。
