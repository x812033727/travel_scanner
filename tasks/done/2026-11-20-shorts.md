# Shorts 零台詞短劇規則與教訓：分共用區與四系列個別區、五拍分鏡與審劇本三道檢查、四關成片品管與雲端同步

## Why

站主 2026-11-19 指示將無語音（零台詞）Shorts 的分鏡結構、剪接、聲音、AI 避險、審劇本與成片品管經驗正式寫入 Shorts 規則，並比照長篇 AI 劇（`docs/videos/drama/`）與解說系列（`docs/videos/explainer-series/`）分成「共用區」與「系列個別區」，同時將 2026-11-04 四個零台詞系列（《汪家夫妻》《闖禍小浣熊》《網美小豬》《社畜地獄》共 20 集）五輪品管與笑點重剪的實戰問題與經驗寫入教訓並納入 `docs/videos/rules-sync/` 自動同步到雲端硬碟，讓後續規劃、審劇本與製作時能直接照規則避開已知陷阱。

## Definition of done

- [x] 建立 Shorts 零台詞短劇共用規則區 `docs/videos/shorts-drama/`：
  - `README.md`：總覽、統一規格、一集從頭到尾流程與共用／個別區索引。
  - `WRITING.md`：黃金五拍分鏡公式（11–16 秒、5–6 鏡逐秒規格）、鏡位與運鏡（單人框鐵律、80% 鎖定機位）、聲音三層設計（BGM、`music_off` 瞬間留白、物理音效打點在鏡內）、第 0 關 AI 6 大系統性陷阱與英文 Prompt 避險寫法，以及花錢前的「審劇本與分鏡三道檢查」（含可直接貼給獨立審稿代理的交辦範本）。
  - `REVIEW.md`：從首格與片段預檢、第 1 關 `qa_check.py` 自動檢查、第 2 關獨立審片人畫面與雙人笑點審核（含獨立審片提示詞範本）、第 3 關五級由便宜到貴修法，到第 4 關八語標題說明、雲端硬碟備份與後台 `shorts import`。
- [x] 建立四個系列的個別規則區 `docs/videos/shorts-drama/series/`（`wangjia-couple.md`、`raccoon-mischief.md`、`influencer-piglet.md`、`shechu-hell.md`），收錄各系列角色定妝錨點、專屬五拍公式、系列專屬 AI 避險、EP1–EP5 實戰修正紀錄與後續集數儲備。
- [x] 建立 `docs/videos/lessons/shorts.md`，收錄無語音 Shorts 共用與四系列 20 集實戰教訓。
- [x] 在 `.agents/skills/animation-preproduction/references/script-to-storyboard.md` 補上無語音 Shorts 審劇本／審分鏡的規則入口與三道檢查指引。
- [x] 更新 `docs/videos/rules-sync/`（`watch.txt`、`manifest.tsv`、`README.md`、`sync.test.mjs`），將 `docs/videos/shorts-drama/**/*.md` 與 `docs/videos/lessons/shorts.md` 納入雲端硬碟自動同步，且測試全數通過。
