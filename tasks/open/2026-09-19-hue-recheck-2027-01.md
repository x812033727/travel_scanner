# hue-day-trip-from-da-nang 上線後複查：每年 1 月門票法規與電子售票、2027-03-01 前 HĐ 觀光列車、hueworldheritage 恢復後補開放時間

## Why

`hue-day-trip-from-da-nang` 的門票表依順化市人民議會 55/2025（2026-01-04 施行），電子售票 API 每年可能換價；HĐ1 到 HĐ4 順化－峴港觀光列車的時刻與票價公布後，「當天來回只能包車或巴士」的結論可能改變；`hueworldheritage.org.vn` 主站與富牌機場官方頁（acv.vn）撰稿時讀不到。規格 `docs/travel-guides-batch-7/hue-day-trip-from-da-nang.md`「上線後與交叉檢查」要求上線 PR 開一張票，2027-03-01 前回查一次。

## Definition of done

- [ ] 2027-01：電子售票 API 與收費決議重查完；有新決議就改門票表、算術段、summary 與 diagram-1。
- [ ] 2027-03-01 前：dsvn.vn 或鐵路運輸股份公司是否公布 HĐ1–HĐ4 時刻與票價查過；公布了就改 H2-1、summary 與 FAQ 第 1 題。
- [ ] hueworldheritage.org.vn 恢復後補開放時間，把「以現場為準」改掉；acv.vn 恢復後補順化機場那句的官方出處。
- [ ] 每次改動更新 `checked_on`，lint 通過。做完一輪就 done，下一年度另開票。

## Steps

- [ ] **每年 1 月（第一次 2027-01）**：重查電子售票 API 的票價與聯票組合；順化市人民議會若通過新的收費決議（現行是 2026-01-04 施行的 55/2025），改門票表、算術段、summary 與 diagram-1。
- [ ] **2027-03-01 前**：查 dsvn.vn 或鐵路運輸股份公司有沒有公布 HĐ1 到 HĐ4 順化－峴港觀光列車的時刻與票價。有就改 H2-1、summary 與 FAQ 第 1 題，並重新判斷「當天來回只能包車或巴士」的結論。
- [ ] **`hueworldheritage.org.vn` 主站恢復後**：補各景點開放時間，把「以現場為準」改掉（規格說這是本篇最想補的一項）。
- [ ] **富牌機場官方頁（acv.vn）恢復後**：補順化機場那一句的官方出處，並評估是否把越南航空航線頁那筆 source 換掉。
- [ ] 跑 lint 與內容包測試，部署後 `guides-import --dry-run` 再 `--publish`。
