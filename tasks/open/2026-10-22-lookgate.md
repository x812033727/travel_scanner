# lookGate 只要站上有任一角色的設定圖審核就不再補送，缺角色的影片永遠等站主

## Why

票 `2026-10-22-409` 的現象裡，工人「再也沒重試」的那一半在 `tools/video/automation/flow.mjs` 的
`lookGate`：它向站上讀這份 `characters/manifest.json` 的設定圖審核，`reviews.length` 不是 0 就不再呼叫
`review-push --gate look`，接著只看「有沒有被退回」「是不是每個角色都核准了」——少了審核的角色既不會被退回也不會被核准，
影片就一直停在設定圖關卡，`auto.json` 也沒有 `blocked`，後台只看得到第一個角色的卡。

`2026-10-22-409` 修了伺服器的清檔與 `review-push` 本身的重送，所以正常情況三筆都會一次送上；但只要任何原因讓一輪只送上部分角色
（服務中斷、一筆 422），這個關卡還是會卡死。

## Definition of done

- [ ] 站上這份 manifest 的設定圖審核缺了任一角色時，`lookGate` 會再呼叫一次 `review-push --gate look`（已送上的角色由站上以同 hash＋subject 回原本那筆），而不是等站主。
- [ ] `tools/video/automation/automation.test.mjs` 有一個測試：站上只有兩個角色中的一個有審核 → 這一輪會 push；push 之後三個都有 → 不再 push。

## Steps

- [ ] `lookGate`：把「`!reviews.length` 才 push」改成「manifest 裡有角色在站上沒有這份 hash 的審核（任何狀態）就 push」。
- [ ] 補測試；跑 `npm run test:tools`。

## How to verify

`node --test tools/video/automation/automation.test.mjs` 通過；主機上對一支只送上部分角色的漫劇跑一輪 `auto`，log 出現 `character sheets sent to /admin/videos`，後台每個角色都有卡。
