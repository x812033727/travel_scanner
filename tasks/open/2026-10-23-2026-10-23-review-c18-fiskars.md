# Independently review C18 Fiskars treatment sources

## Why

The C18 author submitted a source matrix and six-chapter Treatment in draft PR #1702. A different reviewer must reopen the primary sources, test every M01–M12 claim and visual boundary, and bind a verdict to the exact Git blob hashes before an owner can adopt the Treatment.

## Definition of done

- [x] A review-only receipt identifies the exact head and two SHA-256 hashes, verifies every matrix row against primary material, and gives a clear PASS or HOLD with concrete repairs.
- [x] The author Treatment and source matrix are not edited; no script, paid work, import, upload, merge, or publication is performed.

## Steps

- [x] Verify PR #1702 current head, author task scope, and actual Git blob hashes; claim only the review receipt path.
- [x] Open the company history, prospectus, 2003/2006 annual reports, 2017/2014 company releases, MoMA collection, and CIPO registration; review M01–M12 and six chapters.
- [x] Save a hash-bound receipt, run task and diff checks, and create a draft review PR without auto-merge.

## How to verify

`git show 513d0d3049058e51308d0e2b269b4b44f84ad312:<path>` piped as binary to Python SHA-256 for the two author files; `git diff --check`; `npm run check:tasks`; read back both PR head and draft status. The receipt contains per-row source links and the precise HOLD repair.

## Notes

HOLD is limited to M02 / Treatment chapter 2: the original source says post-war management reformed the company structure to accommodate mass production, not that actual scissors output or a specific mass-production start was established. The 2014 company Canada release has inconsistent cover/body dates, so CIPO is the date source. The same company history page shows a photo of a handwritten sheet with scissors, but no readable original vote tally or provenance sufficient to treat it as the 1967 ballot. PR #1702 remains unmerged; a changed Treatment requires a new exact-hash delta review.
