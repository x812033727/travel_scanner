# Unpublished content packs: hub descriptions and lesson ordinals in body text

## Why

站主要求全站不再顯示會成長的數字（篇數、第幾篇），理由是「會一直增加」。
程式那一半在 #533，已上線的三篇中心文章在 `2026-09-16-content-packs-counts-in-hub-titles`。
剩下的都在**尚未發布**的內容包裡：

| 內容包 | 寫死的數字 |
| --- | --- |
| `claude-code-tutorials` | 描述「從 **96 篇**文章…分成 **96 個**可以獨立閱讀的小題目」 |
| `codex-learning-hub` | 描述「規劃 **60 篇** Codex 教學、十個單元」，**五個語系都有** |
| `claude-code-build-todo-app` | 描述「不必先完成**前五十四篇**」 |
| 73 個包的正文 | 「第 N 篇」：37 `claude-code-*`、29 `gemini-*`、5 `notebooklm-*`、2 `google-flow-*` |

正文的「第 N 篇」多數是下載連結標籤（「第 61 篇練習材料」「下載第 69 篇完整練習包」）；
另有三處是散文引用（`gemini-api-document-service-capstone.json:169,267`、
`claude-code-practice-project-setup.json:90`、`notebooklm-multiformat-lesson-pack.json:96`）。
