# 製作 GoPro 品牌故事 X07 前製包

## Why

站主要接續製作符合奇聞檔案局規格的品牌故事，並在每集完成後開 PR。GoPro Karma 2017 年復售、公司自稱在其價位帶第二，2018 年卻退出無人機，是一手申報可查的反常決策。本票以 X07 獨立題目建立可追溯前製，避免把 2016 年撤回錯寫成唯一原因。

## Definition of done

- [x] 六章、單線、具體事件驅動的繁中 Treatment 與來源矩陣已由 SEC 原件建立。
- [x] 30–60 秒濃縮開場、5 秒片頭、至少 8 分鐘實質正文、21 秒片尾、可點連結與 US$25 全項上限都有明確交接。
- [x] 寫出稿面逾 8 分鐘的實質逐字稿、分鏡、YouTube 文案及逐句來源矩陣，經獨立來源審查、兩份敘事盲讀與 lint；實測時長仍是媒體關卡。
- [ ] 完成正式品牌素材選定、US$25 當期預算、媒體生成、TTS 時長、完整影片 QA 與上架交接；前製草稿 PR 不算成片。

## Steps

- [x] 查重與確認 2016／2017／2018 年報、2018-01-08 原始公告可直接讀取。
- [x] 編成來源說法邊界、Treatment 主張矩陣、六章大綱。
- [x] 逐句寫稿、分鏡、兩支 Shorts 與全項製作報價關卡；媒體生成須等最終審查與價格核對。
- [x] 凍結逐句稿與 Shorts SHA；獨立來源複查、兩份只看逐字稿的敘事盲評及免費 lint 均通過。

## How to verify

`git diff --check`、`npm run check:tasks`、`npm run test:docs-videos`、`node tools/video/cli.mjs lint --slug story-everyday-gopro-x07` 均應通過。來源見 [source-notes.md](../../docs/videos/story-everyday-gopro-x07/source-notes.md) 所列 SEC 原件及同目錄 `reviews/source-review-v7.md`；兩份敘事盲評見 `reviews/blind-a-v7.md`、`reviews/blind-b-v7.md`。TTS 實測、付費媒體與成片 QA 仍待後續執行。
