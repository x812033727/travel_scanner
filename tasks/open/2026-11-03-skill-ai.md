# 製片 skill：趨勢掃描、系列診斷、新主題、新影片（含 AI 寵物短劇）

## Why

站主 2026-11-03 要一個「製片」skill：看最近很夯的議題、短片與影片；建議現有系列怎麼改；發展新主題；
創造新的影片（不一定要主題），例如 Instagram 上 15 秒的 AI 寵物短劇；並用後台數據判斷怎麼改。
同一天的頻道判讀發現：28 天 3.1 萬觀看幾乎全是 Studio 宣傳買的（抽查兩支 98–99%），自然點閱 0.7–0.8%，
30 支片 0 留言；縮圖大字沒有人名、臉被字蓋住。製作的 skill 很多（youtube-video、curio-episode、brand-story、
animation-*），但「決定做什麼、哪個系列該改、用什麼數字判斷」沒有地方寫。

## Definition of done

- [ ] `.agents/skills/producer/SKILL.md` 與 byte-identical 的 `.claude/skills/producer/SKILL.md`，`npm run test:tools` 過。
- [ ] 四種工作各有步驟與產出格式：趨勢掃描、系列診斷、新主題、新影片／短劇；每一步指向既有的工具與製作 skill，不重寫它們。
- [ ] 判斷用的數字與門檻寫明出處（YouTube Help、Creator Playbook、vidIQ／1of10），沒查證的標明。
- [ ] 短劇格式寫清楚，並寫明目前 Shorts 工具 25–55 秒放不進 15 秒成片的缺口。

## Steps

- [ ] 寫 SKILL.md（≤300 行）與 references：趨勢掃描、系列診斷、短劇格式、評分表。
- [ ] 複製到 `.claude/skills/producer/`，跑 `npm run test:tools`。
- [ ] 開 PR。

## How to verify

`npm run test:tools`（skills.test.mjs 檢查鏡像、frontmatter、路徑寫法）。
