# 三個新聞索引增補 4.6 的 11 篇（只有 zh-TW，update_index.py 要能限定語系）

## Why

批次 4.6（`2026-09-19-news-batch-4-6-news-since`）的 11 篇只有 zh-TW。三個索引文章
（AI／科技／幣圈 2026 索引）是五語系，4.5 用 `docs/news-2026-batch-4/update_index.py`
原地增補連結時是五語一起做：`NEW` 表跨語系套用（連結文字抄各語系的 title）、`CITED`
把每篇第一個來源加進索引的 sources（上限 20，AI 索引 4.5 後已 19 條）。這兩件事對
zh-TW-only 的批次都不成立，所以 4.6 出 PR 時沒有動索引；11 篇靠 sitemap、Atom feed、
垂直列表頁與 `related` 被發現，索引頁的站內連結留給這張票。

## Definition of done

- [x] `update_index.py` 支援只在指定語系插入連結（例如 `--locale zh-TW`），其他語系的索引一字不動，
      而且對已插入過的連結第二次執行要拒絕（沿用「每個替換只能命中一次」的做法）。
- [x] `CITED` 對這批不套用（AI 索引會超過 20 條來源上限）；寫清楚為什麼。
- [x] 三個索引 zh-TW 各加上 4.6 的連結：AI 4 篇接在 `ai-news-google-cc-family-agent-20260918` 之後（按月份清單）；
      科技 4 篇進各自的主題群（npm→平台與開發者、CISA→資安／法規、Windows→平台、iPhone Duo→硬體或開發者）；
      幣圈 3 篇進各自的地區群（OCC→美國、EBA→歐盟、SEC→美國），連結文字逐字抄各內容包當時的 zh-TW `title`
      （npm 那篇的標題在查核後已改，勿用研究紀錄舊標題）。
- [x] 索引的 `check_article.py` 不適用；跑 `pack_cli lint --kind life --slug <index>` ×3 與內容測試。
- [ ] 部署後 `guides-import --slug` 三個索引（動作是 update），確認 zh-TW 索引頁出現 11 個連結、其他語系頁不變。
      **未做**：本 session 不 push、不部署；合併後由協調者照 Notes 的指令跑。

### 2026-09-22 做了什麼（commit 69ee0115 工具、8d1861f3 內容、HANDOVER 與本票）

- **`--locale` 的設計**：`parse_args()` 收 `--locale=zh-TW`（可重複、可逗號列），未給就是五語（4.5 以前的行為）；
  回傳的語系一律照 `verticals.LOCALES` 的順序，所以同一道指令兩次跑的順序相同。表格形狀沒變（本來就以語系為鍵）。
  包的語系檢查分成兩路：五語跑照舊要求 `list(pack["locales"]) == LOCALES`，限定語系的跑只要求「本次每個語系都在包裡」，
  否則 `f"{slug} carries no {missing}; run with --locale=<包裡有的>"`。
- **三個守門**（只在語系是子集時檢查，都在讀任何檔案之前）：`EDITS`／`INSERT`／`TABLE`／`DROP_COLUMN`／`CAPTION`／`RETITLE`
  留在本次不跑的語系列上 → 具名拒絕（`misdirected()`）；`CITED` 非空 → 拒絕；`RETITLE` 非空 → 拒絕。
- **`--dry-run`**：驗證完用 `difflib.unified_diff` 印出「會寫進去的那份序列化字串」與現檔的差異，不寫檔；
  `main()` 先把 stdout 轉成 UTF-8（diff 裡是中日韓文）。乾跑跑兩次輸出逐位元組相同，`git status` 乾淨。
- **`CITED` 對這批全空的理由**（寫進腳本註解）：AI 索引已引 19 條、科技 17 條，上限 20（`GuideDocument` 讀出來的），
  四篇就爆；而且 `sources` 屬於單一語系文件，只加進 zh-TW 會讓同一個索引的五個語系文件引不同來源，
  之後任何批次都補不回來（要去改四個沒人讀過的語系）；4.6 的 11 個包也只有 zh-TW，本來就沒有別的語系來源可抄。
  `INSERT` 空的理由相同：索引的敘述段是五語文字，只寫進 zh-TW 會讓五個語系描述不同的東西——所以 AI 索引第二段
  也**沒有**像 4.5 那樣加一句點名本批四篇。
- **CISA 放哪一群（站主可改）**：科技索引沒有「開發者」群，唯一的資安群是「歐盟：資安法規與平台條款」，
  而 CISA 是美國機關 → 放「平台與軟體」，接在 npm 那篇後面（兩篇都是開發者供應鏈的事）。要改只需動 `NEW` 裡那一列。
- **第二次執行的確切訊息**（結束碼 1，`--dry-run` 也一樣，因為驗證在印 diff 之前）：
  `zh-TW block 0: expected one '之後多次增補（最近一次 2026-09-18），' in the paragraph's text nodes, found 0`
  （先撞到的是 `EDITS` 的 `replace_once`，`NEW` 的 `<locale>: <slug> is already linked` 排在它後面）。
- **不帶旗標**（五語跑）也拒絕：`ai-news-anthropic-accenture-evaluation-20260918 does not carry all five locales yet`；
  `--locale=en` 拒絕：`this run is en, and these edits are written for a locale it does not touch:` 後面列
  `ai zh-TW: 3 sentence edits`、`tech zh-TW: 1 sentence edit`、`crypto zh-TW: 1 sentence edit`。
