# 祖奶奶今年十八 第一季審劇本：系列設定、60 集分鏡、獨立審稿

## Why

《祖奶奶今年十八》（2025-01-tai-nainai）要開拍，但手上只有 `season-01.json` 的逐集細綱，沒有製作端照抄就能拍的分鏡。
照 `animation-preproduction/references/script-to-storyboard.md` 的審劇本流程，先寫一份全季共用的系列設定（時間線、接點表、帳、場景格局、道具、人物與參考圖、燈帳），
再每人五集寫分鏡，跑 `storyboard-check.py`，由沒寫那幾集的代理分段重疊審稿，意見交回原寫稿者改，裁定寫回系列設定。

## Definition of done

- [x] `production/s1-bible-e001-e060.md` 與 `production/cast.json` 齊備，寫稿與審稿都照它。
- [x] `docs/videos/tai-nainai-e001` … `e060` 每集一份 `script.md`，`storyboard-check.py` 全部 0 ERROR。
- [x] 60 集都經過獨立審稿（20 段、相鄰重疊一集），意見由原寫稿者改完，每集有「2026-11-06 審稿後的修改」一節。
- [x] 系列設定有〈寫稿中補定的事〉〈審稿後補定的事〉〈要站主決定的〉三節。
- [ ] PR 開到 main（不合併，等站主）。

## Steps

- [x] 系列設定與 cast.json。
- [x] 12 位寫稿代理各五集；主控逐批 commit、把新設定寫回 bible。
- [x] 20 段獨立審稿（1–4、4–7、…、58–60）。
- [x] 意見交回原寫稿者改稿；交界衝突由主控裁定寫進〈審稿後補定的事〉。
- [ ] 全季檢查、片長表更新、PR。

## Notes

- 票的 scope 原本寫 `docs/videos/tai-nainai`，但 `tools/tasks.mjs` 只比對目錄前綴，不含 `tai-nainai-eNNN`，所以改列 60 個目錄。
- 寫稿代理用 Opus、effort max、一次 12 個；兩個因單次輸出超過 128k token 中斷（1–5、41–45），叫它一次只寫一集、分段 Write 就過了。
- 主控的「中途存檔」commit 會收進寫稿者還沒交的半成品，定稿 commit 以工作樹為準；寫稿者看到 git 顯示 M 不用理。
- 審稿最常見的問題（已寫成〈審稿後補定的事〉通則）：「她」指錯人、過肩鏡的肩與畫框邊寫反、畫面欄的比喻被畫出來、紙與螢幕只靠「虛焦」擋字、總人數與列出的人對不上、燈 5／6 的光照出祠堂、人物自己的左右與畫面左右混用。
- 交界衝突的裁定：25→26 老陳站位；50→51 地契不離手（手機拍簽名放投影機）；車鑰匙在長桌南端；藥局電腦在櫃台北端；周懷安車內司機不入鏡；九十六歲只拍臉與手；黑漆茶盤是第 1 集林美鳳端的。
- 審稿後拆鏡用加字母的鏡號（c08b、c13a/b），接點表引用的鏡號不變。第 22、50、55 集比細綱目標多 2.5–7 秒，保留。
- 要站主決定的八＋一條在 bible〈要站主決定的〉（Kore／Gacrux 試聽、16:9、CC、不改細綱、預算、第 54 集股份、童謠怎麼錄、說話人括號）。
