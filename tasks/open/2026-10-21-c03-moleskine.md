- [x] C03 的一手來源矩陣、六章 Treatment、完整旁白與畫面計畫完成，獨立查核逐項綁定最終稿件雜湊。

- [ ] 製出正文至少 8 分鐘的 1080p 本機試看片、可關閉繁中 CC、實測音訊與畫面 QA；正式品牌素材、站主看片、上傳與發布各另留實際收據。

## Steps

- [x] 核對原始公司／投資人／交易所資料，標出品牌自述與無法證實的傳說。
- [x] 寫六章因果主線、30–60 秒濃縮開場、每 30–45 秒鉤子與三句收尾。
- [x] 由另一代理逐來源審查稿件與場景，修正後重新綁定雜湊；跑 lint 與說故事盲評。
- [ ] 乾跑語音、插畫與配樂並核對預算、餘額及現有工作；只在已核定範圍內執行付費步驟。
- [ ] 聽核音訊、審查插圖、合成與驗證試片；將正式站、站主與 Studio 關卡分開交接。
