# 製作 C03 Moleskine 品牌故事試作包

## Why

「日用品的意外轉身」已規劃 C03 Moleskine，但這一列仍只是待查候選。C01／C02 的本機試片另有持有者；本票獨立處理 C03，先釐清舊式筆記本、1990 年代建立的品牌與後來公司的關係，再用可讀的一手來源製作下一支影片，不沿用其他集的審稿或媒體核准。

## Definition of done

- [x] C03 的一手來源矩陣、六章 Treatment、完整旁白與畫面計畫完成，獨立查核逐項綁定最終稿件雜湊。
- [x] 付費前有整集張數、語音、評審、配樂與重試上限估價；整支維持 US$25 上限。
- [ ] 製出正文至少 8 分鐘的 1080p 本機試看片、可關閉繁中 CC、實測音訊與畫面 QA；正式品牌素材、站主看片、上傳與發布各另留實際收據。

## Steps

- [x] 核對原始公司／投資人／交易所資料，標出品牌自述與無法證實的傳說。
- [x] 寫六章因果主線、30–60 秒濃縮開場、每 30–45 秒鉤子與三句收尾。
- [x] 由另一代理逐來源審查稿件與場景，修正後重新綁定雜湊；跑 lint 與說故事盲評。
- [ ] 乾跑語音、插畫與配樂並核對預算、餘額及現有工作；只在已核定範圍內執行付費步驟。
- [ ] 聽核音訊、審查插圖、合成與驗證試片；將正式站、站主與 Studio 關卡分開交接。

## How to verify

`node tools/video/cli.mjs lint --slug story-everyday-moleskine-c03`，再依 `youtube-video` 流程執行乾跑、媒體生成、音訊檢查、`qa` 與 `package`；以 `ffprobe`、完整解碼、字幕時序與實際檔案 SHA 驗證試片。`npm run test:docs-videos`、`npm run check:tasks`。
