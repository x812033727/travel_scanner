# 製作 C02 特百惠品牌故事本機試看片

## Why

站主要求延續「日用品的意外轉身」系列，並明確指定影片沿用奇聞檔案局的製作規則。C02 特百惠目前只有選題；要把 2024 年重整、資產出售和仍在流通的品牌分清楚，再製成可供審閱的本機試看片。

## Definition of done

- [x] 官方原始資料逐項核對，六章故事、逐字稿及分鏡通過獨立來源查核與敘事盲評。
- [x] 完成至少八分鐘旁白、MiniMax 插畫、配樂、濃縮開場、5 秒概念片頭、21 秒概念片尾及繁中可關閉字幕的 1080p 本機試看片。
- [x] 完成製作預算、試看片 QA、來源連結及正式上架交接；不把概念品牌素材或本機 QA 冒充正式審核。

## Steps

- [x] 認領只涵蓋 C02 製作包的任務，沿用已配對的雲端影片工具。
- [x] 逐項查核 SEC 原件，確認 2024 年資產出售與品牌／原公司之別。
- [x] 寫稿、分鏡、來源與敘事審核，跑 lint 及付費前乾跑。
- [x] 按單支 US$25 上限生成音訊、圖片和配樂，合成本機試片與執行可完成的技術 QA；正式旁白與品牌 QA 待正式工人處理。
