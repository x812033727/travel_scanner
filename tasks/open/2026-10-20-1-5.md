# 種田娶妻打天下 第1–5集合集：重剪後重做、包頻道片頭片尾、說明加連結

## Why

站主 2026-10-20：確認「種田娶妻打天下 第1–5集 | CC字幕」合集是否 OK，所有語言補齊，上架的東西做完，要有片頭、片尾與連結。

檢查（2026-10-20，只看得到 repo，看不到站主電腦上的成片與正式站後台）：

- **合集是舊畫面。** 合集 10-18 做的；第 1–5 集 10-19 因唐小棠服裝等問題重拍了 25 鏡（`redo-dh-scan-list.json`：e1 2 鏡、e2 8、e3 5、e4 4、e5 6）並重剪重匯入。合集裡還是舊鏡頭，CC 與配音的時間也綁舊剪輯。
- **沒有片頭片尾。** `compile-dh.mjs` 只把各集接起來，沒接頻道片頭與結束畫面片尾，Studio 的影片卡和訂閱鈕沒有位置可放。
- **說明沒有連結。**
- 語言本身齊：第 1–5 集八種外語（en ja ko es pt id vi th）的配音稿每集句數都和中文一樣（51／34／41／33／39），沒有缺漏或空白；合集八語的標題與說明都在 `youtube-locales/`。

## Definition of done

- [x] `compile-dh.mjs` 接頻道片頭與片尾；CC、章節、說明時間、各語言配音跟著移位。
- [x] 九個語言的說明最後都有訂閱連結；結束畫面的 Studio 設定（範本、起點）寫進 `.youtube.json`。
- [x] `prep-import.mjs` 把合集各語言的配音、CC、標題說明一起放進匯入資料夾。
- [ ] 站主電腦上重做合集並重新匯入（見下）。
- [ ] 站主在後台審核新合集，Studio 設多語音軌與結束畫面。

## Steps

在站主電腦（各集工作區與 `_branding` 都在 `VIDEO_WORKDIR`）：

```bash
H=docs/videos/series-plans/zhong-tian-qu-qi/production/hailuo
C="$VIDEO_WORKDIR/zhong-tian-qu-qi-compilations"
rm -rf "$C/e001-005-parts"           # 舊的 parts 是重剪前的，不能 REUSE
DUBS=en,ja,ko,es,pt,id,vi,th node $H/compile-dh.mjs 1 5 "$C/e001-005.mp4"
node $H/local/prep-import.mjs 1-5
node tools/video/cli.mjs import --from "$VIDEO_WORKDIR/zhong-tian-qu-qi-import/zhong-tian-qu-qi-e001-005"
node tools/video/cli.mjs import --from "$VIDEO_WORKDIR/zhong-tian-qu-qi-import/zhong-tian-qu-qi-e001-005" --languages
```

站主已核准過舊合集的話，換成片要走換版流程（`docs/videos/COMPILATIONS.md` 第 5 列）。

## How to verify

- 合成工具假素材試跑（5 段 24 fps、5 秒 30 fps 片頭、21 秒片尾、en/th 配音）：成片 24 fps，第一句 CC 從 1 秒移到 6 秒，章節 0:00/0:16/…，八語說明的章節時間都重寫，配音長度與成片差 0.03 秒，`languageFileProblem` 對每個語言檔都回 ok。
- 真的成片：腳本最後印 `en: … s against … s`，各語言都在 0.3 秒內；`end screen: … start M:SS`。
