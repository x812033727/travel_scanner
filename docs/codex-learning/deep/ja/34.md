## このレッスンの到達点

> Windows、macOS、Linux の端末を開き、現在のフォルダーを確認してファイルを読み、Codex を起動する前に場所を確かめます。読む時間は約 12 分、実習は約 20 分です。削除、インストール、管理者操作はなく、パスと読み取りコマンドだけを扱います。自分の OS の手順を選んでください。

## 画面、シェル、入力を区別する

端末は文字操作のウィンドウで、PowerShell、Bash、zsh などのシェルがコマンドを解釈します。codex を起動すると同じ窓の中でエージェントの対話画面に入ります。一つの窓でも入力先は変わります。PS とパスがあれば通常 PowerShell、Codex の入力欄ならエージェントへの依頼です。シェルコマンド、/plan、自然言語を区別せず一度に貼り付けないでください。

絶対パスは C:\Work\demo や /home/reader/demo のようにドライブやルートから始まります。相対パスは現在地が基準で、. は現在、.. は親です。端末の場所を変えてもファイルが移動したり、別の端末も同時に移動したりはしません。新しい窓では前の記憶に頼らず毎回場所を確かめます。

## 二階層のフォルダーとテキストを用意する

ファイル管理画面で新しい codex-terminal-lab を作り、中に空白を含む lesson one を作ります。同名があれば別名にして、以降は実際のパスを使います。lesson one 内に UTF-8 の標準テキスト note.txt を作り、次の一行を書いて保存します。先に GUI で作ることで、端末が読んだファイルの場所を把握できます。

```text ファイル内容：lesson one/note.txt に貼り付ける
Terminal practice: this is lesson one.
```

構造は次のとおりです。Windows では note.txt.txt、macOS では RTF を避け、Linux では大文字小文字を保ちます。名前の空白は正しく、引用符の練習に使えます。コード欄には入力する命令や内容だけがあり、`PS C:\>` や $ のプロンプト記号を付け足さないでください。

```text フォルダー構成：照合用であり、コマンドではありません
codex-terminal-lab/
  lesson one/
    note.txt
```

## Windows：PowerShell の操作

スタートから PowerShell を開くか、エクスプローラーの codex-terminal-lab で「ターミナルで開く」を選びます。コマンドプロンプトが開いたら PowerShell に切り替えてください。Get-Location は cmd.exe の命令ではありません。次の読み取り命令で場所と直下の項目を確認し、lesson one がなければ先にエクスプローラーで実際のパスを確認します。

```powershell PowerShell：現在地とファイルを確認する
Get-Location
Get-ChildItem -Name
```

手動移動が必要なら、エクスプローラーで codex-terminal-lab の完全なパスをコピーし、次の引用符内を置き換えます。YOUR_NAME は仮の名前で、そのまま実行しません。書類が OneDrive や別ドライブにある場合も実際の場所を使います。LiteralPath は角括弧などをワイルドカードとして解釈しません。移動成功は通常無表示なので、もう一度場所を確認します。

```powershell PowerShell：自分の絶対パスに置き換えてから実行する
Set-Location -LiteralPath 'C:\Users\YOUR_NAME\Documents\codex-terminal-lab'
Get-Location
Get-ChildItem -Name
```

練習ルートを確認したら、空白のある子へ移動して読み、親に戻ります。次の命令はファイルを変更しません。途中で英文が表示され、最後は codex-terminal-lab に戻るのが期待値です。最後の一行だけで全体成功とせず、途中のエラーがあれば止めて確認してください。

```powershell PowerShell：練習ルートから移動、読み取り、復帰
Set-Location -LiteralPath '.\lesson one'
Get-Content -LiteralPath '.\note.txt'
Set-Location -LiteralPath '..'
Get-Location
```

## macOS と Linux：端末の操作

macOS は Spotlight から Terminal、Linux はアプリメニューやファイル管理画面から端末を開きます。macOS では zsh、Linux では Bash がよく使われますが、ここでは両方に共通する基本命令だけを使います。pwd は現在地、ls -a は隠し項目を含む一覧です。macOS の /Users を Linux の /home と同じパスだと考えないでください。

```bash macOS／Linux 端末：現在地とファイルを確認する
pwd
ls -a
```

手動移動は cd と空白に続けて、引用符で囲んだ実際の絶対パスを入力します。次は置き換え用の例です。フォルダーを端末にドラッグする場合、空白が自動処理されているか見て、余計な引用符を追加しないでください。$HOME を使う場合は二重引用符で変数が展開されますが、今回は構文を混ぜないため完全なパスを使います。

```bash macOS／Linux 端末：先に自分の絶対パスに置き換える
cd '/absolute/path/to/codex-terminal-lab'
pwd
ls -a
```

lesson one が見えたら次を実行します。同じ文を読めて元の練習ルートに戻るのが期待値です。途中で失敗したら直してから一行ずつ進みます。macOS と Linux の基本手順は共通でも、大文字小文字の扱いはファイルシステムによるため、完全に同じ名前を使いましょう。

```bash macOS／Linux 端末：練習ルートから移動、読み取り、復帰
cd 'lesson one'
cat note.txt
cd ..
pwd
```

## エラー時の動作を確認して Codex を起動する

練習ルートで存在しない missing-folder へ移動します。PowerShell は Set-Location -LiteralPath '.\missing-folder'、macOS/Linux は cd 'missing-folder' です。パス不存在のエラーが出て現在地は変わらないはずです。文言は言語や版で異なります。失敗した移動ではフォルダーは作られず、cd の失敗を確認せず編集へ進んではいけないことが分かります。

### 違う場所から読み、相対パスを直す

現在地が練習ルートの codex-terminal-lab で、note.txt は lesson one の中だけにあることを確認します。自分の OS のブロックを使ってください。一行目は note.txt が見つからないエラー、二行目は正しいサブフォルダーを指定して Terminal practice: this is lesson one. を読む想定です。読み取り失敗で lesson one に移動することはありません。エラーを隠すために練習ルートにも note.txt を作らないでください。読み取りだけなので元ファイルは変わりません。

```powershell PowerShell：一行目は失敗を想定、二行目でパスを修正
Get-Content -LiteralPath '.\note.txt'
Get-Content -LiteralPath '.\lesson one\note.txt'
```

```bash macOS／Linux 端末：一行目は失敗を想定、二行目でパスを修正
cat note.txt
cat 'lesson one/note.txt'
```

CLI 導入済みなら確認した練習ルートで codex を実行し、次の読み取り依頼を送ります。未導入なら [CLI 入門](article:codex-cli-getting-started)に進み、この授業だけのために権限を変更しないでください。lesson one/note.txt と英文、作業場所が示されるはずです。パスが違えば、まず作業コピーが作られたかを調べてから誤選択を判断します。

```text 自然言語の依頼：Codex の起動後に入力する
Read lesson one/note.txt and report the current working directory.
Do not modify any files. If the file is missing, report the actual error.
```

## 問題対応、終了、追加練習

不明な命令ならシェルを確認し、Get-Content を Bash 命令と考えないでください。パスが分割されたら空白と通常の引用符を確認し、ワープロの曲がった引用符を避けます。アクセス拒否なら管理者実行より、自分の練習フォルダーかを先に確認します。エディターだけがファイルを見ていれば保存し、拡張子、現在地、WSL の別ホームを確認します。

元ファイルは変更していないため、端末を閉じるか練習場所を離れれば終了です。実行中のプログラムは通常 Ctrl+C で中断できますが、書き込み済みデータの復元にはなりません。lesson two/note.txt に別の文を作り、練習ルートから二つを読み分けてください。パスとファイル、空白、失敗後の場所を理解できれば合格です。図の 1、2、3 は場所の確認、読み取り、検証です。

PowerShell のパスは [Microsoft Set-Location 文書](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.management/set-location)、起動は [Codex CLI 文書](https://learn.chatgpt.com/docs/codex/cli)で 2026-09-14 に確認しました。Windows 命令は独立した練習フォルダーでも確認します。macOS/Linux は一般的なシェル操作の説明で、実機画像と称していません。次は [Markdown](article:codex-markdown-basics)と [AGENTS.md](article:codex-agents-md)です。

| 一覧 | Get-ChildItem -Name | ls -a |
| 子へ移動 | Set-Location -LiteralPath '.\lesson one' | cd 'lesson one' |
| 読取 | Get-Content -LiteralPath '.\note.txt' | cat note.txt |
| 親へ戻る | Set-Location -LiteralPath '..' | cd .. |
