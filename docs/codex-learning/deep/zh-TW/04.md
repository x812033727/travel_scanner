## 讀完能做到什麼

> 你會從 iPhone 或 Android 的 ChatGPT 應用程式，連接自己的 Mac 或 Windows 電腦，找到一個 Codex 練習任務，送出唯讀要求，再確認結果來自正確主機。閱讀約 12 分鐘，首次配對與操作約 20 分鐘。這篇先完成一條可核對的 Remote 路線，再說明它與雲端工作的差異。

手機負責傳送需求、回覆與核准；檔案、終端機、瀏覽器及工具由連接的主機提供。手機畫面能看見任務，不表示專案已下載到手機，也不表示關掉電腦後仍能繼續執行。先學會辨識工作位置，比急著在手機上要求大量修改更有用。

## 開始之前：兩邊都要準備

電腦先完成[桌面版入門](article:codex-desktop-getting-started)，準備已解壓縮的[待辦網站材料](https://mokaair.com/guides/codex-first-project/todo-practice.zip)，並以 expected 副本建立 codex-practice 專案。先在電腦開啟這個專案，確認五個檔案都存在；本篇不需另外接上 GitHub 或 SSH 伺服器。

iPhone 從 App Store、Android 從 Google Play 安裝或更新 OpenAI 的 ChatGPT 應用程式。兩邊使用相同 ChatGPT 帳號及工作區，且該帳號可使用 Codex。組織可能需要開啟 Remote Control，登入流程也可能要求 SSO、多因素驗證或通行金鑰。這些條件未完成時，先處理帳號流程，不要用新建一堆任務繞過。

截至 2026-09-14，官方 Remote 文件列出 iOS、Android 作為手機入口，Mac 與 Windows 桌面應用程式作為主機。功能會分階段提供；Linux 桌面預覽版不能因此推定也支援本篇手機主機流程。CLI 或 IDE 擴充套件不能取代首次配對的桌面應用程式。

## 第一階段：在電腦啟用連接

在準備接收工作的那台電腦開啟 ChatGPT 桌面版，進入 Settings → Connections → Control this Mac or PC，選 Set up 或 Add。依畫面啟用遠端存取及完成驗證。請核對這台電腦的名稱與專案，避免在另一台空白測試機完成了配對卻找不到材料。

接著畫面會提供 QR code。這個碼用來配對手機與主機，應由你自己的手機掃描；不要將它放入公開教學截圖或傳給其他人。每台要控制的主機都需要配對，登入相同帳號本身不是所有裝置都已連接的證據。

回到 Connections 檢查是否允許其他裝置連接，以及可用的保持喚醒選項。主機需要開著應用程式、保持連線且未睡眠。Mac 筆電先保持接電與上蓋開啟；Windows 涉及 Computer Use 時，還要依官方條件保持桌面可用。本例只有讀取檔案，不需要為了完成它額外啟用所有電腦控制功能。

## 第二階段：在手機完成配對

iPhone 使用相機掃描主機 QR code，點開連結進入 ChatGPT，依 Remote 設定流程確認相同帳號及工作區。如果連結停在瀏覽器，檢查是否已安裝最新版應用程式，再回主機重新開始配對。不要把網頁聊天紀錄當作 Remote 已連接的完成畫面。

Android 同樣掃描 QR code，選擇以 ChatGPT 開啟，完成帳號與工作區驗證。若系統出現選擇開啟應用程式的提示，確認進入的是官方 ChatGPT。手機未出現 Remote 時，先更新、重新開啟應用程式並檢查帳號可用功能；換手機瀏覽器不能保證取得尚未提供的入口。

兩種系統的完成判準相同：Remote 中出現主機，能選中該主機，並看見其專案或任務。通知權限可用來接收完成或需要注意的提示；即使允許通知，仍應回到任務查看實際結果，不能把通知文字當成檔案驗收。

## 第三階段：完成一個唯讀任務

在手機 Remote 選擇剛配對的主機，再打開 codex-practice 專案中的 Codex 任務。若建立新任務，先確認工作位置依然是主機上的練習資料夾。下面內容貼進手機的任務輸入框，不是在手機搜尋列執行終端機命令。

```text 手機 ChatGPT → Remote → 主機上的 Codex 練習任務
Read this practice project without changing files.
Report the host or environment name if available and the current working folder.
List index.html, style.css, app.js, core.mjs and core.test.mjs.
Explain how task completion is stored and name the localStorage key.
If you cannot inspect a file, report the limitation instead of guessing.
```

回應應指出練習路徑，從程式碼找到專用的 mokaair-codex-todo-v1 儲存鍵，並說明 completed 欄位。回電腦開啟 app.js 與 core.mjs 比對，確認沒有檔案被修改。若只收到一般待辦網站知識，缺少路徑和程式依據，這次仍未完成驗收。

接著在手機送出追問，讓它引用具體檔案說明空白任務為何不能加入。這能檢查你是否延續同一個任務與上下文。你不需要在手機安裝 Node.js，因為本機工具由主機提供；若下一篇要執行測試，仍要先確認主機真的有該工具。

```text 同一個手機 Remote 任務；追問與驗證
In the same project, explain what happens when the new task contains only spaces.
Identify the relevant function and file. Do not edit or reset stored data.
```

預期提到 core.mjs 的 addTask 會整理文字並拒絕空白，搭配表單的錯誤顯示。你可以在電腦預覽中實際輸入空白確認。正常案例是成功讀取專案；邊界案例是拒絕空白輸入，兩者都要有可比對依據。

## 中斷時如何判斷工作狀態

完成唯讀操作後，可短暫讓主機離線，觀察手機是否顯示無法連接；不要在寫入進行中故意測試。恢復連線、開啟主機應用程式後，回原任務查看狀態。離線訊息只代表目前無法連線，不能據此認定前一項操作完全沒有發生。

因此，網路恢復後先查看最後一則回應和檔案，再決定是否重新送出。將同一個「刪除／提交／建立」要求重送多次，可能造成重複結果。這一篇使用唯讀要求，正是為了讓你先練習辨識狀態，再進入需要寫入的流程。

## Remote、雲端與手機網址的差異

Remote 使用連接主機的專案與工具；[雲端任務](article:codex-cloud-tasks-github)使用另外設定的雲端環境。兩者的檔案、分支和依賴不一定相同，不能只因為任務標題相似就當成同一份工作。手機直接開啟某個網頁，也不等於取得電腦本機專案。

同樣地，電腦上 http://127.0.0.1:4173 的 127.0.0.1 指的是那台電腦；在手機瀏覽器輸入同一個網址，指的會是手機自己。需要查看成果時，先在 Remote 任務看主機提供的預覽或截圖。不要為了本篇練習去開放公共連接埠。

## 常見問題與解除連接

手機看不到主機：依序確認主機程式正在執行、允許連接、同帳號與工作區、電腦未睡眠。先修正具體條件再重新配對。舊配對長期未使用時，依官方說明更新兩邊並重做配對。

配對要求沒有出現：開手機 Remote 核對入口，再從主機重啟設定流程；組織帳號請核對 Remote Control 是否由管理者開啟。完成登入不代表組織遠端政策已允許，錯誤訊息應保留給管理者判讀，但不要附上驗證碼。

連上卻找不到檔案：先看主機名稱和工作目錄，再確認專案是否在那台主機。另一台電腦上的資料夾不會因為同名自動同步。將任務交接到別處會涉及實際環境與 Git 狀態，初學者先回原主機完成驗收。

不再需要遠端時，在主機 Settings → Connections 管理已連接裝置，關閉允許遠端控制或移除不再使用的配對。回手機確認已不能操作。關閉 Remote 不會回復先前的檔案變更，也不應當作停止所有工作的保證；有執行中的任務時，先在任務內停止並確認狀態。


| 工作位置 | 提供什麼 | 如何核對 |
| --- | --- | --- |
| 手機 | 需求、追問、核准 | Remote 中選中的主機與任務 |
| Mac / Windows 主機 | 專案檔案與本機工具 | 實際工作目錄與檔案內容 |
| 雲端環境 | 另外設定的程式與依賴 | 雲端任務的環境與分支 |

## 小練習與查證紀錄

在手機要求整理「目前工作位置、檔案清單、未執行檢查」三項交接資訊，再回電腦用同一個任務核對。完成判準是兩邊指向同一主機與路徑，且你能說明哪些結果已實際看過，哪些只是尚待執行的建議。

入口、配對與主機條件依 [Remote connections 官方文件](https://learn.chatgpt.com/docs/remote-connections)於 2026-09-14 查證；本文未在實體 iPhone、Android 或遠端配對流程實測，圖解只用來說明關係。練習網站的行為有獨立瀏覽器驗證。接著可讀[上下文交接](article:codex-context-handoff)、[權限](article:codex-permissions)及[雲端工作](article:codex-cloud-tasks-github)。
