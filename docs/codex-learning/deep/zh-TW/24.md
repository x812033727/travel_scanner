## 目標與準備

> 安裝一個你確實需要的插件，完成外部帳號連線，讀取一份虛構教材，再驗證移除與斷線的差別。閱讀約 15 分鐘、操作約 25 分鐘；需要支援插件的入口及服務帳號。先讀[權限與資料範圍](article:codex-permissions)。本篇以 Google Drive 中你自己建立的練習文件為例，實際可用插件與選項以帳號清單為準。

Plugins 是分發功能的套件，可以包含 [Skills](article:codex-skills)、[MCP](article:codex-mcp) 或其他配套。Skills 說明怎麼完成工作，MCP 工具實際讀取或操作服務。安裝插件不等於已登入那個服務，也不表示每個工具都可立即使用。先把這三種狀態分開，遇到「已安裝但不能讀文件」時才知道該查哪一層。

## 步驟 1：確認使用入口

桌面版從 Plugins 開啟目錄，查看 OpenAI、工作區、Personal 或 Installed 等當下顯示的分類。Windows、macOS、Linux 都先核對桌面版本與插件詳情的環境要求；Linux 預覽中的實際提供情形應在本機清單確認。不要把看到公開介紹頁當成已能在目前系統執行。尚未安裝桌面版可回到[平台選擇](article:codex-platforms-guide)。

CLI 在三種作業系統中都先開啟終端機，進入你的練習資料夾後啟動 codex，再於互動畫面輸入 /plugins。codex 是終端機命令，/plugins 是 Codex 內的斜線指令，必須分開操作。IDE 擴充套件目前不支援 Plugins，不能把 CLI 的選單流程照搬到編輯器裡；需要插件時改用支援的桌面或 CLI 入口。

```sh 終端機：啟動 Codex
codex
```

```text Codex CLI 互動輸入
/plugins
```

| 入口 | 先做的確認 | 本篇操作方式 |
| --- | --- | --- |
| Windows／macOS／Linux 桌面 | 版本、目錄、插件平台條件 | Plugins 詳情中安裝與連線 |
| 三平台 CLI | 已登入、/plugins 可用、市集來源 | 開啟詳情，安裝後開新工作階段 |
| iOS／Android | 帳號在 Chat／Work 可用的插件 | 確認非 Desktop only，再於支援入口使用 |
| IDE | Plugins 不支援 | 改用桌面或 CLI；不混同獨立 Skills |

手機上的插件不是自動取得電腦磁碟的通行證。若工作需要某台電腦的本機檔案，仍依[手機與跨裝置](article:codex-mobile-guide)的連線條件操作；本篇則只讀你選定服務中的文件。標記 Desktop only 的插件不能改在手機直接執行，網頁上可搜尋到也不表示可以安裝在手機上。

## 步驟 2：準備可核對的文件

在你自己的練習用 Google Drive 建立一份文件，標題設為 Codex Plugin Practice，內容完整貼入以下文字。使用私人文件即可，不要為了讓插件讀取而開啟所有人可存取。保留文件網址供下一步指定範圍；若不是這個服務，先完成安裝與狀態紀錄，等你確認替代插件有同等讀取工具後再換例子。

```text 練習文件內容
Codex Plugin Practice
Revision: 1
Document marker: PLUGIN-LAB-A
Task count: 3
Completed count: 2
Pending count: 1
Scope: fictional practice data; read only.
```

這個練習使用固定標記與版本，目的是辨識工具讀到了哪一份文件，並非讓模型猜測三個數字。標題可以重複，網址與標記要對上；若搜尋結果有兩份同名文件，不先選一份碰運氣。先在服務原頁確認內容，再請代理讀取同一網址，才有獨立的比對依據。

## 步驟 3：安裝、連線，再開新任務

打開插件詳情，核對名稱、提供者、市集來源與功能，確認是你打算使用的 Google Drive 插件，再按顯示的安裝按鈕。桌面文件描述為加號；CLI 則在 /plugins 的來源分類中進入詳情安裝。記下插件名稱或識別碼與日期，避免日後把同名的另一份套件當成同一個。

需要登入時，確認授權畫面顯示的服務與帳號是擁有練習文件的帳號，閱讀要求的資料範圍再繼續。不要把密碼、驗證碼、Token 或連線回傳網址貼進對話。若要求的範圍超出你可接受的用途，取消這次連線並記錄未連接；不是靠在提示詞寫「唯讀」就能縮小 OAuth 授權範圍。

登入完成後返回原入口，查看 Installed 與連線狀態，再建立新對話或 CLI 工作階段。某些插件在首次使用時才要求連線，看到已安裝不應省略此步。若使用 API key 登入 Codex，有些需要 OAuth 的插件不提供；先核對帳號認證方式和插件要求，不反覆更換金鑰或在終端機列印它。

## 步驟 4：用實際讀取結果驗收

桌面輸入 @ 選取剛裝好的插件或其技能，再貼上下面需求，把指定位置換成自己的練習文件網址。CLI 在新工作階段直接要求使用已安裝插件處理同一文件，依實際出現的技能選取入口使用。只要求讀指定文件，不搜尋整個帳號或整理所有檔案，這樣結果與資料範圍才容易核對。

```text 給 Codex 的需求；先替換文件網址
Use the installed Google Drive plugin to read this practice document:
<PASTE YOUR PRACTICE DOCUMENT URL HERE>
Return the document title, source link, revision, marker, and the three counts.
Use an actual read result. If access is unavailable, say which step failed.
Do not edit, share, move, delete, or search unrelated files.
```

回覆應指向相同文件，提供 Revision 1、PLUGIN-LAB-A、3／2／1，並有實際讀取工具紀錄。順序依文件中的 total、completed、pending 核對，不因為數字相同就忽略欄位。再親自把文件 Revision 改成 2、Completed 改成 1、Pending 改成 2，請它重新讀取，不在需求中透露新數字；看它是否依新內容更新結果。

如果仍回覆舊數字，先要求重新取得來源並指出實際讀取版本，不直接說「答案錯了重試」；若連線失效、檔案不在該帳號或服務尚未更新，記錄那個錯誤而不是捏造新結果。必要時另開新任務排除舊對話內容的影響。最後回原服務確認文件沒有被代理修改、分享或移動，將你手動改版與代理讀取分開記錄。

## 步驟 5：停用、移除與斷開連線

在 CLI 的 /plugins 中，安裝項目可依畫面用 Space 切換啟用；若要移除，進詳情選 Uninstall plugin。桌面或網頁從已安裝插件詳情尋找相同移除動作。工作區或預設插件可能由管理員控制而不提供此按鈕，此時記錄管理限制，不去刪程式內部快取或手動破壞安裝目錄。

移除套件和解除外部帳號連線是兩件事。個別 MCP 連線可能仍保留，需要到 ChatGPT 的連線管理中選取該服務並斷開；必要時也到服務自己的第三方授權頁確認。先核對是否有其他正常工作共用這個連線，只處理這次練習建立的項目。解除後開新任務確認無法再透過該連線讀取，不能只看 Installed 少一列就宣稱所有存取已撤銷。

將安裝、授權、首次讀取、改版重讀與移除結果各寫一列；沒有實際操作的平台或服務就標記依官方文件查證。這份教材不聲稱已替你登入 Google Drive 或讀取私人文件。圖中 1 是選定插件與範圍、2 是連線與讀取、3 是驗證與收尾；更細的錯誤分層見[插件故障排除](article:codex-plugin-troubleshooting)。
