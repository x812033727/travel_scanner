## 讀完能做到什麼

> 你會確認目前使用的登入方式與工作區，找到對應的用量頁，並用一張不含私人識別資訊的紀錄區分「登入失敗、功能未開放、額度用完」。閱讀約 10 分鐘，操作約 15 分鐘。本篇不需要購買方案、儲值或兌換重置；讀取自己的帳號狀態即可。

## 先分清兩種計費來源

使用 ChatGPT 登入與使用 API 金鑰登入，是兩條不同的存取方式。前者依帳號方案及工作區許可權，後者依 API 組織的計費與限制；同一個電子郵件不會把兩者的額度自動合併。不要因為訂閱有效就假定 API 帳單為零，也不要因為 API 有餘額就推論所有 ChatGPT 雲端功能可用。官方驗證檔案說明雲端 Codex 需要 ChatGPT 登入。

本系列把價格與可用模型的查詢入口集中在這篇及[模型選擇](article:codex-model-selection)，其他教學不重複寫死金額或每日次數。購買前看官方方案頁與自己帳號的實際顯示，包括幣別、稅項、月繳或年繳、席位及工作區條件。使用者畫面沒顯示的方案或選項，不應因教學出現過就假設能購買或使用。

## 第一步：確認帳號與工作區

在桌面版開啟個人選單，檢視目前帳號與工作區。如果你同時有個人與公司工作區，先切到這次要使用的那一個，再看方案和功能。瀏覽器的頭像與桌面程式可能不是同一個登入；切換瀏覽器帳號不代表程式已切換。手機先確認自己使用的登入，再到同一個工作區的用量頁，避免比較不同帳號的數字。

CLI 使用者在作業系統的終端機輸入下方命令，Windows PowerShell、macOS Terminal、Linux 終端機用法相同。這是終端機命令，不是貼在 Codex 對話裡。它用來看驗證狀態；尚未安裝或找不到 codex 時，先回 [CLI 安裝](article:codex-cli-getting-started)，不要把找不到命令當成帳號失效。

```shell
codex login status
```

只記錄它指出的驗證方式與是否已登入，不要複製整份登入快取、Cookie 或金鑰。命令若顯示尚未登入，才執行 codex login 並完成瀏覽器流程；已正常登入時不需要為了跟課程再登出一次。登入方式被組織管理時，依工作區管理員設定處理，反覆覆寫本機設定不會解除組織限制。

## 第二步：開啟正確的用量來源

ChatGPT 登入者使用官方[Codex 用量頁](https://chatgpt.com/codex/settings/usage)。開啟後先核對帳號與工作區，再讀取頁面列出的各個額度區間、剩餘值及重置時間。CLI 的互動階段可輸入 /status 檢視當前狀態；斜線指令是在 codex 啟動後的輸入區，不是在 PowerShell。API 登入者則到自己 Platform 組織的 Usage 與 Billing 核對；ChatGPT 用量頁不能代替 API 帳單。

```text
/status
```

讀百分比前先看標籤是「已使用」還是「剩餘」。假設示例顯示已使用 30%，其餘是 70%；若畫面本來寫剩餘 30%，就不能再反轉一次。沒有數值或正在載入時記為未知，不要當成零。不同期間有各自的重置時間，不可拿其中一個倒數推論全部限制已解除，也不可把較晚更新的頁面當成另一份額度。

## 第三步：建立一份可分享的檢查紀錄

在自己的筆記中複製下面範本，手動填入畫面可確認的資訊。這是紀錄格式，不是設定檔，不需要放到專案根目錄，也不要填寫帳號電子郵件、公司名稱或任何金鑰。時間保留時區，例如 Asia/Taipei，讓後續比較不會把 UTC 與本地時間混在一起；看不到的欄位填 unknown。

```text
Checked at: YYYY-MM-DD HH:mm timezone
Interface and version: desktop / CLI / browser
Authentication: ChatGPT / API / unknown
Workspace category: personal / managed / unknown
Usage source: Codex dashboard / Platform Usage
Window label: copied without private identifiers
Metric meaning: used / remaining / unknown
Displayed value: value / unknown
Reset time and timezone: value / unknown
Feature or error being checked: short description
Next step: verify account / wait / ask workspace admin
```

用一個不用修改檔案的小任務驗證登入，例如請它說明目前練習資料夾有哪些檔案。成功表示這個入口當下可執行該任務，不代表所有模型、雲端功能或外部服務也都可用。若不想消耗用量，只完成狀態檢查即可，並將任務驗證寫成未執行。不要為了測試上限而持續傳送大任務直到額度歸零。

## 常見問題、停止與復原

瀏覽器已登入但 CLI 顯示未登入：先看是否完成回到 CLI 的驗證流程、是否在同一個系統環境，以及是否用了不同 CODEX_HOME。WSL 與 Windows 的家目錄並非同一個。記錄錯誤後重新執行正常登入；不要把 auth.json 上傳給別人排查。沒有瀏覽器的環境可查官方裝置碼流程及工作區是否允許，不要自行停用憑證驗證。

已登入卻沒有某項功能：依序核對入口、版本、工作區角色與方案支援，這不一定是額度問題。顯示用量限制：記下限制名稱與重置時間，先儲存交接紀錄並等待，或自行評估帳號提供的其他選項。登入錯誤、功能資格與用量限制應分開處理；重灌程式不會替帳號增加額度。

本例沒有修改計費設定，結束時關閉用量頁即可。若你真的要登出 CLI，在終端機執行 codex logout；這會清除相應的儲存驗證，不會退費或復原已修改的程式。官方檔案指出 CLI 與 IDE 可共用登入快取，因此在其中一處登出可能讓另一處也需要重新登入。不要為了讓教學截圖乾淨而重置真實帳號資料。

## 完成判準與下一步

小練習是將兩張不同時間的紀錄比對：確認同一帳號型別、同一用量來源、相同區間及時區後，才比較剩餘值。如果任何一項未知，先補證據而不是猜差額。你能指出該看哪個計費來源，並將登入、資格與額度三種問題分開，就完成本篇。接著閱讀[CLI 常用指令](article:codex-commands)、[上下文交接](article:codex-context-handoff)或[有效使用額度](article:codex-usage-efficiency)。
