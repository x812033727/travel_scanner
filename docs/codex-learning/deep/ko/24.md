## 목표와 준비

> 필요한 플러그인을 설치하고 외부 계정을 연결해 가상 문서를 읽은 뒤 제거와 연결 해제의 차이를 확인합니다. 읽기 15분, 실습 25분입니다. 지원 진입점과 서비스 계정을 준비하고 [권한과 데이터 범위](article:codex-permissions)를 읽으세요. 자신의 Google Drive에 만든 연습 문서를 예로 들며 제공 플러그인과 옵션은 계정 목록을 기준으로 합니다.

Plugins는 [Skills](article:codex-skills), [MCP](article:codex-mcp) 등을 묶어 배포합니다. Skills는 절차를 설명하고 MCP 도구는 서비스를 읽거나 조작합니다. 설치가 서비스 인증이나 모든 도구의 즉시 사용을 뜻하지는 않습니다. 상태를 나누면 설치했는데 문서를 읽지 못하는 원인을 찾기 쉽습니다.

## 1단계: 진입점 확인

데스크톱 Plugins에서 OpenAI, 작업 공간, Personal, Installed 등 실제 분류를 확인하세요. Windows, macOS, Linux 모두 버전과 개별 플러그인 요건을 확인하고 Linux 미리 보기는 로컬 목록에서 제공 여부를 봅니다. 공개 소개 페이지가 보인다고 현재 환경에서 실행 가능하다는 뜻은 아닙니다. 설치 전이라면 [플랫폼 선택](article:codex-platforms-guide)을 읽으세요.

세 OS의 터미널에서 실습 폴더로 이동해 codex를 시작한 다음 대화형 화면에 /plugins를 입력합니다. 전자는 셸 명령이고 후자는 대화형 슬래시 명령이므로 따로 실행하세요. IDE 확장은 현재 Plugins를 지원하지 않으므로 편집기에 같은 메뉴를 기대하지 말고 지원 데스크톱이나 CLI를 사용합니다.

```sh 터미널: Codex 시작
codex
```

```text Codex CLI 대화형 입력
/plugins
```

| 진입점 | 먼저 확인 | 실습 경로 |
| --- | --- | --- |
| 세 OS 데스크톱 | 버전, 목록, 개별 플랫폼 조건 | Plugins 상세에서 설치/연결 |
| 세 OS CLI | 로그인, /plugins, 마켓 출처 | 상세 확인, 설치, 새 세션 |
| iOS/Android | 계정 Chat/Work 제공 여부 | Desktop only가 아닌지 확인 |
| IDE | Plugins 미지원 | 데스크톱/CLI 사용, 독립 Skills와 구분 |

모바일 플러그인이 컴퓨터 디스크를 자동으로 열어주지는 않습니다. 로컬 파일 작업은 [모바일과 기기 연결](article:codex-mobile-guide) 조건을 따라야 하며 여기서는 선택한 서비스 문서만 읽습니다. Desktop only는 웹에서 검색되어도 휴대전화에서 직접 실행할 수 없습니다.

## 2단계: 확인 가능한 문서 준비

자신의 연습 Google Drive에 Codex Plugin Practice 문서를 만들고 아래 전체 내용을 붙이세요. 비공개로 유지하며 플러그인이 읽게 하려고 공개 접근을 켜지 마세요. 범위를 지정할 URL을 보관합니다. 다른 서비스라면 먼저 설치와 상태 기록을 마치고 동등한 읽기 도구를 확인한 뒤 예제를 바꾸세요.

```text 실습 문서 내용
Codex Plugin Practice
Revision: 1
Document marker: PLUGIN-LAB-A
Task count: 3
Completed count: 2
Pending count: 1
Scope: fictional practice data; read only.
```

표식과 버전은 도구가 실제 읽은 문서를 구분하기 위한 것이지 숫자를 맞히는 시험이 아닙니다. 제목이 같아도 URL과 표식이 일치해야 합니다. 동명 검색 결과가 둘이면 임의로 선택하지 말고 원래 서비스 페이지를 확인한 뒤 정확한 URL을 요청해 독립적으로 비교하세요.

## 3단계: 설치, 연결, 새 작업

상세에서 이름, 제공자, 마켓 출처, 기능을 확인한 뒤 원하는 Google Drive 플러그인을 설치하세요. 데스크톱 문서는 더하기 버튼을, CLI는 /plugins의 마켓 분류 상세를 안내합니다. 이름이나 ID와 날짜를 기록해 이름이 비슷한 다른 패키지와 혼동하지 마세요.

인증 화면의 서비스와 계정이 연습 문서를 소유하는지 확인하고 요청 권한을 읽으세요. 비밀번호, 인증 코드, 토큰, 연결 반환 URL을 대화에 붙이지 마세요. 허용할 수 있는 목적보다 넓으면 취소하고 미연결로 기록합니다. 읽기 전용 프롬프트가 OAuth 권한 범위를 줄이지는 않습니다.

원래 진입점으로 돌아와 Installed와 연결 상태를 확인하고 새 대화나 CLI 세션을 시작하세요. 처음 사용할 때 연결하는 플러그인도 있어 설치만으로 이 확인을 생략할 수 없습니다. API 키 인증에서는 일부 OAuth 의존 플러그인이 제공되지 않습니다. 키를 반복 교체하거나 출력하지 말고 인증 방식과 요구 조건을 확인하세요.

## 4단계: 실제 읽기 검수

데스크톱에서 @로 설치한 플러그인이나 스킬을 선택하고 아래 요청의 표시 부분을 자신의 문서 URL로 바꾸세요. 새 CLI 세션에서는 같은 문서에 설치된 플러그인을 사용하라고 요청하고 표시되는 스킬 선택 경로를 따릅니다. 전체 계정을 검색하지 말고 지정 문서만 읽어 결과와 범위를 확인하세요.

```text Codex 요청: 먼저 문서 URL 교체
Use the installed Google Drive plugin to read this practice document:
<PASTE YOUR PRACTICE DOCUMENT URL HERE>
Return the document title, source link, revision, marker, and the three counts.
Use an actual read result. If access is unavailable, say which step failed.
Do not edit, share, move, delete, or search unrelated files.
```

같은 문서 링크, Revision 1, PLUGIN-LAB-A, 3/2/1과 실제 읽기 기록을 확인하세요. 숫자만 보지 말고 전체, 완료, 대기 필드에 맞춰 비교합니다. 직접 Revision 2, Completed 1, Pending 2로 바꾼 뒤 새 수치를 요청문에 알려주지 않고 다시 읽게 해 갱신된 내용을 보고하는지 확인하세요.

이전 개수를 반환하면 출처를 새로 읽고 실제 버전을 제시하도록 요청하세요. 연결 만료, 다른 계정, 갱신 지연은 오류로 기록하고 새 결과를 꾸미지 않습니다. 새 작업으로 이전 문맥을 분리할 수도 있습니다. 마지막으로 원래 서비스에서 에이전트가 수정, 공유, 이동하지 않았는지 확인하고 수동 개정과 도구 읽기를 구분하세요.

## 5단계: 비활성화, 제거, 연결 해제

CLI /plugins에서 표시되는 Space로 설치 항목을 전환하고 상세의 Uninstall plugin으로 제거합니다. 데스크톱/웹도 설치된 플러그인 상세에서 찾으세요. 작업 공간이나 기본 플러그인은 관리자가 제어할 수 있으므로 제한을 기록하고 앱 캐시나 설치 폴더를 임의 삭제하지 마세요.

패키지 제거와 외부 계정 연결 해제는 별개입니다. 별도 MCP 연결은 남을 수 있어 ChatGPT 연결 관리에서 서비스를 끊고 필요하면 제공자 측 외부 앱 권한도 확인하세요. 다른 작업이 공유하는지 확인하고 이번 연습 연결만 처리합니다. 새 작업에서 해당 연결로 읽을 수 없는지 확인해야 하며 Installed 항목 하나가 사라졌다고 모든 접근이 취소되었다고 하면 안 됩니다.

설치, 승인, 첫 읽기, 개정 후 읽기, 제거를 각각 기록하고 조작하지 않은 플랫폼은 공식 문서 확인으로 표시하세요. 이 교재는 독자의 Drive에 인증하거나 비공개 문서를 읽었다고 주장하지 않습니다. 그림 1은 선택/범위, 2는 연결/읽기, 3은 검수/정리입니다. 자세한 원인 구분은 [플러그인 문제 해결](article:codex-plugin-troubleshooting)로 이어집니다.
