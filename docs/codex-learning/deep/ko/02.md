## 이 강의의 목표

> 로그인 방식과 워크스페이스를 확인하고 해당 사용량 화면을 찾습니다. 개인 식별 정보 없이 로그인 실패, 기능 미지원, 사용 한도 소진을 구분하는 기록을 작성합니다. 읽기 약 10분, 실습 약 15분입니다. 요금제 구매, 충전, 초기화 사용은 필요 없으며 계정 상태만 확인합니다.

## 두 가지 과금 방식 구분하기

ChatGPT 로그인과 API 키 로그인은 별도의 접근 방식입니다. 전자는 계정 요금제와 워크스페이스 권한을, 후자는 API 조직의 과금과 제한을 따릅니다. 이메일 주소가 같다고 한도가 합쳐지지 않습니다. 구독 중이어도 API 요금이 무료라는 뜻은 아니고 API 잔액이 있어도 모든 ChatGPT 클라우드 기능을 쓸 수 있는 것은 아닙니다. 공식 인증 문서에 따르면 클라우드 Codex는 ChatGPT 로그인이 필요합니다.

가격 확인 경로는 이 글에, 모델 가용성은 [모델 선택](article:codex-model-selection)에 모아 다른 강의에서 고정 가격이나 일일 횟수를 반복하지 않습니다. 구매 전 공식 요금제 페이지와 본인 계정에서 통화, 세금, 월간·연간 결제, 좌석 수, 워크스페이스 조건을 확인하세요. 튜토리얼에 언급된 요금제나 옵션이 자신의 계정에서도 구매 또는 사용 가능하다는 뜻은 아닙니다.

## 1단계: 계정과 워크스페이스 확인

데스크톱의 프로필 메뉴에서 현재 계정과 워크스페이스를 확인합니다. 개인용과 회사용이 모두 있으면 이번 실습에 쓸 공간을 선택한 다음 요금제와 기능을 확인하세요. 브라우저와 앱이 서로 다른 계정일 수 있으며 브라우저 계정 변경만으로 앱이 바뀌었다고 볼 수 없습니다. 휴대전화에서도 로그인과 워크스페이스를 맞춰 다른 계정의 사용량을 비교하지 않도록 합니다.

CLI 사용자는 운영체제 터미널에서 아래 명령을 입력합니다. PowerShell, macOS Terminal, Linux에서 명령은 같습니다. Codex 대화에 붙이는 요청이 아니라 인증 상태를 확인하는 셸 명령입니다. codex를 찾지 못하면 [CLI 설치](article:codex-cli-getting-started)를 확인하세요. 실행 파일이 없다는 것이 계정 오류를 의미하지는 않습니다.

```shell 터미널 명령: CLI 로그인 상태 확인
codex login status
```

인증 방식과 로그인 여부만 기록하고 로그인 캐시, 쿠키, 키는 복사하지 않습니다. 로그아웃 상태일 때만 codex login을 실행해 브라우저 인증을 완료하세요. 이미 로그인되어 있으면 실습을 위해 일부러 로그아웃할 필요가 없습니다. 조직이 인증을 관리한다면 관리자 설정을 따릅니다. 로컬 설정을 반복 수정해도 조직 제한이 해제되지는 않습니다.

## 2단계: 알맞은 사용량 화면 열기

ChatGPT 로그인이라면 공식 [Codex 사용량 페이지](https://chatgpt.com/codex/settings/usage)를 엽니다. 계정과 워크스페이스를 확인한 다음 표시된 기간별 한도, 잔여량, 초기화 시간을 읽습니다. CLI 대화 중에는 /status로 상태를 볼 수 있지만 PowerShell이 아니라 codex를 시작한 뒤 입력해야 합니다. API 키 사용자는 해당 Platform 조직의 Usage와 Billing을 확인합니다. ChatGPT 사용량 화면은 API 청구서를 대신하지 않습니다.

```text 대화형 슬래시 명령: 실행 중인 Codex CLI에 입력
/status
```

백분율을 읽기 전에 사용량인지 잔여량인지 확인합니다. 가상 예시로 30% 사용했다면 70%가 남지만 이미 30% 남았다고 표시되면 다시 뒤집어 계산하지 마세요. 값이 없거나 로딩 중이면 0이 아니라 알 수 없음입니다. 기간마다 초기화 시간이 다를 수 있으므로 하나의 남은 시간으로 모든 제한이 풀렸다고 판단하지 않습니다. 나중에 갱신된 화면도 별도의 한도가 아닙니다.

### 해석 실습: 같은 30%도 뜻이 다를 수 있어요

다음은 가상 기록이며 실제 계정 정보나 요금제 보장이 아닙니다. A: 개인 워크스페이스의 한 사용 기간, 지표는 ‘사용’, 값은 30%. B: 다른 워크스페이스, 지표는 ‘남음’, 값은 30%이며 초기화 시간은 표시되지 않습니다. 각각 얼마나 남았는지, B의 초기화 시간을 추정할 수 있는지, API 대시보드의 잔액으로 A의 구독 한도를 확인할 수 있는지 판단하세요.

정답: A는 70%, B는 30%가 남았으며 B의 초기화 시간은 알 수 없습니다. 다른 워크스페이스의 값을 하나의 잔액으로 더하거나 서로 덮어쓰면 안 됩니다. API 잔액으로 ChatGPT 구독 한도를 확인할 수 없습니다. 값이나 지표명이 없을 때도 0 대신 모름으로 기록하세요. 실제 사용량 페이지에서는 출처, 워크스페이스, 기간, 시간대를 확인한 뒤 표시된 값을 기록합니다.

유지 관리 참고: 현재 공식 문서에 따르면 ChatGPT Work와 Codex는 사용량을 공유하므로 다른 Work 작업도 같은 계정의 한도에 영향을 줄 수 있습니다. [공식 사용량 설명](https://learn.chatgpt.com/docs/pricing)과 자신의 사용량 페이지를 기준으로 삼으세요. 요청문 길이만으로 남은 작업 수를 계산할 수는 없습니다.

## 3단계: 공유 가능한 확인 기록 작성하기

아래 양식을 개인 메모에 복사하고 화면에서 확인한 정보만 채웁니다. 설정 파일이 아니라 기록이므로 프로젝트 루트에 둘 필요가 없습니다. 이메일, 회사명, 키는 제외하세요. UTC와 현지 시각을 혼동하지 않도록 Asia/Taipei 같은 시간대를 기록하고 확인할 수 없는 항목은 unknown으로 씁니다.

```text 개인 메모 양식: 필드를 작성하며 명령으로 실행하지 않음
Checked at: YYYY-MM-DD HH:mm timezone
Interface and version: desktop / CLI / browser
Authentication: ChatGPT / API / unknown
Workspace category: personal / managed / unknown
Usage source: Codex dashboard / Platform Usage
Window label: copied without private identifiers
Metric meaning: used / remaining / unknown
Displayed value: value / unknown
Reset time and timezone: value / unknown
Feature or error being checked: short description
Next step: verify account / wait / ask workspace admin
```

원한다면 실습 폴더 목록을 읽는 작은 작업으로 로그인을 확인합니다. 성공해도 현재 화면에서 그 작업이 가능하다는 뜻이지 모든 모델, 클라우드 기능, 외부 서비스를 사용할 수 있다는 뜻은 아닙니다. 한도를 쓰고 싶지 않다면 상태 확인까지만 하고 작업 검증은 미실행으로 기록하세요. 큰 작업을 반복해 한도를 소진시키는 방식으로 제한을 시험하지 않습니다.

## 문제 구분, 중단과 복구

브라우저는 로그인되어 있지만 CLI는 아니라면 인증 과정이 CLI로 돌아와 완료됐는지, 같은 운영 환경인지, CODEX_HOME이 다른지 확인합니다. WSL과 Windows의 홈 폴더는 다릅니다. 오류를 기록하고 정상 로그인 절차를 다시 시도하되 auth.json을 문제 해결용으로 공유하지 마세요. 브라우저 없는 환경은 공식 장치 코드 절차와 워크스페이스 허용 여부를 확인하고 인증서 검증을 끄지 않습니다.

로그인했는데 기능이 없다면 사용 화면, 버전, 워크스페이스 역할, 요금제 지원 순으로 확인합니다. 반드시 한도 문제인 것은 아닙니다. 사용 제한 메시지가 뜨면 제한 이름과 초기화 시간을 기록하고 인수인계 메모를 저장해 기다리거나 계정에 제시된 선택지를 직접 검토합니다. 인증, 기능 자격, 사용 제한은 별개이며 재설치로 한도가 늘어나지는 않습니다.

이 실습은 결제 설정을 바꾸지 않으므로 사용량 페이지를 닫으면 끝납니다. 실제로 CLI에서 로그아웃하려면 터미널에서 codex logout을 실행합니다. 저장된 인증을 지우는 동작이며 환불이나 파일 복원이 아닙니다. 공식 문서에 따르면 CLI와 IDE는 로그인 캐시를 공유할 수 있어 한쪽에서 로그아웃하면 다른 쪽도 다시 로그인해야 할 수 있습니다. 튜토리얼 화면을 깔끔하게 만들려고 실제 계정 데이터를 초기화하지 마세요.

## 완료 기준과 다음 단계

추가 연습으로 서로 다른 시각에 만든 기록 두 개를 비교하세요. 계정 분류, 사용량 출처, 기간, 시간대가 같은지 확인한 뒤 잔여량을 비교합니다. 모르는 항목이 있으면 차이를 추측하지 말고 근거부터 확보하세요. 어떤 과금 출처를 봐야 하는지 알고 인증, 자격, 한도 문제를 구분하면 완료입니다. 다음으로 [CLI 명령](article:codex-commands), [문맥 인수인계](article:codex-context-handoff), [효율적인 한도 사용](article:codex-usage-efficiency)을 읽습니다.

2026-09-14에 [공식 인증 안내](https://learn.chatgpt.com/docs/auth)와 [사용량 및 요금제 문서](https://learn.chatgpt.com/docs/pricing#where-can-i-see-my-current-usage-limits)로 확인했습니다. 계정 상태와 가격은 바뀌므로 로그인 후 표시를 확인하세요. 양식은 가상 필드를 사용하며 개인 계정 화면을 공개하거나 결제 거래를 테스트했다고 주장하지 않습니다.

| 증상 | 먼저 확인 | 단정하지 않을 것 |
| --- | --- | --- |
| 로그인 실패 | 방식과 워크스페이스 | 충전 필요 |
| 기능 없음 | 화면, 버전, 자격 | 한도 0 |
| 사용 제한 | 사용량 출처와 초기화 시간 | 재설치로 복원 |
