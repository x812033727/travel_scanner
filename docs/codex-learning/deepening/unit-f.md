## ID 20｜修 Bug 的完整流程

## ID 21｜測試、Code Review 與 PR

### 練習起點與逐步內容

**起點材料：** 可比較的功能分支、測試輸出與一份 PR 草稿。

**操作順序：** 分開測試、審查與提交；看精確 diff；寫明問題、行為改變、驗證與限制。

**預計交付：** Review 清單與可交付 PR 描述。
