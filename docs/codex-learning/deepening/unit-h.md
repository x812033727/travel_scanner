## ID 52｜MCP 連線診斷與故障復原

閱讀順序 44；估計閱讀 15 分鐘、操作 20 分鐘。永久 slug：`codex-mcp-troubleshooting`。

先備規劃：[ID 25｜MCP 設定與連線排除](unit-h.md#lesson-25)

### 練習起點與逐步內容

**起點材料：** 正常 MCP 配置與三種受控故障：格式、啟動、網路。

**操作順序：** 先檢查設定，再分 stdio 與 HTTP；確認完整路徑、依賴、認證和工具回覆。

**預計交付：** MCP 診斷決策樹與對應訊息。

### 成功、失敗與恢復

**成功判準：** 每層可定位故障，修復後完成同一個唯讀請求。

**指定失敗／邊界案例：** 首頁可開就推論 MCP 正常、TLS 錯誤時直接關驗證、忽略 server 啟動錯誤。

**恢復或停止：** 恢復原設定並修正單一故障；使用公開資料驗證，不展示認證內容。

### 圖片與延伸

**需補或核對的圖文：** stdio／HTTP 的不同檢查路線。 必須記錄來源、環境、日期及五語替代文字／圖說；圖解不能代替產品實際操作證據。無法操作的平台依官方文件查證並標明未實測。

## ID 27｜Worktree 與多任務隔離
