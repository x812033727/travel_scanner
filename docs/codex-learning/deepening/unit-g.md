## 定向補強紀錄

ID 48、49、24、50、51 已完成本輪定向補強及五語編譯，ID 23 沿用代表稿紀錄。28 個原有程式碼區塊保留，新增七個有標籤的區塊。補上腳本與輸入的不同相對路徑、第二份資料的統計、明確選用政策與恢復、來源端自訂辨識值、三種虛構插件事故及互相衝突的範本修正；並修正範本篇引用的 Bug 情境，使其符合實際 broken 教材。

10 項技能／範本參考檢查通過，原有六檔 ZIP 不變，延伸輸入與可選政策檔由讀者按文中步驟建立。證據見 [G 單元紀錄](../evidence/unit-g-depth-review.json)。實際驗證限 Windows Node 參考程式，沒有安裝或呼叫技能、驗證政策載入、登入外部服務或取得產品截圖；完整五語終審與頁面驗收仍待完成。

## 單元編輯重點

格式可解析、技能被選用、工具被呼叫與工作成功是不同檢查。需要帳號的練習提供判讀例題及支援限制，不冒充已連線；撤銷步驟只作用於本次建立項目。

每篇操作需補足位置、完整輸入、預期結果、分歧處理及至少三項適用的常見問題；下列失敗案例是指定必查情境，不取代完整 FAQ。所有篇章依[共同驗收表](review-checklist.md)核對五語、來源、圖片、連結及還原。
