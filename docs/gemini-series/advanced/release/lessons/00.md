這裡集中整理 Gemini、Google AI 與開發工具的完整教學。你可以按分類找功能、按自己的需求走學習路線，也可以搜尋「MD」「手機」「PDF」「/memory」等關鍵字。目錄會列出目前可讀的篇章與數量；每篇提供操作步驟、可複製範例、結果核對方式及延伸閱讀，不需要從第一篇一路讀到底。

## 第一次來，從哪裡開始

完全沒用過 Gemini，先看[[1|帳號與第一個對話]]，再選常用裝置。電腦讀者可看[[4|Windows 與網頁入口]]或[[5|Mac 應用程式]]；手機讀者則看[[6|Android]]或[[7|iPhone／iPad]]。入口和權限各不相同，請依自己裝置的說明操作。

想整理工作資料，從[[9|提示詞]]、[[10|檔案分析]]和[[13|Deep Research]]開始，再進入 Workspace 或[[20|NotebookLM]]。先用少量可核對的練習資料，知道成功結果長什麼樣，再增加資料量。想學 MD 與命令列，依序讀[[29|CLI 安裝]]、[[30|認證方式]]、[[35|Markdown 基礎]]、[[36|GEMINI.md]]和[[37|記憶載入]]。開發者則從[[47|AI Studio 與 API 第一次呼叫]]走到[[50|文件摘要與擷取工具]]。

熟悉基本操作後，可以挑一個具體作品練習。工作路線從[[51|提示詞 A/B 實驗]]做到[[54|會議資料交接]]；研究路線用[[58|引用查核]]接[[62|有證據的專題報告]]；創作路線由[[63|圖片系列]]接[[65|三鏡頭短片]]。技術讀者可選[[69|GEMINI.md 載入實驗]]、[[75|本機 MCP 工具]]或[[81|Function calling 實作]]。先修與延伸連結都回到同一套文章。

## 如何使用分類、路線與搜尋

目錄維持八大分類，每篇顯示用途、難度、適用平台及閱讀時間。「第一次使用」「手機」「工作研究」「CLI／MD」「API 開發」是基礎路線；深入篇另按工作、研究、創作、MD、CLI 自動化及 API 六個主題安排實作順序。這些路線只引用既有文章，不會複製另一份教學。

先依目標選路線，再依需要縮小分類、階段或深入主題。篩選採交集：例如同時選深入階段與 MD 主題，會留下設定實驗與指令庫等對應篇章。閱讀時間是閱讀正文的估算，動手時間則是完成練習的估算；雲端生成、排程與批次等待另計。

搜尋比對標題、用途與別名。MD 能找到 Markdown、GEMINI.md 與設定檔；手機可找到 Android、iOS 和現場筆記；/memory 能找到上下文與載入實驗。結果太少時，先清除分類或路線，再試較短關鍵字。停用 JavaScript 時仍可瀏覽完整可見分類與文章連結，手機版往下捲動即可找到各項控制。

## 指令應該輸入在哪裡

提示詞是給 Gemini 的自然語言需求；CLI 斜線指令在 Gemini CLI 互動介面使用；終端機命令在 PowerShell 或 shell 輸入。程式區塊會標示語言或檔名，複製前先確認輸入位置，再替換範例值。完整查找請看[[31|CLI 指令總表]]。

GEMINI.md 提供工作指示，settings.json 管理程式設定，自訂斜線指令使用 TOML，三者不能互相代替。[[11|Gems]]的指示在 Gemini 介面設定，不會因為電腦裡存在專案檔案就自動套用。進一步管理團隊規則可讀[[70|模組化規則範本]]；設定無效時看[[71|設定來源除錯]]；要重複執行相同步驟則讀[[72|自訂指令庫]]或[[73|技能擴充套件]]。

## 每篇怎麼讀、如何回到這裡

先看成果與準備條件，再照步驟完成範例。文中具名連結會帶到相關功能，文末提供上一篇、下一篇與建議閱讀；頁首和文末都能返回總目錄。站內連結使用同一分頁，可直接使用瀏覽器返回。下載包的 README 會說明檔案用途、執行位置與要替換的值，先保留原始練習資料再開始修改。

深入教學用一個可檢查的成果串起步驟，也安排失敗案例。資料沒有證據、指令遭拒或模型輸出不合格式時，應留下原因與修正紀錄。例如[[78|批次續跑]]會保留工作狀態，[[85|API Batch 評測]]會區分成功與部分失敗；不能把空白結果當成成功檔案交付。

範例輸出、作者參考實作、官方文件整理與真實平台操作會分別標示。程式語法、本機伺服器、SDK 回應解析與遠端模型成功是不同層次的證據。圖片與影片篇的概念圖也不是模型實際生成的作品；每次練習都要用自己的輸入與平台結果核對，不把示例答案當成保證。

## 更新、方案與查證

各篇官方來源都附實際查證日期。Google 功能可能依地區、年齡、語言、方案與帳號逐步開放，先看準備段落，再對照當下介面與官方說明。個人訂閱價格集中在[[2|方案與額度]]；API 模型、工具、快取及批次費用集中在[[49|API 成本與錯誤處理]]。兩種費用不能互相替代。

NotebookLM 與 Veo 沿用既定網址，正文說明官方名稱與入口的變化。部分官方文件使用 Gemini Notebook 名稱，影片操作則需區分 Gemini 與 Flow；名稱更新不必讓既有連結失效。遇到看不到的功能，先確認帳號資格及發布條件，再使用可用的替代步驟，保留尚未完成的核對項目。
