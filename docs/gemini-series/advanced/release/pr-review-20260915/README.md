**舊候選已因主線內容變動而過期。** 本輪嚴格雜湊檢查在 gemini-canvas-guide 首次不符時停止；[完整候選輸入差異](original-candidate-audit.json) 另列目前變動，不把內容格式／連結通過寫成收據完整性通過。保留舊收據，發布前必須採用後續修訂並重新建立候選。
