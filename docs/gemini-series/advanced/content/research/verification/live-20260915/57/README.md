## 舊產出與額外發現

- 兩種方式均另存 v1、v2 回答為筆記。來源更新後，舊筆記仍是 24 人，新筆記是 30 人；原文完整保存在 `notes.json`，不是用新回答覆寫舊紀錄。
- Drive 舊筆記的引用預覽仍顯示 v1／24 人，同時左側來源檢視器已顯示 v2／30 人。`observations.json` 分開保存兩個區域，不混稱為同一內容。
- 重新開啟兩個筆記本後，五筆回答的文字校驗值一致。但上傳版 S01-v1 又變成已勾選，當下七份來源全選；已再次取消 v1，恢復六份有效來源。這是本次觀察，不能承諾勾選會跨重新整理保存。
- Drive v2 的自動「來源指南」加入「具法律效力」的描述，虛構原文未提供此證據。該摘要未通過全部語意查核。主要名額回答通過，不代表其他自動摘要全部可靠；教材應要求刪去無來源補述。
- 上傳回答把 CAP 標成 `#### CAP`，而原始 Markdown 是二級標題。章節名稱與名額引用正確，但 Markdown 標題層級不準確；不要把回覆當成原始檔案的逐字轉錄。
