## 環境與成本

- Windows、Chrome、個人 Google 帳號；網頁顯示 PRO，這輪文字對話選擇 Flash。
- Flash 是畫面名稱，介面未提供可核對的精確模型 ID，不能當成 Gemini API 型號。
- 使用者授權既有 Pro 額度；另允許 API，但總額上限 NT$0，僅可確認免費的額度。
- 本輪目前沒有 API 呼叫或額外購買。Process／User／Machine 均未設定 GEMINI_API_KEY 或 GOOGLE_API_KEY；只檢查有無值，沒有讀出或保存金鑰。
- 既有個人化設定保留；沒有獨立控制個人化，因此結果只代表這個帳號、模式及時間的一次測試。
- 只傳送教材的虛構資料。公開追蹤檔不保存帳號姓名、email、舊對話或可定位私人對話的 URL。

## 第 51 篇

`51/environment.json` 記錄凍結輸入及限制。`51/audit-live.py` 核對題庫、提示詞、交替順序與不同對話，不替模型評分。已收集 20 筆；`51/captured.json` 與 `51/raw/` 保存畫面回答本文，這是呈現後的文字，並非 HTTP 回應 JSON 或原始 Markdown。

人工評分是獨立門檻；Codex 的語意初查必須標為 AI 初查，不能填成已完成人工評分。即使 20 筆回答全部存在，也不能據此宣稱改寫版勝出或整篇通過語意驗收。

`51/transport-check.json` 的 20 個 checksum 與瀏覽器保留紀錄一致；用來排除轉寫錯誤，不是第三方真實性認證。`51/capture-audit.json` 記錄輸入及原始檔 SHA256；154 個歷史作者交付檔案雜湊維持不變。
