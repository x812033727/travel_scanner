# 第 55 篇：實體手機待測清單

2026-09-15 已重查 Android／iOS 官方 Live 文件，尚未取得實體手機結果。瀏覽器工具目前控制 Windows Chrome，不能用窄視窗替代手機的相機、麥克風與停止分享測試。

## 開始前

選自己的無個資物品，例如筆、杯子或紙盒。先保存一張清楚照片，另拍遮住標籤的照片；不用既有 Commons 圖片假裝是今天拍攝。記下手機型號、OS、Gemini 版本、介面語言、日期與帳號方案，不記錄帳密。Android 與 iPhone 各填一份，另一平台沒測就保留 not_run。

## 實際操作與要記錄的結果

1. 在 Gemini 手機應用程式開啟新的 Live 對話。說「這是 GeminiLesson55Live20260915 現場觀察練習，只描述我分享的物品，不猜品牌或價格」。記下實際入口文字；首次權限或條款由帳號使用者閱讀處理。
2. 開啟相機分享，對準物品，問「指出三個可見特徵與位置，哪些地方看不清楚？」保存實際回答，逐項對照實物。不要預先把參考答案告訴模型。
3. 遮住標籤或部件，問相同問題。記錄模型有沒有承認看不到；移開遮擋後再問，保存修正前後兩份答案與照片。
4. 按相機控制停止分享，再按 End 結束 Live，確認相機及麥克風狀態。只按 Mute 靜音不能當成已停止影像分享；Android 官方明列靜音時影像／螢幕可繼續分享。
5. 查看該對話逐字稿，核對自己的話是否被聽錯。回到電腦同帳號搜尋專用標記，確認能否讀取相同對話；若只能手動複製，就記為手動交接，不填自動同步成功。

這個基本練習使用相機，不需要額外開啟螢幕分享。若另測螢幕分享，只展示無個資測試頁，另記啟動、停止按鈕與系統狀態，不把相機停止當成螢幕停止。

```text
平台／型號／OS／Gemini 版本：
日期時間／介面語言／帳號方案：
Live 入口與相機按鈕：
第一次回答與原圖檔名：
遮擋後回答／移開後回答：
停止相機、結束 Live 的操作及確認方式：
逐字稿有無聽錯：
電腦是否找到同一對話／或手動交接：
未執行或失敗的步驟：
```

口述回報會標為使用者觀察，只有可見畫面或保存的文字才能另外列為直接核對。仍待實際結果，不能把這份清單當成通過紀錄。
