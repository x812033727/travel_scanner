- 四輪使用同一個對話；追蹤檔只保存對話 URL 的 SHA256。私人 URL 留在被 git 忽略的暫存，未寫入內容包。
- v1／v2 使用 Flash，v3／v4 選 Pro。當日選單文字分別是「3.8 Flash 全方位協助」與「3.1 Pro 進階推論」；僅為畫面標籤，不是已驗證的 API 模型 ID。切換模式時也改寫了提示詞，因此不能把結果當作控制變因的模型效能比較。
- 既有個人化設定未變，也未獨立控制。這些結果只代表本帳號、提示詞、模式與時間的觀察。
- API 呼叫 0、額外購買 0、額外花費 NT$0。使用既有 Pro 網頁額度；沒有建立 API 金鑰或開啟額外計費。

### 真正抓到的 1 分錯誤

v3 使用 Number 儲存整數分，再乘上比例的基準點，仍可能超過安全整數範圍。確定性數值探查找到反例後，已在未改動的 v3 原始 HTML 中重現：

```text
人數：10000
每人單價：9393957.73
場地費：9582704.53
備用金百分比：76.49

                    獨立 Decimal 答案     v3 瀏覽器結果
基本費用            93949160004.53       93949160004.53
備用金              71861712487.46       71861712487.47
總額                165810872491.99      165810872492.00
平均每人            16581087.25          16581087.25
```

把這組輸入、正確答案、實際錯誤與規則交給 Gemini 修正。v4 以 BigInt 表示分與基準點，完成乘除及正數四捨五入，再以字串顯示兩位小數。修正版在相同反例恢復正確；不是把本機作者 HTML 替換進 Canvas。

另加未在修正提示詞提供的 B06：3 人、每人 0.01、場地 0、備用金 50%。獨立答案為基本費用 0.03、備用金 0.02、總額 0.05、平均 0.02，用來分別檢查半分四捨五入與平均值。

### 介面失敗與修正

v3 的四個輸入沒有 `aria-describedby`／`aria-invalid`，也沒有動態狀態區域。v4 在錯誤時關聯提示、標記欄位、聚焦第一個錯誤，並更新計算完成、輸入變更與重設的狀態文字。此次確認了 DOM 屬性、可見錯誤與鍵盤焦點，沒有由螢幕閱讀器使用者實測。

在獨立 `html { font-size: 200%; }` 測試副本中，v3 的 360px 畫面實測 scrollWidth 380，標籤與金額擠在一起。v4 加入換行後，同條件 scrollWidth 345（右側有垂直捲軸），畫面可讀。這是根字級放大的測試副本；原生瀏覽器 200% 縮放與實體手機未驗證。兩份 `*-text200-test.html` 僅加入明確標示的樣式與註解，原始下載檔未改動。

## 測試工具異常與排除

- 初次下載事件等待逾時，但 Downloads 確實生成檔案；以實際新增檔名、大小及 SHA256 確認，四份收據在 [download-copy-check.json](download-copy-check.json)。
- 一批非法輸入測試中斷，沒有完整返回結果，不列為通過。舊控制分頁失去連線後，在同一 Chrome 開啟相同已保存對話，沒有重新生成歷史答案。
- 本環境 `fill("")` 曾未清除輸入。保留 v3 不合格工具觀察；後續改用全選／Backspace，讀回實際值確認空白後才算有效測試。
- 初次要求 1440px 的設定套在另一分頁，測試頁仍為 360px；六筆移到 [排除紀錄](viewport-diagnostics.json)，不算桌面覆蓋。最終十二筆數值測試中的六筆桌面資料已於實際 1440px 重做並驗證。
- 桌面整頁截圖曾逾時，裁切結果空白；其後使用分頁截圖成功觀看。只有成功觀看後的結果算視覺檢查。
