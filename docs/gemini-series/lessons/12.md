Canvas 是 Gemini 中用來編輯成果的工作區，適合把對話中的構想變成文章、簡報或小型互動工具。本篇先做一份活動說明，再把同一份已核對內容改成簡報與清單工具。學完後，你會知道如何局部區域修改、檢查結果，以及分清楚預覽、匯出與公開分享。

## 開始前：先決定成果形式

登入 Gemini，準備一份已確認的短資料，例如活動目的、地點、已知日期及待決定事項。先完成[[9|提示詞寫作]]；如果材料來自 PDF，先依[[10|檔案分析]]核對原文。Canvas 能協助編排內容，但不會因為進入編輯模式就讓缺少的資料自動變成事實。

本篇以電腦網頁的官方流程整理，未以實際帳號測試 Canvas。手機也有相應入口，但選單與匯出位置可能不同。某些把檔案轉成其他形式或加入 AI 的功能有年齡、方案與帳號條件，請檢視目前介面，不把所有示範都當成每個帳號的標準配備。

## 實作：建立一份可編輯說明

1. 在 Gemini 開啟新對話，從輸入區的新增檔案或工具選單選擇 Canvas。
2. 貼上下方提示詞，清楚指定要產生檔案，而不是只回答一串建議。
3. 產出後開啟 Canvas，逐段核對活動資訊，確認仍標示日期待公告。
4. 選取需要改寫的段落，透過選取並提問或對話要求局部區域修改；明確說出其他段落應保持的內容。
5. 修改完成後重新從頭閱讀，保留一份文字備份，再進行簡報或工具的延伸練習。

```text Canvas 檔案提示詞
請在 Canvas 建立「社群閱讀下午」的一頁活動說明檔案。
已知資料：二樓閱讀區；自備水壺與筆記本；現場提供共讀書籍。
日期與報名方式尚未公告。
讀者是第一次參加的家長，使用繁體中文。
結構：活動目的、現場流程、準備清單、待確認事項。
現場流程請標為建議草案，不要寫成已確定安排。
```

## 預期結果：內容先於排版

預期檔案有四個清楚區塊，已知資訊與建議草案分開，沒有自行補上日期或報名連結。這是教學驗收條件，實際版面與文字會不同。若某段看起來太長，先指定要服務的讀者與重點，再要求縮短，而不是只說「更專業」。

Canvas 變更可能自動儲存，因此每次大型改寫前，先保留已確認的內容。局部區域修改後檢查其他段落有沒有跟著變動；如果工具顯示版本或近期變更，也可以用來追查。自動儲存方便接續工作，但不能取代自己可辨認版本的成果備份。

文字中的日期、金額與連結應一項一項確認。視覺上有漂亮的標題或卡片，不代表每個段落都可靠。當你準備把內容匯出到其他工具時，先把不確定資訊標清楚，避免下一步把草案排成像正式公告的成品。

## 延伸一：把檔案改成簡報

在對話中要求以目前已確認檔案製作四頁簡報：目的、流程、準備事項、待確認專案。每頁只放一個重點，流程仍保留草案標記。指定台灣讀者與投影閱讀情境，要求字型清楚、避免一頁塞滿長段落；若需要講者備註，也另外說明。

產出後逐頁核對，有些資訊可能在濃縮時被省略。尤其是日期未知、適用物件與限制，不能因為版面簡化而消失。簡報是否能匯出成特定格式，依當前提供的選項確認；在 Canvas 中看得到投影片，不等於已建立可由同事編輯的 Google Slides 檔案。

需要正式協作與版面修訂時，可接著看[[17|Docs 與 Slides 工作流程]]。先確定內容、再選交付格式，比反覆在不同工具重新生成整份簡報更容易維持一致資料。

## 延伸二：製作不含個資的清單工具

可以請 Canvas 以活動準備事項建立簡單的勾選清單，這適合練習互動而不必接外部服務。先要求只在目前頁面處理資料，不加入登入、雲端資料庫、寄信或付費服務。若結果加入你沒要求的功能，先請它移除，再測試基本行為。

```text Canvas 小工具提示詞
以目前的活動準備清單製作簡單互動工具。
固定三項：水壺、筆記本、確認日期。
提供勾選、已完成數量與重設按鈕。
初始為 0/3；全勾選為 3/3；重設後回到 0/3。
使用繁體中文，手機單欄，不需要登入或外部連線。
不儲存跨工作階段資料；重新載入後回到初始狀態。
```

測試時依序只勾一項、勾滿三項，再按重設；核對數字是否為一、三、零。重新載入也要符合原先指定的儲存方式。若預覽出錯，可開啟 Code 檢視程式，並使用顯示主控臺找錯誤訊息；把具體操作與錯誤內容交給 Gemini 修正，避免只說「壞了」。

## 匯出與分享：確認真正的目的地

檔案可透過分享與匯出中的複製內容或匯出到 Google 檔案等選項帶走。匯出後開啟目的檔案，確認文字、段落、表格及來源是否完整。這是另外一份需要確認的成果，不應只看 Canvas 的成功提示就認為同事已經取得存取權。

公開分享 Canvas 應用程式前，閱讀應用程式資訊與資料使用說明。部分應用程式可能共享資料或儲存跨工作階段內容，持有公開連結的人可有哪些行為要看清楚。練習清單不需要公開分享；如果要分享，先去掉個人資料、金鑰及未授權素材，再確認連結能開啟的實際內容。

## 常見問題

「只有一般對話，沒有 Canvas？」先確認已選 Canvas 工具及指定成果形式，並檢視帳號是否提供此功能。介面更新可能移動入口；沒有按鈕時依官方條件檢查，不必把同一句提示詞重送很多次。

「預覽正常就可以當正式系統嗎？」還不行。練習只檢查三項清單的簡單行為，沒有證明多人使用、資料儲存與存取控制都正常。需要正式工具時，請依[[34|程式工作流程]]建立明確測試與交付要求。

「分享連結在手機 App 開不了？」查證當日官方說明指出共享 Canvas 內容需在 Gemini 網頁開啟。請使用瀏覽器檢視並核對帳號條件；不要把行動應用程式無法開啟，直接判斷成內容已被刪除。
