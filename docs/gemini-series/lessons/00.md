這裡整理 Gemini、Google AI 與開發工具的教學。可以按分類找功能、按自己的需求走學習路線，也可以搜尋「MD」「手機」「PDF」「/memory」等關鍵字。每篇都提供步驟、可複製範例、結果核對方式與延伸閱讀，不需要從第一篇一路讀到底。

## 第一次來，從哪裡開始

完全沒用過 Gemini，先看[[1|帳號與第一個對話]]，再選自己常用的裝置。主要用電腦可讀[[4|Windows 與網頁入口]]或[[5|Mac 應用程式]]；主要用手機則讀[[6|Android]]或[[7|iPhone／iPad]]。入口和權限不同，請選符合自己裝置的那一篇。

想把工作資料整理好，可以從[[9|提示詞]]、[[10|檔案分析]]和[[13|Deep Research]]開始，再進入 Workspace 或[[20|NotebookLM]]。先使用一小份可核對的練習資料，知道成功結果長什麼樣，再增加實際工作的資料量。

想學 MD 檔和命令列，先讀[[29|CLI 安裝]]與[[30|認證方式]]，接著看[[35|Markdown 基礎]]、[[36|GEMINI.md]]及[[37|記憶載入]]。想開發自己的小工具，從[[47|AI Studio 與 API 第一次呼叫]]走到[[50|文件摘要與擷取工具]]。

## 如何使用分類、路線與搜尋

下方目錄有八大分類，每篇顯示用途、難度、適用平台與閱讀時間。五條學習路線只是從同一批文章挑出適合順序，不會另外複製內容。第一次使用、手機、工作研究、CLI／MD 和 API 開發，都可從路線清單直接前往。

搜尋會比對標題、用途和別名。例如 MD 可以找到 Markdown、GEMINI.md 與設定檔，手機可找到 Android 和 iOS，/memory 可找到上下文與記憶相關教學。篩選結果太少時，先清除分類或路線，再試較短的關鍵字。

## 指令應該輸入在哪裡

提示詞是給 Gemini 的自然語言需求；CLI 斜線指令是在 Gemini CLI 互動介面使用；終端機命令則在 PowerShell 或 shell 輸入。看到程式碼區塊時，先看語言或檔名標籤，再複製到正確位置。需要替換的值都以範例說明標清楚。

完整查找請看[[31|CLI 指令總表]]。GEMINI.md 提供工作指示，settings.json 管理程式設定，自訂斜線指令使用 TOML，三者不能互相代替。[[11|Gems]]的指示在 Gemini 介面設定，也不能假設它會自動讀取本機專案檔案。

## 每篇怎麼讀、如何回到這裡

先看學習成果與準備條件，再照步驟完成一個範例。文中的具名連結會帶你到相關功能，文末有上一篇、下一篇與建議延伸閱讀。頁首和文末都能返回本總目錄；站內連結在同一分頁開啟，手機可以直接使用瀏覽器返回。

範例輸出和真人實測會明確區分。介面操作多數依官方文件整理；CLI 技術篇記錄核對版本，API 篇區分語法、本機測試與真正遠端呼叫。不要把一段示例答案當成某個帳號已得到的實際結果，也不要把本機測試通過當成網路服務一定可用。
