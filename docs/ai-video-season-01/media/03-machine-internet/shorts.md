# 兩支衍生 Shorts

## 1. 過半機器流量，代表一半網友是假的？

一份報告說，自動化流量超過百分之五十三，就代表一半網友是假的嗎？不代表。這是 Imperva 二〇二六年報告談的二〇二五年流量資料。請求次數不是人數，也不是留言比例。一個程式可以發很多請求。先看分母，再解讀那個很大的數字。

畫面重點：53%：廠商流量資料 → 不是網友比例 → 資料年份：2025

來源：S06

## 2. 十篇都這樣寫，不一定有十份證據

你搜到十篇文章都說同一件事，代表十份證據嗎？如果它們都改寫自同一則沒有查證的貼文，可能只有一個起點。網址不同，不代表資訊來源獨立。這是概念示意，不是平台統計。下次看到很多相同答案，試著沿著連結往回追。

畫面重點：十個網址 → 一個起點？ → 找獨立證據

來源：原創示意／編輯建議
