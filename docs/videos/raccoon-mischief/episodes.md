# 《闖禍小浣熊》EP2–EP7 集數表（2026-11-03）

系列規則照 [`README.md`](README.md)：零台詞、9:16、寫實 AI 擬人化浣熊一家，公式是闖禍 → 鑰匙聲、慢看鏡頭 →
**跳過偽裝過程**，直接看到他已經變成那樣東西（地毯鼓一包）→ 一個小破綻 → 補刀（另一個家人也在偽裝，或媽媽面不改色地把他當那樣東西用）。
這一份是可以直接拿去做分鏡的集數表：六集都還沒進劇本關卡，也還沒花任何錢。

六集都照首格實測的限制設計：

- **每一鏡畫面上只有一個角色**。爸爸、媽媽出場多半只有畫面邊緣的一隻手（藍背心一角、綠毛衣袖口），或放在自己的反應鏡。
- 偽裝那一格一律寫成角色**本身**在做（"Doudou himself is the chandelier, hanging from the ceiling hook…"），
  不寫「旁邊有一盞吊燈」，不然模型會畫一個真的物件放旁邊、浣熊站在一邊。
- 世界裡沒有人類；沒有吃東西、沒有看得懂的字（遙控器、時鐘、插座都不能有字或數字）；家人碰他的過程不拍，只拍結果（披風已經掛在手上、青蔥已經插在土裡）。
- 每鏡是一段 5 秒的片段、一件事，剪進成片時取 1.5–3.5 秒；成片 13–16 秒、5–7 鏡。

升級怎麼排：EP2–EP3 是牆上的小東西、由爸爸補刀；EP4–EP5 換成媽媽「把他當那樣東西用」，懲罰越拖越久（澆到發芽、當燈當到天亮）；
EP6 偽裝本身的破綻被拆穿（真的燈在地毯底下亮了）；EP7 季終反轉，闖禍、偽裝的人換成媽媽，被「用」的換她。

### 怎麼評的

三位獨立評審，用本機的 Claude Code 無介面模式另開三個工作階段（`claude -p`，關掉所有工具與 MCP，在 repo 外的空目錄執行），

### 評審最常提的問題

1. **補刀的人要有動機、要「知道」**。禮物盒裡的爸爸（三位都問為什麼）、只露一隻手的換台爸爸（三位都要交代他是沒發現還是在整人）、
   澆水的媽媽（導演要她先看一眼地毯鼓包）。評審最愛的補刀都是「家人明明知道、卻面不改色地配合」——〈吊燈〉的媽媽用下巴指書頁三位都選為最強。
   補刀的人只露一隻手時，給一個「我知道」的小訊號（老花眼鏡反光、停半拍、低頭看鼓包）。
2. **第一格要一眼看出「完蛋了」**。〈衣帽架〉20 歲在 s01 滑走（媽媽站著不像出事）、導演也要第一格更狠、〈盆栽〉hook 中位數 9（倒一盆植物不夠嚴重）、
   〈時鐘〉要先看到碎鐘再看到吊著的豆豆。最有效的是讓弄壞的東西有份量（媽媽最寶貝的、還在滾、還在冒煙），並讓角色停在闖禍的姿勢上。
3. **第三拍要升級，不是再來一次**。電視第三台要更荒謬（三位都提）、時鐘分針只跳一格太小（轉到手臂扭成麻花）、衣帽架要越掛越重。
4. **收尾要有擊點，最好回扣第一格**：關機後地毯下滾出足球、天亮時地毯滾出一顆水晶、嫩芽長成青蔥。只有「發抖」「看鏡頭」的收尾被說收不起來。
5. **媽媽的青蔥是系列最好用的符號**：盆栽長出青蔥、購物台推銷青蔥、門縫先探進青蔥認出是媽媽，都是評審自己提的。下一季可以讓青蔥固定出現在補刀裡。
6. **季節題材要算檔期**：〈聖誕樹〉兩位提醒平常月份發會很怪。
