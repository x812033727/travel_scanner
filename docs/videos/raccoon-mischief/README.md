# 闖禍小浣熊（系列）

站主 2026-11-03 選定（零台詞系列企劃盲評第 1 名，中位數 89、三位評審都最想追看；企劃全文在 `docs/videos/zero-dialogue-series-ideas/README.md`）。

| 規則 | 內容 |
| --- | --- |
| **零台詞** | 沒有任何台詞、旁白或內心話；只有配樂與音效，關靜音也看得懂 |
| 長度與格式 | 約 13–15 秒，9:16 Shorts／Reels |
| 畫風 | 寫實 AI，真實外觀的浣熊一家像人一樣站著、穿衣服；世界裡沒有人類 |
| 角色 | 豆豆（小浣熊，黃連帽衫＋紅浴巾披風）、浣熊媽媽（綠毛衣、珍珠項鍊、一袋青蔥）、浣熊爸爸（藍背心、老花眼鏡、圓肚子） |
| 場景 | 同一間溫暖的客廳，每集換一個角落 |
| 公式 | 闖禍 → 鑰匙聲、慢看鏡頭 → **跳過偽裝過程**，直接看到他已變成那樣東西（地毯鼓一包）→ 一個小破綻 → 補刀：另一個家人也在偽裝，或媽媽面不改色地把他當那樣東西用 |
| AI 風險 | 偽裝那一格是靜止的角色（低風險）；嘴裡咬東西寫成「夾在嘴角」；碰觸只拍結果不拍過程；三隻靠衣服顏色分辨，設定圖先鎖 |
| 製作與語言 | 同《汪家夫妻》：Colab 首格與 H3 片段、ffmpeg 剪接、`shorts import`；八語只翻標題與說明 |
