# 《恁祖媽今年18》第 43 集〈附件三〉

## 故事前提

快門「咔」一聲，江慕白在院子門口回頭。月棠舉著手機一臉為難：江律師，這東西怎麼關聲音？江慕白盯了她三秒，告訴她側邊的鍵按到底，闔上皮夾夾回左臂，
警告保母別碰別人的東西，進飯廳喝茶去了。福伯從飯廳出來，壓低聲音說：建業前天替林美鳳買了一輛白色休旅車，房子還沒交、尾款也沒到，錢是哪來的？
月棠說只有盛通會先付錢，今晚她去藥局把塗黑的字弄清楚。夜裡她走過停在大門外的白色休旅車，到了藥局。蘇曉把照片傳上電腦，一格一格把對比拉到最高，
塗黑的那一行底下浮出字來：受益人……遠山控股。再往下一行沒塗、字很小，蘇曉放大唸出來：乙方於老宅過戶當日，將「沈記」商標一併過戶……知遠站了起來。
