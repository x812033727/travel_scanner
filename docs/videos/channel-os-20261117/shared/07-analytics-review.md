# 07 數據檢視：每週與每月的固定流程（兩個頻道共用）

對應提示詞 7「YouTube 分析優化」。指令、門檻與決策表的原始出處在
[`.agents/skills/producer/references/series-diagnosis.md`](../../../../.agents/skills/producer/references/series-diagnosis.md)，
這份只把它排成**固定時間做的事**，並補上兩個頻道各自的系列表。讀數據的工具與限制見
[`.agents/skills/youtube-channel-reports/SKILL.md`](../../../../.agents/skills/youtube-channel-reports/SKILL.md)。

> 報表數字是內部用：自行算出的總和、比率與排名不能放上公開網頁或影片說明（[`../../YOUTUBE-REPORTS.md`](../../YOUTUBE-REPORTS.md)）。

## 先記住的三條

1. **付費和自然分開看。** 流量來源 `ADVERTISING`（報表 `traffic_source_type = 1`）一律單獨一欄。2026-11-11 的 35 天裡 86% 的觀看是付費的；
   混在一起看，奇聞〈長篠三段擊〉是 9,659 次觀看的熱門片，分開看它的自然觀看是 119 次
   （[`../../channel-review-20261111-promotion/README.md`](../../channel-review-20261111-promotion/README.md) §3）。
2. **宣傳帶來的訂閱與觀看時數不算營利資格。** 所以營利進度只看自然那一半（出處見 `series-diagnosis.md`〈門檻與出處〉與 [`06-monetization.md`](06-monetization.md)）。
3. **報表晚 48–72 小時**，最近兩天的空白不是零；`window_complete: false` 的不跟滿的比。

## 每週檢視（每週一，約 45 分鐘，一個頻道一份）

**指令**（B 頻道要等站台支援第二個頻道，見 [`05-ai-production.md`](05-ai-production.md)〈第二個頻道要改的地方〉；在那之前 B 用 Studio 手抄）：

```bash
node tools/video/youtube-reports/cli.mjs overview
node tools/video/youtube-reports/cli.mjs videos --window 7 --long
node tools/video/youtube-reports/cli.mjs videos --window 7 --shorts
node tools/video/youtube-reports/cli.mjs traffic --slug <本週最好與最差各一支> --top 10
```

**填這張表**，存成 `docs/videos/channel-os-20261117/reviews/<頻道>-<YYYY-MM-DD>.md`：

| 欄 | 本週 | 上週 | 四週平均 | 門檻 | 判斷 |
| --- | ---: | ---: | ---: | --- | --- |
| 自然觀看（扣廣告） | | | | 比上週高 | |
| 自然觀看時數 | | | | 見營利進度 | |
| 淨訂閱（gained − lost） | | | | — | |
| 縮圖曝光 | | | | — | |
| 自然點閱率（加權） | | | | ≥ 4%（長片）| |
| 自然平均觀看百分比 | | | | ≥ 30%（長片）／≥ 70%（Shorts 看完率代理）| |
| 帶出的自家觀看（後續觀看） | | | | 比上週高 | |
| 留言數 | | | | > 0 | |
| 本週上片數 | | | | 照 90 天計畫 | |
| 宣傳花費（Studio 手抄） | | | | 站主定 | |

門檻的來源：點閱率「一半的頻道落在 2%–10%」是 YouTube 說的；4% 與 30% 是**我們自己定的起步目標**，
依據是 B 種子《種田》第 1–5 集的自然點閱率 6.53%、平均觀看 17.3%（`channel-review-20261111-promotion` §2）。這兩個數字不是 YouTube 給的門檻，三個月後用自己的中位數重定。

**然後做三件事，每件都留一行紀錄：**

1. **最好的一支**：為什麼好？是題目（曝光多）、包裝（點閱率高）、還是內容（平均觀看高）？下週照它再做一支。
2. **最差的一支**：照下面的決策表判斷，只改一件事。
3. **下週的題目**：從頻道的 100 題清單照順序拿，若本週有新證據（搜尋字詞、留言），可以把對應的題目往前移。

## 決策表（照 `series-diagnosis.md`）

| 看到的 | 判斷 | 下一步 |
| --- | --- | --- |
| 自然點閱率 < 2%，平均觀看還可以 | **改包裝** | 縮圖照 [`scorecards.md`](../../../../.agents/skills/producer/references/scorecards.md) 重畫、標題把大家認得的名字放前面，用 Studio「測試與比較」，7 天後看觀看時間占比 |
| 點閱率正常，前 30 秒留存或平均觀看明顯偏低 | **改內容** | 看留存曲線第一個大掉點對到稿子哪一句；開場 5 秒先兌現標題 |
| 兩者都還可以但曝光少 | **加碼** | Shorts 導流、播放清單、結束畫面；要買宣傳只投台灣與香港，目標選「後續觀看」（站主決定金額） |
| 付費占比 > 90%、留言 0 | **先別再買** | 停宣傳，修包裝與內容 |
| 三支以上都低於門檻，改過包裝也沒起色 | **停或換形式** | 寫一段為什麼停；題材有價值就換形式 |

## 每月檢視（每月第一個週一，約 2 小時）

1. **系列表**：每個系列一行（欄位照 `series-diagnosis.md`〈系列表〉：支數、自然觀看中位數、自然點閱率、平均觀看百分比、前 30 秒留存、付費占比、留言、每 NT$100 後續觀看）。
   少於 3 支的系列不下結論。
2. **內容模式**：把當月所有片依自然觀看排序，前 20% 與後 20% 各寫下共同點（題材類型、標題句型、縮圖主體、片長、上片時段）。
   這一步就是「找出成功的模式」：之後的選題分數加上這些共同點。
3. **營利進度**：自然觀看時數（近 12 個月）、訂閱數、近 90 天 Shorts 觀看。和 [`06-monetization.md`](06-monetization.md) 的門檻比，算出「照本月速度還要幾個月」。
4. **100 題清單重排**：把本月證明有效的題型往前移、證明無效的往後移，或刪掉。
5. **把結論寫進頻道的 90 天計畫**〈依表現調整〉那一節，並在 `tasks/open` 開下個月要做的票。
