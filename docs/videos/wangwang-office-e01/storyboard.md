## 檢查沒過、刻意保留的一項

- `lines.narrator`（旁白與內心話占 89%，目標 ≤ 35%）：這個系列的笑點就是狗的內心話，跟動作反差，所以照設計保留。

## 製作路線：Colab H3 → Shorts

1. **劇本關卡**：`script` → 站主核准。
2. **設定圖與關鍵影格**：伺服器 `look`、`keyframes`（約 US$4.8，上限 US$12.6，`shot_plan` 估）。構圖一律把主體放在畫面中間三分之一。
3. **配音**：`tts`，之後用實際時間軸重跑 `shot_plan --timeline` 確認每鏡要買幾秒。
4. **片段**：Colab 的 MiniMax H3，`first_frame` 模式、首格用通過 judge 的關鍵影格，1312×736 畫布、`smooth` profile，每鏡買 5–6 秒。先做三鏡小樣：s07-dash、s08-suck、s09-kpi（動作、機器人、台詞特寫各一）。站主看過才放量。每批用 `h3_detached.py` 跑，前後各抄一次 `h3.sh usage`。
5. **匯入與合成**：`clips import`（這部不是 production profile 作品，收得進）→ `assemble` → 成片核准。
6. **Shorts**：`shorts from-drama` 從 16:9 成片裁 9:16、加 Shorts 字幕層，再照 `check-audio` → `qa` → `package` → `push`。

為什麼不直接生 9:16：產線目前沒有原生直式漫劇（票 `2026-09-28-video-shorts-worker-drama`）。H3 的畫布可以設成 736×1312，但直式首格、合成與 `layout` 檢查都還沒有工具支援。代價是 `from-drama` 裁切後畫質比較軟（608 px 寬放大 1.78 倍）。要不要在小樣多試一鏡原生 736×1312，由站主決定。

## 八種語言

上架時在語言面板勾 en、ja、ko、es、pt、id、vi、th 的**標題、說明與 CC**；Shorts 的語系在 Shorts 設定的「語言」勾。

限制：有角色對話的漫劇目前不能做配音（伺服器回 422 `video_locales_dub_not_for_drama`），Shorts 的畫面字與聲音也維持繁中。所以八語指的是標題、說明與字幕，聲音只有國語。
