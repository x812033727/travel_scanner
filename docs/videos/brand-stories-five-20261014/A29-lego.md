## 點閱包裝與唯一問題

- **標題**：**樂高連賺錢的樂園都賣了：當年到底缺什麼？** 問的是出售原因，不預設賣樂園單獨救活公司。
- **縮圖假設**：左側一般化的卡通樂園亮著燈、標「有賺」；右側年報式紅色虧損數字與一隻把樂園移出畫面的手，主字「賺錢也要賣？」。畫通用方塊與遊樂設施剪影，不生成 LEGO 商標、授權角色、真實園區地標或看似真實的年報內文。
- **主線**：積木公司先開出比隆樂園，1996 年再開溫莎；核心玩具業務出現虧損警訊時，加州與德國樂園陸續開幕。到 2004 年四座樂園仍能獲利，集團卻需要現金並縮回積木主業。賣掉多數股權只是整套重整的一步，還有削減成本、其他資產處分及家族資金安排。
- **時間順序的五個轉折**：1932–1996 年工坊、比隆與溫莎樂園 → 1998–2003 年虧損警訊與加州、德國樂園開幕交錯，2003 年營收急跌 → 2004 年啟動行動計畫並決定出售樂園 → 2005 年完成交易、營收與損益改善 → 2019 年家族投資公司參與 Merlin 私有化，但樂園仍不屬於樂高集團。
