## 共用規格

- MiniMax `image-01`、原樣 `cute-mystery` preset。插畫至少七成，卡片最多連續三張。
- 開場濃縮之後接既有 5 秒動畫；正文之後接既有 21 秒片尾。實際可點擊元素仍需後續在上架包與 Studio 設定。
- 開場預告與揭曉使用同一張已驗收的圖，分鏡先記錄對應；正式產圖後還要核對素材檔與雜湊。
- 繁中 CC 可關閉，英／日／韓語言工作由站主逐片勾選。
- 估時依每分鐘 230–250 個文字計數單位，沒有加空白、慢播或補字湊片長。正式旁白、音訊與剪點尚待實測。

正式時長門檻的正文包含六章旁白及開場濃縮，排除外加品牌動畫；`assemble` 以整條旁白時間軸的 `body_frames` 驗證。部分初稿另列開場後五章的小計，不能拿那個小計代替正式正文長度。

## 證據與後續

每集 `author-sha256.json` 保存作者凍結索引，`integration.json` 記錄逐 byte 複製的交付檔；`independent-reconstruction.json` 是從原稿六章旁白表重新解析並還原分鏡的結果。作者文件中的 Temp、previous 備份與「待獨立覆核」是交稿當下描述；歷史備份留在製作工作區，現在的覆核以該集相符雜湊的 `independent-review.json` 為準。

本批的逐檔雜湊、來源釘選、三組共用圖與總數重算見[整合檢查](integration-verification.json)。完整費用與上限提案見[報價 v3](../cost-proposal/B18-five-production-cost-proposal-v3.md)。

正式章檔的[格式原型與剩餘差距](../formal-prototypes/README.md)另存；一般故事匯入不會直接使用本目錄的完整分鏡與旁白，不能把匯入成功當成已採用作者稿。

這些編輯覆核不代替正式章稿的實際查核、順聽或敘事審查。A01／B18 試作及站主看片仍在五集之前；全片報價與付費授權、實錄、產圖、成片、播放器驗證及上傳分開記錄。
