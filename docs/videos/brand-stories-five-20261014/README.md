## 五集共同的觀看時間軸

| 時間軸 | 觀眾看到與聽到的事 | 製作及驗收 |
| --- | --- | --- |
| `0:00` 起、30–60 秒 | 一個具體場景先落地。前約 20 秒有標題承諾的名字、年份或數字。後面預告三至四個按發生順序排列的事件，各停在結果之前，最後一問接正文。 | 旁白第一句不打招呼、不唸目錄。每個預告在正文有真正的新事實回收；開場說過的事實不重講。Treatment 中的 45 秒只是文字估算，TTS 後量實際時間。 |
| 濃縮開場後 | 全頻道 5 秒／150 格動畫片頭。 | 依[頻道品牌素材規格](../BRANDING.md)在第一章與第二章之間插入。當前本機 `_branding/current.json` 讀到 `mokaair-brand-package-v4-endscreen`、hash `416c8768d4d29f2e746a0c019d2d598ec367cbb66b0ff996841c523651a63e88`、片頭 150 格、片尾 630 格；實際合成前再次回讀並鎖 pin。 |
| 正文約 10 分鐘目標 | 台灣口音單人旁白、六個事件章，MiniMax `image-01` 可愛插畫為主，繁中字幕跟著音訊。預計每集約 75–120 張插畫，實際張數以分鏡與量到的時長決定；每約 5–8 秒更新畫面狀態，圖像要推進下一步。 | 後五章沿一條因果主線，每 60–90 秒埋可回收的疑問。正文插畫 `shot` 至少 70%；兩張插畫間最多 3 張卡，卡片只放數字、名字、引文或出處。章名指向事件；來源不足就縮短，不能用重複或慢播灌長。五支保持 `series.kind=story`、`format=drama`、`visual_tier=stills`；其他語言字幕與配音依另行核定。 |
| 正文最後三句 | 回答開場、給一個與故事相連的留言題、說一個有理由的訂閱邀請。 | 正文不口播「下一支是什麼」；這件事交給結束畫面。 |
| 正文後 21 秒／630 格 | 1 秒停頓與配樂淡入、3 秒動畫、17 秒留兩個影片卡位與一個訂閱位置。 | 最後 16 秒在 YouTube Studio 放「最符合觀眾喜好」、訂閱、「最新上傳」三個**真正可點**的元素；MP4 畫出的外框本身不能點，YouTube Data API 也不能替代 Studio 編排。未上傳前只能準備 `endscreen-setup`，不能宣稱連結已啟用。 |

現用 v4 片尾在動畫之後還有約 1 秒 CTA 淡出，因此可點元素依[時間修正票](../../../tasks/open/2026-10-12-correct-v4-youtube-end-screen-timing.md)與[奇聞檔案局重製片規格](../curio-five-recuts-20261012/README.md)放**最後 16 秒**。`BRANDING.md` 仍寫「片尾第 4 秒／最後 17 秒」，該行尚待修正；實際上傳時以 v4 畫面與 Studio 預覽再核對。

正文旁白至少 8 分鐘，整支以約 10 分鐘為目標；各篇暫以約 10:00 正文加 0:05／0:21 片頭片尾寫稿，實際聲畫時間由 `ffprobe`、TTS timeline 與 QA 驗證，片頭片尾不能湊正文門檻。五集保留母企劃的**非虛構、只用旁白**邊界。畫風只用 `look: {"preset":"cute-mystery"}`，不另加 `style`、`negative`；插畫是說故事，不是來源文件的證據重建。提示詞逐張只寫景別、時地、一個人物的一個動作、焦點物件與光線，不寫畫風或要求模型生成文字、商標、真人肖像。必要的名稱、數字與來源在後製卡片呈現；插畫通過既有 judge 且不與旁白／來源矛盾、畫風未漂移，就可收片。

## 編輯查核與製作順序

1. 先把 Treatment 的六章推進成每章帶來源的逐字稿與畫面句，逐句標明主張。重要數字、時間、因果、法律裁決與企業自述要有頁面證據；爭議說法保留歸屬。開場四個懸念在正文各有 setup/payoff，全文不重播已揭曉的答案。
2. 逐章查核、逐章聽眾審稿，再做完整敘事盲評。`youtube-video` 的[故事主線與開場規格](../../../.agents/skills/youtube-video/references/script-writing.md)及 `node tools/video/cli.mjs narrative --slug ...` 的說故事關卡要在逐字稿後跑；本階段的短企劃不能冒充通過該關。
3. 五集由來源題庫抽出時，不覆寫現有 100 集的已核准順序，也不直接把本 README 交給 worker。五題的來源綁定 worker 輸入與新獨立審稿已在本機完成；若再更動 `chapters`、標題或事實欄位，須重做相符的 `reviews/<id>.json`。正式站匯入前核對既有 slug、集數和進行中工作，先唯讀 dry-run；**A01／B18 試作通過前不套用五支的新作品或啟動工人**。
4. 媒體購買前核對品牌素材、旁白、MiniMax 價格與帳號餘額，按**整集**估插畫張數、重畫、judge、TTS 與總額並取得一次性核定。畫風已由站主選定，不為再選風格反覆試畫；若需要確認分鏡可看，按既定成本做連續鏡頭 pilot，之後依同一核定批量產圖。完成後聽全片、看全片，檢查插畫／卡片比例、字幕、章節、音量、來源、縮圖與 `qa`，分別保存 hash 和費用收據。
5. 待站主看過成片後，才進入上架確認。私密上傳、Studio 結束畫面實際可點、公開發布及站主接受，各記不同證據；不可因為生成 MP4 或 YouTube private ID 就寫成公開完成。

截至本稿，[品牌故事試作票](../../../tasks/open/2026-09-28-video-story-pilot.md)仍未有 A01／B18 成片與站主看過的收據。站主已定它們先完成，這五支接著做；不暗改原 100 集每天兩支的排程。[奇聞檔案局 skill](../../../.agents/skills/curio-episode/SKILL.md)依既有集數記錄的 MiniMax 插畫連 judge 約 US$0.0135／張、整集約 US$1.5–3，是**畫面路線的歷史估算**，不是這五集的報價或已支出。五支的畫面小計粗估約 US$7.5–15，仍不含旁白、文字模型、其他審查、重試及稅費；製作前以當時價目、整支預算與實際帳本核准。A01／B18 的 Gemini 成本與每支 US$25 上限依原試作票另計。
