## 編輯查核與製作順序

1. 先把 Treatment 的六章推進成每章帶來源的逐字稿與畫面句，逐句標明主張。重要數字、時間、因果、法律裁決與企業自述要有頁面證據；爭議說法保留歸屬。開場的懸念在正文各有 setup/payoff，全文不重播已揭曉的答案。
2. 逐章查核、逐章聽眾審稿，再做完整敘事盲評。`youtube-video` 的[故事主線與開場規格](../../../.agents/skills/youtube-video/references/script-writing.md)及 `node tools/video/cli.mjs narrative --slug ...` 的說故事關卡要在逐字稿後跑；已審完整編輯稿也不能替代工人實際章稿的該項檢查。
3. 五集由來源題庫抽出時，不覆寫現有 100 集的已核准順序，也不直接把本 README 交給 worker。五題的來源綁定 worker 輸入依最新完整稿重新對齊及獨立審查；若再更動 `chapters`、標題或事實欄位，須重做相符的 `reviews/<id>.json`。正式站匯入前核對既有 slug、集數和進行中工作，先唯讀 dry-run；**A01／B18 試作通過前不套用五支的新作品或啟動工人**。
4. 媒體購買前核對品牌素材、旁白與當時 MiniMax 價格，按**整集**列明插畫張數、重畫、judge、文字與語音、重試及總額，取得一次性核定。依使用者的訂閱豁免，不再要求提供供應商現金餘額、方案截圖或另證帳務權益作為前置關卡；此豁免不代替每片具體報價與已核定成本範圍。畫風已由站主選定，不為再選風格反覆試畫；若需要確認分鏡可看，按既定成本做連續鏡頭 pilot，之後依同一核定批量產圖。完成後聽全片、看全片，檢查插畫／卡片比例、字幕、章節、音量、來源、縮圖與 `qa`，分別保存 hash 和費用收據。
5. 待站主看過成片後，才進入上架確認。私密上傳、Studio 結束畫面實際可點、公開發布及站主接受，各記不同證據；不可因為生成 MP4 或 YouTube private ID 就寫成公開完成。

截至本稿，[品牌故事試作票](../../../tasks/open/2026-09-28-video-story-pilot.md)仍未有 A01／B18 成片與站主看過的收據。站主已定它們先完成，這五支接著做；不暗改原 100 集每天兩支的排程。[奇聞檔案局 skill](../../../.agents/skills/curio-episode/SKILL.md)依既有集數記錄的 MiniMax 插畫連 judge 約 US$0.0135／張、整集約 US$1.5–3，是**畫面路線的歷史估算**，不是這五集的報價或已支出。五支的畫面小計粗估約 US$7.5–15，仍不含旁白、文字模型、其他審查、重試及稅費；製作前以當時價目、整支預算與實際帳本核准。本次對話僅 A01 有明確 US$25 整片付費授權；B18 仍是後續試作依賴，不能把技術上的試作預算上限或先前文件寫法當成已取得 B18 的付費授權，更不能自動延伸為五集各 US$25。
