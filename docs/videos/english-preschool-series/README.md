# Sunny 與 Pip 的幼兒英文小花園：48 集製作文件

本系列承接已交付的 5 集試播，完成幼兒階段的 4 季、每季 12 集，共 48 個不同課程內容。語言版本不重複計算集數。對象為初接觸英文的幼兒，學習以聽辨、指認、自願跟讀與輕柔動作為主，不要求識字、速度或全部答對。

**目前狀態：本機成品已完成。** 48 集影片及整套／分季 ZIP 已完成，總長約 144.09 分鐘。第 1–5 集保留原試播；第 6–48 集為新增影音。全套驗證與打包檢查通過；採用 Edge 試製合成配音，未接後台正式聲音、未上傳或發布。

## 課程來源與目標

- [`lessons.json`](lessons.json) 為整合製作來源，包含 48 集、480 個場景；每集的 `season` 決定所屬季數。
- [`season01.json`](season01.json)、[`season02.json`](season02.json)、[`season03.json`](season03.json)、[`season04.json`](season04.json) 保存分季課程。變更後須重新整合，再執行語音與渲染，不可只修改衍生的 `lessons.resolved.json`。
- 第 1–5 集的原始講解、英文示範與畫面 token 保留，僅增加季數標記，讓既有成品可以重用。
- 第 6–48 集每集 10 景，含示範、跟讀、至少 3 題聽力題與複習。跟讀保留 5 秒，聽力題保留 6 秒回應時間；每季最後一集整合已學內容。
- 先建立英文聲音與意思的連結，再延伸到短句。可只指認、觀看或坐著參與；不以觀看集數宣稱達成能力等級。
- 第 28 集已納入 **Mom 與 Dad：小熊的家人**，以 Sunny 的家庭為例，不假定每個孩子都有相同的家庭成員。

## 成品與語言規格

| 項目 | 規格 |
| --- | --- |
| 課程數量 | 4 季 × 12 集，共 48 集；第 1–5 集重用試播，第 6–48 集新增 |
| 單集長度 | 目標約 3 分鐘；以五語實際語音長度建立共同時間軸，允許 180–300 秒，不裁切講解 |
| 畫面 | 1280 × 720、16:9、H.264 MP4；預設每秒渲染 15 畫面，輸出 30 fps |
| 英文字幕 | 直接嵌入畫面；跟讀顯示目標英文，聽力題揭答前僅顯示中性英文指令 |
| 教學音軌 | 英文、繁體中文、簡體中文、日文、韓文，共 5 組；MP4 預設繁中 |
| 英文示範 | 五組音軌共用同一段英文單字、短句與跟讀示範，四語不取代英文示範 |
| 翻譯 CC | 繁中、簡中、日文、韓文，共 4 組，可獨立切換或關閉；沒有英文 CC |
| 音訊檔 | 各語獨立 `.m4a`，AAC、24 kHz、單聲道，並封裝進 MP4 |
| 字幕檔 | 各語 `.srt`、`.vtt`，MP4 內嵌四語可切換字幕；瀏覽器播放器使用內嵌的字幕資料 |
| 離線播放器 | `index.html`，選季、選集、播放、暫停、拖曳進度、獨立切換音軌與 CC |
| 交付方式 | 全系列目錄加 `Sunny_Pip_Season_01.zip` 至 `Sunny_Pip_Season_04.zip`，每包 12 集，含該季獨立播放器 |
| 發布狀態 | 本機試製交付，未接後台、未使用後台正式聲音、未發布或上傳 YouTube |

試製音訊使用 **Microsoft Edge read-aloud 合成語音**：英文 Jenny、繁中 HsiaoChen、簡中 Xiaoxiao、日文 Nanami、韓文 SunHi。這些名稱是本機製作選擇，不能宣稱為後台設定的正式聲音。切換正式聲音時須重新量測語音長度、建立字幕時間軸並驗證成片。

聽力題先播放英文，再完整等待 6 秒，最後才顯示英文答案與四語翻譯。揭答前的講解與 CC 不翻譯目標詞，畫面不預先圈選答案；選項位置輪替，大小、顏色、位置等概念只改變被教的差異。

## 檔案位置與分季打包

媒體輸出固定放在公開 repository 外：`/workspace/preschool-series-output`。原試播在 `/workspace/preschool-pilot-output`。repo 僅保存課程文字、文件與工具，不收進 MP4、音訊、語音快取或憑證。

```text
/workspace/preschool-series-output/
  lessons.resolved.json       # 實測語音長度與共同時間軸
  audio-plan.json             # 語音請求計畫
  audio-manifest.json         # 語音製作狀態、語音來源與快取紀錄
  batch-status.json           # 要製作、已完成、失敗與等待語音的集數
  curriculum-checks.json      # 全系列驗證或未完成的進度檢查
  package-checks.json         # 四季交付包的完整性檢查
  幼兒英文48集課程目錄.csv    # 依四季整理的課程目錄
  Sunny_Pip_Season_01.zip     # 第 1 季；另有 02、03、04
  build-logs/                # 各集製作紀錄
  index.html                 # 全系列播放器
  ep01/ ... ep48/
    final.mp4                # 1 影像、5 音軌、4 CC
    picture.mp4              # 離線播放器使用的無聲影像
    poster.jpg
    checks.json              # 長度、串流、來源與成品雜湊、解碼結果
    audio/{locale}.m4a
    captions/{locale}.srt
    captions/{locale}.vtt
```

分季 ZIP 應各自包含 12 個 `epXX` 目錄與只列該季的 `index.html`，保留播放器需要的相對路徑。季別為 01–12、13–24、25–36、37–48；附課程資料、閱讀說明與驗證紀錄。包內必須保留離線播放器使用的 `picture.mp4`；不要納入 `.tts-cache`、中間影格、暫存檔或製作日誌。包內媒體與最終 `checks.json` 的雜湊必須一致，解壓後再確認播放器能找到每集影片、封面、音軌與字幕。

## 重建與續做

以下命令從 repo 根目錄 `/workspace/travel_scanner` 執行。需要 Python 3、Pillow、`edge-tts`、FFmpeg／FFprobe；播放器檢查需要 repo 的 Node 依賴。語音合成需要可用網路；代理、CA 信任與認證依環境規則設定，不把憑證寫進課程或命令。

先做不連網的來源與語音計畫檢查：

```bash
python tools/video/preschool/audio.py \
  --source docs/videos/english-preschool-series/lessons.json \
  --output /workspace/preschool-series-output \
  --plan-only
```

從完整課程重建，或在中斷後以相同命令續做：

```bash
python tools/video/preschool/batch.py \
  --source docs/videos/english-preschool-series/lessons.json \
  --output /workspace/preschool-series-output \
  --workers 3 \
  --fps 15
```

若第 1–5 集已按原樣帶入輸出目錄，這輪只製作新增集數：

```bash
python tools/video/preschool/batch.py \
  --source docs/videos/english-preschool-series/lessons.json \
  --output /workspace/preschool-series-output \
  --start-episode 6 \
  --end-episode 48 \
  --workers 3 \
  --fps 15
```

同一輸出目錄只保留一個語音 producer。若 `audio.py` 已在外部執行，上述批次命令增加 `--watch-audio`，使用它已寫出的音訊；若音訊已完整完成而只要渲染，改加 `--render-only`。不可同時啟動兩個 producer 寫相同 manifest。`--cache-dir` 可指向既有內容雜湊語音快取，未指定時使用輸出目錄的 `.tts-cache`。

批次工具最多 2 個並行語音網路請求、3 個渲染 worker；完成每集音訊後即開始該集渲染。已完成影格與有效成片經來源、renderer 與成品雜湊比對後可續用；失敗以非零狀態退出，在 `batch-status.json` 與 `build-logs` 留下紀錄。

### 可選的 Pillow SIMD 加速

一般 Pillow 即可正常重建，SIMD 不是必要依賴。本次第 6–14 集已使用 Pillow 12.3 製作；第 15 集起改用 `/tmp/preschool-simd` 中的 Pillow 12.1.1.post0，以 `PYTHONPATH` 前綴選用，本機圖像繪製基準測得約 5.5 倍加速。

本次已比對 103 組畫面，圖像部分的像素差異不超過 2／255；英文文字間距與 `ff` 連字有些微差異，已目視確認文字清晰。`build.py` 在每集檢查紀錄保存實際 `render_library` 與 renderer 版本，新的 scene cache 雜湊包含繪圖函式庫版本，避免混用不同版本的場景快取。`verify_series.py` 依每集記錄的函式庫驗證已完成成片，舊版成品則按既有 metadata 規則核對。

當環境已安裝上述 SIMD 套件、且音訊已完成時，可用以下命令續做第 15–48 集；保留原本的 `PYTHONPATH` 路徑：

```bash
PYTHONPATH="/tmp/preschool-simd${PYTHONPATH:+:$PYTHONPATH}" \
python tools/video/preschool/batch.py \
  --source docs/videos/english-preschool-series/lessons.json \
  --output /workspace/preschool-series-output \
  --start-episode 15 \
  --end-episode 48 \
  --render-only \
  --workers 3 \
  --fps 15
```

未安裝 SIMD 時直接使用前面的標準命令。重建時仍須以逐集成品與全系列驗證結果判定完成，不能只依加速測試或語音成功數判定。

### 播放器與交付包

音軌與影片都完成後，單獨重建播放器：

```bash
python tools/video/preschool/build.py \
  --source /workspace/preschool-series-output/lessons.resolved.json \
  --output /workspace/preschool-series-output \
  --player-only
```

完成媒體驗證後，產生四個分季包與課程目錄：

```bash
python tools/video/preschool/package_series.py \
  --resolved /workspace/preschool-series-output/lessons.resolved.json \
  --output /workspace/preschool-series-output
```

工具會生成 `Sunny_Pip_Season_01.zip` 至 `Sunny_Pip_Season_04.zip`、`幼兒英文48集課程目錄.csv` 與 `package-checks.json`；每個季包使用獨立播放器，只列出該季 12 集。本次另加 `--all-zip`，提供 `Sunny_Pip_48_Episodes.zip` 整套包。

一集需要重做時，使用 `batch.py --episode ep28` 等單集參數；先修正課程來源，再重建實測語音與時間軸。只有字幕或封裝變更且素材未變時，才使用 `build.py --episode ep28 --mux-only`。

## 驗證與交付條件

1. **課程資料：**來源包含 48 個不重複集數、4 季各 12 集、每集 10 景；五語 `instruction` 與四語 `demo_translation` 完整。新增一般集數至少 3 題 quiz；第 47 集故事為 1 題，其餘集數依各集設計，等待秒數、選項與目標相符；聽力題的畫面英文只能是 `Listen and point.` 或 `Listen and do.`。第 1–5 集保留原試播內容，不為符合新增集數規則而改稿。
2. **語音與字幕時間軸：**查看 `audio-manifest.json` 與 `lessons.resolved.json`。每集五語音訊與四語 SRT/VTT 都存在，字幕時間不超出成片，聲音與英文示範不被截斷；quiz 在 `reveal_at` 前不出現答案翻譯。本次完成四語文稿交叉審查與五音軌音量抽查，未進行逐集人耳全程聽審。
3. **畫面語意：**查看所有新 token 與每類 quiz 的揭答前後畫面。檢查家庭角色、身體部位、數量、形狀、顏色、大小、方向、位置與動作確實可分辨，沒有字卡遮擋、提前揭答或靠位置猜答案。`art-validation.json` 僅是畫面機制證據，不能取代成片觀看。
4. **成片技術檢查：**`build.py` 封裝後自動用 FFprobe 確認 1280×720、1 影像／5 音軌／4 CC、無英文 CC、180–300 秒及時間軸誤差小於 0.2 秒，再用 FFmpeg 完整解碼所有影像與音軌；結果寫入各集 `checks.json`。第 1–5 集另核對與試播成品的 SHA-256 相同，並重新完整解碼複製後的成品。
5. **播放器：**資料完整後執行下列 JS DOM 操作檢查；它會模擬媒體介面，不能證明真實影音解碼。本次檢查全系列及各 ZIP 的選集、換季、五音軌／四語 CC 獨立切換、關閉 CC 與跳轉，並核對包內媒體路徑；未進行真實瀏覽器實播。
