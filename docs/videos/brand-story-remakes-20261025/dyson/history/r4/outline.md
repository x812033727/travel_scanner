# Dyson R4｜單線大綱

承諾：一台無袋原型從工廠分離問題、跨國重新開發，走到自家製造與初期英國接貨；不是全球first、日本救命或公司產品清單。

## 四個人有圖，卻找不到人組裝

你只靠四個工程人員，要把新吸塵器交出去，誰來組裝？ → 不用集塵袋的想法，中間還要換過多少人的手，才能做成能賣的機器？

來源：N07、A04、D14、N06、N01、N09；171 units。

## 布濾堵住，家裡的空袋也吸不動

開場那台無袋吸塵器的原理，是從戴森處理的一個工廠故障接過來的。 → 能做出工作樣機以後，誰來付模具的錢、把它批量做出來？

來源：N01、N02、N03、N04、N05；766 units。

## 授權有人接，工作還沒結束

戴森回憶，他和合作夥伴原先選擇，把工作放在發明、工程與樣機上。 → 你如果想直接沿用原設計，哪個規格差異會先讓人停下來？

來源：N05、D01、D02、D07、D08、D09、D06、A01、D10；526 units。

## 馬達改了，入口也要動手

山本說，英國和日本的電壓不同，他們得重新找馬達。 → 戴森回英國時，這些設計要怎麼繼續接下去？

來源：D10、D11、D12、D14、D15；428 units。

## 圖紙跨海，商品走到日本市場

山本說，戴森人在英國時，他們就一再傳真往返。 → 收入進來了，量產模具的錢，就一定借得到嗎？

來源：D15、A02、D13、D16、D17、A04、N06；419 units。

## 圖面之外，還缺資金和組裝的人

開場問的模具款，戴森回憶，一位到企業訪問的銀行人員，替他爭取貸款。 → 可是，有了能交的機器，你就一定找得到店家接貨嗎？

來源：N06、N07、D20、N08、D22；402 units。
