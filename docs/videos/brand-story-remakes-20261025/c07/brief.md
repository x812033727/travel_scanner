# C07 馬汀靴 R4｜一雙舊靴從選修到回程

狀態：R4作者修訂稿，HOLD，待另一位獨立來源／書面配鏡審核與兩位全新隔離讀者。R3的PASS綁定舊四檔，不適用本稿；作者曾作R3來源reviewer，現在不得自審或自寫verify。

## 問題

一雙鞋底快磨穿、鞋面仍好的馬汀靴，換底時到底換走什麼，穿慣的上半部怎樣跟著回來？

## 一句答案

授權換底服務拆換舊外底、沿條與縫線；留下的鞋面接上新沿條與外底，修邊、清理和穿帶後，整雙裝盒交回穿著者。

## 站主觀點

我想讓觀眾看懂自己說的換底，手上實際在動什麼。從一位穿著者已公開說出的選擇開始，鞋進盒後才往收件與工作檯走，回程只給新的通知與結果。不同原件提供不同層級的資料：顧客說自己的使用與感受，示範讓我們看手和工具；它們不能被剪成拍到同一雙實鞋的證明。

## 本次建議

### 選項 A：先選好，再把這一雙送出去

開場的具歸屬案例從選修理和配色開始，接到沿條位置、現行服務範圍，再把靴子放進舊鞋盒。收件通知把敘事交給另一次授權示範，刀口、機針、熱接、修邊、擦拭與重新穿帶各自帶來新狀態。示範裝盒後，接回七月評論者收到的完工消息與回程；新增鞋帶和穿著者自述收住主問題。

## R3 → R4 修訂範圍

共同未通過的四項為one_line、no_toc、no_recap、no_detour。選配色的自述移入開場，裝盒寄出只在第二章末發生一次；結尾不回述星期四裝箱。開場承諾保留品牌與一雙鞋的尺度，移除三部件／三步旅程的目錄句。重複的倒靴手扶姿勢、沿條已接而新底仍分離、四年舊底與好鞋面的再述、泛說新舊部件的空泛句均刪。年度修復量問答和品牌忠誠段落退出這趟送修，結尾不再重列拆接工序。

## 六章事件

1. 公開評論中的四年舊靴先選修理與配色，留下拆開範圍及回程新增物兩個未揭結果。
2. 沿條位置與現行服務說明接住選項，靴子裝盒寄出，穿著者收到到站消息。
3. 授權示範裡，舊底被拆走，新沿條縫上留下的鞋面。
4. 熱刀、滾輪與冷卻接回新底。
5. 新底修邊、鞋面清理和鞋帶重新穿回，鞋被擺到紙箱旁。
6. 示範裝盒後，接回七月評論者的完工通知與回程，新增鞋帶回收開場預告。
