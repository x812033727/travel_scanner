本配方與同集已核准新稿只有`subtitles.burn_in: true → false`差異；原繁中燒錄來源保持不變。`derivation.json`記錄官方劇本、實際版本字典下的旁白、圖像、畫風與混音輸入雜湊一致，字幕輸入雜湊不同。保留同一新版slug及預算身分，不借舊集已放行帳戶。

目前只有衍生配方，沒有乾淨影片、媒體QA、final核准或實際配音資格。`lint.json`與輸入雜湊不是已驗收媒體的證明。原生配音仍要求目前核准的clean成片、綁成片SHA的完整QA與後台真實語言選擇；不得修改資格規則或把已燒字幕檔案改標籤。

正式入場與實際主素材驗收完成後，繁中燒錄輸出及乾淨國際主片共用同一份新音訊、插圖與配樂，分別本機重新輸出，不重買整集素材。以相同不可變字典、原生輸入hash及真實檔案／供應商收據核實快取；缺少或過期先停下核對，不強制重購。

配方資料夾不是canonical執行目錄。正式執行時用正確slug與隔離export目錄；重新完整解碼與驗證無燒錄字幕、可關閉繁中CC、音畫、正式5秒片頭及21秒v4片尾。各輸出保留實際SHA，clean輸出重新作final審核，不能沿用另一個MP4的QA或核准。正文12–14分鐘仍須實際量測。
