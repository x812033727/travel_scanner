# C03 八語文字準備

英文、日文、韓文、西文、葡文、印尼文、越南文、泰文，各143句字幕文字、6章與標題說明／標籤／縮圖文字；共1,144句、48章。八份JSON均由原生`i18n-sheet`／`i18n-merge`產生雜湊，逐欄保護原始ID、來源與cue順序；非譯者逐語覆核、修正後精確差分重查均為`TEXT_PASS`。原始FIXES_REQUIRED、已撤回的系列標籤要求、修正及原輸入保留於`reviews/`與`history/round-1/`，未將歷史意見改成一致通過。

這是對已核准r3劇本的**文字準備**。實際TTS仍被預算入場鎖拒絕，因此沒有真實時間軸、SRT、語速或字幕同步驗收，也沒有外語配音；多子句長行仍需依實際cue切分，配音須在實際視窗下適配並重審縮短。

後台已讀回八語的標題說明、CC、配音全部選取；原始決定時間來自後台，見`../backend-language-choice.json`。前置選擇不表示可啟動語言製作。原生品牌故事配音要求目前核准成片有真實乾淨無燒錄QA；本批會保留繁中燒錄輸出，另以`../variants/clean-master/`配方實際組出乾淨主片，QA及成片關卡成立後才進八語配音。

`preparation-status.json`綁各檔與重查收據；`runtime-rehearsal.json`確認新建隔離執行目錄可以逐位元組帶入八份翻譯，原生lint 0 errors且無缺漏或過期翻譯警告。這項檢查未生成媒體、核准或付費請求。

接續時用官方CLI沿真實時間線產生CC；先讀回同一版後台語言選擇，再由正常語言流程同步`languages.json`，不手造決定時間或配音資格。八語音軌共享同一乾淨主片與已驗素材，不重買整集圖像。
