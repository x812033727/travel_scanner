# C03 乾淨國際主片配方

這份`video.json`與已核准r3只有`subtitles.burn_in: true → false`一項差異；原繁中燒錄配方保持原樣。`derivation.json`與獨立`review.json`實核官方劇本位元組、旁白、圖像、畫風、混音輸入相同。影片識別仍是同一個新版C03 slug，沒有借原C03已放行的slug或建立第二個支出身分。

**目前只有配方，沒有clean影片、QA、成片核准或配音資格。** 這不是把已燒字幕檔案改標籤。後台八語均已選metadata／CC／dub，原生`_story_dub_ready`要求目前核准的實際clean成片與綁定MP4雜湊的完整QA，之後才會啟動語言輪。

正式主機入場完成後，先按主r3製作並驗收同一份新旁白與100張新圖。保留實際繁中燒錄輸出及其SHA；以這份配方在正確slug的隔離export目錄，從同一批已實際驗收的檔案與供應商收據重新本機render／assemble乾淨主片，不重買音訊、圖片或配樂。使用原生雜湊與檔案證據驗證快取；任何輸入／檔案不相符先停下核對，不能以缺快取為由再整片購買。

本配方資料夾名稱不是canonical project目錄；正式執行時保留正確slug、同一不可變字典與原生來源雜湊。`tts --refresh-evidence`只在原始takes全數已驗且current時使用，不合條件應拒絕；不得改成force重錄。把實際旁白／圖片的適用核准交給原生hash檢查，不能繼承另一個MP4的final核准或QA。

乾淨主片必須重新完整解碼、驗證確實無燒錄字幕及繁中可關閉CC、音量、品牌5秒片頭／21秒v4片尾與完整QA，再作為後台目前final供原生審核。這會滿足八語共用主片的既有契約；繁中燒錄版另保留供需要固定中文字幕的觀看與交付。兩輸出時間線相同，不以停頓補滿正文12–14分鐘。

完成以上實際媒體證據與關卡後，才依既有八語選擇順序製作配音、按真實line視窗擬合、聽檢、生成對應CC、重新打包。字幕文字可沿用`../../i18n/`並以原生hash確認當前；任何縮短保留金額、日期、人名及事實，依原生重試上限處理。
