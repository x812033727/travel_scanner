# C09 Patagonia｜奇聞檔案局逐鏡草案

**非付費、未鎖定張數與報價。** [逐句稿](script.md)的每個 ID 對應本表一個畫面；畫面是概念插畫或後製字卡，不冒充原始影像、目擊紀錄、某一印次型錄或可考人物。下列張數與比例為**按鏡數預檢**，正文插圖**時間**占比要等真實旁白計時才可確定。

## 共通視覺契約

- 之後若獲核准，插圖用 MiniMax `image-01`，精確 `look: {"preset":"cute-mystery"}`。提示詞只描述景別、地點、匿名成人的一個動作、視線落點與柔和光源；**畫風詞不寫進 prompt**。不生成商標、品牌名、可讀文字、真人肖像、特定攀岩路線或未授權型錄掃描圖。
- 主角道具是同一種**無字岩釘形狀**，陪觀眾由鍛造台到傷痕、型錄、1977 工廠；楔塊以另一個可拆的普通金屬形狀對照。形狀只需能理解兩種器材的差別，不能當攀岩安全示範或歷史精密復原。
- 圖像以匿名成年攀岩者／鐵匠做一件事為主，遠景、中景、近景輪替；日間岩壁、室內工坊、陰天街景交替。1973 年攀登與 1977 年採訪的插圖明確是抽象示意，不畫成兩位史實人物的臉。若鏡頭無人，焦點必須是該句的器材或傷痕。
- `stats` 是後製卡，一卡只標一個年份、原文限定、名字或證據歸屬；卡片文字不交給模型畫。原件簡短文字、來源與日期由後製排版，不直接複製館藏影像。正文繁中 CC 可關閉，不燒入插圖。
- 冷開場後放既有 5 秒頻道片頭；正文後放既有 21 秒 v4 片尾與連結。若日後核准配樂，方向為輕巧、好奇、微懸疑、無人聲。縮圖的 **PATAGONIA** 橘色大字只由後製放左上；這份草案不觸發圖片、TTS、配樂或上傳。
