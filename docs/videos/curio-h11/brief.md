### 選項 A：讀不懂的書，究竟查清了什麼？（推薦）

一行說明：跟著一本書從收藏桌走進實驗室，依序看材料定年、文字規律與新生成模型各回答了什麼，哪些問題仍留在原文裡。

開場鉤子：一九一二年，一名書商在義大利買下一本書。翻開來，有植物，也有一行行陌生的文字。畫面像是要教人辨認什麼，旁邊的句子卻還沒有確定的讀法。後來，研究人員會從羊皮紙取下一點樣本，想先問出它的年紀。一所大學也會發布解讀研究的消息，學者隨即提出疑慮。再後來，研究者重新處理不同光下拍到的影像，試著看清頁邊淡去的字。這些方法能讓我們離內容更近，還是只讓別的問題先有答案？

開場朗讀預估：以上約 180 字元，以每秒約 4 個中文字及短停頓配置 42–52 秒；正式配音實測後從第一章調整同等秒數，不靠停格湊時長。「像是」只描述觀眾看插畫的感受，不斷定此書是教材。

**主角／故事類型**：主角是 MS 408 這本書，屬疑問故事。每次新檢驗都讓我們多知道一層，下一層問題再自然冒出；不做奇書排行榜或解密術語教學。

**主線**：被購藏並留下問題 → 取樣確認材料年代 → 統計找出規律 → 解讀消息受到檢驗 → 新影像增加歷史線索 → 生成模型讓「看起來像」與「讀出原文」的差距變得具體。

- 0:36–0:45，A-L3：2024 年研究者重新處理先前在不同光線下取得的頁邊影像，暫不揭露三欄內容；不把 2014 年拍攝誤放在 2019 年之後。（C09–C10）
- 0:45–0:55：品牌片頭；第一章回到這本書本身，避免先講一整段解密歷史。

### 選項 B：首頁邊緣，藏著誰讀過它的痕跡？

一行說明：沿一本書的首頁邊緣，從書商留下的試劑痕跡走到現代影像與筆跡研究，尋找文字讀者和抄寫者留下的可辨認線索。

開場鉤子：一九一二年，一名書商買下一冊陌生文字的書。除了正文，頁邊還留著後來人寫過的痕跡，有些已淡得難以分辨。要接近這本書，也許能先問誰碰過它。接下來，書商會用試劑試著讓淡字顯出來；多年後，一組相機又會用不同的光重新拍它。還有人把書裡的筆畫逐一比較，試著分辨是不是出自同一隻手。字的意思還沒有答案，這些人留下的痕跡，能不能先替我們找到一條路？

開場朗讀預估：以上約 170 字，以每秒約 4 字及短停頓配置 40–50 秒；正式配音驗時，三個動作皆停在結果揭露前。頁邊概述來自後來研究，沒有宣稱書商買書當天已看清全部註記。

**主角／故事類型**：主角仍是 MS 408，以首頁痕跡作為觀看入口，屬物件的疑問故事。跟著對書本的觀察與保存前進，較 A 著重人手留下的歷史，刪去 2019 年新聞事件及 Naibbe 模型支線。

**主線**：一本陌生文字書進入近代收藏 → 嘗試看清頁邊而留下痕跡 → 材料檢驗約束年代 → 新影像把部分淡字變清楚 → 留在邊緣的字可能屬後來讀者 → 不懂意思也能進一步辨認抄寫筆跡。

## 取捨與交接
