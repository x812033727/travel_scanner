## 教訓

- 開場五步要塞進 60 秒，利害句只能兩句、場景五句、預告兩句、承諾一句、問題一句，合計約 220 字；多一句就超過。
- lint 的時長估計跟新語速差一截：2,980 字估 12.2 分鐘，照 4.5 字／秒約 11 分鐘加停頓；等旁白量過再決定要不要補一段。
- 第一版查核表的備註欄（奢侈的食物、Arbois、代理婚禮、「不太聰明但極好心」）夠加長 700 字，不必找新來源。
- 改一句之前先看前一句（S30 第二版的教訓）：拆 `brioche` 那景時，「蛋糕從哪裡來」的問句要留在拆出來的新景裡，不然 loop 的 setup 會掉。
