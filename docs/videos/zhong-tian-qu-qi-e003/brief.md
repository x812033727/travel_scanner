# 《種田娶妻打天下》第 3 集〈三日二十兩〉

## 故事前提

第 2 集收在錢員外的家丁一把扣住唐小棠的手腕「二十兩，拿人抵」、一把柴刀破空飛向門口。第 3 集從同一刻接下去：柴刀「篤」地釘進門框，離家丁的手只差一寸，畫外秦霜一句「放手。」——是她從院子中間擲出來的。錢員外抖開借據要二十兩，小禾躲在水缸後說家裡只剩一碗米；錢員外乾脆要家丁把三個新娘都寫進新字據。許硯從袍子裡掏出一本薄薄的《大衡律》：配婚的女子在官府名冊上，私押就是搶官府的人。錢員外臉色一垮，改押許家的房、地，還有許硯自己；許硯按下手印：三天，還你二十兩。

錢員外一走，系統「叮」一聲送來新手禮包：肥皂配方——字跡一片模糊，只剩「材料自備」「工具自備」。好感度第一次開啟，許硯對阿令耍帥說了句「有我在，誰都帶不走妳」，系統判定「空話」，電得他頭髮炸起，阿令的好感從 0 掉到 -5。半夜灶間，阿令一下一下磨著短匕，許硯老實認錯；從沒開過口的阿令第一次說話：「你為何不押我們？」許硯張嘴——「我……」，收在這裡。

本集細綱：`docs/videos/series-plans/zhong-tian-qu-qi/season-01.json` 第 3 集（90 秒，調性爽＋喜劇）。開頭 3 秒是柴刀釘門框＋「放手。」；中段鉤子是新手禮包的模糊配方（約 0:46–0:53）；奇觀是好感度三條第一次亮起、阿令那條掉到 -5 閃紅（0:55、1:03，面板在剪接時疊上，見 overlays.json）；結尾收在許硯話到嘴邊。
