# X01 Adobe Creative Cloud｜上架交接

此資料夾是品牌故事 **X01 本機試看片**的可審閱製作包，屬既有 C01–C20 規劃之外的補充題。現行 `video.json` SHA-256 為 `dfb2f9479fd15bae89352e3c796d59f75232d6c42acece758d5ef33e924ae253`；內含正式待用標題「訂閱數暴增，營收卻跌？Adobe 轉向 Creative Cloud 的那一年｜品牌故事」、縮圖文字「訂閱漲／營收跌」、87 句繁中旁白、六章、11 組伏筆、11 張數字資料卡、1 張中立選擇卡及 1 張 2013／2014 轉折卡、字幕設定及四份 SEC 原始申報連結。逐句依據見 [來源矩陣](source-matrix.md)。[獨立來源審查](reviews/verify-1.md)與[敘事盲讀](reviews/narrative.md)綁定舊稿；其後的提示詞修訂、新增 2013 財年產品收入 **61%** 資料卡及轉折卡，由 [視覺修訂覆核](reviews/visual-amendment.md)承接現行稿。

本機使用 5 秒**概念片頭**接在 30–60 秒濃縮開場後，並於正文後接 21 秒**概念片尾**。這兩段均明標概念版，不能冒充站主已選定的正式動畫。正式工人接手時，以站主選定動畫替換同長度區段，維持字幕與聲音時間軸；若實際長度不同，重做字幕與全片 QA。

片尾畫出左、右兩個影片框和訂閱鈕版位。MP4 內的框線**不會自行變成可點連結**；私人上傳後須在 YouTube Studio 對最後 17 秒設定兩個影片卡（最符合觀眾喜好、最新上傳）與訂閱鈕，實際打開播放器點擊驗證。上架時保留 `video.json.youtube.description` 的四個 SEC 原始網址，另上傳本機產生的繁中 WebVTT 字幕；正式影片 ID 和 End Screen 連結只在設定完成後填入。

資料口徑要保留：2013 年 30 萬→140 萬是財年末 **Creative Cloud 付費訂閱份數**，不等於人數；2013 營收及淨利、2013 產品收入占比 **61%**、2014／2015／2025 訂閱收入比例屬 **Adobe 全公司**，不等於 Creative Cloud 或 Photoshop 單品。2013 年的 61% 是 SEC 所列 **Product 收入分類**，不能改寫為 CS6 或全部買斷授權的營收。2013 數位媒體收入跌幅的年報原因包含 Creative Cloud 與企業長期授權方案採用；淨利變化另受收入按期認列和成本費用增加影響。2014 財年第二季的供應變動只指 CS6 永久授權產品停止**一般供應**，不能寫成 Adobe 全部買斷授權停售。插圖人物、場景與介面皆為示意。
