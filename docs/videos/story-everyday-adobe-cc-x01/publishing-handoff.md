# X01 Adobe Creative Cloud｜上架交接

此資料夾是品牌故事 **X01 本機試看片**的可審閱製作包，屬既有 C01–C20 規劃之外的補充題。`video.json` 含標題、縮圖文字、繁中旁白、章節、11 組伏筆、字幕設定及四份 SEC 原始申報連結；逐句依據見 `source-matrix.md` 與獨立查核收據 `reviews/verify-1.md`。

本機使用 5 秒**概念片頭**接在 30–60 秒濃縮開場後，並於正文後接 21 秒**概念片尾**。這兩段均明標概念版，不能冒充站主已選定的正式動畫。正式工人接手時，以站主選定動畫替換同長度區段，維持字幕與聲音時間軸；若實際長度不同，重做字幕與全片 QA。

片尾畫出左、右兩個影片框和訂閱鈕版位。MP4 內的框線**不會自行變成可點連結**；私人上傳後須在 YouTube Studio 對最後 17 秒設定兩個影片卡（最符合觀眾喜好、最新上傳）與訂閱鈕，實際打開播放器點擊驗證。上架時保留 `video.json.youtube.description` 的四個 SEC 原始網址，另上傳本機產生的繁中 WebVTT 字幕；正式影片 ID 和 End Screen 連結只在設定完成後填入。

資料口徑要保留：2013 年 30 萬→140 萬是財年末 **Creative Cloud 付費訂閱份數**，不等於人數；2013 營收及淨利、2014／2015／2025 訂閱收入比例屬 **Adobe 全公司**，不等於 Creative Cloud 或 Photoshop 單品。2013 數位媒體收入跌幅的年報原因包含 Creative Cloud 與企業長期授權方案採用；淨利變化另受收入按期認列和成本費用增加影響。2014 財年第二季的供應變動只指 CS6 永久授權產品停止**一般供應**，不能寫成 Adobe 全部買斷授權停售。插圖人物、場景與介面皆為示意。

旁白已完成 87 句及兩輪逐句自動複查；第二輪仍有 4 個近義措辭旗標，詳見 [`reviews/audio-check.md`](reviews/audio-check.md)。音訊尚待人工聽核，不能視為正式核准。畫面、字幕、最終成本和本機檔案驗收結果待製作完成後填入 `local-preview.md`。正式品牌素材、正式音訊核准與 Studio 可點片尾連結若尚未具備，本包只可作為明標的本機審片版本，不宣稱已正式上架。
