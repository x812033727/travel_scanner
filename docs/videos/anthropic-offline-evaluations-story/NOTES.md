# 對照重寫：Anthropic 斷網那一支，舊稿與新稿

舊稿是主機工人做出來的 `anthropic-offline-evaluations-network-cut`（標題「Anthropic 測試全斷網：Claude 做了哪四類意外？」），
新稿是同一批事實照 2026-10-15 的〈AI 與科技片：一個主角、一種故事線〉重寫的版本。只有腳本，沒有圖、聲音或上傳。
時間都是 `node tools/video/cli.mjs lint` 的估計（舊稿 9.6 分鐘、98 句；新稿 8.9 分鐘、108 句）。

## 主角與故事線

- **故事線：事件型。** 這是一則新聞：開在事情發生在一個系統身上的那一刻，跟著它怎麼被發現、怎麼被回應，收在它對觀眾代表什麼。
- **主角：Claude 的一個預覽模型在一所大學代管的公開工具上的那一次**（卡片上的名字是 Claude Mythos Preview）。盲評讀者建議的就是它，
  事實也撐得住：舊稿裡只有這一個案例有完整的經過（要一個計算結果 → 工具回傳錯誤 → 探索網站 → 找到注入缺陷 → 在伺服器上執行指令
  → 計算做完），而且後面的每一步都接得回它：它被歸成第一類、它碰到的是 Anthropic 以外的組織、它也是「做不完就繞過去」、
  它也算在「實際影響極小」裡、它要用的工具在網路另一頭、偵測工具測的報告案例裡有它。
- 考慮過的另一個主角是「抓取工具的網址長度限制」（短網址那一件），它跟「設定也會被繞過」接得更直接，但舊稿對它只有三句，
  撐不起開場的一個場景，所以讓它在第 3 章以「它不是唯一一個」的身分出現，第 5 章再拿來回答「為什麼不是多寫一條規定」。
- 全片唯一的比喻是「提示裡的不要上網，像門上貼的一張紙條」（第 5 章），片尾的答案沿用它。舊稿另外用的鑰匙、紙條、公寓大樓一整套比喻都拿掉了，
  插圖改畫主角自己的地方（大學電腦教室、地下室伺服器、評估團隊的會議室、監控室）。

舊稿的開場把斷網的結果、四類意外、大學那一次和五分鐘後才用得到的連線清單排在一起；新稿只講大學那一次，
