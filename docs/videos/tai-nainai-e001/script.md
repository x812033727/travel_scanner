## 劇情

二〇二六年十一月十六日（週一）夜裡九點，九十六歲的月棠穿著自己備好的壽衣，在老宅祠堂替長明燈添油；隔著院子，聽見正廳裡林美鳳笑「老的撐不過今晚」。
福伯來扶她回房，她讓福伯把門鎖上去睡，自己陪燈再坐一會兒。正廳裡，建業說盛通談好了、年底過戶；林美鳳學老太太晚飯的口氣說「這個家，要散了」，兩人笑成一團；
福伯經過，冷冷頂一句「老太太歇下了」；補習回家的小滿從廳裡跑過，書包上的銅鈴響了一聲，笑聲停了。祠堂裡，老太太坐上躺椅，對著燈說守不住了，閉上眼。
燈從帶灰的黃長成溫暖的橘金；睜開眼的是十八歲的她，身上還是那件壽衣。她在銅鏡裡看見自己十八歲的臉，從燈座下摸出備用銅鑰匙，打開福伯從外面鎖上的門，
迎面撞上端茶穿過院子的林美鳳：茶盤脫手，林美鳳尖叫「有賊！報警！」

## 分鏡與台詞

景別與運鏡寫中文給人讀；正文照 `minimax-h3-colab/references/motion-quality.md` 第二節與 `WRITING.md` 第十一節改寫成英文（構圖、人數、前景、一個運鏡、
動作軌跡、最後的樣子、每張臉的表情）。燈的亮度照 `cast.json` 的 `lamp.levels`，`compile.py` 每鏡自動加燈的分數與固定描述；燈不在畫面裡的鏡標「燈不入鏡」。

**欄位怎麼讀**：
- 「畫面裡有誰」寫總人數、位置、面向、服裝、道具、前景。
- 「動作」寫起點 → 主要動作 → 最後的樣子與剪點，以及每張看得到的臉的表情（眉、眼、嘴角、下巴、呼吸）；說話的人寫「嘴在說話」、對誰說、對方在畫面哪邊，其他人寫「嘴閉著」。
  2026-11-08 起「沒寫表情就是嚴肅」不再用：每張臉都寫。
- 台詞的標記：
  - 「→ 答在 cNN」：這句的回應在哪一鏡。
  - 「← 因為 cNN」：這個轉折的原因在哪一鏡。
  - 「（結尾）」：這場的結果；「（懸念 → 下一集第一場）」：本集最後的懸念。
- 秒數照句內 4.5–5.5 字／秒加動作時間估，再留半秒；說話的鏡夠講完那句，動作與反應鏡 1.5–2.5 秒；本集沒有超過 6 秒的長鏡。
- 剪點都寫在動作中間；下一鏡從同一個動作的後半開始。轉換動作（坐下、起身、轉身）寫在前一鏡的結尾或自己成一鏡。
- 每一鏡都是新的片段，不借別鏡。
