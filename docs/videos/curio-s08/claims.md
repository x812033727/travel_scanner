# S08 劇本主張與畫面對照

對照 2026-10-19 `video.json`／`script.md`：正文 91 句、片尾 2 句。來源代號與固定版本見 [`research.md`](research.md)。`[HZ33]` 為《三國志》卷三十三〈後主傳〉，`[ZG35]` 為卷三十五〈諸葛亮傳〉，`[ZG35-P]` 為裴松之注所引《諸葛亮集》，`[YY102]` 為後出的小說《三國演義》第一百二回。

| 旁白 | 依據與界線 |
| --- | --- |
| `ox001`–`ox010` | [HZ33] 建興十二年斜谷流馬、建興九年祁山木牛；[ZG35-P]「一脚四足」；[YY102] 扭舌停車。開場的布蓋只是卡通插畫中的遮蔽，不是出土器具外形；木牛與流馬名稱、補給結果及舌頭操作留到後文。`ox004` 僅預告另有裴注文字，未宣告能否復原原圖。 |
| `ox011`–`ox024`（不含刪去的 `ox020`、`ox023`） | [HZ33] 建興九年「始以木牛運」與夏六月「糧盡退軍」；[ZG35] 同記以木牛運、糧盡退。沒寫台數、單台載量或路程，故不能單憑退軍判木牛無用，也不能反推足夠全軍。`ox021` 的總量／路程／持續天數是可能缺口的分析，不說已知成因。 |
| `ox025`–`ox034`（不含已刪的 `ox029`、`ox031`–`ox033`） | [HZ33] 建興十年「休士勸農於黃沙，作流馬木牛畢，教兵講武」。前一年木牛已用；「畢」說作成，不能據此排除流馬就在 232 年初造，也沒列數量與改造項。`ox027` 把勸農讀作兼顧糧食來源的安排，屬語境分析。 |
| `ox035`、`ox037`–`ox050`、`ox100`–`ox101`、`ox108`（不含已刪的 `ox038`、`ox048`） | [HZ33] 建興十二年「始以流馬運」；[ZG35] 五丈原、每患糧不繼、分兵屯田，耕者與渭濱居民雜處，以及「相持百餘日」。流馬有運輸記錄，屯田仍是長駐安排；沒有運量或收成表，不說流馬成敗已定。`ox100`–`ox101` 把田的位置連回前線糧運，`ox108` 以相持日數說明為何持續補給重要。 |
| `ox051`–`ox056` | [ZG35] 陳壽正文「木牛流馬，皆出其意」；[ZG35-P] 裴注引「亮集載作木牛流馬法曰」。把正文歸屬與註文形制分成兩層；引用不證明裴親眼量過機器。 |
| `ox057`–`ox069`、`ox102`–`ox105` | [ZG35-P] 木牛「方腹曲頭，一脚四足」「舌著於腹」「牛仰雙轅，人行六尺，牛行四步」「載一歲糧，日行二十里，而人不大勞」「特行者數十里，羣行者二十里」。古文已有「舌」這個部件名，但**沒有寫轉舌停車**；那是 [YY102] 的操作情節。腳、足與行路字詞不能單獨證明會步行；古代量詞不換算現代公斤。`ox065` 只說古文沒有交代押運人數；「牛馬不食」只見本集所引後世小說，**不歸入裴注古文**。`ox104`–`ox105` 只區分特行／群行的記述，不推算速度或載重。 |
| `ox070`–`ox081`（不含已刪的 `ox074`、`ox080`） | [ZG35-P]「流馬尺寸之數」列肋、前後軸孔、杠、前後四腳、方囊二枚且各受米二斛三斗。木牛「一脚四足」與流馬「前後四脚」屬**不同段**；軸孔不能定輪數，固定轉錄未給唯一接法。`ox079` 把接點留作問題，在 `ox094` 回收。`ox081` 問的是**扭轉就停的操作**，不是古文是否已有「舌」字。 |
| `ox082`–`ox089`、`ox106`–`ox107`、`ox109`（不含 `ox088`） | [YY102] 小說司馬懿先搶器具、拆開仿造；不到半月造二千餘隻，派往隴西；蜀軍扮魏兵混入運糧隊，轉舌使器具停住，魏兵牽拽與扛抬不動，蜀軍再轉回舌頭，並扮神兵放煙火。全段明標小說，不當三世紀現場報告。`ox087` 對照 [HZ33]/[ZG35]：史書運糧句子沒有這套操作。 |
| `ox090`、`ox092`、`ox094`–`ox095` | [HZ33]/[ZG35]/[ZG35-P] 綜合：古文有器具使用、部件位置與尺寸，但沒有指定完整接法。`ox092` 的前軸孔去頭四寸出自「前軸孔分墨去頭四寸，徑中二寸」，單是孔位不能指定另一塊木件如何接上。試做模型即使能運糧，也只證明其接法可行，不能確定是古代唯一原貌；不宣稱所有古代圖稿或實物從未存在。 |
| `ox098`–`ox099` | 片尾留言與訂閱邀請，沒有新歷史主張。 |
