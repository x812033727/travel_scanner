## 參考圖與連戲

- 參考圖都在 `_series/zero-root-yaozu/refs/`（`docs/videos/series-plans/zero-root-yaozu/production/refs.json`）。錢通有定妝照與三視圖（s01-qian-tong-portrait／turnaround t1）；阿猙、歸伯用各自的 portrait／turnaround。參考圖若還是真人感的版本，3D 國漫重拍前要先換成 3D 定妝照，或只拿它當臉型與服裝的參考、由 look 轉成 CG。
- 沒有參考圖的：灰影（watcher 的 `night-runner` 造型，s02–s06，全程蒙面）、褐袍弟子（s32、s34，臉不特寫）、小虎斑貓（s17–s19）、池塘（s03–s10、s23、s29–s31）、陸拾的臥房（s01、s24–s28）。池塘一場可以先用 s04 與 s29 的採用首格當之後各鏡的空間參考（夜、晨各一張）。
- s01 接第 5 集 s38–s39：同一個深夜、同一扇破了洞的紙窗、窗在畫面右邊。
- 軸線：臥房陸拾在左、紙窗在右；池塘一場阿猙一律在右、灰影在左、陸拾在左；院子陸拾在左、盆在右或畫面下方；魚簍一場歸伯在右、陸拾在左；村口錢通與弟子在右、陸拾在左（s36 令牌指向畫外左邊）。
- 道具帳：濕褐布 s08 撈起 → s09 跟靈石對雲紋 → s10 捏成一團。靈石：s09 一顆（第 5 集木盒裡的），s11 丟一顆、s12 一變二、s13 再丟一顆、s14 三顆不動、s15 整盒倒進去（之後不再提數字，第 7 集錢通說的「三十二顆」是窗外那個人看到的數；第 10 集陸拾從魚簍倒出三十二顆）。小貓 s17 放進盆 → s18 彈出 → s19 嘶叫。假靈石：s23 撈河石 → s24 塗螢火粉 → s25 一排 → s26 一滴水沖掉一顆的光 → s28 一袋塞進床底地磚下。真靈石：s29 布袋抱在胸口 → s30 進歸伯的魚簍（第 9、10 集）。
- 盆的規矩（s01-t06 收線）：一晚只認一次（s12 第一次有用、s14／s15 之後都沒反應）、活的東西不收（s18–s22）。細綱寫「一天一次」，台詞說「一晚上……只認一次？」，因為第 4、5 集都是夜裡變的。
- 雲紋是繡在布上、刻在石上的小圖案，不是字；s21 的金光眨眼只是光。
- 阿猙在池塘裡只拍胸口以上、穿著短褂（advertiser_safety 不拍濕身）。灰影撞上阿猙那一下不拍（兩人接觸是 C 風險）。
