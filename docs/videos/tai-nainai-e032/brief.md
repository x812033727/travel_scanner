# 《恁祖媽今年18》第 32 集〈帳對不上〉

## 故事前提

第 23 天（十二月八日，週二）早上八點半，開店前。她把今年和去年兩本深綠進貨帳並排攤在櫃台上，兩根食指同時劃過兩行：這裡，和這裡。
知遠的臉白了：同一樣貨，今年中間多過了一手，價錢跳了一截。她說去年沒有這一家，今年每月第三週貨都從它手上過，多半是盛通安插的人。
蘇曉在電腦上查公司登記，唸出來：董事，沈建業。知遠打給二叔，電話那頭只丟下一句：藥局這個月就拆，你吵什麼？知遠要回老宅當面說清楚，
她攔在門前：那隻手姓沈，你爸會夾在中間為難。

她拿出福伯的舊手機想打回家，打不出去——門號是沈家辦的，人一走，號也停了。蘇曉說辦手機要身分證，她搖頭；蘇曉想了想：那用我的名字，先辦一支給妳。
蘇曉低頭填申請表，知遠拿著一盒藥忘了放上架。近中午蘇曉辦好回來，新門號插進舊手機；她走進儲藏室帶上半扇門，第一次用自己的號碼打給福伯。
福伯說大小姐吃得下飯，就是夜裡還喊媽。她說：跟她說，媽一定去接她，叫她等著。

深夜，兩個男人在藥局門口掛起一條長布條。她在暗掉的店裡隔著玻璃看著，沒有出去：夜裡偷偷掛的，就等天亮，讓整條街看著它下來。她在門邊坐了一夜。
清晨，春桃阿婆挎著菜籃走到門口，抬頭唸出布條上的字：本店下月結束營業……連沈記都撐不下去了。她轉身走回巷口。
