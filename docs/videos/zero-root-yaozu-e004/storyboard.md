## 參考圖與連戲

- 參考圖都在 `_series/zero-root-yaozu/refs/`（`docs/videos/series-plans/zero-root-yaozu/production/refs.json`）。胡奶奶的定妝照用 t1。本集只有陸拾與胡奶奶兩個角色，雞是畫面裡的動物、不列角色。
- 本集幾乎都在 set-hu-courtyard：雞舍前那個裂紋陶盆就是聚靈盆，每一張首格都要畫成同一個盆（盆身那道裂縫的位置固定）。場景圖是傍晚的光，夜、清晨、正午三種光照照 prompt 重打；s04 遠景要看得到角落的雞舍與盆。
- s01 接第 3 集 s44：同一盞油燈、同一隻手、同一張字條，第 3 集 s44 的採用首格當構圖參考。
- 道具帳：靈石 1 顆（s02 拋、s03 接、s05 彈進盆、s06 落盆）→ 2 顆（s08、s10、s11、s13 塞進前襟、s14–s17）→ s18 兩顆＋一枚方孔銅錢入盆 → s23 四顆＋兩枚銅錢（s25 排成一排）→ s33 四顆倒回盆；靈石上有一道細裂紋（s15 兩顆裂紋一樣，之後都要看得到）。奶奶的豆腐刀：s12 切豆腐 → s32 擱在砧板上被拿走 → s33 夾在陸拾腋下 → s34–s36 捧在手上 → s37 還在他手上（第 5 集 s01 被奶奶奪回）。被子：s19–s24 補丁棉被，s24 滑下肩。稻草：s27 蓋住盆，s29 沾在頭髮上，s30 奶奶看那堆稻草。
- 軸線：飯桌陸拾在左、奶奶在右（接第 3 集）；院子裡陸拾一律在左（雞舍那一側），奶奶與灶房門在右（s12、s26、s28、s30、s37）；s36、s37 奶奶在他背後的右邊。
- 金光：盆的光只在 s20–s24（半夜那一次）與 s35（刀尖碰盆沿時閃一下）出現；s21、s23 從正上方拍盆，是本集的奇觀，shot_plan 標 B 風險 physics.fluid（水紋），建議小樣就從這一段開（shot_plan 選 s21–s23）。
