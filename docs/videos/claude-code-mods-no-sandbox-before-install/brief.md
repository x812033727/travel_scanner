# Claude Code Mods：用一個計數器學會看懂與核對

狀態：2026-10-09 完整改寫稿，等待獨立事實與聽眾審稿；尚未產生新版旁白、成片或上架包。

## 問題

Claude Code 工作時，我怎麼用一個 Mod 看見工具呼叫次數，並確認這個功能的程式、權限與結果？

## 一句答案

讓 Mod 記錄工具呼叫事件，再把次數顯示在 Claude Code 介面；用完整範例核對掛鉤、載入與實際結果。

## 站主觀點

站主指出參考影片更清楚，並於 2026-10-09 要求「開始改善」。改善方向已授權：效果先行、只用一個具體案例、同一張角色流程圖、風險放在載入前、操作配預期結果。

這是改寫方向授權，不是針對新版 brief、script、audio、final 雜湊的核准。原片與原核准不可沿用到新版。保留原本 Sulafat 音色及 voice.style，不用 restyle；不把原片素材重新包裝成已完成新版。

## 觀眾看完能做到的事

- 分清 Claude 模型、Claude Code、工具、Mod 與外掛包。
- 解釋一次工具事件如何讓計數加一，以及為何次數不等於成功數。
- 找到官方完整範例，辨認三個檔案與四個掛鉤。
- 載入以前，閱讀來源並核對 hooks 與 calls。
- 依版本、路徑、載入、指令、事件紀錄的順序排查問題。
- 知道單次載入、重新載入歸零、停用與永久安裝之間的差異。

## 格式與長度

- 類別 tutorial；格式 slides；標題「Claude Code Mods 怎麼做？用一個工具計數器，看懂原理與載入步驟」。
- 目標 8–12 分鐘，瞄準約 10 分鐘。這是撰稿估算，正文及成片至少 8 分鐘仍須媒體實測。
- 全片只使用一個案例：官方 first-mod 工具呼叫計數器。
- 字卡、程式片段、同版面流程圖、官方公開網頁；沒有 shot 場景，不用 AI 插圖代替操作。
- 關鍵數字 0、1、2、3 都有「示意」或「預期」畫面標示；本機版本與執行限制只留在製作證據，不插入觀眾的操作流程。
- 繁體中文 CC，不燒錄旁白字幕。

## 證據與製作界線

當日官方文件查核在 claims.md。初次只執行 `claude --version`、`claude --help`、`claude plugin --help`，沒有載入 Mod 或發送模型請求。主協調者後續另備妥隔離的 2.1.293 CLI；validate/test 執行遭 automatic approval review 拒絕，原因只有 `blocked by policy`；不繞過或重試。demo/ 是可閱讀的教學來源，未宣稱在本機 Claude runtime 通過。

官方 screencast 指向公開文件，不登入、不錄製私人資料、不將官方素材描述為本機操作。程式命令卡是教學步驟，卡上「預期」不是實際 stdout。若後續取得可執行環境，先保留版本與事件證據，再以真實錄影替換相對應畫面。

獨立審稿通過與 lint 通過後，仍需新的旁白實測、音訊查核、視覺／影片 QA、CC、上架包、後台雜湊讀回與適用核准。本次不花費合成／模型額度，不更動原影片後台、發布狀態或原有核准。
