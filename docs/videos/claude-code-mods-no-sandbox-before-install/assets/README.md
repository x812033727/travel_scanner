# 原創教學圖

這五張圖由本次改寫直接撰寫 SVG，沒有引用第三方插畫、標誌或產品畫面，隨本教學來源提供使用與修改。文字與機制依 [Anthropic 的 Create a mod 官方範例](https://code.claude.com/docs/en/plugins/mods/create) 查核；官方文件不是這些圖的圖片來源。

- `counter-before-after.svg`：同一個工作加入計數前後的示意。
- `mod-flow.svg`：完整工具呼叫路徑。
- `mod-flow-model.svg`：同版面突出模型。
- `mod-flow-hook.svg`：同版面突出事件與計數器。
- `mod-flow-ui.svg`：同版面突出顯示結果。

`build-diagrams.mjs` 可重建以上五個檔案。示意中的數字不是本機測得；不要移除圖上的證據標示，或把它們當成實際操作錄影。
