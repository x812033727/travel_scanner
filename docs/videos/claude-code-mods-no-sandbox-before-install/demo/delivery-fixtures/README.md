# 交稿清單練習材料

這些檔案是教學自製情境，不是實際活動資料。它們可供一般檔案操作練習；不代表 Mod 已載入或測試成功。

在自己的練習目錄建立 `mods-lesson/delivery-practice`，從本資料夾只複製 `article.md` 和 `sources.md` 進去。保留 `cover-brief.md`，先不要複製。這就是教案的起點。

| 情境 | 準備方式 | 能核對的結果 |
| --- | --- | --- |
| 缺一份 | 只有文章、資料依據 | 封面需求的指定路徑不存在 |
| 補齊 | 再複製封面需求 | 三個路徑存在，內容仍待審閱 |
| 空白反例 | 在另一份練習副本建立空白 `cover-brief.md` | 路徑存在，但封面內容不完整 |
| 名稱錯誤 | 在另一份副本使用 `cover_brief.md`，不放 `cover-brief.md` | 約定的路徑仍缺少；底線與連字號不同 |
| 無法存取 | 只在純邏輯驗證注入明確的拒絕錯誤 | 無法檢查，不能當成缺少；這不是 OS 權限或 Claude 原生錯誤的實測 |

請在副本做空白與錯名練習，保留完整範本。核對實際使用的資料夾、完整檔名及重新檢查時間。讀資料依據時也要辨認尚待確認的資訊，不能把「有檔案」當成可以交稿。
