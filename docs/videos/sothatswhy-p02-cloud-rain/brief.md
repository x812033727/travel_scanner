# 一朵雲，怎麼變成午後大雨？（原來如此事務所 對話版試做 P02）

企劃與形式決定：[`../so-thats-why/dialogue-pilot-20261103/README.md`](../so-thats-why/dialogue-pilot-20261103/README.md)。
題目來源：PR #1971 `refresh-20261101/EPISODES.md` 的 P02（素材 S42、S57、S84）。

## 問題

一朵積雲裡大約有幾百公噸的水，水又比空氣重，它為什麼能留在天上？又怎麼在一個小時以內，變成打在你身上的大雨？

## 一句答案

雲裡的水碎成數不完、直徑約百分之二公釐的小水滴，每一顆都落得比蝸牛還慢，還被往上衝的熱空氣托著；要等大約一百萬顆湊成一顆雨滴、重到空氣托不住，才落下來。夏天下午地面最熱、熱空氣衝得最高，雲才長得夠大，一口氣倒下來。

## 站主觀點

我的看法是：「雲很輕所以會飄」這個直覺錯在把雲當成一整塊東西。這一集要讓觀眾分清三件事：雲有重量；重量分散在極小的水滴裡；決定下不下雨的是水滴能不能長大、空氣托不托得住。所有數字都是「一朵普通積雲」的估算或典型值，片中說「大約」「常見」，不說每朵雲都是這樣；台灣午後雷陣雨的時間只說「常常在下午」，不給固定幾點。兩條雨滴長大的路（碰撞合併、冰晶）都講，不說哪一條是台灣的主因。雷達、閃電、雨的味道不展開（P02 的刪減條件）。

本集是對話版第一支：所長（頻道聲音 Sulafat）講解，小問（約八歲）代替觀眾發問。小問的錯誤猜法都是常見直覺，所長不嘲笑；不替站主或角色編造真實的個人經歷，陽台、騎樓都是示意場景。
