## 製作大綱

### 選項 A：做完一套交稿檢查（推薦）
一行說明：從兩份材料開始，用同一個面板找出缺件，補檔後刷新，再用空白與錯名練習理解判斷界線。
開場鉤子：文章寫好了，資料也整理好了，但設計師還缺封面需求。能不能在交出去以前就把漏掉的那一份找出來？

1. 交稿情境、三份固定材料與本集完成目標。
2. 準備文字檔、核對副檔名與複製完整資料夾路徑。
3. 閱讀模組來源與能力，核對版本，單次載入；區分 shell 與 Claude 指令輸入框。
4. 指定資料夾，解讀「存在／缺少／無法檢查」。
5. 提供的封面需求加入後按鈕刷新，對照實測前後結果。
6. 空白內容、錯名與檢查時間的實作練習及答案。
7. 一次性提示與固定面板如何選；完成自己的交稿檢查小練習。

### 選項 B：先看三種交稿錯誤，再組成固定面板
一行說明：先用漏件、錯檔名與空白內容對照，再回到同一份完整材料，解釋何時值得使用固定檢查面板。
開場鉤子：三份檔案都看得到，就真的能交稿嗎？先看空白檔、錯名字與漏掉的需求，分清楚每種問題需要怎麼檢查。
