# API 依據與查核範圍

文件確認日期：2026-10-09。這份說明供想理解範例程式的人閱讀；實際跟做請使用 [Windows 操作教材](../README.md)。

本例主案例使用 Claude Code 2.1.293；[建立指南](https://code.claude.com/docs/en/plugins/mods/create) 的 Mods 門檻為 2.1.287 以上。API 需與執行版本相符；修改程式時仍要讀取當前版本產生的型別，再執行原生驗證。

## 本例使用的 API

| 呼叫或事件 | 在這個範例的作用 |
| --- | --- |
| `session.start`、`$.command.register` | 註冊 `deliverables` 指令 |
| `command.run` 的 `e.args` | 取得指令後的整段參數，本例解析一個帶引號的完整路徑 |
| `$.fs.stat` | 確認指定位置是資料夾 |
| `$.fs.list` | 讀取指定目錄的一層項目清單 |
| `$.clock.now` | 取得本次查詢時間，顯示為 UTC |
| `$.ui.open`、`ui.render`、`$.ui.resolve` | 開啟並繪製自己的面板 |
| `$.ui.invalidate` | 狀態改變後要求重繪；重繪本身不查檔 |
| `Button` 的 `onPress` | 使用者按下重新檢查或關閉按鈕時處理動作 |
| `$.ui.close` | 要求關閉自己的面板 |
| `session.end` | 清除這次對話中的狀態 |

官方依據：[API 指南](https://code.claude.com/docs/en/plugins/mods/api)、[介面指南](https://code.claude.com/docs/en/plugins/mods/interface)，以及查核時對照的 [固定版本官方型別](https://github.com/anthropics/claude-code/blob/684800b206824dfd0cc8a876e8604b20f72c3617/mods/types/claude-code.d.ts)。

## 為什麼用目錄清單判斷缺件

本例只使用清單項目的 `name` 和 `kind`。成功取得且整份格式有效的清單後，才對照三個約定名稱：

1. 名稱完全相同，顯示路徑存在。
2. 只有大小寫不同，顯示無法檢查，請使用者核對名稱。
3. 沒有同名或大小寫候選，才顯示缺少。

清單讀取失敗不當成空陣列，不靠錯誤訊息中的文字猜缺檔。這是一份單次查詢快照，不是即時監看，也不是內容品質判斷。同名資料夾或符號連結的名稱存在，不表示它的內容或目標可讀。

## 指令與畫面

指令參數由範例程式解析，不當成 shell 指令執行；Windows 反斜線保留原樣。相對路徑、UNC 網路位置與裝置路徑不在範例範圍。

面板以固定 ID 開啟，繪圖時核對自己的 `requestId`，使用 `Box`、`Text`、`Button` 建立內容。繪圖只讀保存的狀態；真正查詢發生在開啟指令或按下重新檢查時。晚到的舊查詢不應覆蓋後來選定的新目錄。

`$.ui.open` 的回傳語意在查核時的指南與固定型別表述不同。本例只等待呼叫完成，不讀取其回傳值，也不以回傳值推論畫面已顯示；需要更多面板能力時，請再核對執行版本的型別。

## 模組結構與能力

依 [建立指南](https://code.claude.com/docs/en/plugins/mods/create)，事件名稱與 API 呼叫明寫在入口檔，使用靜態相對匯入。主機 API 保留於 `register.mjs`；匯入的純邏輯函式只接收資料，不接收 `$`。

程式不匯入 Node 或第三方套件，不使用動態匯入、模型、網路或程序 API。這份能力清單是對本例原始碼的描述，不是對整個執行環境的安全保證；模組以使用者權限執行，詳見 [官方安全說明](https://code.claude.com/docs/en/plugins/security)。
