# Claude Code Mods：交稿檢查完整範例

這是原 Mods 影片的教學重製版。從一份讀書會交稿情境開始，帶觀眾找出缺少的封面需求、補入材料、重新檢查，再練習空白檔、錯名與內容驗收。

## 開始跟做

- [Windows 跟做教材](materials/README.md)：完整程式、精確路徑、載入指令、缺件到補件及排錯。
- [完整提示與延伸練習](materials/EXERCISES.md)：可複製需求、日期修改與課程交付的答案。
- [旁白與逐幕教案](script.md)。

`materials/delivery-practice` 起初只有文章與資料依據；封面需求保留在 `materials/delivery-fixtures`，練習時再補。課程練習同樣把參考答案留在 `lesson-fixtures`。完整 Mod 放在 `materials/delivery-check`，需要連同 `.claude-plugin` 一起取得。

## 示範的依據

站主在原生 Claude Code 的「交稿檢查 v2」面板確認了缺件、補件及按鈕刷新。本片使用教學卡片整理實測結果，並附可重做材料；沒有把文字回報冒充操作錄影。空白與錯名是附答案的跟做練習。檔名存在不代表內容已審閱，課程範例也沒有宣稱附上另一個已完成的 Mod。
