# S02〈草船借箭，其實不是諸葛亮？〉史料底稿

## 依故事順序能說的事

| # | 原文與位置 | 可用主張 | 邊界 |
| --- | --- | --- | --- |
| R01 | 《三國志》〈吳主傳〉本傳，第 2506 行前：「十六年權徙治秣陵，明年城石頭……聞曹公將來侵，作濡須塢」 | 孫權在曹軍到來前已有濡須防線。 | 不畫能識別規模、地形的確定工程重建。 |
| R02 | 本傳第 2506 行：「十八年正月曹公攻濡須，權與相拒月餘……乃退」；《通鑑》第 5745–5746 行標公元 213 年。 | 事件放在 213 年濡須，不是赤壁之戰；兩軍相持一個多月，曹操最後退去。 | 本傳**沒有**轉船借箭的具體情節。 |
| R03 | 同一裴注先引《吳歷》：「曹公出濡須，作油船，夜渡洲上。權以水軍圍取……權數挑戰，公堅守不出。權乃自來，乘輕船……」 | 《吳歷》另記先前一次夜渡交鋒；孫權後來乘輕船去觀察曹營、曹操識破來意。 | 夜渡交鋒不寫未核精確人數／傷亡，不畫血；「觀察曹營」是引文敘述，不代表後人知道孫權的內心。 |
| R04 | 《吳歷》：「勑軍中皆精嚴，弓弩不得妄發。權行五六里，迴還作鼓吹」 | 《吳歷》明寫曹操叫弓弩**不要亂射**，孫權見完隊列折返。 | 《吳歷》轉錄局部地名有異字；不必口播五六里或細地名。 |
| R05 | 《吳歷》：「生子當如孫仲謀」；孫權書「春水方生，公宜速去」，另紙「足下不死，孤不得安」；曹操答「孫權不欺孤，乃徹軍還」 | 這份版本的軍容觀察、曹操稱讚、孫權的信及另紙、撤軍。 | 引語依一部引書；不把它演成可確證的現場對話，旁白將後句白話化。 |
| R06 | 同一裴注轉引《魏略》：「權乘大船來觀軍，公使弓弩亂發」 | 《魏略》版本換成**大船**，且曹操下令亂發弓弩。 | 與《吳歷》的**輕船、禁亂射**相衝；不能當成同一趟船先後兩階段。 |
| R07 | 《魏略》：「箭著其船，船偏重將覆，權因迴船，復以一面受箭，箭均船平，乃還」 | 《魏略》的核心是船偏重、將覆；孫權轉船讓另一側受箭，平衡後返回。 | 原文沒有箭數、草束、濃霧、三日期限，也沒說孫權是預先求箭。圖像只能畫成《魏略》版本的插畫。 |
| R08 | 《資治通鑑》建安十八年正月只寫軍容整肅、曹操稱讚、通信後撤退。 | 後世編年史對同段的取捨更接近《吳歷》，沒有《魏略》的船身受箭情節。 | 「不寫」不足以證明箭沒有發生；也不足以裁決兩引書孰真。 |
| R09 | 《三國演義》第 46 回，周瑜想藉造箭除掉諸葛亮，要他監造十萬枝箭；原問十日，諸葛亮提出三日並立軍令狀。 | 小說的問題是死期逼近，諸葛亮主動設計交差。 | 這是小說戲劇衝突，不是可套到周瑜、諸葛亮身上的史實。 |
| R10 | 第 46 回：諸葛亮請魯肅借二十隻船、綁兩側草束，並交代別告訴周瑜；前兩日未動，第三日四更，大霧中與魯肅北上，船用長索相連、擂鼓呐喊。 | 小說用二十隻綁草的船與霧，讓曹軍向看不清的船放箭；魯肅同行並替他保密。 | 船、人、霧皆是小說細節；畫面若出現必在旁白或說明標明小說。 |
| R11 | 第 46 回：船先頭西尾東，再吊回頭東尾西，兩邊草束收箭，每船約五六千，交十萬餘枝。 | 小說裡轉船是為**兩側草束收箭**，回營完成周瑜的任務。 | 《魏略》轉船是救偏重的大船；目的不同。十萬多是小說敘事數字，非經核實的軍需記錄。 |
| R12 | R03–R11 的直接比對 | 兩段共有孫／諸葛臨曹營、曹軍射箭、轉船受箭的意象；人、時、地、目的與道具均不同。 | 可以說「相似」「小說把相似畫面寫成另一個故事」。**不能**說已證實羅貫中直接改寫《魏略》，更不能把《魏略》片段擴寫成完整「草船借箭」史實。 |
| R13 | 《三國志》〈吳主傳〉本傳第 2506 行前「十三年……遇於赤壁」，同篇「十八年正月曹公攻濡須」；《通鑑》明標 213 年。 | 赤壁在建安十三年即 208 年；濡須記於建安十八年即 213 年，相距五年。 | 《演義》的箭船**位於小說的赤壁戰前敘事**；不由此推出真實諸葛亮曾在赤壁借箭。 |

## 編輯判斷

片名保留反問：**「草船借箭，其實不是諸葛亮？」**。答案須準確說成「《魏略》留下孫權轉船受箭的相似片段；但裴注同時留下不射箭的《吳歷》版本。小說的三日十萬箭仍是小說。」主角是觀眾逐步看清的**一艘船與兩種記錄**，而不是假裝能判決二世紀那天的每個動作。

不採用：題庫 finding 的「小說把這件事移到赤壁、換成諸葛亮」直述；「正史證實孫權草船借箭」；「《資治通鑑》否定受箭」；「孫權讓箭射進草束」；沒有來源的箭數／船型、船艙對話、江面霧與當事人心理。
