# 《種田娶妻打天下》第 55 集〈鎖起來〉

## 故事前提

第 54 集收在河灘的火堆旁：秦霜抹掉眼淚，指著許硯眼前的空氣：「你常對著那裡笑。那裡有什麼？」阿令也停下撥火，轉過頭來等他回答。第 55 集從他的回答開始：他看著火，「那裡有我想要的。」「一個家。」（細綱的 hook；他沒說出系統，但這是真話——第二季第 70 集系統的「說謊扣分」從這種地方來。）火堆另一邊的阿令手停住，系統：阿令好感六十一。秦霜嘟囔一句「這算什麼答案……」，靠在他肩上睡著了。

系統接著跳出：「三位妻子好感，」「全數突破六十。」「解鎖大獎。」一道比火光還亮的金光打在他臉上（細綱的奇觀），火堆另一邊的阿令瞇起眼看他對著空氣瞇眼：「大獎：火藥配方。」許硯低聲：「火藥……」膝上的手握成拳。他看著河灘遠處被綁成一排的押解：「有了它，」「誰還敢抓我的家人。」再低頭看靠在肩上、在睡夢裡握緊玉佩的秦霜：「可它也能，」「讓很多人死。」（細綱的 conflict。）他把手掌平按在面前的空氣上：「封存。」「連我自己都不打開。」一道淡藍光閃過：「確認封存。」（細綱的 turn。）

阿令隔著火看他很久：「你在想什麼？」（細綱的 mid_hook。）「能殺很多人的東西。」「先鎖著。」她第一次沒有移開視線，嘴角很輕地動了一下（細綱的顏值鏡頭），然後把柴放進火裡：「鎖好。」

回柳溪那天，村口的老柳樹掛滿紅布條，全村敲鑼打鼓。秦霜扛著槍挑眉：「這陣仗，」「比州城還熱鬧。」韓伯舉著竹杖：「咱們柳溪，」「出了個解元！」小禾撲進他懷裡：「哥！」「阿令姊姊說，」「你一定會回來！」又撲向阿令：「阿令姊姊！」阿令頓了一下，把手輕輕放在她頭上。錢員外被村民推到最前面：「解、解元老爺……」許硯笑：「錢老爺，」「說好的磕頭——」錢員外膝蓋一軟：「我、我……」「免了。」「作個揖就好。」錢員外一揖到底，全村叫好（細綱的 satisfaction：face_slap）。唐小棠撥算盤：「這筆帳，」「總算算完了。」

傍晚的院子，阿令在柿子樹下倒茶。小禾問：「哥，」「解元是什麼？」許硯揉她的頭：「就是以後，」「沒人敢欺負妳。」信差撞開破木門：「唐小姐！」「京城急信！」唐小棠拆信唸：「魏少卿……」「帶著一幅畫像，」「進了相府。」她停住，抬眼看阿令。阿令手裡的茶碗晃了一下（細綱的 cliffhanger，reveal，「畫像上畫的是誰？」）。

本集細綱：`season-01.json` 第 55 集（110 秒，第一季第六章第五集，調性甜寵＋感人，lead_arc wins）。satisfaction：level_up（s02–s07）、face_slap（s28–s33）。general_payoffs 全部入鏡：三位妻子好感都過 60（s02、s04）；得到大獎火藥配方、許硯選擇封存（s07、s14–s15）；以解元身分回到柳溪、錢員外當眾作揖（s22–s33）。
