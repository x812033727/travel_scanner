## 測驗證據

- Q1: Which pass should the first traveler open?
  - 正解：The latest pass
  - 重播：A03, A04
  - A03: I received a new seat assignment earlier. Could that affect this pass?
  - A04: It might. Please open the latest boarding pass in the airline app.
- Q2: What is the updated seat?
  - 正解：Sixteen C
  - 重播：A05, A06
  - A05: This one shows seat sixteen C instead of twenty A.
  - A06: That is the updated pass. Let me scan it and confirm your seat.
- Q3: Where should the second traveler wait?
  - 正解：At the desk
  - 重播：B01, B02
  - B01: The scanner says my pass has already been used, but I haven't boarded.
  - B02: Please step to the desk while I check the passenger record.
