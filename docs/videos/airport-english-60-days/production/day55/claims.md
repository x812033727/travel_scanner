## 測驗證據

- Q1: Until when is the first traveler at the hotel?
  - 正解：Thursday morning
  - 重播：A03, A04
  - A03: I'm staying there only until Thursday morning. Does that affect the delivery?
  - A04: Please give us that date and an alternative contact address if your plans change.
- Q2: What does the agent request first in the second conversation?
  - 正解：The report reference number
  - 重播：B01, B02
  - B01: I need to update the phone number on my baggage report.
  - B02: Please give the reference number first so I can find the correct case.
- Q3: What are the last four phone digits?
  - 正解：6281
  - 重播：B04, B05
  - B04: Thank you. Please repeat the last four digits so I can confirm them.
  - B05: They are six, two, eight, one. Could you read the full number back privately?
