## 測驗證據

- Q1: Where should the suitcase go first?
  - 正解：On the scale
  - 重播：A01, A02
  - A01: I'd like to check this suitcase. Where should I put it?
  - A02: Please place it on the scale with the handle facing me.
- Q2: What identifies the checked suitcase?
  - 正解：The baggage receipt
  - 重播：B01, B02
  - B01: Could you explain what this small baggage receipt is for?
  - B02: Keep it until you collect your suitcase. It identifies your checked bag.
- Q3: What should happen to old routing tags?
  - 正解：Remove them
  - 重播：B05, B06
  - B05: My suitcase has an old tag from another trip. Should I remove it?
  - B06: Yes, please remove old routing tags so the current tag is clear.
