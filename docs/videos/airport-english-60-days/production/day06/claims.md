## 測驗證據

- Q1: Where is the available window seat?
  - 正解：Row twenty-eight
  - 重播：A01, A02
  - A01: Could I have a window seat if one is still available?
  - A02: Let me check. There is one near the back in row twenty-eight.
- Q2: What does the second traveler prefer?
  - 正解：An aisle seat
  - 重播：B01, B02
  - B01: I would like an aisle seat, please. I get up quite often.
  - B02: The standard aisle seats are taken, but one extra-legroom seat is available.
- Q3: What does the second traveler finally keep?
  - 正解：The original seat
  - 重播：B05, B06
  - B05: Thank you. I'll keep my current seat if there is a charge.
  - B06: No problem. Your original window seat is still assigned to you.
