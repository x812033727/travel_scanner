## 測驗證據

- Q1: What should the traveler increase?
  - 正解：Screen brightness
  - 重播：A01, A02
  - A01: Good morning. Here are my passport and mobile boarding pass.
  - A02: Thank you. Please turn up the brightness so I can scan the code.
- Q2: How should the family show its passes?
  - 正解：One at a time
  - 重播：A05, A06
  - A05: Do you need to see the boarding pass for my child as well?
  - A06: Yes, please show each passenger's pass separately.
- Q3: Where should the second traveler go?
  - 正解：The assistance desk
  - 重播：B03, B04
  - B03: The code still isn't scanning. What should I do next?
  - B04: Please step to the assistance desk so we can help without blocking the line.
