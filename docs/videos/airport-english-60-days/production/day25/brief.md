# Day 25：航班延誤

狀態：修訂後的製作來源；正式關卡尚未核准。

## 一句話問題

The display says “delayed”; how can you ask for a new departure estimate?

## 目標觀眾

準備自行搭機、需要辨識機場資訊的成人英語初學者。

## 觀眾看完能做到的事

聽清楚目前預估時間，並向服務櫃台詢問受影響的轉機。

## 站主觀點

依使用者指定：每天十分鐘的實用情境聽力；英文常駐、英文預設語音，四語 CC 與教學語音可獨立選擇，角色對話維持英文。不代替即時旅運資訊。

## 格式與長度

官方投影片版型、1080p30、Sulafat。成片總長 600 秒，含實測品牌素材；目前只有文字估計，旁白合成後才確認時長。刻意重聽用於理解、問答連結、跟讀和減少提示，作答停頓用於練習。

## 實際示範或實算

兩段原創對話，三題明確指定 evidence_ids 的聽力題；每題重播必須包含支持答案的對話。

## 章節大綱

方案 A：當集問題 → A 聽懂 → A 跟讀 → B 比較 → B 跟讀 → 三題驗收 → 減少提示重聽 → 回收與下一步。
方案 B：先完成兩段對話辨識，再集中跟讀與作答；仍保留相同問題與例句。
建議 A：先建立一段完整語境，再辨識變化。這是製作建議，未代替正式大綱關卡。
