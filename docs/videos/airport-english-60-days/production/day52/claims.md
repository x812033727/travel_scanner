## 測驗證據

- Q1: Where should the traveler go before leaving?
  - 正解：The airline baggage service desk
  - 重播：A01, A02
  - A01: The belt has stopped, and my suitcase hasn't appeared. What should I do?
  - A02: Please go to the airline's baggage service desk before leaving the collection area.
- Q2: What helps staff trace the bag?
  - 正解：The baggage tag number
  - 重播：A03, A04
  - A03: I have my baggage receipt and boarding pass with me.
  - A04: Good. The agent will use the tag number to check the bag's status.
- Q3: What should the traveler keep for updates?
  - 正解：The report reference number
  - 重播：B03, B04
  - B03: How will I check for updates after I leave the airport?
  - B04: Keep the reference number and use the contact method printed on your report.
