## 測驗證據

- Q1: What is the current gate for Paris?
  - 正解：K seventeen
  - 重播：A03, A04
  - A03: Here it is. The printed pass says gate K five.
  - A04: The current display shows K seventeen. Please use the latest gate information.
- Q2: What is the boarding time?
  - 正解：Three ten
  - 重播：A05, A06
  - A05: Has the boarding time changed as well?
  - A06: It is still three ten. Please allow time to reach the new gate.
- Q3: Who can confirm whether the original pass remains valid?
  - 正解：The transfer agent
  - 重播：B05, B06
  - B05: Will my original boarding pass still be valid?
  - B06: The transfer agent can confirm that and issue a replacement if required.
