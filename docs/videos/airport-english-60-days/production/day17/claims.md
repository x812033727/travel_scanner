## 測驗證據

- Q1: Which corridor should the first traveler take?
  - 正解：The right-hand corridor
  - 重播：A03, A04
  - A03: The corridor splits ahead. Which direction should I take?
  - A04: Take the right-hand corridor. The gate numbers increase in that direction.
- Q2: Does the traveler need to change levels?
  - 正解：No
  - 重播：A05, A06
  - A05: Is gate B twenty-six on this same level?
  - A06: Yes, stay on this level. You don't need the stairs or the train.
- Q3: What should the second traveler do?
  - 正解：Turn around
  - 重播：B03, B04
  - B03: I'm looking for B twenty-six, but I just passed B thirty.
  - B04: Then turn around. Your gate is back along this corridor on the left.
