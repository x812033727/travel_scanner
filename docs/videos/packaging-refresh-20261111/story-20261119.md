# 品牌故事舊集改標題（2026-11-19）

- 日期：2026-11-19。規則：本資料夾 [README.md](README.md)（§二、§四、§五、〈標題檢查〉、〈譯名〉）、[`.agents/skills/brand-story/SKILL.md`](../../../.agents/skills/brand-story/SKILL.md) §標題與縮圖；公式照黑猫研究院：大家認得的名字放前 6 字、一個利害或意外的字、一個數字或年份、只有一個問號、後綴前最多 30 字、利害字或數字落在前 18 字、不寫平靜的閱讀題、不破梗、不重用縮圖大字。
- 每個 zh-TW 新標題都跑過 `tools/video/core/narrative.mjs` `titleProblems`，結果都是 `[]`；標題裡的每個數字、年份、名字都出自該集 `video.json` 的旁白或 claims／verify／source 檔（「為什麼」欄註明出處）。
- 八語標題照同一套公式另寫，不逐字翻，結尾是〈譯名〉的定版系列後綴；每一條加上 `CAPTION_TAGS` 的完整字幕標記後都在 YouTube 100 字元內（`captionedTitle` 實測，沒有一條要退到短標記 `｜CC`）。
- **怎麼換**：站主在 Studio 換，或在站主於對話裡明確同意後，在主機跑 `python -m app.cli video-youtube-caption-titles --set-title <VIDEO_ID> <LANGUAGE> <TITLE> --apply`（每支 50 配額單位；不加 `--apply` 只報告）。同一支影片兩次改動之間隔 14 天；Studio 的「測試與比較」A/B 測試還在跑時不要改標題。
- 這份只列標題；縮圖不動（`thumbnail` 文字在 `visualHash` 裡，見 README §三）。`video.json`、i18n 檔都沒有改。
- **品牌故事的後綴**：zh-TW 的 `video.json` 標題本來就帶「｜品牌故事」。上架包由 `tools/video/core/metadata.mjs` `captionedTitle(..., { story: true })` 去掉再補一次（`STORY_TAGS`），所以帶不帶都一樣；但主機的 `--set-title`（`apps/api/app/video_youtube/retitle.py`）呼叫 `captioned()` 時**沒有**傳 `story=True`，不會自動補品牌故事後綴。所以下表八語標題都已經寫上 `STORY_TAGS` 的後綴，原樣貼上即可。repo 裡這 15 支都沒有 `i18n/` 資料夾，舊的八語標題只在站上。
