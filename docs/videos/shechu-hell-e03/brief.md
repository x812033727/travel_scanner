# 社畜地獄 EP3〈主管巡視〉

## 故事前提

阿金腳翹在桌上射紙飛機偷懶；遠處傳來項圈鈴鐺聲，他耳朵一豎、彈起來瘋狂打字。鈴鐺聲的來源是一隻掛著鈴鐺的發條玩具老鼠，慢慢滾過走道。阿金鬆一口氣、腳又翹回桌上——一片陰影罩下來。隔板上方，項圈上沒有鈴鐺的喵總正低頭看著他，面無表情地把隔板上的釘書機推下去。

## 角色

- 阿金（ajin）、喵總（miaozong）：同系列定裝照。

## 站主觀點

零台詞；貓的天性：項圈鈴鐺（拿下鈴鐺，才能悄悄巡視）與把東西推下去。

## 格式

- 9:16，約 16 秒；Colab 首格與 H3 片段。

## 大綱

### 選項 A：主管巡視
一行說明：腳翹桌上射紙飛機 → 鈴鐺聲、耳朵一豎 → 瘋狂打字 → 鈴鐺在發條玩具老鼠上 → 腳又翹回去 → 陰影罩下來 → 隔板上沒鈴鐺的喵總推下釘書機。
開場鉤子：上班時間，黃金獵犬腳翹在桌上射紙飛機。
