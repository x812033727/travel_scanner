# X13 Spotify｜敘事盲評的可採性

初稿 A／B 與修訂稿 C 的回饋可用於編修，但審查代理是在繼承上游對話的工作階段啟動，可能先看到前一輪評語。因此，它們**不計入**「兩位未接觸前評者審讀同一凍結稿」的通過門檻。原報告保留供檢查修改脈絡；D 發現同一問題後沒有出具判定，也沒有改檔。

正式門檻須由以 `fork_turns="none"` 啟動的兩位新讀者，各自只讀同版 `drafts/narration.md`、`drafts/shorts.md` 和 `visual-plan.md`，且不讀其他評語。兩份報告均須記錄三檔 SHA-256、給出敘事判定；稿件任何位元變更後，兩份判定與逐句來源審查都必須重做。

第一次真正隔離的盲讀見 `blind-fresh-1.md`、`blind-fresh-2.md`：兩人讀相同 SHA（旁白 `8026acf0…`、Shorts `6466a18c…`、畫面 `559286c5…`），均判 **NO**，共同指出財報事件多於決策主線、第五章口播數字太密、片尾未具體回答開場。這兩份是有效的退修意見，**不批准**後續改寫版。第二位把八分鐘當總片長計算；系列實際規格是約十分鐘、實質正文至少八分鐘，該項時間推算不作定論，仍要配音實測。

第二組隔離盲讀 `blind-fresh-3.md`、`blind-fresh-4.md` 同看旁白 `e9753f33…`、Shorts `a732bb31…`、畫面 `ad17d571…`，各判 **5／7** 與 **4／7**，共同指出口播數字梯及開場回收過慢；後者另指出年表感。那版的逐句來源審查 PASS 見 `script-source-audit-independent.md`，只適用該版凍結 SHA。它們都不批准後來稿。

第三組隔離盲讀 `blind-fresh-5.md`、`blind-fresh-6.md` 同看 v3 旁白 `44b16a99…`、Shorts `a732bb31…`、畫面 `f2471178…`，均判 **6／7，整體 NO**。兩人都認為章三至六仍靠年份／財報欄位串聯，缺乏可由來源支持的單一決策主線；其他六項，包括紙上正文超過八分鐘、結尾直答、兩支獨立 Shorts，均 Yes。這些是凍結 v3 的有效退修意見，紙上時長不等於實際錄音時長。

同版獨立來源審查見 `script-source-audit-v3-independent.md`，綁定 source matrix `cb8d31b6…`、Treatment `029f49e1…` 及上述三份旁白／畫面 SHA，判 **HOLD**。九件 SEC 原件雜湊吻合，但 S9 影片數量是七月二十五日公告的「now available」，不是已證實的六月底值；另有「舊內容」、早年卡片影片觀看、關閉節目數量與排程、季度毛利造成全年營業獲利等過度具體化。任何 v4 修改均須重新審核，不能沿用 v3 盲讀或來源票。

此處的「盲」只指不接觸前評與作者企劃，不代表沒有看待審稿本身。來源真偽與逐句界線由獨立來源審查文件查核。
