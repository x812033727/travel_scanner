# X13 Treatment｜買下播客後，Spotify 又改寫了播客生意

一條主線：Spotify 為取得節目與創作者工具而買公司；2023 年重整播客業務並對部分內容資產認列減損；2024 年首度全年營業獲利時，播客仍是產品的一部分，但「自己製作多少、誰看影片、費用放在哪個業務」正在變。鏡頭跟著一張播客製作桌上的兩份合約、一份內容資產表和兩條業務分類線移動，避免拍成公司通史。

**開場濃縮（結構樣稿，尚非配音稿）**：2019 年 2 月的兩天，Spotify 買了一套讓創作者製作並發行播客的工具，又買下一家製作播客的公司，合計收購對價三億零八百萬歐元。四年後，自己的報表卻寫下播客內容資產減損，還重整播客業務。隔年，它公布第一個全年營業獲利。觀眾先看到沒有具體節目名稱的內容資產減損卡，然後才看到盈餘卡。最後一句提出本集問題：「如果播客這條路不是一路向上，Spotify 究竟改了哪一本帳？」此句後才接正式 5 秒頻道片頭；片頭不算正文。
