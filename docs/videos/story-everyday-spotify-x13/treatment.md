# X13 Treatment v10｜Spotify：關掉節目，真的放棄播客了嗎？

**故事線：疑問型。主角是 Spotify 的播客配置是否退場。** 2019 年兩天買進創作／發行工具和節目製作能力，後來免費播放器背後的廣告業務承受成本壓力。2023 年有部分播客內容資產沖銷和若干節目關閉，這使「是不是放棄播客」成為真的疑問；但同年 7 月公告時平台仍有逾十萬可用影片播客，2025 年又有合格影片創作者方案及 Premium 新觀看體驗。這些先後出現的公開動作支持「縮掉部分內容、改變合作與成本配置，並非全面放棄」，**不證明**某一檔被關節目轉成影片、2020 壓力唯一造成重整、播客單獨賺錢或 2019 兩案回本。

第一章紙上約 45–55 秒：2019-02-14 買 Anchor 創作工具、隔天買 Gimlet 節目製作公司，合計 €308m **收購對價**。匿名錄音鍵與播放器讓觀眾看見買入的兩端；其後三個尚未揭結果的時刻依次出現：免費聽眾按播放而廣告收入格仍空；一份 2023 內容調整紀錄抵達但結果遮住；另一名匿名創作者送出影片，會員端下一步尚未知。這些是不同時刻、不同匿名人物的用途示意，**不是**同一檔真節目或真實內部會議。最後直接問重整是否等於放棄播客。正式 5 秒片頭接在問題之後，開場與片頭不計入正文八分鐘。
