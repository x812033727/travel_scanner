# X05 Meta｜上架與本機試看片交接

本資料夾是「品牌故事」X05 的零付費前製包，接在 X01 Adobe、X02 Domino’s、X03 Netflix 與 X04 Beats 的補充題之後；原 C01–C20 順序不變。`video.json` 應包含繁中逐句旁白、插畫和原生數字卡指示，以及 YouTube 標題、說明、縮圖文案與四份 SEC 原始連結。逐句依據和數字單位見 `source-matrix.md`、`source-notes.md`；原始 HTML 的獨立審查見 `reviews/source-audit.md`。本階段尚無真實配音、圖片、配樂、字幕或影片，不能當成已交付成片。

另有兩支 [Shorts 離線六拍稿](shorts.json)：一支拆開 FY2022／FY2023 裁員公告與年底名冊的時間差，一支辨別 FY2025 AI 眼鏡銷售、RL 收入與整欄營業虧損。兩支只重用長片規劃的無字鏡頭，不另買圖片；逐支來源、估時及未完成的關鍵影格驗證見 [Shorts 交接](shorts-handoff.md)。正式短片不套用長片的 5 秒片頭或 21 秒片尾，相關影片連結與上架狀態仍要等來源長片確實存在、審過及公開後再設定。

最終逐句 [來源審查](reviews/source-review-v9.md)、兩份獨立 [盲讀 O](reviews/blind-o-v9-delta.md)／[盲讀 P](reviews/blind-p-v9-delta.md) 均綁定本稿並通過；[手動草稿發音釘選收據](reviews/lexicon-bootstrap.json)由獨立審閱者簽核。本機零付費釘選交易 `5b35f7fc-d370-4c39-a86a-19bb5bee11bf` 已在 repo 外的媒體工作區完成，後續正式工人仍須核對自己的同版發音鏈。釘選後的 `tts --dry-run` 列出 84 句待合成，尚無音檔；`keyframes --dry-run --takes 3` 列出 66 張待繪插圖。配樂乾跑要等真實 TTS 時間軸，不能先報可生成。

規格是 30–60 秒濃縮開場、其後 5 秒片頭、實測口播正文至少 8 分鐘、21 秒片尾；計畫字數或 lint 估值不能代替 TTS 時間軸，**片頭片尾不能補正文最低片長**。本前製稿的正文 8 分鐘門檻尚未由 Sulafat 成音時間軸驗證；若實測不足，須補有一手來源的新事件並重做敘事與來源審查，不能只放慢語速。本機無正式頻道片頭片尾及 YouTube Studio 連線；若後續先做試看片，片頭、片尾必須在畫面上明標「概念」，正式檔取得後等長替換並重做字幕與音畫 QA。繁中 SRT／WebVTT 獨立交付，不燒入影像。

概念動畫動作稿：濃縮開場在一張留白分部報表上停住，5 秒片頭讓兩條抽象帳本欄線翻頁，落到頻道名稱與「品牌故事」，畫面註明本機概念。21 秒片尾延續同一張紙；前 4 秒收束，最後 17 秒保留左右兩個影片安全區及訂閱元素版位。框線本身不可點擊。正式私人上傳後，須在 YouTube Studio 分別設置「最符合觀眾喜好」、「最新上傳」及訂閱元素，實際點擊驗證，再填影片 ID 和公開網址。未做這步前不可宣稱連結完成。
