## 寫稿當天的實測

**指令**（金鑰只從環境變數讀，不會被印出或寫進檔案；後台卡片上的金鑰是加密存放的，要由站主從 TypeSafe 主控台另外提供）：

```bash
cd docs/videos/ai-term-system-one-model/demo
python3 demo_live_jev.py --date-probe          # 先看計畫，不連線
JEV_API_KEY=... python3 demo_live_jev.py --live --date-probe --out live-YYYYMMDD.json
```

**開跑前登記的失敗條件**，任何一條成立都照實講：

- 「日期怎麼寫」選的不是「只說相對的日子」，或選項倒過來那題的答案不一樣。
- 「人數是估計的嗎」低於 0.5。
- 壞題（只給兩個日期）的信心值 ≥ 0.5，也就是二選一時第一名至少 75%。
- 修正版（加上「信裡沒寫」）沒有選「信裡沒寫」。
- 中文版和英文版落在 0.5 的兩側。
- 兩次日期探針落在 0.5 的兩側，或任何一次低於 0.5。

**壞題的兩種讀法**，跑出哪一種就照實講：

- 把握高：`big` 寫「它很有把握地挑了一個」。
- 大約各一半：`big` 寫「兩個日期各一半左右」。

兩種都歸類為指令錯誤：選項裡少了「信裡沒寫」。依據是 "`jev-1.13` answers the question you wrote, not the one you meant."（https://docs.typesafe.ai/model-jaggedness/jev-1.13 ）。修正版那題就是證據。
