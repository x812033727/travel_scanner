## 盲讀（先於來源）

六章因果主線可辨：德國緩震鞋底 → 英國取得製造權和改款 → 1460 出廠 → 工作靴 → 青年文化採用 → 多重甚至對立的意思。第一章有具體場景和主問題，第二至五章有章末懸念；主詞大致清楚。77 句共 2,290 個旁白字元，不以字元推定 480 秒。

盲讀 HOLD：c070603–c070604 突然引入 1981 年照片，緊接著又說它不證明照片人物穿 1460，聽感是繞到另一件不連著靴子的證物，削弱結尾的因果。建議從口播移到背景查核，或改用能直接說明不同穿著者／穿法的材料。c070405「在腳上待很久」不自然，建議「得久站、久走」。c070310「目前沒有那張首筆零售收據」像查核報告且證據範圍過大，建議「出廠日期有記錄，首次賣出的日子仍無法確定」。上述盲讀意見在看來源前已傳給協調者。

## 本輪直接核對的來源及界線

- B1：[公司沿革](https://www.drmartensplc.com/about-us/our-brand/) Heritage 段，直接可讀。支持公司多年後自述的 1945、1947、1959、1960、早期 £2 工作靴及後來青年文化；不是當年合約、帳簿或街頭照片。
- B3：[品牌 1460 檔案](https://www.drmartens.com/uk/en_gb/archive/1460)，直接可讀。只明確說 1960-04-01 第一雙下線、下一週去展會接夏季訂單及設計特徵；沒有首次零售日期。
- B2：[品牌 History](https://www.drmartens.com/ca/en_CA/history)，本輪直接開頁兩次逾時；搜尋索引可讀到郵差／工廠工作者及個人表達段，故不把本輪搜尋結果當作已直讀原頁。相同對象另由 M1 直接證實；品牌對郵差的說法亦見可直讀的 [Posties 檔案](https://www.drmartens.com/ca/en_ca/archive/posties)。
- B4：[公司現行業務頁](https://www.drmartensplc.com/our-business/) 直接可讀，稱產品是個人表達象徵；只能證今天公司如何敘事。
- M1：[London Museum 1995 格紋靴館藏](https://www.londonmuseum.org.uk/collections/v/object-91428/boot-ankle-boot/) 直接可讀。館方後來的說明提早期郵差、警察與工廠工作者、晚 1960 年代 skinhead 採用及 1995 時尚靴；1995 物件不是 1960 年代現場原件，也未指每位青年穿的型號都是 1460。
- A1：[Arthur Crucq 2021 研究](https://www.pismowidok.org/en/archive/2021/31-visuality-of-social-classes/double-class-on-the-popularization-of-dr.-martens) 直接可讀。工作階級風格、加勒比音樂影響、晚 1970 年代 punk、部分 skinheads 後來走向極右、荷蘭作者回憶都有段落支持；屬研究分析及部分本人回憶，沒有原始零售帳或第一位穿著者。
- V2：[V&A Gavin Watson 館藏脈絡](https://www.vam.ac.uk/articles/staying-power-photographs-of-black-british-experience) 直接可讀。1981 年 Micklefield 照片及 Wycombe Skins 的多族裔 ska 脈絡可核；完全沒說照片人物穿 Dr. Martens。照片是 1981 原件，文字是後來策展說明。
- B1、B2、B3、B4 都屬同一品牌利益方，不能當多個獨立歷史證人；M1、A1、V2 提供獨立的後來描述或研究，不能升格為 1945–1980 年代的完整原件。

## 分鏡審查

本版 77 行與旁白 ID 一對一；63 shot、14 stats，按鏡數為 81.8% shot，最長連續 stats 為 2。這只證鏡數，不證實際時間占比；TTS 後須量 ≥70%。共通契約指定 MiniMax image-01 與精確 look: {"preset":"cute-mystery"}，後製文字不交模型，照片不當插圖原件重建；這些目前是草案，未有實際 video.json 或生成圖可驗。

- c070101、c070505、c070608：一鏡左右分景／四個近景／三個小場景，與「單一焦點、一個動作」及 image-01 易讀提示詞衝突。改成一張主畫面一個動作，或在同一旁白 ID 下明列後期剪接但各張圖單獨提示、計價和檢查。
- c070310、c070507：空白收據夾／購物紀錄抽屜易像「史料檔案已查遍」的視覺證明；用抽象出廠—展會—首賣未知節點或時間線卡，不造檔案庫場景。
- c070603–c070604：畫面已謹慎不嵌 V&A 原照、不宣稱穿靴；若口播移除，這兩鏡也要同步改／刪。
- c070301：一張 stats 列八孔、黃車線、刻槽底三個資訊，和「卡片只放一項」的契約略衝突；可把設計特徵放回插畫／後製單項分層，避免三項擠一張。
