## 直接來源與強度

- **B2**：[Dr. Martens History](https://www.drmartens.com/ca/en_CA/history)：1901 年 Griggs 工作靴、1945–47 德國團隊與主要年長女性顧客、1959 海外雜誌廣告、Bill Griggs 於鞋業雜誌看見廣告、英國改鞋跟／鞋面／車線／鞋底及黑黃拉環、早期郵差與工廠工作者、某時曾當園藝鞋販售、八〇年代小尺碼男款八孔靴的花卉客製。這些是**品牌事後回顧**，沒有當期廣告、購買收據、第一位穿著者或園藝鞋確切年份／型號。
- **B3**：[1460 品牌產品檔案](https://www.drmartens.com/uk/en_gb/archive/1460)：明寫 **1960-04-01 首雙下線**、**下一週**帶到鞋業展會且**準備接夏季生產訂單**，及八孔、黃車線、刻槽底、黑黃拉環。檔案沒有首次零售日期，也沒有證明展會實際成交。
- **M1**：[London Museum 物件 `95.525/6a-b`](https://www.londonmuseum.org.uk/collections/v/object-91428/boot-ankle-boot/)：館方後來概述早期郵差／警察／工廠工作者、晚六〇年代 skinhead 採用；物件資料列 **1995 年**、紫黃格紋、製作者 Dr Martens。這件 1995 靴既不是 1960 的 1460 樣靴，也不是八〇年代某女孩客製靴；藏品數位圖片另列授權。
- **A1**：[Arthur Crucq，〈Double “Class”〉，《Widok》31（2021）](https://www.pismowidok.org/en/archive/2021/31-visuality-of-social-classes/double-class-on-the-popularization-of-dr.-martens)：本審查會話先前曾直接讀到文章全文；本輪重新直開 HTML 逾時、PDF 入口停在驗證頁，同日原網址搜尋索引仍可讀到對應全文段落。研究記述工人階級服飾、褲腳、吊帶、拋亮靴面，mods 與西印度移民傳入的 ska／rocksteady／rude-boy 風格、晚七〇年代龐克、不同政治取向、作者八〇年代末荷蘭回憶、耐穿及相對經濟的**可能**吸引力、九〇年代混搭與品牌後來行銷取捨。這是含二手文獻與個人經驗的研究詮釋，不是同期英國銷售檔、全體穿著者訪談或品牌 1960 會議紀錄。
- **B4/B5**：[公司 What we do](https://www.drmartensplc.com/our-business/what-we-do/) 與 [Our business](https://www.drmartensplc.com/our-business/)：今天的 1460 核心款與個人表達定位；只證**現行公司自述**。**B1** [Our brand](https://www.drmartensplc.com/about-us/our-brand/) 這次網頁閱讀逾時；先前以直接 HTTP 讀到 1959 英國製造權，與 B2/B3 同屬公司，對新改句不當獨立證人。
- **V2**：[V&A，Gavin Watson／Wycombe Skins](https://www.vam.ac.uk/articles/staying-power-photographs-of-black-british-experience)：1981 年多族裔、愛 ska 的具體群體及其後政治脈絡；**頁面未說照片中任何人穿 Dr. Martens**。V2 只作背景交叉核對，不為靴款採用、早期買家、畫面人物或鞋型背書。V1 不能直接取回，不是本次放行依據。
