## 第二章｜襪子裡的原型（O01–O11）

- **O01** 地區品牌回顧說，Michael Eidson 當時是緊急醫療技術員，也是一位騎車的人。〔S2／M02〕
- **O02** 那篇回顧把場景放在一場自行車活動；另一份騎車飲水專利則指出，騎乘中取瓶飲水有操作難題。〔S2、S4／M01、M02〕
- **O03** 車架能固定瓶子，但要喝時仍得把它拿起；Eidson 的臨時解法，把水放到哪裡？〔S2、S4／M01、M02；E；鉤 M〕
- **O04** 他在品牌故事裡把水裝入點滴袋，再把那只袋子塞進襪子。〔S2／M02〕
- **O05** 襪子連同水袋被放進車衣背後，重量和水一起移到身上；水又該從哪裡喝？〔S2／M02；E；鉤 K〕
- **O06** 接著，一根管子越過肩膀，把水的出口帶到靠近嘴邊的位置。〔S2／M02；回收鉤 A〕
- **O07** 管子的末端不是複雜機關；品牌回顧說，他用衣夾把出口夾住。〔S2／M02〕
- **O09** 而衣夾解決的，是水不該一直從管口流出的問題。〔S2／M02；E；回收鉤 C〕
- **O10** 品牌回顧稱比賽在一九八九年；較晚專利稱背包與水瓶於一九八八年結合，未證是同一事件。〔S2、S5／M03〕
- **O11** 這份回顧講的是一次騎乘的辦法；它哪一步才變成能擺上商品架的東西？〔S2、S3／M02、M05；E；鉤 E〕

## 第三章｜一只襪子成了商品（I01–I10）

- **I01** CamelBak 自己和後來的母公司，都把公司的成立年份寫成 1989 年。〔S1、S3／M04〕
- **I03** 母公司 2014 年回看這段歷史，把 ThermoBak 稱為 CamelBak 的第一款商品。〔S3／M05〕
- **I05** 然而，這份回顧沒有列出首批商品每個零件，也沒有給出它第一天上架的日期；誰開始跟著它走？〔S3／M05；鉤 L〕
- **I06** 所以不能把今天看到的背包、水囊和管口，整套倒貼到那隻襪子上。〔S2、S3／M02、M05；E〕
- **I07** 母公司記下的另一件事更關鍵：九〇年代初，第一批跟著這項產品走的，是山地車騎士。〔S3／M08〕
- **I08** 它一開始仍圍著騎車的難題轉，卻從一人的臨時用品，變成能讓一群騎士認得的商品。〔S2、S3／M02、M05、M08；E〕
- **I09** 背上有水，嘴邊卻不能一直流水；商品越要給別人用，出水這一步就越值得追問。〔S2、S3、S4／M02、M06；E〕
- **I10** 到底要怎樣，才能讓管口平常關著，想喝時才打開？〔S4／M06；鉤 F〕

## 第四章｜管口還有一道題（E01–E15）

- **E01** 這裡有另一份原件：發明人 Roger Fawcett 在 1990 年申請了一件飲水閥專利。〔S4／M06〕
- **E02** 申請文件從同一個騎車難題出發：水可以帶著走，手卻不方便一直去拿瓶。〔S4／M01、M06〕
- **E03** Fawcett 談的是管子末端怎麼控制出水，和 Eidson 的襪中水袋是不同文件裡的兩個角色。〔S2、S4／M02、M06、M11；E〕
- **E04** 這件專利描述的軟閥，出口有一道平時閉合的開口。〔S4／M06〕
- **E05** 它接在水管末端；沒有受到咬合壓力時，材料的彈性讓開口維持關閉，那怎麼打開？〔S4／M06；鉤 N〕
- **E06** 咬住閥口使它變形，那道開口才打開，水才有路流出。〔S4／M06；回收鉤 F〕
- **E07** 鬆開後，它回到關閉狀態；這正對應原型衣夾一直在處理的管口問題。〔S2、S4／M02、M06；E〕
- **E08** 但專利是一種技術方案的記錄，不是 ThermoBak 首批零件清單。〔S3、S4／M05、M06、M11〕
- **E10** 申請在 1990 年，授權在 1992 年；兩個都不是商品上市日，較晚的產品文件又怎麼描述管口？〔S3、S4／M06、M09；鉤 O〕
- **E11** 母公司在 2014 年描述當時的水袋系統時，才明列水囊、連接管和自封式咬合口。〔S3／M09〕
- **E13** 它不能反過來證明，最初每個 ThermoBak 都裝了 Fawcett 專利裡那一種閥。〔S3、S4／M05、M06、M11〕
- **E14** 就算水袋、管口都說得通，商品也不會自己從工作桌走到騎士眼前。〔S2、S3／M07、M08；E〕
- **E15** 品牌回顧裡，下一個把它搬到人群面前的人是 Jeff Wemmer；他第一站賣給誰？〔S2／M07；鉤 G〕

## 第五章｜從賽場走到單車店（T01–T12）

- **T01** 依 CamelBak 地區品牌故事，Wemmer 本身是競技騎士，先把這種商品帶到比賽場合販賣。〔S2／M07〕
- **T02** 這不是說他發明了水袋；他做的，是讓商品離開原本的小圈子，出現在其他騎士面前。〔S2／M07；E〕
- **T03** 品牌回顧接著給了一個具體年份：1993 年，他騎機車去拜訪單車店，這條路走到哪裡？〔S2／M07；鉤 P〕
- **T04** 回顧把路線寫成從佛羅里達到加州，但沒有留下每一家店的對話或成交數。〔S2／M07〕
- **T05** 我們能跟著的動作，是把商品從賽場帶到店裡，讓原本沒看過它的人有機會遇見。〔S2／M07；E；回收鉤 G〕
- **T06** 這條通路和九〇年代初山地車騎士的追隨者並排看，能看見早期對象仍是騎車族群。〔S2、S3／M07、M08；E〕
- **T07** 兩份回顧沒有證據說巡店單獨造出後來的銷售成績；要走出山地車圈，商品得改哪裡？〔S2、S3／M07、M08、M11；E；鉤 Q〕
- **T10** 後來的母公司回顧說，水袋包的使用場景已經超出山地車。〔S3／M09〕
- **T11** 騎車以外，步行、跑步、滑雪，甚至軍方用途，也出現在後來的商品描述裡。〔S3／M09〕
- **T12** 但如果使用情境越來越多，所有人都該把水背在身上嗎？〔S3／M09；鉤 H〕

## 第六章｜背包以外，又有一只瓶子（N01–N22）

- **N01** 母公司 2014 年的資料，先展示一件事：水袋包沒有只做成同一個騎車背包。〔S3／M09〕
- **N02** 山地車有輕便款，較長的越野騎乘又有較耐用、容量安排不同的款式。〔S3／M09〕
- **N03** 到了登山與步行，後背板的襯墊和空氣流通，變成文件裡提到的設計重點。〔S3／M09〕
- **N04** 滑雪款加上固定頭盔、板子和鏟子的配置；到了跑步，水又該放在哪裡？〔S3／M09；鉤 R〕
- **N05** 跑步用品還包括腰包，有的以放置多只水瓶為設計；答案已不只是一種背包。〔S3／M09；回收鉤 H〕
- **N07** 另一個轉彎在 2006 年：母公司說，CamelBak 進入可重複使用的水瓶類。〔S3／M09〕
- **N08** 最早被它點名的水瓶產品是 Better Bottle；這是新產品類別，不是襪中水袋的另一個名字。〔S2、S3／M02、M09；E〕
- **N09** 那個起點曾想讓騎士不用伸手拿瓶，現在公司卻決定做瓶，矛盾究竟在哪裡？〔S2、S3／M02、M09；鉤 I〕
- **N10** 公司的水袋包回答的是「活動中怎樣從身上取水」，瓶類則把焦點帶向不同使用者的手邊。〔S3／M09；E〕
- **N11** 母公司說，Better Bottle 之後，又推出供日常使用、騎車和兒童等情境的瓶款。〔S3／M09〕
- **N12** 於是「不用拿車架上的瓶」不再是公司唯一的問題；有些場景，拿起瓶子反而就是使用方式。〔S2、S3／M02、M09；E；回收鉤 I〕
- **N13** 公司說 2006 年進入瓶類，讓產品碰到更廣的消費者與通路；店面後來長成什麼樣？〔S3／M13；鉤 S〕
- **N14** 到 2014 年報表，零售類別已列有單車、戶外、家用品、自然食品等不同店面。〔S3／M13〕
- **N15** 但這張名單沒有逐家註明，哪種店是瓶類第一次帶進來，不能替它編一條巡店路線。〔S3／M13〕
- **N16** 真正把故事翻回來的，是 2014 年那一年的產品比例，而且必須看清楚分母。〔S3／M13；鉤 J〕
- **N17** 母公司披露：在 **CamelBak 2014 年毛銷售額** 裡，瓶類約占百分之五十。〔S3／M13〕
- **N18** 同一分母、同一年度，水袋背包約占百分之三十七；兩者不是現在的市占率。〔S3／M13；回收鉤 J〕
- **N19** 這也不表示咬合閥專利或 1993 年跑店，單獨造成了那個比例。〔S2、S3、S4／M06、M07、M13〕
- **N20** 回到那只襪子：最初移動的是水的位置；後來改變的，是誰在什麼場合用哪一種容器。〔S2、S3／M02、M09、M13；E；回收鉤 B、D〕
- **N21** 你用過哪件先為一種場合發明、後來又長出另一種版本的日用品？〔S2、S3／M09；觀眾提問〕
- **N22** 如果你喜歡這種從一件小物追到整門生意的故事，歡迎訂閱，我們下次再一起追問。〔S2、S3／M11；編輯邀請〕
