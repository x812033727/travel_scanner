# C14 CamelBak｜為了不拿水瓶，為何後來又推出水瓶？

本集屬「日用品的意外轉身」。站主已核准 70 句繁中旁白與 70 鏡 v8 方向；本機器專案只作非付費轉檔，不改受核准 SHA 綁定的原稿或分鏡。C14 的整支 US$25 試片報價仍是未核准提案。

## 問題

騎車不想騰手拿瓶，為何從襪中水袋起步的 CamelBak 後來又推出水瓶？

## 一句答案

依品牌多年後回顧，原型把水背到身上，商品經競技騎士與單車店接觸更多人；2006 年水瓶產品另為不同使用場景進入市場。母公司 2014 年報把瓶類和背水包都列為當年的產品線，瓶類約占 CamelBak 當年毛銷售額一半，但這不證某個原型、專利或銷售員單獨造成比例變化。

## 站主觀點

以「不用拿瓶」開題，沿水袋原型、商品、賣到單車店、嘴邊出口的設計文件與後來的水瓶走一條時間線；結尾回到不同場景要用不同容器。1998 口器專利、2005 水瓶申請、2006 展會實物各守文件身分，不能畫成同一件量產零件。
