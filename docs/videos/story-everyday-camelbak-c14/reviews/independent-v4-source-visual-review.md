## HOLD 的旁白與畫面修改

1. **故事聲音（O08、I03、I10、E06、E10、T04、T10、N08、N12、N14）**：這些句子至少一部分在講來源缺口、查核方法或「我們的解讀」，使故事頻繁停下來解說審稿。保留必需的品牌／母公司歸屬與專利提案界線，將其餘查核語放回 `script-source-notes.md`；用下個有來源的**事件或物件變化**承接。I10 還須依上表修正事實。E07–E10 的軍方寄送可作背水用途擴展，但它與後面水瓶決策沒有因果證據，E11 的轉場不可暗示捐贈導致瓶類。
2. **產品線連續性（I11–E06、T03–T09、N09–N12）**：前兩件專利是設計文件，2006 年二月是另一份現場實物報導，2014 年報是回顧產品類別。可說瓶與背包共用「咬合閥設計」這一類別，不能說展場瓶已證實完整裝上 US6070767A 或 US20060226110A1 的所有圖示零件。I11「還得舒服、不能漏」宜明示是後來專利處理的設計目標，不要當作早期騎士已抱怨的歷史後果。
3. **74 鏡逐 ID 文字核對**：`H01–H05 / O01–O09 / I01–I13 / E01–E11 / T01–T18 / N01–N18` 均有 JSON 鏡頭且順序一致。除 **T05 字卡**上表年份問題外，**I03 插圖**的 `early-looking backpack` 像未證實的首款外觀重建，應改為純泛用背包；**N07 插圖**讓瓶子逐漸占更多*實體貨架*，把毛銷售占比具體畫成貨架面積，來源無此證據；**T18／N12 插圖**從單車店貨架移往家用品貨架，易被讀成有記錄的逐店遷移，應改成同時並列的泛用使用情境。其他鏡頭作匿名、無字、無標誌的**概念插圖**可保留作文字方向；圖像未生成，無逐張視覺 PASS。E07–E10 不重建 2003 照片或戰地人物。
