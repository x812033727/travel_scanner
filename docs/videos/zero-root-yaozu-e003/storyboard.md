## 參考圖與連戲

- 參考圖都在 `_series/zero-root-yaozu/refs/`（`docs/videos/series-plans/zero-root-yaozu/production/refs.json`）。胡奶奶的定妝照用 t1（採用的那張，三視圖也是照它畫的）；t2 可當備用的第二張臉參考。孫二只有定妝照、沒有三視圖：s28 他在全景裡逃跑，首格不像就先畫一張他挑貨擔的全身當連戲參考。
- 三張場景圖都是黃昏或傍晚的光，本集全在夜裡：set-changdeng-gate、set-changdeng-village、set-hu-courtyard 只當空間與擺設的參考（牌坊、老槐樹、水井、方桌與長凳的位置），光照 prompt 寫的燈籠與油燈重打。set-hu-courtyard 雞舍前的裂紋陶盆是第 4 集的聚靈盆，s34 入鏡就讓它留在角落，不要畫掉。
- s01 接第 2 集 s36：阿猙藏在背後的斧頭在 s01 拿出來，斧頭的樣子（長柄、舊鐵、鈍口）抄第 2 集 s29 的採用首格；陸拾的扁擔插回罈子繩套（第 2 集 s28 之後他撐地站起，本集不再拿在手上）。
- 道具帳：鈍斧（s01、s02、s06、s07、s11）；三嬸的鐵錘先掛在圍裙腰帶上（s10、s12、s14、s15），s23 抽出、s24 砸地、s26 扛上肩、s28 舉著、s31 掛回去；歸伯的釣竿線末端只有空結（s10、s15、s27、s32、s33）；團團的糖葫蘆（s10、s15、s17、s29）；饅頭在陸拾前襟（s09、s18、s19）→ s37 放上桌 → s38 掰開 → s39 掉出靈石與字條；字條上的墨跡永遠看不清（`no_text` 會扣分，要讀的字之後另外合成）。
- 人群：村口的村民一律寫成虛焦背景，不列角色、不給臉；每鏡列的角色不超過三個（s10、s15 是三人同框的全景，shot_plan 標 B 風險 crowd／cast.three，留著當重新交代空間的鏡頭）。
- 軸線：坡上陸拾在左、阿猙在右（s01–s06、s11）；村口對話陸拾在左、村民（三嬸、團團）在右（s12–s19、s30、s31）；孫二從右邊的路進來，與三嬸、歸伯（左）對峙（s20–s29），所以 s26、s27 的三嬸與歸伯換到左邊；院子裡陸拾在左、奶奶在右（s34–s44）。
- s04 從背後拍陸拾與阿猙，臉看不到：identity 題可能被扣，被扣就改成只把他們寫成畫面下緣的背影、`characters` 留空。
- 提示詞裡陸拾寫作 Lushi（第 1、2 集寫 Lu Shi）：分鏡讀取的 `nameOf` 用角色的 id 或中文名比對，「Lu Shi」讀不到 lushi，畫外子句（`toward Lu Shi off screen left`）的對象就讀不出是誰；寫成 Lushi 就對上。新角色的 id 也照這個規則取成提示詞裡讀得到的一個字：Grandma Hu → grandma、Third Aunt → aunt、Old Gui → gui、Tuantuan → tuantuan、Sun Er → sun（提示詞裡不再單獨出現 sun 這個英文字；sun-tanned 有連字號，比對時不算）。
- shot_plan 的槓桿列了五個可以切素材的同鏡位（s16←s05、s21←s05、s26←s14、s30←s19、s33←s27），每一對的表情與動作都不同，本集不切。
