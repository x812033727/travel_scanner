# 《長燈村：零靈根的我被一村妖祖養大》第 3 集〈一村人等門〉

## 故事前提

第 2 集收在月光下的松林路：大松倒在路上，阿猙把沒有刃的斧頭藏到背後說「剛好。」；陸拾背著裂開的醃菜罈、罈子繩套裡插著短竹扁擔，懷裡揣著雲知意給的布包饅頭。第 3 集從同一條路接下去：阿猙用斧背往路上一截松木輕輕一敲，木頭順著紋路裂成兩半：「力氣，大。」陸拾張嘴要追問，坡下三百盞燈籠同時亮起，從山腳一路連到村口，像一條暖橘色的河。阿猙只說「等你。」陸拾在燈河裡回頭笑了，又想起自己沒選上，摸著懷裡的饅頭想偷偷回家；村口的老槐樹下卻站滿了人，三嬸一嗓子「拾兒回來啦！」他躲到阿猙背後，阿猙一步讓開。他鼓起勇氣要認錯，話還沒說完，三嬸就說「仙門瞎了眼！」歸伯慢吞吞補一句「瞎了。」他問誰告訴他們的，團團舔著糖葫蘆：「我算的。」還知道他把饅頭留給奶奶。貨郎孫二挑著貨擔晃進燈光裡：「喲，仙門退貨的回來啦！」三嬸從圍裙上抽出鐵錘，一錘砸在他貨擔旁邊的石板上，石板裂開、貨擔跳起來，歸伯一句「送客。」全村把孫二轟出村口。陸拾鼻子一酸，三嬸揉亂他的頭髮：「菜都熱三回了！」他順口問歸伯的釣竿怎麼沒有鉤，歸伯只說「魚，自己會來。」回到胡家院子，奶奶坐得筆直、一桌菜擺好：「回來了？洗手，吃飯。」陸拾把留著的饅頭推給她，奶奶掰開，掉出一顆發著淡藍光的靈石和一張摺起來的字條。陸拾看不懂字；奶奶看了一眼，臉色變了，把字條湊到油燈上。「奶奶，上面寫什麼？」火苗舔上紙角。

本集細綱：`docs/videos/series-plans/zero-root-yaozu/season-01.json` 第 3 集（115 秒，調性感人＋狗血）。開頭 3 秒是斧背一敲木頭裂開＋「力氣，大。」，陸拾的問題被三百盞燈打斷（0:06）；中段鉤子是三嬸搶先說「仙門瞎了眼」與團團的「我算的。」（0:31–0:39）；轉折是孫二那句「仙門退貨的回來啦」換來三嬸一錘、全村轟人（0:45–1:05）；結尾收在火苗舔上紙角。埋下的線：燒掉的字條（s01-t04）、歸伯沒有鉤的釣竿（s01-t05）、陸拾看不懂字（m04）；收掉的線：饅頭裡藏了什麼（s01-t01）。
