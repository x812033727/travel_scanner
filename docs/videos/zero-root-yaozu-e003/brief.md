# 《長燈村：零靈根的我被一村妖祖養大》第 3 集〈一村人等門〉

## 故事前提

第 2 集收在月光下的松林路：大松倒在路上，阿猙把沒有刃的斧頭藏到背後說「剛好。」；陸拾背著裂開的醃菜罈、罈子繩套裡插著短竹扁擔，懷裡揣著雲知意給的布包饅頭。第 3 集從同一條路接下去：阿猙用斧背往路上一截松木輕輕一敲，木頭順著紋路裂成兩半：「力氣，大。」陸拾張嘴要追問「這叫力氣大？」，坡下三百盞燈籠同時亮起，從山腳一路連到村口，像一條暖橘色的河。阿猙只說「等你。」陸拾在燈河裡回頭笑了：「等我？」又想起自己沒選上，摸著懷裡的饅頭想偷偷回家；村口的老槐樹下卻站滿了人，三嬸一嗓子「拾兒回來啦！全村等你呢！」他躲到阿猙背後，阿猙一步讓開。他鼓起勇氣要認錯，話還沒說完，三嬸就說「仙門那是瞎了眼！」歸伯慢吞吞補一句「瞎了。」他問誰告訴他們的，團團舔著糖葫蘆：「我算的。」還知道他把饅頭留給奶奶。貨郎孫二挑著貨擔晃進燈光裡：「喲，仙門退貨的回來啦！」三嬸從圍裙上抽出鐵錘，一錘砸在他貨擔旁邊的石板上，石板裂開、貨擔跳起來，裂口邊緣竟燒得通紅冒煙；歸伯一句「送客。」全村把孫二轟出村口。陸拾鼻子一酸，三嬸把錘子掛回腰帶：「笑啥？菜都熱三回了！」他順口問歸伯的釣竿怎麼沒有鉤，歸伯只說「魚，自己會來。」回到胡家院子，奶奶坐得筆直、一桌菜擺好：「回來了？洗手，吃飯。」陸拾問她怎麼知道他今晚到，奶奶不答，只說「人回來就好，菜還熱著。」他把留著的饅頭推給她，奶奶手指一捏就停住，掰開，掉出一顆發著淡藍光的靈石和一張摺起來的字條。陸拾看不懂字；奶奶看了一眼，臉色變了，把字條湊到油燈上。「奶奶，上面寫什麼？」火苗舔上紙角。

本集細綱：`docs/videos/series-plans/zero-root-yaozu/season-01.json` 第 3 集（115 秒，調性感人＋狗血）。埋下的線：燒掉的字條（s01-t04）、歸伯沒有鉤的釣竿（s01-t05）、陸拾看不懂字（m04）；收掉的線：饅頭裡藏了什麼（s01-t01）。

## 角色

- 陸拾（lushi）：主角。外觀沿用第 1、2 集（灰藍粗布短打、腰上破葫蘆、背上裂開的醃菜罈，扁擔插回罈子的繩套）；本集他想躲、想認錯，最後被全村護著。提示詞寫作 Lushi（理由見 storyboard.md）。
- 阿猙（azheng）：一句話不超過三個字；肩上那把沒有刃的斧頭、背上一捆柴，接第 2 集。
- 胡奶奶（grandma）：胡九娘，妖祖之首；本集在家擺好一桌菜等他，掰開饅頭、讀了字條、把它燒掉。手邊那把磨亮的豆腐刀放在碗旁。聲音 gemini:Gacrux（站主試聽選定）。
- 三嬸（aunt）：畢三娘，村裡的鐵匠，嗓門大、左腿微跛；圍裙上掛一把鐵錘。聲音 gemini:Pulcherrima。
- 歸伯（gui）：村長，戴斗笠披蓑衣，拿一根沒有鉤的竹釣竿；話最少。聲音 gemini:Enceladus。
- 團團（tuantuan）：七歲，兩個包子頭、桃紅小襖、手上一串糖葫蘆；什麼都「算」得出來。聲音 gemini:Leda。
- 孫二（sun）：本季客串的貨郎，嘴賤愛看熱鬧，挑一副掛滿針線糖果的貨擔、手搖撥浪鼓。setting.json 沒有替他選聲音，本集由代理暫定 gemini:Zubenelgenubi（沒有試聽過）。
