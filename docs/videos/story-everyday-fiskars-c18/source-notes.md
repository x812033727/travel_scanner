# C18 Fiskars｜逐字稿來源註記

本檔幫助另一位代理逐句審稿；**不是獨立查核收據**。旁白沿已採用的 [企劃](treatment.md) 和 [M01–M12 來源矩陣](source-matrix.md) 書寫，另增兩份同屬 Fiskars 發行的 S13–S14 原件作工廠轉場；這兩項新增內容尚未獨立核准。`script.md` 每句的「依據」是作者映射，審查仍需另一位代理直接讀原件，逐句核對旁白及同 ID 畫面。作者另直接讀到 [MoMA 藏品頁](https://www.moma.org/collection/works/3250)、[加拿大 CIPO 原件](https://ised-isde.canada.ca/cipo/trademark-search/pdf/1602003?lang=eng)、S13 與 S14；M01–M10 仍須由獨立審查者依原件重核，不可沿用舊版 PASS。

## 不能滑入旁白或畫面的斷言

- 「世界第一塑膠柄剪刀」、公司買下所有橘色、所有其他橘柄剪刀均侵權、1977 年以後剪刀全在美國製造、橘色單獨造成銷量成長，均沒有這份來源所需的比較或因果證據。
- 精確的 1967 年橘色決定日期若要寫，只有公司後來的說法，不能作同時期會議紀錄；本稿不寫。
- MoMA 館藏影像和 CIPO 登記圖樣不授權給圖片模型重畫；現行分鏡用原創通用剪刀和完全空白的概念文件。
