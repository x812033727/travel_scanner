## 尚未核實／不得倒推

1. **沒有同時期配色工單或票箱紀錄**：橘色剩料與投票以 Fiskars 的後來敘述呈現。[M05–M06]
2. **顏色與商業成功不是已測得的單一因果**：更輕的握柄、刀片製程、拓展產品與國際設廠都在這條故事內；來源不能把銷量全歸功於橘色。[M04、M07–M08]
3. **「世界第一」暫不做本集定論**：公司與設計館資料有此說法，但要把範圍定為哪種塑膠柄、比較對象與當年原件，還缺獨立的產品史查核。
4. **商標是按登記的商品、標示與法域判定**：不能說「橘色被 Fiskars 買下」或「別人的橘色剪刀都違法」。[M09–M11]
5. **館藏≠原型、年報≠1967 年現場紀錄**。[M03、M05–M06、M12]
