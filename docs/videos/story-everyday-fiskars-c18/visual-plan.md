圖片模型只接收每景 `prompt` 和作品既定 `look: {"preset":"cute-mystery"}`。`prompt` 不含品牌／設計師姓名、商標、可讀文字、真人肖像或受保護角色；歷史年份及地名只用旁白或後製卡。人物作為一般觀眾、工匠或檔案員的概念角色，並非對真人或歷史照片的重建。卡片不送圖片模型，也不拿卡片湊插圖占比。

文字預檢要核對：每景與相同 ID 旁白沒有事實相反、所有人數與顏色相符、主角剪刀在各章持續出現、無連續三張以上卡片、沒有畫風詞混進 `prompt`。成片製作另需先過來源覆核、兩位真正只讀旁白盲讀、站主核稿、整支報價和付費批准。
