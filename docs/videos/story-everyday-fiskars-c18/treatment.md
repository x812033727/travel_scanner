# C18 Fiskars｜一把橘色剪刀，怎麼變成識別？

狀態：**企劃來源獨立覆核 PASS，站主於 2026-10-23 採用方向；逐字稿仍未審核**。本檔是《日用品的意外轉身》[既定 C18 選題](../brand-stories-everyday-reversals-20261020/20-episode-plan.md)的六章 Treatment，不是已核准逐字稿、分鏡報價、媒體生成或上架計畫。逐項獨立審查見[審查草稿 PR #1706](https://github.com/x812033727/travel_scanner/pull/1706)；每個日期與可說界線見 [source-matrix.md](source-matrix.md)。

## 觀眾問題與包裝

- **觀眾問題**：如果橘色一開始只是多出來的試色，為什麼它會跟一把剪刀一起延續數十年，甚至進入商標紀錄？[M05–M06、M09–M11]
- **一條因果主線**：老鐵工坊與剪刀製造能力 → 金屬刀片加塑膠握柄的量產設計 → 橘色樣品被選中 → 性能與產品線繼續改良、進入海外市場 → 特定「橘色剪刀把手」後來成為受保護的品牌標示。顏色是可記住的表面，故事的推力還包括器具好不好用及如何做出來。[M01–M11]
- **本集一手轉折**：2003／2006 年公司年報說明橘色如何由試色變成商標；加拿大智慧財產局的原始登記把保護標示限定在特定剪刀把手可見表面的橘色。這讓結尾能回答「變成識別」具體指什麼，而不把「橘色都歸這家公司」當法律事實。[M05、M09–M11]
- **目標觀眾**：在書桌、抽屜或手作教室看過彩色握柄剪刀，但未必知道外觀、手感與製法如何連在一起的人。
- **標題三案**：①「Fiskars：一把橘色剪刀，怎麼變成識別？」②「Fiskars：橘色只是試色，為什麼大家記住它？」③「Fiskars：一把剪刀的顏色，能登記成商標嗎？」③ 只能以本案具體登記與範圍回答，不能當一般法律建議。[M09–M11]
- **縮圖假設**：左上橘色大字 **FISKARS** 由後製排字；兩把無商標、輪廓不照描實物的通用剪刀分列黑色與橘色握柄，中間一個抽象選擇手勢。後製疑問句「為什麼選橘？」。圖像模型不畫品牌名、logo、可讀文字或原型的精確外形。

## 濃縮開場草稿（預定約 45 秒，非定稿旁白）

> 一張工作桌上，幾把沒有名字的剪刀排在一起。只看手把，那抹橘色或許已經讓你想到一家公司。但它並非一開始就被指定為主角。Fiskars 後來說，設計剪刀時，機器裡剩下的橘色塑膠讓它多了一種試色；員工又在幾種顏色中選了橘色。問題是：偶然選到一個顏色，怎麼會讓它跟著一把日用品走出工廠，幾十年後還寫進商標紀錄？

開場的工作桌與樣品是概念插圖，不冒充 1967 年工廠照片；「機器剩料與投票」明說是公司回顧，不演成可核實的現場目擊。[M05–M06]
