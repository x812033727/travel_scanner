# 哪幾支值得買宣傳（2026-11-11）

站主 2026-11-11 問：「幫我用報表分析哪幾支值得投」。這份報告把付費觀看和自然觀看分開，挑出值得花錢推的影片。

- **資料**：站台保存的 YouTube Reporting API 報表（`channel_basic_a3`、`channel_traffic_source_a3`、`channel_reach_basic_a1`），2026-10-04 至 2026-11-07（太平洋時間），2026-11-11 00:01Z 匯出。
- **本文所有總和、比率與排名都是依 YouTube 報表原始數據自行計算**，不是 YouTube 給的數字，不可放上公開網頁或影片說明（見 [`../YOUTUBE-REPORTS.md`](../YOUTUBE-REPORTS.md)）。
- **缺資料**：宣傳花費不在報表裡（要從 Studio「內容 → 宣傳活動」抄），所以這裡算不出每位訂閱的成本。約 2,050 次觀看來自站台沒有對到 slug 的 Shorts，下面沒有逐支列出。

## 量法

- **付費觀看**：`traffic_source_type = 1`（YouTube advertising）。**自然觀看**：其他所有流量來源。
- **自然平均觀看百分比**：自然流量的 `watch_time_minutes × 60 ÷ 自然觀看`，再除以片長。片長用 `average_view_duration_seconds ÷ average_view_duration_percentage` 反推。
- **點閱率**：把 `曝光 × 點閱率` 加總後除以總曝光。縮圖曝光不含廣告的曝光。
- **帶出的觀看**：別支自家影片的「推薦影片」流量裡，`traffic_source_detail` 是這一支的觀看數。這個數字最接近 Studio 的「後續觀看」。
- **淨訂閱**：`subscribers_gained − subscribers_lost`。報表沒有依流量來源拆，所以只能看整支影片的數字。
