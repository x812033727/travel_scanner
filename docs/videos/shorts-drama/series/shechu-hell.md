## 一、系列定位與固定笑點公式

和早期退掉的《汪汪社畜》（靠狗的內心獨白與職場黑話撐笑點，評審與站主都覺得慢）不同，本系列**完全不講話**，笑點 100% 來自**「貓的天性就是任性老闆」**：把桌上的東西推下桌、一天睡十六小時、坐在鍵盤上、看到雷射筆紅點就失控、最愛躲紙箱、永遠搶走最暖的陽光位。上班族一看就懂，養貓養狗的人更秒懂。

| 項目 | 設定 |
| --- | --- |
| **系列名稱** | 社畜地獄（`shechu-hell`） |
| **預設標籤** | `["社畜地獄", "社畜", "貓老闆", "黃金獵犬", "零台詞", "AI短劇"]` |
| **畫風與世界觀** | 寫實 AI，真實外觀的黃金獵犬與胖橘貓像人一樣穿襯衫與西裝在辦公室上班；世界裡完全沒有人類 |
| **固定場景** | 同一間辦公室（但每一鏡身後必須寫成封閉素色牆面，避免 AI 畫出人類同事）、老闆大皮椅、會議白板前 |
| **五拍公式** | **① 狗員工阿金想做一件正常的上班事（下班、簡報、偷閒、談加薪、曬太陽，`0.9–2.6s`）** → **② 貓老闆喵總出現並啟動貓咪本能（瞳孔放大、伸出貓掌、響起鈴鐺，`1.5–2.4s`，配 `dun`）** → **③ 狗員工呆住或求饒反應（`0.6–1.8s`）** → **④ 跳過過程給荒謬職場結果（加班到深夜、簡報白板被撲倒、貓老闆沉入紙箱，`2.0–3.0s`）** → **⑤ 貓老闆若無其事再補一個貓動作定格（`1.3–3.0s`，配 `dun`/`thud`＋`hold: 0.4–0.9s`＋`music_off`）** |

## 三、本系列專屬的 AI 避險與實戰教訓

1. **辦公室場景必寫「緊貼身後的素色實牆」，嚴禁開放式隔間**：
   - 第一版《社畜地獄》因為寫了 `in an office`，模型在背景隔間與走廊自動畫出大量模糊的人類上班族人影（`QA-2026-11-04.md` 第一輪被抓出最多高嚴重度問題的系列）。
   - **定版鐵律**：本系列每一鏡的 `ff` 都必須寫 **`directly behind him is a solid plain grey wall, no cubicles, no windows to other rooms, empty room`**，把背景鎖死在單純牆面、白板或百葉窗前。
2. **黃金獵犬的手最容易變成人手**：
   - 阿金敲門、拿雷射筆、舉長條圖、打鍵盤的鏡頭，第一版常畫出五根人類手指。
   - **定版鐵律**：必須明寫 **`with his two furry golden dog front paws, no human fingers`**；舉圖表或報告時，寫成圖表板夾在兩隻毛茸茸的狗前掌之間（或放在桌上、狗掌壓在邊緣）。
3. **筆電、文件、白板、識別證一律無字無 Logo**：
   - 筆電寫 `a plain unbranded silver laptop lid with no logo`；識別證寫 `a blank white ID badge with no text or photo`；加薪長條圖只畫三根往上走的彩色粗柱子與一個紅色向上箭頭（`three simple coloured bars and a big red upward arrow, no text, no numbers`）。
4. **狗與貓對戲一律拆正反打（單人框）**：
   - 狗與貓體型差距大，同框容易比例失調或衣服混在一起；除了遠景（如 `e01` 深夜辦公室阿金在前景、喵總在遠處印表機上捲成一顆橘色毛球）外，一律阿金一鏡、喵總一鏡。
5. **一季不要長成同一副骨架**（2026-11-21 重製盲評）：
   - 五集一起寫時，全部變成「貓做事 → 狗 0.8 秒僵住 → 硬切慘狀 → 狗以為沒事 → 貓眼往旁飄＋抽音樂 → 再整一次＋『登』定格」，導演評審連看兩集就猜到結尾。
   - **定版做法**：不要每集都放「貓眼往旁飄」的預告鏡；至少一集讓阿金先贏一拍（e01 膠帶封桌）；收尾輪流落在喵總與阿金；收尾音效輪替（打呼、水聲、金幣、`dun`）；「貓愛箱子」這類天性一季只用一次當主梗。
6. **道具要讓手機上一眼看懂**：加薪圖表畫成**金幣疊成的柱子＋紅箭頭**（只有長條，評審看不出是加薪）；喵總推落的東西要在畫面裡被看到推、被看到掉，水這類液體要補一格看得到的水花。
