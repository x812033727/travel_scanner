# Shorts 零台詞短劇的審片與品管：從首格到雲端備份與上架

這份是共用區：任何一部無語音（零台詞）Shorts 短劇，從「分鏡過了三道檢查、開始生成」到「成片通過畫面與笑點雙重審核、備份雲端並送上後台」的完整品管關卡。

站主 2026-11-04 定下的規矩：**每一集成片都要過審核才能上架；有問題就修，修完再審；笑點也要夠。**
審片的人與做片的人必須分開：做片與剪接的人看自己的片子會自動腦補劇情，獨立審片人用「第一次在手機上滑到」的眼光才能抓出人手、背景人影與看不懂的笑點。

- 分鏡怎麼寫與花錢前的審劇本三道檢查：[`WRITING.md`](WRITING.md)。

## 1. 首格檢查（送 H3 片段前先擋掉八成重抽）

MiniMax H3 是圖生影片（以 `colab/ff/<shot>.png` 當第 0 格）。**首格上已經畫錯的東西，H3 片段永遠救不回來**；反過來說，在首格階段抓到錯，只花幾秒鐘重畫一張圖，能省下一整支 H3 片段的 GPU 點數。

每集首格畫完，先逐張看四件事才送 H3：
1. **核心笑點造型有沒有畫出來**：第 3 拍「誇張結果」那一張首格（如整隻浣熊蹲在藍色大花瓶裡、柯基頂著巨型粉紅捲髮、水豚抱住漏水水塔），是不是一眼就看懂？如果模型畫成「動物站在物件旁邊」或「抱著一塊布」，當場改 `ff` 提示詞重畫首格。
2. **手與爪子**：拿東西或托腮的鏡頭，是不是毛茸茸的動物爪（`two furry front paws`）？有沒有長出五根人類手指或指甲油？
3. **背景與文字**：身後有沒有模糊的人影？筆電、時鐘、招牌、衣服上有沒有品牌 Logo 或可辨識的字？
4. **同機位連戲鏡**：像《闖禍小浣熊》EP3 電視換台（`s03`、`s05`、`s06`、`s07`），後三張首格是否用 `s03` 首格當底圖編輯（確保電視外框與背景完全一致）？

## 2. 第 1 關：成片自動檢查（`qa_check.py`）

H3 片段生完、用 `edit.py` 照 `edit/plan.json` 合成出 `<VIDEO_WORKDIR>/<slug>/edit/final.mp4` 後，第一步先跑免費的自動檢查：

```bash
python3 production/qa_check.py <slug> --work <VIDEO_WORKDIR>
```

### 自動檢查做哪三件事：
1. **硬規格把關（不過直接回結束碼 1）**：
   - 解析度 `1080×1920`（9:16 直式）、幀率 `30 fps`、音訊取樣率 `48 kHz`；
   - 片長落在 **`9.0–20.0 秒`**（最佳區間 `11–16 秒`）；
   - 整體響度落在 **`-15.0 ~ -13.0 LUFS`**（目標 `-14 LUFS`）。
2. **鏡中硬切換景偵測**：
   - H3 常常在 5 秒片段的第 3–4 秒自己「硬切」到另一個鏡位。`edit.py` 會在偵測到的硬切點之前自動截斷，但「鏡頭慢慢移到別處」或「角色臉部逐漸變形」抓不到，會標在報表裡交給第 2 關人工看。
3. **產生每秒 3 格、帶黃字時間碼的檢查聯絡表**：
   - 自動輸出 `<VIDEO_WORKDIR>/<slug>/qa/<slug>.jpg` 與 `<slug>.qa.json`，供第 2 關獨立審片人逐格檢視。

## 3. 第 2 關：獨立畫面審核＋雙人笑點審核

自動檢查通過後，**開全新的獨立子代理**（沒看過前面的審核紀錄、也不是寫稿或剪這集的人）讀 `qa/<slug>.jpg` 檢查圖，有疑點就用 `ffmpeg` 從 `final.mp4` 抽 540px 寬的大格確認。

### A. 畫面上架門檻（零「高」、零必修改「中」）
嚴重度分三級：**高**＝一眼看出很怪、立刻出戲；**中**＝注意看會發現；**低**＝挑剔細節。

| 類別 | 判定規則 |
| --- | --- |
| **高嚴重度** | **0 容忍，一律必修。** |
| **必修改的中嚴重度** | 只要出現以下任一項，就算審片人標「中」也**一律必修**：<br>1. **人類痕跡**（含遠處背景人影、人類手指與手臂、指甲油）；<br>2. **多出或缺少的肢體、角色分身**（同框出現兩隻主角或多一隻懸空手）；<br>3. **看得懂的文字、品牌 Logo、角落浮水印**；<br>4. **片段中途突然換景或角色變臉**（如水豚打噴嚏後半變成別的動物）；<br>5. **讓核心笑點看不懂的劇情矛盾**（如說熄燈但螢幕還亮著、說看手錶但手錶被切掉且沒低頭動作）。 |
| **可接受的中／低嚴重度** | 不影響笑點理解的次要道具連戲差異（如鏡頭間電視邊框些微不同、地毯上的道具款式微變），可在品管紀錄 `QA-<日期>.md` 寫明「接受」後上架，不無限抽卡。 |

### B. 笑點審核門檻（兩位不同觀眾角色盲審）
站主 2026-11-04 定案：企劃階段的文字盲評看不到畫面與停頓（33 萬讚的參考片轉成文字盲評只拿 55 分），**成片看得到畫面與聽得到音效打點，才是判斷好不好笑最準的時候**。

每支成片由**兩位不同觀眾角色**的獨立審片人（例如：**角色 A：21 歲常滑 Shorts／TikTok 的年輕觀眾**；**角色 B：32 歲喜劇短片導演**）各自看檢查圖與抽格，回答五項指標：

| 指標 | 評分方式 | 上架門檻 |
| --- | --- | --- |
| **1. 鉤子** | `1–5 分`：前 1.2–2 秒有沒有怪事或衝突，讓人不想滑走 | 參考診斷（低於 3 分優先砍短第 1 鏡） |
| **2. 核心笑點有畫出來** | `是／否`：這集的核心笑點（偽裝造型、誇張結果、假景穿幫、貓老闆動作）在畫面上**不靠文字解釋就看得懂嗎**？只靠想像腦補的算「否」 | **兩位都必須判「是」**（只要有一位判「否」就不過） |
| **3. 收尾** | `1–5 分`：最後一拍有沒有補刀、定格與音效打點有沒有力 | 參考診斷（低於 3 分加 `hold`、`music_off` 或重排收尾） |
| **4. 好笑度** | `1–5 分`：1 不好笑、3 會心一笑、5 笑出聲；附一句理由 | **兩位平均 `≥ 3.0 分`** |
| **5. 會不會轉傳** | `是／否`：會不會想傳給某個具體的人（另一半、同事、朋友） | 參考診斷 |

### C. 獨立審片人提示詞範本（直接貼給新開的審片子代理，換掉 `【】`）

```text
你是第一次看這批影片的獨立審片人，請扮演【角色 A：21 歲常滑 Shorts 的一般觀眾 ／ 角色 B：32 歲喜劇短片導演】，用「一般觀眾第一次在手機上滑到」的眼光，挑出所有看起來怪、會讓人出戲的地方，並評核笑點。全程繁體中文。不要修改任何檔案、不要花錢、不要呼叫 Colab。

這是【N】支 9–18 秒的直式零台詞 AI 短劇（寫實風格，動物像人一樣站著、穿衣服；世界裡沒有人類）。
系列設定：
【貼上每個系列的一行設定：角色、外觀錨點、固定笑點機制；例如「網美小豬：粉紅小豬粉粉（白蕾絲洋裝、草帽）與水豚男友（綠漁夫帽、灰 T 恤）；前 1.2 秒唯美照 → 拉遠揭曉廉價假景與苦力男友 → 成品照裡水豚偷偷入鏡或出糗是刻意笑點」】

檢查圖（每秒 3 格、左上角黃字是時間碼，由左到右、由上到下）：`<VIDEO_WORKDIR>/<slug>/qa/<slug>.jpg`，slug：【列出】。
原片：`<VIDEO_WORKDIR>/<slug>/edit/final.mp4`；有疑點請抽大格確認：
`ffmpeg -v error -y -ss <秒> -i <final.mp4> -frames:v 1 -update 1 -vf scale=540:-1 <VIDEO_WORKDIR>/<slug>/qa/z-<秒>.png`
各鏡順序與長度：`<VIDEO_WORKDIR>/<slug>/edit/plan.json`。

一、畫面檢查要找的問題：
人類（含遠處背景人影、人手人臂、指甲油）、多出或缺少的肢體、角色分身、臉或身體變形、看得懂的文字、品牌 logo、浮水印、片段中途突然換景或角色被換掉、黑塊閃爍、同一集角色或服裝明顯不一致、跟劇情矛盾、看不懂在演什麼（核心笑點沒有被畫出來）。

二、笑點評核（只看畫面與剪接時間軸判斷，不看文字企劃）：
每支給出：
1. 鉤子（1–5 分）：前 1.5 秒有沒有讓人停下來的衝突或怪事？
2. 核心笑點有沒有被畫出來（是／否，若為「否」請指明哪一鏡缺了什麼）？
3. 收尾（1–5 分）：最後一拍有沒有力？收尾音效與定格有沒有到位？
4. 好笑度（1–5 分：1 不好笑、3 會心一笑、5 笑出聲）＋一句理由。
5. 會不會轉傳給某個具體的人（是／否，轉給誰）？
6. 一條最能讓它更好笑的具體修改建議（剪短哪一鏡、換鏡頭順序、加定格與靜音、加音效、裁切推近、或重畫哪一鏡）。

交付格式：
- 每支一段，列出畫面問題：秒數、鏡號、看到什麼、嚴重度（高＝一眼看出很怪／中＝注意看會發現／低＝挑剔）、建議修法（剪到幾秒、整鏡拿掉、改用首格靜止、裁切、重畫）。沒問題寫「沒有明顯畫面問題」。
- 每支的笑點五項評分與具體修改建議。
- 最後一張總表：列出每支的「高／中畫面問題數」「核心笑點是否畫出」「好笑度分數」與「能不能上架（能／修完再審）」。
```

## 4. 第 3 關：由便宜到貴的五級修法與複審紀律

2026-11-04 四系列 20 集實戰證明：**審片人挑出的問題，超過七成用本機剪接（0 元、幾秒鐘）就能修好**，只有約兩成需要回 Colab 重畫。收到審片意見後，一律按下面**由便宜到貴的五個等級**依序處理：

| 優先序 | 修法等級 | 怎麼做（`edit.py`／`recut.py` 選項） | 實戰成功案例（`QA-2026-11-04.md`） |
| --- | --- | --- | --- |
| **第 1 級**<br>*(免費)* | **剪短、掐頭去尾、加定格與靜音** | - 開頭鋪陳或呆滯反應鏡直接改 `in` 與 `dur` 砍到 `0.6–1.2s`。<br>- 片段後半變臉或穿幫：把 `dur` 縮短在變形前截斷。<br>- 揭曉與收尾加 `"hold": 0.5~1.1`（最後一格定格）與 `"music_off": True`。<br>- 把掉在片尾外的音效 `at` 往前移進鏡頭內。 | - 《網美小豬》全系列唯美照從 4.6 秒砍到 1.2 秒。<br>- 《闖禍小浣熊》全系列鑰匙聲反應鏡砍到 0.6–0.8 秒。<br>- 《網美小豬》EP2 噴嚏鏡只留前段水豚臉還沒變形的那一段，後接 `hold: 0.8`。 |
| **第 2 級**<br>*(免費)* | **對調鏡頭順序、整鏡拿掉或借鏡回切** | - 廢鏡或跳場鏡直接從 `plan.json` 拿掉（音效併到前一鏡）。<br>- 對調揭曉順序強化反差。<br>- 把前面出現過 0.6 秒的特寫切在結尾當補刀。 | - 《汪家夫妻》EP5 先給老婆佔滿整張床的超巨型被捲（`s04`），再接阿福縮在寵物墊（`s03`），反差立刻出來。<br>- 《社畜地獄》EP2 結尾補切 0.6 秒貓老闆放大瞳孔（取自 `s02-pupils` 後半）再切黑（`"black"`）。 |
| **第 3 級**<br>*(免費)* | **改用首格靜圖慢推（`-still`）** | 若 H3 片段一動起來手部就變形或背景亂跑，但**首格（`colab/ff/`）本身畫得很準**，直接拿首格轉成慢推靜止片段放進 `edit/`。 | - 《汪家夫妻》EP2 `s01-perm-still`（卡門框的巨型粉紅捲髮用首格 2.0 秒＋`pop` 音效，比亂動的片段更穩更好笑）。<br>- 《網美小豬》EP2 `s05-still`、EP3 `s01-falls-still`。 |
| **第 4 級**<br>*(免費)* | **局部裁切推近（`push`＋`anchor`）或暗色遮罩（`box`）** | - 手部像人手但臉部表情對：在 `plan.json` 用 `"push": [1.7, 1.85], "anchor": [0.5, 0.0]` 只裁臉部上半段，把人手切出畫框外。<br>- 局部小瑕疵（如行動電源螢幕沒暗掉）：用 `"box": [x, y, w, h, t, "0x1c2622"]` 蓋上同色暗塊，搭配 `"lights_out": [0.3, 0.6]` 分段熄燈。 | - 《闖禍小浣熊》EP4 媽媽看錶那一鏡手太像人手、重畫又多一隻手臂 → 直接裁切原片只留臉部「先低頭看下、再抬眼起疑」加滴答聲。<br>- 《網美小豬》EP3 結尾用 `push: [1.0, 1.8], anchor: [0.95, 0.0]` 慢推到成品照瀑布頂端的水豚頭加 `gurgle` 咕嚕聲。<br>- 《網美小豬》EP5 用 `box`＋`lights_out` 做出燈串三段熄滅。 |
| **第 5 級**<br>*(花 CU)* | **回 Colab 重畫或補畫單鏡（`redo`）** | 只有當「核心笑點完全沒畫出來」或「主角全身嚴重崩壞、裁切也避不開」時才重畫：<br>- 舊檔改名 `.old` 保留（萬一新版更差可退回）。<br>- **重畫時必須改寫提示詞為「結果的靜態造型」**，加上 `two furry front paws` 與 `solid plain wall`。<br>- **停損鐵律：同一鏡重畫兩次（共 3 版）還是犯同一個錯，就立刻停手換構圖／換表現方式，絕不繼續抽卡。** | - 《闖禍小浣熊》EP1 補畫 `s03b-vase`（直接寫豆豆整隻已經坐在藍色大花瓶裡）。<br>- 《網美小豬》EP2 補畫 `s05b-inhale`（水豚仰頭憋噴嚏 1.0 秒蓄力鏡）。<br>- 《汪家夫妻》EP2 `s05` 柴犬平頭重畫三次仍不像平頭 → 停手不再抽卡，改在地上畫滿剪下的粉紅捲毛＋手上拿嗡嗡響的電剪交代。 |

### 複審紀律
- 每一輪修改完，重新跑 `edit.py` 與第 1 關 `qa_check.py` 更新檢查圖。
- **交回同一位（或同一組）獨立審片人複審**：他知道上一輪挑了什麼問題，能直接確認「原本的問題修好了沒、有沒有修出新破綻」。
- 直到兩位笑點審片人都判「核心笑點有畫出來、好笑度平均 ≥ 3、無高或必修改中度畫面問題」，才算過關。
- 每一批在系列或批次資料夾留存一份 `QA-<YYYY-MM-DD>.md`，如實記下每集各輪分數、做過的修改、以及決定「接受」的輕微已知問題。

## 5. 第 4 關：八語標題說明、雲端硬碟備份與後台匯入

### 1. 八語標題與說明欄（`youtube-meta`）
- 零台詞短劇沒有對白與字幕翻譯成本，每一集一次產出繁中（`zh-TW`）與八語（`en, ja, ko, es, pt, id, vi, th`）標題與說明欄。
- **標題寫法**：寫「日常衝突情境」＋系列 Hashtag（例如：`老婆燙了新髮型，老公看都沒看就點頭 #汪家夫妻`），**嚴禁在標題講出最後的誇張結果或反轉**。
- **合成內容揭露**：說明欄寫明「本片畫面、配樂由 AI 生成」，匯入時 `synthetic_media: true`。

### 2. 雲端硬碟完整備份（`AI/備份/Shorts/<系列名>/`）
所有通過品管的集數，將完整製作包備份至雲端硬碟 `AI/備份/Shorts/<系列名>/`，確保未來任何 session 都能無損重剪或換鏡：
- `workdir/<集>/edit/`：`final.mp4`、`plan.json`（定版剪接表）、`plan.v1.json`（初版剪接表）、`sfx/`、`music.mp3` 與處理過的靜圖／裁切片段；
- `workdir/<集>/colab/`：`ff/`（每鏡首格）、`clips/`（每鏡 5 秒 H3 原始片段）、`prompts/`、`ff.json`、`clips.json`、角色定妝照；
- `workdir/<集>/qa/`：`qa/<集>.jpg`（每秒 3 格檢查圖）、`qa/<集>.qa.json`；
- `production/`：`edit.py`、`recut.py`、`qa_check.py`、`gen_specs.py`、`QA-<日期>.md`、`youtube-meta.json`。

### 3. 後台匯入（`shorts import`）
- 將成片（30 fps、48 kHz、−14 LUFS）、封面與 `meta.json` 透過 `node tools/video/shorts/cli.mjs import --from <DIR> --workdir <VIDEO_WORKDIR>` 匯入後台（細節見 `.agents/skills/youtube-video/references/shorts.md`）。
- 注意：後台 `/admin/videos?tab=shorts` 的 `seconds_min` 預設為 25 秒（給有旁白的實測線用）；匯入 11–18 秒的零台詞短劇前，需確認後台最短秒數已調低至 9–10 秒。
