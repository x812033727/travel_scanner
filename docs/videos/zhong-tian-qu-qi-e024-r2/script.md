## 劇情

鬥商第一日早上，許硯和唐小棠剛卸下許記的門板，對街魏記揭了紅綢，夥計敲鑼喊肥皂五文一塊，排隊的人跑了一半去對街。
唐小棠說五文連豬油錢都不夠，許硯說魏記是拿宰相府的錢賠本砸；魏少卿在對街二樓說三十天陪他慢慢玩。
二牛要跟著降到四文，唐小棠說不降：他砸的是宰相府的錢，我們砸的是自己的命。她在門口擺一只大木盆，舊皂頭拿來換新皂，一塊折一半；
又拿出梅花紋的木牌，老客憑木牌次次九折。系統報：老客回頭，七成。許硯說留得住老客，對方天天五文，拚價還是輸；他想要一樣魏記做不出來的貨，
兌換了放了九天的製糖法，系統挖苦他終於想起來。他從隔壁攤子拿起最便宜的紅糖，說今晚回柳溪，要讓它變得比雪還白。
當夜在柳溪糖坊，二牛熬了兩個時辰的黑糖漿，許硯把糖漿灌進陶漏斗凝住，再淋上一勺黃泥水；二牛嚇得問淋了泥還能吃嗎，許硯說等天亮。
第二日天剛亮，漏斗裡的紅糖從上往下一層層變白，二牛嘗了一口：白得像雪，甜得也像雪。系統報：白糖試做，成功。
十斤紅糖只出一碗白糖，要賣得有幾百斤；二牛去鄰鎮收，許硯進城叫唐小棠去糖行訂。
第三日早上，許硯把那碗白糖擺上許記的櫃檯，唐小棠從糖行跑回來：全州的紅糖昨天一夜被人買光，訂的三百斤也沒了，一車一車拉進了魏記。
許硯問鄰鎮總不會也被買光吧，對街二樓的魏少卿搖著扇子：全州的糖，包括鄰鎮；沒糖，看你熬什麼。

- **時間**：鬥商第一日（第二十四天）早上 → 當夜（柳溪糖坊）→ 第二日（第二十五天）清晨 → 第三日（第二十六天）早上（縣城許記）。
- **錢**（都從許記櫃檯抽屜裡當天的進帳出，唐小棠記帳；木錢箱在柳溪家裡）：
  - 紅糖十斤，一斤十五文，共一百五十文；陶漏斗十個、陶壺一把、矮陶罐十個，共二錢。
  - 第二日唐小棠向縣城糖行訂紅糖三百斤，訂金一兩（碎銀，小布包）；第三日糖行退回，c32 交給許硯，c35 交還唐小棠收回櫃檯抽屜。
  - 許記零售肥皂一塊一錢；舊皂換新一塊五分；會員木牌九折。魏記粗皂五文一塊（賠本）。本集不結帳，鬥商的帳見第 25、26、29 集的面板。
- **貨**：
  - 肥皂：第一日許記貨架上是第二十一天起在柳溪新熬的一批（約一百塊，照第 1–5 集的法子；共用設定沒寫數，本集只寫「貨架上的新皂」）；舊皂頭收在門口木盆裡。
  - 白糖：第二日試做一碗（約一斤）；第三日許硯捧著那碗，**帶回柳溪**（第 25 集第一鏡還捧著）。
