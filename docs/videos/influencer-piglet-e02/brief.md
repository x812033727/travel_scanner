# 網美小豬 EP2〈雪國〉

## 故事前提

粉粉在漫天大雪裡轉圈拍美照。拉遠：大太陽的頂樓，雪是刨冰被電風扇往上吹；水豚男友頂著刨冰機站在電風扇後面，凍到眉毛結霜。她重擺姿勢，水豚打了一個噴嚏，整片冰屑噴了她一身。

## 角色

- 粉粉（fenfen）、水豚男友（capy）：同系列定裝照；這集粉粉換白色毛帽與白色毛衣。

## 站主觀點

零台詞；系列公式：唯美 → 閃光一瞄 → 拉遠揭曉 → 男友 → 成品照破綻 → 重擺被整。

## 格式

- 9:16，約 16 秒；Colab 首格與 H3 片段。
