# 本片原創簡報示例

此目錄保存本片生成的4頁PDF、原生文字／形狀PPTX、四頁SVG／PNG、逐頁引用清單，以及作者需求／初稿／修改與產出記錄。這是本片助理原創規劃及確定性本地排版，不是Google Notebook產品實測或獨立互動pause的紀錄。

原始Stanford 60頁PDF、擷取的完整頁文字與整頁PNG未放公開repo；請依page-citation-manifest.json中的官方來源URL與SHA下載核對。原manifest包含56個原work檔案，其中未隨附的來源只保留原始SHA，不能把它視為56檔全公開交付。本目錄另外列copied-file-manifest.json明示實際附上的檔案。

PDF以四張頁面圖片組成，只有PPTX為原生可編輯物件。PPTX已重新開啟作結構檢查，未在PowerPoint原生程式渲染，不保證跨平台字型完全一致。所有實際圖值採2025資料；2026是報告年份。70／79保留為未對齊的來源觀察，沒有判定報告錯誤。

生成器為原run程式封存，依賴原work來源與現成PDF／PPTX處理環境；這份快照不冒稱在新目錄已重跑。原始56檔SHA已由獨立代理核對，本目錄的原創交付檔保持原bytes。
