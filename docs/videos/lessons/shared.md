# 所有 AI 劇共用：教訓

所有 AI 劇（種田、祖媽、奇聞、原來如此）都會遇到的教訓。只跟一部劇有關的，寫在那部劇自己的檔案。

寫法：一條一段，最新的放最上面。開頭寫日期、哪一集（slug）、誰發現的，接著寫發生什麼、為什麼、下次怎麼做。
已經變成正式規則的，搬進規則檔，這裡留一行「已升為規則：<檔案>」。

這份會自動同步到雲端硬碟 `AI劇/_共用規則/教訓/教訓.md`（docs/videos/rules-sync）。
