## 稿面會計與時間檢查

- M17 的 US$510m、US$466m 跌幅與 US$125m 軟服增加，是三個不同收入類別；不能把金額當手機銷量。合併總營收跌幅約 US$851m 由申報直接列示。
- FY2017 AIF 同時談「全部硬體開發外包」及一款擬由公司設計、第三方製造的未來手機；稿只表述主方向，保留過渡與計畫的界線。
- M18 的 FY2018 US$64m 是 BlackBerry 自有 Handheld Devices 收入，不是授權夥伴新手機的收入；它包含舊機、配件與修理服務。原件把公司舊庫存不再補貨與新品牌手機由夥伴承擔連在同一段。
- M18 列設備收入占「收入」的 27.2%→6.6% 採調整後總收入為分母；本稿明說以 GAAP 合併總收入換算，FY2017 約 28.6%，FY2018 約 6.9%，不要把兩組占比交叉對照。
- M18 的 Licensing, IP and Other +US$70m 有 Teletry 與既有 IP 授權等非手機內容；FY2020 的 Mobility 收入認列規則也不能反推出 KEYone 銷量或現金入帳時間。
- 結尾把 FY2017 舊收入縮小、FY2015 已明言降低庫存風險的考量，與 FY2018 自有手機庫存不再補貨放在一起，作為**編輯推論**回答「為何交給夥伴」。申報沒有給這次轉向單一、可量化的動機，不能寫成公司正式宣布「因某一個數字而外包」或推算節省金額。
