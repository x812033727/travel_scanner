# ForTy兩個真實COG ROI：獨立資料查核

查核日期：2026-10-25（Asia/Taipei）。範圍為目前`forty-demo`兩個2020 ROI的來源、像素值、分類推導、座標、圖示與可用旁白事實。未修改repo、作者產物、圖像、原始JSON或GeoTIFF；沒有登入、註冊、模型呼叫或外部寫入。

**結果：資料與推導PASS。73項獨立檢查全部通過。** 這個結果可支持「讀取真實已公開模型輸出並重算分類」，不支持地面真值、全域精度、年度變化或法規合規。

## 獨立取得與解碼方法

我沒有只重跑作者的程式：

1. 另向官方GCS物件metadata取得size／generation／md5欄位，與紀錄比對。
2. 對同一generation重新取得TIFF首64KiB及五個full-resolution band tile，共六個受限HTTP Range、**160,141資料bytes**；HTTP全部206、Content-Range、長度與每段SHA-256均與作者收據相同。
3. 從新標頭的TIFF tag自行算出full-resolution tile索引46／100／154／208／262，沒有直接信任JSON的索引。
4. 直接用系統libzstd解壓五個tile，再依TIFF Predictor2逐列做累加、mod256還原像素，獨立於GDAL的像素解碼。
5. 把新取回的位元組重建成只含已知區段的記憶體TIFF；GDAL讀取同一512×512block的五band，與上述手動解碼完全一致。
6. 比對兩份完整10×10 GeoTIFF與JSON：每份500個儲存值全部相同；重新推導Other、全部六分數、argmax、有效值、transform與座標。

來源物件：
https://storage.googleapis.com/nature-trace/export_rasters/forest_typology_2020_v1_0/raster_51R_20_1_4.tif

- 物件size：7,293,206bytes。
- generation：1777582191968217。
- metadata的MD5欄位與原manifest一致；**沒有下載整物件重算MD5**，不把metadata比對說成全檔checksum重驗。
- 本次查核另有一個metadata GET；160,141只計六段資料傳輸，不是整個企劃所有網路工作流量。
- 稀疏中間檔在未取回區段是空洞，不能讀其他未取得區域作證據。我只解碼這五個確實取回的tile。

完整機器收據：`independent-results.json`。可重現查核程式：`independent_check.py`。腳本固定編輯UA、保留TLS與平台代理，沒有關閉驗證或繞過403；公開物件按正常有權限的GET讀取。

| 本地ID | 官方名稱 | 本片可用繁中稱呼 | 儲存／推導 |

| 1 | PrimaryForest | 原始林 | band1 |

來源TIFF沒有文字band description，因此名稱依官方文件的band順序對應，不是假稱從TIFF自帶名稱讀出。兩個JSON的鍵順序、figure類別順序與官方順序一致。OtherLand不能簡化成「裸地」或「完全沒有樹」。

nodata=255，儲存類別值為0–250。計算使用有號整數，避免uint8殘差回繞；有效像素檢查及六分數總和均正確。分數=儲存值÷250，即乘0.004。

A的0.992不能說成99.2%實際正確率；B的0.344也不能說成34.4%實際正確率。它們是未事後校準的模型輸出分數，與全域驗證accuracy不是同一個量。

### B的並列不能藏在綠色裡

B沒有唯一最高者。綠色是本次明列的**NumPy first-maximum顯示規則**造成的衍生標籤，沒有驗證官方另行發布的硬分類層也採相同tie規則。現有README、figure標題與原始JSON都揭露這個限制，PASS。

可用說法：

> 這格的自然再生林與其他土地，分數都是零點三四四。這張圖依我們列明的取首規則塗成綠色；單看顏色，就會看不見並列。

不要說「B被資料唯一認定為森林」，也不要只展示綠色而不講兩個最高者。

新來源標頭、JSON與兩份完整crop的transform、CRS、中心轉換逐項一致。原始Y步長為正，row往較大的UTM northing增加，不能沿用一般north-up TIFF的負Y假設。Figure的`origin=lower`正確：資料row0在下方，較大row在上方；east向右。嚴格說這是網格northing方向，不是宣稱圖片經緯線已做無投影變形的實地量測。

每格的affine面積行列式絕對值為100m²；每個10×10窗口的**名目投影格網範圍**為100m×100m=10,000m²=1公頃。這不能直接講成「一公頃已確認真實森林」或「完成實地面積測量」。

兩個示例也**不是相鄰格**：中心相差225col與55row，投影平面約2.3km。用「同一已取回區塊中的兩個例子」，不要說「隔壁一格」。

### 一項措辭精確化，不是資料錯誤

`roi[5,5]`是指定／紅框像素的中心。偶數10×10窗口的精確幾何中心在四格之間；因此可說「紅框格子的中心座標」或「窗口中間附近的指定格」，不要稱此點為「整個ROI精確幾何中心」。目前figure只列所選格座標，未作後者主張。
