## 一條主線

**AI地圖如何把森林從一片綠變成六類，再讓我們讀懂真實像素輸出。** 一直跟同一2020 COG的兩個ROI走：A完成正常讀法，B完成不同結果的閱讀練習。六類定義與AlphaEarth機制只在解釋這份輸出時出現，不另開森林政策、模型排行榜或安裝支線。

建議分類：`ai-news`；格式：`slides`、教學卡片。不是安裝工具片，不為規則硬加寫程式任務。輸出成品是六分數與可用註記，觀看者可用紙筆或一般計算機完成。`RUN`來源／工具版本放來源欄；旁白不講73項查核、Range byte或製作過程來填長度。

**已具備：** 真實A/B完整小TIF、原始數值、原創PNG/SVG、獨立資料審查；協調者已render實看的三張繁中`assets/pixel-comparison.svg`、`assets/roi-a-scores.svg`、`assets/roi-b-scores.svg`與來源manifest。**待製作：** 其餘逐步中文卡、正式腳本、音訊、字幕、翻譯、縮圖與QA。comparison整圖放B結果揭露後；開場只用A結果，A-only格網由協調者另行提供。原創研究樣圖不當成成功App截圖；原生screencast只有實際捕捉成功後才加入。

## 概念與全口播內容

這裡規定「必須口頭交代什麼」，不是已定稿旁白。正式稿保留完整輸入、操作與結果；一句過長就拆句，不省略造成無法重算的數字。長網址／路徑不用唸。

### 六類：讓名詞能用在同一份資料

先說觀眾動作：「讀到類名，先對回它在這份圖裡的定義。」卡片與旁白完整涵蓋：

1. 原始林是原生樹種的自然森林，沒有明顯人為干擾跡象。
2. 自然更新林主要靠自然更新形成，也包括干擾後恢復的次生林；不能直接當成原始林。
3. 人工栽植林主要經栽植或播種形成；這份資料用超過四十年的操作性輪伐期區分。
4. 林木種植園指集約經營的森林；這份資料用四十年以內作操作性區分。
5. 樹木作物與農林複合包含油棕、橡膠、果園等農業樹作及混合系統，不能因為有樹就直接歸為森林用途。
6. 其他土地包含其餘類型，也能有稀疏木本、城市樹木與小樹片；不是「完全沒樹」。

類別3／4的40年是這份資料的proxy，不講成所有國家林業定義或法規判定。類名中文以此文件固定稱呼，官方英文與ID放對照表。必要的資料定義是教學內容，完整唸；HTTP測試與查核次數不唸。

### 機制：觀測訊號到模型分數

輸入是衛星觀測中的光譜、結構、空間與時間線索；AlphaEarth Foundations的表示把多年觀測濃縮成可用特徵，ForTy據此等訊號推測類別。畫面標「機制示意」。步驟三張：觀測 → 表示 → 類別分數。結果是每類分數，不是直接看到管理者意圖或地面歷史。

旁白要將「同樣有樹，結構和季節模式仍可能不同」連回六類為何能作為研究任務；不宣稱模型看穿土地權利、經營意圖或本次兩地的實際狀況。不加入參數量、訓練硬體或未查數據。

> 我們指定東經一百二十一點四、北緯二十四點七。

## 日期、證據與畫面文字

所有資料圖持續保留小標「2020基準模型輸出／本片裁切與實算」。首次畫面提供來源DOI與CC BY4.0；說明欄完整署名及改作。年度消息用另一種時間線欄，清楚標「2026-10-22介紹／2017–2025 early release」。論文的2026-10-21為date-only；Figshare2026-05-22 UTC對台北5/23；不自行替date-only補時區。

統一用語：模型分數（score）；單點實際正確率；地面真值；本地衍生分類；刻意選樣；唯一最高／並列最高。B的.344不是正確機率，A的.992也不是；不使用「確定」「證明現地」等延伸。兩點只說同一來源block，不說相鄰；窗口範圍只稱名目投影面積。

字幕與畫面同時出現的數值要一致；圖表正確的方向依source transform。長英文類名不擠進大字卡，必要時用ID＋短中文，下一行放官方英文對照。`stats`最多四項，六分數拆卡或改`table`；`table`六列符合上限。SVG進正式asset前拆圖、調中文字與字體並實際檢視，不能把研究大圖整張放滿一分鐘。

## 九語製作界線

繁中原稿先鎖定語義與資料，再做en、ja、ko、es、pt、id、vi、th的字幕、metadata、七個章名、縮圖文字與配音。每語走完整三遍：翻譯 → 留存批評 → 修訂；獨立核對後native merge，配音由協調者序列化執行。

翻譯不可改的內容：

- 六類英文ID及順序、類別3／4區分與Other範圍。
- A五值、和248、Other2、.992／.008；B五值、和164、Other86、.344／.004／.308／.344。
- B刻意選低分、不是隨機樣本；第2與第6類並列、沒有唯一最高；本圖本地取首規則，未核對官方硬分類tie。
- 2020資料年、2026發布日期與早期2017–2025序列；本次沒有年度像素結果。
- score未事後校準，不能替換成accuracy或現地正確機率；公司介紹／官方定義／本次實算各歸各的證據。

逐語max_chars依原生worksheet，不預設外語可塞與中文相同字數。小數的數值固定，口語與小數點格式依locale自然處理，但須能逐項回對原值。音色、速度、style用原生設定；不手改hash或跳音檢。主片CC與八外語字幕獨立掛載，不燒字幕。
