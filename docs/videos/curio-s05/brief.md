# 三顧茅廬，為何史書還寫諸葛亮自己上門？

奇聞檔案局 S 軸 S05。製作日期：2026-10-19。採事件型 A 案，現稿估約 8.1 分鐘；候選題庫的鉤子只作選題，事實以本集固定原文查核。影片從 227 年諸葛亮寫〈出師表〉開始，回到劉備與諸葛亮相遇的兩種文字，跟著裴松之比對其矛盾，最後追問《魏略》那條異說的消息來源能否查明。

## 問題

搜尋意圖：「三顧茅廬 是真的嗎」「諸葛亮 自己找劉備 魏略」「出師表 三顧 裴松之」。同一個結識過程，陳壽〈諸葛亮傳〉和諸葛亮〈出師表〉都說劉備去找諸葛亮；裴松之注引《魏略》，並說《九州春秋》記載相同，卻是諸葛亮主動北行拜見劉備。為何一部史書裡，見面的方向會互相牴觸？

## 一句答案

裴松之用〈出師表〉明確反駁《魏略》所述的諸葛亮先往說，認為兩種文字背離太大。他留下《魏略》引文，也提到《九州春秋》同說；但這段註沒有交代兩書各自的傳話來源，因此無法查明兩種初遇敘述何以分岔。

## 站主觀點

沿用 S 軸站主已定的立場：按史料形成時間與文本身分說故事，把當事人自述、陳壽正文、裴注引文和裴本人的判斷分開。這集不替古人補寫不存在的日程；讓觀眾學會問「這條異說的消息源在哪裡」。

## 編輯判斷

- **A 案（採用）**：沿《三國志》卷三十五閱讀：先聽徐庶的建議與劉備所問，再翻同卷裴注，看《魏略》怎樣改由諸葛亮走進去；跟裴松之核對〈出師表〉，最後追查反向記載的傳話線索。懸念是誰先上門、裴用何證據判斷，以及分岔的源頭是否可見。
- **B 案（備選）**：從《三國演義》的三趟訪問出發，逆推史料。可用於短片，長片易讓小說場面占過半，觀眾會混淆正文與後世增飾。

## 敘事大綱

| 節拍 | 發生的事與未解問題 |
| --- | --- |
| 227 年，寫下「三顧」 | 諸葛亮在〈出師表〉自述劉備三次到草廬。若當事人這樣寫，為何史書旁邊還留下相反方向？先埋諸葛亮北行去了哪裡、牛尾飾物怎麼引出對話、新野來勸劉備出門的人是誰三個具體疑問；最後一句回到新野，直接接徐庶登場。 |
| 徐庶不肯代請 | 陳壽寫新野的徐庶向劉備推薦諸葛亮，劉備先要他帶來，徐庶說應親自拜訪；劉備「凡三往，乃見」。原文未逐趟記日期和路線，卻記了私談與劉備的回應。旁白只留避曹判斷及「善」「情好日密」，立即翻同卷裴注：另一場初遇從哪來？ |
| 《魏略》的訪客反向走來 | 同卷裴注引《魏略》：劉備屯樊城，曹操將壓向荊州，諸葛亮主動北行求見。集會散後留下，有人剛送來犛牛尾，劉備自己編飾物；諸葛亮藉此開談。口播只取劉備承認兵少、諸葛亮提出游戶申報、劉備採計且待以上客，交代《魏略》如何把陌生訪客寫成相識的人；不展開戶籍行政過程。《魏略》沒有另記劉表是否下令。裴要怎麼判斷兩種初遇？ |
| 裴松之翻到〈出師表〉 | 《魏略》引文後，裴先補《九州春秋》同說，才以「臣松之以為」轉入自己的評語。若把草廬和樊城排成兩次會面，草廬在前會卡在《魏略》「備與亮非舊」；樊城在前又要解釋為何徐庶仍問劉備願否見亮。文本沒有把兩地排成行程的日期。裴引諸葛亮自述「先帝不以臣卑鄙，猥自枉屈，三顧臣於草廬」，說諸葛亮不可能先往見劉備，直言兩說背離可怪；他仍把被反駁的異說留在註裡。能再追到異說最初是誰講的嗎？ |
| 裴留下異說，傳話人卻未現身 | 《魏略》引文沒有標出初遇故事的最初講述者；裴補上《九州春秋》「所言亦如之」，卻未抄第二段原話，也沒交代兩書是否各自取材。陳壽〈諸葛亮集序〉同樣說三顧，仍是同一作者；〈出師表〉則是當事人自述，可支持裴對初遇方向的判斷，但不能僅因它未提牛尾細節就判場面絕不可能發生。 |

## 邊界

- 不把裴注引的《魏略》與《九州春秋》當成兩份保存完好的獨立現場證詞；可核原文是裴注的引述，後者僅以「所言亦如之」帶過。
- 不把劉備在新野、樊城的異地敘述硬拼成同一段有精確日程的旅行；《三國志》裴注另有約 207 年的推算，現稿不口播這段與異說來源無關的年份。
- 不說「諸葛亮沒有主動見過劉備」；裴反駁的是把**初遇**寫成諸葛亮先往的異說。
- 不把小說前兩次撲空、風雪、晝寢說成陳壽或〈出師表〉的細節；不引用不存在的逐字現場錄音。
