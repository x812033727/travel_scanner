# 三顧茅廬，為何史書還寫諸葛亮自己上門？

奇聞檔案局 S 軸 S05。製作日期：2026-10-19。採事件型 A 案，現稿估約 9.33 分鐘；扣除約 47 秒預告開場與片尾後，正文估 8 分 23 秒；候選題庫的鉤子只作選題，事實以本集固定原文查核。影片從 227 年諸葛亮寫〈出師表〉開始，回到劉備與諸葛亮相遇的兩種文字，檢查能否把兩次會面排成有憑據的先後，再看裴松之實際引用哪篇文字判斷，最後追問《魏略》異說的傳話來源能否查明。

## 問題

搜尋意圖：「三顧茅廬 是真的嗎」「諸葛亮 自己找劉備 魏略」「出師表 三顧 裴松之」。同一個結識過程，陳壽〈諸葛亮傳〉和諸葛亮〈出師表〉都說劉備去找諸葛亮；裴松之注引《魏略》，並說《九州春秋》記載相同，卻是諸葛亮主動北行拜見劉備。為何一部史書裡，見面的方向會互相牴觸？

## 一句答案

裴松之用〈出師表〉明確反駁《魏略》所述的諸葛亮先往說，認為兩種文字背離太大。他留下《魏略》引文，也提到《九州春秋》同說；但這段註沒有交代兩書各自的傳話來源，因此無法查明兩種初遇敘述何以分岔。

## 編輯判斷

- **A 案（採用）**：沿《三國志》卷三十五閱讀：先聽徐庶的建議與劉備所問，再翻同卷裴注，看《魏略》怎樣改由諸葛亮走進去；跟裴松之核對〈出師表〉，最後追查反向記載的傳話線索。懸念是誰先上門、裴用何證據判斷，以及分岔的源頭是否可見。

## 敘事大綱

| 節拍 | 發生的事與未解問題 |
| --- | --- |
| 227 年，寫下「三顧」 | 諸葛亮在〈出師表〉自述劉備三次到草廬。裴松之抄下另一段相遇故事後為何寫「可怪」？另埋牛尾飾物怎麼引出對話、新野來勸劉備出門的人是誰兩個具體疑問；最後一句回到新野，直接接徐庶登場。開場停在答案之前。 |
| 徐庶不肯代請 | 陳壽寫新野的徐庶向劉備推薦諸葛亮，劉備先要他帶來，徐庶說應親自拜訪；劉備「凡三往，乃見」。原文未逐趟記日期和路線，卻記了私談與劉備的回應。旁白聚焦「善」「情好日密」，再用關羽、張飛不悅與劉備的魚水比喻，證明正文把這場會談寫成兩人熟識的起點；此關係稍後會拿來核《魏略》的「備與亮非舊」。曹操戰略旁支已刪。同卷裴注的另一場初遇從哪來？ |
| 《魏略》的訪客反向走來 | 同卷裴注引《魏略》：劉備屯樊城，曹操將壓向荊州，諸葛亮主動北行求見。集會散後留下，劉備不先問這位來客的目的；有人剛送來犛牛尾，他自己編飾物，諸葛亮藉此開談。口播只取劉備承認兵少、諸葛亮提出游戶申報、劉備採計且待以上客，交代《魏略》如何把陌生訪客寫成相識的人；不展開戶籍行政過程。《魏略》沒有另記劉表是否下令。兩種初遇能否排成先後？ |
| 兩種會面順序接不上 | 影片試排草廬在前：正文「情好日密」與《魏略》樊城的「備與亮非舊」接不上。再試樊城在前：已成上客與徐庶仍問劉備是否願見亮接不上。兩篇不只沒有足以證成雙重初遇先後的日程，也沒有寫另一場已先發生的承接句。這只是旁白的假設檢驗，不冒充裴本人論證。裴實際拿什麼作判準？ |
| 裴引用〈出師表〉判誰先上門 | 《魏略》引文後，裴先補《九州春秋》同說，**才**以「臣松之以為」轉入自己的評語。他讀諸葛亮自述從布衣躬耕、先帝屈尊三顧、問事到答應效力的順序；奏章自己說距答應效力已有二十一年，故是當事人回憶、非當日日記。裴引「先帝不以臣卑鄙，猥自枉屈，三顧臣於草廬，諮臣以當世之事」，說諸葛亮並非先往見劉備，直言兩說背離可怪。可怪的不是從前面試排推算出來，而是裴按奏章的行動者作出的明白判斷。異說最初從誰傳來？ |
| 裴留下異說，傳話人卻未現身 | 《魏略》引文沒有標出初遇故事的最初講述者；裴提《九州春秋》「所言亦如之」，卻未抄第二段原話，也沒交代兩書是否各自取材。陳壽〈諸葛亮集序〉同樣說三顧，仍是同一作者；〈出師表〉則是當事人自述。片尾回收標題：同一卷會同見兩方向，是正文與裴保留、反駁的引文同在，不等於裴支持反向初遇。 |

## 邊界

- 不把裴注引的《魏略》與《九州春秋》當成兩份保存完好的獨立現場證詞；可核原文是裴注的引述，後者僅以「所言亦如之」帶過。
- 不把劉備在新野、樊城的異地敘述硬拼成同一段有精確日程的旅行；《三國志》裴注另有約 207 年的推算，現稿不口播這段與異說來源無關的年份。
- 不說「諸葛亮沒有主動見過劉備」；裴反駁的是把**初遇**寫成諸葛亮先往的異說。
- 不把小說前兩次撲空、風雪、晝寢說成陳壽或〈出師表〉的細節；不引用不存在的逐字現場錄音。
