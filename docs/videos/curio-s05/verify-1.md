# S05 獨立史料與敘事覆核

2026-10-19，第二位讀者在未參與撰稿的情況下，對照 [`video.json`](video.json)、[`claims.md`](claims.md) 與 [`research.md`](research.md) 所列固定版《三國志》卷 35、《三國演義》第 37–38 回，逐句檢視 113 句旁白。最新稿另以獨立盲讀完成 13／13 題，`narrative` 判定通過；系列 `lint` 為 0 錯誤、0 警告。

| 關鍵主張 | 查核結論 |
| --- | --- |
| 「凡三往，乃見」與「三顧臣於草廬」 | **通過**。《三國志》正文記劉備往見，〈出師表〉是諸葛亮其後的第一人稱追述。這些文字不提供三趟的逐日行程或天氣。 |
| 《魏略》稱諸葛亮先往見劉備 | **通過，限於裴松之注的引述**。裴引異說後援引〈出師表〉駁斥；影片以兩種相背記載呈現，沒有編造可兼容的行程。 |
| 約 207 年相遇 | **通過，屬裴松之倒推**。以 208 年敗退、227 年上表及表內「二十有一年」推算；旁白沒有指定某日。 |
| 風雪、晝寢、張飛揚言放火 | **通過，限後世小說**。《三國演義》第 37–38 回有這些場面；影片沒有把它們說成三國時的現場紀錄，也沒有演成真的縱火。 |
| 荊州、益州策略與登記游戶 | **通過，分屬兩版對話**。前者在陳壽正文，後者在裴注引《魏略》；並非合併成一次可確證的對話。 |

未見需擋下製稿的重大史料出入。固定版本連結和每句來源範圍見 [`research.md`](research.md)、[`claims.md`](claims.md)。史書與奏章仍是傳世文字，不能證明人物容貌、每次拜訪的準確日期或小說細節；插圖按情節層級呈現，不作現場重建。
