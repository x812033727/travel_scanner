## 不足以說成定論的問題

1. **當年的動機與損益**：公司史把「從開始附保證」說清楚，Smithsonian 館藏目錄說創辦人不喜歡計畫淘汰，但沒有此輪可直接閱讀的 1933 年原始保證卡或分品項維修成本。旁白不說他「靠燃料與耗材賺回保修費」。[M03]
2. **戰時故事**：公司回顧中的軍方供應不是每位士兵的持有紀錄；戰爭不是保修效果的實驗。[M06]
3. **歷史與現行政策不可混同**：1930 年代有公司的承諾敘述；現行美國功能範圍、英國內膽處置與 Arc 保固是不同來源、不同時地，不能倒寫成 1933 年的詳細條款。[M03、M08–M12]
4. **產量與環境效果不可倒推**：第六億支是截至 2020 年的累計生產節點。公司另有「可重複用減少丟棄」的自述，但未在此輪找到可獨立覆核的生命周期比較，故企劃不報減碳、減廢總量或保修帶動多少銷量。[M13]
5. **原始專利與影像**：專利圖可查機件，但只作資料閱讀，插畫不照描專利線條；專利 PDF 若未來匯入主機工人，需標 `reviewer_only` 或補工人可直接讀的原件 HTML。
