# S04 周瑜病逝：史料讀本與界線

查核日：2026-10-19。這集問「周瑜真的是被氣死的嗎？」答案應分成兩層：傳世史書明寫 **病卒**，另記他病困時安排繼任；「被諸葛亮三氣而亡」是《三國演義》的情節。史書沒有病名，也沒有驗證死因的醫療資料，不能反向確診舊箭傷或另一疾病。

## 能逐字對的敘述

| 事項 | 來源原句 | 正片可說的話 |
| --- | --- | --- |
| 孫策舊交 | SZ54〈周瑜傳〉：「策與瑜同年，獨相友善。瑜推道南大宅以舍策，升堂拜母，有無通共。」 | 兩人同年，孫策借住周瑜讓出的房子，關係親密。不能拍成確定的結義儀式。 |
| 歷陽迎接 | SZ54：「會策將東渡，到歷陽，馳書報瑜，瑜將兵迎策。」 | 孫策**將**東渡時先到歷陽、致書周瑜；周瑜率兵相迎。不能說已渡江後才相會。 |
| 「周郎」與樂曲 | SZ54：「瑜時年二十四，吳中皆呼爲周郎」；「瑜少精意於音樂，雖三爵之後，其有闕誤，瑜必知之……『曲有誤，周郎顧。』」 | 「周郎」是當時稱呼，聽出錯音後回頭是傳中軼事；「三爵」是飲酒量的原文，不必畫成固定舞台。 |
| 赤壁決策 | SZ54〈周瑜傳〉載曹操南下時，劉琮降曹，荊州水軍落入曹手；周瑜在軍議中主戰，分析北軍不習水戰、水土與疾病風險。裴注另指出魯肅此前也主張抗曹，陳壽本文未完整呈現。 | 周瑜在抗曹與赤壁作戰有明確角色，魯肅的前議不能抹去；不把聯軍成果全歸周瑜，也不演成他全程只妒忌諸葛亮。 |
| 黃蓋火船 | SZ54〈周瑜傳〉：「初一交戰，公軍敗退，引次江北，瑜等在南岸……操軍船艦首尾相接，可燒而走也……實以薪草，膏油灌其中……先書報曹公，欺以欲降……又豫備走舸各系大船後……悉延燒岸上營落。」 | 赤壁初戰曹軍退到江北，黃蓋見連舟可燒，假寫降書，以柴草油料和幔布遮火船、後繫小舟備退，火蔓延到岸營。這是史書作戰敘述，不畫小說式超自然東風。 |
| 南郡箭傷 | SZ54：「瑜親跨馬擽陣，會流矢中右脅，瘡甚，便還。後仁聞瑜卧未起，勒兵就陣。瑜乃自興，案行軍營，激揚吏士，仁由是遂退。」 | 周瑜在對曹仁的南郡戰事中右脅中流箭，傷重返營；仍起身巡營激勵士兵，曹仁退。**沒有**說這傷後來復發致死。 |
| 對劉備的意見 | SZ54：「愚謂大計宜徙備置吳……分此二人，各置一方……權以曹公在北方……故不納。」 | 周瑜曾主張把劉備留在吳地、分開關張；孫權沒有採納。這是不同政治判斷，不等於被諸葛亮氣到失去理智。 |
| 新作戰構想 | SZ54：「乞與奮威俱進取蜀，得蜀而并張魯，因留奮威固守其地，好與馬超結援……瑜還與將軍據襄陽以蹙操……權許之。瑜還江陵，爲行裝。」ZZTJ 指明奮威為孫瑜。 | 周瑜提出與孫瑜西取益州、處理張魯、結援馬超、再圖襄陽的方案；孫權同意，他回江陵整裝。這些是**計畫**，不能說取蜀已開打或成功。 |
| 途中病逝與年齡 | SZ54：「瑜還江陵，爲行裝，而道於巴丘病卒……時年三十六。」裴注：「所卒之處，應在今之巴陵，與前所鎮巴丘，名同處異也。」ZZTJ 將此段列於建安十五年（210）。 | 210 年江陵整裝後**已上路**，在史書稱「巴丘」處病逝、年三十六；不能說「未能出發」。裴松之提醒同名地點不能混為前一處巴丘；正片避免畫現代精確定位。 |
| 病困與繼任 | SZ54〈魯肅傳〉：「周瑜病困，上疏曰……魯肅智略足任，乞以代瑜。」裴注引《江表傳》異文：「道遇暴疾，昨自醫療，日加無損……魯肅忠烈……可以代瑜。」並指出兩版本辭句不同。 | 周瑜病困時已有推薦魯肅的文字；裴注版描寫途中急病並治療。史書沒有病名、沒有證據判定箭傷引起或情緒造成。若引信中文字，必點明是哪一版。 |
| 早識魯肅與承接 | SZ54〈魯肅傳〉：「瑜因薦肅才宜佐時」；周瑜死後「即拜肅奮武校尉，代瑜領兵……令程普領南郡太守。」 | 魯肅非臨終突然現身；周瑜早年曾向孫權推薦他，後來魯肅接其部眾、程普接南郡。 |
| 孫權反應 | SZ54〈周瑜傳〉：「權素服舉哀，感慟左右」，裴注引《江表傳》：「公瑾有王佐之資，今忽短命，孤何賴哉！」 | 孫權舉哀並安排喪事；「王佐之資」是裴注引書的孫權評語，不能當原音。 |
| 程普相處 | SZ54 本文：「性度恢廓，大率爲得人，惟與程普不睦。」裴注引《江表傳》：「普頗以年長數陵侮瑜。瑜折節容下，終不與校……『與周公瑾交，若飲醇醪，不覺自醉。』」 | 本傳承認起初不睦；裴注說周瑜不與程普計較，後來程普敬服。這是性格材料，**不能**證明周瑜從未憤怒。 |
| 小說的三氣 | YY 第 51 回先有周瑜佯裝病危設伏曹仁，後有南郡失算、箭瘡迸裂；第 54 回寫聯姻計，第 55 回寫劉備、孫夫人脫身與「二氣」；第 56 回回目標「三氣」，第 57 回寫諸葛亮的西川警告書到達。周瑜**先**寫給孫權、囑咐將士，然後昏厥、醒來喊「既生瑜，何生亮！」而亡。 | 明確標成**小說**。第 51 回佯裝病危不能當真病況；第 57 回的怒氣致死因果只屬小說敘述，不能把信件與昏厥拍成讀完即倒。 |

## 不可偷渡的推論

1. 「史書沒寫諸葛亮氣他」不足以證明他一生從未被人惹怒；本集只回答**沒有史料能支持三氣致死，傳中寫病逝**。
2. 南郡右脅箭傷確有記載；但把 210 年急病診斷為箭傷感染、舊傷復發、肺炎或其他病，都是缺證猜測。
3. 《江表傳》在裴注中的周瑜臨終箋、陳壽本文中的上疏，**意旨相近而措辭不同**。不拍成一份可以驗證字字都是周瑜親筆的原件。
4. 程普的稱讚與「曲有誤」是關於人際與音樂的材料，不是醫療病因證據；現版劇本不使用這兩段軼事，避免偏離已獲准的取蜀旅程。
5. 插圖是史書和小說的可愛示意，非歷史人物真實容貌、傷口或巴丘地點重建。舊箭傷可用衣物遮擋、不畫血或開放性傷口；病逝只畫空座與收起的地圖。
