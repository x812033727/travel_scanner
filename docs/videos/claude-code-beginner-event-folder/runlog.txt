3. **剔除不該寄的。** 備註寫「取消」的人和測試資料，不放進寄信名單。
4. **挑出資料有問題的。** 沒有 Email 或格式不對的人，放進 `輸出/要補資料.csv`，之後由你去問對方。
5. **整理出寄信名單。** 剩下的人加進 `輸出/確認信名單.csv`。部門名稱會統一成行銷部、業務部、研發部、人資部、財務部這五種。

> 6. 備註或報名表裡寫想改成線上參加的人，另外列進 輸出/改線上名單.csv（他們仍留在確認信名單，不要刪）。
