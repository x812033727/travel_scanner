## 這個檔案每一段在做什麼

**最上面（第 1–5 行，兩條 `---` 中間）是這個技能的名片。**
它告訴 Claude 這個技能是做什麼的：檢查講座報名表，產出寄信名單、要補資料名單和處理日誌。它也寫了什麼時候該啟動：有新的報名表進來，或有人說「檢查報名」。

**第 7 行「報名表檢查」是標題，沒有功能。**

**下面六步是 Claude 實際要做的事：**

1. **先讀資料。** 它讀你指定的報名表，沒指定就讀 `報名表.csv`。它也讀 `活動說明.md` 和現有的 `輸出/確認信名單.csv`。讀現有名單，是為了知道誰已經在上面了。
2. **去重複。** 同一個 Email 填了兩次，只留最後一次。名字一樣但 Email 不同，算兩個人。已經在名單上的 Email 不會再加一次。
3. **剔除不該寄的。** 備註寫「取消」的人和測試資料，不放進寄信名單。
4. **挑出資料有問題的。** 沒有 Email 或格式不對的人，放進 `輸出/要補資料.csv`，之後由你去問對方。
5. **整理出寄信名單。** 剩下的人加進 `輸出/確認信名單.csv`。部門名稱會統一成行銷部、業務部、研發部、人資部、財務部這五種。
6. **統計並寫日誌。** 它算出素食、過敏、其他忌口各有幾位，連同這次做了什麼，一起寫進 `輸出/處理日誌.md`。
