# 講座籌備資料夾規則

1. 不要刪除任何檔案；要淘汰的檔案，移到 `_封存/` 子資料夾，不要直接刪。
2. 不要覆蓋或改寫既有檔案；要修改時另存新檔，檔名加日期（例如 `_2026-10-21`），或先徵得我同意。
3. 簡報大綱有多個「最終版」時，以檔案修改時間最新的為準，並在整理時告訴我你採用哪一份；不要自行合併內容。
4. `報名表.csv` 含個人資料（姓名、聯絡方式），不要複製到其他檔案、不要貼進對話摘要，也不要上傳或傳送到外部服務。
5. 檔名使用繁體中文，格式為「主題_版本或日期」；重新命名前先列出「舊名 → 新名」給我確認。
6. 整理完成後，簡短回報動了哪些檔案（移動、新增、改名）；沒有動的檔案不用提。
