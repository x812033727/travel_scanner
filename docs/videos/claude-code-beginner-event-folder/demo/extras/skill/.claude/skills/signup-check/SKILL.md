# 報名表檢查

1. 讀要檢查的報名表（沒指定就讀 報名表.csv）、
   活動說明.md，和現有的 輸出/確認信名單.csv。
2. 同一個 Email 只留最後一次；同名但 Email 不同，
   當成兩個人。已經在名單上的 Email 不重複加。
3. 備註寫「取消」的人和測試資料，不放進寄信名單。
4. 沒有 Email 或格式不對的，加進 輸出/要補資料.csv。
5. 其餘加進 輸出/確認信名單.csv，部門統一成
   行銷部、業務部、研發部、人資部、財務部。
6. 算出素食、過敏、其他忌口各幾位，連同做了什麼，
   寫進 輸出/處理日誌.md。
