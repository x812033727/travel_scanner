# 照片信任長片：開場與包裝修改

日期：2026-09-29。狀態：獨立審片新版，未替換正式後台版本，未發布。

## 這次修改

- 標題改為「照片是真的，故事就是真的？轉傳前先查這3件事」。
- 縮圖改為「真照片／假故事」，用同一張示意圖搭配不同標題，對應正片的問題。
- 原先約 49 秒的開場，先問觀眾選圖，再撤回真假測驗。本版直接演示同圖換上「新品上市」「店家停業」「五年前活動」，然後交付查證的三個方向；實際新時長以 technical-report.json 為準。
- 第二段區分圖裡看得到的內容與文字額外帶入的解釋。
- 第八段改為回扣同一張排隊圖；結尾回應新標題。
- 來源憑證卡片改成「建立方式／修改紀錄／事件仍需查證」，不暗示每份憑證都驗證人的身分。

全程標示虛構示意，不主張三種說明已經證實、也不把三者都判成假。縮圖是生成的概念圖，不是真實商家新聞。

## 獨立來源查核

由另一審稿代理重新閱讀原稿與官方頁面，2026-09-29 核對：

| 主張 | 判斷 | 官方依據 |
| --- | --- | --- |
| 來源追蹤、水印與偵測回答不同問題 | 支持；保留概念拆解，不捏造偵測準確率 | [NIST 2024 報告](https://www.nist.gov/publications/reducing-risks-posed-synthetic-content-overview-technical-approaches-digital-content) |
| 沒有來源憑證不等於假；有憑證不保證事件真實 | 支持；資料加入為選擇性，可能移除，來源資料本身不能決定內容真偽 | [C2PA 2.4 Explainer §7.1.2、§7.2.2、§7.2.3](https://spec.c2pa.org/specifications/specifications/2.4/explainer/Explainer.html) |
| 憑證必然指出真實作者身分 | 不支持這種強推論，因此修正卡片 | [C2PA §7.2.4](https://spec.c2pa.org/specifications/specifications/2.4/explainer/Explainer.html) |
| 看起來逼真且有實質生成／修改的內容需揭露 | 支持原稿的條件式措辭 | [YouTube 官方說明](https://support.google.com/youtube/answer/14328491?hl=en-GB) |

## 任務分工與驗收界線

使用者指定 Shorts 由另一對話處理。本版不包含 shorts 欄位，不執行整季 CLI、不改共用 season-one 原稿、快取或工具。所有新音訊、字幕、章節及影片輸出到獨立 repo 外資料夾。

尚未取得頻道 CTR／留存資料；這是可驗證的編輯改善假設，不能預告流量增幅。技術解碼、響度和抽幀檢查也不能代替完整人耳聽審、最終畫面驗收或實際觀眾數據。

前 30 秒驗收項目：觀眾看到的圖保持不動、三個標題依聲音切換、示意標記一直可見、承諾與縮圖一致。正式回送審核時須綁定新檔案雜湊，不能沿用舊版核准。
