# 網美小豬 EP1〈夕陽海邊〉

## 故事前提

小豬粉粉在海邊夕陽下拍出雜誌封面般的美照——鏡頭一拉遠，是夜市後巷：夕陽是掛在晾衣竿上的保溫燈、大海是被抖動的藍色防水布、她站在倒扣的水桶上。畫面外，水豚男友面無表情地一手高舉手機、一腳抖防水布、頭頂綁著電風扇。成品照裡的夕陽是一張水豚的臉；她重擺姿勢，水桶裂開下沉，水豚的臉又慢慢升進燈裡。

## 角色

- 粉粉（fenfen）：粉紅小豬，白色蕾絲洋裝、大草帽配粉紅緞帶、珍珠髮夾，永遠同一個唯美側臉。
- 水豚男友（capy）：綠色漁夫帽、灰 T 恤，永遠面無表情，脖子上掛行動電源。

## 站主觀點

零台詞系列（盲評第二批第 2 名，中位數 84）。網美照 vs 現實：唯美特寫 → 拉遠揭曉假景 → 揭曉畫面外的男友 → 成品照的破綻 → 重擺、loop。小豬和水豚永遠不同框。

## 格式

- 9:16 Shorts／Reels，約 16 秒，零台詞；Colab 首格與 H3 片段。

## 大綱

### 選項 A：夕陽海邊
一行說明：夕陽美照 → 閃光、眼珠一瞄 → 拉遠是夜市後巷 → 男友在畫面外撐場 → 成品照的夕陽是水豚臉 → 重擺、水桶裂 → 水豚臉又升進燈裡。
開場鉤子：完美的夕陽側臉，但夕陽底下垂著一條電線。
