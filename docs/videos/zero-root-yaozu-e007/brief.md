# 《長燈村：零靈根的我被一村妖祖養大》第 7 集〈她說你偷的〉

## 故事前提

第 6 集收在第十天早上的村口：一聲銅鑼，玄穹宗執事錢通奉命追回「失竊靈石」，褐袍弟子一排推開村民，錢通的令牌直直指著陸拾：「就是他。」第 7 集接到當天午後的胡家院門口：錢通令牌往屋裡一指：「搜！」兩個弟子踹開院門，床板被掀起來、米缸被推倒、白米灑了一地，雞籠也被踢翻，陸拾衝口而出：「那是我奶奶的雞！」奶奶背挺得筆直站在屋簷下，團團抱著她的圍裙悄悄說：「團團算過了，他們找不到。」一個弟子嫌門口的燈籠礙事：「這破燈礙事。」抬腳要踢——全村的人同時往前一步，長長的影子一齊壓過去；三嬸把鐵錘拍在掌心：「燈，不准碰。」弟子把腳放下、往後退，錢通看在眼裡：「一盞破燈……這麼要緊？」回到被翻爛的屋裡，錢通笑著說：「三十二顆，交出來。」陸拾一驚：「你怎麼知道……三十二？」錢通指了指自己的眼睛：「我的人，看得清清楚楚。」他抖開一封信：「雲師姐親口說——是你從她房裡偷的。」陸拾湊近看，一個字都看不懂；錢通大笑：「零靈根，還是個睜眼瞎。」陸拾急著要說「是雲師姐給——」，錢通眼睛一亮：「說啊，她也得陪你受審。」門口的奶奶低低叫了一聲「拾兒。」陸拾咬牙抬起下巴：「撿的。」錢通倚著門框冷笑：「又是撿的？」兩個弟子抱著院裡的大石水缸怎麼也搬不動：「這缸……搬不動！」陸拾一個人一推就把水缸推倒，水沖了滿院：「要搜，自己看。」錢通的笑僵在臉上：「零靈根……力氣倒不小。」他把一捆發著金光的縛仙索甩在桌上：「交出靈石，或者——回宗對質，她陪你受審。」陸拾的手在那封讀不懂的信上慢慢握成拳；「想好了嗎？」他回頭看了看翻倒的床，跪下去，手慢慢伸向床邊那塊鬆動的地磚。
