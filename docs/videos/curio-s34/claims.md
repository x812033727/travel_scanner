# S34　影片稿主張與來源對照

- 查核日期：2026-10-19。範圍：`video.json` 現存的 **94 句** `ed001`–`ed100` 旁白（`ed007`、`ed067`、`ed093`–`ed096` 已刪除）、2 張日期資料卡、片尾、縮圖、YouTube 文案及分鏡中的可查核敘事。
- 來源為薛克頓事後出版的《South!》及書中收錄的日記；章節與原始行號對應文末固定版本。問句、情緒與結尾詮釋仍列入相鄰段落，以便逐句覆核。這不是逐字人物對話的授權。
- **適用對象**：`28 人` 均指堅忍號所在的威德爾海隊；遠征另有羅斯海支隊。`miles` 保留原書單位，不任意換算。
