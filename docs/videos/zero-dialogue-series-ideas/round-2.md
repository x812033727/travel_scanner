# 零台詞短劇：新系列企劃第二批（2026-11-03）

接在 [`README.md`](README.md) 的第一批後面。目標一樣：不靠台詞就好笑、可以每集換一個物件或情境就套用的系列，
這次再發想 8 個，和已經在做或已經企劃過的系列都不重疊（《汪家夫妻》《闖禍小浣熊》《企鵝與河馬合租》
《樓上住了一隻熊》《綿羊理髮廳》《金魚老大》《倉鼠想變壯》）。這一份是企劃與盲評結果，還沒有進劇本關卡，也還沒花任何錢。

設計時照第一批學到的製作限制：寫實擬人化動物、世界裡沒有人類與真實品牌；**每一鏡只放一個主角**，
第二個角色用背影、畫面邊緣（虛焦）或下一鏡的反應鏡處理；笑點那一格寫成角色**本身**的樣子；
不拍吃喝、看得懂的字、兩個角色碰觸的過程與手指拿小道具的特寫；每鏡一件事，成片 13–18 秒、5–7 鏡。
公式照舊：一個人人懂的衝突 → 角色演出來的停頓 → **跳過過程，直接給荒謬的結果** → 補刀；收尾不用「對鏡頭甜笑」。

### 怎麼讀這些分數

- **〈花瓶〉這次拿 85**（第一批同一個系列的盲評稿拿 89）。換一組評審、換一批對手，同一份東西差了 4 分，
  雜訊大約就是 ±3–4 分。所以：第 1、2 名（85、84）**和〈花瓶〉同一級**，但沒有超過它；
  第 3 名（79）明顯低一截；第 4–7 名（76–71）是同一群；第 8 名（57）是真的不行，三位都在第 2 或第 4 鏡就想滑走。
- 「最想追看」三票裡〈花瓶〉拿兩票（已婚、導演，理由都是「全家裝成家具這個格式每集都能換」），
  20 歲那一票給《網美小豬》（「工具人男友這組 CP 每集換一個打卡場景都能套」）。也就是說，
  **這批沒有一個系列的「想追」強過《闖禍小浣熊》**；《網美小豬》是唯一贏過它一票的。
- 文字評審看不到表演、停頓和畫面那一格的笑（`.agents/skills/animation-preproduction/references/comedy-review.md` 的〈校準〉），
  分數只用來**排名與找問題**。改過的 EP1（下面三份）**還沒有再評**；要再評就換一組新評審，照 `comedy-review.md` 的流程。

## 評審最常提到的問題

1. **第一格還是太平**（九份裡六份被點名：小豬、阿嬤、夜市、樹懶、孔雀、鴕鳥）。評審要的是「第一格就有破綻」：
   唯美照的角落露出一截電線、噴嚏的同一格背景那顆殼就抖一下、樹懶直接從白煙裡開始。第一批學到的這一條還是最常犯。
2. **結尾被前一鏡搶走**：小豬的 s05 成品照比 s06 好笑、颱風天的「颱風眼」和「吹回家」兩個收尾互搶、
   大象的 s05 溫馨美景讓喜劇節奏斷掉。最強的那一格要放在倒數第一或第二，後面只留一個很短的鉤子。
3. **觀眾看到角色就猜到答案的梗會被扣 surprise**：「樹懶很慢」「其實考很好」「比大的就是更大的贏」「阿嬤覺得你冷」。
   評審不反對熟梗（阿嬤還是第 1 名），但反轉要做在熟梗**反方向**（樹懶最後「快」到把整座廟留在原地、
   新娘只開一根羽毛就贏），不能停在大家預期的那一格。
4. **前提要人人有份**：《夜市對面攤》墊底不是畫面不好，而是「兩攤比誰的棉花糖大」沒有人有過這個經驗；
   三位都說要先立好「搶客人」（對面大排長龍、自己這攤沒人）。
5. **最好的點子要提早埋**：夜市的螞蟻排隊、颱風天的打卡鐘、阿嬤的棉被，評審都希望在前面先露一眼，最後才兌現。
6. **空拍會被點名**：孔雀的揮手、大象女兒單獨的「準備彈琴」、阿嬤第一格的小噴嚏。一鏡只做一件事，但那件事要推進衝突。
7. **評審常常開出要「寫字」的藥方**（手機跳出「明日停班停課」、考卷名字欄寫著隔壁同學、打卡紙印 09:00、新花瓶的價格標籤）。
   這些違反「不要看得懂的字」的限制，不能照抄；但它們指出的是同一件事：**要一個台灣人一秒懂的生活符號**。
   改寫時用圖像代替：紅色漩渦的颱風圖示、空白的打卡鐘指針指在正九點、笑臉印章。

## 第 1 名《阿嬤覺得你會冷》（EP1 中位數 85，和〈花瓶〉同分）

**一句話設定**：烏龜阿嬤只要看到孫子有一丁點「冷」的跡象，下一秒孫子就被包成一個荒謬的東西；而阿嬤自己永遠穿得最清涼。

**固定角色（外觀錨點）**

| 角色 | 外觀 |
| --- | --- |
| 烏龜阿嬤 | 紫色碎花背心、花布袖套、碎花頭巾、老花眼鏡掛在脖子上；動作很慢，**頭從殼裡伸出來**是她的招牌停頓 |
| 小水獺阿弟 | 細瘦、短袖 T 恤加短褲、背著小書包；被包起來時只露出兩隻眼睛和一撮鬍鬚 |

固定場景：盛夏的老公寓（窗外大太陽、電風扇、紗窗、塑膠椅），每集換一個出門或在家的情境。

**固定笑點機制**：孫子一個極小的「冷」的訊號（小噴嚏、抖一下、一陣小風）→ **阿嬤的頭慢慢從殼裡伸出來、推一下老花眼鏡**（停頓）→
**跳過**包的過程，直接看到孫子變成一顆球、一條春捲、一個浮標 → 升級：孫子流一滴汗，阿嬤以為發燒，再加碼 →
補刀：阿嬤自己吹冷氣、泡冰水，或下一輪又要開始。

**為什麼關靜音也好笑**：「阿嬤覺得你冷」是台灣每個人都被做過的事，一張「布球只露兩隻眼睛」的截圖就懂；
冷熱對比全在畫面上（大太陽、汗、冒煙的布球、泡冰水的阿嬤），不用任何字。會被轉到家族群組，也會被年輕人轉給表兄弟姊妹。

**AI 製作風險**

- 低：最好笑的那一格是**靜止的布球**加兩隻眼睛，沒有角色碰觸；包的過程完全跳過。阿嬤與孫子永遠不同框（阿嬤在畫面邊緣虛焦時只露殼）。
- 中：「布球只露眼睛和鬍鬚」要先做一張首格，確認模型不會把水獺畫到球外面；暖暖包要寫成「白色方形貼片」，不能有字。
- 中：烏龜頭從殼裡伸出來是全系列的招牌鏡，要用 H3 測一次動作是否順（慢速、直線往前），不順就改成靜圖加推鏡。
- 注意：不拍喝熱湯、吃東西；「冰水盆」只泡腳。

### EP2〈出門上學〉

早上小水獺穿短袖要出門，一陣很小的風吹動門簾，他的毛翹一下 → 阿嬤的頭從殼裡伸出來 →
**跳過**：玄關立著一捲棉被捲成的「春捲」，只露出眼睛和兩條書包背帶，旁邊擺一雙雨鞋 →
春捲要跨出門檻，卡住，整捲慢慢往後倒 → 補刀：鏡頭往巷子裡一看，對面三戶人家門口也各立著一捲春捲，只露出不同動物的眼睛（全巷的阿嬤都一樣）。

### EP3〈游泳課〉

小水獺換好泳褲要去游泳課，站在池邊抖一下 → 阿嬤的頭從殼裡伸出來 →
**跳過**：池子裡浮著一個水獺形狀的浮標：羽絨衣、毛帽、身上套了三個游泳圈，只有眼睛露在水面上 →
升級：其他泳道的水花都濺不到他，他在原地慢慢打轉 → 補刀：池畔的躺椅上，阿嬤戴著墨鏡、穿著碎花泳衣，殼上插一把小陽傘，正在做日光浴。

## 第 2 名《網美小豬》（EP1 中位數 84；新系列唯一拿到「最想追看」票）

**一句話設定**：每張網美照都美得像雜誌封面，但鏡頭一拉遠，就是水豚男友在畫面外用最荒謬的方法硬撐出來的。

**固定角色（外觀錨點）**

| 角色 | 外觀 |
| --- | --- |
| 小豬粉粉 | 粉紅小豬，白色蕾絲洋裝、大草帽配緞帶、珍珠髮夾；永遠擺同一個側臉角度 |
| 水豚男友 | 綠色漁夫帽、灰 T 恤，永遠面無表情；身上總掛著一堆打光、吹風的雜物 |

固定場景：每集換一個「唯美打卡景點」，而揭曉後永遠是同一個台灣日常的角落（夜市後巷、頂樓水塔、騎樓、停車場）。

**固定笑點機制**：唯美特寫（但角落已經露一點破綻）→ 快門閃光，她的臉不動、只有眼珠一瞄（停頓）→
**拉遠揭曉**：景是假的 → 再揭曉：男友在畫面外做什麼 → 成品照裡有一個男友的破綻 → 補刀：她重擺，破綻又出現（loop）。

**為什麼關靜音也好笑**：「網美照 vs 現實」是大家都看過的對比格式，一拉遠就懂，不用任何字；
工具人男友是可以直接標記朋友的角色（20 歲評審：「會丟給有在幫女友拍照的朋友」）。成品照那一格本身就是一張可以截圖的圖。

**AI 製作風險**

- 低：小豬和水豚**永遠不同框**（揭曉景、揭曉男友、成品照各一鏡）；沒有碰觸、沒有吃喝。
- 中：成品照的「有臉的太陽」要畫成水豚的臉被橘光照成圓形，先做一張首格；照片外框不要有任何介面或字。
- 中：手機只拍「舉得高高的」中景，不拍手指和螢幕；保溫燈、防水布、電風扇都不能有品牌。
- 不採用：評審建議讓水豚嘴裡咬著行動電源，嘴裡咬東西會被讀成吃東西，改用掛在脖子上。

**一句話設定**：颱風天沒放假的狐獴上班族，每次出門都被風吹到荒謬的地方，但他從那裡照樣把今天的任務完成。

- **EP1〈發考卷〉**（盲評稿）：考卷背面透紅光、鬼片音效 → 脖子縮、眼鏡滑到嘴喙 → **跳過**：頭插進桌面、身體端坐 →
  桌子底下她和抽屜裡一疊更舊的紅光考卷對望 → 風扇把考卷翻面：紅色笑臉印章 → 她把整片桌面套在脖子上走出教室。
- **EP2〈家長會〉**：門外傳來媽媽的高跟鞋聲 → **跳過**：頭插進教室地板，身體立正 → 補刀：地板底下是樓下的教室，她倒著和樓下也把頭插進天花板的另一隻鴕鳥對望。
- **EP3〈健康檢查〉**：輪到量體重 → **跳過**：頭插進體重計裡 → 補刀：體重計的指針因為她的頭轉了一圈又一圈。
- **評審的問題**：「其實考很好」大家都等著（導演）；抽屜那疊舊考卷代表她以前都考爛，削弱了這次的反轉——20 歲建議抽屜裡也全是笑臉，
  代表她每次都嚇到鑽桌子，反轉才回頭看合理；s06 她挺胸走出去的動機不清楚，要先讓她看到笑臉、眼睛一亮。

### 第 8 名《夜市對面攤》（EP1 中位數 57）

- **一句話設定**：夜市走道兩邊面對面的石虎與獼猴，兩攤賣一樣的東西，每晚都要比誰的更大。
- **固定角色**：石虎老闆（額頭兩道白紋、紅頭巾、黑圍裙）、獼猴老闆（紅臉、黃背心、反戴鴨舌帽），永遠用正反拍分開。
- **固定笑點機制**：對面加碼 → 瞇眼（停頓）→ **跳過**：自己這攤已經荒謬地更大 → 對面再加碼 → 反轉：兩攤一起被自己的東西反咬 → 補刀。
- **為什麼關靜音也好笑**：大小對比與「棉花糖雲下起粉紅雨」都是畫面；但前提沒有共鳴，見下。
- **AI 製作風險**：中；夜市容易被生出人群與招牌字，要寫死空的走道；粉紅雨與塌下來的糖雲需要特效級的首格。
- **EP1〈棉花糖〉**（盲評稿）：石虎仰頭撐著比頭大的棉花糖，對面更大的粉紅影子蓋過來 → 瞇眼 → **跳過**：一團雲那麼大的棉花糖綁在攤車上 →
  獼猴坐在粉紅積雨雲頂 → 粉紅雲真的下雨，白雲塌下來埋住石虎 → 一排螞蟻排隊到他攤前，今晚第一條隊伍。
- **EP2〈霓虹燈〉**、**EP3〈叫賣喇叭〉**：同一個機制換成燈與聲音；但在前提改好之前不建議往下寫。
- **評審的問題**：三位都在 s02 或 s04 想滑走；「兩攤比誰的棉花糖大」沒人有共鳴，要先立「搶客人」：自己這攤沒人、對面大排長龍
  （但排隊的客人是群眾，AI 風險高，要改成地上一長排腳印或空的號碼牌架）；螞蟻是全片最好的點子，要在第一格就埋一隻螞蟻在看他。
  如果要救，最省事的方向是把它改成「園遊會的兩個家長」（已婚評審），但那會靠近《汪家夫妻》的家庭題材。
