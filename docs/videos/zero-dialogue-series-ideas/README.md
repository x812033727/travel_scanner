# 零台詞短劇：新系列企劃（2026-11-03）

目標：做出「像參考爆紅片那樣，不靠台詞就很好笑」的新系列，和《汪家夫妻》（狗夫妻的家事衝突）不重疊。
這一份是企劃與盲評結果，還沒有進劇本關卡，也還沒花任何錢。

共用公式（從參考片歸納）：13–20 秒、5–7 個畫面、零台詞；人人懂的關係或衝突；一個挑釁 → 一個停頓 →
**跳過過程，直接給荒謬的結果** → 再補一刀。每個系列都把這個公式換成自己的「固定笑點機制」，讓每一集只要換一個物件或情境就能套。

各自只讀一份盲評包：六個系列的 EP1 加上參考爆紅片的逐格轉寫，七份隨機排序、不告訴他們哪一份是參考片，也不給設計理由。

### 怎麼讀這些分數

- **參考片拿 55**（上一次校準是 44），六個新系列全部比它高。這不代表我們比 33 萬讚的片好笑：
  文字評審看不到表演、停頓和那一格的畫面（`.agents/skills/animation-preproduction/references/comedy-review.md` 的〈校準〉）。
  我們的分鏡把因果寫得比較明白，文字評審就給得高。這份分數只用來**排名與找問題**。
- 參考片的三個分數差最多（39 到 78）：已婚上班族給 78、說「完全是我家」；導演和 20 歲都嫌「動機不明、第一格沒怪事」。
  家庭觀眾對夫妻梗的接受度明顯比較高，這也是為什麼《汪家夫妻》該繼續做，新系列要拉開觀眾面。
- 換一組評審的雜訊大約 ±3 分，所以第 2–4 名（84、82、81）其實是同一群；第 1 名《闖禍小浣熊》是唯一明顯拉開的
  （三位都排第一、三票全拿）。第 5、6 名各有一位評審打得很低，是真的有問題，不是雜訊。
- 改過的 EP1（下面三份）**還沒有再評**。要再評的話換一組新評審，照 `comedy-review.md` 的流程。

## 評審最常提到的問題

1. **第一格還不夠怪**（六份裡五份被點名，參考片也是）。第一格就要有衝突或荒謬的東西已經在發生，
   例如刺蝟已經被震到半空、膠帶直接貼過河馬的臉，而不是「角色坐著、準備要發生事情」。
2. **「黑畫面一拍」和「剪刀喀嚓一聲」是偷懶的停頓**（綿羊、倉鼠）。停頓要由角色演出來（慢轉頭、眼皮跳、眼珠一飄），
   或用一個具體的聲音（樓板很長的「嘎——」），不要用黑畫面代替。
3. **鋪陳洩底**：倉鼠先鼓起臉頰，觀眾就猜到要塞東西了。挑釁那一格不要預告結果。
4. **跳過的過程要「猜得出因果」**：金魚怎麼跟貓交換、槓片是不是從大猩猩正在推的槓上拿走的、天花板的洞是不是刺蝟撞的，
   評審都問了。跳過過程可以，但結果那一格要留一個線索（撞出的小洞連成一圈虛線、鋸子還插在牆上），讓觀眾一秒補完。
5. **同一個笑點重複第三次就弱了**（企鵝鋸沙發、鋸電視、再鋸燈）。第三拍要反轉，不要再加一次。
6. **收尾要落在主角身上**：斑馬逃跑、熊腳伸出窗外這種旁觀式的收尾被嫌「硬接」或「多餘」；
   評審想看的是主角的反應，或一個留給下一集的鉤子（媽媽把青蔥插進「花瓶」、熊跟刺蝟一起抬頭看更上面的樓）。
7. **世界觀要一致**：只要是全動物的世界，就不能出現「人」；寵物系列的動物也要穿衣服、像人一樣過日子，
   不然評審會覺得「不是擬人化」（金魚老大因此被已婚上班族打 51）。
8. **重複的鏡可以合併**：鑰匙聲和小浣熊看鏡頭合成一鏡（前景臉、背景虛焦的門把在轉）、企鵝盯屁股和眼皮跳合成一鏡，
   省下來的秒數給最好笑的那一格多撐一拍。

## 第 1 名《闖禍小浣熊》

**一句話設定**：浣熊一家三口每次闖禍，都把自己假扮成被弄壞的那樣東西，一動不動地等著被發現。

**固定角色（外觀錨點）**

| 角色 | 外觀 |
| --- | --- |
| 小浣熊豆豆 | 小孩體型，黃色連帽衫、背後綁一條紅色浴巾當披風；天生黑眼罩，看起來就像小偷 |
| 浣熊媽媽 | 綠色毛衣、珍珠項鍊，總是提著一袋青蔥（她的識別道具，也是補刀的道具） |
| 浣熊爸爸 | 藍色背心、老花眼鏡，肚子圓 |

固定場景：同一間溫暖的客廳（沙發、邊桌、落地燈、地毯、玄關），每集換一個角落。

**固定笑點機制**：闖禍 → 門外的鑰匙聲（停頓：小浣熊慢慢看鏡頭、耳朵貼平）→ **跳過**偽裝的過程，
直接看到他已經變成那樣東西，地毯鼓起一包 → 偽裝出一個小破綻 → 補刀：**另一個家人也正在假扮別的東西**，
或媽媽一臉平靜地「把他當成那樣東西來用」。

**為什麼關靜音也好笑**：所有笑點都是「一個不該是活的東西是活的」，看一眼就懂；破綻靠眼珠一飄、一片花瓣掉下來，
不靠聲音。結果那一格本身就是一張可以截圖轉傳的畫面。

**AI 製作風險**

- 低：偽裝那一格是**靜止的角色**，AI 最擅長；沒有兩個角色碰觸、沒有吃喝、沒有字。
- 中：嘴裡咬花（像吃東西，生成時寫成「花莖夾在嘴角」）、頭上頂燈罩與桌巾裹身的布料；三隻浣熊要靠衣服顏色分辨，設定圖先鎖。
- 中：「媽媽把青蔥插進花瓶」是手拿道具碰到另一個角色，所以**不拍插的過程**，只拍插好的結果（同樣是跳過過程）。

### EP2〈電視〉

小浣熊在客廳踢球（腳，不用手），球正中電視，螢幕裂成蜘蛛網 → 玄關傳來爸爸的拖鞋聲、小浣熊慢慢看鏡頭 →
**跳過**：電視櫃上的螢幕被拆掉了，小浣熊坐在空框框裡，擺著卡通人物跳舞的姿勢定格；爸爸坐上沙發、拿起遙控器 →
爸爸按一下，小浣熊立刻換成新聞主播的坐姿；再按一下，換成氣象主播指著空氣；再按一下，換成料理節目拿著鍋鏟 →
補刀：爸爸按下電源，小浣熊在框框裡慢慢躺平、閉上眼睛「關機」。（升級靠換台的次數；遙控器只拍爸爸手掌按下，不拍手指特寫）

### EP3〈時鐘〉

小浣熊吊在牆上的掛鐘擺錘上盪鞦韆，掛鐘整個摔下來 → 媽媽的鑰匙聲、慢慢看鏡頭 →
**跳過**：牆上原本掛鐘的位置，小浣熊貼著牆、張開雙手當時針和分針，指著三點 → 媽媽看看自己的手錶、皺眉，
小浣熊的「分針」偷偷往前跳一格 → 補刀：上方的咕咕鐘小門「啪」地打開，探出來的是爸爸的頭，原來咕咕鐘也是他弄壞的。

## 第 2 名《企鵝與河馬合租》

**一句話設定**：潔癖企鵝和邋遢河馬合租一間公寓，用一條黃色膠帶分家；河馬一越界，企鵝就把那樣東西「公平地」鋸成兩半，
但每次都鋸過頭，反咬到自己。

**固定角色（外觀錨點）**

| 角色 | 外觀 |
| --- | --- |
| 企鵝 | 小紅領結、黃色洗碗手套，挺直站姿；身邊永遠有一台掃地機器人 |
| 河馬 | 大一號的花襯衫、沙灘褲，永遠癱著，身邊一圈零食袋和臭襪子（不能有品牌與文字） |

固定場景：合租公寓，一條黃色膠帶從地板正中間貼過家具、爬上牆，左邊一塵不染、右邊垃圾山。

**固定笑點機制**：河馬越界 → 企鵝眼皮跳兩下、慢慢轉頭看工具間（停頓）→ **跳過**鋸的過程，
那樣東西已經沿著膠帶整齊地變成兩半 → 升級：連不該鋸的也鋸了 → **反轉：鋸過頭，倒楣的是企鵝自己**。

**為什麼關靜音也好笑**：膠帶和左右對比是一眼就懂的圖像；「一刀兩半」的結果是純畫面的荒謬；
反轉也靠畫面（冷氣只吹到河馬那半），不用解釋。每個合租過、跟兄弟姊妹分過房間的人都有對象可以轉。

**AI 製作風險**

- 低：結果那一格都是靜物或角色靜坐，沒有碰觸、沒有吃喝。
- 中：「整齊鋸成兩半的家具」要靠關鍵影格把切面畫乾淨，先做一張首格驗證；同一個房間要在多格裡保持一致（固定機位、固定膠帶位置）。
- 中：電視半邊亮半邊黑、冷氣只吹一邊，需要光線與小粒子（霜、汗）的細節，寫成清楚的視覺錨點。
- 注意：已婚上班族評審說「室友我已經過了那個年紀」，但改成夫妻分床就會撞到《汪家夫妻》，所以維持室友，觀眾面偏年輕。

### EP2〈冰箱〉

河馬的大西瓜滾到冰箱裡企鵝那層（一整排排得整整齊齊的藍色保鮮盒）→ 企鵝眼皮跳、看工具間 →
**跳過**：冰箱沿膠帶鋸成兩半，西瓜也鋸成兩半 → 升級：連冰箱裡的燈都只亮一半 →
反轉：壓縮機在河馬那半，河馬那半嗡嗡運轉、冒著冷氣；企鵝那半不冷了，它的冰塊和魚在滴水，企鵝抱著融化的冰塊發呆。

### EP3〈浴室〉

河馬泡澡泡到水溢出來，水流越過膠帶 → 企鵝眼皮跳、看工具間 →
**跳過**：浴缸沿膠帶鋸成兩半，河馬坐在半個浴缸裡，水從切口嘩啦啦往外流 →
反轉：流出去的水淹的全是企鵝那半的乾淨地板 → 補刀：企鵝坐在它那半張沙發上，像坐木筏一樣漂過客廳。

## 第 3 名《樓上住了一隻熊》

**一句話設定**：小刺蝟住在大棕熊的樓下，每次抗議鄰居太吵，熊都用一個技術上解決問題、但荒謬到不行的方法回應。

**固定角色（外觀錨點）**

| 角色 | 外觀 |
| --- | --- |
| 小刺蝟阿刺 | 很小，粉紅睡帽、條紋睡衣；生氣時刺全部豎起來，會蜷成刺球 |
| 樓上的熊 | 超大的棕熊，灰色連帽衫、毛拖鞋，個性溫和，永遠在睡或在打呼 |

固定場景：老公寓的小套房與它的天花板（熊家的地板），加上公寓外觀。

**固定笑點機制**：熊造成的噪音或麻煩 → 刺蝟用自己的方式抗議（刺球撞天花板、關窗、走樓梯）→
安靜下來的停頓 → **跳過**熊的「解決」過程，直接看到結果：問題確實沒了，但換成一個更大、更荒謬的狀況 →
補刀：兩隻要一起面對下一個問題（讓他們慢慢從敵人變成室友般的盟友，這是系列的長線）。

**為什麼關靜音也好笑**：大小對比（小刺蝟、塞滿房間的熊）是一眼就懂的圖像；「咚咚咚」可以用震動的吊燈和掉下來的灰塵
看見，不用聽；結果那一格的熊形大洞是可以截圖的畫面。住過公寓、被樓上吵過的人都有對象可以轉。

**AI 製作風險**

- 低：最荒謬的那一格是熊在睡覺、刺蝟坐著瞪眼，靜態，沒有碰觸（熊圍著床，不抱刺蝟）。
- 中：熊與刺蝟大小差很多、要同框，靠全景與固定機位；「熊形狀的洞」與「洞邊一圈小洞」要在關鍵影格裡畫清楚。
- 中：熊在夢裡「比噓」是手勢，寫成「大掌放到嘴前」，不要寫手指。

### EP2〈烤肉的煙〉

熊在陽台烤肉，煙一直飄進刺蝟的窗戶，刺蝟咳到刺都在抖，用力把窗戶關上 → 煙停了，安靜 →
**跳過**：中午，刺蝟的整面窗戶被熊的大背擋住：熊坐在刺蝟家陽台外面，用身體把煙全擋下來，被燻得滿臉黑、眼睛流淚，還很努力地點頭 →
補刀：熊的背擋住所有陽光，刺蝟的房間中午一片漆黑，刺蝟默默打開檯燈。

### EP3〈電梯〉

一樓電梯門打開，裡面被熊塞得滿滿的，熊的臉壓在玻璃上；刺蝟提著一袋菜嘆口氣，轉去爬樓梯，爬到二樓就癱坐在階梯上 →
樓梯間的縫裡，熊的眼睛往下看著 →
**跳過**：隔天刺蝟按電梯，門打開，裡面空蕩蕩、寬敞到可以轉圈 → 補刀：公寓外觀，熊戴著安全帽、綁著登山繩，
正沿著外牆往七樓爬，路過每一戶陽台時，喝茶的鴨子鄰居們一起抬頭看。

## 其他三個系列（精簡版）

### 第 4 名《綿羊理髮廳》（EP1 中位數 81，和第 3 名在雜訊範圍內）

- **一句話設定**：自己一頭羊毛爆炸的綿羊理髮師，聽到客人的「一點點」就鄭重點頭，然後剪出完全不是那樣的成品。
- **固定角色**：綿羊理髮師（蓬亂爆炸的米白羊毛、小圓眼鏡、黑背心、脖子掛皮尺）；每集換一個動物客人。
- **固定笑點機制**：客人一個小要求 → 師傅鄭重點頭、眼鏡反光 → **跳過**施工，轉椅子揭曉成品 → 客人低頭看自己 →
  補刀：剪下來的東西被師傅拿去用了。
- **為什麼關靜音也好笑**：「改造前後」是最直接的畫面對比，一張截圖就懂。
- **AI 製作風險**：低；不拍剪的過程，只拍前後。剃光的獅子要畫得滑稽而不噁心（寫成「像剛洗完澡的大貓」）。避免鏡子反射。
- **EP1〈修一點點就好〉**（盲評稿）：獅子用兩根爪子比「一點點」→ 綿羊點頭、眼鏡一閃 → 獅子安心閉眼 →
  轉回來：全身剃光只剩頭頂一撮毛、還在微笑 → 獅子低頭看身體、再翻眼看那撮毛 → 綿羊把整片獅鬃戴在自己頭上威風地站在門口，斑馬客人拔腿就跑。
- **EP2〈染亮一點〉**：斑馬指著一張色卡 → 成品：斑馬的條紋被重新排成蘇格蘭格紋 → 補刀：門外排隊的熊貓看一眼，倒退著走掉。
- **EP3〈幫我打薄〉**：豪豬想打薄 → 成品：全身光滑粉紅 → 補刀：綿羊坐在櫃台，用拔下來的刺當棒針在織毛衣。
- **評審的問題**：第一格不夠怪（讓鬃毛大到卡住門框，或有鳥從鬃毛裡飛出來）；「喀嚓＋黑畫面」是最老的套路，改成電推剪一路
  「嗡——」、鏡頭停在獅子微笑的臉上、毛一直往上飛；結尾的斑馬是旁觀者，改成光溜溜的獅子跟著走出來，權力反轉才完整。

### 第 5 名《金魚老大》（EP1 中位數 72）

- **一句話設定**：每次橘貓對金魚起歹念，金魚只是面無表情地轉過來盯著牠，隔天地位就整個反過來。
- **固定角色**：胖橘貓（藍色項圈掛鈴鐺）、小紅金魚（凸眼、面無表情，會吐一顆泡泡當招牌）。
- **固定笑點機制**：貓起歹念 → 金魚轉正、一眨不眨地盯著（停頓）→ **跳過**，隔天貓被「管教」，地位反轉 → 金魚吐一顆泡泡「啵」。
- **為什麼關靜音也好笑**：弱小的那一方是老大，大小與權力的反差全在畫面上。
- **AI 製作風險**：低到中；玻璃折射與水要寫清楚，貓的掌懸在魚缸上方不要碰到。
- **EP1〈伸爪〉**（盲評稿）：貓臉被魚缸放大、流口水 → 貓掌懸在魚缸上方 → 金魚轉正瞪貓 → 隔天貓被關在空玻璃缸裡、
  金魚霸佔陽光貓床還掛著貓的項圈 → 飼料灑在貓頭上 → 金魚吐泡泡。
- **EP2〈推下桌〉**：貓把魚缸一點一點往桌邊推 → 隔天貓卡在衣櫃頂端下不來，魚缸被一圈小黃瓜圍在桌子正中央，衣櫃下面的地板也鋪滿小黃瓜。
- **EP3〈半夜釣魚〉**：凌晨三點貓叼著玩具釣竿躡手躡腳 → 隔天貓被那根釣竿吊著項圈、掛在魚缸上方當誘餌，金魚在下面張嘴。
- **評審的問題**：已婚上班族打 51，說它不是擬人化（沒有衣服、沒有生活感），要做就讓貓和金魚穿衣服、像室友或公婆；
  「怎麼交換的」完全留白，被嫌作者硬換，至少要給一個符號（泡泡「啵」一聲當成魔法或威脅）或讓魚鰭從畫面上緣伸進來灑飼料；前兩格都還在講「貓想吃魚」。

### 第 6 名《倉鼠想變壯》（EP1 中位數 69）

- **一句話設定**：健身房裡的小倉鼠看到大猩猩做什麼就逞強學，結果每次都用「倉鼠的方式」完成。
- **固定角色**：倉鼠（紅色頭帶、迷你背心）、大猩猩（黑色背心、銀背、脖子掛毛巾）；配角全部是動物。
- **固定笑點機制**：大猩猩一個猛動作 → 倉鼠深吸一口氣 → **跳過**，倉鼠用頰囊、滾輪、築巢這類倉鼠習性荒謬地完成 → 補刀：大猩猩偷偷學倉鼠。
- **為什麼關靜音也好笑**：大小反差與「用錯方法卻成功」的結果都在畫面上。
- **AI 製作風險**：中；臉頰裡看得出槓片輪廓需要好的關鍵影格；器材上不能有品牌與數字。
- **EP1〈臥推〉**（盲評稿）：大猩猩推彎槓的槓鈴、倉鼠崇拜 → 倉鼠看著槓片架深吸一口氣 → 黑畫面 → 倉鼠兩頰塞滿槓片搖搖晃晃走過 →
  大猩猩推著一根空槓 → 更衣室裡大猩猩偷偷把啞鈴塞進臉頰、含淚硬撐。
- **EP2〈瑜珈〉**：大猩猩做單腳平衡 → 整間健身房的瑜珈墊被咬碎堆成一個大窩，倉鼠睡在正中間 → 補刀：大猩猩也蜷在窩裡睡著了。
- **EP3〈翻輪胎〉**：大猩猩翻巨大的曳引機輪胎 → 輪胎被立起來，倉鼠在裡面跑成滾輪 → 補刀：輪胎滾出大門、滾下街，大猩猩追在後面。
- **評審的問題**：臉頰先鼓起來就洩底了；黑畫面是在拖時間，深吸一口氣直接硬切到結果；槓片是不是從大猩猩正在推的槓上拿走的要拍清楚
  （讓空槓因為太輕往上飛出畫面）；「跑步機上的人」破壞全動物世界觀；健身房梗能轉給的人比較少。
