# 《我的修仙獎勵是不是發錯了？》第 1 集〈獎勵怎麼是口鍋〉

## 故事前提

白玉宗雜役院的清晨，宋管事翻開清退名冊，念到的第一個名字就是江小滿：雜役滿三年沒修為，下月初一下山，下山只有一條妖獸道。他窮到拿撿來的破書墊灶，一天一碗碎靈米撐三十天。夜裡他提水桶出院門，內門首席沈照雪倒在牆邊油燈下，臉色白得透明、袖口燒焦，一句「別叫」。他把她扶進小屋，把唯一的半碗飯雙手遞過去，拍著肚子撒謊「我吃過了」；她嫌「粗米」，又吃了第二口，問他叫什麼。

他伸手去抓破書餵火，書在他手裡亮起藍金色的光，書頁自己翻動，一道光柱升起，仙錄的聲音念「百工仙錄，開啟」；一口黑鐵壓力鍋從光裡落到灶上，「獎勵：壓力鍋」。他對著書面無表情：「我要的是修為。」敲敲書頁要換一個，書沒反應。他認命把整袋碎米倒進鍋，蒸汽滿屋，木勺舀起的飯在蒸汽裡帶著金色光點。沈照雪吃一口，臉色一點點回血、唇色轉紅，把空碗推回來：「再一碗。」仙錄報「靈力恢復，百分之三」，他笑出來：「這鍋……是仙器？」鍋蓋上的銅閥突然猛噴一道蒸汽尖叫，他絆倒凳子跳起來，她的手已握住劍柄。書頁翻動停住，頁底浮出一行小字：「百工仙錄，第二次開啟。」他愣住：「第二次？」沈照雪盯著書，手在劍柄上收緊一次，什麼都沒說。不解答（第 2 集從鍋還在叫、他對鍋賠罪接）。

本集細綱：`docs/videos/series-plans/xiuxian-jiangli/chapter-01.md` 第 1 集（結尾類型揭露）。前 3 秒是宋管事念清退名單第一個名字；中段鉤子是破書在他手裡亮起（約 0:50）；結尾收在「第二次開啟」與沈照雪收緊劍柄的那一格。

## 角色

- 江小滿（jiangxiaoman）：主角，雜役，經脈漏靈；灰色短褐、袖子捲到手肘、腰上一把木勺；本集夜裡臉上一道煤灰。
- 沈照雪（shenzhaoxue）：內門首席，本集受傷：臉色白得透明、一邊袖口撕裂燒焦，劍一直背著或橫在膝上；s37 是顏值鏡頭（臉色回血、唇色轉紅）。
- 宋管事（songguanshi）：雜役院管事，本集反派；名冊永遠在手上，鑰匙串會響。
- 仙錄（xianlu）：沒有身體，只有聲音與剪接時疊上的藍金色書頁面板（`overlays.json`）。
- 雜役群：十幾個灰衣雜役，只在 s01、s05、s07 當背景，不列角色。
