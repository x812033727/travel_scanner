# 《恁祖媽今年18》第 53 集〈作證〉

## 故事前提

建邦簽了責任書，推著母親走出安養院，把她抱進副駕、輪椅摺起放後座。車開進老城的路口，人行道上十幾個老人看見車就跟著走，老陳隔著車窗喊：我們都去你家，替老太太作證。
四點，大廳站滿老街的老人，林導的直播從人群掃到站在中央的月棠。阿凱照約好的來記證詞：老陳說民國三十七年冬天沈記的月棠救了他阿公，老先生、阿婆一個一個接著說老太太的恩。
林美鳳問：老太太救人是老太太，她是誰？玉琴自己推著輪椅從院子門進來，一字一字：「她是我媽。」月棠蹲下，把收了半個月的手帕放回女兒手裡。
林美鳳說失智老人的話不能信，玉琴說出六歲那年吞下媽的銀戒、媽抱著她守了一夜，戒指上留了一道牙印；月棠轉過戒指，阿凱彎腰看——有。
阿凱說法律上要請老太太本人出面，月棠說：「你要的本人，我就在這裡。」林美鳳尖叫「瘋了！」，建業吼：「驗DNA！」
