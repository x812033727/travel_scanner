# X12 Peloton｜成片與上架交接

**交付級別：離線前製。** 目前沒有 TTS 音檔、插畫、MP4、站主正式片頭片尾或 YouTube 影片 ID；`youtube.video_id` 應維持 `null`。審稿通過只代表可以進媒體製作，不能回報「影片已完成」。

1. 鎖定 `video.json` 與 `shorts.json` 的 SHA，另一代理逐句比對五份 SEC 原件；兩位未看過前稿的讀者對**同版**主片與 Shorts 做盲審。任何作者改稿都使舊收據失效。
2. 通過後以本集配對影片工具唯讀乾跑、重讀媒體價格、額度、帳本與 US$25 上界。TTS 製成後聽每句、量濃縮開場 30–60 秒，扣掉第一章、末三句、五秒片頭和二十一秒片尾後，**實質正文 ≥8 分鐘**。不足要增加新來源支持的事件或說明、重做來源與盲審，不靠慢讀或空鏡湊數。
3. 插畫先小批付費試圖，評審加原尺寸人眼檢查，再做受控批次。MiniMax `image-01`、`cute-mystery`，至少七成插畫、最多連續三卡；拒絕假字、商標、真人相貌與把 Tonic 停運畫成 Ohio。合成音樂、逐字可關閉繁中 CC、兩支實測 25–55 秒 Shorts 和 QA。
4. 正式五秒片頭放在第一章後，正式二十一秒 v4 片尾放在末三句後。站主選定版本的授權檔尚需從正式工作區取得；本機替代動畫只能明標「概念試看」。
5. 主片說明與兩支 Shorts 已放直接可點的 SEC 原件網址。取得真實長片 YouTube URL 後回填 Shorts 說明與相關影片欄；長片片尾的可點訂閱、推薦影片元件要在 YouTube Studio 設定。沒有實際影片 ID 不能捏造連結或宣稱已裝好片尾連結。
6. 上架後核實主片、兩 Shorts、CC、來源連結、片尾點擊元素及整集帳本，保存真實網址和各資產 SHA。PR 是可追溯製作包，不是公開影片的替代品。
