# 闖禍小浣熊 EP1〈花瓶〉

## 故事前提

小浣熊豆豆披著紅浴巾在沙發上假裝超人，撞碎了客廳的藍色大花瓶。門外傳來鑰匙聲——下一格，他已經用藍色桌巾把自己裹成花瓶站在邊桌上，嘴角夾著花，地毯底下鼓起一包碎片。媽媽回來，轉頭發現爸爸也頂著燈罩假裝落地燈。最後，媽媽默默在「花瓶」裡插了一把青蔥。

## 角色

- 豆豆（doudou）：小浣熊，黃色連帽衫、紅浴巾披風，天生黑眼罩。
- 浣熊媽媽（mama）：綠毛衣、珍珠項鍊，總提著一袋青蔥。
- 浣熊爸爸（baba）：藍色背心、老花眼鏡、圓肚子。

## 站主觀點

零台詞系列。闖禍就把自己偽裝成被弄壞的東西；跳過偽裝的過程，直接給偽裝好的那一格；補刀是另一個家人也在偽裝，或媽媽面不改色地「把他當那樣東西用」。

## 格式

- 9:16 Shorts／Reels，約 13 秒，零台詞，只有配樂與音效；Colab 首格與 H3 片段。

## 大綱

### 選項 A：花瓶
一行說明：撞碎花瓶 → 鑰匙聲、慢看鏡頭 → 已經變成花瓶 → 爸爸也在裝落地燈 → 花瓶裡被插了青蔥。
開場鉤子：碎了一地的花瓶，和沙發上定格成超人姿勢的小浣熊。
