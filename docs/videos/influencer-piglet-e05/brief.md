# 網美小豬 EP5〈螢火蟲之夜〉

## 故事前提

粉粉在夜晚森林裡被螢火蟲圍繞。拉遠：地下停車場，日光燈一閃一閃，螢火蟲是一串小燈泡，從一根釣竿垂下來；水豚男友站在梯子上舉著釣竿，燈串的線接在他脖子上的行動電源，蚊子繞著他飛。她重擺姿勢，整串燈掉下來纏在她身上，一顆一顆熄掉——行動電源沒電了。

## 角色

- 粉粉（fenfen）、水豚男友（capy）：同系列定裝照；粉粉穿系列招牌的白蕾絲洋裝、大草帽配粉紅緞帶、珍珠髮夾。水豚男友脖子上的行動電源是這集的道具。

## 站主觀點

零台詞；系列公式：唯美 → 閃光一瞄 → 拉遠揭曉 → 男友 → 成品照破綻 → 重擺被整。EP5 題目由本批企劃，照系列公式；男友的固定配件行動電源第一次派上用場。

## 格式

- 9:16，約 16 秒；Colab 首格與 H3 片段。

## 大綱

### 選項 A：螢火蟲之夜
一行說明：螢火蟲圍繞 → 閃光一瞄 → 地下停車場的燈串釣竿 → 男友用行動電源供電、被蚊子叮 → 成品照樹林裡有水豚臉 → 燈串掉下來纏住她、一顆顆熄掉。
開場鉤子：夜裡的螢火蟲，有一隻吊在一條細線上。
