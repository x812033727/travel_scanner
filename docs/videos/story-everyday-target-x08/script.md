## 第 3 章｜店開了，銷售沒有照預期到來

- `x080301` 第一年，Target 說加拿大銷售與營運都低於預期。
- `x080302` 加拿大銷售十三點一七億美元。
- `x080303` 約五成五的店在上半年開張，還有四分之一到第四季才開。
- `x080304` 那個好看的首季毛利，撐到年底了嗎？
- `x080305` 二〇一三會計年度，加拿大部門毛利率只剩百分之十四點九。
- `x080306` 答案在庫存：公司說銷售低於預期，過多的商品得清貨。
- `x080307` 供應鏈剛起步，也增加了壓力。
- `x080308` 商品賣出後，真正留下多少錢？
- `x080309` 商品毛利約一點九六億美元。
- `x080310` 銷售、行政及一般費用，卻約九點一億。
- `x080311` 加上折舊與利息，稅前營運虧損是十點一八億。
- `x080312` 明年銷售若增加，毛利能追上銷售管理費嗎？
- `x080313` Target 年報說，商品得合顧客期待。
- `x080314` 它還得避免庫存再次堆得過高。
- `x080315` 這些是當時的改善條件，不是已完成的成果。
- `x0803a01` 還記得開店前的人員與服務成本嗎？門市開了，它們會立刻退場嗎？
- `x0803a02` 不會。年報說，開店年度的銷售管理費仍含這些啟動支出。
- `x080317` 下一財年，將是加拿大店網第一個全年營業的財年。
- `x080318` 下一年，這批店會先出現改善嗎？

## 第 5 章｜一月十四日，董事會作出決議

- `x080501` 董事會在一月十四日批准停止加拿大門店營運。
- `x080502` 隔天，開場那份法院保護申請由加拿大子公司遞出。
- `x080503` 母公司 Target 同日宣布退出；申請保護的不是美國母公司。
- `x080504` 公告時仍開著的門店，接著要走清算程序。
- `x0805a01` 母公司承諾，待法院批准，提供過渡融資支撐清算期間的營運。
- `x0805a02` 上限一點七五億美元，是可借額度，不是已花掉的現金。
- `x0805a03` 公司也請法院指派監督人，負責監督清算與收尾。
- `x080505` 那員工怎麼辦？
- `x080506` Target 提議設立員工信託。
- `x080507` 計畫讓幾乎所有加拿大員工至少有十六週薪資與福利。
- `x0805a04` 不必留到整段清算結束的員工，也在這項保障設計裡。
- `x080508` 法院批准後，年報記載已注入七千三百萬美元。
- `x080509` 這是為員工設的過渡保障，卻無法讓店繼續營業。
- `x080512` 那這項退出決定，先在財報留下多少費用？
