## 劇情

阿凱的警笛遠去。福伯用門上的備用鑰匙從裡面鎖上祠堂，聲音發抖：「您要是她，就讓我看一樣。」他說，他鎖門的時候老太太在裡面，開門出來的卻是她。
月棠背對老藥櫃，眼睛看著福伯，一隻手往後伸，三十個抽屜一格一格拉開又推回，最後一格推上，三十格同時齊平。福伯跪下喊老太太，長明燈亮了一分。
她叫他起來；福伯問老太太的身子在哪，她說就在這裡，兩人一起看向空蕩蕩的躺椅。她問福伯怎麼一眼就認出她，福伯說七十年前他進門那天，她十八歲的照片剛掛上牆，
他擦那張照片擦了七十年。她要福伯先別說，讓她以遠房親戚的孩子來當保母；福伯說二房不會收，她說那就讓建邦收。這一夜她睡在祠堂的躺椅上，福伯坐在門外守著。
隔天夜裡，換上棉布衫的她坐在東迴廊；福伯說阿凱做完了走失的筆錄、建邦點頭讓她當保母。晚自習回來的小滿瀏海和外套肩膀濕著，把滴水的書包塞進廚房門外的垃圾桶，
一聲不吭關上房門；書包上的鈴鐺在桶裡悶悶響了一聲。
