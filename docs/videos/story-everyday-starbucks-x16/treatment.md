# X16 星巴克｜故事 treatment

**系列位置：**二十支新品牌故事系列 `brand-stories-everyday-reversals-extra` 的第 16 支；本集只講 2008 美國門市盤點，與 `原來如此` B07 的杯型命名問題不同。參考頻道只借熟悉品牌加反常問題的類型，不使用它的逐字稿、畫面或推論。參考頻道即時片庫目前未能可靠回讀，故不宣稱它沒有拍過。

**主問題：**星巴克 2008-07-01 公告約 600 家表現不佳的美國直營店要關；為何入選群組約七成才自 FY2006 開始後開？

**主線：**跟一張匿名的美國直營店名單走：七月公佈的異常比例 → 回看一月展店減速 → 找出選店依據 → 把年報裡的計畫、已關與淨店數分開 → 另一批約 200 家出現 → 成熟店銷售轉正，回答新店為何入選。畫面中的店與店員都是概念角色，旁白只敘述 SEC 可查的公司事件。

**後面四個具體時刻：**開場只看到 1 月 7 日董事會展店計畫被打開、FY2008 九月店數表朝上、2009 年另出一批關店名單、2010 年美國同店表改變；正文依次揭示放慢展店、淨增 445、另一約 200 家及 +7%。開場不先交代單店回報的答案。十個 `loops` 在 `video.json` 逐句綁設問與新的揭曉。

**我們的轉折：**觀眾容易把「宣布關約 600」當成一夜關完，還把「七成很新」當全美新店的失敗率。FY2008 年報其實同時顯示：這一批已關 205 家，**美國直營店總數還淨增 445 家**。FY2009 再把七月群組做至 588 家，還有另一批約 200 家。這個先上後下的年終店數讓「一刀救回公司」的故事無法成立，而同店 −6%→+7% 和多項營運變化給出較窄但可信的答案。
