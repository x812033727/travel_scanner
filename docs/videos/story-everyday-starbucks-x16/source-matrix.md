## v5 逐項口徑鎖定

| 主張或畫面 | 必須守住的解釋 | 主片定位 |
| --- | --- | --- |
| 約 600 與先前 100 | 600 **含** 100，是公告計畫，不能說 7 月 1 日已關 600。 | `x160102`、`x160303–304` |
| 約 70% | 分母是被選入關閉計畫的店，不是全美門市或全體新店；店齡只是入選群的**統計特徵，公告未列作選店條件**。 | `x160103`、`x160305–314`；Short 1 |
| 選店原因 | 公告列店面獲利、預期回報、場址、市場及景氣；沒有各店獲利表，不能編造哪個真地址因何被選。 | `x160309–317`、`x160641` |
| 一月策略的狀態 | S1 的放慢美國展店與部分資金改投國際是**宣布的計畫**，不能說 1 月 7 日已執行完。 | `x160201`、`x160208–211` |
| 舒茲的舊任期 | S1 明說 Schultz 曾在 1987–2000 年任 CEO，公司其間於 1992 年上市並有美國和國際成長；旁白的「上次任執行長時」只作轉向背景，不補未經證實的個人動機。 | `x160202–202b` |
| 示意卡與真實地點 | S2 說入選門市遍及主要美國市場，管理與各地營運主管參與盤點；沒有任何可重建逐店選中原因的地址、財務或訪談，示意卡只作敘事物件。 | `x160302a–b`、`x160308a`、`x160315–317b` |
| 預計關店費用 | S2 的資產沖銷／減損、租約退出及遣散是估計項目；不能說被沖銷的一定是設備，或設備曾按「原價」入帳。 | `x160322–327` |
| 三種進度與新店計畫 | S2 把資產沖銷與退租費用預估在不同財季，實際關閉還依第三方協議；FY2009 新開美國直營店少於 200 是當時**預計**，不是 2009 實開或淨變化。S3 確認關店行動在 FY2008 第四季啟動。 | `x160319–327`、`x160331a–c`、`x160401–401b` |
| 員工與顧客 | S2 說關店門市的全／兼職職位將裁撤，預期許多受影響員工可去附近空缺，也計畫以店鋪查找工具與客服指引受影響顧客；不能改說已安置或已成功轉移。 | `x160328–330` |
| 計畫、實關與淨變化 | FY2008 七月群組實關 205；全美直營淨增 445，是所有開／關互抵的年度結果。FY2007 的 1,065 與 FY2008 的 445 都是**淨增**，不能據此量出新開毛數或開店速度。 | `x160401–412` |
| FY2009 兩批 | 七月群組再關 383、合計 588；2009 一月**另提**約 200 家並實關 183。不能把 183 加到 588，亦不能拿全美淨減 474 代替關閉數。 | `x160501–517`、`x160619–630` |
| 2010 同店 | +7% 只指滿 13 個月的美國直營店同比，排除第 53 週；交易 +3%、平均每筆 +4%。沒有未關店對照組，不能獨歸七月關店。 | `x160601–616` |
| 未關店對照 | 所查 S1–S5 沒有提供七月入選店若未關閉的對照結果，不能外推成「誰也沒量到」。 | `x160611–618` |

插畫只呈現匿名概念咖啡店、鑰匙、木塊與無字帳冊；**不是任何入選真店、真名單或員工的重建**。品牌名、精確數字與來源由後製文字卡和上架說明排版。逐句作者標記在 `line-source-matrix.md`；它不代替另一位審稿者對凍結 JSON／原件的獨立核查。
