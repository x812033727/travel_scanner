## 三個候選與原創增益

### 1. Kimi K3.1 Pro：追上閉源了嗎？先分清可用、可下載與評測條件

採用理由是新近跨頻道關注，加上官方資訊與創作者標題間有一個值得解釋的落差：能從服務使用，跟已經拿得到完整權重，是兩件必須分別查證的事。

[官方技術文章](https://www.kimi.com/en/blog/kimi-k3-1-pro)列出 100 萬 token context，稱 3T-class；完整權重承諾在 **11/4 前釋出**，截至本次查核不能寫成已可下載。Terminal-Bench 4.0 的 65.7% 是供應商公布的特定評測結果，不是所有工作都贏的證據。API、Kimi Code 與會員額度須依[官方價格文件](https://platform.kimi.ai/docs/pricing/chat)另逐項確認，本研究未宣稱實測費用或速度。

可做零付費原創示範：用本地 JSON 與 HTML 做一個「模型主張檢查台」，把服務可用、權重預告、benchmark 名稱／版本／工具設定／來源日期分欄，故意放一筆版本不相同的比較，顯示為何不能直接排名；相同條件的數值才計算百分點差。這是查核方法的可重現示範，不能叫做 Kimi 性能實測。

保留的限制：沒有執行 Kimi 推論、下載新權重、測 3D、測 token 速度或重跑供應商 benchmark。不可把其他創作者的魔術方塊或 10 小時測試寫成我們做過。ROOT 提醒的 ARC 99.9→62.7 是 9/3 當天兩種 harness 的脈絡，不是 10/25 新拒收／重測；本題不靠錯置日期製造新聞。

### 2. Claude Duet：它會主動做事，但台灣用戶現在能用嗎？

Matt Wolfe 週報把 Duet 放在開頭，Brock、Riley 也各有獨立影片，可作跨頻道題材線索。Brock 的第三方頁有時間矛盾，不能把其 17.1 倍指標當已驗證的 YouTube 官方成績。

[Anthropic 10/21 官方公告](https://claude.com/resources/articles/claude-duet)說明：研究預覽從美國 Pro／Max 候補開始，與其他 Claude 共用使用量。寄送、付款、簽署、刪除等行為先呈現並等待批准；不能宣稱任何人已能免費使用或放手處理所有事。

原創示範可用虛構信箱與行事曆，在本地畫出「讀取→草稿→待批准」狀態：找出時間衝突後產出建議，寄送或刪除仍停在待批准。明標我們自製的工作流程示意，不冒充 Duet 介面、帳號資格或實測結果。

### 3. Gemini 4 Argon：究竟贏在哪些工作？

Fireship 的比較片在本輪有最高絕對觀看快照，Two Minute Papers 提供另一頻道的比較，但官方發布里程碑較早，故排在 Kimi 後面。

[10/13 官方 model card](https://deepmind.google/models/model-cards/gemini-4-argon/)顯示各工作成績有高有低；100 萬 context 是輸入輸出合計的上限，不能說所有 100 萬 token 都已由我們驗證可靠回憶。[官方產品頁](https://deepmind.google/models/gemini/)列出 Pro／Ultra 使用資格，不能假設免費本地可跑。

原創示範可將官方評測列做成本地「依工作選工具」互動圖，保留評測條件和版本，顯示換一種工作排名就改變。這是公開表格的重算與閱讀示範，不是新跑三家模型的 benchmark。
