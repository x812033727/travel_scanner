# AI 代理跟聊天機器人差在哪？讓它完成一件事給你看

## 觀眾

會用聊天工具問旅行問題、但不清楚「AI 代理」多做了什麼的一般觀眾。搜尋問題是「AI 代理是什麼」「AI agent 跟 ChatGPT 差在哪」。不預設觀眾會寫程式。

## 觀眾看完能做到的事

能用「有沒有工具結果、是否依結果改變下一步、最後有沒有可查交付物」三個問題判斷一個示範是不是代理工作。能把自己的第一個任務寫成包含資料範圍、停止條件與驗收證據的交辦。

## 站主觀點

提案，待站主確認：我重視可回查的完成證據。代理可替我查資料與改草稿；日期、票價、預約和對外動作仍要由人核對與決定。這是本片的編輯立場，沒有冒稱站主親身經驗。
