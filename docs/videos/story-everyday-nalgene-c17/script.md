## Origin｜先有工作台，才有步道

| ID | 旁白 |
| --- | --- |
| O01 | 故事先回到美國紐約州的羅徹斯特。 |
| O02 | 一九四九年，Nalge 公司的起點，是塑膠實驗用品。 |
| O03 | 官方回顧提到吸管架，還有後來供實驗室使用的各種容器。 |
| O04 | 想像一下工作台：一排器皿等著盛裝、搬移，再把裡面的東西取出。 |
| O05 | 在那裡，瓶子首先要完成的是容器的工作；它不是為登山拍照而生。 |
| O06 | 蓋子能關住內容物，瓶身拿起來輕，移動時較不容易漏，這些是原廠反覆提到的特點。 |
| O07 | 它們在實驗室說得通；一離開實驗室，卻也可能解決另一種麻煩。 |
| O08 | 走路的人要帶水，背包裡的重量和瓶蓋，忽然都變得重要。 |
| O09 | 但請先別把一九四九年想成今天這種戶外水瓶的上市日。 |
| O10 | 那一年有記載的是 Nalge 的實驗用品事業，不是已經在店裡販售的登山瓶。 |
| O11 | 這個故事真正的轉身，還要等到有人把工作台上的瓶子拿走。 |
| O12 | 誰會先這樣做？答案並不在運動用品店。 |

## Idea｜科學家把瓶子帶出門

| ID | 旁白 |
| --- | --- |
| I01 | 依品牌今天的回顧，時間到了六〇年代。 |
| I02 | 公司裡的科學家去健行、露營時，把輕巧、較不易漏的實驗瓶放進行囊。 |
| I03 | 這是公司多年後說起的故事；它沒有指向某位員工的一趟特定行程。 |
| I04 | 可是用途的變化很容易懂：本來在室內裝東西的瓶子，開始跟著人走。 |
| I05 | 走到路口，水還在瓶裡；要喝的時候，轉開蓋子就能拿出來。 |
| I06 | 同一個瓶蓋，在工作台上是收住內容物，在步道上則是讓人帶水出門。 |
| I07 | 品牌回顧還說，當地的露營者和戶外愛好者，逐漸注意到這種容器。 |
| I08 | 這裡沒有一場可以重演的單次發明，也沒有一個可以指定的發現者。 |
| I09 | 變化比較像是：有人先拿來用，旁邊的人也發現，它在另一個地方管用。 |
| I10 | 一只瓶子開始出現在更多背包裡，卻還不等於公司已經正式做起戶外生意。 |
| I11 | 它要到什麼時候，才從順手帶走的實驗容器，成為面向消費者的商品？ |

## Engine｜從少數人的辦法到日常商品

| ID | 旁白 |
| --- | --- |
| E01 | 到了七〇年代，原廠回顧裡，寬口瓶已經成為戶外場景裡容易認出的形狀。 |
| E02 | 寬大的瓶口、能旋緊的蓋子，讓一只容器有了很清楚的使用方式。 |
| E03 | 你不必知道它原本待在哪座實驗室，才懂得怎麼把水裝進去。 |
| E04 | 公司說，戶外使用者的需求逐漸成形，到了七〇年代中期，才設立面向消費者的產品部門。 |
| E05 | 這一步改變了誰在買它：原本是實驗室採購，如今也能是準備出門的人。 |
| E06 | 它不是一九四九年就從實驗台，突然跳上戶外用品店的貨架。 |
| E07 | 但場景已不只在山上；品牌回顧把八〇年代的運動課、九〇年代的大學教室也寫進路線。 |
| E08 | 它從工作台出門，走到營地，又跟人回到室內，只是這次桌上放的是飲水。 |
| E09 | 每換一個場景，消費者要的仍是能反覆帶著走的容器。 |
| E10 | 於是大家越來越認得那種瓶形，卻容易漏看另一個問題。 |
| E11 | 看起來像同一只瓶子，裡面的材料，難道也一直相同？ |

## Turn｜熟悉的外形，材料改了

| ID | 旁白 |
| --- | --- |
| T01 | 到了二〇〇八年，問題不再只是瓶子要跟人去哪裡，而是瓶子要用什麼做。 |
| T02 | 當年四月，Nalgene 宣布，將在接下來幾個月逐步停產一類產品。 |
| T03 | 範圍要聽清楚：是戶外系列裡，含 BPA 的聚碳酸酯容器。 |
| T04 | 這是一項停產計畫的宣布，不能直接當成所有舊瓶當天就從架上消失。 |
| T05 | 也不能把它講成全部實驗室用品，或每種戶外瓶，都在那一天一起換材。 |
| T06 | 公司在公告裡說，這樣做是回應消費者對不同材料的偏好。 |
| T07 | 同一份公告也保留了公司的當時立場：它認為舊產品依預期方式使用是安全的。 |
| T08 | 因此，這不是一紙宣告舊瓶造成傷害的醫學判決。 |
| T09 | 公司當時已有 Everyday 系列，使用不含 BPA 的 Tritan 材料。 |
| T10 | 從這裡看，改變並非「忽然有了水瓶」，而是在熟悉的用途下，重新挑材料。 |
| T11 | 出門裝水、帶回來再用，這件事沒有被改掉。 |
| T12 | 但當人們開始問瓶子由什麼做，品牌不能只回答：我們的蓋子很好轉。 |
| T13 | 材料這一關過後，下一個問題又來了：新材料從哪裡來？ |

## Now｜回到那只背包裡的瓶子

| ID | 旁白 |
| --- | --- |
| N01 | 二〇二〇年，Nalgene 推出 Sustain 系列，起初有三十二盎司的寬口款。 |
| N02 | 外形仍讓人想到那只可以帶著走、反覆裝水的瓶子。 |
| N03 | 不同的是，這一系列採用 Tritan Renew 樹脂。 |
| N04 | 發表時最醒目的數字，是「百分之五十」。 |
| N05 | 乍聽之下，好像每只瓶子裡，都剛好有一半回收塑膠。 |

| N07 | 說得簡單一點，這是一套追蹤供應鏈投入、再把回收來源額度分配給產品的帳目方法。 |
| N08 | 瓶子的故事又多了一層：用途看得到，材料來源卻要用另一套方法追蹤。 |
| N09 | 截至二〇二六年查閱時，品牌常見問答說，多數現售瓶採用 Tritan Renew；這說的是現在，不是回頭替每個年代的瓶子改材質。 |
| N10 | 回頭看，實驗台上的容器，先因為輕、方便帶，被人拿上步道。 |

| N12 | 後來，瓶子維持反覆帶水的用途，材料卻隨著新的需求與選擇繼續變。 |
| N13 | 所以開頭的問題有答案了：這只登山瓶不是一九四九年完整出廠的今天版本，而是實驗用品逐步走向戶外的結果。 |
