## 必查主張與停線邊界

| ID | Treatment 可用的窄說法 | 依據 | 停線／歸屬 |
| --- | --- | --- | --- |
| M01 | 1949 是 Nalge 實驗器皿事業的起點，非已有證據的戶外飲水瓶上市年。 | S2 正文、S3 | S2 開頭導語與正文口徑不一；以正文較精確的商品分類敘述，旁白標「公司回顧」。 |
| M02 | 原廠回顧稱 1960 年代自家科學家把輕、耐漏的實驗瓶帶去健行、露營。 | S1、S3 | 原廠事後回憶；無同期照片或員工筆記，不重建特定員工、單次行程或對話。 |
| M03 | 公司說戶外使用經當地露營者等擴散，至 1970 年代中期形成面向消費者的產品部門。 | S2、S5 | 無早期銷售台帳，不定 1972／1975 為首賣年，不推單一發現者。 |
| M04 | 瓶子的輕、耐用、較不易漏與簡單蓋子是原廠所列的跨場景理由；「為何適合步道」可作功能解釋。 | S1、S2 | 不是實測比較數據；不保證每種蓋、溫度、使用方式都零漏。 |
| M05 | 公司回顧稱 1970 年代寬口款成為戶外常見形狀，1980／1990 年代走到其他活動、校園。 | S2 | 只用作時代場景變化，不說戶外消費者全部轉去校園，不把品牌自評「第一」口吻變成事實。 |
| M06 | 2008 年公司宣布逐步停產 Outdoor 系列**含 BPA 聚碳酸酯**瓶，當時已有不含 BPA 材料的 Everyday/Tritan 款。 | S4 | 不能改寫成「2008 年所有 Nalgene 瓶被禁售／召回」；公告不證明停產完成日或醫學因果。 |
| M07 | 2008 年公司把材料選擇與消費者偏好連在一起；公司的當時安全立場也在同一稿。 | S4 | 要歸屬給公司，不把爭議作單向醫學判決；不提供個人使用安全建議。 |
| M08 | 2020 年推出 Sustain，形式仍是寬口可重用瓶，材料改用 Tritan Renew。 | S5、S7 | 新線上市不等於全公司當天改完，也不能把 2020 產品放回 1970 年代畫面。 |
| M09 | Sustain「相當於 50% 認證回收內容」是**ISCC mass-balance 分配**，不是對每只瓶的物理成分切開稱重。 | S3、S5 腳註、S7 | 旁白若無法口語說清，就只說「採回收來源分配的樹脂」，不畫實體 50／50 粒子剖面，也不寫成 50% 舊水瓶碎片。 |
| M10 | 現行 FAQ 說多數現售瓶用 Tritan Renew，並列 BPA 等成分與有限保固條件。 | S6 | 現況查閱時點需保留，不能作全部過去年份或所有材質產品的說法。 |
| M11 | Nalgene 及供應商有減少一次性瓶、排放等宣稱，但本 Treatment 不把它們當已獨立實測的市場／環境成效。 | S5、S7 | 不用「每買一瓶省多少」或「設計必然造成銷量」作劇情結果。 |
| M12 | 早期原廠型錄與戶外首銷日尚未找到；可敘「從實驗室用途發現戶外需求」，不可敘「發明了全世界第一只水瓶」。 | S1–S3、檢索邊界 | NRS 1976 起開放掃描型錄索引，但未核得 Nalgene 商品列，不能以索引作販售證據。 |
