# 第 1 集重製版 r2：製作交辦

給做第 43 集以後那個雲端 session（RunPod／Colab 路線 A）。稿子在同資料夾的 `script.md`，為什麼這樣改在
`docs/videos/series-plans/zhong-tian-qu-qi/production/camera-feel-study-20261105.md`。站主 2026-11-05：目前的動畫 40 分、
參考的《孟婆今天也不想上班》80 分，這集要做到比 80 分好；做完先給站主看，看過才決定第一季其他集要不要照這樣重做。

## 順序

1. **把稿子轉成製作檔**：照 `script.md` 寫 `docs/videos/zhong-tian-qu-qi-e001-r2/video.json`（slug `zhong-tian-qu-qi-e001-r2`，
   38 鏡，一行台詞一筆、不拆半句）與 `overlays.json`；正文照 `minimax-h3-colab/references/motion-quality.md` 第二節寫成英文，
   每鏡寫出 `script.md` 那一列的動作、景別、運鏡，對話鏡寫過肩或反打、視線看對方。唐小棠一律用 `tangxiaotang-portrait-t2`。
2. **三鏡試拍**（先做，不要一次跑完整集）：c05（跟拍拖上岸）、c13（跟拍擁抱）、c22（過肩對話）。三段式同現在的設定。
   每鏡跟原版第 1 集同場景的一鏡，用 `camera-feel-study` 的量法量：**鏡內動量 ≥ 7、靜止幀 ≤ 15%**，人物臉與定妝照一致、
   嘴在說話的鏡頭嘴型有動、沒有多出來或消失的人。三鏡都過才拍整集；沒過就改正文再試，同一鏡最多試三次，還不行就回報站主。
3. **整集片段**：其餘 35 鏡。每鏡兩個 seed，挑動作完整、在動作中間能切的那支。
4. **配音**：中文整句錄（聲音照 `production/cast.json`），語速句內 4.5–5.5 字／秒。九語先不做。
5. **配樂與音效**：照 `script.md`〈音樂與音效〉。`assemble-v4.mjs` 的側鏈壓縮改成可從 edit 表設定（`duck_ratio`、`duck_release_ms`，
   預設維持現在的值，不影響其他集），這集設 ratio 3.5、release 900。
6. **剪接**：`edit-dh-e001-r2.json` 設 `punch: false`、`slow_max: 1.1`、`interpolate: false`；剪尾留在動作中間。
7. **量成片**，結果寫進這個檔案最後一節：
   - 鏡內動量中位數，目標 ≥ 7。
   - 靜止幀比例，目標 ≤ 15%。
   - 平均每句字數，目標 ≥ 10。
   - 句內語速，目標 4.5–5.5 字／秒。
   - 響度 -14 LUFS。
   - 跟原版第 1 集同一套數字並排。
8. **給站主看**：`import --from <dir>`（只送成片審核，先不送上架包），在備註寫「第 1 集重製版 r2，對照原版第 1 集」。
   站主看過、說要上架，才做九語與上架包。上架包照新流程 `--clips … --edit …`，組片資料一起帶。

## 預算與停損

- 38 鏡 × 6 秒、平均抽 1.5 次，約 55–60 CU；試拍約 5 CU。**超過 90 CU 先停下來回報站主**。
- 開工前和收工後都要記一次 `colab usage` 或 RunPod 的花費，寫進最後一節。

## 備份

- 工作資料夾每天推一次到 `transfer/zt-e001-r2-work`（`git add -f`、單檔 < 100 MB、推完數檔數）。
- 試拍與整集的提示詞、manifest、takes 照慣例放 `production/colab/runs/e001-r2/`。
