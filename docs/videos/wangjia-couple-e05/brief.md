# 汪家夫妻 EP5〈搶被子〉

## 故事前提

阿福半夜把整條棉被捲在身上打呼，珍珠只剩床邊一隻發抖的腳。隔天早上阿福睡在角落的寵物軟墊、只蓋一條粉紅小毛巾；珍珠把棉被、地毯、浴室踏墊、窗簾全捲在身上，捲成佔滿整張床的大被捲。阿福把小毛巾拉上來蓋頭，腳就露出來；縮腳，頭又露出來。

## 角色

- 阿福（afu）、珍珠（zhenzhu）：同系列定裝照。s01 的珍珠只有床邊一隻柴犬腳。

### 選項 A：搶被子
