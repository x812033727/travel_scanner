# S57 R6 盲讀敘事評核 A

僅依 `script.md` 與指定的 13 項敘事評核問題判斷。結論：**11 YES／2 NO**。

| Panel | 判定 | 簡要依據（`script.md` 行號） |
| --- | --- | --- |
| `scene_first` | **YES** | 前四句把觀眾放在 1872 年 3 月的封日記、託付、啟程現場；有人與物件正在行動（9–21）。 |
| `no_spoiler` | **YES** | 開場停在日記要走、人會去哪裡的疑問（9–21）；補給與勸歸的結果仍未說出（33–45）。 |
| `one_line` | **YES** | 預告式開場後，正文由 1871 年烏吉吉相遇，依序走到勸歸、湖上查訪、東行找貨、1872 年告別（51、153、251、325、419、505、603–671）。 |
| `no_toc` | **YES** | 提問都指向故事內的下一個動作或結果，例如「會把人帶回去嗎」「先往哪裡去」（205、319）；沒有宣告影片的講述順序。 |
| `chapters_link` | **YES** | 章末疑問由下一章首句接續：報信者→蘇西（147→153）、勸歸問題→史丹利發問（245→251）、同行去向→湖的北端（319→325）、舊布未取回先到什麼→新援助（499→505）。開場的去向問題也由回到烏吉吉找續行補給接住（45→51）。 |
| `open_loops` | **YES** | 正文持續留具體懸念，從誰先報信、是否返國，到舊箱是否完整、同行人手何處來，間隔均短（147、205、241、393、435、463、483、537、597、643、675）。 |
| `payoffs` | **YES** | 主要提問有新答案：蘇西報信（147→153）、不先返國而先完成考察（241→279）、舊箱短少（393→491）、人手要從海岸來（537→549）、最後未能返家（675→679）。 |
| `no_recap` | **NO** | 同一個「補給到手後仍要繼續考察、不返家」決定在同章反覆說出：541、545、557；後兩處沒有作為遠距回呼的新事實。 |
| `chapters_are_events` | **YES** | 章名指向可見事件或揭曉，如「蘇西跑來報信」「史丹利把貨交給他」「日記走了，人留下」（149、501、599）。 |
| `outro_no_next` | **YES** | 片尾止於去世及回看日記，沒有提下一集或下一份檔案（675–687）。 |
| `opening_hooks` | **YES** | 首個封日記場景後，開場另留至少三個待揭問題：補給回來會否改變決定、勸返家會怎樣回答、兩人為何分路（37、41、45）。 |
| `one_thread` | **YES** | 李文斯頓是否隨史丹利返家，貫穿失去補給、勸歸、繼續查水路、補給到手後的計畫及告別（45、95、251–315、337、505–557、647–687）。 |
| `no_detour` | **NO** | 回烏吉吉後的美國領事來信、亞丁舊電報、李沒有同類信件，連續三拍沒有改變找貨、勸歸或查水源的行動，也未在後文回收（377–389）。 |
