## Six untimed chapter titles

- 配送預覽中間少了一大段 → Bagian tengah pratinjau pengiriman tidak ditampilkan
- 原表還在，省略出現在回覆裡 → Tabel asal tetap utuh; baris hanya tak tampil dalam balasan
- 三筆包裹，只有一筆入選 → Tiga paket, hanya satu yang terpilih
- 少一個字母，查詢先停了下來 → Kurang satu huruf, kueri berhenti
- 檔案重開後，逐筆對回原表 → Buka ulang berkas dan cocokkan tiap catatan ke tabel asal
- 準時包裹加入，清單換了需求 → Paket tepat waktu ditambahkan: kebutuhannya berubah
