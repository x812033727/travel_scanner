# DuckDB 真實操作截圖的原生整合

本目錄保存 Root 當次實際執行的來源套用與 native render wrapper 文字副本。普通工具仍在 `tools/video`，沒有新增渲染引擎、語音供應商或全域設定。兩張原創操作視窗截圖只存 repo 外的 content-addressed `stock/<SHA>.png`；實際媒體沒有進 Git。

`human-footer` 對應一般模式的 `1200 rows (40 shown)`，`agent-omitted` 對應中間 `1160 rows omitted`。圖中標明操作重現日期 2026-10-27、原始 fixture 2026-10-25、虛構資料與原創視窗，並非 DuckDB 官方 UI、模型推理或效能測試。旁白111個完整line物件與八語全文不變；只換兩景版型及畫面資料、增加兩份真實來源授權。

正常 `script` 重產使兩個版型標籤及 narrative footer 改變；舊腳本核准保留而正常失效。原生兩份12/13 false及所有歷次失敗保持，不能因畫面整合稱當前敘事、音訊或整片通過。原生 render 重畫2狀態、重用62狀態並重產聯絡表，細節以公開實際收據為準。

這些一次性執行 helper 的 marker 已消耗，不是可以重播的續作工具。舊來源、腳本與摘要逐bytes保存於本片 history；舊實體render版本保存在 repo 外的當輪 before/W，原 content-addressed frames原位保留。後續依正常 source／審核／音訊／視覺關卡建立下一個版本，不移植核准或降低門檻。
