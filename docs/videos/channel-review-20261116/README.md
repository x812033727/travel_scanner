## 篩法

每題四問，各 0 或 1 分：

1. 觀眾手上或家裡現在就有這個東西嗎？
2. 標題能不能寫成「為什麼／憑什麼」的反常問題？
3. 是規格、標準或「誰在收錢」的故事嗎？（它的 HDMI、A4、1TB 這一型）
4. 是「大公司輸掉」或日本品牌嗎？（它的 Seiko、世嘉、YKK 這一型）

人物傳記與創業史不加分。分數是一個代理憑題目與提問打的，不是量出來的；同分照原本的順序。
