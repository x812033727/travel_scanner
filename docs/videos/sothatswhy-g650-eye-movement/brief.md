# 轉眼珠、眨眼睛，畫面為什麼從來不糊也不黑？（原來如此事務所 G650）

企劃與形式決定：[`../so-thats-why/dialogue-pilot-20261103/README.md`](../so-thats-why/dialogue-pilot-20261103/README.md)、[`../so-thats-why/look.md`](../so-thats-why/look.md)、[`../lessons/sothatswhy.md`](../lessons/sothatswhy.md)。
題目來源：題目池素材第一名 G650（素材候選 H83-001～H83-014）。

## 問題

人的視線一秒跳動數次，眼球在高速滑移時，整個世界在眼底高速滑過，急停後水晶體甚至還像果凍一樣抖動。如果拿攝影機這樣晃，畫面早就糊成一片；而且我們每分鐘眨眼十幾二十次，每次眼前全黑超過一百毫秒，為什麼我們眼前的世界從來不糊、不抖，也從來沒感覺到黑？那段影像到底去哪了？

## 一句答案

轉眼珠時，不是只有大腦在調暗視覺，連沒有大腦的視網膜自己看到畫面高速滑過都會主動變鈍，急停後更用清楚的新影像把晃動拖影直接蓋掉；而眨眼黑掉的一百毫秒不但沒漏看，突發的明暗對比反而把大腦注意力重新整理、激發輪廓神經，大腦還會精明地挑故事空檔、快速轉頭甚至賽車直線段才眨眼！

## 站主觀點

套用立場：2、3、6、7、9、10。

我的看法是：「以為眼睛只是單純攝影鏡頭」是所有人最常見的直覺誤區。攝影機被動記錄每一束光，晃動就產生動態模糊；但眼睛從視網膜受體到大腦皮質，是一套具備主動抑制、神經預警與時間縫合的智能感測系統。

全片內容與頻道立場完全一致：
1. 官方原文與實測出處優先（立場 2、3、6）：全片引用的科學數字（水晶體微晃 15–20 Hz、離體視網膜 80% 壓抑、眨眼後辨識率提升至 86.7%、3.8 萬次轉頭追蹤、賽車手直線段眨眼）全數來自同行評審的一手實測論文，分清數字出處，不誇大其詞，實驗推測明說是推測。
2. 虛構對話與真實科學分清（立場 9）：本集為原創科普漫劇，所長與小問的辦公室、暗室皆為示意場景，不冒充真人真事，不替站主或角色編造虛假經歷；小問提出的是大眾直覺疑問，所長以科學事實解答，不嘲笑錯誤直覺。
3. 看完就能做的動作（立場 7）：片尾留給觀眾隨時能在鏡子前與日常中嘗試的體驗——對著鏡子轉眼珠親自感受看不見自己眼珠移動，以及在轉頭瞬間眨眼體驗大腦的視覺剪輯。
4. 純粹科普絕無醫療建議（立場 10）：純粹探討正常人體神經生理學與認知科學，不涉及任何眼疾診斷、就醫、用藥建議或保健品推薦，零商業置入。

## 結構

| 章 | 推進與科學事實 | 小問的直覺與疑問 |
| --- | --- | --- |
| 1. 每次轉眼珠，畫面其實先糊掉、再抖一下 | 系列片頭後破題：眼球高速掃視（Saccade）與急停慣性，穆爾西亞大學測出水晶體果凍振盪（15–20Hz、65ms、影像位移達 0.3 度）[H83-001] | 眼球停了，畫面就該立刻停住 |
| 2. 老答案：大腦在轉眼前就先把視覺調暗 | 起跑前 50–100ms 視覺變鈍（壓抑），且只鈍明暗/亮度對比、不鈍顏色 [H83-002]；隔板分視野實驗證實左右信號會合於大腦皮質中樞 [H83-003] | 畫面變黑是眼皮擋住，轉眼沒閉眼不可能變暗 |
| 3. 第一轉折：沒有腦的視網膜，自己也會「看不見」 | 杜賓根大學離體視網膜實驗：畫面高速滑過，視網膜自身神經反應即被壓抑八成 [H83-004]；人眼不動看背景滑過照樣變鈍，均勻背景下轉眼反而不變鈍 [H83-005] | 肯定是大腦發出轉眼訊號在控制 |
| 4. 糊掉的那一段：被蓋掉、被習慣掉，還被偷偷拿來用 | 逆向掩蔽效應：著陸後的清楚畫面回頭覆蓋拖影 [H83-006]；掃視壓抑可透過一週訓練在著陸瞬間精準解除 [H83-007]；拖影未被丟棄，目標若跳位眼睛順著拖影更快追上 [H83-008] | 沒看見的拖影就是被大腦直接丟進垃圾桶 |
| 5. 第二轉折：眨眼黑那一下，反而幫你看得更準 | 眨眼全黑 100 多毫秒，明暗脈衝反而提升對低頻淡粗條紋的辨識力 [H83-009]；睜眼後 300ms 內抓目標正確率從 75% 提升至 86.7%，液晶遮光眼鏡假眨眼無此效應 [H83-010] | 眨眼黑掉純粹是漏看資訊，閉越久越吃虧 |
| 6. 大腦是神級導播：挑好時機才眨眼 | 看故事影片自發同步眨在情節空檔與換幕 [H83-011]；暗室聽純聲音直到判斷段落結束才眨眼 [H83-012]；轉頭前 500ms 憋住眨眼、藏在轉頭模糊區 [H83-013]；職業賽車手 300km/h 每一圈都精準眨在直線段、彎道憋住 [H83-014] | 眨眼只是眼睛乾了隨機眨一下 |
| 7. 原來如此 | 所長與小問總結兩大轉折，大腦與視網膜的精密協作；小問蓋章；留一個日常生活轉眼挑戰 | — |
