# 汪家夫妻 EP1〈幫忙曬衣服〉

## 故事前提

柴犬老婆珍珠叫柯基老公阿福去曬衣服。阿福把整籃濕衣服倒扣在曬衣架上，就回沙發滑手機。珍珠看到，髮捲一顆顆彈掉，慢慢轉頭——下一個畫面，阿福被曬衣夾夾著睡衣，跟衣服一起掛在曬衣繩上隨風晃；珍珠在底下喝茶，對鏡頭甜笑。

## 角色

- 阿福（afu）：柯基老公，短腿、胖、條紋睡衣，懶、得意。
- 珍珠（zhenzhu）：柴犬老婆，碎花圍裙、粉紅髮捲，平常很甜，生氣時更甜。
