# 羅阿諾克「消失的殖民地」：CROATOAN 到底是什麼意思？

奇聞檔案局 H02。2026-10-12 起草；**大綱草稿，建議 A，尚未核准**。製作路線：本機插圖投影片（`format: "slides"`、`category: "explainer"`），Cute mystery 第 3 版既定畫風，MiniMax image-01；繁中長片正文瞄準 10–11 分鐘，至少 8 分鐘。這是歷史檔案說書，沿用 H01／U02／L08 的系列規格；事實依據與推論分開，不套操作型教學卡片。片長以合成後實測為準，完整證據需要更多時間時不刪內容。

## 觀眾

聽過「失落殖民地」與 CROATOAN，但只記得一百多人蒸發、一棵樹和神祕刻字的台灣觀眾。搜尋問題是「羅阿諾克 真相」「CROATOAN 意思」「失落殖民地 找到了嗎」。

## 觀眾看完能做到的事

1. **讀懂留言的上下文**：把樹上的 CRO、柵欄木樁上的 CROATOAN、約好的遇難十字分開，說明為什麼懷特把留言當去處，不當咒語。畫面證明為原文短引卡與位置對照卡；證據層級：引用懷特 1590 年返航記述。
2. **檢查「找到了」的推論**：分辨器物的產地、年代、出土環境和使用者，說出一件歐洲器物為什麼還不能指認殖民者。画面證明用黃銅戒指案例、島上與內陸兩條考古線的對照；證據層級：引用官方說明及研究方主張，並保留年代與交易疑點。
3. **給懸案一個有分寸的判斷**：指出已知的是約定去處、推測的是遷移或融入、缺的是能確定屬於殖民者的聚落與人物證據。結檔卡把三種層級分開，不把「有線索」講成「已解案」。

## 站主觀點

沿用系列已定的檔案立場：流傳的版本要和當時留下的文字分開；能說明幾步就說幾步，不把未知填成超自然答案，也不把研究方的宣告當作定論。CROATOAN 最有人情味的部分，是一個祖父看到記號時以為家人平安，而他沒能完成下一段航程。親情只靠可查的日期與行動，不編對話和內心獨白。

## 示範或實算

這不是實作教學。三組判讀示範均為**引用**，不冒充實測。

- **位置與記號**：原文樹上 CRO／柵欄木樁 CROATOAN；約好搬走刻去處，有難再加十字。輸入是同一份返航記述，判讀動作是把位置、約定與懷特的反應連起來；結果只支持他當時如何讀懂留言。
- **两个五十英里**：殖民者離開前曾準備往內陸約五十英里；刻字指向南邊的克羅托安島，今天哈特拉斯島一帶約在羅阿諾克以南五十英里。卡片分成方向相反的兩列，不能寫成「約好去五十英里外的島」。
- **黃銅戒指**：出土後曾被當成金戒指與家族線索，後來材料分析是黃銅；判讀先問材質、年代與使用者。材料被認出不等於持有人被認出，歐洲器物也可能因交易進入原住民聚落。

## 大綱

### 選項 A：留言讀懂了，為什麼人還是沒找到？（推薦）

一行說明：以 1590 年現場的「留言—讀法—未走完的航程」為主線，再查後來的傳聞與考古。答案在前 30 秒交代，留下真正的問題，不把刻字當故弄玄虛的道具。

開場鉤子：「一百一十多人不在了，留下的字卻讓總督很高興。」
轉折：「你以為那是看不懂的神祕留言；其實克羅托安是地名，是約好的搬家記號。」

1. **讓他高興的留言**（約 0:00–0:30）：一百一十多人不在；懷特自己寫他很高興；克羅托安是去處。章末問：那他為什麼還是沒找到人？
2. **三年前的道別**（約 0:30–2:30）：1587 年原定乞沙比克灣、被留下羅阿諾克、早期聚落失敗留下的空屋；與克羅托安人的關係並不毫無嫌隙；外孫女 8 月 18 日出生；25 日聯名請求、27 日出發；約定留言與十字；1588 年戰爭與補給船受挫。章末問：三年後他到底看到了什麼？
3. **清晨的空堡**（約 2:30–4:20）：1590 年 8 月 18 日上岸、吹號唱歌無人回應；樹上 CRO 與木樁 CROATOAN；房屋拆下、新柵欄、散置重物、埋過又被挖開的箱子；未找到先前船艇與部分小炮；沒有十字的限度；唯一目擊記述。章末問：有了去處，還差哪一步？
4. **沒有走完的五十英里**（約 4:20–5:50）：內陸計畫與南方島嶼不是同一路；克羅托安今天的地理；四個錨只剩一個、淡水桶落在岸上；先計畫南下補給過冬、8 月 28 日風暴逼改往亞速群島再回英格蘭。章末問：這之後還有誰留下了線索？
5. **遲到一百年的故事**（約 5:50–7:15）：1709 年哈特拉斯人的祖先自述屬轉述；屠殺說也不是親眼所見；樹輪的大旱可能增加壓力，不能單獨解釋去向；十九世紀「失落殖民地」包裝；1930 年代刻字石多數被判偽造。章末問：故事靠不住，挖出來的東西呢？
6. **器物會不會認人**（約 7:15–9:35）：哈特拉斯島歐洲器物與混雜年代；金戒指變黄銅；地圖補丁下的堡壘狀符號與內陸伯蒂郡；團隊宣告與独立證據分開；交易和年代使「某人用過」難以確認。章末問：要找到什麼，才能把檔案結掉？
7. **有去處，沒有定案**（約 9:35–10:40）：把當時目擊、後來轉述、現代推論分層；現在仍缺確定的人與聚落；可能遷移、分散、融入，但未知每個人的結局。蓋「未結」；留言題與系列訂閱邀請，不承諾未定下一題。

時間是撰稿瞄準，非音檔量測。短句、每景單主體單動作，約 100–110 景；插圖瞄準七成以上實際時長、3 張公有領域照片穿插。數字、刻字與原文由卡片呈現，AI 插圖不畫文字。

### 選項 B：一句地名，怎麼變成四百年的詛咒？

一行說明：以故事的加工為主線；1590 年記號只是地名，1709 年傳聞、十九世紀命名、1930 年代刻字石把缺口變成懸案。優點是傳說拆解清楚；缺點是懷特的航程退居第二線。

開場鉤子：「克羅托安不是咒語，是一個早就有人住的地方。」
轉折：「你以為殖民者留下了一句神祕暗號；其實看見它的人知道去哪裡找。」

1. 地名與約定（0:00–1:30）：木樁與樹、十字規則 → 為什麼沒去？
2. 卡住的返航（1:30–3:40）：道別、戰爭、空堡與斷錨 → 之後的故事從哪來？
3. 百年後的自述（3:40–5:15）：祖先傳聞、屠殺說、乾旱 → 哪些能驗？
4. 懸案的商品（5:15–6:50）：十九世紀命名、刻字石 → 真文物能定案嗎？
5. 兩條考古線（6:50–9:35）：戒指、補丁、島與內陸 → 缺哪一塊？
6. 結檔判斷（9:35–10:40）：地名已讀懂、去向未確定 → 回答鉤子。

### 選項 C：祖父回來那天，外孫女滿三歲

一行說明：以懷特離開與回來的日期為情感線，現場證據與後世推論穿插。優點是人物動機容易跟；缺點是容易使觀眾把他的願望當作殖民者實際命運，因此不能編心理或對話。

開場鉤子：「祖父回到島上的那天，剛好是外孫女的三歲生日。」
轉折：「你以為他看見刻字會絕望；其實他寫自己很高興。」

1. 出生九天後的道別（0:00–2:00）：1587 年生日、聯名請求、約定 → 為什麼等三年？
2. 跨不過的海（2:00–3:30）：戰爭與補給船 → 回來看到什麼？
3. 生日那天的空堡（3:30–5:30）：號聲、刻字、箱子 → 去處在哪？
4. 沒抵達的島（5:30–7:00）：地名與失去的錨 → 還能追嗎？
5. 後來的人留下什麼（7:00–9:35）：轉述、戒指、補丁與發掘 → 證據認出誰？
6. 未結的家人與聚落（9:35–10:40）：誠實的未知 → 回答鉤子。
