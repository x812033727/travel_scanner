# 給站主：同一份檔案，兩種講法

H01 瑪麗賽勒斯特號，照 2026-10-13 的新寫法重寫一次。事實沿用
[`../curio-h01/claims.md`](../curio-h01/claims.md) 兩輪查核後的版本；講法全部重寫。
重寫的時候有十九處把事實講歪或講強了，獨立查核的第一輪全部抓到，也全部改回來了（見〈第四輪〉）。
`lint` 0 錯誤 0 警告，估 11.1 分鐘、140 句、124 張插圖、7 張卡片。
只有腳本：沒有生圖、沒有配音、沒有花錢。

**說故事關卡：過了。** 一個只拿到旁白、什麼都沒看過的讀者，十題全是「是」——登船那一幕只在
第 1 章出現、沒有任何一段被講第二次、宣告句不見了、片尾只帶沒講過的東西。第一稿是被同一關
擋下來的（四題「不」），後面三節是它兩次說了什麼、每一次改了什麼。

## 盲評擋下第一稿，這是第二稿

說故事關卡（`script-writing.md` §說故事關卡）是十題是非題，由一個**只拿到旁白、什麼都沒看過**的
代理回答。第一稿是撰稿自己答的，自己給了十題全過；換一個只讀旁白的讀者來答，**四題是「不」**。
下面是它說的，和這一稿做了什麼。

  整個解釋就建在這上面。

## 第三輪：十句「還記得」砍到三句

第二稿十題全過，但同一個讀者另外講了一件沒問的事：前兩三句「還記得」像說書人回頭去拿一樣東西，
到了第 6 章四句連著（07:55、08:08、08:17、08:38）、第 7 章又五句，聽到的就是公式而不是故事；
它特別點了「勘驗官量過的船殼」和「那位美國軍艦的艦長」背對背像在點名。
同一批五支稿子裡，別的四支各只有四到五句，所以這是 H01 自己的毛病。

改法：**只有隔了好幾分鐘的三個掛鉤留著「還記得…嗎」**——船長自己買的股份（第 2 章埋、
第 6 章回收，隔六分鐘）、船尾那條斷掉的粗繩（第 1 章埋、第 7 章回收，隔九分鐘）、
空白的九天（第 3 章埋、第 7 章回收，隔六分鐘）。其他七處改成直接把那樣東西撿起來往下走，
不問觀眾記不記得：

| 原來 | 改成 |
| --- | --- |
| 還記得桌上那頓熱飯菜嗎？ | 那頓熱飯菜，連這篇小說裡都沒有。 |
| 可是還記得勘驗官量過的船殼嗎？船殼和貨，一點傷都沒有。 | 可是勘驗官量過的那艘船，連貨都是完好的。 |
| 還記得那位美國軍艦的艦長嗎？ | 那位美國軍艦的艦長，報告裡還寫了一句。 |
| 還記得甲板上那根量水深的桿子嗎？ | 甲板上那根量水深的桿子，現在有用了。（讀者自己給的寫法） |
| 還記得那一千七百零一桶酒精嗎？ | 那一千七百零一桶酒精，這時候才真的被數過。 |
| 不過還記得清單上少掉的那幾樣東西嗎？ | 清單上少掉的那幾樣東西，這個解釋還是擋不住。 |
| 還記得那九個空桶嗎？十個人離開的理由，目前只有它說得通。 | 十個人離開的理由，目前只有那九個空桶說得通。（第四輪的查核又把它改掉了：「只有…說得通」比紀錄強） |

每一句都還是點名那樣東西（第 7 題要的），但都往前走一步、不重述它（第 8 題要的）：
桿子「現在有用了」接的是下一句被拆開的幫浦，桶「才真的被數過」接的是下一句的九個空桶。
`mc5g` 本來那句「還記得」其實也不合規則——它指的事情三十五秒前才講過，
點名的回呼要留給隔了幾分鐘的掛鉤。

順帶一件事：第 5 章原本靠 `mc5g` 那個問號當鉤子，改成陳述句之後 `lint` 就說
05:32 到 07:14 有 102 秒沒有任何掛著的問題，所以中段那句「傳說一旦跑起來，就停不下來了」
改寫成升級句「更離奇的還在後面。」，接到海怪那一段。事實沒有增減。

三輪都是同一份事實，`claims.md` 沒有新增任何沒查核過的說法。
**這一輪改完還沒有再跑一次盲評**：通過紀錄是第二稿那一次。交片之前值得讓另一個沒看過的讀者
再答一次十題，確認硬接法沒有被讀成重述——跑 `node tools/video/cli.mjs narrative --slug curio-h01-v2`。

## 第四輪：獨立查核抓到的十九處

2026-10-13，一個**沒有寫過這份稿子**的代理做了這一版的第一輪查核（[`verify-1.md`](verify-1.md)）：
把 `video.json` 抽成 270 條，併成 77 列判定（CONFIRMED 50、CHANGED 19 列、NOT FOUND 2、
OUT OF SCOPE 6），當天用 curl 把第一版兩輪查核引過的每一個網址重開一次。結論是**重講的時候有
十九處把事實講歪了或講強了**，另有四處文件落後於稿子。十九處全部改進稿子，改的只有旁白的字、
兩張卡片的欄位和說明欄；場景、場景 id 與 `prompt`／`camera`／`visual` 一個都沒有動（插圖已經畫好、付過錢）。

最重的四條：

- **說明欄把熱飯菜算回 1884 年那篇小說**（R1）。道爾全文裡沒有任何桌上的飯菜，本集自己的 `mc5g`
  就說「連這篇小說裡都沒有」——說明欄和旁白當場矛盾，而且這正是第一版兩輪查核各改過一次的同一條。
  現在說明欄把它分成兩件事：小說寫進記憶的是「小艇都在」，熱飯菜是「又是從哪裡長出來的」。
- **天文鐘那 120 哩的方向反了**（R5）。來源寫的是船長的**實際位置比他以為的偏西** 120 哩，
  所以他以為早三天就該看到陸地；稿子寫成「以為自己在一百二十哩以西」，正好相反。
  `claims.md` c45 從第一版就寫反了，只是第一版的旁白沒講方向、錯誤沒有露出來，這次連 c45 一起改。
  `mc6q` 現在是「天文鐘有誤差，船長的位置比他以為的偏西一百二十哩。」
- **爐灶與羅經櫃被搬進勘驗那一章**（R8、R9）。兩件事都查得到，但出處是**上船那天的證詞**；
  Austin 12-23 的報告反過來寫爐灶與炊具「in good order」、羅經櫃本身沒有受損。排在勘驗官上船
  那一段裡，聽起來就變成勘驗官說了他報告裡否認的話。各加一個時間標記就解決（「大副上船那天」、
  「那天的羅經櫃」），接著的船頭刀痕改成點名勘驗官，免得時間標記一路蓋到 Austin 的發現上。
- **片尾把未結的案子收成一條路**（R12）。「目前只有那九個空桶說得通」比紀錄強：`claims.md` c49 列的是
  兩條路，本集自己的 `mc6v` 說「這兩條路，都還有破洞」。`script-writing.md` §結尾已經把這一句記成
  反例，所以照那一條改：未結的檔案第一句講紀錄留下了什麼，不下結論——
  「十個人離開的理由，紀錄最後留下的是那九個空桶。」它仍然點名那九個空桶，數字也還是只在第 7 章講一次。
