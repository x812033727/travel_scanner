站主 2026-11-18：「那規劃 AI 劇相關的音樂與音效吧」。接在
[`../../explainer-series/music-library/README.md`](../../explainer-series/music-library/README.md)

## 為什麼要做

- 種田的分鏡規則要「一場一首配樂、揭曉時一個重音、每個動作配音效」（[`../../series-plans/zhong-tian-qu-qi/production/storyboard-brief-for-planners.md`](../../series-plans/zhong-tian-qu-qi/production/storyboard-brief-for-planners.md)），
  但目前只有三段 Lyria cue（`cue-tension`、`cue-suspense`、`cue-comedy`）加一套合成音效；第一季審片也記了「配樂與音效偏少」。
- 恁祖媽今年18 的審片點名幾個招牌音效要聽得到：三顆銅鈴、長明燈的低鳴與一閃、三十個抽屜歸位、福伯懷錶的滴答、落地鐘、快門
  （[`../../series-plans/top40-2025-2026/2025-01-tai-nainai/production/REVIEW.md`](../../series-plans/top40-2025-2026/2025-01-tai-nainai/production/REVIEW.md)）。
- 婚約到他判刑那天為止（歐美版，`till-the-verdict`）剛開始做，還沒有任何配樂。

種類同前：`bed`（一場一首的配樂，約 2–3 分鐘）、`cue`（重音、揭曉、轉場、片尾等短音樂）、`sfx`（音效，一個檔 6–8 個變化夾靜音，用時再切）。
漫劇的配樂寫法是 `video.json` 的 `music.track`（檔案放 `_music/`）；種田另有自己的 `music/cue-*.mp3` 與剪接設定，換用時照 `production/assets/README.md`。
