## 原本每一段放到哪裡

## 鉤子、起源、轉折、收尾怎麼排

- **鉤子**（0:00–0:42）：書 → 誰買、多少錢 → 為什麼怪 → 「可是你想不到」拿回不到一半 → 兩個高潮標籤（最後四分之一的價錢、BBC 自家網站的決定）。沒有講起源，也沒有講賣價。
- **起源**（0:50–3:21）：照黑貓的「故事要回到」句型，先給年份和地點（1972 年倫敦），再交代處境（四百英鎊、一台破車），然後才講書。名字的由來是人物的怪癖。
- **轉折**：大約每 40–70 秒一個小轉折，問句一律放在句尾（lint 只把句尾問號算成鉤子）。大起落有四次：2009 年國會與虧損 → 2011 年轉盈；2011 年照原價 → 網站延誤、自己做旅遊版；2013 年賣掉 →「事情有這麼簡單嗎？」帳是六年慢慢減的；9 月「賣在最完美的時機」→ 11 月報告與「接近一億」。
- **收尾**：先回到開頭的問題，給報告的答案，再倒帶回廚房桌，最後一句是旁白自己的看法。留言題和訂閱各一景。
