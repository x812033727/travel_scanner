# S49｜一八三五年《太陽報》怎麼把月球寫成有人住？

奇聞檔案局新歷史長片前製候選，2026-10-20。原建議的 1904 聖路易奧運馬拉松需要的官方賽會報告在本環境不可讀；依站主持續製作新題、採編輯推薦方向的指示，改選題庫 U30「月球大騙局」。S01–S48 無這支片；U30 仍是**待核候選卡**，其中銷量、天數、神話單角獸等文字未直接採用。本站大綱與劇本關卡尚未個別核准；這裡的選 A 是本地編輯選案。

## 問題

一篇「月球有翼人」的報導，為什麼後來選錄的報紙反應既有稱讚，也有質疑與反諷？

## 一句答案

1859 年保存的《太陽報》重印本先借真實天文學家 Herschel 的好望角旅行，再捏出一份學術增刊、助理書信、光學儀器與層層加碼的月面景物；它選錄的同時代反應既有信服，也有質疑與反諷。1902 年天文學家 Jacoby 批評其中的「人工光補望遠鏡亮度」只是術語拼貼。材料顯示這個故事如何製造可信感，不能據此量出全民相信或真實銷量。

## 站主觀點

站主未給本題預設立場；本集的編輯判斷是讓觀眾跟著一張報紙看權威、來源和數字如何互相支撐，再把能打開的原文與不能查到的文件分開。所有月面畫面只示意當年文字主張。

**觀眾帶走：**辨認「真人真地點＋查不到的刊物與助手」如何把虛構掛到權威上；把文章裡精密倍數和真的觀測器材分開；分辨 1859 年重印本裡收錄的當代贊同、懷疑和反諷，不接受「所有人都被騙」的總括。插圖示範人物讀報與想像，不冒充原紙、月面照片或 Herschel 真器材。
