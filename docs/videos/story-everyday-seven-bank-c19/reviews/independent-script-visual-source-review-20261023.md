## 必須窄修的五個 ID

1. **c190313｜配鏡 HOLD。** 旁白只是「別家為何要接上」的問題；提示詞讓一位合作銀行職員持別家卡片且「表情猶豫」，彷彿重現某家機構的實際遲疑或選擇。S6 P11–P13 和 S3 P14 是合作模型，沒有這個人物或情緒。保留抽象兩條網路／兩張素面卡的疑問畫面，移除具體職員的「猶豫」表演。
2. **c190409｜旁白與來源註記 HOLD。** S3 P14 寫的是合作方使用該 ATM 網，相對自有 ATM 可以降低 maintenance and funding costs；沒有逐家採用動機，沒有直接稱「少自己設點」，funding costs 也不能逕譯成實體「備鈔負擔」。S6 P13 可支持自有 ATM 的替代／外包概念，但不補足備鈔翻譯。建議改成「二〇一〇年年報說，合作方使用這張網，較自行持有 ATM 可降低維護與資金成本」之類的公司歸屬說法；來源註記精確指 S3 P14／紙面 13。現有比較道具僅可作概念圖，不能演成某家銀行在 2001 年的決策現場。
3. **c190410｜配鏡 HOLD。** 提示詞要求畫「固定金額符號」再擦除，與自身「畫內無可讀字／金額」契約衝突，且影像模型可能把固定金額或幣符留下來。直接用兩條互不相接的無字費用路線與素面單據，不描述任何待擦除的字、數字或幣符。旁白「不是每個使用者都付固定費」可保留。
