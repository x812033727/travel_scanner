## 劇情

放榜日早上，州城城門下人山人海，許大郎一手按著懷裡的銀袋。紅榜從城樓上滾下來，報榜人從第八十名唸起。
唐小棠急著問要唸到什麼時候，秦霜說解元留在最後。周員外擠過來笑許硯昨天去州府告狀，誇口他要是能中，自己倒著走一條街；唐小棠讓大家都聽見。
兩個州府差役在紅榜旁的考官榜前喊：主考馮學正舞弊，即刻革職，一筆紅墨劃掉他的名字。周員外嘴硬，許硯按著袖子裡的銀票，問榜到底改回來沒有；
秦霜說唸到最上面就知道。第三名、第二名都沒有他，周員外仰頭大笑，唐小棠咬著指甲。秦霜問他緊不緊張，他攤開滿是汗的手心。
最後一名：「解元，青州清水縣柳溪，許硯！」整條街靜了一拍，然後炸開。系統宣布鄉試任務完成、獎勵活字印刷，還順口嫌他考了四次。
差役送來解元的青色襴衫與紅綢花。午後遊街，周員外在前面倒著走，唐小棠替他數步；許硯騎白馬拱手道喜。秦霜走到馬邊伸手拉住韁繩，
把斗笠推到額頭後，仰頭看他：今晚，我有話要單獨跟你說。
