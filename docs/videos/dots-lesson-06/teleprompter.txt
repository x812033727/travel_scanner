這是一堂逐步畫面示範，畫面使用實際擷取的操作步驟。
今天開啟 dot 的雲端電腦，做一次接管與交還。
再用一份虛構本機摘要，確認本機連線和撤銷的差別。
你會知道電腦顯示離線，不代表權限已經移除，也會知道工作到底在哪裡做。

dot 本來就有自己的雲端電腦與瀏覽器。
它們有自己的檔案、軟體和網站工作階段，不依賴本機的雲端工作可以在你的電腦關閉後繼續。
但是本機檔案與應用程式要另外允許存取。
而且本機步驟需要電腦線上，ChatGPT App 保持開啟。
官方目前說明，一次只能連線一部個人電腦，雲端電腦仍保持連線。
連線 Codex 或啟用 Work Sync，也不會單獨給 dot 本機權限。
所以我們從 dot 的個人資料檢查，而不是看到其他產品已有連線就推定完成。
另一個容易混淆的是網站登入。
你在自己的瀏覽器登入，不會讓雲端也自動登入。
這堂課先用公開官方頁面，避免把登入與接管混在同一個練習。
等控制流程熟悉後，真正需要帳號時再由你完成私人登入。
公司工作區也可能限制本機存取，先依目前帳號可見的設定確認。

回到 dot，請它開啟本課官方來源，整理雲端與本機差別。
先說清楚這次不要登入、提交表單或連線新的帳號。
接著在個人資料的 Computers 找雲端電腦。
如果對話提供瀏覽器交接，也可以從 Open computer 開啟。
開啟畫面只是檢視，目前還沒有取得滑鼠和鍵盤控制。
先辨認控制狀態，再選 Take over 接管。
接管後只做一個簡單的操作，例如在官方頁面捲到某個標題。
這時不要同時叫 dot 點同一個頁面，避免兩邊互相干擾。
觀察頁面真的移動，再記下你停留的段落。
畫面顯示的是工具操作結果，後面整理的文字仍需要另行對來源驗收。
如果頁面沒開啟，先讀失敗原因，不能拿別的畫面假裝目前已開啟。
影片會保留實際的控制與頁面變化，必要時用放大幫觀眾看清按鈕。

操作完成後，選 Return control 交還。
在對話說明你已捲到哪一段，請 dot 從目前頁面接續整理。
再檢查它的來源連結與內容，確認接續的確是這份頁面。
如果未來某個網站要求登入，dot 可以送出私人表單，也可以交給你接管網站自行登入。
密碼、驗證碼和其他憑證不需要貼在聊天。
私人表單會把資訊送到遠端瀏覽器，這段由帳號持有人處理，錄影要停止。
有提供 Save to Passwords 時，儲存登入是可選的。
有效網站工作階段和已儲存密碼，是兩件不同的事。
網站工作階段可能在之後仍可用，也可能過期或需要重新驗證。
要用已儲存的登入建立新工作階段，仍需要你確認。
完成登入後再交還控制，讓 dot 繼續原本的工作。
公開素材只展示工作需要的非敏感區域，不能讓帳號資訊與登入內容留在影片中。

現在準備本機練習。
在專用資料夾放一份本機讀書會摘要，只含虛構活動日期與待辦。
記下確切路徑，不需要讓它搜尋整臺電腦。
在這部電腦的 ChatGPT App 開啟 dot 個人資料。
進 Computers 找 Your computer，選 Allow access。
讀完確認內容後，再選 Allow access 完成連線。
回對話提供指定路徑與檔名，請它只核對這一份摘要。
它可能建立本機 Work 或 Codex 工作，開啟工作看實際執行位置。
本機權限和每個工具是否支援，仍要依當前環境確認。
如果它讀不到，先查電腦是否線上、App 是否開著以及路徑是否正確。
連線會保留在任務之間，所以做完這次讀取，還要知道怎麼撤銷。
目前一次只有一部個人電腦可連線，別把選另一部電腦理解成把舊工作也搬過去。
原有工作要從原環境檢查，下一課會繼續說明。

先由你人工把摘要的截止日改成另一個明確日期。
保持電腦上線，在原工作請 dot 重新讀取這份檔案，只列新舊日期差異。
把檔案和結果並排檢查，不能拿聊天中的更新提示當成工具已重新讀取。
完成後回 Computers，選 Revoke access 撤銷本機存取。
如果你只是讓電腦離線，畫面顯示 Offline，表示現在不可用，連線沒有因此撤銷。
這兩個狀態要分開記錄。
撤銷後再問它能否重新讀取指定摘要，預期不能把舊結果說成新讀取。
同時開啟相關工作，確認哪些仍在執行、哪些等待電腦或權限。
撤銷存取與停止委派工作，也需要分別檢查。
停止不會回復已完成的修改，這次只有讀取，所以成果版本容易核對。
如果之後還需要本機工作，依允許的範圍重新連線，不要為了一個檔案把所有服務都開通。
公開時記得遮罩私人路徑與裝置識別，只保留示範需要的資料。
這裡再分清楚三件常被混在一起的事。
第一件，是你看得到雲端畫面。
第二件，是目前由誰操作滑鼠與鍵盤。
第三件，是網站本身允許哪個帳號做哪些動作。
接管只改變控制者，不會替你完成網站授權，也不代表網站登入已建立。
所以我們用公開頁練習控制，用專用摘要練習檔案，讓每項證據各自可核對。
如果接管時你改了頁面位置，交還後說清楚目前在哪裡。
如果你完成登入，也說明可以從哪個頁面繼續，但不要把密碼或驗證內容寫出來。
dot 的下一步仍應指向原工作，不能因為能操作瀏覽器就擴大到無關網站。
本機摘要更新也是同樣原則。
我們提供確切路徑，要求重新讀一份來源，再看結果是否反映新值。
工作完成後，把實際讀取時間、使用環境與版本一起儲存。
如果結果沒有更新，先查檔案是否儲存、工作是否使用同一個路徑，以及電腦是否可用。
不要只靠它說看過最新版本就勾完成。
撤銷前後也要各留一張狀態截圖，確認本機權限發生什麼變化。
如果原工作還在雲端整理之前讀到的內容，這與重新存取本機不是相同的事。
因此測撤銷時要明確要求新讀取，並讓它說明是否可用。
這個習慣能避免把儲存下來的舊內容，誤認為現在仍可取得新資料。
雲端與本機可以協同，但每個環境的檔案、登入和工作狀態仍要分別確認。
確認清楚後，再進下一課從 Activity 開正確工作，會更容易追蹤問題。

雲端網站不能用時，先看是否需要登入或額外驗證。
如果網站阻擋雲端瀏覽器，可以在允許的情況下請 dot 改用已連線電腦。
這可能建立獨立本機工作，不會移轉雲端登入，也不保證所有本機瀏覽器都受支援。
網站要求你驗證，就由你完成，不能靠教學指令碼繞過防護。
本機 Offline，檢查網路、App 和登入工作區；想移除權限，要用 Revoke access。
完成檢查時，確認你能辨認檢視與接管，並做過交還。
指定檔案有讀取與更新證據，本機權限也已按練習範圍核對。
如果某個操作沒有實拍記錄，課程就保留待驗，不能用示意或舊結果補成成功。
