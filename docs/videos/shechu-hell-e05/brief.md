# 社畜地獄 EP5〈午休〉

## 故事前提

阿金的座位曬到一片暖暖的陽光，他伸個懶腰、抱著頸枕去午休。玻璃辦公室門邊，喵總的眼睛鎖定那片陽光。阿金回來，笑容垮下來：喵總四腳朝天睡在他的鍵盤上。阿金只好抱著筆電坐到印表機旁的冷角落，冷氣對著他吹。陽光慢慢移到他身上，他鬆了一口氣——辦公桌上，喵總睜開一隻眼，盯著那片陽光。

## 角色

- 阿金（ajin）、喵總（miaozong）：同系列定裝照。

## 站主觀點

零台詞；貓的天性：搶最暖的位置、坐鍵盤。

## 格式

- 9:16，約 17 秒；Colab 首格與 H3 片段。

## 大綱

### 選項 A：午休
一行說明：座位曬太陽、去午休 → 喵總盯上陽光 → 阿金回來笑容垮掉 → 老闆睡在鍵盤上 → 阿金縮在冷角落 → 陽光移過來 → 老闆睜開一隻眼。
開場鉤子：黃金獵犬的座位被午後陽光曬得暖洋洋。
