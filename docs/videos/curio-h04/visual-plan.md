# H04 共用畫面備料規格

2026-10-12。站主已核准 A 案；以下為備料原則，實際素材、像素檢查與後續分鏡核准各另留收據。

沿用 H03 已接受的線條、平塗色盤及說書聲音設定。近期人物不生成肖像；如需要人的存在，以匿名遠背影、剪影或戴手套的手呈現。空帳篷、鞋、文件、樹與雪層本身不加五官。避免以可愛表情消費罹難者。

| 段落用途 | 可準備畫面 | 必須看得出的界線 |
| --- | --- | --- |
| 引出離帳疑問 | 雪夜空帳篷、鞋、空的雪坡 | 畫面標歷史情境示意；不畫一個人持刀行動當成已知情節 |
| 旅行與搜尋 | 白天雪路、旅行用品、匿名遠背影、森林邊緣 | 不畫九張可識別臉；不用人物合影或AI重造歷史照片 |
| 原始文件 | 結案書鞋子、足跡及結論局部 | 使用已核對像素的原件；檔案頁碼、作者、日期與授權記入assets |
| 雪板機制 | 平台、吹雪、層狀積雪、弱層 | 幾何示意不當真實測繪；需要準確坡度或數字時用原生卡片 |
| 研究後續 | 白天山坡、無人機、測量用品 | 不將2021測坡與2022雪崩痕跡放成同次探勘；重建畫面標示意 |
| 收尾 | 日照空坡、合上檔案、未結章字卡 | 未結指完整事件順序未證明；不把缺少細節說成所有說法同樣可信 |

初稿目標約100–115景、插圖時長65–75%。每張一個主體、一個動作，約5–8秒；遠景、中景、物件特寫交替。夜景不超過一半，白天搜救、研究及室內文件提供亮度變化。

文件候選不用湊張數：只有授權、可讀尺寸、像素與旁白確實吻合才採用。同一頁的腳印與結論若需要裁切，要保存原檔SHA、裁切區域與輸出SHA。含驗屍文字的區域不進畫面。足跡數字用字卡，不要求生成模型精確畫出八九道。

不依賴隊員照片、帳篷原照、紀念碑肖像、河流CC BY-SA照片、來源未定的底圖或新增系列片頭。研究圖若使用，只選權利明確的作者自製圖，保留CC BY 4.0完整署名及修改說明。

正式生圖前跑原生 `keyframes --dry-run` 確認供應商為MiniMax image-01、提示長度及預算。每張先讀選用圖與judge，不修改judge評語換取自動核准。沒有啟動本集付費生圖。
