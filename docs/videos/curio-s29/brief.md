# S29｜曹沖稱象是從佛經學來的嗎？

## 問題

曹沖稱象的辦法，能證明是從佛經學來的嗎？

## 一句答案

《三國志·曹沖傳》和《雜寶藏經》〈棄老國緣〉都寫船、水線與替代重量；前者說曹沖提議「稱物以載之」，沒有指定石頭，後者由藏匿老父教大臣「量石著中」。卷首標注的北魏漢譯晚於曹沖在世，但無法為原故事定年，更不能由相似方法推出誰抄誰、傳播方向或曹沖本人借用經文。

## 故事線

跟著船側那條水痕，從曹沖向曹操提出測重方法，走到傳記的「物」，再進入一則結構不同、以敬老為主旨的佛教譬喻，看那裡為何改寫成「石」，最後回答相似文本能證明到哪裡。畫面用不同場景區分兩個故事；同一個老人絕不畫成曹沖的老師。

| 章 | 故事往前走的動作 | 章末未解問題 |
| --- | --- | --- |
| 一條水痕，兩頁故事 | 曹沖提議讓象上船，刻下水痕；後來的漢譯另有船量象故事 | 相同方法能證明借用嗎？ |
| 曹沖留下水痕 | 孫權送象、曹操求重量、曹沖提出刻痕與替代載物 | 第二次裝船那四個字到底寫什麼？ |
| 石頭從哪裡來 | 原文是「物」；看清比較方法與傳記如何用兩則軼事寫曹沖 | 另一個故事又把那條水痕交給誰？ |
| 地下的父親給出答案 | 佛教譬喻裡的棄老國、大臣藏父、天神問白象重量 | 那艘船第二次載的是什麼？ |
| 經文讓石頭上船 | 老父指定石頭，後續難題逼大臣說出真正答者 | 這相似辦法誰先說？ |
| 兩個年代，推不出一條傳抄路 | 曹沖卒年與北魏漢譯署名只能排一層時間 | 「石頭」怎麼進曹沖的通行故事？ |
| 留下同一道水線 | 回到「物」與「石」的不同證詞和各自敘事目的 | 結論限於可核文本；借用方向未明 |
