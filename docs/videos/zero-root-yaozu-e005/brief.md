# 《長燈村：零靈根的我被一村妖祖養大》第 5 集〈越疊越多〉

## 故事前提

第 4 集收在傍晚的雞舍前：陸拾把四顆靈石倒進破陶盆，雙手捧著奶奶的豆腐刀往盆裡放，刀尖剛碰到盆沿，背後奶奶問：「拾兒，你在幹嘛？」第 5 集從同一個傍晚接下去：奶奶一把奪回豆腐刀：「刀不准碰。」她低頭看了盆一眼，在圍裙上抹了一下刀，什麼都沒說就進屋了；陸拾一屁股坐在地上：「她……看見了吧？」之後一夜一夜，盆裡的靈石越疊越多，八顆、十六顆，最後滿盆金光照亮整個雞舍。他掰著手指盤算：奶奶的新刀、團團的糖、還有自己的仙家功法。到了青石鎮的錢莊，夥計斜眼看他：「鄉下人換什麼？」他把靈石往櫃檯一拍，夥計整個人坐直；可是對著光一照，臉色變了：「玄穹宗的印？」陸拾只能說「撿、撿的。」夥計笑著把一袋銀子推過來：「撿得真巧。」他買了一把新菜刀，又在舊書攤看不懂字、照著圖挑了一本功法，抱在胸口偷偷做夢：「仙人……我也當得成。」回村他給團團二十串糖葫蘆，團團卻說「團團算過了，會出事喔。」他把新刀推給奶奶，奶奶原封不動推回來，只用那把舊豆腐刀：「舊的順手。」當晚他照著功法把靈石按在丹田吸了一夜，一點都沒進去，天亮時靈石在掌心碎成灰：「零靈根……果然還是廢物。」第九天深夜，他從床底拖出木盒數靈石：「三十、三十一……三十二。」窗紙的破洞裡，一隻眼睛跟著他的手一顆顆數，輕聲接了一句：「三十二。」
