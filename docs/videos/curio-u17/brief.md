## 問題

主軸：外星（U）。

觀眾會打的字：「外星人綁架 第一案」「希爾夫婦」「Betty Barney Hill」「消失的兩小時」「Zeta Reticuli 星圖」「藍皮書計畫」。

大部分人相信的版本：一九六一年一對夫妻在新罕布夏的山路上被飛碟攔下、少了兩個小時的記憶，三年後在催眠裡想起被外星人帶上飛船檢查；
空軍說他們看到的是木星；太太畫下的星圖指向 Zeta Reticuli。

## 一句答案

「被帶上飛船」這段情節，查得到的最早一筆是 Betty 自己說的、事發十天到兩週後連著好幾晚的夢，十一月寫成五頁（Webb 1965）；
兩年多後（1964 年 1 月起）的催眠裡，Barney 第一次也講出被帶上飛船；1965 年 10 月報紙連載五天，夫婦成了全國話題。
空軍當年的報告裡是一條會轉向、伸出 V 形翼與紅燈的光帶，沒有人影、沒有時數；藍皮書的正式分類是「資料不足」，「極可能是木星」只出現在 1963 年的回信，同一段前面又說無法判定。
主持催眠的醫師接受有目擊、不接受綁架。**綁架的故事從夢開始，一步一步進了錄音帶和報紙；那道光是什麼，空軍自己寫資料不足。**〔#1、#3–#12、#19〕

## 站主觀點

沿用系列守則與 README §靈異守則：講檔案不講結論，不講成真的、也不嘲笑相信的人。三段照查核的寫法：「他們說」（窗後的人影、記憶斷片、少了大約兩小時、被帶上飛船）
→ 空軍的紀錄（報告、雷達、分析表、紀錄卡、1963 年的回信）→ 醫師與研究者的看法（Simon、Kottmeyer、Sagan 與 Soter、Sheaffer、Holman、Hopkins 與懷疑論者），每一句掛名。
不講：綁架真的發生、催眠找回被抹掉的記憶、空軍判定是木星、雷達證實、暢銷書、史上第一宗、手錶停擺與後車廂亮點；不念、不畫住址；催眠裡的檢查細節不念不畫。

## 兩個大綱

- **A（推薦，採用）：先說故事，後開檔案。** 前三分之二跟著夫婦照時間走：夜路 → 到家隔天的電話 → 五天後的信 → 十天後的夢與十一月的五頁 → 1963-12-14 的診間與 1964 年的錄音帶 → 1965 年的連載、1966 年的雜誌與書、1975 年的電視電影；
  後三分之一照「最早那份報告寫了什麼」一路打開：報告 100-1-61 與雷達 → 藍皮書分析表、紀錄卡、1963 年的回信 → 醫師與電視影集的時間點 → 星圖 → 2011 年的標誌與兩派解讀。
  為什麼：這就是 README §U 軸說書版定的結構（量到的中文外星百萬片都是一個人從頭講到尾），故事段讓觀眾先站在車上，檔案段的每一份文件都在回答故事段留下的問題（報告寫了什麼、醫師怎麼看、那些點是不是星星）。
- **B：照文件出現的順序交錯。** 每講到一件事，當場打開那天的文件（9-21 講完電話就讀報告、9-26 讀信、1963 年讀回信、1964 年讀錄音……）。
  為什麼不選：故事一直被文件打斷，前五分鐘就要讀三份空軍文件，跟 H 軸的解說片沒有差別；說書版要試的正是「先講完，再開檔案」會不會留得住人。

站主 2026-10-26 說「用推薦的就好不用問」，採用 A。
