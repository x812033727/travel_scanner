# 手動上傳到 YouTube

在影片後台的「送到 YouTube」表單，或已停止的「YouTube 同步」面板，按
**手動模式：下載檔案與複製文字**。配額用完後也能使用；不必先重試 API。

1. **影片**：尚未上傳時下載完整的 `final.mp4`，在 Studio 建立影片並先設私人。
   已有 YouTube ID 時直接開啟原影片，不再提供重複上傳 MP4 的操作。
   不確定先前的 API 上傳是否成功時，先到 Studio 確認。
2. **文字**：選語言，分別複製標題、含章節的完整說明，以及影片標籤。
   原始語言貼在影片詳細資料；其他語言貼在 Studio 的字幕／語言頁之「標題與說明」。
   表單尚未送出的標題／說明會帶入手動模式，切回 API 模式也會保留。
3. **縮圖**：下載圖片，在影片詳細資料上傳並儲存。
4. **字幕**：按檔案上的語言逐一下載，到 Studio 對應語言選「包含時間碼」上傳。
   已發布的字幕可跳過。發布字幕不等於公開影片。
5. **設定**：依核准包的目標觀眾、合成內容揭露、類別與語言，在 Studio 確認，
   最後自行儲存及選擇公開時間。網站顯示的原定時間僅供對照。

備用的 `description.en.txt` 等檔案第一行是標題，空白行後為說明；
`metadata.json` 記錄完整設定。這些是閱讀用檔案，不用傳到 YouTube。

## 實作界線

- 只讀取既有的 `/admin/videos/{slug}` 與受管理員權限保護的檔案下載路徑。
  不呼叫 YouTube，也不新增排程、同步或完成狀態。
- 只採用最新已核准的 publish review。進行中的同步、未核准及已放棄影片不提供手動操作。
- 字幕語言支援現有及舊版 role 命名；檔案下載保持原雜湊，合集使用既有完整影片下載路徑。
- metadata 讀取失敗時保留可用的核准文字／下載，缺漏設定明確顯示未指定。
- 手動操作完成後，網站原本的 API「失敗／等待」可能仍存在；以 Studio 實際狀態為準。
- 本功能不會解除 YouTube 對未通過 API 稽核的上傳影片施加的私人限制。

## 驗證

`npm run test:web -- components/admin-video-manual-upload.test.tsx components/admin-video-youtube.test.tsx`

覆蓋配額失敗入口、既有影片防重複、五語複製、字幕與縮圖下載、
表單編輯保留、缺檔／缺資料／權限錯誤、合集及沒有 API 寫入。
