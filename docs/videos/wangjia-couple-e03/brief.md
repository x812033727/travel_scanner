# 汪家夫妻 EP3〈等妳出門〉

## 故事前提

阿福在玄關敲錶敲到錶面裂開、翻白眼嘆氣催珍珠出門；浴室門開一條縫，珍珠只畫好一隻眼，默默把門關上鎖起來。下一格阿福還站在原地，長出拖地的白鬍子、全身蜘蛛網、頭頂鳥巢裡三隻雛鳥，窗外在下雪。他吸一口氣想再嘆，雛鳥同時瞪他。最後浴室門終於打開，一隻粉紅拖鞋踏出來——停一拍，又縮回去。

## 角色

- 阿福（afu）、珍珠（zhenzhu）：同系列定裝照。這一集珍珠只有半張化好妝的臉與一隻腳入鏡。
