# 網美小豬（系列）

站主 2026-11-03 選定（第二批零台詞系列企劃盲評第 2 名，中位數 84、新系列唯一拿到最想追看票；企劃全文 `docs/videos/zero-dialogue-series-ideas/round-2.md`）。

| 規則 | 內容 |
| --- | --- |
| **零台詞** | 沒有台詞、旁白；只有配樂與音效，關靜音也看得懂 |
| 長度與格式 | 約 15–17 秒，9:16 Shorts／Reels |
| 畫風 | 寫實 AI，真實外觀的小豬與水豚站著、穿衣服；世界裡沒有人類 |
| 角色 | 粉粉（粉紅小豬：白蕾絲洋裝、大草帽配粉紅緞帶、珍珠髮夾）、水豚男友（綠漁夫帽、灰 T 恤、面無表情、脖子掛行動電源） |
| 公式 | 唯美特寫（角落已露一點破綻）→ 快門閃光、只有眼珠一瞄 → **拉遠揭曉**假景 → 揭曉畫面外的男友 → 成品照裡的男友破綻 → 重擺、loop |
| 鏡頭 | 小豬與水豚**永遠不同框**（成品照裡的「臉」是唯一例外，屬於照片內容） |
| 不拍 | 吃喝、看得懂的字或介面、品牌；手機只拍舉高的中景 |
| 製作與語言 | Colab 首格與 H3 直式片段 → ffmpeg 剪接 → `shorts import`；八語只翻標題與說明 |
