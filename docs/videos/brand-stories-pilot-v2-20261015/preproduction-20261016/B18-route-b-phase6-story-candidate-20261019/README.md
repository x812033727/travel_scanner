主要來源及網址在 `B18.md` 尾端，均沿用 Row10c 的六個來源欄位。此版新增的兩項主張分別對應 [J-Net21 首店敘述](https://j-net21.smrj.go.jp/special/expo1970/20231113.html)及[石野集團官方年表](https://www.ishino-group.com/history/)。1978 年設備商販售機器，**不表示**元祿在 1970 年萬博使用，也不表示剝蝦、剪海苔或排隊問題由那台機器解決。撲克牌／名片兩種扇形靈感說法保持分開；1967 年仙台／東京展店屬法院判決記錄的獲授權另一家公司；1972 年屆滿只指法院認定的第 579776 號實用新案；1985 年仍在運轉的輸送機與另存早期板片不是同一件物品。
