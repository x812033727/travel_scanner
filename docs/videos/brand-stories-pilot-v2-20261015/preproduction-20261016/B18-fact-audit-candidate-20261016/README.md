## 關鍵衝突：1978 不是已查定的原始權利期滿日

- [發明協會的產業沿革](https://koueki.jiii.or.jp/innovation100/innovation_detail.php?eid=00026&age=high-growth&page=keii)「イノベーションに至る経緯」網頁 L34、L43 把白石 1962 年名下 `コンベヤ附調理食台` 寫成實用新案，並說相關權利期滿後 1978 年起大量新業者進入。[J-Net21 的元祿產業報導](https://j-net21.smrj.go.jp/special/expo1970/20231113.html)「市場規模は7500億円に」則把該權利稱作「特許」，同樣寫 1978 年失效。[白石博志的 Kindai Picks 訪談](https://kindaipicks.com/article/002589)約第 180–182 行也說 1978 年，但沒有指認登錄號；這是家屬回憶，不足以覆蓋權利登錄資料。
- [日本法院官方判決 PDF](https://www.courts.go.jp/assets/hanrei/hanrei-pdf-13913.pdf) 的**判決理由**在 PDF 第 9 頁（0-based P8，L466–469）認定 `コンベヤ附調理食台` 是 1960-02-20 申請、1962-12-06 登錄的實用新案 **第 579776 號**；第 11 頁（0-based P10，L574–578）明確認定「本件實用新案權」於**昭和 47 年，即 1972 年**期滿，之後已有多家與原告無關的輸送帶壽司店。這是法院的事實認定，並非單引被告答辯。
- 同一判決第 6 頁（0-based P5，L306–315）的**被告答辯**進一步說 1972-07-24，並提到另一件 `被覆を装備するコンベア附調理食台`、登錄 **第 851953 號**，當時仍牽涉授權；具體 1972-07-24 與第二件權利的屆滿日尚未由公報或判決理由獨立核實。不能把兩件權利混成同一個「1978 才開放市場」的故事。

因此 `B18-PC-H02-4`、`B18-PC-T02-1` 的 1978 期滿句與 `B18-PC-T02-2`、`B18-PC-T02-3` 隨後的入場／加盟因果皆維持 HOLD。若暫時不查清完整權利鏈，安全的敘事方向是：先說 1962 年登錄的**實用新案**曾保護部分裝置、元祿一度擴張；後來基本權利屆滿、其他權利和品牌授權仍糾纏，新業者逐步加入。不要把單一年份說成全國擴張唯一開關。這是**改稿方向**，尚未產出或核准新旁白。
