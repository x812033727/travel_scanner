# A01 r21 離線敘事盲讀收據（2026-10-19）

## 範圍與判定

先只讀完整 `candidate/script.md`，獨立判斷開場懸念、相鄰場景的因果、人物引入、節奏和結尾回收；之後才看 r20 盲讀收據、兩版文字差異與 r21 metadata。`manifest.json` 的列示輸出已逐檔重算 SHA-256，均相符。這份收據只評**離線故事**；另有來源審查指出的 P1 不由此抵銷，也不構成 74 筆主張的正式查核、TTS／成片驗收或主機 `script-review.json`。

**敘事判定：P0 0、P1 0、P2 1；故事可繼續試讀，但整體製作仍 HOLD。** `hook-01` 至 `hook-06` 以重箱、安妮塔旅後是否繼續使用、百貨能否上架及安檢困境建立具體問題；`origin-1939-case`、`engine-07b`／`engine-10`、`turn-07c` 和 `now-1993-stow` 分別回收問題。安妮塔的自製箱、Sadow 的通路阻力、Plath 的操作困境與後續市場使用，形成回答片名的連貫故事；片尾的「肯拉、店肯賣、用起來順手」自然收束，並把三人間直接傳承限定為本集資料無法證明。

## P2（非阻斷的銜接提醒）

`turn-09b`（第 49 鏡，稿第 224 行）緊接車庫把推車與箱子用螺絲固定、安檢員答「好」的回憶，口播只說「箱身直立，底下兩個輪子……」。第一次聽可能把後來的直立拉桿設計理解成同一款螺絲推車實驗的即時結果。畫面提示已把直立箱放在中性背景、離開車庫；若要在純音訊也清楚，可在口播或剪輯中給一個「後來」的時間橋，勿把日期未明的安檢回憶硬併到 1987／1988。這是敘事歧義，未判作史料 P1；史料由另組逐條審查。
