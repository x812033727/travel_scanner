## 來源界線

關鍵官方或訪談來源原文位置在 `source-evidence.json`： [石野集團公司沿革 1978 年 4 月](https://www.ishino-group.com/group/) 明確記錄大増商事設立「全國くるくる寿司連鎖總部」及入江第一家**直營**店；[石野集團市場年表 1975 年](https://www.ishino-group.com/history/) 僅記金澤「一號店」，**沒有寫經營者**。這兩個不同口徑不能合併，也不能把金澤店算成石野製作所、北日本カコー或大増商事的直營店。[J-Net21 訪談](https://j-net21.smrj.go.jp/special/expo1970/20231113.html) 明載 1960 年道頓堀第二店、萬博外國訪客、排隊後改 300 日圓握壽司套組與仍繁重的人工備料；沒有改套餐後隊伍長短的量測。1980 年檀香山是設備出口，不能推成元祿分店。法律號碼留在非口播來源註，不朗讀。
