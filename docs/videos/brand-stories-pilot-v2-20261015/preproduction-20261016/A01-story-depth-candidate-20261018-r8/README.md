## 三處增量修正

1. **兩段經歷分開說。** Shiller 使用的是他自己的四輪拖帶箱；下一章明確另起西北航空機師 Robert Plath 的故事。兩人的箱子、遭遇與影響關係沒有來源可以串成同一條因果線。Emmer 未標年份的機組輪袋回憶，以及 Plath 未標年份的安檢外置推車回憶，仍各自歸屬。
2. **安檢畫面對上旁白。** `turn-05` 畫面可見前方旅客在安檢口解開彈力繩，準備把箱子從獨立金屬推車卸下；下一鏡再看卸箱細節。此時不畫 Plath 後來的螺絲固定組合，也不畫安檢員答覆或通關結果。
3. **1928→1939 的回路不外插。** 開場只問旅後 Anita 是否仍帶輪箱。回收文字限於 1939 年當地報紙記下她在**一場**茶會身旁有輪箱；這不能辨認為 1928 年同一只箱，也不能推定其間每年持續使用。丈夫的反應留在正文，不寫入開場未說的問題。
