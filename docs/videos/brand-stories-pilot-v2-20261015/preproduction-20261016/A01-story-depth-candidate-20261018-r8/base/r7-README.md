## 修掉的問題

- **開場前四鏡縮成兩個動作：**Sadow 在波多黎各機場手提沉箱，另一人推著載重機器的輪板；他轉頭對妻子說的一句話留到正文才說。刪掉重複描述「機器輕鬆走、箱子仍重」的兩鏡。1928、1970、Travelpro 歸因的 1987 年三個預告仍不先說結果；Anita 丈夫是否接受輪箱依史料留到正文。
- **刪掉低價值問句：**「普通手提把還能留下嗎」只是專利資訊，照原稿簡述，不再當成觀眾要等近一分鐘的答案；「百貨採購怎麼看」重複開場已有的進貨問題，刪去。短到只隔一鏡的舊 `loops` 列也從表中刪掉，旁白事實照留。
- **安檢只走一條人物線：**Shiller 自用舊拖帶箱的晃擺結束後，另起 Plath 的機組回憶，再以「另一段時間未明的回憶」進入他在安檢看到外置推車的故事。刪掉 Macy 章預先出現的推車與第一次安檢問句；只留下 Plath 對「鎖在一起能否過安檢」的一次具體疑問和他自述安檢員答「好」的回收。Emmer 草圖故事與安檢回憶未證先後，不建立因果。
- **刪掉答案先到的問題：**「誰先把箱子拉到旅客眼前」在空服員畫面前一瞬就被揭曉，因此刪去回路；機組使用、旅客看到的事件正常往下講。
- **1993 實測不再冒充 2010 年因果證據：**刪掉「輪子好推是否導致多裝」的預埋問句與過場畫面。記者把衣物和平裝書加進外袋，是她那只箱子的收納測試；多年後受訪空服員對旅客裝得更滿的觀察，另行歸屬。1989 倉庫與 1991 轉全職兩段公司年表移到特定外袋收納問題**之前**，讓問題直接接 1993 實測。
