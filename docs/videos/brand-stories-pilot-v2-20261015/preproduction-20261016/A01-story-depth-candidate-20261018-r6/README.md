# A01 輪子行李箱：r6 故事鉤子離線候選 — HOLD

這是從 r5 衍生的**另一份離線候選**。`base/` 保存 r5 的候選稿、來源表、驗證表、README 與 manifest 位元組快照；`build.mjs` 會同時核對 r5 原目錄與快照。r5 以前的任何檔案、正式機章稿及審稿收據都沒有改。這裡只調整口播懸念、兩個畫面在揭曉前的內容，以及對應的稽核資料；不代表可以在主機上套用。

## 這一輪改了哪些真正的轉折

- 開場仍從 Sadow 在機場看見推重機器開始，但不先說出 1928 年安妮塔丈夫嘲笑輪子箱；父親是否跟著拉，到正文才依溫尼特卡歷史學會的記錄揭曉。1928 年是否在旅後繼續使用，仍要等 1939 年 Midland 當時報紙的**一場**出席記錄回收；不能說報紙證明是同一只 1928 年的實物。
- Sadow 的問題從「箱底能裝輪子」推到「原來的提把能否保留」，答案放在他的 1970 年專利。接著讓靠繩拖箱的樣品進入採購視線，才讓採購依 Sadow 後來的訪問表示荒唐、拒絕。產品細節和買家的阻力各往前走一步。
- Shiller 自用的四腳輪拖帶箱與 Plath 看到的外置金屬推車仍分開講。安檢的兩個問題依序是「箱子與推車能否不分開」及「安檢員會讓鎖住的組合過嗎」；回答分別是 Plath 的車庫嘗試及他回憶的安檢員答覆。不推斷他受 Shiller 啟發，也不替兩段未標明先後的 Plath 往事排序。
- 旅客看見機組拉箱之後，1993 年《洛杉磯時報》記者的外袋收納問題仍經過實際裝入衣物與書才揭曉。早先那張疑問插圖不再重複後面裝外袋的動作，也不預示放不進機艙的結果。最後由一位受訪空服員的觀察回答「好推會不會裝得更滿」，不當作普遍統計。

七組新回路的 setup、payoff、來源與限制逐組列在 `source-map.json`。`validation.json` 分開量「明說的未解問題」及「有來源事件的轉折代理」；兩者都只是依文字與 250／275／300 口語單位每分鐘估計，**不是 TTS 實測，也不是盲聽通過**。短於二十秒的回路不能拿來充數，必須由獨立聽眾判斷是否自然。若正文任何一段仍超過約 45 秒而缺真正推進，保留 HOLD，不用問號、停頓或重複內容補。
