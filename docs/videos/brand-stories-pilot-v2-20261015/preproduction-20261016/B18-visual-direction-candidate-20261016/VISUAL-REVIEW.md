# B18 視覺審查便箋（未簽核）

## 已知風險與留待實看

1. **史料版本**：`idea-s028` 是 J-Net21 轉述的撲克牌版本，`idea-s029` 是發明協會的名片版本。兩張都是示意，不等於有當時照片。`idea-s030` 明確將兩本空白資料夾分開，旁白才說無法判定哪一種真是現場。
2. **原件與身份**：所有人物均匿名；插畫中的工廠、店、工作台、裝置圖、權利資料夾、會場只示意故事位置。`now-s096` 是兩件分開的概念模型，沒有畫 2021 年的實際館藏處理事件；不能以圖片宣稱它們是白石本人、原店、原圖紙、原展位或館藏物。產圖後尤其要防模型自加文字、商標、太陽之塔或把早期板片併進後期機器。
3. **時間與地域**：1947 布施小店、1948 吹田工廠、1957 試作、1958 首店、1970 大阪會場、1970–80 年代不同店型有不同環境。`engine-s048` 只寫「後來」的大阪展店，避開道頓堀 1960／1962 的史料衝突；`turn-s079` 只示意 1972 後有其他店，不能讀成期滿就是唯一開店原因。
4. **結尾視覺**：`now-s100` 手與盤子的距離、`now-s101` 一張圖的一處轉彎、`now-s101b` 單條街的餐廳、`now-s102` 食客選盤、`now-s103` 留白結束畫面都需在聯絡表上檢查實際差異。模型如把它們畫成同一張店面，須在既有預算和修圖規則內窄修，不能單靠這份提示詞宣稱已解決。
5. **剪輯風險**：71 張插圖／90 景、19 張原生字卡、幾個超過十秒的估計停格仍保留；沒有 TTS 或成片。視覺候選不會修正長鏡或字卡比例，需在實際聲畫小樣與手機預覽判斷。品牌故事只有旁白，漫劇專用的角色台詞與動作指標不宜直接當過關條件。
6. **機械警告讀法**：官方 lint 仍有 22 條 warning；重複詞現在是 `counter`、`window`、`japanese` 等場景名詞。`craft risk.decorative` 報 29／71 張「沒有人」，但 `tools/video/core/craft.mjs` 的 `PERSON` 詞表不認 `chef`、`visitor`、`operator`、`worker`、`diner` 等本集角色詞，不能把這條直接解讀成 29 張空景；逐鏡人看與實際圖片仍要驗。`craft motion.look` 也讀 `data.motion`，本片靜圖只有慢運鏡而無角色動態描述。
