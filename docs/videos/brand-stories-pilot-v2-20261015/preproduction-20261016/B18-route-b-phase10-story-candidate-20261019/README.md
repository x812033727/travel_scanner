- E03 引述 J-Net21 的**白石第二家店**道頓堀；T01 持續明稱**另一獲授權公司**，並把其 1968 年郡山「連鎖第二店」的主詞留在同一句。道頓堀確切年份仍不朗讀、不畫年卡。1970 → 1967 → 1968 → 1970 的倒敘明示。
- T04 刪除「不能畫成」的口播製作指示；1958 首店不得畫成後場直線改裝的限制，移至 T04 非口播註與 `turn-s072` 畫面理由。T05 先講茶與收盤，再區分大増商事店和石野設備商；大増商事總部全名保留在來源卡。
- T06 刪去 Phase 9 重講郊區家庭店的兩個舊口播錨點 `t14`／`t15`，保留為非口播溯源。新增石野市場年表的 1983 年多段價格事件，接發明協會記錄的**未定年**盤色分價辦法；不把兩來源硬說成同年或同一店。N01 新增 2015 年「不迴轉的迴轉壽司店」的點餐／直接送餐轉折，再回到 2021 年機械遺產。兩項新主張及兩個概念畫面均待審，沒有生成圖。

## 來源邊界

- [J-Net21 訪談](https://j-net21.smrj.go.jp/special/expo1970/20231113.html)與[發明協會沿革](https://koueki.jiii.or.jp/innovation100/innovation_detail.php?eid=00026&age=high-growth&page=keii)的「約十年」都是發想至試作的全程，沒有量出單獨解轉角花了幾年。J-Net21 寫道頓堀第二店於 1960 年開；[法院判決](https://www.courts.go.jp/assets/hanrei/hanrei-pdf-13913.pdf)採認原告公司 1962 年 4 月的道頓堀展店。口徑未釐清，不能口播一個確定年。法院另列 1967–1968 年**獲授權公司的**仙台、東京、郡山展店，郡山的「第二」只在該公司的連鎖序列裡計次。
- [石野集團市場年表](https://www.ishino-group.com/history/)列 1983 年多段價格定著、1984 年家庭客郊區店及洋風店名、2015 年各地有觸控點餐與直接送餐的「不迴轉」店；它沒有給任何特定店的盤色辦法年份，也沒有說所有店停用迴轉帶。`source-evidence.json` 分列來源原文、位置、可說與不能推的界線。
- 1991 年《廣辭苑》第四版新增「回転寿司」，除 J-Net21 與石野年表外，[岩波書店辭書編輯部供稿](https://news.noitamina.tv/funewoamu/article/20161019__11.html)也列該新增詞；原版字典頁尚未直接檢視，`n8` 繼續 `UNCHECKED`。概念畫面不能偽造字典內頁、真實觸控介面、店面或設備示範。
