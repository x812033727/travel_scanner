### A. H01–H03：先有人物與阻力，再留三個不同時刻

> 啤酒瓶一個接一個在輸送帶上向前，白石義明卻想到壽司店裡：客人越來越多，師傅忙得快跟不上。一九四八年，他在大阪吹田看到了這條會動的線。壽司盤，也能這樣送嗎？
>
> J-Net21 記下，後來試作的帶子一到轉角就堵住，盤子掉了。白石怎麼把盤子送過這道彎？一九七〇年大阪萬博，西口站前也開了店；那條線面對人潮，能送得及嗎？發明協會另記，之後有店改在後場做壽司；盤子和客席隔著一段路，最後這段怎麼送？
>
> 小店裡，師傅還在一盤盤遞。

這是由 [J-Net21 的 1948 工廠、轉角故障與 1970 萬博記載](https://j-net21.smrj.go.jp/special/expo1970/20231113.html)、[發明協會的後場直線記載](https://koueki.jiii.or.jp/innovation100/innovation_detail.php?eid=00026&age=high-growth&page=keii)取材的**改寫示意**，沒有聲稱他當場說出任何話。現有視覺破梗必須另改；新開場的 30–60 秒、來源歸屬與每個 loop 的 line ID 也須重新計算。

### B. E04／T01–T02：法律界線簡短說清，回收時講精確權利

> 元祿壽司也向相似的店發出過警告。J-Net21 記載，他們在東京和大阪請律師與專利代理人處理。但餐台的登記只針對那項裝置；壽司店的招牌，得另看。

> 發明協會說，萬博出店受表彰，元祿壽司靠加盟後來到約兩百四十家。展店其實早於萬博：法院判決記載，一九六七年，獲准使用餐台與元祿招牌的**另一家公司**，在仙台開直營店，也把連鎖店帶到東京。

> 至於先前那項登記，法院確認的是第**五七九七七六**號餐台實用新案在一九七二年期滿。判決也記載，之後已有與本案原告無關的公司經營輸送帶壽司店；它沒有說招牌、其他設計和每一家新店，都能用這同一個年份解釋。

本示例的時間跳接要靠前段 E05 萬博實事支撐；E04 不預先重講 E05 的邀請、地點與客流，也不把「哪一年到期」這種日期測驗算成新鉤子。不能把 1972 到期說成 1967 授權展店、所有後來開店或後場直線路線的單一原因。[法院判決 P8 的獲授權公司與 P10 的特定權利](https://www.courts.go.jp/assets/hanrei/hanrei-pdf-13913.pdf)、[J-Net21 的警告與萬博出店](https://j-net21.smrj.go.jp/special/expo1970/20231113.html)、[發明協會的 240 家說法](https://koueki.jiii.or.jp/innovation100/innovation_detail.php?eid=00026&age=high-growth&page=keii)需逐句重審。這不是法院認定「警告有效」的證據，也不給未確認的警告結果。

### C. N01–N03：用兩件實物收束，少念一次路線清單

> 二〇二一年，日本機械學會列出的第一百一十二號機械遺產，有兩件不同年代的東西：一台是一九八五年製、當時還在堺東店運轉的輸送機；另一組，是元祿產業另外保存的早期「ウロコ」板片。這不是一九五八年首店那台機器一路轉到今天。

> 當年讓盤子轉過吧台角落的是早期板片，後來不同店依廚房和座位重畫盤子的路。

> 留下的不是某一台不停轉的老機器，而是壽司做好後，客人伸手就能拿到盤子的那一步。你吃迴轉壽司時，會先拿眼前那盤，還是等最想吃的一盤？如果你喜歡聽熟悉事物怎麼一步步變成今天的樣子，歡迎訂閱。

[日本機械學會第 112 號](https://www.jsme.or.jp/kikaiisan/heritage_112_jp.html)把 1985 年堺東店當時仍在用的整機，與元祿產業另存的早期板片分開列明。第二段是依整片已講路線做的**編輯收束**，不主張每家新店都沿用同一早期板片；真圖也不能把兩件實物畫成一台 1958 原機。

三處替換若連同 E04、T01–T02、N01–N03 一起採用，會改動已審稿的精確 hash、既有 65 項 claim 錨點、95 景分配、三個 loop line ID、片長與 `now-outro` 長度。不能把示例直接貼進 Phase 4 的六個 `remapped-chapters/*.json`；應在**新的隔離稿**重排、重新量字與真 TTS、重新對來源與畫面，先獨立審稿再談正式 worker。尤其不能為了達到八組回路而增寫沒有原始來源的個人對白、警告結果、特定店面的轉型路線或未證實的年份。

這三組示例也**不是完整片長方案**。同一計數法下，A 開場從 128 變 177 字、B 法律三段從 392 變 230 字、C 結尾從 310 變 213 字；若其餘段落全不動，淨少 210 字，純口播會從 8:54 變約 **8:12**。這只是紙上算式，不是 TTS；若 9–11 分鐘實測未達標，須找有來源且推進故事的新事件或重新界定篇幅，不能把刪去的清單換成空白、慢播或重複問題。
