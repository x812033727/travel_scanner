## 第四章｜專利寫下旅客得自己走的路

| 行 | 旁白 |
| --- | --- |
| T01 | 百貨公司把箱子放上貨架，只是第一步。旅客買回去，還得自己帶到車站或機場；薩多在專利說明書裡，寫下這段搬運怎麼落到旅客身上。 |
| T02 | 他說旅行的人變多了。過去行李常由搬運工接手，在靠近街邊的地方上下車；如今到了大型航站，尤其是機場，旅客常得自己處理箱子。 |
| T03 | 史密森尼後來回顧，汽車能把人和行李一路載到目的地附近，飛機卻不同：報到、轉機和抵達，都可能讓旅客帶著行李步行。 |
| T04 | 在薩多的申請書裡，旅客有時得走很遠；一只沉重的箱子，不能只在出發地被提起一次，而是每走一段就得自己照看。這是他提出的使用難題，不是梅西百貨的銷售調查。 |
| T05 | 他的辦法很直接：讓箱底落到地上，四個輪子接住行李，再用一條柔軟的拖帶牽著走。人還是得走路，卻不必從航站的一頭到另一頭始終用手提著箱子的重量。 |
| T06 | 薩多在申請書中特別說，希望新設計仍保有普通行李的外形、大小和樣式。專利圖上的輪子分在箱蓋與箱身兩側；箱子合起來，兩邊各一對輪子一起著地。拖帶扣在箱子上緣，原來的提把也還留著。 |
| T07 | 旅客可以遇到不能滾的地方時提起它，回到平地又放下來拖。同一只箱子，於是有了兩種搬法。 |
| T08 | 但拖帶跟著箱子往前，箱子是橫放在四輪上；到了人多、要轉向的地方，帶著它走還能更順手嗎？十七年後，一名天天進出機場的機師又遇上這道題。 |
