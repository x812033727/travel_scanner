## 每支影片的觀看順序

1. 第 1 秒進入具體場景。旁白開場 30–60 秒，只預告後續三個有年份的轉折，在結果前停住；預告要按事件順序，正文逐一回收。
2. 第一章後接頻道 **5 秒動畫片頭**。第二章從人物和困境出發，之後每章由上一章的結果引出下一個問題，不念章節目錄，也不重播已說過的答案。
3. 六章合計目標旁白正文 **約 10:00**，實際秒數由 TTS timeline 與 `ffprobe` 量。正文至少 8 分鐘；材料不足就縮短或退回企劃，不能用沉默、慢播或片頭片尾充數。只用台灣口音單人旁白；繁中字幕跟音訊。
4. 正文末三句回答開場、留一題與故事相關的留言問題、給有理由的訂閱邀請。接 **21 秒動畫片尾**；YouTube Studio 在最後 16 秒設「最符合觀眾喜好」影片、訂閱與「最新上傳」影片，實際上傳後逐項點擊驗證。MP4 卡位本身不可點。

畫面以 MiniMax 可愛卡通**靜態插畫**說故事。`look` 只能是 `{"preset":"cute-mystery"}`，不加 `style` 或 `negative`；不生成商標、名人肖像、真實文件內文。全部正文鏡頭用 `visual: "still"` 與後製緩慢運鏡，**生成影片 clip 鏡頭數為零**；片頭片尾沿用頻道既有 v4 動畫素材。若成片格式需要配樂，只能在整支 US$25 帳本內預留有上限的一條配樂，不開無界重試。提示詞逐鏡只寫時地、景別、**一個一般化人物做一件事**、焦點與光線。正文至少 70% 是插畫 `shot`，連續卡片最多三張；卡片只放必要的數字、名字、短引文或來源。插畫是故事示意，不聲稱重建歷史現場。預估 75–120 張只是排程假設，付費前需依定稿分鏡估全片張數、重畫、judge、TTS、文字模型、轉錄與合成的上限。
