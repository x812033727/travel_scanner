# A01｜輪子行李箱：為什麼早有人做，旅客卻很晚才開始拉？

## 點閱承諾與主線

**標題假設**：「輪子行李箱早有人發明，為何等到登月後才賣得動？」登月只作時間對比，不寫成產品流行的原因。縮圖左邊是沉重、無品牌的舊皮箱，右邊是細輪和長繩，後製主字「早有輪子，沒人買？」；不能把歷史照片、專利圖或當事人肖像偽裝成生成圖。

唯一主線是一只箱子的上架與改良：1928 年出發時已有自製輪子箱 → Sadow 在機場看到輪板並做出四輪橫拖箱 → 百貨公司先拒賣，Macy's 使它上架，據 Sadow 回憶顧客立即接受 → 他的專利指出大型航站的長距離步行問題 → Plath 把箱子立起來，加上兩輪與伸縮拉桿 → Samsonite 的四輪直立箱及萬向輪又延伸使用方式。前案、上架、使用問題、後續改良是不同步驟；專利說明書不能單獨證明銷量因果，Plath 的 1987 年設計也不是 Sadow 的 1970 年箱子獲接受的前提。

## 濃縮開場旁白（約 45 秒，錄音後量測）

> 波多黎各機場，一位行李箱公司主管拖著兩個塞滿的箱子，卻看見工人用帶輪子的墊板，輕鬆推走更重的東西。
> 他把輪子裝到行李箱上，帶去百貨公司。採購為什麼不想賣？
> 一九七〇年，箱子終於上架。旅客這時到底碰上了什麼麻煩？
> 十七年後，一名機師又在車庫改掉箱子的姿態。為什麼航空公司的人先搶著用？
> 更奇怪的是，輪子箱早在這一切之前就有人做過。這只箱子缺的，真的只是四個輪子嗎？

第一句用人物、物件和動作落地；三個年份按 1970、1987、再回溯前案的提問安排。工人與主管的相遇由 [ABC 2010 年訪問](https://abcnews.com/Travel/suitcase-wheels-turns-40-radical-idea-now-travel/story?id=11779469)轉述，不能額外編對話或表情。插畫人物只用匿名旅客，不畫 Sadow 或 Plath 的可辨識肖像；畫面是明顯卡通示意，不冒充當年影像。
