# 《恁祖媽今年18》第 59 集〈古董商〉

## 故事前提

第 43 天上午，老陳一早看見林美鳳進了錢老闆的古董店。她帶著知遠推門進去，錢老闆手一抖。她問今早林美鳳賣了什麼；錢老闆說兩萬塊收了一個不值錢的舊印，
可玻璃櫃裡那塊絨布的凹槽已經空了。他拿出鑑定書說是清代的老銀印、買家搶著要；她看一眼就說環鈕的刀法是民國的工，抬起手上那枚戒指：同一個師傅的手。
錢老闆乾笑著招了：兩萬收進來，兩百萬轉給周董的人，周董早交代過「沈家的銀印，有幾枚都要」。知遠問周懷安要銀印做什麼，錢老闆壓低聲音：「不是他要。」他是替別人收的。
傍晚，新城區的公寓門口，盛通的人交給建業一個牛皮紙信封：「合作愉快，到此為止。」裡面是建業自己簽的股權轉讓書影本，和一張紙條「老宅的事，你自己擔」。
林美鳳問怎麼辦，建業抬頭看向老宅的方向：「那個保母，要付代價。」
