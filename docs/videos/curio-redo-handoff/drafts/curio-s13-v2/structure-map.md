## 鉤子怎麼排

- **鉤子**：先對觀眾說他是誰（遊戲裡的真田幸村、四百多年前在大坂打仗的武將），再翻出反差「他親手寫的信，沒有一封簽幸村」，用 1917 年的圖版當證據畫面（標題幸村、簽名信繁）。之後只丟兩個高潮標籤：報告旁被後人補上的兩個小字、文化六年真田家擬好的答案。不講小字是什麼、答案是什麼。
- **起源**：從系譜稿的出生年與幼名講起，交代「幸」字是祖父和父親名字裡的字、他起初叫信繁，然後是站錯邊、九度山、要燒酎的信與「好白」，最後進大坂城。
- **轉折**：每一關的結尾都停在問句上，下一章第一句接住（別人怎麼寫他 → 敵營就有；最早寫進哪本書 → 一般認為《難波戰記》；真田家自己怎麼記 → 還記得系譜稿嗎；怎麼變成全國都知道 → 說書和小說）。
- **收尾**：步 9 回到開頭的問題，把「不知道」（誰取的）和「答得出來」（他自己用沒用過）分開講，倒帶串回正月、二月、三月三封信，收一句金句，再存檔。
