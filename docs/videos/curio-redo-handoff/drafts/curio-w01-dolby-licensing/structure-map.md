## 鉤子、起源、轉折、收尾怎麼排

- **鉤子（步 1）**：問句情境（你家電視上的兩個字）→ 利害（每台付一筆、13.49 億、九成三）→ 流傳的說法 →「但你想不到」翻出反差（第一筆生意賣自己造的機器）→ 兩個高潮標籤（1996 平安夜有人反對；年報至今寫得一直說服別人）。都停在結果之前，不講原因。
- **起源（步 3）**：「故事得回到一九四九年的美國加州」，先給年份地點與時代痛點（磁帶嘶聲），再讓主角一路走：打工、錄影機、劍橋、印度、想通原理、1965 開車回英國途中在阿富汗寄信。雷·杜比本人不入畫，用器材與 Ada 帶。
- **第一次起落（步 4）**：倫敦工廠一角 → 先做影像，BBC 沒要（挫折）→ 回頭做聲音，A 型、迪卡九台（翻身）→ 名字變成「杜比」→ 小結「這就是杜比的起點」。
- **升級關卡（步 5）**：三關。家用版不自己造卻押錯開盤機 → 卡帶翻身、授權家數、專利遲到 → 進戲院，母帶、1975／1976、星際大戰、六千家、AC-3。每關結尾都留一個問句。
- **最大反轉（步 6）**：平安夜看似大勝，「事情有這麼簡單嗎？」翻成門票也是繩子，範圍只到美國地面數位電視。
- **揭曉（步 7）**：真正收錢的機制與九成三的正確意思。
- **尾聲（步 8）**：「故事到這裡還沒結束」，電視在掉、手機得一直說服、最後的 7%。
- **收尾（步 9–10）**：半句對半句錯 → 倒帶串回四個意象 → 我的解讀 → 存檔 → 對觀眾提問 → 訂閱。
