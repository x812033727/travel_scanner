## 最大的改動：從「倒著追」改成照時間走

原片的主角是這句話，順序是 1740 開場一景 → 1775 → 1841 → 1843 → 1782 → 1760 年代 → 1740（揭曉「他就是盧梭」）→ 1835。
這是倒敘偵探結構：開場先演里昂那一幕，正片從 1775 開始倒著追，第 8 章才回到開場。RULES 第 1 條（拿掉開場的濃縮劇情）與第 4 條（不跳時間）都會打到它，所以全片改成照時間順著走：

1740 里昂糕點店 → 1760 年代後半寫書、她在維也納 → 1770 嫁到法國 → 1774 當王后 → 1775 麵粉戰爭與兩封信 → 1778 盧梭過世、1782 書出版、1783 英譯 → 大革命的文宣 → 1793 她過世 → 1841 卡爾 → 1843 卡爾自己說大概不是她 → 1903 英譯 → 1907 伯爵夫人回憶錄 → 收束。

主角一直是「這句話」：每一段都在交代它此刻在誰手上、被寫成什麼樣子，不換主角。

懸念從「開頭那個年輕人是誰」換成標題本來就揭曉的反差（書裡那件事比她出生早十五年），加上「那它是怎麼跑到她頭上的」。鉤子只預告結果與兩個高潮標籤（她自己寫信提到麵包、最早寫她的人兩年後自己說大概不是她），不交代中間怎麼走。

**每一步怎麼排**

1. **鉤子**：你一定聽過這句話 → 大家說是瑪麗．安東尼 → 讓她背了「不知百姓苦」的名聲（這是什麼）→ 反差一：目前找得到最早寫到她名下的文字，在她死後四十八年 → 反差二：更早的書裡，那件事比她出生還早十五年（為什麼怪）→ 兩個高潮標籤：她自己寫信給媽媽提到麵包；最早寫她的人兩年後自己說大概不是她。
2. **承諾句**：Ada 說「今天我們就來聊聊：沒有麵包就吃蛋糕，瑪麗皇后真的說過嗎？」，接路線圖一句「我們照時間順著走，從一家糕點店的門口開始」。
3. **時代與起源**：「故事要回到一七四〇年的五月，法國里昂」→ 二十八歲的年輕人住進憲兵總監家當家教 → 偷喝侏羅小白酒、喝酒要配東西 → 佩劍不敢買麵包（問句）→「這像話嗎」→ 三十家糕點店、一個人跑遍全城、店裡只能有一個人 → 想起一位偉大的公主的話（原文第一次出現）→ 買了布里歐，布里歐不是蛋糕（埋「蛋糕哪來」）→ 他叫盧梭 → 那一年她還要再過十五年才出生（收鉤子的十五年）→「一件小事，我們怎麼會知道？」
4. **第一次起落**：二十多年後寫進書裡 → 英國鄉下、城堡、第六卷不能確定、快六十歲、「我想起」→ 憑記憶、錯一定很多、學者懷疑是編的、能確定的只有他已經知道這個段子 → 他寫書時她在哪？維也納十來歲、不到十三歲 → 1770 嫁到法國 → 1774 當上王后。小結：句子已經寫好、等著出版；她走上了王后的位子。
5. **升級關卡**：傳說裡的缺麵包日子真的有過嗎？有 → 一半收入、你會不會上街 → 穀物買賣放開 → 暴動、凡爾賽宮門口、巴黎麵包店、麵粉戰爭 → 名聲受傷 →「但這還不是最糟的」赤字夫人 → 我覺得黏得住她的原因 → 她知不知道麵包多貴？→ 加冕、六月二十二日的信（收鉤子的信）→ 只寫一次嗎？七月又寫 → 我讀到有點意外 → 能證明她沒說過嗎？不能。
6. **最大危機或反轉**：1778 盧梭過世、書還沒印 → 1782 日內瓦印出《懺悔錄》、洛桑版也有 → 公主是誰？沒寫 → 書出來時她二十六歲、當了八年王后（讀者身邊正好有一位王后：這句話最危險的時刻）→ 1783 英譯：酥皮點心，同一段又叫「一小塊蛋糕」（收「蛋糕哪來」的前半）→ 大革命：有人寫文宣罵她，卻找不到這句話（反轉：最恨她的年代沒用它）→ 1793 她過世，這句話還不在她名下。
7. **翻身與揭曉高潮**：直到四十八年後，1841 卡爾（收鉤子的四十八年）→《黃蜂》「人家傳說、不知真假」→ 轉述不是發明 → 兩年後他又寫了什麼？→ 1843：「人民」、沒寫哪一年、一七六〇年的書記在托斯卡尼公爵夫人身上 →「這大致證明不是她說的」→ 最早寫她的人自己說大概不是她（收鉤子的高潮標籤）→ 書名沒找到 → 鄉下人變人民、走了六十年。
8. **尾聲延伸**：「故事到這裡還沒結束」有沒有紀錄寫出說話的人？→ 1903 英譯還是酥皮 → 1907 伯爵夫人回憶錄：維多利亞夫人、極好心、含淚說肉派的酥皮 → 哪裡不一樣？好心 → 可靠嗎？1781 才出生、聽來的、1835 才動筆 → 蛋糕後來才成通行譯法（收「蛋糕哪來」的後半）。
9. **主題收束**：倒帶串回開場意象（同一家糕點店，門這次開著；兩頂帽子放在同一條路上）→ 我們覺得這句話一直在找主人 → 開頭那個問題 → 紀錄回答不了；書裡這句話說的不可能是她（畫面回到鉤子那張空搖籃）。
10. **提問與 CTA**：存檔 → 你第一次聽到這句話是在哪裡 → 訂閱。
