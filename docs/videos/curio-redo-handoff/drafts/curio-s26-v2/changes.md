## 敘事改了什麼

1. **從倒著追改成照時間走。** 原片先演里昂那一幕，正片再從 1775 → 1841 → 1843 → 1782 → 1760 年代倒著追，第 8 章才揭曉「開頭那個家教就是盧梭」。這正好是 RULES 第 1 條（開場的濃縮劇情）和第 4 條（不跳時間）要拿掉的東西。現在照時間走：1740 里昂 → 寫書 → 她在維也納 → 嫁到法國 → 1775 → 書出版 → 大革命 → 1841 → 1843 → 1907。主角一直是「這句話」，沒有換人。
2. **鉤子講得懂。** 依序講四件事：
   - 這句話是什麼。
   - 掛在誰名下。
   - 讓她背了什麼名聲。
   - 兩個反差：死後四十八年才有人寫到她名下；更早的書裡，那件事比她出生還早十五年。標題本來就揭曉了後者。

   接著是兩個高潮標籤：她自己寫信提到麵包；最早寫她的人，兩年後自己說大概不是她。中間怎麼走到那裡，鉤子不講。
3. **承諾句**改用固定句型「今天我們就來聊聊：……」，由 Ada 說。後面接一句路線圖「我們照時間順著走，從一家糕點店的門口開始」。
4. **前面埋的梗後面收。** 開場埋 5 條，全部兌現：
   - 四十八年 → karr
   - 十五年 → fifteen
   - 信 → june-quote
   - 卡爾自打 → rueful
   - 真的說過嗎 → verdict-b

   「蛋糕從哪裡來」在步 3 埋下，步 6（1783 英譯的「一小塊蛋糕」）和步 8（後來成了通行譯法）各收一半。「鄉下人」在步 3 埋下，步 7 用「還記得…嗎？」回收。23 條全部列在 `structure-map.md`。
5. **收尾倒帶**：同一家糕點店（門這次開著）、兩頂帽子放在同一條路上，接「這句話一直在找主人」，再回到鉤子那張空搖籃，下結論。
6. **刪掉的句子**（順序改了以後用不到，或會重述）：
   - mb110「倒著追一百年」
   - mb313「開頭那四十八年是誰寫下的」
   - mb408「那在他之前呢」
   - mb509–mb510「比卡爾早將近六十年有一本書，寫它的是誰」：書已經在步 6 出版過了
   - mb801 的「還記得…」：盧梭改成照順序介紹
   - mb815「說實話，我每次想都覺得不可思議」
7. **新寫的轉場句**（都不帶新事實）：
   - 「照理說，出門買一塊麵包就好了。可是，他不敢。」
   - 「可是，一個家教買麵包的小事，我們今天怎麼會知道？」／「因為二十多年後，他自己把這件事寫進了一本書。」
   - 「但這還不是最糟的」
   - 「故事到這裡還沒結束」
   - 「先說一件小事」
   - 「倒回去看」
8. **語氣**：沒有「我自己算的」這類句子。旁白自己的反應都交給 Ada，包括「我覺得」「老實說有點意外」「這就很怪了」「這就很妙了」「你看，有意思了」「我們覺得」。
9. 旁白裡沒有英文原名，所以 lexicon 不用加詞。

## 要站主決定的事

1. **倒敘改順敘。** 原片最大的揭曉是第 8 章的「開頭那個家教，就是盧梭」，加上「早了十五年」。改成照時間走以後，這兩件事在 3:00 左右就講完了。後半的懸念改成「這句話怎麼跑到她頭上」和「最早寫她的人自己說不是她」。原片第 1 版盲評 13／13 通過的是倒敘版，順敘版還沒有盲評。
2. **歷史人物改用物件代稱。** 盧梭、王后、卡爾、女皇、維多利亞夫人、伯爵夫人都過世超過 70 年，原片把他們畫成卡通人物。`NOTES.md` 記著第一輪 keyframes 已經花了 US$1.96。這次照 RULES 補充全部改成固定物件，那批圖都用不到了。
3. **`subtitles.burn_in`。** 原檔是 `true`，現行 lint 會警告「奇聞檔案局 2026-11-04 起不燒字幕」，所以改成 `false`。如果要保留原值，lint 會多一個 warning。
4. **縮圖。** 原縮圖的底圖 `the-question` 是「捧著布里歐、一臉疑惑的王后」，現在不能畫王后的臉，所以改用 Ada 舉著布里歐的 `open-promise`。也可以改用空搖籃（`fifteen`）配「她沒出生」，但那張沒有臉。
5. **沒有更新的欄位**，等站主確認新稿後再改：
   - `youtube.description` 還寫著「畫中的歷史人物都是卡通化的角色」，現在已經不畫了。
   - `voice.performance` 是照倒敘順序寫的（「他就是盧梭」揭曉停一拍），大致還能用。
   - `i18n/` 沒有動。
6. **句長。** RULES 要每句 25–42 字，又要每景 4–9 秒，補充說換圖節奏優先。這次平均每句約 21 字，有 50 句不到 20 字，最短的是「這份檔案，存檔。」，跟 CTA 放在同一景。
7. **步的比例。** 步 1 鉤子 46 秒（5.8%），比模板稍長，因為要先講清楚「這是什麼」。步 5 升級關卡占 21.9%，模板是 25–35%。步 9 收束占 5.0%，模板是 6–8%。要補的話，可以把原 mb815「我每次想都覺得不可思議」放回步 9。
8. **只畫手的景。** duty 畫的是王后蓋封蠟的手（淺藍蕾絲袖口）。如果覺得太像在畫她，可以換成無人的封蠟信。
