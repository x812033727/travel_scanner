## 鉤子、起源、轉折、收尾怎麼排

- **鉤子**：先講觀眾身邊的東西（機車行、音樂教室、十二萬五千台）→ 大家以為的版本（子公司）→「可是你想不到」：第一台機車是鋼琴公司賣的 → 兩個停在結果之前的預告（戰爭留下的東西、富士山跟本田比了一場）→ 今天位置不一樣了。不講中間怎麼發生。
- **起源**：從 1887 年濱松講起，照時間一路走到 2026 年，中間不倒敘、不換主角（主角是「山葉」這個名字：先是寅楠的風琴，再是日本樂器，再是分出去的機車公司）。
- **轉折**：被打槍 → 第二台過關；做鋼琴的接到螺旋槳；轟炸後燒掉的是樂器機器（諷刺）；機器成了機車的契機；又貴又賣不動 → 不但沒停還分家 → 第一名；感情好 → 帳本是另一回事 → 持股倒過來。
- **收尾**：先答案（不是同一家），再營收五倍多（全片只說一次），倒帶串回風琴、空襲、極機密命令，收在「同一支音叉」與「名字一起用、帳本各記各的」，最後留言題與訂閱。
