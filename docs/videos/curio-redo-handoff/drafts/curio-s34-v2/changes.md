## 敘事改了什麼

1. **拿掉開場的濃縮劇情。** 原開場是：廣告 → 困冰快兩年 → 一九一四年倫敦、船長的夢、門上的牌子、「你錄取了」 → 書裡廣告在哪一頁 → 兩個預告 → 634 天卡。夢、門牌、「你錄取了」整段搬回步 3（起源），照年代講。
2. **鉤子講得懂。** 第二句新加「據說，這是一百多年前，探險家薛克頓招人去南極時登的」，沒聽過的人第一句就知道是誰、為什麼登。怪點用兩個查核過的事實：流傳的文字不只一個版本〔#32 備註〕、他自己的書裡沒提到這則廣告〔#31〕。高潮標籤只留兩個（小木船只靠太陽、一個世紀後回去找船），不講因果。
3. **承諾句**改成「今天我們就來聊聊：那則人人會背的廣告，到底在哪裡？」＋「還有，困在冰裡的這一船人，最後回來了幾個？」，兩題分別在 close-legend、rescue-all-ada 收。
4. **起源照時間走，不跳主角。** 一九一四年初倫敦 → 五千封信 → 五十六人兩隊 → 沃斯利（先說他是誰，再講夢與門牌）→ 布宜諾斯艾利斯的偷渡少年 → 十二月五日起錨。
5. **前面埋的梗後面收。** 新加兩組：沃斯利的冰塊夢 → 困冰時「夢裡那些冰塊，這下真的圍上來了」；「下一次踩到陸地」改在起錨時埋（「先記住這個問題」），象島收。收尾新加 close-shelf，把夢、門牌、底片、沉船位置倒帶串回四個代表物，再收一句金句（close-line）。
6. **比喻**：沒有新加需要解釋的比喻；兩磅改成問觀眾「只能帶這麼一點，你會帶什麼？」。沒有「我自己算的」這類話。
7. **英文名**：旁白沒有英文原名（人名、船名原片就用中文），`lexicon.json` 不用加詞。
8. **卡片全改插圖**：數字只在旁白；畫面用質性比喻（Ada 倒抽一口氣、一艘小船在大海正中、射在靶心旁邊的飛鏢、氣球、空鍋）。
