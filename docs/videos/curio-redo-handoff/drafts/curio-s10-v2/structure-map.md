## 鉤子、起源、轉折、收尾怎麼排

- **鉤子（步 1）**：先講觀眾聽得懂的東西：這句台詞、誰說的（明智光秀）、攻打誰（住在本能寺的織田信長）、三百年後成了成語。接著才翻反差：那一夜的紀錄翻了好幾份，沒有一份寫著這一句。最後丟兩個高潮標籤：「五十九年後，書裡是士兵先開口問他」「再過一百八十多年，有人讓他舉鞭自己喊出來」。中間的因果（書記官寫什麼、老兵以為是誰、誰寫了哪本書）一個都不先講。
- **承諾句（步 2）**：Ada 說「今天我們就來聊聊：敵在本能寺，光秀真的喊過嗎？」，再說出這一集的路線：跟著台詞走兩百四十五年，看最早是誰寫下它。
- **時代與起源（步 3）**：天正十年。先由 Ada 說明這一集的人物用物件代表（金色扇子＝信長、深藍頭盔＝光秀）。接著照日子走：光秀準備往西出征 → 五月二十六日進龜山城 → 二十七日愛宕山抽籤 → 二十八日連歌會 → 信長二十九日上京住進本能寺，只帶二三十個隨從，大軍「這一次不用跟」→ 六月一日四個重臣商量 → 入夜出兵、掉頭向東、老之山岔路口「他會走哪一條？」→「光秀往左」→「今天的故事都說，就是在這一夜他喊了那一句」→「真的有人聽見嗎？」。原片把出兵前的日子、信長的隨從都放在後面的章節當補述；現在照時間放回它發生的地方，後面不再倒敘。
- **第一次起落（步 4）**：照那一夜出發時的順序翻三份紀錄：《信長公記》記下的命令是「往攝津」（第一次落空）→ 大村由己只寫出兵、卻先定性「多年的逆意」→ 佛洛伊斯報告的「閱兵」與「對付家康」→ 三份都沒有 → 「那走在隊伍裡的人怎麼說？」。
- **升級關卡（步 5）**：照那一夜往前推：老兵本城（以為是家康、不知道本能寺在哪、跟著利三的兒子、渡桂川天快亮）→《川角太閤記》過桂川後的「天下之主」令（還是沒有「敵」字）→ 快到京都，利三指向本能寺的樹林（第一次說出本能寺，但不是光秀說的）→ 天亮圍寺，信長的「不及是非」→ 信長死 →「那是誰先把它寫進書裡？」。
- **最大反轉（步 6）**：《織田信長譜》。台詞終於出現，但是一問一答：士兵先問，光秀才答。中間補上這本書比《信長公記》多出來的東西（壕溝、粽子、五個家臣、「信長要殺我」、閱兵）。
- **揭曉高潮（步 7）**：《日本外史》。回到開頭的岔路口與老兵的桂川，這一次沒人問，光秀舉鞭自己喊「吾敵在本能寺矣」，也就是開場說「今天的故事都說他喊了一句」的那個版本。再拆它跟一六四一年那本差在哪、兩本之間的線索、自衛的理由不是山陽的。
- **尾聲（步 8）**：「故事還沒結束」：讀的人最多、二十幾種明治刊本 → 成語「真正的目標另有所在」→ 1914 年的「英國」→ 明治課本兩種寫法並存、「兩個爸爸」。
- **主題收束（步 9）**：回到開頭的問題：台詞是後來寫的、目前查到最早是林羅山父子 → 回收四個月後的定性 → 動機五十類、沒有定說、二〇一四年的信 → 一句金句回扣岔路口（標成「我覺得」）→ 存檔與未結。
- **提問與訂閱（步 10）**：「你第一次聽到敵在本能寺，是在哪裡？」，訂閱。
