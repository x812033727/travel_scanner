## 敘事改了什麼

1. **拿掉開場的濃縮劇情**：原開場是 1943 年農家兒子挖墓、九塊、報紙寫「眼鏡」，再接兩個預告。現在的鉤子只問觀眾心裡的維京人，翻出反差（挖出來的維京頭盔一件有角的都沒有），再丟兩個高潮標籤：
   - 真的有角的兩頂，比維京人早了一千七百年左右。
   - 1876 年歌劇院台上有人戴牛角，台上卻一個維京人也沒有。
2. **承諾句**：「今天我們就來聊聊：維京人頭上那對角，到底是誰替他們戴上去的？」由 Ada 說。
3. **起源從那頂鐵盔的時代講起**：十世紀後半一個男人下葬，陪葬品、五六匹馬、很貴的頭盔、被兩支矛刺過；同一個世紀的《哈康之歌》與兩百多年後的《Heimskringla》都沒寫角。接著「一躺九百多年」「時間快轉到一九四三年」才出土。
   - 原本這些陪葬品和詩是出土以後才補講的，現在照時間排，主角從頭到尾是同一頂頭盔。
4. **考古線收乾淨再進書本線**：數頭盔（回收「一件都沒有」）→ 沼澤角盔（「其實就在前一年」的小倒敘，回收一千七百年）→ 比拜魯特晚六十六年 → 「那角從哪來？從更老的書裡」。
5. **書本線照年份走**：西元 98 → 1616 → 十八世紀 → 1825 → 1869 → 1870／1872 → 「維京時代」這個名字 → 1875 → 1876。
   - 原本 1870 年銅模那章排在塔西佗之前、「維京時代」排在 1876 之後，兩處都會讓人覺得時間往回跳；這次照 NOTES 裡的備案搬到 1875 年之前。
6. **前面埋的都有收**：鉤子四條（一件都沒有、一千七百年、台上沒有維京人、誰戴上去的）、詩與史書（count-texts、spread-heims 回呼）、Frithiof 的鷹盔、塔西佗那句「難得一兩個」（Doepler 翻書時回呼）、「你看到什麼，要看心裡先裝了什麼」（收尾 close-theme 回收）。
7. **收尾**：回到開頭那頂碎鐵盔（「本來就沒少什麼」），新加一景 close-rewind 倒帶回鉤子的兩個標籤，再收一句看法。CTA 保留原本的留言題。
8. **拿掉「我自己算的」這類話**：原本「我們翻了一首……」改成直接講詩的內容。比喻只留原片的「像天氣」（是 Frank 的原話）與「兩個是一起長出來的」。
9. **英文名照原文**：Ringerike、Gjermundbu、Yarm、Viksø、Heimskringla、Roberta Frank、Frithiof、Erling the Bold、Doepler、Cosima、Ragnar 改用原文。
   - 原本是音譯：林厄里克、耶爾蒙布、亞姆、維克瑟、海姆斯克林拉、法蘭克、弗里喬夫、勇者厄林、多普勒、柯西瑪、拉格納。
   - 有通行中文名的保留中文：華格納、塔西佗、拜魯特、厄蘭島、明尼蘇達維京人、史密森尼、《哈康之歌》、《尼伯龍根的指環》。
