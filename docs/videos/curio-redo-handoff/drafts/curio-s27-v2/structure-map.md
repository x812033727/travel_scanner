## 鉤子、起源、轉折、收尾怎麼排

- **鉤子（30 秒）**：先問觀眾腦中的維京人（不用懂任何背景就聽得懂），再翻反差：挖出來的維京頭盔一件有角的都沒有。接兩個高潮標籤：真的有角的頭盔早了一千七百年；1876 年一座歌劇院台上有人戴牛角，台上卻沒有維京人。不講農家兒子、不講中間的因果。
- **承諾句**：「今天我們就來聊聊：維京人頭上那對角，到底是誰替他們戴上去的？」
- **起源**：「得先回到一千年前」→ 十世紀後半一個男人下葬（陪葬、五六匹馬、昂貴的頭盔、被兩支矛刺過）→ 同世紀的詩、兩百多年後的史書都沒寫角 → 「在土裡一躺九百多年」→ 「時間快轉到一九四三年」。主角是那頂鐵盔，從下葬一路跟到出土，不跳時間。
- **第一次起落**：出土（碎成九塊、客廳、電話、報紙的眼鏡、戰時一天挖完）→ 拼回來解開眼鏡 → 「沒有一個地方長角」→ 「會不會只是例外？」
- **升級關卡**：關卡一，數頭盔（兩頂加碎片，回收「一件都沒有」）；關卡二，沼澤角盔（「其實就在前一年」的小倒敘，回收鉤子的一千七百年）；最後用「比拜魯特還晚六十六年」把考古線關掉，問「那角從哪來？從更老的書裡」。
- **反轉**：從西元 98 年照年份往前走，角是從書裡借來的；1872 年鳥脖子 → 「心裡先有了，才看成角」。
- **揭曉高潮**：Doepler 以為自己在考據 → 「第二年八月，幕拉開了」→ 回收鉤子的舞台：台上一個維京人也沒有。
- **尾聲**：一本書接一本書（回收 Frithiof、《Erling the Bold》、《Heimskringla》）→ 1900 年成了招牌 → 「停得下來嗎？停不下來」→ 1961 球場、紀念品店。
- **收尾**：回到開頭那頂碎鐵盔（「本來就沒少什麼」）→ 倒帶回兩個標籤 → 一句看法收束 → 存檔、提問、訂閱。
