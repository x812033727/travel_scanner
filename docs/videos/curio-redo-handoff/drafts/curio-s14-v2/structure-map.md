## 鉤子、起源、轉折、收尾

- **鉤子（0:00–0:53）**：一句交代主角與事件（日本劍客宮本武藏、小島上的決鬥），三句講流傳版本（等兩個多小時、划船來、船槳削的木刀），一句利害（決定你心裡的武藏是哪種人），兩句現代場景（銅像晚四個月、導覽開玩笑），然後「可是你想不到」翻到反差：最早提到這一戰的碑，連小次郎的名字都沒有、也沒寫遲到；「更怪的是」丟一個高潮標籤（熊本那張桌子）。
- **承諾句（0:53）**：今天我們就來聊聊：武藏那天，到底是不是故意遲到的？
- **起源（0:59）**：先從最該知道答案的人開始，武藏自己。
- **轉折**：碑上寫同時到（3:14）→「那遲到的故事從哪來」→ 商人與船夫 → 失蹤、信、睡過頭 → 「你遲到了嗎」→ 書裡偏偏沒寫為什麼 → 熊本照抄又多寫 → 「語氣有了，動機呢」→ 直木第一次寫出「故意」→ 吉川讓它家喻戶曉。
- **收尾**：導覽的「六分之一大」→ 故事也是後來才長大的 → 結案 → 三份紀錄倒帶 →「沒有人」→ 存檔 → 提問 → 訂閱。
