## 改了什麼

1. **拿掉開場濃縮**：原開場的「我去翻」「四份口供」卡改掉。鉤子先講清楚是誰、跟誰、在哪、等多久、拿什麼（給沒聽過的人），再翻反差。
2. **《五輪書》從最後一章移到最前面（步 3）**：照時間它是最早的（寬永二十年，1643），原片放最後是倒敘。這樣「不跳時間」，而且「最該知道答案的人什麼都沒留下」變成前面埋、結尾收的梗。代價：原片最後「還有一個證人沒開口，是誰？——武藏自己」的揭曉沒了（`silent` 那一景刪掉）。**請站主決定**（見下）。
