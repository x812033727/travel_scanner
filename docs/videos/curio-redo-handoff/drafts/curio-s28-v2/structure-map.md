## 怎麼排

**主角與時間軸。** 原片是「倒著翻」：從一九二〇年代的讀本開場，往回翻《宋史》→ 邵伯溫 → 惠洪 → 蘇軾，再轉回來看缸怎麼換上去，最後跳到二〇一五年和唐朝的請君入甕。照規則 4（不跳時間），這一版改成**從一〇一九年一路往後走到今天**，主角從頭到尾是同一口甕（司馬光用一顆灰石頭代表）：

1. 北宋：司馬光出生 → 五六歲的青胡桃 → 七歲聽講《左傳》→（科普：缸和甕差在哪）→ 做到宰相 → 熙寧年間求雨的甕 → 一〇八四年《資治通鑑》裡的請君入甕 → 老朋友蘇軾、百姓喊「救活百姓」。
2. 一〇八六年他過世，蘇軾的長文獨缺這件事 → 生前看不到有人提過 → 一一二〇年前後惠洪寫下第一筆。
3. 南宋到元朝：書目批評 → 一一三二年邵伯溫 → 學者判可信 → 南宋另一部傳沒有 → 一一八八年類書「擊甕圖」→ 修身書放進「濟人」→ 一三四五年《宋史》。
4. 十七世紀筆筒 → 清末民國課本 → 一九二〇年代讀本 → 一九三三年廣告。
5. 二〇一五年的質疑 → 今天的課本 → 那件事到底有沒有發生。

**鉤子（步 1）。** 拿掉原片開場的濃縮劇情（讀本的場景、和尚與筆筒兩個預告）。鉤子第一句先把故事講清楚（孩子掉進大水缸、他拿石頭砸破），讓沒讀過的人也聽得懂；接著是利害（二〇一五年有人說它是假的）、反差（宋元古書沒有一個用缸字）和兩個標籤（最早那一筆在他過世三十年上下、「砸缸」兩個字可能要等到一九三三年）。中間怎麼換字、誰寫的、哪本書，一句都沒講。

**承諾句（步 2）。** Ada：「今天我們就來聊聊：司馬光砸的，真的是缸嗎？那口缸，又是從哪裡來的？」承諾句之後直接進一〇一九年，不回顧開場。

**起源先鋪梗（步 3）。** 原片放在後面的幾件事，照年代搬到司馬光在世的時候，當伏筆：

- 青胡桃（他親筆寫下的童年是一次說謊）→ 步 8 收：「他自己寫的，是一次說謊；別人替他傳的，是一次救人。」
- 熙寧求雨的甕 → 步 7 用「還記得熙寧年間……」回收。
- 請君入甕（一〇八四年進呈的《資治通鑑》）→ 步 7 用「還記得司馬光自己主編的那部書嗎？」回收。
- 百姓喊「救活百姓」→ 步 8 用「還記得百姓攔路喊的那四個字嗎？」回收。
- 缸和甕的字義（原片第 5 章）提前到這裡科普，後面每次講到「甕」「缸」，觀眾已經知道差在哪。

**轉折。** 「為什麼？」（蘇軾）→「生前有沒有別人寫過？」→「會不會是缸？不是。」（惠洪）→「可是問題來了」（書目批評）→「那它什麼時候變成缸的？」（步 5 收尾，帶進步 6）→「更怪的是」（五六尺高）→「然後，有人拿這口缸，回頭質疑整個故事」（帶進步 7）→「答案是：……從來就不是缸，是甕」→「可是，最後一個問題」（步 8）。

**收尾（步 9–10）。** 倒帶：課本的缸 → 筆筒的大盆 → 宋朝人寫的甕；接一句看法（容器和名字會換，宋朝人讀到的「仁」沒變），再收原片的結檔句（一頁存檔、一頁未結），最後是原片的留言題與訂閱。沒有講下一集。
