# 給站主：同一份檔案，兩種講法

L08 麥田圈，照 2026-10-13 的新寫法重寫一次。**事實一條都沒改**，全部沿用
[`../curio-l08/claims.md`](../curio-l08/claims.md) 兩輪查核後的版本（查核日 2026-10-10）；
只有講法變了。`lint` 0 錯誤 0 警告，估 10.6 分鐘、144 句、108 張插圖、17 張卡片。
只有腳本：沒有生圖、沒有配音、沒有花錢。

## 章名：舊 vs 新

| --- | --- | --- |
| 1 | 麥田圈是誰做的：1991 年兩個老先生的告白（18 秒） | **酒吧打烊，他們提著一根鐵棒進麥田**（52 秒） |
| 2 | 流傳的版本：飛碟、旋風、人做不出來 | **那個東西，又回來了**（105 秒） |
| 3 | 酒吧裡的主意：飛碟巢、鐵棒，和一塊木板 | **氣象學家說，那是帶電的旋風**（99 秒） |
| 4 | 專家怎麼解釋：旋風假說與暢銷專書 | **專家看完那個圓，說人類做不出來**（86 秒） |
| 5 | 1991 年 9 月：報社的測試與當場示範 | **那年夏天，田裡已經有別人**（99 秒） |
| 6 | 承認之後：麥田圈為什麼越做越複雜 | **有人開始付錢，請人去壓麥田圈**（76 秒） |
| 7 | 田是誰的：農夫的損失、觀光與刑事毀損 | **每一個圈底下，都是別人的收成**（117 秒） |

第一版的七章，三章是從一個標籤開始的（「先講流傳的版本」「答案在一間酒吧裡」「每一個圈底下…」），
每一章結尾都問一個問題——這一點第一版做得比它的姊妹集好，第 4、5、6 章的第一句真的在接上一章的
問題（「報紙一報，認真研究麥田圈的人就來了」「一九九一年九月」「因為做麥田圈的人，早就不只他們
兩個了」）。**這三句我留著，只換了措辭。** 新的七章，每一章的第一句都是上一章的後果或答案：
第 2 章用「他們沒有停」接住第 1 章的「三年沒人注意」，第 4 章用「還記得那筆研究經費嗎」回答第 3 章
章末留下的那件事，第 5 章用「還記得那位研究者的反問嗎」回答第 4 章最後那個問句。

## 開場：舊 vs 新

| 上架那一版的開場（8 句） | 第二版（12 句，52 秒） |
| --- | --- |
| 兩個老先生當著記者做了麥田圈。 | 七〇年代後半，英格蘭南部的一個星期五傍晚。 |
| **研究者看完卻說，人類做不出來。** | 兩個朋友在小酒館喝完最後一杯。 |
| 一九九一年，道格六十七歲，戴夫六十二歲。 | 一個叫道格，一個叫戴夫，都是風景畫家。 |
| **他們承認，那些被當成神祕現象的圓，是自己做的。** | 他們要在這裡壓出一個麥田圈。 |
| **工具裡有木板、繩子，還有一頂裝了鐵絲的棒球帽。** | 道格手上提著一根鐵棒。 |
| **但公開告白以後，田裡的圖形沒停，反而越來越複雜。** | 那根鐵棒，平常拴著他畫框店的後門。 |
| **多年後，道格還說，後悔把這件事告訴大家。** | 他們想做出飛碟降落過的樣子。 |
| 這兩個原本守著祕密的人，為什麼選在那一年開口？ | 他們把麥子一圈一圈壓倒。 |
| | 壓出來的，是一個直徑大約九公尺的圓。 |
| | 然後兩個人回家睡覺。 |
| | 之後整整三年，沒有人注意到那些圓。 |
| | 那為什麼到了一九九一年，他們自己說出來？ |

粗體那五句，是開場就把第 4、5、6、7 章的揭曉和結局講完的地方：觀眾聽完 40 秒已經知道專家被騙、
工具是什麼、圈後來越做越複雜、道格後悔了，正文再講一次，就是「拼湊」的來源。
第二版是**一個場景照順序走**：走出酒館、翻進麥田、鐵棒、壓倒麥子，走到第一個說不通的事實
（做成飛碟降落的樣子，卻整整三年沒有人注意）就停住，最後一句是全片要回答的問題。
示範現場、被騙的專家、木板與棒球帽、道格的後悔都留在後面。

## 四個鉤子：埋在哪、在哪回收

| 留著什麼 | 埋 | 回收 |
| --- | --- | --- |
| 那根鐵棒後來換成了什麼 | 第 1 章 `cl1e`「道格手上提著一根鐵棒。」 | 第 2 章 `cl2i`「還記得道格手上那根鐵棒嗎？」→ 木板、繩子、帽簷上的鐵絲圈 |
| 為什麼要做成飛碟降落的樣子 | 第 1 章 `cl1g`「他們想做出飛碟降落過的樣子。」 | 第 2 章 `cl2b`「還記得他們想做出飛碟降落的樣子嗎？」→ 澳洲報紙上的飛碟巢 |
| 被壓壞的那片田，損失誰承擔 | 第 2 章 `cl2q`「這筆帳，我們留到最後再算。」 | 第 7 章 `cl7a`「還記得我們留到最後再算的那筆帳嗎？」→ 農夫的損失與捐款桶 |
| 那筆研究經費跟他們開口有什麼關係 | 第 3 章 `cl3v`「先記住這一件事，等一下它會回來。」 | 第 7 章章末 `cl7x`「還記得那筆研究經費嗎？」→ 兩種紀錄並排，答案在 `outro` 第一句（**全片最長的一條，跨五章**） |

第 4 章章末那個問句（「他們把那塊木板帶去加拿大了嗎？」）不算鉤子：第 5 章的第一句隔四秒就回答它
（「那時候，田裡已經不只他們兩個。」），那是章與章之間的銜接。原本那裡寫成「還記得那位研究者的
反問嗎？」，等於把剛說完的話再問一次，所以拿掉。

另外每 60–90 秒輪流留一個沒回答的問題：升級（「問題來了」「但這還不是最奇怪的地方」）、
收著（「然後記者打了一通電話。他要請誰來看這個圈？」就停）、問句（「那兩位老先生後來怎麼樣了？」）、
轉折（「這麼多年下來，有一件事一直沒有人算」）。`lint` 量到的最長空白是 77 秒。

## 從舊稿刻意拿掉的東西

明細在 [`claims.md`](claims.md) 的「這一版沒有講的主張」；這裡只列為什麼。

- **「你以為…其實…」**。第一版開場第三、四句就是這個句型。新的開場要第一章是故事的第一個場景，
  「你以為」是評論，會把觀眾從那片麥田拉出來；那個對比改成讓第 1 章直接演出來。
- **「流傳的版本」整整一章**。飛碟降落的痕跡、帶電的旋風、人類做不出來，改成在故事裡該出現的
  地方各講一次（第 3 章開頭的飛碟迷、氣象學者的旋風、第 4 章研究者的原話），仍然標明是誰在哪一年
  說的，只是不再自成一個櫃子。
- **1678 年〈割麥惡魔〉與兩張照片**。一條從七〇年代走到今天的故事線中間插進十七世紀會把觀眾拉走；
  而 `cute-mystery` 的 `drama` 形狀沒有照片卡。文字主張還在。
- **兩張只在重述的卡**。「三個問題」那張教學式 `steps` 改成讓第 5 章直接做；「鑑定的結論 vs 現場的
  事實」兩句旁白把剛說過的話再說一遍，現在讓「沒有人類做得出這個」直接接「做這個圈的兩個人，
  就站在他後面」，對照由故事自己做完。
- **聽起來像同一個數字的「一百英鎊」**。它本來一次是被壓掉作物的價值、一次是 2000 年的罰金。
  卡片仍然寫 £6,000 與約 £100，旁白把作物改成「大概只值它的六十分之一」，一百英鎊只留給罰金。
- **重複**。「兩個六十多歲的人」第一版出現在開場、旁白和兩張卡片；現在 `big` 卡寫「67 歲與 62 歲」，
  旁白只講一次。「一九九一年」從五句降到兩句，中間改成「那一年」「那年夏天」「隔年」。
  2010 年的誠實箱與農民聯盟那句話也拿掉了，2017 年的水桶與警方那句話已經講完同一件事。
- **片尾不講下一份檔案**。第一版的 `outro` 卡與旁白都是「下一份檔案，我們繼續翻」（站主 2026-10-13）。

## 加進來的東西

- **兩句補回故事裡的內容義務**：「第一個圓是哪一年，報導有的寫一九七六，有的寫七八」（第 2 章，
  來源分歧就說分歧）、「飛碟迷說，那是飛碟降落留下的痕跡」（第 3 章，第一版放在條列卡裡）。
- **每一章一張以表情為主的 medium**。兩位老先生與所有近代人物都不畫臉（背影、手部、遠景的身影），
  需要表情的那一張換成虛構的一般人：收割機駕駛、報童、記者、攝影師、遊客中心職員、統計學者、農夫。

## 三次盲評改了什麼

稿子送三個只拿到旁白、沒看過企劃的讀者盲評。他們抓到的都是同一類毛病：**重述**。

**片尾在重述正文**（第一、二次）。第一稿片尾把第 4 章的理由、道格那句玩笑、第 1 章的清單各再說
一遍；加上「回到開頭那個問題」這種回呼標記也救不回來——「還記得」是用來把**埋下的東西**提起來
回收，不是用來重複一個觀眾已經拿到的答案。真正的毛病在結構：開場問「他們為什麼在一九九一年自己
說出來」，而第一稿在第 4 章開頭就回答了，片尾自然沒有新東西可講。現在原因整個留到最後：

- 第 3 章章末照舊埋鉤子（愛好者開始向政府要研究經費／先記住這一件事）。
- 第 4 章只講「那年九月，兩個人決定說出來」，**不講為什麼**，直接進肯特郡那塊田。
- 第 7 章章末才回收：「還記得那筆研究經費嗎？」接「為什麼開口，紀錄留下兩種說法」，旁白講訃聞
  那一種（公開是戴夫的主意），`compare` 卡把兩種紀錄並排。
- `outro` 第一句第一次說出答案，帶一個全片沒講過的數字：「做了十三年之後，是那筆研究經費讓他們
  開了口。」十三年出自時代雜誌（起始年份的分歧已經在第 2 章講明）。

**章首在重述上一句**（第三次）。第 5 章原本開在「還記得那位研究者的反問嗎？」，而那個反問是上一章
最後一句，隔四秒；第 7 章原本開在「還記得我們留到最後再算的那筆帳嗎？」，緊接在第 6 章的「有一件事
一直沒有人算」後面。隔幾秒的問題由下一句接住就夠了，「還記得」留給掛了幾分鐘的鉤子。現在第 5 章開
在事件（「那時候，田裡已經不只他們兩個。」），第 7 章開在 2000 年那場法庭，那筆帳的回收移到 2017 年
的損失前面——回收的位置反而更準，帳就是在那裡算的。`loops` 表也從五個減成四個。

**第 7 章照論點排，不照年份排**（第三次）。原本是 2017 年的兩英畝、衛報 2018–2022 年的估算、
2004 年的觀光、2000 年的罰金、2018 年道格過世；每一條都有出處，聽起來卻像在舉證。現在照年份走：
二〇〇〇年的法庭與罰金 → 刑事毀損 → 二〇〇四年的觀光生意 → 回收那筆帳 → 二〇一七年的兩英畝與
捐款桶 → 衛報的估算 → 二〇一八年道格過世。主張、出處與數字都沒有動，只有順序。

**同一輪修掉的重複**：見報本來講兩次，現在日期收在一句、標題卡只唸標題；「模仿的人也出現了」本來
第 3 章先說、第 5 章再當答案說一次，現在第 3 章整個留白；第 7 章第一句本來把章名再說一遍。第 4 章
也因此照發生順序重排（決定開口 → 肯特郡的圈 → 鑑定 → 承認 → 九月九日見報 → 漢普郡的示範），
不再有「在那之前」的倒敘。
