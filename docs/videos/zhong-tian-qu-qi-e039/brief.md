# 《種田娶妻打天下》第 39 集〈她回來了〉

## 故事前提

第 38 集收在縣城醫館門口：阿令拍著醫館的門，身後一排守軍的弩同時對準她的背，隊長舉起手：「放——」。第 39 集從同一刻接下去：醫館的門「吱」地打開，白大夫披著棉背心衝出來一聲「放下！」「她是來求醫的！」，隊長的手垂下，弩一把把放低。阿令喘著氣：「小妹燒了一夜，」「大夫，救她。」白大夫皺眉：「柳溪？半個時辰，」「老夫不會騎馬。」阿令從馬鞍扯下繩子：「不用你會。」插鏡：她的手把繩子在老人腰上勒緊打死結，畫外「抓緊我。」一騎衝出暗街，守軍貼著牆退開。

黎明的官道上，一匹馬馱著兩個人衝出晨霧，身後一串火把越追越遠（細綱的奇觀）。白大夫畫外喊「追上來了！」「後面有兵！」，阿令伏在馬背上頭髮散開、咬緊的唇（顏值鏡頭）一夾馬腹；白大夫閉著眼抱著她的腰「慢、慢一點！」，阿令淡淡一句「閉眼，」「數到一百。」就把馬拉離官道，斜穿旱田；火把在路上停成一團、縮進霧裡。白大夫閉眼數到「九十八，」「九十九……」睜開一隻眼，柳溪的茅屋頂到了。

許家屋內，油燈下許硯守了一夜，絞著濕布蓋在小禾額頭上「小禾，再撐一下。」聽見馬蹄聲猛地抬頭「阿令？」——門撞開，阿令拖著一身灰的白大夫進門，白大夫一句「病人在哪？」就跪到床邊搭脈：「燒太久了，」「先退熱。」插鏡藥粉倒進缺角碗，畫外「一口氣餵完。」許硯抱著小禾的頭餵藥「乖，喝了就不燙了。」白大夫：「天亮前看她退不退。」阿令靠著床柱說「我守著。」，說完就滑下去睡著了。全景：油燈燃盡，窗紙從黑變灰變金。

晨光從窗縫照進來，阿令靠著床柱睡著，木簪滑落、一綹頭髮落在臉頰（顏值鏡頭）。許硯把一件青布外衫輕輕蓋在她肩上、塞到下巴；系統：「阿令好感，加十二。」（面板：好感 +12 → 50）；「好感五十，獎勵箱開啟。」「獲得：玻璃燒製法。」（面板）。許硯壓低聲音嘀咕「石英砂、高溫窯……」「先收著吧。」（細綱：要石英砂和高溫窯，只能先收著）。小禾睜開眼「哥……」，許硯手掌一貼額頭「退了！」「不燙了！」把她連被子抱起來；阿令醒來，手摸到肩上的外衫「退了？」，頓一下、默默拉回肩上；白大夫扣上藥箱「退了就無礙了。」

中段鉤子：小禾抓著草兔子小聲說「哥落水那天，」「我看見有人推。」許硯笑容沒了「誰？」。小禾比著自己的頭「戴草帽，綁紅繩，」「我沒看見臉。」許硯「紅繩……」——插鏡（回憶）：錢府側門旁掛在木釘上那頂綁紅繩的舊草帽（第 8 集他看見的那一頂），畫外「錢府側門。」（本季短線 s01-t09 的 payoff；m05 不揭曉：只知道是戴紅繩草帽的人推的）。這時秦霜一身灰衝進門：「許硯，穀倉那邊，」「壓不住了。」許硯「刁七？」把小禾的被子按一下就往外走。

穀倉前（田頭）：全村拿著鋤頭棍子擠在穀倉門口，韓伯橫著竹杖擋人；刁七被兩個村民從穀倉拖出來、綁著手，被推跪在田頭的麥茬上，繩子套在胸口勒向門邊的木樁。韓伯「等許秀才來！」竹杖頓地；刁七「有種就動手。」；插鏡幾雙手把繩子在木樁上再繞一圈，畫外韓伯「住手！」；秦霜按著柴刀「人是我擒的，」「輪不到你們動。」許硯跑到田頭，全村一個一個回頭；刁七抬起疤臉冷笑「柳溪的許秀才？」；韓伯讓開路「村裡要他一個交代。」；秦霜抱起手臂「留，還是交給他們。」全景：所有人都轉向站在左邊的許硯、刁七綁在右邊的木樁上、鋤頭舉在半空停住；收在許硯的臉，眼睛從鋤頭掃到繩子，嘴唇張開、話還沒出口，畫外刁七「秀才，你說。」（第 40 集從「先問話」「再算帳」接）。

本集細綱：`docs/videos/series-plans/zhong-tian-qu-qi/season-01.json` 第 39 集（130 秒，第一季第四章，調性感人＋甜寵）。hook 是醫館門打開、白大夫「放下！」「她是來求醫的！」弩一把把垂下（0:00–0:06，rescue）；mid_hook 是小禾退燒醒來說「哥落水那天」「我看見有人推」（1:20–1:31）；turn 是阿令把白大夫綁在身後狂奔回村、天亮小禾退燒、阿令睡著、許硯蓋外衫（0:16–1:01）；衝突是白大夫上了年紀不會騎馬、回程要甩開巡夜的兵（0:10–0:35）；cliffhanger 是穀倉前全村押刁七到田頭、繩子已經套上、所有人回頭看許硯（1:38–2:07，choice，「放過流寇頭目，還是交給村民處置？」）。細綱的 general_payoffs 全部入鏡：小禾退燒（s29）、阿令好感 50（s25 面板）與開箱「玻璃燒製法」（s26 面板，s27 說只能先收著）、許硯想起錢府側門那頂紅繩草帽（s35–s36）。payoffs 的 s01-t09（小禾燒糊塗時那句話的意思）在 s32–s34 收：她看見有人推哥哥下河、戴紅繩草帽、沒看見臉。
