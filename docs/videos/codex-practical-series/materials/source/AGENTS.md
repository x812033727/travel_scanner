# Small Steps 練習規則

- 開始先讀 README.md、docs/data-contract.md、docs/handoff.md。
- 同名任務以 ID 區分；篩選不得修改原清單、順序或儲存資料。
- 不加依賴、網路請求或登入。只改目前任務列出的檔案。
- 原始測試不得刪除；新驗收以案例測需求，不能只抄實作。
- 檢查是 `node --test`；瀏覽器操作另記 PASS／FAIL／NOT RUN。
- UTC 完成時間與台北報表日期不同；未知時間不可捏造。
- 匯入整批驗證再合併；資料來源、既有輸出与其他儲存鍵不得覆寫。
- 交付記錄實際命令、exit code、分支／版本及仍未驗證項目。沒有真的操作過的模型、MCP 連接、代理、排程、CI 或 PR 必須標明未執行。
