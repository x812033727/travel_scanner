# 可照貼提示

## App

讀者先在完整教材包外層讀 README.md 與 acceptance.md，將本課目標、修改範圍和驗收要求貼到 App 聊天，再選 start 專案。start 只有原始五檔；不要求模型讀取其中不存在的 README 或 acceptance。

在本課獨立練習專案使用 只讀五個專案檔與 core.test.mjs；交檔案地圖與原始測試結果。 目標是：確認路徑、檔案地圖、執行既有測試；把失敗當作觀察，不先改程式。。依讀者提供的需求核對工作路徑與五個檔案，列出基準及差距；本課只讀，不改程式。所有未跑檢查寫 NOT RUN，不能改原始輸入來湊答案。

## CLI

从本課 snapshot 開 codex；貼入：只讀五個專案檔與 core.test.mjs；交檔案地圖與原始測試結果。 目標是：確認路徑、檔案地圖、執行既有測試；把失敗當作觀察，不先改程式。。先讀檔、確認範圍、保存基準。測試命令 node --test core.test.mjs。輸出實際命令/exit code/diff/未驗證；不得聲稱 App、瀏覽器或 CI 操作。

## 遷移

不讀 answers，處理 challenge：completed 篩選仍是錯的，辨認 actual/expected。 先寫預期，再讓案例證明結果。

## 固定變式與補充案例

主變式：不讀前一輪報告，用全新 start/reference 重跑同一 node --test core.test.mjs，解釋差異並交第03課範圍。另做 challenge：只讀診斷 Completed 失敗，不實作。
