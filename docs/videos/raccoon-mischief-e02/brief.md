# 闖禍小浣熊 EP2〈吊燈〉

## 故事前提

豆豆盪壞了水晶吊燈，就把自己掛在天花板的掛鉤上當吊燈，兩手抓著手電筒。媽媽回家按下開關，他慌忙打開手電筒；媽媽面不改色地在他底下看書，用下巴指一下書頁讓他照好。天亮了，他還掛在那裡。

## 角色

- 豆豆（doudou）、浣熊媽媽（mama）：同系列定裝照。

## 站主觀點

零台詞；集數規劃盲評 85（`docs/videos/raccoon-mischief/episodes.md`）。

## 格式

- 9:16，約 16 秒；Colab 首格與 H3 片段。

## 大綱

### 選項 A：吊燈
一行說明：吊燈摔碎 → 鑰匙聲、慢看鏡頭 → 自己掛在天花板當燈 → 媽媽按開關 → 他慌忙開手電筒 → 媽媽在底下看書、用下巴指書 → 天亮了他還掛著。
開場鉤子：天花板只剩掛鉤在晃，吊燈碎在地上。
