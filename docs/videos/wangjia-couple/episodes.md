# 《汪家夫妻》EP2–EP7 集數表（2026-11-03）

系列規則照 [`README.md`](README.md)：零台詞、9:16、寫實 AI 擬人化狗夫妻，公式是挑釁 → 慢轉頭 → **跳過過程給荒謬結果** → 補刀。
這一份是可以直接拿去做分鏡的集數表：六集都還沒進劇本關卡，也還沒花任何錢。

六集都照首格實測的限制設計：

- **每一鏡畫面上只有一個角色**。另一個角色只用背影、畫面邊緣的一隻腳或一角圍裙，或放到下一鏡的反應鏡。
- 懲罰那一格寫成阿福**本身**在那個狀態裡（「Afu himself is swaddled in…」「Afu himself sits on the cake plate…」），
  不寫「旁邊有一個嬰兒床／蛋糕」，不然模型會畫一個真的物件放旁邊。
- 世界裡沒有人類；沒有吃東西的過程、沒有看得懂的字（遊戲畫面、時鐘數字、標籤都不入鏡）、沒有兩個角色身體接觸的過程。
- 每鏡是一段 5 秒的片段、一件事，剪進成片時取 1.5–3.5 秒；成片 13–17 秒、5–6 鏡。
- 懲罰每集不同、都能截圖當梗圖：嬰兒床、冰箱裡的生日蛋糕、寵物軟墊、襪子怪面壁、同款捲髮、等到長鬍子。
  收尾都落在阿福身上，沒有一集是「老婆對鏡頭甜笑」。

**一句話**：老婆燙了一顆卡在門框的大捲髮、老公看都沒看就點頭——下一格他頂著一模一樣的捲髮，隔天她剃了平頭回來。

- **縮圖**：s04-twin——柯基頂著巨大粉紅捲髮一臉放空，三位評審裡兩位列為最強的一格。

  s05 讓她手上隨意拿著還在嗡嗡響的電推剪（2 位），s06 點頭點到一顆髮捲飛出去、他慌張夾回去（2 位）。這三點都不加鏡、不加角色，建議做首格前採納。

## EP7〈等妳出門〉（約 14 秒）

**一句話**：老公在玄關敲錶嘆氣催老婆，她只畫好一隻眼、默默把浴室門鎖上——下一格他等到長出白鬍子、頭上築了鳥巢。

這一集角色反過來：挑釁的是老公、讓他吃苦頭的是時間，珍珠全程沒有動手。

- **AI 風險與避法**
  - 中：s03 細節多（鬍子、網、鳥巢、雛鳥、雪），寫成 "Afu himself has grown a long white beard reaching the floor"，

  導演建議 s04 和 s05 對調，把「拖鞋踏出又縮回」這個最強的時機放在最後（已婚上班族也覺得雛鳥瞪人收尾偏題）；20 歲與已婚上班族都建議縮回前讓她換了一套衣服或一雙不同顏色的拖鞋，讓「又縮回去」有具體的理由。

## 盲評

### 怎麼評的

三位獨立評審，用本機的 Claude Code 無介面模式另開三個工作階段（`claude -p`，關掉所有工具與 MCP，在 repo 外的空目錄執行），
同一個模型，讀不到這份集數表與設計理由，也沒有花任何錢。每位只讀一份盲評包：六集的分鏡描述（鏡頭、觀眾看到的那一刻、音效、秒數），
代號 A–F、順序各自打亂，評分表與 [`.agents/skills/animation-preproduction/references/comedy-review.md`](../../../.agents/skills/animation-preproduction/references/comedy-review.md) 的 100 分表相同。

- `shorts-20`：20 歲大學生，每天滑 Shorts／Reels 兩三個小時，前一秒沒抓住就滑走。
- `married-35`：35 歲已婚上班族、有一個小孩，最有感的是家庭、夫妻、鄰居的生活梗。
- `comedy-director`：做了十年搞笑短片的導演，專剪零台詞的畫面喜劇，對套路很挑剔。

### 評審最常提的問題

1. **前提的因果要一秒看懂**。〈最後一塊蛋糕〉三位都卡在「髮捲為什麼在盤子上」，有兩位在 s02 滑走；
   誰的東西、證據指向誰，要用畫面本身交代（柴犬臉蛋糕、柯基奶油掌印），不要靠觀眾推理一個道具的意思。
2. **第一格直接從最怪的那一刻開始**。〈新髮型〉兩位說從「捲髮卡在門框」開始、砍掉走進來；〈凌晨三點〉導演要先交代「凌晨」（指針時鐘指三點）、20 歲嫌第一格太黑；〈等妳出門〉20 歲要先給裂開的錶面特寫。
3. **最強的一格要放在最後，或後面要更強**。蛋糕的「變成甜點」後面接一個更弱的新蛋糕、等出門的「拖鞋縮回去」不在最後、搶被子的「毛巾蓋頭」太輕，
   都被說收尾掉下來。
4. **同一招用兩次就弱了**。〈襪子山〉的盆栽伏筆（s02）和枯掉的盆栽（s05）被兩位點名是同一招，導演則說伏筆小到手機上看不到；導演也說「一格一格慢轉頭」在六集裡出現太多次，
   建議改用動作說殺意（戴手套、拉下泳鏡）。系列公式的「慢轉頭」可以保留，但每集換一種演法（歪頭、天線、順著掌印看、眼皮跳）。
5. **用爛的視覺梗會被導演扣分**：等到長白鬍子、結蜘蛛網。觀眾評審仍然很愛（89、85），所以留著，但導演的 67 是提醒：同一種時間流逝符號不要再用第二次。
6. **收尾落在阿福身上、而且要有動作**。評審最常建議的補刀都是阿福的小動作（毛巾蓋頭又露腳、髮捲飛出去又夾回、自己聞襪子昏倒），不是珍珠的表情。
