# 汪家夫妻（系列）

站主 2026-11-03 定下的系列規則，每一集都照做：

| 規則 | 內容 |
| --- | --- |
| **零台詞** | 整集沒有任何台詞、旁白或內心話；只有配樂與音效。笑點要關靜音也看得懂 |
| 長度與格式 | 約 15 秒（最多 20 秒），9:16 Shorts／Reels |
| 畫風 | 寫實 AI，真實外觀的狗像人一樣站著、穿衣服過日子 |
| 角色 | 阿福（柯基老公，短腿、條紋睡衣、懶）、珍珠（柴犬老婆，碎花圍裙、粉紅髮捲） |
| 公式 | 一個家事或夫妻衝突：挑釁 → 慢轉頭 → **跳過過程，直接給荒謬的結果** → 再補一刀；結尾不要每集都用「老婆對鏡頭甜笑」 |
| 參考 | 站主給的 Instagram 爆紅片（擬人化狗夫妻、13 秒、零台詞）；只學公式，不抄角色、服裝與情節 |
| 製作 | Colab：Qwen 首格、MiniMax H3 片段（直式 736×1312）→ ffmpeg 剪接 → `shorts import` |
| 語言 | 八語只翻標題與說明；零台詞，沒有字幕與配音要做 |
| 評分審核 | `.agents/skills/animation-preproduction/references/comedy-review.md`，`--style` 寫明「寫實擬人化、零台詞」；文字評分只做排名與診斷，好不好笑看關鍵影格與小樣 |
