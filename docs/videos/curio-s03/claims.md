# S03 劇本逐段主張對照

本表對照 2026-10-19 的 `video.json`、`script.md`；目前旁白編號由 `ef001` 至 `ef103`，音檔覆核後刪去重複的 `ef076`、`ef100`，其餘 101 句均列入。固定文本的完整網址、成書層次及逐項引文在 [`research.md`](research.md)。`[SG35]` 是《三國志》〈諸葛亮傳〉正文及裴注，`[SG03]` 是〈明帝紀〉，`[JS01]` 是《晉書》〈宣帝紀〉，`[YY95]` 是《三國演義》第九十五回。

| `ef001`–`ef005` | [YY95] 第95回題目與正文；[SG35] | 第一句已標「小說裡」與西城縣；城樓琴、灑掃、司馬懿勒馬是**小說開場**，停在退兵結果之前。動畫插畫不是現場復原。`ef005` 的駐地懸念後文 `ef041`–`ef053` 回答。 |
| `ef006`–`ef008` | [SG35] 郭沖三事與裴「難曰」；[YY95] | 開場只立三個待解疑問，不揭底：較早的郭沖故事有沒有琴、裴先發現哪個矛盾、二二八年正史記下什麼。郭沖有開門與掃地，沒有琴，後文 `ef088` 回答。 |
| `ef009`–`ef016` | [SG35] 建興六年段；[SG03] 太和二年 | 228 年第一次北伐、祁山與三郡響應、曹真督關右、張郃破馬謖、趙雲鄧芝在箕谷為疑軍，均有正文。`ef015`–`ef016` 的街亭關口與追問是敘事收束，不把司馬懿放進街亭戰場。 |
| `ef017`–`ef021` | [SG35] 街亭敗後「還於漢中」「請自貶三等」「右將軍，行丞相事」 | 西縣「千餘家」寫作一千多戶；《三國志》**這一段**沒有琴聲或空城逆轉，不據此推論整個史書所有段落都沒有。 |
| `ef022`–`ef026` | [SG35] 裴注引《蜀記》「晉初……郭沖……條亮五事」及裴「沖之所說實皆可疑」 | 郭沖不是一手現場見證；裴保存五事並逐條質疑。`ef022` 只說同一篇傳的裴注，**不說郭沖第三事在街亭段同一頁後面**；它實際附在較早的屯沔陽段。`ef024` 的「晉朝」是「晉初」的白話。 |
| `ef027`–`ef031` | [SG35]「郭沖三事曰：亮屯于陽平，遣魏延諸軍並兵東下……亮惟留萬人守城」及「將士失色」「亮意氣自若」 | 這些都是**郭沖的故事內容**，旁白用「郭沖說」引入；一萬守城者與魏延動向不能當史實。 |
| `ef032`–`ef037` | [SG35]「大開四城門，埽地却洒」「疑其有伏兵，於是引軍北趣山」及後文候邏回報 | 「收起旗鼓、不許帳篷裡的人亂出」取自郭沖記述；灑掃者的人數、年齡未加。`ef036` 說隔天探子回報北走，不聲稱司馬懿第二天是否回來。`ef034` 先質疑司馬懿能否在場，並非說郭沖版本本身提出這個問題。 |
| `ef038`–`ef042` | [SG35] 裴松之「難曰」「案陽平在漢中」「宣帝尚為荊州都督，鎮宛城」 | 核心駐地反證。畫面用地圖方向而不報兩地距離；裴說的是諸葛亮**初屯陽平時**。 |
| `ef043`–`ef047` | [JS01] 227 年六月屯宛、督荊豫；[SG35] 裴同說宛城 | 《晉書》後於裴注成書，只是今日交叉核對。`ef045` 說文本時間線相符，不說兩部古籍互相獨立證明所有細節。`ef047` 說郭沖寫的「那次」，不編出夜間時刻。 |
| `ef048`–`ef053` | [SG03] 太和五年曹真薨、詔司馬懿拒亮；[SG35]「至曹真死後，始與亮於關中相抗禦」及建興十二年渭水對峙 | 231 年與後來渭水兩軍相持在紀錄中；與郭沖**前期陽平空城故事**分開。`ef053` 回收開頭，只否定郭沖所說這次司馬懿已到陽平。 |
| `ef054`–`ef058` | [SG35] 裴「魏甞遣宣帝自宛由西城伐蜀，值霖雨，不果」；[JS01] 230 年遇雨班師 | 另一趟西行遇雨，沒在陽平交戰；這裡「西城」是伐蜀經路，不把它和小說的西城縣簡單畫成同一座城。`ef058` 是轉入裴的其他質疑。 |
| `ef059`–`ef064` | [SG35] 郭沖退軍故事與裴「若疑其有伏兵，正可設防持重，何至便走乎」 | `ef059` 以「還記得」明示退軍回呼；`ef061` 限於裴原文的「設防持重」，不說魏軍有沒有試探城門。`ef062` 明說不是現場戰報。郭沖的二十萬只以「郭沖列出的」表述，不當實際統計。`ef064` 轉入魏延分兵矛盾而不重述東下。 |
| `ef065`–`ef070` | [SG35] 郭沖「遣魏延諸軍並兵東下」；裴引《魏延傳》之分兵潼關提議及亮不許 | `ef066`–`ef068` 描述魏延自行提出的方案，不稱魏延從未領兵；`ef069` 問誰准重兵東下，`ef070` 以《魏延傳》所記此前分兵未獲准作答，說明裴為何不信**郭沖這次安排**。 |
| `ef071`–`ef075` | [SG35] 郭沖向扶風王說五事、司馬駿稱善、裴「對子毀父，理所不容」 | 司馬駿是司馬懿子；郭沖**聲稱**王稱讚。裴的反問是心理和敘事可信度推論，不是行軍紀錄。 |
| `ef077`–`ef079` | [SG35] 裴「故知此書舉引皆虛」 | 裴明確強烈駁斥郭沖諸事。影片只將論證結論用在**郭沖陽平交鋒**；不宣稱所有類似空城策略在任何時代都不曾用過。 |
| `ef080`–`ef087` | [YY95] 題名與西城場景；[SG35] 第三事 | 小說第95回把它的空城設在街亭後的西城縣，讓軍士扮百姓灑掃、諸葛亮帶兩童子焚香操琴，司馬懿疑伏。後段補開場未說的扮裝、童子與退兵，不再演一遍開場。`ef087` 是傳播敘事的設問。未證明《三國演義》是琴聲版本的首次發明者。 |
| `ef088`–`ef094` | [SG35]、[SG03]、[YY95] 三層對照 | 郭沖段無琴、故事設在陽平；小說場景在西城，不能單憑文本比較證明直接改編源流。`ef090` 明說把共通的開門、掃地錯當同一份證據會導致琴被倒灌進史書，這是辨認文本的分析，不是新歷史事件。正文沒有小說那場西城彈琴退兵；`ef093` 點名回呼裴的「難曰」，他收錄郭沖之後明確反駁。不能把三層證據合成一場確定史實。 |
| `ef095`–`ef099`, `ef101` | [SG35] 郭沖段與裴評語；[YY95] | 沒有可靠材料可把**郭沖那一次**定為實發；裴留下反證。其餘是對三層文本的編輯結語與讀者判讀提醒，不聲稱小說故事全無文化價值。`ef101` 以裴的問號收束，不再重述已查過的陽平、宛城。 |
| `ef102`–`ef103` | 片尾互動與訂閱 | 留言選項邀請及 CTA，不增加新史實，也不留下待回收的劇情問題。 |
