# 空城計那天，司馬懿根本不在那裡？

奇聞檔案局 S 軸新題 S03。站主 2026-10-19 要繼續完成新的歷史影片，並把選題交給製作方推薦；這集避開已由另一位工作者認領的 S01／S09／S18。題庫的 S03 卡片仍是未查核候選，所有結論以本集逐條史料查核為準。

## 問題

一座城門打開，諸葛亮在城樓彈琴，司馬懿疑有埋伏而退兵。這個人人都能想像的空城計，最早是誰寫的？裴松之為何說故事中的兩位主角當時沒有在那裡交手？

觀眾會搜尋：「空城計 司馬懿 宛城」「郭沖 空城計 裴松之」「空城計 諸葛亮 彈琴 史實」。標題的問號指**郭沖故事設定的那次**，不宣稱兩人生涯裡從未交戰；《三國志》正文還記錄他們後來在關中對峙。

## 一句答案

裴注保存的郭沖故事寫的是諸葛亮在陽平開四門、令守軍掃地，讓進軍的司馬懿疑有伏兵而退；故事裡沒有琴。裴松之緊接著說，諸葛亮初屯陽平時，司馬懿鎮守宛城，直到曹真死後才在關中與諸葛亮對陣，並指出魏延分兵、二十萬大軍立即退走等內部疑點。《三國演義》第九十五回把相近的開門情節寫在街亭失守後的西城，添上彈琴等戲劇細節。結論是：**郭沖的開門退兵軼事被裴松之強烈質疑；彈琴則是後來小說裡的場面。**

## 站主觀點

沿用 S 軸定案：既讓名場面好看，也能從版本與紀年分清「史書正文」「裴注所收軼事」「小說」。看完可判斷一段戲為何不能只因列在史書旁邊就當作確證，並指出裴松之採用的兩種檢查：人當時在哪裡、故事自己的軍事安排說不說得通。畫面須讓這三層一眼可分，演義的琴不作「歷史重建」。

## 大綱

### A 案（建議）：裴松之追問司馬懿的行程

一條線追問同一個畫面。開場先把《三國演義》裡城門和琴交代為**小說場面**；接著翻到較早的郭沖版本，跟著裴松之逐條核對，最後回到小說怎麼把傳說變得難忘。

| 章 | 約略位置 | 發生的事、留給下一章的疑點 |
| --- | --- | --- |
| 開場濃縮 | 0:00–0:50 | 小說西城縣的城樓、琴、城門與勒馬的司馬懿。暫停在他退兵之前，留下正史寫了什麼、較早說法有沒有琴、史官何以反駁等疑問。 |
| 街亭失守之後 | 0:50–2:05 | 《三國志》正文的北伐、街亭失利與退還漢中；讀者預期下一秒是那座空城，但正文寫了什麼？ |
| 郭沖寫下四扇門 | 2:05–3:35 | 晉初郭沖的五事中，第三事才是開門、掃地、退兵。它被裴松之收入注解，同頁緊接著一個「難曰」。 |
| 司馬懿當時在哪 | 3:35–5:15 | 裴松之把陽平、宛城和曹真之死排成時間線，指出兩人首次在關中對峙是其後的事。標題的疑問在此回收。 |
| 就算在場，怎麼退 | 5:15–7:00 | 裴松之的戰術反問、魏延分兵與扶風王司馬駿的態度疑點；區分「文獻反證」與「裴的推論」。 |
| 琴是後來才響的 | 7:00–9:30 | 演義第九十五回把它的空城設在西城與街亭失守後，寫出琴聲與兩個童子，並把灑掃者寫成扮百姓的軍士；回到三層證據，收在一個好故事如何蓋過校注。 |

每章結尾留一個有事實依據的問題，下一章直接接住；`loops` 至少八組，前段埋三組。正文至少八分鐘，目標約十分鐘。

### B 案（備選）：追一把琴從哪裡來

由演義小說的「琴」出發，往回追更早文獻。這版入口醒目，但容易把「小說後加的道具」當成全片答案，壓縮裴松之對駐地和軍事邏輯的檢驗。故採 A 案起草完整劇本。

## 來源和畫面

- 主要文獻：《三國志》卷三十五〈諸葛亮傳〉正文、裴松之注引郭沖三事及「難曰」；《晉書》卷一〈宣帝紀〉用來交叉檢查宛城任命；《三國演義》第九十五回用來標明小說增加的畫面。固定版本與逐條引文見 [`research.md`](research.md)。
- **轉錄不是獨立史證**：兩個 GitHub 版本可交叉查漏字，不能因此說郭沖故事有兩份獨立見證。裴松之自己的駐地論證與《晉書》的記載也須分清成書年代。
- 插畫走 `cute-mystery`／MiniMax `image-01`；人物過世逾七十年，可以畫成卡通。每張一人一動作、不要在圖內生成可讀文字。宛城與陽平的距離只用地圖方向，不報沒有逐條核實的公里數。
- 圖像中的城門和琴明確標成「演義畫面」，文獻卡標「郭沖故事／裴松之反駁」。卡片少用，正文至少七成插圖；史書字句以真正資料卡呈現，插畫不假裝證據照片。
- 固定 Gemini `Sulafat` 旁白、開場後片頭、可關字幕、系列配樂與音量；片尾不預告下一集。

## 不採用的說法

- 不說「《三國志》證實諸葛亮彈琴退兵」；琴不在裴注所收郭沖段落。
- 不說「司馬懿生涯中從沒見過諸葛亮」；後來關中確有對峙。
- 不把郭沖描述的「二十萬」或諸葛亮的兵數當作歷史統計；它們是被質疑故事的內部設定。
- 不把裴松之的「如果疑有伏兵，守住就好」當成獨立的行軍紀錄；那是對故事合理性的反問。
- 不把小說中的城樓、琴、掃地者畫成當年攝影式重建；只作明示的卡通小說場面。
