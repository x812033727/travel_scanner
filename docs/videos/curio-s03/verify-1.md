# S03 獨立史料覆核 1

日期：2026-10-19。覆核者只查來源，未參與 S03 劇本撰寫；本檔由製作方整理其報告。範圍為影片的**歷史主線和最易混淆之處**，逐句映射另見 [`claims.md`](claims.md)。

| 主張 | 獨立查核結果 | 使用邊界 |

| 郭沖第三事的城在陽平，有四門與灑掃，沒有彈琴 | PASS。[《三國志》卷35裴注固定版](https://github.com/Ancient-China-Books/sanguozhi/blob/10a0b1ab3019d8821262f7402366d14fb4aaa102/OEBPS/Text/035.htm#L23)：「亮屯于陽平……又令大開四城門，埽地却洒。」覆核者比對整段，無彈琴。 | 郭沖的軼事被裴收錄且駁斥；不能稱《三國志》證實開門退兵。 |
| 裴松之以駐地拆郭沖故事 | PASS。同段：「亮初屯陽平，宣帝尚爲荊州都督，鎮宛城，至曹真死後，始與亮於關中相抗禦耳。」 | 指郭沖設在諸葛亮初屯陽平的**這一次**；不說二人從未交手。 |
| 街亭當年的魏方角色 | PASS。[《三國志》卷3](https://github.com/Ancient-China-Books/sanguozhi/blob/10a0b1ab3019d8821262f7402366d14fb4aaa102/OEBPS/Text/003.htm#L17-L25)太和二年記「曹真都督關右」「張郃擊亮於街亭」，沒有司馬懿指揮街亭；太和五年曹真薨後，司馬懿奉詔拒亮。 | 228 年街亭失利與 231 年司馬懿抵抗諸葛亮不能剪成同一役。 |
| 宛城任命、雨阻及後來西屯 | PASS。[《晉書》卷1](https://github.com/Ancient-China-Books/jinshu/blob/7ab60ece69db62d9bc40a62918f93e14432e96a3/OEBPS/Text/1131.html#L56-L74)：227 年六月詔司馬懿屯宛、督荊豫；230 年西城道伐蜀遇雨班師；231 年西屯長安。 | 《晉書》是唐代編修，司馬家帝紀有頌揚傾向；用作時序交叉核，不說成裴松之當年手上材料。此「西城」是進兵路線，不能直接等同小說場景。 |
| 裴的另外三種質疑 | PASS。卷35同段：若疑伏兵，何不設防持重；魏延傳顯示其另道領兵提議未獲亮允；司馬駿身為司馬懿子卻在郭沖說法裡稱讚這段。 | 戰術與司馬駿反應是裴的論證／推論，不是第二份目擊證詞。 |
| 琴、西城縣、童子與灑掃扮百姓 | PASS。[《三國演義》毛評本第95回](https://github.com/Ancient-China-Books/sanguoyanyi/blob/761813427eb5685c395804493f9fbd7ad8dc7d/OEBPS/Text/472.html#L59-L62)題名「馬謖拒諫失街亭 武侯彈琴退仲達」，正文寫西城縣、焚香操琴、每門軍士扮百姓灑掃。 | 小說**沒有「一個老兵掃地」**的設定；本稿只說門口有人，後文明說軍士扮百姓。網頁夾有毛評，要把夾注和敘事分開。 |
| 結論範圍 | PASS。裴末句「故知此書舉引皆虛」；可下的結論是他強烈駁斥郭沖這則陽平故事。 | 不能外推成諸葛亮從未用過任何空城策略。`ef078`–`ef079` 已明示。 |
