# X03 Netflix｜本機試看片製作估算與成本控制

本集全部付費呼叫及稅費合計以 **US$25 為硬上限**。語音、轉錄、模型複查、插畫、畫面評審、配樂、重做與稅費均計入；正式站影片工具顯示的單片 US$200 限額不是本集授權額度。每個付費階段開始前先核對本集媒體台帳及未報價費用，若無法確認仍在 US$25 內便停止該階段。可見台帳不是完整供應商帳單，不能把未列項目視為免費。

本估算綁定 [逐句稿](video.json) SHA-256 `647b73fdb22a2452ad2817ca5554689db5801af0e97996913e7e73c1694b2fb9`，以及 [發布版來源審查](reviews/source-review-release.md)、[盲讀 A](reviews/blind-a-release.md) 與 [盲讀 B](reviews/blind-b-release.md)。它們審的是 80 句文字、畫面提示詞和來源，不是生成媒體。免費 lint 為 **0 錯誤、0 警告**，估計口播約 9.1 分鐘、濃縮開場約 51 秒；最終時長須由實際 TTS 時間軸量測。片中規劃 65 張 MiniMax `image-01` 插畫、12 張後製數字卡，以及一張原生旁白結語卡。後製卡片不應算成付費插畫。
