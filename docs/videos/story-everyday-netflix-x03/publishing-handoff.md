# X03 Netflix｜上架與本機試看片交接

本資料夾是「品牌故事」X03 的製作包，屬原 C01–C20 規劃之外的補充題，承接 X02 達美樂，不改原二十集的編輯順位。片名以 [現行逐句稿](video.json) 為準：**DVD 寄出片數還多了 20%，Netflix 為何先開立即觀看？｜品牌故事**。現稿 SHA-256 為 `647b73fdb22a2452ad2817ca5554689db5801af0e97996913e7e73c1694b2fb9`；80 句旁白與 [逐句來源矩陣](source-matrix.md)一一對應，[原件筆記](source-notes.md)及[發布版來源審查](reviews/source-review-release.md)記錄事實口徑，兩份獨立盲讀為 [A](reviews/blind-a-release.md) 和 [B](reviews/blind-b-release.md)。

影片安排為 30–60 秒濃縮開場、**5 秒片頭**、其餘至少八分鐘口播正文、**21 秒片尾**。本機版本只能放明標「概念」的片頭與片尾；真正的頻道品牌動畫須由站主選定檔案後等長替換，若長度改變就重算字幕、章節時間及全片 QA。結語卡的三句旁白屬正文，片尾動畫接在其後。繁中字幕交獨立 SRT 與 WebVTT，可關閉，不燒進畫面。以下為章名，**正式章節時間待實際 TTS 和合成片量測**：

21 秒片尾保留左右兩個影片元素與訂閱元素的視覺版位。**動畫中的框線不能點擊**。正式私人上傳後，須在 YouTube Studio 的 End Screen 對最後 17 秒設置「最符合觀眾喜好」、「最新上傳」兩個影片元素與訂閱元素，並在實際播放器逐一點擊驗證。完成後才填正式影片 ID、可點連結及最終公開網址；本機概念片不可冒稱已完成連結。說明欄應保留 `video.json.youtube.description` 中四份 SEC 原始申報網址。

資料口徑隨片交接：2007 年 **+20%** 是寄給付費訂戶的 DVD **全年總片數**對 2006 全年，不是人均月租片數；2007 年末約 747.9 萬是**年末總訂戶**，不是一月上線日訂戶。2010 年「多數訂戶」指每位訂戶各自用串流看的內容多於 DVD，**不是串流營收超過 DVD**；同年全年寄片總數仍增 **9.7%**，每位平均付費訂戶月租片數則降 **22.3%**。加拿大 2010 年九月推出不含 DVD 的串流方案，不能寫成美國當時已停寄。2023 年四月宣布計畫、九月二十九日停止 DVD 郵寄服務；「影響不重大」是公司的整體財務判斷。片中匿名訂戶、郵袋、電腦與無字介面是插畫示意，不是真實網站截圖、片庫畫面或歷史影像。

媒體製作與 QA 尚須把以下實測證據補入本包：正文與首章時間軸、每句旁白核對及必要重錄、65 張插畫逐鏡驗收、12 張後製卡、配樂與可見成本台帳、預覽 MP4／縮圖／SRT／VTT 的 SHA-256。輸出至少驗證 1920×1080／30 fps、完整視音訊解碼、連續影格時間戳、聲音響度及真峰值、字幕和最終逐句稿吻合；待審插圖或旁白必須明列，概念版仍標 `approved:false`。成本遵守 [US$25 製作估算與硬上限](production-quote.md)。完成正式品牌素材、人工音畫複核及 YouTube Studio 可點片尾元素驗證後，才可另行判定正式上架。
