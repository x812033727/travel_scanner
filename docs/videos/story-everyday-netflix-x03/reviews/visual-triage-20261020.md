# X03 Netflix｜本機概念試片視覺規格複核（2026-10-20）

**結論：目前試片只供故事與剪輯概念審看，不能依「奇聞檔案局同規格」核准畫面。** 影像沒有發現必須推翻旁白的明顯反事實圖解，但 23 個名義上屬於 `shot` 的畫面實際由本機 SVG 輸出，且所有 MiniMax 畫面使用了自訂 `look.style`，不符合站主固定的 `{ "preset": "cute-mystery" }` 畫風設定。現有 `approved:false`、`official_branding:false` 標記應維持。

## 核對範圍與可重算數字

- 對照 [目前主片](../video.json) SHA-256 `08c931bb000f373fbf5778d02b0703ef1a8b5144c665bfa30afda7c44ed3e5ac`、[人工選圖收據](manual-keyframe-selections-a0cbc1ff06c9.json)、媒體工作區 `keyframes/manifest.json` SHA-256 `966ec34ecb624f6fb3fc8242f2d075f3a697186be5f6643145557eea62ef248c`、三頁接觸表及概念 MP4 SHA-256 `28237f52f5deacd7bbe1ea2c90cf2616cc48d1e57cb296c65c407e587b8cd728`。工作區中的 `keyframes/manual-source/generate.mjs` 首行自述「No media model」，產生 SVG 再輸出 PNG；其來源在選圖收據的 `donor_file` 可逐鏡查回。
- `video.json` 有 **65 個 `shot`、12 個 `big`、1 個 `outro`**；正文計算母數是 77。49 個替代鏡頭中，**23 個**選用本機 SVG 衍生 PNG（19 個不同圖檔），其餘 26 個選用其他已生成的 MiniMax 候選圖。以實際生成來源計，最多 **42／77＝54.5%** 的正文景是 MiniMax 插畫，低於至少 70% 的門檻；把 SVG 景在 JSON 裡標成 `shot` 不會改變來源。接觸表上多個 SVG 景也呈平面流程圖，與系列的可愛敘事插畫觀感不同。
- `keyframes/manifest.json` 的 65 個選圖只含 **39 個不同 SHA**，有 26 次額外重用。`scene-nx0105` 的同一記事本畫面出現六次（`nx0105/nx0305/nx0315/nx0408/nx0501/nx0519`），`nx0103` 的電腦觀眾畫面出現四次。這些畫面未必直接說錯事實，但會讓 2007、2010 等不同段落看起來像同一時刻。
- `video.json.look` 同時含 `preset: "cute-mystery"` 與自訂 `style`。`tools/video/core/drama.mjs` 的 `resolveLook()` 採用 `look.style ?? preset.style`，所以這不是只留在文件的註解，而是取代預設生成提示詞。系列規則要求**只有** `{ "preset": "cute-mystery" }`，不得另加 `style`、`negative`。因此，嚴格照現行規則重製時，現有 42 個 MiniMax 選圖也不能當作已合規的最終插圖。
- 時間軸 `timeline.json`：開場在影格 1,501 結束；結尾三句從影格 15,922 開始。嚴格排除開場與三句結語後，故事正文是 `(15,922−1,501)/30 = 480.70` 秒，即 **8:00.70**。現版剛好過八分鐘門檻，但只多 0.70 秒；重配音時須重新實測。舊說明中的「8:21.33 剩餘口播」含三句結語，不能當成嚴格正文時長。
- 本輪在本集 Git 文件、媒體工作區及概念片交付資料夾均未找到兩支 `from-episode` Shorts 的腳本或成片；這是與視覺修復分開的交付缺口，不能把長片概念版視為一整集已完成。

## 最小合規修法與費用關卡

1. 保留現在的 MP4 和原始選圖證據作為未核准概念紀錄；另開媒體工作區重製，以免舊 manifest 的手動替代圖混入新選圖。`video.json.look` 改為只有預設，鏡頭提示詞只描述內容，不塞畫風或假字；稿件文字不需因這次視覺審查改寫。JSON 全檔 SHA 會變，原來源／盲評收據須留下精確的畫風差異覆核，不能繼續宣稱綁舊 SHA 的審查適用新檔。
2. 在新畫風下對 **65 個 `shot` 都使用 MiniMax `image-01`**；12 個後製數字卡繼續只放有來源的數字與名稱，最多三張連續卡。每張圖核對所述時代、郵袋／光碟、方案數量、無假字及卡通畫風，再合成、重做接觸表和片內 QA。新畫面應減少同圖在不同年份的多次重用。
3. 從已審稿的長片片段另製兩支 25–55 秒 `from-episode` Shorts，沿用同一旁白聲線與正確畫面；單獨檢查字幕、裁切與來源。現有交付物尚未提供這兩支。
4. 在任何付費重畫前，先取得完整供應商費用核算及整批乾跑報價。本輪唯讀 `keyframes --dry-run --takes 3` 報 **65 景、單次全批約 US$0.88、最多三次約 US$2.63**，相當於最多 195 次圖片候選與相應評審的當下估價；移除 `look.style` 後還須重新乾跑確認。現有工具台帳 SHA-256 `04fd035da3dd59359964c25cbf869cce22359ae2ca19893c13138a0a6cd5c671` 只計 **US$1.7135**（122 張候選圖、121 次評審、一首配樂）；若整批依上限另花 US$2.63，可見台帳約為 **US$4.3435**，距 US$25 表面上有 **US$20.6565**。這**不是**可用餘額，因語音、轉錄、額外複查及稅費未拆帳。全支 US$25 硬上限無法由目前帳單證明，故本次複核**沒有啟動付費生成**。
