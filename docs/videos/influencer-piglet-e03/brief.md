# 網美小豬 EP3〈仙境瀑布〉

## 故事前提

粉粉在霧氣繚繞的叢林瀑布前拍美照。拉遠：陰天的頂樓，瀑布是不鏽鋼水塔破洞噴出來的水，背景是一塊印著葉子的防水布；水豚男友站在梯子上，兩隻手各堵住水塔的另一個破洞，全身濕透。她重擺姿勢，男友的手一滑，兩道水柱把她從頭沖到腳。

## 角色

- 粉粉（fenfen）、水豚男友（capy）：同系列定裝照；粉粉穿系列招牌的白蕾絲洋裝、大草帽配粉紅緞帶、珍珠髮夾。

## 站主觀點

零台詞；系列公式：唯美 → 閃光一瞄 → 拉遠揭曉 → 男友 → 成品照破綻 → 重擺被整。EP3 題目照系列 README。
