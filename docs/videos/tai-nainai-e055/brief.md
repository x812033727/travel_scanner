# 《恁祖媽今年18》第 55 集〈家譜〉

## 故事前提

DNA 剛念完，建業就喊檢體換了、她收買了檢驗所；阿凱說那就再驗一次、他親自送。林美鳳問十八歲的丫頭怎麼生得出七十八歲的女兒，月棠答：玉琴是我十八歲那年生的。
建邦一句話也沒說，轉身往祠堂走。那天夜裡他還坐在祠堂的燈前，福伯端來的晚飯涼了；他從供桌抽屜拿出七十年沒人翻過的家譜，一翻開，半張黑白照片滑出來：
年輕的作甫懷裡抱著這盞燈。福伯打開懷錶，拿出藏了七十年的另一半——老太太自己撕開的。兩半在燈前拼成一對年輕夫妻和一盞燈；
家譜那一頁寫著「沈月棠，民國三十七年立燈」，筆跡跟大廳牆上的兩個簽名一模一樣。他在祠堂坐了一夜，天亮時周懷安來電：明天不用印，盛通抽銀根，下個月發不出薪水。
他握著家譜沒出聲，把家譜收回抽屜，只帶走兩半照片。傍晚，月棠在正廳一勺一勺餵玉琴喝甜粥，建邦捏著照片站在她身後，嘴動了動，喊不出來。
