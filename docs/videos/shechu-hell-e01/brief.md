# 社畜地獄 EP1〈準時下班〉

## 故事前提

六點整，狗員工阿金一秒收好包包要下班；貓老闆喵總坐在他桌上，面無表情地把他剛做完的報告慢慢推下桌。深夜，整層樓只剩阿金重排報告，喵總在溫暖的印表機上睡覺——醒來，又伸出一隻掌。

## 角色

- 阿金（ajin）：黃金獵犬，白襯衫、歪掉的藍領帶、空白識別證、黑眼圈。
- 喵總（miaozong）：胖橘貓，深灰西裝、金色領帶夾，面無表情。

## 站主觀點

零台詞系列《社畜地獄》（`docs/videos/shechu-hell/README.md`）：笑點來自貓的天性就是暴君老闆。一鏡一個主角，同框只給全景、不碰觸。

## 格式

- 9:16 Shorts／Reels，約 15 秒，零台詞；Colab 首格與 H3 片段。

## 大綱

### 選項 A：準時下班
一行說明：六點整 → 收包包踮腳要走 → 老闆把報告推下桌 → 慢轉頭 → 報告散落 → 深夜重排、老闆睡印表機 → 老闆睜眼伸掌。
開場鉤子：時鐘跳到六點。
