## 不採用／待重查

| 說法 | 本次處理 |
| --- | --- |
| 日誌寫看守員哭泣、禱告或「上帝在上」 | 不作真實日誌，不安排逐句朗讀；傳播史若加回，必須另開原刊與研究者原文。 |
| 海怪、謀殺、集體逃離、金絲雀 | 無本次一手證據，不拿來延長片長或製作肯定式縮圖。 |
| 三人死於同一波浪的確切姿勢與順序 | 無目擊，不畫成確定場面。 |
| 大浪高 110 英尺 | 禁用；把設施高度誤當浪高。 |
| 某人違規或受罰造成事故 | 本次未確認，不歸責遇難者。 |

## 兩個可檢驗的觀看成果

1. 觀眾能把「整理過的廚房」與「詩中的餐桌」放回不同文件，判斷哪個可作現場證據；畫面用日期及文件類型的短卡片證明。
2. 觀眾能指出官方海浪說依據哪些損害，以及為何仍不能還原最後瞬間；同一西側路徑的插圖與高度卡片承接，不用另開理論清單。
