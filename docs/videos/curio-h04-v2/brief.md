# H04 v2｜佳特洛夫事件：九個人為何離開山坡上的帳篷？

## 一句問題與答案

1959 年二月，搜救者找到鞋和外衣仍在的空帳篷，九人為何離營？1959 年卷宗確認帳篷有從內側割出的切口、往山下的不同足跡，以及調查者的突然離營推論。2021 年的小雪板模型提供一個在若干地形、弱層、切坡、風吹雪條件下可行的機制；2021–22 年考察補強部分地形與區域雪崩前提，沒有還原當夜的雪層或九人的行動順序。因此答案仍是有根據的可能，而非破案宣告。

## 大綱

### 選項 A：跟著搜救者打開空帳篷（現行稿）
一行說明：二月發現空帳篷後，隨搜索、四月鑑定、五月結案與後來的模型和考察逐步揭開；每項證據只在它被查出的節點出現。
開場鉤子：「一九五九年二月二十六日，搜救者在北烏拉山找到一頂帳篷。」

### 選項 B：從往山下的足跡追起
一行說明：先讓觀眾跟搜救者辨認不同鞋襪印，再回望身後那頂空帳篷；之後仍依卷宗、鑑定與研究被查出的順序推進，重心偏向九人離營後的路線。
開場鉤子：「一九五九年二月，搜救者在帳篷外，看見幾組往山下延伸的足跡。」

選項 A 已落在本版 `video.json`。B 是同一組來源的另一個現場切入點，尚未寫成腳本，也沒有取得站主對 v2 的選角核准。

## 故事路線

現行 A 版由發現空帳篷開始，跟著搜索與後來調查所得的時間順序走，避免把「足跡／卷宗／雪崩理論／結論」排成各自重啟的資料清單。

1. 00:00–00:45：搜救者走近空帳篷，只看見鞋子與往山下延伸的足跡。依序投下四個未揭曉的後續瞬間：四月鑑定桌、五月結案書、後來的雪板模型、兩名當地嚮導再到附近雪坡。
2. 00:45–03:03：搜救者沿殘存足跡找人；名單原有十人、一人因病折返；分辨足跡形態、八至九組的不確定性。結案書把林邊火堆附近兩人、朝帳篷方向三人及五月溪溝深雪下四人的位置記錄下來。裂口方向仍待鑑定。
3. 03:03–04:29：四月鑑定指出內側切口；五月結案書寫「無力克服的自然力量」，並未指明哪片雪或時刻；2019–20 年的複查與記者會把雪崩說法帶回視線。
4. 04:29–05:44：2021 年研究提出局部陡坡、雪下弱層與搭帳平台切口的模型條件。
5. 05:44–06:52：風搬運舊雪增加負載，模型允許延後釋放；時間是有條件的可行性，不是事故時鐘。
6. 06:52–結尾：2021 年地形測量、2022 年鄰近坡雪崩痕跡與模型差異，最後回收開頭問題，以三句收尾：謹慎回答、觀眾問題、訂閱理由；不預告下一支。

四條 `loops` 的 setup/payoff 精確列在 `video.json`。中間的兩個提問維持 60–90 秒的進展節點。約 8.7 分鐘是 `lint` 的旁白估計，實際時長要以合成音訊測量。
