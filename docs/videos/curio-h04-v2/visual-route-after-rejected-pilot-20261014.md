# H04 退件後的視覺路線判斷（2026-10-14）

本檔只做離線路線試算，**沒有**改正式分鏡、音訊、後台核准或付費媒體。現行敘事與音訊已核准；已付費的 `model-paper-card` 雖由正常 judge 判為 PASS，但原圖有黃帳篷、樹和特定雪板，人工退件。`tent-opening-question` 只有美術方向候選，未具來源示意標籤，亦未人工採用。負面證據及帳本見 [六圖授權後檢](authorized-six-pilot-postflight-20261014.md)。

現行時間軸 15,827 格，插畫門檻為 `ceil(15,827×0.5)=7,914` 格。分鏡表的 `shot` 規劃是 7,935 格，僅多 21 格；它不等於可用實圖。若把退件的 `model-paper-card` 231 格改成來源圖卡，規劃 `shot` 變 7,704 格、缺 **210** 格。若另把未標「非復原」的 `tent-opening-question` 143 格也改來源卡，變 7,561 格、缺 **353** 格。現有來源卡各 202 格以下，僅改場景類型湊不回缺口，且不能把退件圖當成已驗收畫面。

### 可免費驗證的候選

1. 保留插畫路線：在**隔離副本**把模型章 `model-later-two` 的兩句 87＋186＝273 格試排成抽象雪板機制畫面。僅在 231 格退件鏡頭改卡的情況，規劃可達 7,977／15,827 格，餘 63 格。若連開場 143 格也改卡，再加 `snow-over-step` 的 214 格，規劃為 8,048／15,827 格，餘 134 格。這些新畫面仍需每張來源安全、人審可用；真實帳篷、林木、現場雪崩形態不得被虛構。機制所需的條件與來源文字也須保留在畫面或旁白，不能只為比例把精確圖卡改為插畫。**新付費圖片沒有授權**。
2. 來源圖卡為主的純投影片路線：可用現有正式渲染器製作來源可查的原創卡與局部有聲草剪，不依賴 MiniMax 重畫現場。但這會修改已選的插畫比例與畫面規格，須由站主選定，不能自行宣告等同原規格。

現有 `keyframes` 產線沒有經審原創 SVG／手繪圖正式匯入 `shot` 的可用路徑；不得手填 manifest 或改 `accepted` 欄位冒充已通過。正式變動後要重跑獨立敘事、重建時間軸、重新取得精確音訊雜湊核准，再做連續小樣、字幕、完整圖組與 QA。兩條候選目前都未證明能產出完整合格影片。
