## 劇情

第 3 天清晨，月棠把小滿的書包從垃圾桶撈出來，蹲在院子的木盆邊洗乾淨，掛上東側的竹竿；小滿天沒亮就抱著紙袋出門了。林美鳳出來一腳踢翻水盆：「保母，去洗衣服。」
她只回一句：衣服我洗，盆子妳扶起來。近午，她蹲在洗衣間的鐵皮盆邊手洗衣服，福伯忍著笑教她把衣服丟進洗衣機按一下，滾筒自己轉起來。她用老法子把米先炒過再熬粥，端給坐輪椅的玉琴；
玉琴嚐了一口，手帕掉在腿上，抓住她的手腕：「這是我媽的味道。」外送員在廚房門口喊，她當他是餓肚子的孩子要請他喝粥，原來是林美鳳點的餐；林美鳳搶過袋子笑她把外送當乞丐，
她湊近一看，說林美鳳的珍珠孔口顏色深，是染的，林美鳳紅著臉頂回去。廚房小桌上三個人安安靜靜吃完那鍋粥，玉琴問她明天還熬不熬，她說天天都熬；玉琴第一次對這個保母笑。那一刻祠堂的燈長高了一級。
夜裡她進祠堂添油，看見燈比昨夜高，剛要笑，建邦站在門口問她一個人在祠堂做什麼。
