# 網美小豬 EP4〈櫻花雨〉

## 故事前提

粉粉在滿天櫻花雨裡伸手接花瓣。拉遠：灰濛濛的機車停車場，櫻花樹是一棵枯樹纏滿粉紅衛生紙和塑膠袋，花瓣是碎紙；水豚男友站在梯子上，拿吹葉機往一箱粉紅碎紙裡吹，滿臉黏著碎紙。她重擺姿勢，一整箱碎紙從天而降，把她埋成一座粉紅小山。

## 角色

- 粉粉（fenfen）、水豚男友（capy）：同系列定裝照；粉粉穿系列招牌的白蕾絲洋裝、大草帽配粉紅緞帶、珍珠髮夾。

## 站主觀點

零台詞；系列公式：唯美 → 閃光一瞄 → 拉遠揭曉 → 男友 → 成品照破綻 → 重擺被整。EP4 題目由本批企劃，照系列公式。

## 格式

- 9:16，約 16 秒；Colab 首格與 H3 片段。

## 大綱

### 選項 A：櫻花雨
一行說明：櫻花雨接花瓣 → 閃光一瞄 → 停車場枯樹纏衛生紙 → 男友拿吹葉機吹碎紙 → 成品照櫻花叢裡有水豚臉 → 一整箱碎紙把她埋掉。
開場鉤子：櫻花雨裡，有一片花瓣是方方正正的粉紅衛生紙。
