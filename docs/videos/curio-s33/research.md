XML 日期字串末尾是 `L0`，編輯標題沿實錄的傳統紀月日。1443 與 1446 的關鍵條目都寫 **「是月」**：它們被編在十二月末與九月末的條目下，**不能**改寫為「十二月三十日造字」或「九月二十九日出版」。1444 奏疏、世宗答覆與次日記事則有逐日紀錄。全片可以用公元年份；月日需說「實錄二月二十日」，不另宣稱是換算後的西曆日。

## 原文與可查譯解

| ID | 原文定位與短句 | 可在旁白說的意思／限制 |
| --- | --- | --- |
| P1 | SG33-A `wda_12512030_002`：「是月，上親制諺文二十八字……分爲初中終聲，合之然後乃成字，凡干文字及本國俚語，皆可得而書……是謂訓民正音。」 | 實錄稱世宗親自創制 28 字，字可組合寫語音；此為 1443 年冬的記錄，未給創制的單日。`凡干文字` 依拼音文字脈絡白話為漢字的讀音可記，不能說新字代替了漢字字形。不能把今天常用字母數回填為當年的 28。 |
| P2 | SG33-B `wda_12602016_001`：「命集賢殿校理崔恒……以諺文譯《韻會》，東宮……監掌其事。」 | 實錄二月十六日記載世宗命崔恒等人以新字處理《韻會》，世子與兩位大君監掌。這是朝廷分派工作，**不是**說整個集賢殿一致贊成。 |
| P3 | SG33-B `wda_12602020_001` 開首：「集賢殿副提學崔萬理等上疏曰：『臣等伏覩諺文制作，至爲神妙……然……尙有可疑者。』」 | 崔萬理等**先稱製作巧妙，再逐條反對推行**。署名是「等」，不能說所有朝臣、所有學者都反對。 |
| P4 | 同條奏疏第一、二段：「字形雖倣古之篆文，用音合字，盡反於古」「若流中國……有愧於事大慕華」「《傳》曰：『用夏變夷，未聞變於夷者也。』」「今別作諺文……豈非文明之大累哉？」 | 反對者擔心對華關係、既有漢字文化秩序；拿其他自有文字的政權作負面比較，是**他們**的價值語言。這是奏疏的論點，不是本片接受其價值判斷，也不是世宗的動機。 |
| P5 | 同條奏疏第三段：「先讀數書，粗知文字，然後乃用吏讀」「若行諺文……不顧學問文字。」 | 他們說舊有吏讀仍把人帶到漢字學習，擔心新字變成官吏停學漢文的捷徑。記錄並沒有證明這個預測後來成真。原文此段另寫「二十七字」，與 P1、P10 的 28 字不一致；**不拿這個數字作定量結論**。 |
| P6 | 同條奏疏第四段：「今以諺文直書其言……悉皆易曉」「獄囚之解吏讀者，親讀招辭，知其誣而不勝棰楚，多有枉服者」「刑獄之平不平，在於獄吏之如何，而不在於言與文之同不同也。」 | 奏疏承認有人主張新字可讓被審者明白供詞，卻舉懂吏讀者仍可能屈打成招的例子，反駁冤案關鍵在官吏而非文字。這是具體制度爭點，不能簡化成「大臣不讓百姓識字」。 |
| P7 | 同條奏疏第五、六段：「今不博採群議……劇欲廣布」「東宮……猶當潛心聖學」。 | 反對者還質疑推進速度、諮詢範圍及世子耗費時間。奏疏稱「欲廣布」，只能說他們擔心即將廣布，**不是已證全國發行**。 |
| P8 | 同條世宗答覆：「且吏讀制作之本意，無乃爲其便民乎？如其便民也，則今之諺文，亦不爲便民乎？」 | 世宗以舊吏讀的便利性反問：若舊法可為民方便，新字何以不可。這是實錄記錄的**世宗答辯**，不宜代他補出未說的政策細節。 |
| P9 | 同條答覆與處置：「且疏云：『新奇一藝。』……汝等之言，頗有過越」「前此金汶啓曰：『制作諺文，未爲不可。』今反以爲不可」「予召汝等，初非罪之也……變辭以對」「遂下……于義禁府。翌日，命釋之，唯罷昌孫職。」；次日 `wda_12602021_001`：「金汶……只贖杖一百。」 | 世宗認為部分措辭越界、答話變動；他**自稱**起初並非為問罪而召見。七名具名反對者被交義禁府，次日獲釋；鄭昌孫遭罷職，金汶次日另被追究前後說詞，只贖一百杖。**不能**說七人都被長期監禁、受了實際百杖或全部遭革職。 |
| P9a | 同條世宗第一輪答話後，崔萬理等人對曰：「薛聰吏讀，雖曰異音，然依音依釋，語助文字，元不相離。今此諺文，合諸字而竝書，變其音釋而非字形也。且新奇一藝云者，特因文勢而爲此辭耳，非有意而然也。東宮於公事則雖細事不可不參決，若於不急之事，何竟日致慮乎？」 | 反對者當場回答：舊吏讀仍連著漢字音義，新字的拼寫在他們看來是另一套；「新奇一藝」只是順著文章語勢，沒有輕慢本意；世子參與公事合理，但他們不認為這項工作急到要整天費心。這是他們**自述的辯解**，不是現代學界對兩種文字系統的總結。 |
| P10 | SG33-C `wda_12809029_004`：「是月，訓民正音成。御製曰：『國之語音，異乎中國，與文字不相流通……予爲此憫然，新制二十八字，欲使人易習，便於日用耳。』」 | 1446 年《訓民正音》成書；御製序直接說世宗希望容易學、方便日用。這是**御製序的自述**，不能從書成倒推所有人立刻識字。 |
| P11 | 同條鄭麟趾序：「學書者患其旨趣之難曉，治獄者病其曲折之難通」「臣與集賢殿應敎崔恒……謹作諸解及例。」 | 鄭麟趾在成書序中說明漢字與當地語音不合帶來讀寫、案件表述問題，並列出合作作注解的集賢殿人員。這與 P3 的反對者同在朝廷，不能把集賢殿畫成單一立場。 |
| P12 | SG33-C `wda_12812026_003`：「今後吏科及吏典取才時，訓民正音，竝令試取。雖不通義理，能合字者取之。」 | 同年十二月二十六日的諭令把《訓民正音》納入吏員甄選；即使不精通義理，能拼字也可錄取。這證明**制度上的採用命令**，不證明普通百姓當年已全面使用。 |

## 取捨與影片邊界

- 一條故事線：從二月十六日編《韻會》的工作，到二十日奏疏、當面回應、次日處置，再問兩年後文本是否做出來，收在成書與吏員考試。1443 造字作必要的短回溯。
- 懸念在「大臣先稱神妙卻反對什麼」「世宗怎麼回答司法問題」「反對後是否停下」「成書是否真開始用」。每個答案由原文提供，不用佈景代替證據。
- 不說世宗是完全孤身造字，也不把「28 字」換成現代字母 24；不說全國百姓 1446 年突然識字、所有大臣反對、崔萬理遭處決、反對者被永久流放。
- 圖像是可愛插畫；奏疏、御製序、字母與書頁上的**真字**留給少量帶明確出處的字卡，MiniMax 不生成可讀的假史書。真人照或現存文物在未核授權與館藏前不用。
