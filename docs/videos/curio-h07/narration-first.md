# H07｜旁白初稿：開場至第三章

## 開場

一七零三年，巴士底獄副官把一名蒙面囚犯的死訊寫進登記簿。
他記下死亡時刻，也記下面具，卻沒留下能確認死者身世的名字。
一六六九年，一封公文曾為一名受嚴密看守的囚犯寫下姓名。
那個名字，會不會就是副官缺少的答案？
一六九八年，典獄長帶著一名老囚犯走進巴士底獄。
那一筆入獄登記，會怎麼稱呼這名囚犯？
一七三八年，伏爾泰又在信裡給這段故事一個稱呼。
他的寫法，會讓這副面具變成什麼模樣？
被埋葬的人究竟是誰，他的面具真的是鐵做的嗎？

## 第一章｜副官補記了一副黑絲絨面具

副官的筆尖沒有停在「蒙面」兩字。
死亡補記還寫著：面具是黑絲絨。
他記下囚犯當晚約十點去世，始終沒有交代可核對的本名。
隔天下午四點，囚犯葬在聖保羅堂區墓地。
你以為，下葬紀錄終於能證明他是誰。
其實，留下的是一個連拼法都不一致的名字。
一份轉錄把它讀成馬爾基奧利。
另一份摹本讀成馬爾基亞利。副官的邊註，還有第三種拼法。
這些讀法都連著這次下葬，卻無法獨自證明死者本名。
而典獄長早年收到的那封公文，寫的又是誰？

## 第二章｜盧福瓦寫下多熱的密令

一六六九年七月十九日，那封公文寫下厄斯塔什．多熱這個名字。
寫信的官員是盧福瓦，收信的是典獄長聖馬爾。
國王要把他送到皮涅羅爾關押。
光看這封信，還不知道他犯了什麼事。
可官員連送飯的人，都指定好了。
聖馬爾必須親自送飯，哨兵不能聽見囚犯說話。
他也不能把消息傳到監獄外。
官員到底要防他說出什麼？
信裡沒有答案，只有一句讓後人更難解的稱呼。
盧福瓦說，這人只是一個「男僕」。
有人按字面理解，也有研究者認為是雙關語。
兩種讀法都不能替他補出一份履歷。
更關鍵的是，這封信沒有提到面具。
它也沒有說，多熱就是後來巴士底獄那名無名囚犯。
前一份登記不給姓名，這封密令卻給了名字。
兩端之間，有沒有一道足以接起名字的線索？

## 第三章｜聖馬爾押送「老囚犯」進巴士底獄

一六九八年七月，聖馬爾又收到移監公文。
官員准他從聖瑪格麗特島帶一名「老囚犯」去巴士底獄。
這次的命令要聖馬爾防護，別讓旁人看見或認出囚犯。
它只談這趟押送，沒交代先前每座監獄如何看守。
但這位「老囚犯」是多熱嗎？公文沒寫。
同年九月十八日，巴士底獄的入獄登記接住了這條路線。
還記得開頭那筆入獄登記嗎？
入獄登記沒寫姓名與材質；黑絲絨出自死亡補記。
副官也記下，聖馬爾以前曾在皮涅羅爾看管他。
同一名典獄長、同一座舊監獄，讓兩端有機會接上。
線索可以支持追查，卻不能把推測當成簽名。
後來，有一封信替那副面具換了名字。
信裡那個字，會不會真的是它的材質？
