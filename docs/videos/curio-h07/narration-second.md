# H07 後半段旁白｜第四至第六章

### 第四章｜伏爾泰信裡出現「鐵面人」

一七三八年，伏爾泰叫他「鐵面人」，卻沒交代材質的查驗依據。
他說自己問過曾服侍囚犯的人。
可惜信裡沒有那場問答的逐字紀錄。
我們無法從這句話查出，對方親眼見過什麼面具。
更不能由此認定，伏爾泰是第一個說「鐵」的人。
還記得死亡補記的黑絲絨嗎？為何「鐵」字會蓋過它？
一七五一年，《路易十四時代》把故事帶給更多讀者。
書裡又多了一個細節。
伏爾泰寫的是面具下巴有鋼製彈簧，讓囚犯戴著也能吃飯。
鋼製的是他描述的彈簧，不能憑這句話認定整副面具是鐵的。
書裡還有大量細節，讓這位沒有名字的人活了起來。
但它把囚犯轉入巴士底獄的年份，寫成一六九零年。
獄方那份登記，比這個年份晚了八年。
這個差錯提醒我們，作家的敘事不能代替獄方紀錄。
面具的材質越講越硬，連囚犯的身世也變得高貴。
王室身世是何時進入故事的？
一七七一年版的另一段文字，猜囚犯是國王的兄長。
那段文字被標作「編者增補」，作者是不是伏爾泰仍有爭議。
這只是後人的猜想，獄方沒有揭露他的身世。
到了十八世紀末，兄長故事又長出雙胞胎版本。
如果兩張臉一模一樣，遮住其中一張，劇情就說得通了。
後來大仲馬把雙胞胎寫進小說，這副面具更難和王室分開。
可是故事越完整，最初的文件卻沒有多出一行王室身分。
金屬頭罩和雙胞胎，能解釋傳說怎樣流行；不能替囚犯填姓名。
真正能接近名字的，仍是那封祕密公文和下葬簿的摹本。
兩條線索看似可以拼在一起，卻未必屬於同一個人。

### 第五章｜兩個候選姓名不能拼成一人

我們把兩個候選名字，分別拿來對照死亡登記。
如果多熱就是蒙面囚犯，同一名典獄長的路線就能接上。
從皮涅羅爾到埃克西耶，再到聖瑪格麗特島和巴士底獄。
四處監禁地點、大約三十四年，都靠這項身分推定才成立。
這個年數說的是囚禁，並不是戴面具的時間。
還記得開頭那封有名字的密令嗎？
但死亡登記沒有寫多熱，這一步仍靠研究者推定。
歷史學者桑尼諾甚至提出了封口的理由。
他認為多熱曾替馬薩林樞機的財務總管當僕役。
依他的推論，馬薩林侵吞英國前國王與王后的財產，可能被多熱知道。
在法王爭取英王參戰的時候，這個秘密可能會惹出麻煩。
這是桑尼諾對公文和時局的重建，不是那封關押密令列出的罪名。
它提出一種「為何保密」的解釋，卻還不能替死亡登記補上真名。
問題來了：如果下葬名另有所指，多熱那條路線還能成立嗎？
另一條線索，是前面那個下葬名。
堂區原簿已毀，十九世紀刊出的摹本還在。
我們仍能比對摹本與轉錄，卻無法確定那是不是囚犯本名。
十九世紀史家芬克布倫塔諾，認為名字指向馬提歐里。
這讓馬提歐里成為一位候選人，沒有讓爭議就此消失。
若死者真是馬提歐里，多熱的囚禁路線就不能算在他身上。
兩種說法各有線索；把它們各取一半，會得到一個文件裡不存在的人。
直到現在，坎城的鐵面人博物館仍說他的真實身分不明。
那個「鐵」字，最後還有一關：能拿什麼實物驗它？

面具沒留下；副官記下黑絲絨，死者是誰仍未定。
