# 凱撒真說了「連你也，布魯圖斯」？六十多人的密謀，誰聽見了這句｜奇聞檔案局

## 角色

- Ada（researcher），聲音 gemini:Sulafat

## 場景

### 連你也，布魯圖斯？

#### 1. open-you

旁白（對觀眾說，像聊天）：你大概聽過，有人被朋友出賣的時候，會學凱撒說一句：連你也，布魯圖斯？

#### 2. open-meaning

旁白：說的是凱撒被一群人刺殺的那一刻，看見布魯圖斯也拿著刀。

#### 3. open-plot

旁白（放慢，帶一點挑釁）：這大概是全世界最常被借用的遺言；它背後，是一場超過六十人參與的密謀。

#### 4. open-stage

旁白（沉穩，停住）：舞台上演到這一幕，扮布魯圖斯的人舉起道具刀，凱撒正要開口。

#### 5. open-last

旁白（轉折，亮起來）：可是你想不到：在這齣戲的劇本裡，這句名台詞，竟然不是凱撒的最後一句。

#### 6. open-two

旁白（升級，收著）：更怪的是，那一天有兩個布魯圖斯：一個勸凱撒出門，另一個會站在哪裡？

#### 7. open-promise

旁白（承諾句，問句上揚）：今天我們就來聊聊：歷史上的凱撒，臨死前真的說了這句話嗎？
