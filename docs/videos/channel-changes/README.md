# 頻道改動紀錄與檢討節奏

站主 2026-11-11 要一個分析與改善機制。每個會影響頻道數字的改動都在這裡記一列，到了檢討日再拿報表回來對答案。

- **這裡只記決定**：改了什麼、預期哪個數字會變、哪天回來看、結論。報表數字不寫進來，寫在每週的製片單（`producer` skill）。自己算的比率不能公開，見 [`../YOUTUBE-REPORTS.md`](../YOUTUBE-REPORTS.md)。
- **判斷規則**：照 `.agents/skills/producer/references/series-diagnosis.md`。只看自然流量，至少 3 支、滿 7 天才下結論，跟同系列的中位數比。
- **一次只改一件事**：同一個系列同一時間只改一個變數（縮圖、標題、開場、宣傳），不然分不出是哪個改動造成的。
