# 社畜地獄（系列）

站主 2026-11-03 提的系列：**員工是狗、老闆是貓，演上班的事情。** 零台詞系列，跟《汪家夫妻》《闖禍小浣熊》同一套規則。

和之前退掉的《汪汪社畜》不同：那一版靠狗的內心獨白和職場黑話撐笑點，評審與站主都覺得無聊。
這一版**不講話**，笑點來自「貓的天性就是暴君老闆」：把桌上的東西推下去、一天睡十六個小時、坐在鍵盤上、
看到雷射紅點就失控、最愛紙箱、永遠搶走最暖的位置。上班族一看就懂，養貓的人更懂。

## 系列規則

| 規則 | 內容 |
| --- | --- |
| **零台詞** | 沒有台詞、旁白、內心話；只有配樂與音效，關靜音也看得懂 |
| 長度與格式 | 13–18 秒，5–7 鏡，9:16 Shorts／Reels |
| 畫風 | 寫實 AI，真實外觀的狗與貓像人一樣穿西裝上班；世界裡沒有人類 |
| 場景 | 同一間小辦公室：一排員工座位、老闆的玻璃辦公室與大皮椅、會議室、茶水間、印表機 |
| 公式 | 狗員工想做一件正常的上班事 → 貓老闆用貓的天性破壞 → 停頓（狗慢慢轉頭、貓面無表情對看）→ **跳過過程**，直接給荒謬的結果 → 補刀 |
| 收尾 | 不要每集都「對鏡頭甜笑」；補刀多半落在貓老闆一個若無其事的貓動作上 |
| 鏡頭 | **一鏡一個主角**：狗與貓的對手戲用正反打（狗一鏡、貓一鏡），兩個同框只給全景、而且不碰觸 |
| 不拍 | 吃喝過程、看得懂的字（文件、螢幕、名牌都模糊或用圖示）、碰觸的過程 |
| 製作與語言 | Colab 首格（定裝照當參照）與 H3 直式片段 → ffmpeg 剪接 → `shorts import`；八語只翻標題與說明 |

## 角色

| 角色 | 外觀錨點 | 個性 |
| --- | --- | --- |
| 阿金（狗員工） | 真實的黃金獵犬，站立，白襯衫、歪掉的藍色領帶、掛著空白識別證，黑眼圈 | 認真、好脾氣、永遠準時、永遠被整 |
| 喵總（貓老闆） | 真實的胖橘貓，深灰西裝、金色領帶夾，坐在超大的黑色皮椅上 | 面無表情、愛睡、想到什麼就推什麼下去 |
| 同事（偶爾） | 臘腸狗新人「小香腸」：短腿、過大的西裝 | 只當背景與反應 |
