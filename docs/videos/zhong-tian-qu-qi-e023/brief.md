# 《種田娶妻打天下》第 23 集〈逃婚的真相〉

## 故事前提

第 22 集收在夜霧渡口：小船剛離岸，船尾那個桃粉色的小小背影抱著膝沒有回頭，許硯煞在棧橋最後一塊木板邊上，眼睛從遠去的船落到腳下黑黑的水、又猛地抬起。第 23 集從同一刻接下去：他把燈籠往木板上一放，縱身跳下棧橋，落在船邊只到膝蓋的淺水裡，兩手抓住船舷：「船家，回頭！」唐小棠終於回頭：「你瘋了？水這麼冷！」老船夫嘆口氣把篙插進河底；許硯牙齒打顫還在笑：「冷。所以妳先拉我上去。」她一把抓住他的手腕把他拉上船。

船上，他擰著濕衣襬：「為什麼逃婚？這回說實話。」她垂眼看著膝上的金算盤：「我回魏家，你們就安全。」指尖把算珠一顆顆撥回零。許硯伸手按住她的手：「妳不是我贏來的，也不是誰的債。」系統：「唐小棠，好感加六。」她抹掉眼淚，說出真相：「宰相扣了唐家八條鹽船，」指尖推上八顆算珠，「逼我爹指婚。」「那林二丫……」「媒婆說她病死了，名額空著。」「我買的。」許硯愣住，忍不住笑：「所以妳是花錢嫁給我的？」她一巴掌拍在他手臂上：「要你管！」

晨霧散開，兩個人並肩坐在竹篷下，船夫默默把船頭掉回柳溪。唐小棠在船頭抬起哭紅的眼，晨光把睫毛照成金色，她把淚一抹，撥響了金算盤：「我賭我自己。」「賭什麼？」「三十天，比營收。許記贏，他撤告、退婚書。」許硯笑容收起：「輸了呢？」她不回答，把臉轉向前方發亮的水面。

白天，縣城客棧上房，三個商會老掌櫃站在屏風邊作證。唐小棠把賭約拍在魏少卿桌上，魏少卿笑：「賭？拿妳自己賭？」「三十天，許記營收贏你。」「輸了呢？」「我跟你回京。」許硯「小棠——」，她在桌邊按住他的手腕：「我算過了。」魏少卿起身：「好。請商會作證。」又湊近她：「三十天後，我來接新娘。」他的拇指沾了朱紅印泥按在紙上那一刻，系統：「強制任務。」「鬥商三十日，勝出。」「失敗：唐小棠好感歸零。」收在唐小棠對魏少卿笑出梨渦、什麼都不知道，許硯在她身後一動不動盯著她（第 24 集從鬥商第一天、對街魏記敲鑼「肥皂，五文一塊！」接）。

本集細綱：`docs/videos/series-plans/zhong-tian-qu-qi/season-01.json` 第 23 集（120 秒，第三章，調性甜寵＋權謀＋狗血）。開頭是許硯縱身跳下棧橋、落在淺水裡「船家，回頭！」（0:00–0:04）；中段鉤子是唐小棠低聲「我回魏家」「你們就安全」，許硯「妳不是我贏來的」「也不是誰的債」（0:21–0:31）；轉折是她說出真相（宰相扣了唐家八條鹽船逼她爹指婚，她向媒婆買了病死的林二丫的名額），然後擦乾眼淚自己定下賭局「我賭我自己」（0:34–1:00）；結尾收在魏少卿當著商會證人按下手印、系統紅框「強制任務」「鬥商三十日勝出」「失敗：唐小棠好感歸零」，三十天拿什麼贏宰相府不解答。細綱的 general_payoffs 全部入鏡：好感 +6（s14，「她不是誰的債」之後）、她親自定下的賭約（s24–s27 船上講條件、s30–s32 客棧拍板）、商會作證（s30、s37）。好感歸零的懲罰只有許硯看得到，唐小棠不知道，結尾的戲劇反諷就在這裡。

## 角色

- 許硯（xuyan）：主角。洗白的青布長衫，本集從 s02 起衣襬濕到膝下（只濕到膝蓋，男角）。開頭跳水（s01–s03）、凍得發抖還在耍嘴皮（s06）；船上兩句「妳不是我贏來的」「也不是誰的債」（s12–s13）是本集的情緒；s20「花錢嫁給我的？」是喜劇；結尾 s40–s41 只有他看得到系統面板。
- 唐小棠（tangxiaotang）：本集主角之一。桃粉襦裙、雙丸子髻、腰間小金算盤。夜裡哭（只寫臉上的淚，衣服不濕）、說出真相；本集顏值鏡頭 s23（船頭晨光把睫毛照成金色，把淚一抹、撥響算盤，細綱的 glamour_shot）；暗藏本事是 s24–s27 自己定下賭局、s32 當面跟宰相之子談條件、s34「我跟你回京」。金算盤是她的道具線：s10–s11 撥回零（帳目兩清）、s16 推上八顆（八條鹽船）、s23 撥響、s26–s27 一條條算條件、s29 握緊。
- 魏少卿（weishaoqing）：宰相之子，只在客棧（s30–s39）。灑金摺扇半開、抵唇、指向證人、搖開；不碰唐小棠，靠扇子與笑演壓迫；s39 只露寶藍織金袖口的手按手印。
- 系統（xitong）：沒有身體，只有聲音與剪接時疊上的面板（`overlays.json`：s14 好感 +6、s39–s41 強制任務紅框）。
