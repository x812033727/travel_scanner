# 社畜地獄 EP2〈年度簡報〉

## 故事前提

阿金拿雷射筆指著業績圖做年度簡報；喵總的瞳孔放到最大、屁股開始扭。下一格會議室全毀，喵總掛在天花板的燈上。阿金低頭——紅點正停在他自己的胸口。

## 角色

- 阿金（ajin）、喵總（miaozong）：同系列定裝照。

## 站主觀點

零台詞；貓的天性：雷射紅點。

## 格式

- 9:16，約 15 秒；Colab 首格與 H3 片段。

## 大綱

### 選項 A：年度簡報
一行說明：自信簡報 → 紅點 → 老闆瞳孔放大、屁股扭 → 阿金驚覺 → 會議室全毀、老闆掛在燈上 → 紅點在自己胸口 → 老闆盯上他。
開場鉤子：雷射紅點在業績圖上。
