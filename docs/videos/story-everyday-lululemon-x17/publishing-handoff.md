# X17 Lululemon｜正式製作與連結交接

本包是**v9 離線候選稿**：[v8 獨立 SEC 審核](reviews/script-source-audit-v8-independent.md)只通過舊 SHA 的事實；兩位真正首讀的[盲讀 A](reviews/blind-a-v8-independent.md)／[盲讀 B](reviews/blind-b-v8-independent.md)都將 Q8 判為否，A 另指出年度比較離題與 Short 2 撤貨範圍不明。[v9 作者修訂索引](reviews/v9-author-response.md)記錄改動。本版仍待新 SHA 的獨立 SEC 查核及兩位全新敘事盲讀，也沒有真實配音、插畫、聲畫、正式機匯入、影片 ID 或發布網址。成片必要事實只用 Lululemon 向 SEC 提交的原件 S1–S5、S6a；其中 S1、S3、S5、S6a 是短附件，S2、S4 必要段落在前 40,000 個解析文字內。其餘長 10-K 與 S7a 留作審稿補充。

**獨立審核交接。** 第二位審稿者應重抓 [`source-matrix.md`](source-matrix.md) 的六個成片 URL，記錄**當次 raw** byte 數與 SHA，並逐行查 [`line-source-matrix.md`](line-source-matrix.md) 與 [`shorts-source-matrix.md`](shorts-source-matrix.md)。矩陣的 10/20 raw 值不能冒充當次值；[v8 審核](reviews/script-source-audit-v8-independent.md)曾測得六份各多 9 bytes，只有尾部 SEC 安全 script URL 變動，還原該標籤後正文逐位元組相同。必查：S2 的一般布料檢驗及外部製造流程不能冒充涉事批次史實；更衣間顧客是明稱「想像」的示意，不是真人證詞，辨認在售批次是敘事推理而非公司實際調查方法。S1 的品質區隔為公司自述。S3 只說部分變數未充分測試，**沒有**完整列出舊清單逐項漏測什麼；產線評估仍在進行、夥伴教學是後續安排、公司當時財測未變。S4 的品牌聲譽說法須歸屬公司；網站指標只在研究索引，v9 主片沒有口播。`last seven weeks of the first quarter` 必須是**第一季最後七週**；S4 其他既有商品與新品只被公司用來解釋可比門市增長，不能變成黑褲單獨銷售數；Q1 毛利額多 US$13.5m、毛利率由 55.0% 降到 49.4%，不能混為同一指標。3 月的 `pull-back` 只限部分黑 Luon，兩支 Short 也必須獨立保持此範圍；4 月是布料**可能**達舊測試且多因素交疊；US$12–17m／US$57–67m 是三月**預測少賣**；US$17.5m 是 Q1 **已入帳存貨準備**；6 月 10 日的「90 天內回店」聲明晚於 5 月 5 日 Q1 截止。第六章只用 S6a 確認年度公告沒有黑褲單獨全年少賣實數，不口播全年公司營收、週數或毛利比較。新盲讀應在同一 SHA 評重述、章節銜接、開場問題與兩支 Short 是否各自成篇；舊票不能代替。

**媒體交接。** 待審核通過後，正式機先按 [`production-quote.md`](production-quote.md) 讀回**全項 US$25 上限**與餘額。用 `image-01`、精確 `look: {"preset":"cute-mystery"}` 生成並審核 98 張概念靜態圖，0 支生成影片 clip；用原生後製卡片排字，不生成商標或假文書。配音使用 `video.json` 的繁中逐句 `say` 暫擬發音，台灣口音 TTS 先試讀 Lululemon／Luon，人工審音再鎖。若需要改讀法，更新 `say`、`say_for` 並重編 hash；不要靠放慢語速補長。以 TTS timeline 量**實質正文 ≥8:00**，照音檔調整 16:9 剪點，短片各實測 25–55 秒，手機逐拍驗 `shorts-portrait-plan.md` 的直式裁切。Short 1 最後一拍目前重用主片的箱子／空架 shot，驗片時要確認畫面能承接「檢查做好成衣」的口播；若對不上，按同一 US$25 額度重畫，不可把箱子硬說成成衣檢驗。字幕需可關閉，與台灣繁中成音逐字對齊。

**官方動畫和 YouTube 連結。** 第一章 30–60 秒濃縮後接頻道既有 v4 **5 秒**動畫片頭；末三句後接既有 v4 **21 秒**動畫片尾。工作樹只有交接 cue，沒有聲稱持有官方資產或製作了代用品。先在正式機確認可用素材的身分、時長、聲量和位置，再合成。最後 16 秒在 YouTube Studio 設「最符合觀眾喜好」影片、訂閱、「最新上傳」影片；私人上傳後在播放器逐一點擊驗證，靜態 MP4 畫面不能代替真連結。`video.json` 的 `youtube.video_id` 目前為 `null`，兩支 Short 沒有預填 watch URL；實際上傳後才把主片、兩支 Short、播放清單的真實 ID／URL 回填至 YouTube 描述欄、置頂留言與彼此導流位置，並做點擊驗收。此包不含上架授權。

**離線重建與確認。** 在 repo 根目錄依序跑 `node docs/videos/story-everyday-lululemon-x17/compose-video.mjs`、`node docs/videos/story-everyday-lululemon-x17/compose-shorts.mjs`；其後主片 lint、Shorts 各自 schema／主片 shot hash 驗證、`npm run test:docs-videos`、`npm run check:tasks`、`git diff --check`。兩個 composer 只寫本包檔案，不連供應商或發布平台。重新編譯會改 hash，因此獨立審核必須針對交接時 README 的**實際檔案 SHA**；舊版審核不得沿用到改稿版。
