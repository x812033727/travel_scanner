# X17 v4｜作者對 v3 HOLD 的修訂索引

這是作者修訂記錄，**不是**獨立 SEC 審核或敘事盲評。v3 的三份獨立票只綁 v3 JSON；v4 必須依 [README](../README.md) 的新 SHA 重抓原件、重讀兩支 Short，並由兩位未看作者意圖的新讀者評故事。

| v3 退件點 | v4 定點修訂 |
| --- | --- |
| [SEC 時間口徑 HOLD](script-source-audit-v3-independent.md)：`last seven weeks of the first quarter` 被寫成「第一季後七週」。 | 主片 `x170501`、其原生資訊卡和 Short 2 `x17s204` 都改為「第一季最後七週」；Short 2 headline、描述、逐句稿、兩份來源矩陣與 brief／Treatment／畫面規劃同步。這指 FY2013 Q1 最後七週，不是 Q1 結束後七週。 |
| [盲讀 A](blind-a-v3-independent.md) Q2：開頭先說倉庫／運途也受影響，搶了第三章的揭曉。 | `x170105` 只說六月公司公布回店進度並問空架等多久；倉庫／運途首次在 `x170314` 回答 `x170308`。開頭仍有四月檢驗、六月回店、六月季度帳三件未解時刻。 |
| A/B 共同 Q8：2006 舊規格與倉庫範圍被重講。 | `x170402` 明確用「還記得」回扣 `x170214`，新增公司說規格與程序後來未大改；`x170507` 明確回扣 `x170314`，新增倉庫／途中的受影響貨也被調低到市價的會計後果。兩次回扣都帶新發現。 |
| [盲讀 B](blind-b-v3-independent.md) Q7：`x170211` 問事故前誰檢查成衣，原件沒有答案。 | `x170211` 改問布料哪些變化沒量到；`x170408` 以 S3 公司調查發現的布料特性測試缺漏回答，不再推斷成衣售前檢驗是否存在。 |
| B Q13：FY2012 店數／收入把事件拖遠；第六章反覆說全年總額不能拆單品。 | 移除原 `x170218–219` 的 211 店和 US$1.37bn 岔題；第二章只用 `x170220` 一句關閉前一財年。第六章刪除原 `x170606–608`、`x170612–613` 的重複解釋，只保留一個全年收入結論、一個全年毛利界線與 53／52 週比較提醒。 |
| B 指出「伸展模數／公差／容許範圍低端」難聽懂，Short 必須單獨成立。 | 主片 `x170403` 說公司標準的低端；`x170416–417` 改成布被拉開時受力與伸長的關係、重量和允許偏差。Short 1 `x17s104/107` 用同一日常語意；Short 2 把季度時間放進聲音與手機 headline。平布與褲腿仍只是有條件的物理示意，非涉事批次的實測復原。 |

本輪還把 S3 的跨部門工作線、當時未變的財務預測，和 S4 網站轉換率／客單價、其他毛利因素編入原有主線。新增說法都已在 [作者來源矩陣](../line-source-matrix.md) 標記，待獨立查核；沒有使用未能證明的單一纖維原因或 FY2014 延伸故事。作者本機重編與檢查結果見 README，成音時間、手機畫面及官方書擋仍需正式媒體驗收。
