# X17 v5｜作者對 v4 SEC HOLD 的修訂索引

這是作者修訂紀錄，**不是**獨立 SEC 審核或敘事盲評。[v4 獨立來源審核](script-source-audit-v4-independent.md)確認六份必要原件的 byte／SHA，但對主片 `x170519` 發出 HOLD：S4 記載網站流量增加、轉換率及平均訂單金額下降；舊句「結帳卻變少」多推了一個無法由原件判定的絕對訂單數。

v5 在逐句母稿與重編的 `video.json`、`script.md`、`line-source-matrix.md`，將同一句改為「網站來的人更多，**完成結帳的比例卻下降**、單次花費也下降；毛利帳又如何？」。來源矩陣與上架交接增列轉換率／絕對筆數界線。Shorts 旁白與鏡頭未改，仍重跑 composer 與 schema 驗證；兩支 Short 必須隨新主片 SHA 一起交獨立審核。

v4 的 HOLD 及更早敘事票只綁各自原 SHA。v5 待新 SHA 的 SEC 逐句複核與兩位全新敘事盲讀，並待真實 TTS、影像、官方書擋及平台連結驗收；本修訂不宣稱任何獨立 PASS 或付費製作。
