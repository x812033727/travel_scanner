# C05 金鳥蚊香｜逐句旁白草稿

狀態：本稿依 [Treatment](treatment.md) 新版來源界線進行第二輪非付費修訂；**新版 Treatment／來源矩陣的 SHA 尚待站主窄幅重綁，本稿也尚待重新獨立逐句查核、兩位盲讀、時長實測與站主劇本核准**。前兩輪盲讀的 REVISE 與舊版查核只綁舊雜湊，不能當本稿 PASS。本表的 ID、依據與章名不念出來。目標約十分鐘，純旁白時長須以核准稿實測，來源不足便縮短，不用停頓或重述灌長。冷開場之後接頻道五秒片頭；二十一秒 v4 片尾沒有下一集預告。

依據欄的 `F01`–`F20` 指向新版[來源矩陣](source-matrix.md)；植物原料的補充說明直接連到[金鳥工廠頁](https://www.kincho.co.jp/factory/listen/detail.html)。`推論` 只表示從列出的物件／步驟得出的平面幾何或敘事問題，不能被當成當年某人的引述。獨立查核者必須逐句判定；公司的事後回顧、館藏描述及現行規格各留在自己的時代。所有日期與性能數字截至 2026-10-22 查詢。

## 6｜慢燃的答案，在香體裡（now）

| ID | 旁白 | 依據 |
| --- | --- | --- |
| N01 | 金鳥工廠說，香條斷面的空隙少，氧氣不易進入，這才使它慢慢燃燒。 | F18；緊接 T12 回答，只是公司技術解釋 |
| N02 | 螺旋延長的是火要走的路；香體的空隙與氧氣，則影響這段路燒得多快。 | F18、推論 F03；路徑與速率分開 |
| N03 | 現行一般尺寸一卷約七十五公分，金鳥標示約可燃七小時。 | F11；現行規格，不倒推早期 |
| N04 | 另外有約三、十二小時的尺寸；使用環境也會改變實際時數。 | F11；不同尺寸與現行 Q&A |
| N05 | 金鳥說，今天其蚊香的有效成分屬合成擬除蟲菊酯；這與早期採用除蟲菊的時代不同。 | F12、F20；只比較有效成分來源，不說植物粉全部被替換 |
| N06 | 工廠把這種成分與植物粉、木粉和黏結材料混合，揉成可加工的原料。 | F12；現行所述製法，非 1902 配方 |
| N07 | 原料先擠成片，再打出螺旋並乾燥；手盤換成打型，外形依然保留。 | F12、F09；跨時期工法對照 |
| N08 | 可那抹熟悉的綠色不是混料原色；金鳥說，原料混合後其實偏棕。 | F17；只述公司所述產品 |
| N09 | 於是工廠用染料染綠，一來容易上色均勻，二來給夏天使用的人清涼印象。 | F17；公司設計理由，無降溫效果 |
| N10 | 金鳥還說，綠色讓人想到早年蚊遣所燃草葉的葉色；這是顏色聯想，不是煙的顏色。 | F17、F19；公司後年回顧，不倒推上色年份 |
| N11 | 早年靠草木冒煙，今天從一片材料打出螺旋，兩幅畫面之間隔著多次製程轉換。 | F19、F12、F09；年代對照，不稱配方延續 |
| N12 | 回頭看那塊一八九五年木模，它沒有量產；後來的手卷、打型卻把螺旋留在貨架上。 | F04、F09、F12；不推 1902 完整量產工序 |
| N13 | 開場的答案有三段：螺旋裝下更長路徑，香體空隙少讓氧氣難進、燃得慢，雙卷則按金鳥說法減少運送折損。 | 推論 F03、F18、F08；三機制明確分開 |
| N14 | 四十分鐘就燒盡的直條，最後留下的不是一個單純的圓，而是一串材料、製造與送達的選擇。 | F02、F04、F08、F09、F12；回收開場的敘事歸納 |
| N15 | 你拆雙卷時，有沒有差點從外緣把它折斷？ | F11；留言問題，現行用法 |
| N16 | 下次從中心分開它時，可以想起那塊沒進產線的木模；喜歡這些日用品轉身故事，歡迎訂閱。 | F04、F11；回收物件與結尾邀請 |
