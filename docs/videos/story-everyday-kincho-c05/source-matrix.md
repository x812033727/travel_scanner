# C05 金鳥蚊香｜一手來源矩陣與敘述界線

核對日期：2026-10-22。這份矩陣只支持非付費 Treatment，**不等於逐句旁白查核**。主要使用金鳥自身的年表、保存物件介紹與現行產品 Q&A，再以國立科學博物館的館藏登錄和國立公文書館的歷史檔案介紹辨識物件與歸屬差異。公司多年後的回顧不能被寫成當年的直接觀測或獨立性能實驗。

## 來源可用性與仍缺的證據

- 金鳥年表、技術遺產頁、現行 Q&A、工廠說明、國立公文書館介紹，以及本輪的博物館木模頁均可讀 HTML；逐字稿前仍須依實際工人抓取結果重測。**F07 的「六小時」目前只有 PDF 支持**，不得宣稱所有精確數字都有可讀 HTML；正式匯入時依 reviewer_only 規則處理或移除該數字。
- 2017 年化學遺產文章雖刊於日本化學會刊物，作者是金鳥社長；它**不是獨立的性能測試**。Good Design 得獎頁的歷史欄主要也是企業自報。日本政策金融公庫的[2018 年社史研究](https://www.jfc.go.jp/n/findings/pdf/tyousa_gttupou_1807.pdf)可交叉讀，但其歷史細節仍回引公司社史，不能算第二份同時期原件。
- 未找到 1900 年螺旋蚊香原始專利、1895–1902 年逐年試作帳、早期直條與螺旋同配方實驗、實際運輸破損率或成本降幅。旁白只能就上述證據講可確認的製程問題；若六章內容不足八分鐘，應縮短或換題。
