## 寫稿時決定的事與理由

1. **故事線用 A 案（一座橋，斷了三次），照覆核的修正。** 這是一集反著來的題目：名場面本身就在正史裡。開場在建安十三年秋天的當陽長坂：五千精騎一日一夜三百多里、
   十幾萬人一天十幾里、丟下妻兒、張飛和二十騎停在河邊、喊了一句話；接四個停在結果之前的預告，照揭曉順序（河上那座橋是開口之前還是之後斷的 → 元朝說書人讓他只喊一聲，橋怎麼了
   → 明朝小說裡曹操身邊一位將領出了事 → 劉備說他做錯了一件事）；最後一句是標題的問題。開場不講陳壽、65 字、語序、平話的結果、將領的名字、錯在哪裡。
2. **一條線：照查出來的順序。** 陳壽 65 字（二十騎做什麼沒寫、據水斷橋瞋目橫矛、身是張益德也、敵皆無敢近者、漢津夏口）→ 語序：斷橋在前 → 誰斷的沒寫 → 李暠「據斷橋而橫矛」順序一樣
   → 「敵」是誰：華陽「公徒」、通鑑「操兵」，曹操本人與退多遠都沒寫 → 元朝平話（河與大橋、二十人、五十面旗、三十萬、只見曹操、燕人張翼德、橋梁皆斷、三十多里、查得到最早、廟贊）
   → 明朝嘉靖本（則目據水斷橋、木橋小字、鞭打、樹枝、三聲、夏侯霸、傘蓋與帽子、百萬兵、拆橋、失於計較、三座橋、夏侯霸後面還在）→ 清朝毛本（夏侯傑只一次、我乃燕人張翼德也、
   翼德定名、回目不見據水斷橋、刪小字、留帽子與詩、浮橋）→ 辭典兩義 → 結檔一次。
   三條小線都掛在這條主線上，一次只多一步：橋的斷法（陳壽語序 → 被喊斷 → 喊完才拆 → 浮橋）、追兵的數字（五千 → 三十萬 → 百萬）、喊話裡的名字（益德 → 翼德 → 益德 → 翼德）。
3. **S21 的寫法與 S06、S02 的盲評教訓：**
   - chapters_link：每章停在問句，下一章第一句直接答、帶一個具體事實：「張飛這一聲吼，史書真的有寫嗎？」→「有。開頭那個建安十三年的秋天，陳壽寫進了《三國志》張飛的傳記。」；
     「陳壽留下的這些空白，後來是誰填上的？」→「是說書人。元朝至治年間刊的《三國志平話》……」；「到了明朝的小說裡，還喊得斷橋嗎？」→「喊不斷了。明朝嘉靖年間的刊本裡，張飛橫著矛，站在橋上」；
     「那今天通行的本子裡，他還叫夏侯霸嗎？」→「不叫了。到了清朝的毛本，那位將領，變成了夏侯傑。」章末不先講答案。
   - payoffs：只問表裡答得出的問題（史書有寫嗎、開口之前還是之後、追兵敢上前嗎、敵是誰、空白誰填、騎兵在這裡做什麼、那座橋呢、還喊得斷嗎、將領怎麼了、張飛做了什麼、劉備怎麼說、
     還叫夏侯霸嗎、多了哪一個字），每一個都有明說的答案。「敵是誰」陳壽沒寫，但華陽、通鑑給了答案。不問「橋是誰斷的」「為什麼改名夏侯傑」「誰最早改成翼德」（答案只有「沒寫」或「沒找到」）。
   - one_line：主角是那座橋和那一聲；每一章換一本更晚的書，問的都是「這座橋怎麼斷、那一聲怎麼喊」。
   - no_detour：拿掉趙雲救阿斗、劉備擲手戟、曹純俘獲兩個女兒、文聘、魯肅、諸葛亮的強弩之末、萬人敵、劉備「以人為本」、裴松之沒加注、周訪甘卓的斷橋用例、水經注、郝經、
     長坂在哪裡（只上卡片「當陽一帶」）、嘉靖本的詩賦、平話裡孫夫人的回憶；沒有「誰也這樣寫」的名單（華陽、通鑑各只講它改了哪一個字）。
   - no_recap：結論只在 cb517 講一次，而且只一句（存檔一半、還沒結案一半），前一句 cb515–cb516 用「還記得陳壽那個斷字嗎？」點名，補整集沒講過的辭典兩義；
     開場的五千在第 3 章用「還記得開頭那五千精騎嗎」點名、補三十萬；三十萬在第 4 章用「剛剛的三十萬」補百萬；陳壽的語序在第 3 章用「剛剛陳壽的句子」補「併成一件」，第 4 章只說「順序整個倒了過來」；
     開場的二十騎在第 2 章用「開頭那二十個騎兵」補「做什麼沒寫」；嘉靖本的則目、木橋小字、三座橋在第 5 章各自點名、各補一個新的變化。
   - no_spoiler：四個預告都停在結果之前（先後？那座橋怎麼了？出了事、做錯了一件事）；章名不放答案（第 3 章只說「讓張飛喊了一聲」，第 4 章「連吼了三聲」，第 5 章「又改了一次」）。
   - 章名的時間都在該章旁白裡：建安十三年（cb101；cb201 點名回呼）、元朝至治年間（cb301）、明朝嘉靖年間（cb401）、清朝（cb501）。
   - 不念目錄：沒有「接下來」「最後」「先來看」。
4. **「斷」不下定論**：只講句子的順序（「陳壽的句子裡，斷橋，排在開口之前」「至於是誰斷的、怎麼斷的、斷成什麼樣，他一個字也沒寫」）；「斷橋」不翻成白話；
   李暠只說「也只寫了一句……跟陳壽的順序，一模一樣」，不當反方；胡三省、反切、第 49、51 列一律不用；周訪、甘卓的用例會變成替一種讀法舉證，不用。片尾用辭典的兩義收在「還沒結案」。
5. **曹操在橋前**：正史只說「敵」不敢近，華陽「公徒」、通鑑「操兵」；曹操本人在橋前只出現在平話（「只見曹操」）與嘉靖本、毛本，旁白都標在那本書裡講。
   「退了三十多里」只在平話那一章。
6. **夏侯霸／夏侯傑**：只說「嚇得肝膽碎裂，從馬上栽了下來」（卡片放原文「倒撞於馬下」），旁白不出現任何人死；嘉靖本後面夏侯霸還去五丈原探路，只當同一部書的事實講，
   不推論改名的原因；說「到了清朝的毛本，那位將領，變成了夏侯傑」，毛宗崗的名字整支不提。
7. **嘉靖本與毛本的分工**照第 37、50 列：傘蓋、帽子與簪子、「一聲好似轟雷吼，獨退曹公百萬兵」放在嘉靖本那一章；第 5 章只說毛本「倒是留著，只改了幾個字」，
   「浮」是毛本新加的那一個字。嘉靖本只說「明朝嘉靖年間的刊本」，不說 1522。
8. **翼德**：只說平話已經全作翼德（12 對 0）、嘉靖本寫回益德、毛本「把翼德定成了今天通行的名字」（第 29、31、38、39 列）；不提酈道元、北宋、張佳胤（第 48 列留給故事線 B）。
9. **念法（`SAY`）**：長坂／長阪 → 長板（bǎn）、李暠 → 李浩（hào）、瞋目 → 嗔目（chēn）、燕人 → 煙人（yān）；字幕仍是原字。冠（guān）不念，旁白說「帽子」；
