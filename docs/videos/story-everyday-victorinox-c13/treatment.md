# C13 Victorinox｜瑞士刀遇上飛安限制，為何手錶早已在貨架上？

狀態：六章 Treatment 修訂稿；前版獨立查核對 M05 判 HOLD，**本版尚待差異覆核與站主企劃採用**。這是「日用品的意外轉身」第 C13 題，原選題卡的「遇上飛安限制後，賣什麼」須改成更準確的問題：刀具通路急縮時，早已開始的其他商品線和當時的應急決策各做了什麼？來源、分母及不能推出的因果見[來源矩陣](source-matrix.md)。本稿不授權逐字稿、付費生成、匯入或發布。

## 企劃卡

- **主角**：瑞士折疊多功能刀，以及在 2001 年前就已出現在品牌商品架上的手錶和旅行用品。
- **核心問題**：2001 年後機場不再是熟悉的售刀場所，Victorinox 如何應對刀具需求急縮？為什麼把「9/11 之後才開始賣手錶、行李箱」當成答案，會把真正的決策順序說反？
- **一句答案**：2001 年後部分機場售刀與旅客手提刀具受限，Victorinox 嘗試調整刀具、提醒託運；CEO 多年後說暫借員工，並認為既有手錶、專業刀及廚刀支柱幫了忙。公司年表顯示手錶 1989 年進北美、旅行用品 1999 年已透過授權入市。當期兩篇報導對「近三成」跌幅的期間有衝突，片中不把它當單一確定的季度數字；美國經銷公司 SABI 的品類數字也不能當作瑞士 Victorinox AG 全球報表。[S1][S3][S4][S5][S6][S7][S10]
- **反常轉折**：危機後不是「一夜改賣行李箱」；鐘錶與旅行用品先於危機，多功能刀本身也嘗試找新使用情境，而員工的工作安排成了短期緩衝。多條路分屬不同時間與法人，不能剪成單一神奇妙招。
- **觀眾**：看過瑞士刀、也可能在機場或百貨看過同牌手錶、旅行用品的台灣觀眾。用一把關起來的刀、一只錶、機場貨架和員工班表說清楚，不討論刀具使用技巧或現行跨國攜帶規則。
- **熱門潛力**：編輯判斷中高。熟悉物件碰上機場限制，有清楚的畫面對照；真正的看點是 2001 年前後的時間反轉與經銷公司原始報表。這是編輯判斷，不是點閱預測。若正式來源只夠較短影片，不重複機場安檢畫面湊八分鐘。

**冷開場 0:00–0:45（方向稿，不是已查核逐字稿）**：機場貨架上，一把闔起的多功能刀曾是旅客能順手帶走的紀念品。2001 年後，部分機場停止售刀，手提刀具也受限。直覺會說：公司趕快去賣手錶和旅行箱。但翻開年表，手錶在 1989 年、旅行用品在 1999 年就已上架。那麼危機來時，公司正在做什麼？[S1][S5][S10]
