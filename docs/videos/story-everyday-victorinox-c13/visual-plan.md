## 圖文與聲音規則

- 每個 `illustration` prompt 只描述抽象概念場景的物件、動作與光線；可愛謎題畫風只由 `look.preset` 指定，不重複寫進 prompt。不得輸出商標、十字盾牌、可讀文字、品牌商品外形複製、專利圖、真人肖像、真實機場或 9/11 重建。年份、公司名、數字及來源歸屬只由後製文字卡承載。角色如出現，為一名匿名通用人物做一個清楚動作。
- 沿用 `look: {"preset":"cute-mystery"}`。如後續**另外獲付費授權**才使用 MiniMax `image-01`；目前沒有呼叫生成、配音、匯入或上傳。插畫須逐張人工檢查是否真的描繪該句物件和問題，不能拿抽象紙張重複充數。
- 繁中單人說書，配樂規劃為輕巧好奇、無人聲、低於旁白；可關閉的 CC 由字幕流程處理，圖上不燒字幕。剪輯以物件連續性銜接：闔刀 → 工作台 → 商品架 → 帳本 → 產品進度 → 員工班表 → 回到商品架。T07–T08 連續兩張卡後立刻恢復插畫。
- 縮圖草案：左上後製橘色大字 **VICTORINOX**；左邊抽象貨架與泛用闔刀，右邊泛用手錶和旅行箱，中間後製「2001 前／後」。不讓生成模型畫字或品牌標誌；縮圖不是史料圖。
