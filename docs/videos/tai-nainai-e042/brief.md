# 《恁祖媽今年18》第 42 集〈用印前夜〉

## 故事前提

第 32 天早上八點，老宅大門口。建邦走到門口低聲說：安養院昨晚來電，玉琴這幾天都不肯吃飯，一直哼一首歌，要人唱給她聽才肯吃；
就是那段影片裡，月棠在祠堂唱的那首，只有她會唱。月棠答應跟他去。林美鳳不服，建邦第一次頂回去：她回來照顧媽，住保母房，院方破例，中午他就帶她去。福伯接過她的藍布包。
下午三點，兩人從安養院回來，玉琴聽著歌把一碗粥吃完了。江慕白在大廳等著：盛通把沈氏集團欠銀行的債整批買下了；周懷安的電話緊跟著打來，
用印提前到這週日。建邦的手開始抖。林美鳳請江慕白去飯廳喝茶，江慕白把皮夾留在長桌上，先到院子回電話；林美鳳叫月棠「收拾」。
月棠的手停在皮夾上，打開：附件三就在裡面，一行字被黑色麥克筆塗掉。院子裡的腳步聲回來了，她舉起手機拍，「咔」一聲快門響，江慕白在院子門口回頭。

- **上一集**：第 41 集最後一鏡 c26（第 32 天 08:00，大門）：林美鳳（`home`）拉著一扇門；月棠（`faint-line`）在門外石階上，兩手抱藍布包；
  建邦（基本款）站在林美鳳身後的穿堂中間，剛說完「我請的」（接點 41→42）。本集 c01 同一刻：建邦走到門口，低聲說安養院來電。
  第 41 集的懸念「建邦為什麼請她回來？」答在本集 c01–c04。（已對過第 41 集 c26）
- **下一集**：本集最後一鏡 c23（第 32 天 15:00，大廳）：月棠（`faint-line`）站在長桌東側，江慕白的深棕皮夾攤開在她面前，她右手把黑色手機舉在皮夾上方；
  江慕白在畫面右後方的院子門口剛轉頭；下午光（接點 42→43）。第 43 集第一鏡同一刻：她舉著手機一臉為難。
- **燈**：6，本集不拍祠堂。月棠全集 `faint-line`。
- **藍布包**：c08 福伯接過，送進保母房（她第 32 天起住保母房）。
- **江慕白的皮夾**：夾在左臂進來 → c17 放在長桌上 → c23 攤開（第 43 集他拿走）。附件三是皮夾裡的一張 A4，一行被黑色麥克筆塗掉。
- **用印**：細綱「後天」照 bible 寫成「這週日」＝第 35 天（12/20）。
