## 正式機接入順序

1. X06 是編輯序列第六集，排在 X05 後；X06 前製 PR 可以先以草稿送審，正式成片及上架仍按站主系列順序決定。接入時先唯讀核對本 slug、系列排程與正式工人的現有稿件；不得讓本地分鏡覆寫較新的已審章稿。
2. 比對 `video.json`、`script.md`、`source-matrix.md` 與正式工人 `story/chapters/*` 的**精確版本與 hash**。若工人合成或改寫任何口播，重新跑逐句來源查核、兩份獨立敘事盲讀、lint，並以新 hash 保存審查結果；本地 PASS 不自動跨稿生效。
3. 以 [production-quote.md](production-quote.md) 的 US$25 全項硬上限與正式總帳讀回決定是否可逐鏡生成。後製完成後查看完整影片，逐段驗證插畫比例、年份、2025／2026 轉折、旁白與字幕。只有實測成片才能標為「完成」。
4. YouTube 上傳後填回真實 `video_id` 與公開網址；設定片尾三元素並實點。說明連結需能打開、期間與百分比仍正確，縮圖不把美洲家清說成已售。保存 Studio 驗證與站主看片結果。

本文沒有正式片頭／片尾素材的路徑、YouTube Studio 權限或已發布影片 ID；這些需要正式工人工作區及上傳後的實際讀回，不能由占位值推定完成。
