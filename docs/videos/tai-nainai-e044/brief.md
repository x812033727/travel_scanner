# 《恁祖媽今年18》第 44 集〈商標〉

## 故事前提

第 33 天早上九點，月棠端茶進書房，像隨口一問：沈記的招牌，也一起賣了？建邦頭也沒抬：沒有，合約賣的是房子。她把手機放在他面前。
建邦看見附件三：老宅過戶那天，沈記的商標一起過戶；再往下，介紹人沈建業領雙倍尾款、限十二月內完成。他終於懂了二房為什麼急著這個月賣。
月棠說：招牌一過戶，沈記就不姓沈了。建邦打給江慕白要撤約，江慕白慢慢說：違約金，三億。茶杯晃出水來。他再打給建業，建業只答：哥，你簽了。
近午，建業與江慕白回到大廳，建邦第一次對弟弟吼出來；建業說債在人家手上，不賣大家一起死；林美鳳說後天就用印、周董事長馬上到。門環響了兩下，
建業說盛通的周董事長到了。門外的周懷安等著開門時，抬頭看了沈記舊門面上那兩個空鐵鉤好一會兒，端著茶在門房小窗後的月棠看見了。周懷安穿過暖黃木頭的光走進大廳，所有人退開半步，只有端著茶盤的月棠沒動。他的目光停在她身上：「妳不像保母。」
