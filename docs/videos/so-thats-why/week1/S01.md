# S01 為什麼飛機航線在地圖上是彎的？

## 修正

- 標題、鉤子不改。
- 答案補一句：地圖上看到的彎線有兩層——第一層是大圓（理論最短），第二層是實際航線會再依噴射氣流、轉降機場規則與空域每天調整，所以實飛比大圓長。原答案「再加上風向與空域的考量」保留，但片中不能暗示台北—紐約會飛過北極：理論大圓接近北緯 79 度，實際航班走日本、北太平洋、加拿大。
- 距離數字全部用「約」，15,400 公里標明是本所估算。

## 後台發起用

故事前提：

```text
為什麼飛機航線在地圖上是彎的？
從台北飛紐約，地圖上航線往北彎。要講清楚：地球是圓的，兩點最短路線是大圓（台北—紐約約 12,500 公里）；常見的麥卡托地圖把「方向不變」的線畫成直線，照直線飛反而多將近三千公里；實際航班還會依噴射氣流、雙發動機客機的轉降規則與空域每天調整，所以不完全照大圓飛。用地球儀和一條繩子示範。
```

https://pubs.usgs.gov/pp/1395/report.pdf

## 大綱建議

- 開場鉤子：「在地圖上，紐約在台北的東邊、只稍微偏北。可是從台北飛紐約，航線卻一路往北彎，經過日本、北太平洋，再從加拿大進美國。」
- 原因 1：地球是球，兩點間最短的線是「大圓」，台北到紐約約 12,500 公里（flightpaths.com 的大圓距離 7,795 英里）。
- 原因 2：常見的麥卡托地圖把「方向不變」的線畫成直線，照這條直線飛，本所估算要約 15,400 公里（USGS《Map Projections》）。
- 原因 3：天上有由西往東吹的噴射氣流，航空公司每天挑順風、避逆風的路線（NOAA）。
- 原因 4：雙發動機客機越洋，航線上每一點都要能在規定時間內轉降機場，所以航線會貼著陸地與機場走（FAA AC 120-42B）。
- 一句話答案：地圖是平的、地球是圓的，最短的路在平面上看起來就是彎的；再加上風和安全規則，飛機每天走的是「又短又安全」的那條彎線。
- 片尾預告：「下一集：日本沒被英國殖民過，為什麼開車靠左？」

## Shorts

### Short 1：濃縮版

- 標題 A：台北飛紐約，航線為什麼往北彎？
- 標題 B：地圖上的直線，其實是繞遠路
- 說明：最短的路，在平面地圖上反而是彎的。完整版在長片。

1. `台北飛紐約，為什麼往北彎？`
   - 「地圖上，紐約在台北東邊稍微偏北，」
   - 「可是航線卻一路往北彎。」
2. `地球是圓的`
   - 「在地球儀上拉一條繩子，」
   - 「最短的線叫大圓，約一萬兩千五百公里。」
3. `地圖上的直線更遠`
   - 「平面地圖上的直線，照著飛反而更遠，」
   - 「估算要多將近三千公里。」
   - 「所以最短的路，在地圖上看起來是彎的。」
4. `再加上風`
   - 「航空公司還會看噴射氣流每天調整。」
   - 「完整故事在長片。」

### Short 2：一個驚人事實

- 標題 A：平面地圖騙了你：直線不是最短的路
- 標題 B：為什麼在地圖上畫直線去紐約，會多飛三千公里？
- 說明：同樣從台北到紐約，一條看起來直、一條看起來彎，彎的比較短。完整版在長片。

1. `直的比較長，彎的比較短`
   - 「從台北到紐約畫兩條線，」
   - 「一條在地圖上是直的，一條是彎的。」
2. `答案是彎的那條`
   - 「彎的那條是大圓，約一萬兩千五百公里；」
   - 「直的那條，估算要約一萬五千四百公里。」
3. `地圖把地球攤平了`
   - 「因為平面地圖把圓的地球攤平，」
   - 「最短的路就被畫彎了。」
4. `飛機實際怎麼飛？`
   - 「真正的航班還會看風向與安全規則調整，」
   - 「飛機實際怎麼飛？看長片。」

## 不做的事

- 不把台北—紐約畫成飛越北極；理論大圓接近北緯 79 度，實際航班沒有這樣飛。
- 不點名航班繞開哪一國的空域，沒有公開的逐日依據。
- 不畫航空公司塗裝、機尾標誌；飛機用無標誌的泛稱客機剪影。
- 不說「地圖是錯的」；麥卡托是為了方向不變的航海而設計，片中說它「量的東西不一樣」。
