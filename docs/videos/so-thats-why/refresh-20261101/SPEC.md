# 原來如此事務所：把一個日常疑問講成一段發現

修訂日：2026-11-01。名稱仍是「原來如此事務所」；《十萬個為什麼》指廣泛生活科普的提問方向，沒有指定版本或頻道，不抄書中問答、節目台詞或造型。

## 定位與選題

觀眾在生活中遇見一件事，直覺解釋有一個缺口；跟著具體物件或現象找出機制，最後能用同一原理解釋另一個情境。從「一個為什麼」進場，帶走一個能遷移的理解。

- 核心：生活物理、食物與材料、自然與動物、看不見的日用科技、交通與城市設計。
- 商業題保留價格、支付、供應與制度的具體機制；公司興衰與創辦人傳記轉品牌故事候選，不重複拍。
- AI 名詞、工具版本與操作教學回既有 AI 系列；本系列保留不依單一產品版本的日用科技。
- 文化不寫成整個民族只有一種個性；旅遊規定不當恆久真理。需要更新政策才能成立的題目退出首批。
- 只夠講一個冷知識的題目改短片或併入母題。尚無答案的題目若沒有足夠證據比較，暫緩，不能用一個假說填滿全片。

每題選入長片前須同時成立：生活關聯清楚、一句能說出的反差、有至少三個相接的因果步驟、畫得出來、找得到機制的可靠來源、和同系列及其他系列不重複。這是編輯判斷，沒有以點閱率或訂閱數作保證。

## 一集的因果節奏

| 段落 | 約略預算 | 要讓觀眾追的問題 |
| --- | --- | --- |
| 開場 | 45 秒 | 我每天看到的東西，哪裡跟直覺不一樣？ |
| 第一個觀察 | 110 秒 | 直覺答案為何解釋不了眼前現象？ |
| 第一層機制 | 140 秒 | 物件裡實際發生什麼？ |
| 機制繼續推進 | 150 秒 | 這一步如何導致下一步？ |
| 反例／適用邊界 | 150 秒 | 換一個條件，結果還成立嗎？ |
| 回到生活 | 150 秒 | 同一原理能解釋什麼熟悉現象？ |
| 回答與收尾 | 35 秒 | 回收片頭疑問，留一個可以討論的觀察。 |

合計 780 秒是正文規劃預算，片頭片尾會使實際成片略長；以旁白時間軸與播放器重算。不得將這張表或題庫 brief 當成已完成的 13 分鐘腳本。

## 查核與驗收

1. 題庫列「採用」只代表選題通過。新題的來源支持核心機制，不代表所有數字、例子與延伸段落已查核；舊題來源日期也不自動刷新。
2. 先做 treatment：一條因果線、三個轉折、11 個 loops、兩個可靠來源方向、每章畫面、需要重新查證的主張。來源不足便退回選題。
3. 寫完整稿、claims 與分鏡，由另一個查核者逐主張查核；不能把標題疑問偷換成確定結論。第三季與新增題仍需完整製作包。
4. 盲讀檢查：不看圖是否能跟上、每章接得上、答案有說清楚、比喻沒有取代機制、未解處說清楚、結尾回收。讀者不過就改稿，再跑 lint。
5. 舊工人的 90 秒鉤子與三四個開場預告不可當本版已通過。新版須逐段人工／獨立盲讀確認，待共用產線同步後才把自動 lint 當這份規格的檢查器。
6. 預算、旁白審聽、插圖、成片 QA、語言、上傳與發布仍依既有流程。原 T26／T27／B26 的影片、審核與付費紀錄不改；若重製，用新 slug 並重新綁定核准。

## 開場示範：S42 雲

「你看天上的雲，可能覺得它輕得像棉花。可是那一大片白色，裡面真的有水。水明明比空氣重，為什麼沒有整團掉下來？先把鏡頭拉近：你看到的不是一整塊水，而是很多很小的水滴。問題是，水滴再小，難道就不會往下掉？今天就從一片雲裡的水滴開始，看它怎麼留在天空，也看它什麼時候變成雨。」

這是口吻與主線示例，不是通過查核的可錄音稿；不在未選定雲的大小與含水量前喊「幾百噸」。後續必須分清終端速度、上升氣流、凝結與降水過程，不說小水滴沒有重量。
