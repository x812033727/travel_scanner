## 題庫怎麼用

```powershell
node tools/video/so-thats-why/cli.mjs check
node tools/video/so-thats-why/cli.mjs list
node tools/video/so-thats-why/cli.mjs show A08
node tools/video/so-thats-why/cli.mjs brief S76
```

`show` 能看全部 313 列的理由；`list` 只列 100 個有效長片題；`brief` 拒絕剔除、暫緩、短片、併題及轉系列的題目。輸出有新版限制與原來源，明標 `EDITORIAL_BRIEF_NOT_IMPORT_READY`，不能拿去當審核或付費開拍授權。`merged_topics` 帶母題可選對照的原資料與查核限制，不能把它當必須塞進稿子的章節。主題被選中不代表舊影片沒做過。

原三季 JSON、完整包與舊核准保持原檔。清單綁三份來源檔及選題資料 SHA-256；來源變了會拒絕繼續選題，重新審閱才執行 `build`。這個保護只作用於新版本機入口，沒有聲稱已替所有舊 CLI 或後台加上過濾。
