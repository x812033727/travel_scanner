## 合併審查結果（2026-11-11，站主核准後）

站主：「合併是真的能合併才合併，不要硬補而亂加」。**P16 潮汐＋P24 海嘯不合併，兩集都改成後備**：建議的核心問題『長波怎麼被水深與海岸塑形』，在潮汐這半邊沒有任何現有素材回答：S82 只有兩個 NOAA 頁面，講的是引力差異與三種潮型因地而異，『潮汐也是受海盆控制的長波』那章 NOAA 教學還沒逐主張讀，港口潮位紀錄也沒有。少了這座橋，前半講月亮的引力、後半講海嘯在淺水變高，是兩個問題接在一起，『海嘯不是潮汐』只是一句命名對照，撐不起轉場。只算回答同一核心的事實（潮型因地而異加 S83 單一 JetStream 頁的傳播與淺化）約 9 條，估約 7.3 分；審查的 10.2 分是把引力模型與大小潮（大小潮的來源段落也缺）一起算進去，而且兩個海灣的近岸紀錄缺了，第四章只能靠示意圖重講。要合必須先補港口潮位紀錄與兩灣近岸紀錄，所以現在是後備。
