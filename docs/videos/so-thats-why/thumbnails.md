# 原來如此事務所：縮圖規格

2026-09-28 起草。縮圖跟著 [`look.md`](look.md) 走：同一個畫風與色盤，沒有吉祥物、沒有真實人臉或 logo。這份定版面、字、印章、各主軸的強調色與 A/B 測試，並逐欄對到現有的 `thumb` 版型（`tools/video/templates/templates.mjs` 的 `thumbnailHtml`、`tools/video/templates/theme.css` 的 `.thumb`）。版型做不到的列在最後的「缺口」，**這份不改程式**；缺口補上前照「現在能做的」一欄出圖。

## 色盤

| 用途 | 顏色 | 規則 |
| --- | --- | --- |
| 紙底、大字 | 奶油 `#F6EFE3` | 大字一律奶油色，放在墨藍遮罩上 |
| 遮罩、描邊 | 墨藍 `#1F2A44` | 文字區底下的遮罩；深色主軸標籤的底 |
| 印章 | 印章紅 `#D8452F` | **只給印章**。大字、標籤、背景都不用紅色，和片中「紅色＝答案」一致 |
| 強調 | 芥末黃 `#E8B64C` | 大字裡最多一個詞（`**…**`）；商業主軸的標籤底 |

## 版面格線（1280×720）

| --- | --- | --- | --- |
| 文字欄 | x 72–940、y 64–656 | 標籤、大字、小字，垂直置中 | `.thumb` 的 padding `64px 72px`、右 padding 340px |
| 遮罩 | 左往右漸層，0–48% 最深，右緣幾乎透明 | 讓大字在插圖上讀得到 | `THUMB_BACKGROUND_CSS` 的 `.thumb-scrim` |
| 插圖主體 | x 700–1280（右側約 45%） | 關鍵影格裡最有衝擊的物件 | `data.shot` 的關鍵影格，`object-fit: cover` |
| 品牌字樣 | 左下 x 72、距底 48px | 目前是 MOKAAIR | `.thumb .brand` |
| 印章 | 文字欄右上，中心約 (860, 150)，直徑約 150 | 見「印章」一節 | 版型沒有，見缺口 G2 |

### 安全區

| 區域 | 範圍（px） | 為什麼 | 規則 |
| --- | --- | --- | --- |
| 隱藏區 B：時間標籤 | 右下 x 1060–1280、y 620–720 | YouTube 在右下角蓋影片長度（手機與桌機都是） | 不放字、不放插圖主體、不放印章 |
| 隱藏區 A：懸停按鈕 | 右上 x 1140–1280、y 0–140 | 桌機滑鼠停留時出現「稍後觀看」「加入佇列」 | 不放字與主體 |
| 進度條 | 最下緣 12px | 看過一部分的影片會在底部顯示紅色進度條 | 不放重要內容；品牌字樣距底 48px 已避開 |
| 縮到 320 寬 | 全圖 | 手機列表與建議影片欄的小圖 | 縮圖做完一律縮到 320×180 看一次，大字要讀得出來（`youtube-video` skill 的上架檢查） |

插圖主體（例如 S01 的彎曲航線、A08 的草莓）要落在 x 700–1060、y 120–600 之間，避開兩個隱藏區。

## 文字規則

| 項目 | 規則 | 版型現況 |
| --- | --- | --- |
| 大字 `headline` | **≤ 10 個中日韓字**（英數兩個算一個字）；最多 2 行，每行 ≤ 6 字；要斷行時用 `\n` 指定斷點，不要讓瀏覽器在詞中間斷 | 字級 136px、Noto Sans TC 字重 900、行高 1.1；`.fit` 會把放不下的字縮小最多 40%，最多排得下 3 行。長度與行數版型不檢查（缺口 G6），撰稿時自己數 |
| 內容 | 不重複標題，補標題沒說的那一句：反常識的結論或一個數字（標題「為什麼網速 Mbps 跟下載 MB 差 8 倍？」→ 縮圖「差 8 倍」「b ≠ B」） | — |
| 強調 | 大字裡最多一個詞用 `**…**` 標，顯示成強調色 | 目前強調色是主題的橘 `#f0a04b`，不是芥末黃（缺口 G1） |
| 標點 | 可以用一個「？」或「！」；不用引號、括號、刪節號 | — |
| 數字 | 用阿拉伯數字，和影片卡片一致；數字必須已經查核（同 README 查核規則） | — |
| 標籤 `tag` | 2–4 字，見「各主軸強調色」 | 字級 40px、字重 800、膠囊形 |
| 小字 `sub` | **預設不用**。只有 A/B 的變體 C 用，≤ 12 字 | 字級 44px、字重 700 |
| 真實名稱 | 品牌名可以寫成文字（「Nokia」），但不放 logo、不模仿字體 | — |
| 語系 | 縮圖只做繁中一張；YouTube 縮圖不分語系 | — |

## 印章

片頭與片尾的紅色印章，也是縮圖的系列識別。

- 形狀：方形朱文印，約 150×150px，旋轉 −8°，邊緣做出蓋章的不均勻墨色，印章紅 `#D8452F`、不透明度 90%。
- 字：「原來如此」四字 2×2 排（各語系一樣用這四字，當成圖形）。不用「受理」，受理只在片頭。
- 位置：文字欄右上，壓在大字第一行的右端上方一點，中心約 (860, 150)；不碰插圖主體、不進隱藏區 A。
- 一張縮圖只有一個印章。
- 版型自動畫（見「缺口與支援狀態」G2）；`tag` 留給主軸。不要讓圖片模型畫印章：`look` 的 `negative` 擋文字，畫出來的會是沒有字的紅圈。

## 背景插圖（`data.shot`）

- 背景必須是本集已畫好的一張關鍵影格：`thumbnail.data.shot` 填那個鏡頭的 id，`render` 會把它的關鍵影格鋪滿 1280×720（`tools/video/render/plan.mjs`；鏡頭要在 `thumbnail` 之前出現，`tools/video/core/drama.mjs` 會檢查）。不為縮圖另外生圖。
- 挑鏡頭的條件：
  1. 主體在畫面右側（x 軸 55% 以後），左側是乾淨的留白或單色背景，遮罩壓上去不會糊。
  2. 一眼看懂的單一物件或對比（兩個物件並排最好），不選地圖全景、不選人群。
  3. 沒有字、沒有 logo、沒有真實人臉（`look.md` 已擋，這裡再看一次）。
  4. 通常是鉤子段落的鏡頭，和影片前 20 秒的畫面一致，點進來的人不會覺得被騙。
- 撰稿時就在分鏡裡安排一張「縮圖鏡頭」：鉤子段落的其中一張，提示詞寫明 `subject on the right third, calm empty left half`。
- 1920×1080 的關鍵影格縮成 1280×720 是等比例，不會被裁；主體仍要避開右下時間標籤。

## 各主軸強調色

色盤只有四色、紅色保留給印章，所以主軸用**標籤的底色與字色組合**分辨，不另加顏色。

| 主軸 | 標籤文字 | 標籤底 | 標籤字 | 大字強調詞 |
| --- | --- | --- | --- | --- |
| 商業與品牌（business） | 商業 | 芥末黃 `#E8B64C` | 墨藍 `#1F2A44` | 芥末黃 |
| 生活與科學（science） | 科學 | 奶油 `#F6EFE3` | 墨藍 `#1F2A44` | 芥末黃 |
| 旅遊與各國文化（travel） | 旅遊 | 墨藍 `#1F2A44`，芥末黃 3px 描邊 | 芥末黃 `#E8B64C` | 芥末黃 |
| 科技與 AI（tech） | 科技 | 墨藍 `#1F2A44`，奶油 3px 描邊 | 奶油 `#F6EFE3` | 芥末黃 |

- 標籤文字可以換成播放清單的簡稱（「日本為什麼」「AI 怪毛病」），但同一個主軸的配色不變。
- `thumbnail.data.pillar` 指定主軸，版型照上表上色（G3）。

## A/B 測試（YouTube「測試與比較」）

Studio 的縮圖測試一支影片最多 3 張，依觀看時間分享選出勝者。每支長片上架時都放 3 張：

| 變體 | 名稱 | 大字 | 背景鏡頭 | 其他 |
| --- | --- | --- | --- | --- |
| A | 問題大字 | 把問題縮成 ≤ 10 字（「冰為什麼會浮？」） | 縮圖鏡頭 | 標籤＝主軸；有印章 |
| B | 反常識一句 | 結論或數字（「差 8 倍」「不是空氣」），強調詞用芥末黃 | 同 A | 同 A |
| C | 兩物對比 | ≤ 6 字、一行（「圓窗 vs 方窗」） | 另一張有兩個物件並排的鏡頭 | 小字 `sub` 補一句 ≤ 12 字 |

- A 與 B 只差大字，量的是「文字寫法」；C 換背景，量的是「畫面」。前 20 集每集都測，把勝出的變體記在該集的 `brief.md`；第 20 集檢討時看哪個變體勝率高，改成預設。
- 測試期間不改標題，否則分不出是誰的效果。
- **做法**：`thumbnail` 本身是 A；`thumbnail.variants` 放 B、C（最多兩個），每個是 `{ "data": {...} }`，蓋在 A 的 `data` 上，所以 B 只要寫 `headline`，C 寫 `headline`、`sub`、`shot`（可加 `layout`）。lint 對每個變體跑同樣的字數與欄位檢查，`shot` 必須是本集的鏡頭。`render` 除了 `thumbnail.jpg`（A）另外出 `thumbnail-b.jpg`、`thumbnail-c.jpg`，`frames/manifest.json` 的 `thumbnail_variants` 列出來；拿掉變體再 render，舊檔會刪掉。範例：`tools/video/core/fixtures/explainer/video.json`。
- 上架包（`package`）把 `thumbnail_variants` 列的 B、C 複製到 `upload/` 的 `thumbnail.jpg` 旁，記在 `metadata.json` 的 `thumbnail_variants`；`UPLOAD.md` 第 1 節的縮圖步驟改成三張都傳到「測試與比較」、測試期間不改標題。上架包檢查對 B、C 跟 A 一樣：列了卻不在、或超過 2 MB 就不過。成片審核（`review-push --gate final`）與「可以上架」卡片把 B、C 跟 A 一起送上網站（檔案角色 `thumbnail-b`、`thumbnail-c`）；網站卡片顯示它們在票 `2026-10-02-show-thumbnail-variants-b-and-c`。

```json
"thumbnail": {
  "template": "thumb",
  "data": { "headline": "雷聲為什麼\n**晚到**？", "tag": "科學", "pillar": "science", "shot": "flash" },
  "variants": [
    { "data": { "headline": "**每 3 秒**\n走一公里" } },
    { "data": { "headline": "光 vs 聲", "sub": "同時出發，誰先到？", "shot": "race", "layout": "right" } }
  ]
}
```

## 欄位對照

| 規格項目 | `thumb` 版型欄位 | 對應 | 狀態 |
| --- | --- | --- | --- |
| 版型 | `thumbnail.template` | 固定 `"thumb"`（`THUMBNAIL_TEMPLATES` 只有它） | 有 |
| 大字 | `thumbnail.data.headline`（必填） | ≤ 10 字、`\n` 斷行、`**…**` 強調 | 有；長度不檢查（G6） |
| 主軸標籤 | `thumbnail.data.tag`（選填） | 「商業／科學／旅遊／科技」或「原來如此」 | 有；顏色固定（G3） |
| 小字 | `thumbnail.data.sub`（選填） | 只給變體 C | 有 |
| 背景插圖 | `thumbnail.data.shot` | 本集一個鏡頭 id | 有（漫劇才有底圖，本系列是漫劇格式） |
| 遮罩 | —（固定） | 墨藍漸層 | 顏色是 `#0e2627`（G1） |
| 大字顏色、強調色 | —（主題） | 奶油、芥末黃 | 是主題的 `#f7f1e8`、`#f0a04b`（G1） |
| 品牌字樣 | —（固定 `BRAND`） | 「原來如此事務所」 | 固定 MOKAAIR，青綠色（G5） |
| 印章 | — | 紅色方印 | 沒有（G2） |
| 主軸配色 | — | 見上表 | 沒有（G3） |
| 版面變體 | `thumbnail.variants` | 3 張測試圖 | 有（G4，上架包也帶 B、C） |
| 文字在右、插圖在左 | — | 主體只能在右 | 遮罩方向固定左深右淺，不能鏡像（G7） |

## 缺口與支援狀態

2026-09-28：`look.preset` 是 `flat-explainer` 的影片，`render` 會用系列自己的縮圖（`tools/video/templates/templates.mjs` 的 `THUMB_SERIES`，`tools/video/render/plan.mjs` 的 `thumbnailSeries`）。其他影片的縮圖一個位元組都沒變。

| # | 缺口 | 狀態 | 怎麼用 |
| --- | --- | --- | --- |
| G1 | 系列色盤 | 已支援 | 自動：墨藍遮罩、奶油大字、芥末黃強調與字樣 |
| G2 | 印章 | 已支援 | 自動：「原來如此」2×2 紅色方印，約 (860, 150)，旋轉 −8°，用 CSS 畫 |
| G3 | 主軸配色 | 已支援 | `thumbnail.data.pillar`：`business`／`science`／`travel`／`tech`，標籤配色照「各主軸強調色」表 |
| G4 | 三張 A/B 變體 | 已支援（render、上架包、審核送檔）；網站卡片顯示待補 | `thumbnail.variants`，見「A/B 測試」一節；卡片顯示 B、C 在票 `2026-10-02-show-thumbnail-variants-b-and-c` |
| G5 | 系列字樣 | 已支援 | 自動：「原來如此事務所」取代 MOKAAIR |
| G6 | 大字長度 | 已支援 | lint／render 擋：每行 ≤ 10 字、≤ 2 行（`**` 與空白不算） |
| G7 | 主體在左的鏡頭 | 已支援 | `thumbnail.data.layout: "right"`：文字欄、遮罩、印章一起鏡像 |
