## 這批可以怎麼拍

- **中文加空格，空在哪裡才有幫忙？** 先讓觀眾比較四種排法，再分別看母語者與學習者研究。空格是否標對詞界，比一律多加空白更有解釋力；兩份研究分開呈現。[閱讀題卡與原研究](batches/wave46-reading.json)
- **跳蟲彎成 U 形，帶著的小水滴幫了什麼忙？** 活體翻正與人造落體比較分開，讓形狀和水滴的作用看得見。起跳、翻正與落水保留不同的控制條件，不把整篇研究硬塞同片。[動物動作題卡](batches/wave46-life.json)
- **冰裡藏著空氣，為什麼反而可能融得更快？** 對照兩次水槽的冰面退縮，再看氣泡附近的流動。兩個試驗與能量模型分開，不把特定倍率寫成所有冰河通則。[冰雪題卡與原研究](batches/wave46-earth.json)
