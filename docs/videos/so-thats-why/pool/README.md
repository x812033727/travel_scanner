## 這批怎麼取捨

**小天體的現場線索。** 收進 10 題。舊題 E11015 已經解釋一般撞擊坑為什麼常是圓的。這次問龍宮的人工撞坑怎麼少了半圈，觀眾可以把同一處撞擊前後的影像疊上去，比較一塊移動、一塊幾乎沒動的巨石。DART 飛到雙小行星的題材則將辨認小伴星、從地面量週期、解釋噴出物反衝接成同一支。[10 題及原研究](batches/wave36-space.json) · [非作者覆核](reviews/wave36-physics-reviews-space.json)

**從磨豆到杯裡。** 收進 7 題。「磨得越細會不會萃得越多」已有 F4030。本批保留的是磨豆機刻度相同時，豆溫怎麼改變碎片尺寸，以及細粉最後留在機器還是落進杯裡。兩題分別用回溫和消電位置做對照，合講時能分開「磨出了什麼」和「收到什麼」。烘焙後的孔隙另有原研究，只留作備用段落。[7 題及原研究](batches/wave36-physics.json) · [非作者覆核](reviews/wave36-space-reviews-physics.json)

兩組共查 17 項原研究，逐題保存實際閱讀位置和證據能支持的範圍。另記 31 個未另收方向及理由，例如從單一熱圖精算石頭孔隙、依沖水高度就指定最佳手沖配方。JAXA 團隊簡報和相應論文、咖啡研究的期刊頁與典藏副本均按研究身分整理。[來源身分核對](reviews/wave36-central-checks.json) · [當批整合紀錄](reviews/wave36-editorial-integration.json)
