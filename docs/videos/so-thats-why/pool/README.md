## 這批可以怎麼拍

- **六角蜂巢的接縫裡，怎麼跑出五邊和七邊？** G485 先讓觀眾看兩片方向不同的蜂巢會在哪裡碰頭，再把接縫各格的邊標出來。小角差可以逐排轉過去，方向差更大時非六角格更常見。看清接縫就收尾。[題卡與原研究](batches/wave45-life.json)
- **只敲杯底沒彈走球，整杯先掉下去怎麼就行？** G490 暫停在杯底還沒碰地的畫面，讓觀眾找水線。球已先浸得更深，再接碰地時水的壓力衝量，答案藏在撞擊前。[水杯、入水與反彈實驗](batches/wave45-physics.json)
- **這麼重的海岸巨石，非得海嘯才搬得動？** G494 對齊同一地方的背景，再看風暴季前後岩塊位置的差別。六百多噸是體積乘密度的估計，三公尺半是前後位置差；畫面把兩種證據分開。[海岸觀測與原研究](batches/wave45-earth.json)

28 個新核心都有原研究定位、讀取版本和適用條件。另 51 個方向未另收，包含翻瓶轉慢、一般沿岸搬砂等舊答案，也包含「親水球永遠不帶氣腔」這類過度推論。逐題比較本批 top-5 近鄰及作者手查近對後，這 28 題無須再合併。[編輯裁決](reviews/wave45-editorial-integration.json) · [來源反查與範圍](reviews/wave45-central-checks.json)
