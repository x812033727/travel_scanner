## 本批怎麼選、怎麼合拍

- **帶電的花，是靠哪裡感到的？** 兩排人工花都接地後，熊蜂原本的選擇優勢下降。這項實驗補回舊題 B2312。另一篇研究讓觀眾看到電場下的觸角和體毛都會動，再揭開神經記錄，比對哪一種偏轉還伴隨放電。兩步在 G407 合拍。[訪花素材、研究與不收理由](batches/wave41-flower.json)
- **動了就算醒著嗎？** 倒立水母夜裡第一次失去支撐時反應較慢，再測一次，這個晝夜差異消失。章魚則是在快速換色的活動期對弱震動反應較低。G412 用同一個「怎麼知道」串起兩場實驗，另外分清反應測試能支持到哪裡。[動物睡眠素材](batches/wave41-life.json)
- **同樣撞到牆腳，壁球怎麼會貼著地出去？** 高速畫面停在球第一次碰地時：它是在牆上往下滾，還是已經離牆？G416 只講這個時間差。球場的其他題案另有軟球打水漂、母球偏擊，以及拍線或中空棒壁來不來得及彈回。[運動物理素材](batches/wave41-physics.json)
- **熔岩向上噴，湖面的岩殼為什麼反而往那裡沉？** G421 先讓觀眾盯住兩片岩殼，跟著熱影像看它們朝噴濺處匯聚。熔滴飛起與表殼下沉可以同時發生；另以虛線畫氣泡破裂留下局部凹處的解釋。[火山觀測素材](batches/wave41-earth.json)

36 個原提案留下 35 個新核心。26 個新核心與 B2312 組成 19 個片案；9 個新核心留在池裡，例如花面溫度圖樣、不同洞穴魚族群的側線試驗、棒球縫線朝向與火山岩壁落石。另有 59 個重述、過薄或證據不足的方向附未收理由。36 筆來源書目均列出讀取範圍與限制，R41001 可作別名搜尋。[編輯整合](reviews/wave41-editorial-integration.json) · [來源核對](reviews/wave41-central-checks.json)
