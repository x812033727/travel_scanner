## 去重工具及歷史保護

完全相同問法可正規化合併；其他合併由編輯比較答案與適用條件決定。本次新增本機語意近鄰輔助搜尋，仍沒有自動依相似分數合併或退題。

上一批已知的 50 組人工合併中，詞面找到 11 組、語意 top-10 找到 29 組，聯集 31 組。這是非隨機已知集合，**不能當全庫召回率或沒有漏題的證明**。詳見 [工具與限制](SEMANTIC.md) 及 [評估收據](reviews/wave3-semantic-baseline.json)。新批的人工判斷另存，不靠換物件、換名詞灌水。

1,000 與 2,000 檢查點均以雜湊鎖定的 gzip 保存，分別見 [首批驗證](VALIDATION-1000.md)、[第二批驗證](VALIDATION-2000.md)。新建置必讀 [checkpoints.json](checkpoints.json)，缺快照或改舊 raw 就拒絕；舊入選核心退休／合併須逐筆聲明。只有已凍結的舊 ID 可以沒有新段落欄位，新題漏填就拒絕。來源增加新讀取範圍不會覆寫舊閱讀紀錄。

## 本機使用

Node 24；本輪使用 Codex 附帶 v24.19.0。

```powershell
node tools/video/so-thats-why/pool/cli.mjs check
node tools/video/so-thats-why/pool/cli.mjs index
node tools/video/so-thats-why/pool/cli.mjs search 螢光
node tools/video/so-thats-why/pool/cli.mjs show O3068
node tools/video/so-thats-why/pool/cli.mjs theme G32
node tools/video/so-thats-why/pool/cli.mjs baseline
node tools/video/so-thats-why/pool/cli.mjs source https://grace.jpl.nasa.gov/data/get-data/gia-trends/
```

`show` 能用原始 ID 查合併後核心；關鍵字搜尋也可能找到在範圍內提及該 ID 的其他題，並非必然只回傳一列。`source` 反查相關核心及影片，不抓取或監控外站。`index` 寫入忽略版控的本機 SQLite；同快照再匯入是 0 writes，過期索引拒絕查詢。

新批次依「來源閱讀 → 原創問題與段落設計 → 詞面/語意近鄰 → 非作者覆核 → 集中合併/暫緩 → 選入 → 組片 → 建置驗證」續接。輸入、程式、來源包、檢查點及輸出由 manifest 綁定雜湊。驗證範圍與結果見 [VALIDATION.md](VALIDATION.md)。
