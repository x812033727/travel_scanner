## 本批取捨

本批11個核心排成6組。陶鍋殘留分層與淡水食材的碳庫偏差，分別回答哪一餐、哪一年。火塘焦屑和炭化麥芽用兩種尺度辨加工步驟。陶篩與牙結石從加工器物追到個人。足跡組把下層受壓與足趾穿層放在同一片對照，蜥腳類缺印單獨短講，菊石拖痕與癒合骨則對照生前與死後的證據。27個方向留存未另收理由。

優先試讀「只找到前腳印，這隻恐龍一定在游泳嗎？」。同一組四足著地模型，只改地面強度，足以在一分鐘左右把直覺翻過來。第二順位是古陶篩與牙結石，一張器物圖、一個個人的樣本，就能把村落曾處理乳品和誰曾攝取乳品分開。若跨研究轉場試讀仍容易誤認同一人或同一處，先拆成短段。

這是紙上編輯判斷，尚無觀眾測試。完整稿、試讀、小樣、錄音及媒體新增均0，舊文字小樣未改；正式產線規格未變，短題案不等於可直接匯入的成片。
