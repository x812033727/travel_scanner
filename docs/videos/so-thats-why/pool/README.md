## 去重與退題

相同完整問題正規化後可自動合併；其他題目要比較核心答案和成立條件。換動物、物件或用另一公式描述同一機制，不另加一筆。像螳螂蝦的空穴力峰歸回空化核心，塑膠夾模力歸回壓力乘面積；有用案例和來源仍留下。

第二批 50 組人工合併中，現行詞面／研究目標相似工具只提出 11 組，其餘 39 組由閱讀發現；沒有一組被標成必處理高相似警示。這是已知重複的非隨機集合，**不能當成全庫召回率或沒有漏題的證明**。詳見 [去重稽核](reviews/wave2-dedup-audit.json)。擴至萬筆前仍要改善語意檢索與獨立判讀樣本，不能只調到這組案例過關。

只有現象或名詞、缺少機制的題目先暫緩。只夠一句解釋、需要太多前置知識或尚無好用情境的合格題保留候補。沒有刪除原始提案，也沒有把歷史剔除／轉線題靠新標題復活。

## 從素材組成影片

[26 組主題](THEMES.md) 都有共同追問、相接理由、每章新增資訊、時間預算、無聊風險、應刪條件及證據缺口。本批較值得先寫 treatment 的例子：

- 斷電以後，資料究竟躲在哪裡？8–11 分鐘。
- 獵物藏起來，電鰻怎麼逼牠露出位置？8–10 分鐘。
- 水變乾淨了，污染物去哪裡？9–12 分鐘。
- 塑膠盒上的凹痕和細線，是怎麼留下的？9–12 分鐘。
- 記得很清楚，就代表真的看過嗎？8–10 分鐘。

取捨也有留下：切葉蟻組題須避免把不同類群拼成一個動物；蜂群出發門檻缺完整研究；貨車煞車、轉彎與液體晃動的拼接過廣，暫不升格為本輪組片。單純相關不等於能連成好故事。

沿用 [新版規格](../refresh-20261101/SPEC.md)：開場先給具體疑問，每 30–45 秒有實際資訊推進或追問；刪一段不影響理解就刪。章節秒數只是預算，沒有用字數假裝實測片長。刪重述後不足 8 分鐘退出長片或改短形式；林蛙題若比較資料無法呈現，就改 3–5 分鐘，不用耐寒排行撐長。

## 本機使用

Node 24；本輪使用 Codex 附帶的 v24.19.0，沒有新增 npm 相依。

```powershell
node tools/video/so-thats-why/pool/cli.mjs check
node tools/video/so-thats-why/pool/cli.mjs index
node tools/video/so-thats-why/pool/cli.mjs search 電容
node tools/video/so-thats-why/pool/cli.mjs show D2130
node tools/video/so-thats-why/pool/cli.mjs theme G17
node tools/video/so-thats-why/pool/cli.mjs baseline
node tools/video/so-thats-why/pool/cli.mjs source SRC-00513691bfb6db9f
```

最後一個指令的來源 ID 請用 [SOURCES.md](SOURCES.md) 中的實際 ID，亦可直接傳入來源 URL。`source` 回查相關核心題、別名及影片主題；它不抓取或監控外站。發現來源更正後，先重查支持的前提及相關章節，再更新來源閱讀紀錄、去重和選入處置。

- `baseline` 比較首批：舊原始資料不可靜默改寫；若退休或合併首批入選 ID，必須明列理由。
- `index` 寫入忽略版控的 `.cache/pool.sqlite`；相同快照再次匯入為 `UNCHANGED / 0 writes`，交易中斷保留上一版，原 ID 與修訂仍可回查。
- `search` 預設只查入選題；`--all` 可含候補／暫緩，原 ID 用 `show`。搜尋頁也支援合併變體文字。
- 新資料放 `batches/*.json`，先跑 `preview`、完成獨立審閱及集中處置，再更新 `selection.json` 並 `build`、`check`、`index`。
- `manifest.json` 綁定輸入、程式、來源包、基線與輸出雜湊；變動會讓舊輸出／索引失效。

完整驗證見 [VALIDATION.md](VALIDATION.md)。

## 使用與擴張界線

《十萬個為什麼》用來啟發從日常追問機制的方向，沒有複製特定版本目錄或整本問答。來源以研究機構、原始研究、官方技術資料與教材為主，只保留原創提問、短摘要和定位，不搬入全文、圖片或實驗圖表。公開可讀不等於圖文可商用；OpenStax 等資料仍須逐版本核對權利。

本批 2,000 規模的索引與瀏覽已實測；10,000／100,000 的效能、語意召回率、編輯採用率與成片成效尚未量測。後續以小批增加到 10,000，再驗證十萬筆以上；完整 treatment、逐主張查核、試讀與製作前程序仍須逐集執行。

本輪未產生媒體、修改正式資料庫、部署或發布；未另啟動付費媒體服務。模型研究的完整計費資料未提供，不把它宣稱為零成本。本次是可續接的 2,000 筆檢查點，沒有背景自動擴庫。
