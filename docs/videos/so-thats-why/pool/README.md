## 本批取捨

本批留8個昆蟲行為實驗問題、4個海底泥沙流問題。把兩種外觀相似的爬球行為放在一起，比較改變太陽方向、隔絕前足熱傳會各自得到什麼結果。海底纜線中斷、流速計及海床地震儀也合成一案，分開回答前緣速度和後段持續多久。另29種重複或證據不足的提法記入未收。

本批比對了舊庫 3,490 筆原題與 1,367 個未收方向。每個新題由另一位編輯核對來源及答案條件，逐一判讀作者提出的 28 組近似題，以及每題最相近的五個檢索結果（共 60 組有向配對，與作者名單部分重疊）。
