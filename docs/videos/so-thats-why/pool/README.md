## 這批可以怎麼拍

- **閉上眼聽是「巴」，張開眼怎麼變了？** G445 把原聲和錯配嘴形剪在一起，先讓觀眾自己回答。接著換一個實驗，同一位聽者在不同回合看到兩種嘴形，每回畫面關掉後再辨音。開著畫面聽到什麼，和關掉畫面後還留下什麼，分兩步揭曉。另有一案把英語和荷語字幕都關掉，才測陌生口音的新台詞能複述幾個字。[語音題卡與原研究](batches/wave43-speech.json)
- **看起來整片山坡一起亮，哪一處其實先閃？** G451 先看帳篷內單隻與一群螢火蟲各要等多久才開始下一串閃光，再把野外亮點依發光時間上色。帳篷資料採期刊勘誤後的版本；由最先準備好的個體帶起下一串，是研究用來解釋間隔的模型。鳥群篇則沿用 B2248，新增三維實測，區分鄰鳥的數目與相隔幾公尺。[群體行為、勘誤與野外記錄](batches/wave43-life.json)
- **水下的珠子料斗，怎麼快漏光時反倒越快？** G455 先請觀眾猜出珠速度，再讓染色水顯出它怎樣穿過珠床。最後封住頂部，用幫浦固定進水量，讓觀眾看兩條出料曲線的末段。另一支則用連續影格分清出口的珠子短暫排成拱，和這座拱真的能把流動堵住。[顆粒流實驗與圖表定位](batches/wave43-physics.json)
- **比海水輕的液態二氧化碳，怎麼留在海床下？** G460 從取芯孔冒出液滴開始，再看密封樣本的成分。海床下那層水合物可能像蓋子，這一步用虛線標示成研究者的解釋。超鹹水池另有池邊覓食影像、池內外沉積薄層、鹽分來源三種問題，共用同一篇現場研究，各自附取證位置。[深海觀測與採樣來源](batches/wave43-earth.json)
