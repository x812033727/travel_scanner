## 這批可以怎麼拍

- **咬洋芋片的聲音，和旁邊吵不吵，是兩個實驗。** G426 先切換受試者耳機中自己的咬聲，再改成與咬合無關的白噪音，讓觀眾預測甜、鹹與酥脆評分會往哪裡走。片上分清主觀新鮮度與食物的實際含水量。另有一支從氣道模型的示蹤粒子轉到人的香味位置回報，問香氣到鼻子，為什麼人會指向舌頭。[風味素材與研究](batches/wave42-flavor.json)
- **螞蟻走過九段坡，會在哪裡回頭找巢？** G431 先用舊題 B2329 的新變體比較只在返程改步幅與去回程都改，再將坡道與平地交換。第一場試驗追步幅，第二場追水平投影，不能替兩者套上同一種折返統計。信鴿的當地空氣對照併進 B2245 作嗅覺導航的陸上案例，保留來源、物種與放飛條件。[導航素材與研究](batches/wave42-life.json)
- **改顆粒形狀和改顆粒大小，乾掉的顏色會去哪裡？** G437 先讓觀眾看同材質的橢球在液面聚成網，再看三種大小的圓球在邊緣分帶。前者解釋外圈為何變淡；後者讓觀眾在水滴剖面上找出，最大的球從哪裡就擠不過去了。普通咖啡環已有 H3092。[書寫與乾燥圖樣](batches/wave42-physics.json)
- **火星探針為什麼越敲越往上退？** G440 把尾端位置標在照片上，比較機械臂抵住探針側面，和改壓旁邊土壤時的進退。探針設計需孔壁提供摩擦以抵住回彈；進尺停住不能單憑一張照片就指定前方有石塊。[火星現場素材與來源](batches/wave42-earth.json)

38 個原提案保留 36 個新核心。30 個新核心與舊題 B2329 組成 G426–G444 共 19 個片案，6 個新核心先留素材。兩個併回舊題的提案號 L42-001 和 L42-009 仍可搜尋。另 62 個重述、證據不足或太薄的方向附未收理由。38 筆研究來源各標示實際查閱方式與範圍，水彩一題使用研究預印本；本批風味組的香味定位與甜水餘感限於原作者摘要。[編輯決定](reviews/wave42-editorial-integration.json) · [來源核對](reviews/wave42-central-checks.json)
