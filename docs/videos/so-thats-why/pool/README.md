## 這批可以怎麼拍

- **把藏食坑挖空，種子反而走得更遠？** G470 開場只給一個空坑。等觀眾猜完，再沿無線電標籤的位置畫出同一顆棕櫚種子被挖走、重新埋下的路線。最後將每一段搬運相加，與種子離原點有多遠並排，讓觀眾看出兩個距離怎麼差這麼多。[種子題卡與原研究](batches/wave44-life.json)
- **把一疊「書頁」壓彎，厚一倍就多用一倍力嗎？** G475 的實驗用未裝訂的塑膠薄片，比較 1、25、70 片。先把量到的總力除以片數，再看厚疊在最吃力時連平均每片也較高。看懂兩條力曲線之間的面積，這支便可收尾。[薄片與折紙實驗](batches/wave44-physics.json)
- **恐龍走路只留腳印，蹲下時哪裡多出了手印？** G480 把同一處痕跡放大，讓觀眾自己找出手印並比較兩手方向，再看研究者如何推斷那隻獸腳類的手掌朝向。另有一案用洞道形狀、骨骸位置與保存狀態判斷恐龍是否住過，保留水沖入的替代解釋。[化石、足跡與原研究](batches/wave44-earth.json)
- **重量猜錯時，手指和感覺會同時改口嗎？** G465 沿用 A21002 的同重木塊，先比提起時的指力與主觀評分，再換成多日接觸小重、大輕物塊的訓練。G467 則先看兩指托著的鋁條上，明明沒被敲的地方怎麼會被指出來，再看另一項木桿試驗如何靠振動辨認真實落點。[觸覺實驗與勘誤](batches/wave44-touch.json)

38 個原提案中，36 個成為新核心。短期提重試驗 R44001 併回入選的 A21002；手掌刷觸 R44008 只補充歷史題 LEG-S74 的來源，維持剔除。另 64 個方向留有未收理由，例如換不同花色再拍一次三浦摺、把同一張薄膜每次新添的痕都拆一題。39 筆來源紀錄含 1 篇期刊勘誤，另區分原刊實驗、作者摘要及模型推論。[編輯裁決](reviews/wave44-editorial-integration.json) · [來源反查](reviews/wave44-central-checks.json)
