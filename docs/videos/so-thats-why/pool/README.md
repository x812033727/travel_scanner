**落雨之後，8 題。** 在濕葉上用染色區分哪一滴水被拋走，在帶鏽斑的小麥葉上則追蹤離開葉面的乾孢子。兩個試驗合講，畫面跟著被搬走的東西換視角。空中水滴碎裂、葉尖的排水速度留作段落；靠短片就能講清楚的水槽滴聲另成一案。[題目與研究](batches/wave38-physics.json) · [非作者覆核](reviews/wave38-arch-reviews-physics.json)
