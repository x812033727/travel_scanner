## 第三十五批

**動物留下的工具痕跡。** 收進 9 個有原始研究可查的提問。獼猴敲果核時也會打出銳利的石片；只看石片，有時只能回答石頭怎麼裂。另一項研究先看見海邊獼猴拿石錘敲食物，回頭檢查不同敲法磨損的是哪一端。兩個案例接在一起，觀眾可以先用痕跡猜，再看觀察怎麼驗證。[9 題與原始來源](batches/wave35-tools.json) · [逐題覆核](reviews/wave35-physics-reviews-tools.json)

**車和人怎麼一起移動。** 收進 6 個提問。舊題 T4014 解釋塞車隊尾為何向後退，這次的環道研究檢驗能否只改一輛車的速度，就讓波動減小。迎面人潮因前排分心而晚些成行、直角交會時形成斜帶，也各有不同的實驗和答案，編進同一支片。三位朋友在人潮中怎麼站，只留作補充段落。[6 題與原始來源](batches/wave35-physics.json) · [逐題覆核](reviews/wave35-tools-reviews-physics.json)

兩組以不同作者交叉查核。本批共整理 15 項研究，作者預印本、典藏稿及原刊頁以同一研究登錄。另有 29 個未另收方向，包括重提海獺怎麼保存石頭，以及把不同人數的同行隊形各拆一題。題目、理由及對應的研究都保留在兩組資料裡。[整合紀錄](reviews/wave35-editorial-integration.json) · [來源身分核對](reviews/wave35-central-checks.json)
