## 哪些題目值得拍在一起

- **一刀切洋蔥，分開看兩件事。** 快霧在什麼時候飛出來，可以逐格看外層破裂；放低催淚因子合成酶的活性後，受傷組織還能做出多少刺激物，則要靠成分檢測。酵素題補回舊題 LEG-S03，只有噴滴形成另收一個核心。[蔥蒜覆核](reviews/wave39-physics-reviews-food.json)
- **停在草地上的紅點去哪了？** 螢幕上的模擬獵物只有移動時才變紅。先讓人看見牠停著的外觀，再給一次搜尋機會，是這支片值得保留的第二輪。另一個用烏賊體紋讀出殘缺輪廓的實驗併回 C2008，仍能用新題號 L39-003 找回來。[偽裝覆核](reviews/wave39-space-reviews-life.json)
- **一條裂縫何時分成兩條？** 乳膠膜留下的 Y 字節點與高速影格可以互相對回。結繩另用熟麵打結的實驗說明入口急彎的斷裂位置；鞋帶鬆脫已有舊題。[裂紋覆核](reviews/wave39-root-reviews-physics.json)
- **土衛二的海會不會只有南極那一小片？** 飛掠時量到的引力缺額可以用局部有水解釋；對齊不同年份的隕坑，看冰殼擺幅，才有依據把推測的海畫到整層冰殼下面。兩步放在同一支，圖上分別標量測與推論。[行星觀測覆核](reviews/wave39-life-reviews-space.json)

本批 32 個原提案中，30 個新核心入選，2 個併到舊核心；另有 53 個過薄、重述或超出證據的問法保留未收理由。新增核心中有 25 個已排入本批片案，5 個仍是備用素材。33 筆來源紀錄分別標明原刊、作者稿、摘要或任務團隊說明，洋蔥原已列過的研究另標出書目關係。[蔥蒜](batches/wave39-food.json) · [動物偽裝](batches/wave39-life.json) · [裂紋](batches/wave39-physics.json) · [土星系統](batches/wave39-space.json)
