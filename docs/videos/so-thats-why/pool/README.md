## 本批取捨

本批收進7個木材與年輪問題及4個火星、月球探測問題。取捨集中在證據能支持到哪裡：已知火年的日誌可測樹疤是否漏記，單一傷痕不足以認定火災；軌道前後照能查火星新撞坑，沒看到坑時也要先看搜尋覆蓋。28個重複或過度延伸的提法留有退題紀錄。

本批比對了舊庫 3,479 筆原題與 1,339 個未收方向。每個新題由另一位編輯核對來源及答案條件，逐一判讀作者提出的 26 組近似題，以及每題最相近的五個檢索結果（共 55 組有向配對，與作者名單部分重疊）。
