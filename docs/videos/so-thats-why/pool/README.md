## 這批可以怎麼拍

- **木頭裡的氣泡是什麼時候冒出來的？** 先把超音波尖峰對回木薄片的顯微畫格，再換到枝條，疊上水下剪切前後的斷層影像。兩次各留一個讓觀眾自己找氣泡的停格。這組 9 題的實驗條件另註明完整植株、離體枝或木薄片。[木材題目與來源](batches/wave40-wood.json)
- **鳥群換成員，舊做法會留下還是會改進？** 山雀兩邊推門都能得到同樣的蟲，要看各地新手第一次推哪邊。鴿隊則可將輪替組與固定搭檔飛過相同趟數的返家路線放在一起，看有沒有少繞路。兩個實驗各有自己的比較標準。動物組共 8 題。[動物題目與來源](batches/wave40-life.json)
- **一盤沙怎麼唱出不只一個音？** 同批阿曼沙滑下斜槽，先看未過篩的幾個頻譜峰，再篩出大小接近的沙粒，辨認一個主音和它的泛音。聽覺以外還有圖可以比。聲學組共 9 題，另有音孔、波紋管及壺哨保留作片段。[聲學題目與來源](batches/wave40-physics.json)
- **海床上的冰退日曆會漏掉一格嗎？** 聲納顯示的是留到今天的矮脊。另畫拉森灣模型的兩次低潮，第二次觸床可能蓋掉前一次的痕跡。把觀眾的注意力留在那個被蓋掉的位置，就能說清楚為什麼退縮速度可能被高估。冰海紀錄組共 9 題。[冰海題目與來源](batches/wave40-earth.json)

35 個核心中，26 個排進 G388–G406，9 個先留素材。另有 58 個方向記錄未收原因，例如只換飲料或水位再講一次音高，以及用一次幹徑變化估算固碳量。37 筆來源閱讀各附實際查到的段落與可支持的主張。[編輯裁決](reviews/wave40-editorial-integration.json) · [來源核對](reviews/wave40-central-checks.json)
