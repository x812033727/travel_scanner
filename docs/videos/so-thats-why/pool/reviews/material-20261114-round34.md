# 原來如此事務所素材池：第三十四輪（2026-11-14）

接續[第三十三輪](material-20261114-round33.md)（5,181 題存檔點）。站主 2026-11-14：「整個結束後繼續再跑四輪」，這是第一輪；規則與門檻不變。 完整紀錄在 [material-20261114-round34.json](material-20261114-round34.json)。

**做法：** 第三十四輪：在 5,181 題存檔點上續跑，針對入選核心與可成題長題數最少的四個分類，由四位作者（F164–F167）動筆前先以 JATS 作者群＋Europe PMC（Crossref 可用時補查）逐對確認研究網互不合著，再從零研究四個新長題；四位未參與撰寫的獨立覆核者（V184–V187）核對請求紀錄與快取雜湊、重抓全文、重拆作者群複查合著、逐卡對全文並重算分鐘，覆核結論優先。通過素材審視的四題再經獨立觀眾初評（A3）、改寫（W2）、複評（A4）。上一輪覆核抓到的通病已寫進本輪作者工作單。

## 觀眾評分

初評（A3）與複評（A4）的錨點偏移是 −0.80 與 −0.875。G653 蜂蜜（8.80 → 8.97）與 G654 溫度知覺（8.50 → 9.18）採用改寫版。G655 木材炭化的改寫版複評反而較低（6.17），保留原版的 6.80。G656 LED 效率初評只有 4.70（評語是「像工程簡報」「平常不會問這個問題」），改成辦案抓兇手的包裝後複評 6.58，過門檻但只高 0.08；以單一評審的誤差看等於貼線，排片時應排在後面，寫稿時中段還要再簡化。（[評分紀錄](audience-20261114-round34.json)）

## 限制

- 估時依加權事實數紙上估算，尚未試讀逐字稿；所有新增題案 `production_ready: false`。
- 四題的素材餘裕都比上一輪薄（比門檻多 0.85–1.60 條）。G653 靠三張沒有直接量結晶的間接卡才過線；G655 任兩個不利情形並發就跌破門檻。補強建議寫在各題的 `material.review_note`。
- Europe PMC 全文端點本輪大面積回 500／503：兩位作者有 7 篇改由 NCBI 取得，四位覆核者合計只重抓到約一半的全文，其餘以作者快取核對；被改動最多的幾張卡（G655 的 T84-001、004、005）沒有獨立重抓。
- 作者對 5xx 的重試偏多、一位覆核者的重抓腳本重疊執行造成兩篇各被請求三次，都不是 429／403 之後的重試，但已照實記錄。
- 各篇論文的補充資料都沒有取得，只出現在補充資料的數字一律沒引用。
- G653 與既有題案 G617（蜂蜜驗真）同屬蜂蜜題，製作時要避免兩支都講摻糖；G656 與 G644（光纖把雷射開大沒用）句型相近，不要相鄰上架。
- G654 多數原文以疼痛或臨床為框架，卡片已清乾淨，但寫稿者回頭讀原文時容易把痛閾與疾病類比帶回來。
