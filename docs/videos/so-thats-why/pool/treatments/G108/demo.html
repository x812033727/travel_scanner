每組都贏，
總比率怎麼反而輸？

固定兩種難度的答對率，只改各自做了多少簡單題。觀察整體排名會不會跟著改變。

這是虛構教學模型。每組總共 110 題；答對率是設定值，不是真實測驗或教學成效資料。

A 的答題紀錄

難度設定答對率答對／題數
簡單90%
難20%

B 的答題紀錄

難度設定答對率答對／題數
簡單80%
難10%

在預設例子中，A 的難題多、B 的簡單題多。合計比率會受兩種難度各佔多少影響，不能直接平均兩個百分比。

有一種難度設為 0 題時，那一格沒有觀察比率；表中的百分比仍只是模型設定。

滑桿是在重算另一組虛構資料，沒有真的把人換題或重新測驗。相同組成可展示加權的差別，仍不能單憑這個例子判斷因果。
