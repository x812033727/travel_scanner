# B26 為什麼超市常把牛奶放在最裡面？

狀態：[reviews/batch01/B26.md](reviews/batch01/B26.md)。製作查核日期：2026-10-01（Asia/Taipei）。本檔是製作企劃及包裝草稿；待獨立事實與聽眾審稿。長片目標 480 秒＝8 分鐘，只有六章企劃，尚無長片逐字稿、音訊或成片；章長都是預算，不是正式片時碼。

本集問題：美國採訪中，牛奶放在店後方有什麼理由？觀眾看完能區分「業者的解釋」「研究觀察到的效果」與「單一全球原因」。標題的「常」是採訪描述，不是全球位置比例統計。冷藏鮮奶是本集示意物，不把常溫保久乳混在一起。

### Short 2

標題：蔬果搬到門口，就一定賣更多？

```text
把蔬果搬到超市門口，就一定賣得更多嗎？英格蘭一項試點研究，把蔬果區擴大、移到入口，還移走結帳附近的糖果。研究看到店內蔬果銷售增加。但改的不只位置，也不是隨機挑店分組，不能把效果全算在入口。後來一項較大型研究，也看到改配置後的初期銷售增加，追蹤時效果卻變弱了。所以位置可能有影響，卻不是放哪裡都保證多賣，更不代表每個家庭都吃得更健康。研究看的是蔬果，也不能直接證明牛奶放後面是為了讓你多買。看懂結論，還得一起看限制。
```
