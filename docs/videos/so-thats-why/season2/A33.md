# A33 為什麼程式錯誤叫 bug？

文字製作包；作者 `write_t26`，製作查核日期 2026-10-01（Asia/Taipei）。審稿狀態以 [獨立審稿](reviews/batch02/A33.md) 與同名 JSON 雜湊收據為準。長片目標 480 秒（8 分鐘），本檔只有六章製作企劃，尚非長片完整逐字稿。兩支 Shorts 秒數是估計；未生成音訊、插圖或成片，未匯入、核准、排程或上架。

本集只回答：bug 為什麼可以用來指程式錯誤？從更早的工程故障用例與飛蛾日誌，拆開「已有的用語」和「後來出名的故事」，不判定英語詞的最早發明者，也不把一次機器內的飛蛾事件當成史上第一個程式錯誤。

## 不做的事

- 不說 Hopper 親手找到第一個 bug、日誌一定是她的，或飛蛾造成史上第一個程式錯誤；不把演講推廣者當發現者。
- 不把 1947 事件日期改成其他年份；不把 Mark II 說成 Mark I，也不從題材名稱推定整台是現代電子電腦。
- 不說 Edison 發明 bug 一詞、1878 是已窮盡的最早用例，或 debug 也由飛蛾事件開始；不採未核語源傳說。
- 不以現在展出當承諾，不向觀眾提供「現場必看飛蛾」旅行指引；收藏與展出分開。
