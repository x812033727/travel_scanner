作者：`write_b26`。來源確認日期：2026-10-01（Asia/Taipei）。審稿狀態以 [批次審稿報告](reviews/batch02/B27.md) 與同名 JSON 雜湊收據為準。本檔是文字製作包，包含六章長片企劃、兩支完整Shorts旁白與五語包裝，**不是長片完整逐字稿**。未生成音訊／插畫／成片，未匯入正式後台，未核准或發布；480秒為製作預算，Shorts秒數為字數估計。

本集回答：為什麼零售價格會使用9結尾？把價格感覺、實際需求及業者動機分開。標題的「常」是研究討論的定價做法，不代表今日全球盛行率。片中2.99／3.00是原論文的美元例子，所有其他商品畫面皆原創示意，不冒充台灣實價調查。

故事前提：

```text
為什麼商品價格常用九結尾？
從二點九九美元與三美元的原論文示例開始：數值只差一美分，左端數字卻從二變三。Thomas與Morwitz二〇〇五年研究描述左位數效應，並指出左端數字與比較距離等條件很重要，不說每個人每次都會誤判。接著把感覺與交易分開：Anderson與Simester二〇〇三年研究在兩家女裝郵購公司的三個實地實驗中看到九結尾提高需求，新品效果較強，促銷文字可能削弱尾數效果。作者認為資訊線索是一種較受支持的解釋，但仍未解開為何偏偏是九與相關信念怎麼形成。最後用Stiving二〇〇〇年的摘要提醒，品質定位與整數價也有研究討論；整數不保證品質，九結尾不保證便宜。回答：九結尾可以影響價格感覺，也可能作為價格線索，實際效果取決於商品與情境。沒有全球固定增幅，也不講收銀機防偷錢的起源故事。
```
