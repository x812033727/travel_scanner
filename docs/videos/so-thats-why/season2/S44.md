# S44 為什麼冷凍庫的冰塊放久會變小？

本集只回答：冰一直放在冷凍庫，為什麼還可能變小？先解釋昇華，再用周圍水蒸氣與包裝條件限制答案。不保證所有設備和容器都以相同速度縮小，也不靠尺寸診斷設備故障或食物安全。
