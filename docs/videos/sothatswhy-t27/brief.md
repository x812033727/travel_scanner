# 日本垃圾桶少？旅客調查說了什麼

用一個原創答題小故事，讀懂日本觀光廳公布的旅客調查。保留垃圾桶困擾這個問題，把排名、比例、受訪範圍和問題內容連起來，不替站主編造旅行經驗。站主於 2026-10-02 指定接著做下一集，依第二季順序製作 T27。

## 大綱選項

### 選項 A：一張回答卡，怎麼變成全國印象（推薦）

一行說明：先揭排名與多數的差別，再以十人原創答題例子拆解受訪者、日期、複選和資料能回答的問題。
開場鉤子：垃圾桶少是第一名困擾，就代表多數旅客都在抱怨嗎？

1. 最多不等於多數：二十秒內給出 17.2% 與「最多困擾項目」的差別，用原創三人回答示意排名。
2. 誰被問到：五座出境機場、4,110 位外國旅客與面訪方法，介紹受訪者和問題的關係。
3. 跨兩年的日期：調查起迄與公布日，用答題、整理、公布的事件順序說明兩種日期。
4. 兩種回答：17.2% 和 43.7% 分別代表的回答；十人例子加入同一人選兩項，分清人數和選項數。
5. 經驗與普查：以旅客感受、地點盤點、歷史研究三種筆記，示範不同問題需要不同資料。
6. 回到垃圾桶疑問：帶觀眾改寫一句容易誤解的分享文字，保留人群、時間、問題，回答開場。

### 選項 B：十個旅客，十一個選項

一行說明：先用十人教學例子揭示複選，再回看官方問卷的困擾排名、日期和受訪範圍。
開場鉤子：只有十個旅客，答案卻可以有十一個勾。

從複選問題出發，先拆人數與回答數，再介紹實際調查的兩個比例和來源範圍，最後辨認調查能回答哪些垃圾桶問題。

### 選項 C：把一則旅行分享讀完整

一行說明：沿著分享文字裡被省略的對象、日期和題目，逐次補回調查資訊。
開場鉤子：一張垃圾桶圖表，少了哪幾個字就會讀錯？

先閱讀簡化標題，再補上「困擾項目」、「這批出境旅客」及「這段調查期間」；中段以複選例子解答比例疑問，最後形成一段完整轉述。
