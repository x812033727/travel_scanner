# T27 原創插畫製作

本集採 1600×900 原生 SVG，全部圖形、匿名旅客、問卷、機場概念圖、日期卡及資料筆記均為本集自行編寫。沒有外部照片、現場訪談畫面、官方截圖、生成圖片服務或付費關鍵影格。著作與本集製作使用權屬專案站主。

色票沿用奶油白 `#F7F0DE`、深藍 `#22344B`、印章紅 `#BF5146`、芥末黃 `#D5A544`。素材只共用繪圖元件；每一景按凍結口播指定構圖、選項、圈選或資料狀態，並保留短 caption。130 個 diagram 對應 93 種語義狀態，沒有相鄰景使用相同狀態。正文切換節奏與最終字幕安全區另由實際時間軸及正常 renderer 檢查，SVG 張數本身不代表實測片長。

## 資料與示意

- 官方比例重繪採固定 0–100% 長條軸；垃圾桶少 17.2% 與沒有困擾 43.7% 在同圖時共用基線和尺度，不繪成互補區塊。
- 十人例子固定一、二、三號選垃圾桶；三、四號選網路；五號選指標；六號選語言溝通；七至十號回答沒有困擾。三號以連線顯示重疊。六人有困擾、七個困擾勾、加四個沒有困擾勾，合計十人十一個勾。
- 所有十人、排名及複選教學示意保留「原創示意，非本調查數據」。教學長條使用人數，與正式調查百分比保持不同場景和標示。
- 五機場只表達收集回答的地點；出境外國旅客與面訪問卷另有概念圖，不把機場畫成困擾發生範圍。網路貼文與面訪回答分開描繪。
- 調查開始、結束、公布分開標日期：2025-11-18、2026-01-13、2026-04-28。日期卡依事件順序排列，圖中明示卡片間距不代表時長。相簿、回答卡沿日曆排列的比喻標原創概念示意，不暗示每一天都有訪問。
- 旅行經驗、街道盤點、歷史研究使用三本不同資料筆記；路線與垃圾桶位置圖皆為原創概念，不提供真實街道位置、數量或歷史起源。密度示意保留同一範圍長度與單位。
