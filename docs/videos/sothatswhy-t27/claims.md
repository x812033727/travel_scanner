## 與企劃不同的地方

採正常大綱判定選中的 A 與有效企劃六章，完整口播稿逐句展開。新增官方附件明示的面訪、複選，以十人、十一勾的原創示例把人數與選項數分開。第三章用照片分享日比喻公布日；第五章用三本筆記分清旅客經驗、地點盤點與歷史問題。原企劃個別章節秒數是配額，實際章節由正常旁白合成後重算。

使用純投影片原創 SVG 圖解，圖片路徑暫為按 scene id 對應的待製作資產；本稿不呼叫圖片供應商。不製作舊企劃裡的 Shorts 或其他語言。正常語速正文及成片各須實測至少480秒，估算不能代替媒體。

## 我懷疑但沒動的事

未新增各城市密度、與其他國家比密度、垃圾桶配置起源、垃圾分類政策、店家代收、前一年變化或任意旅客百分比。43.7% 的沒有困擾不是垃圾桶困擾的互補；旁白不說「多數旅客沒有任何困擾」。沒有用圖形面積模擬不相容的兩半或合併 2,000 則網路貼文分母。
