# 實驗保存規則

`protocol.json` 保存送出給兩個新脈絡子代理的完整文字與預先可核對答案；`plain.json`、`structured.json` 是真實的一次輸出，海報 HTML 與其中的 poster_html 相同。不得因為結果不夠戲劇化改寫回答。

算式與三題皆由兩組答對。字幕只可說明本次結果。精確後端模型版本未由工具提供，請保留 unknown，不標稱 GPT、Claude 或 Gemini 某個版本。

這次三個任務打包在同一則請求裡，所以不能排除前題影響後題；將來要做評測型結論，需將每個任務分開、預先指定多題與重複次數。海報由 HTML/CSS 產出，兩張都含虛構活動聲明，不可被用作真實活動公告。

模型只做過一次生成。之後要求子代理把自己的原始回答落地，是保存步驟，不是重新採樣。
