## 審查者關係與證據界線

審查者也參與了 structured 的原始輸出與原樣存檔，因此這份報告**不是完全盲評，也不是由完全未參與輸出的第三方所做的查核**。`independent Codex review` 是本次分開執行的查核工序名稱；算式與文字存在性可由封存檔重現，設計偏好不由審查者替觀眾判勝負。預定另由 contentagent 交叉覆核；截至本報告，該覆核尚未納入證據。

本次未修改封存實驗或生產程式。查核使用 JSON 解析、Python 標準函式庫 HTMLParser、人工對照與獨立重算。HTML 文字檢查限定於 body 的文字節點，不以 title 或 aria-label 代替海報正文。跨元素的文字節點按順序合併並正規化空白。

plain 使用 `<h1>MOKAAIR<span>AI 夜市實驗室</span></h1>`，並以 CSS 將 span 設為 block。其標題在畫面上分行；合併標題文字節點後為「MOKAAIR AI 夜市實驗室」。只在 HTML 原始碼搜尋完整連續字串，會錯誤判成正文漏字。本報告沒有這樣判定。

兩份原始碼均有 800×1000 的海報尺寸、body margin 0 與 sans-serif 字型設定；插圖以 HTML 元素及 CSS 幾何形狀構成。檢查未見 script、img、iframe、外連資源屬性、CSS 外部資源或 emoji。這些是原始碼層的檢查結果，不能據此證明所有文字均在實際渲染範圍內。

## 待視覺驗證

這一輪尚未打開渲染畫面，未驗證字型實際排版、文字裁切、元素碰撞、800×1000 邊界、手機縮小後的可讀性與閱讀順序。

plain 的原始碼將 html、body 與海報固定為 800×1000，沒有窄螢幕 media query；structured 具有寬度小於 800px 時的 media query 與 cqw 單位。這項原始碼差異可確認，但還不能寫成「structured 在手機上已驗證可讀」，也不能以它判定審美勝負。後續應在相同字型環境、相同呈現尺寸並列兩張海報，另檢查手機呈現。
