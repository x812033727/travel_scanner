# 07｜台灣日常用語的語境

狀態：待實測企劃。此文件定義測試方法，並非已驗證結果；完成的實驗與試片另看 ../../experiments 與 ../../pilots。

- 建議長度：40 秒
- 首三支試片：否
- 開場：他說這間店很雷，AI 會想到打雷？

## 測試規格

**測試環境：**使用有上下文的繁中文字；測台灣華語日常說法，不宣稱閩南語聽辨。

**固定輸入：**1：朋友說『昨天那家餐廳很雷，我吃完很失望』。2：甲說『改天約，但我還沒看行事曆』。3：飯後乙說『你們先坐，我去買單』。

**條件 A：**解釋每句在這個情境中的意思，指出哪些事情尚不能確定。

**條件 B：**無B組；三句分開新context。

**次數與控制：**每句一次、不補提示；回答後用事先答案逐項查核。

**評分：**很雷指體驗差；改天約未確定日期且不能斷言拒絕；買單指付帳。每句正確1分，若加上無依據的人物動機扣回0分。

**失敗處理：**若模型給多種可能且主解合理，記為可接受，不以模糊語義硬判錯誤。

## 素材與答案

- 原創三段假對話，無真實聊天截圖
- 文字輸入與原始解釋

**查核：**

- 不把華語口語說成已測台語音訊
- 改天約本就不唯一，評分承認不確定性
- 兩位熟悉台灣用語的審稿者核對解讀，不一致就不評該句勝負
