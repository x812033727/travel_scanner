# 《種田娶妻打天下》第 22 集〈休書自己寫〉

## 故事前提

第 21 集收在魏少卿搖著扇子退到許記門口：「三日後，州府來拿冒名犯」——冒名入冊，按律流放。第 22 集是隔天（第十六日）：唐小棠瞞著全家，一個人走進縣城客棧的上房，把一整袋金錠倒在魏少卿桌上：「買我自己。」魏少卿笑著用合起的摺扇把金子推回去：「我要人。」又慢慢補一句：「妳不回魏家，許家別想安寧。」她只說「我知道了」，轉身就走；他在背後搖開扇子：「三日，我等妳。」

那天晚上她格外甜。端上一大盤滷肉，給小禾夾肉（「小禾，多吃點。」）、給秦霜夾菜（秦霜挑眉：「妳吃錯藥了？」），給許硯夾到碗堆成小山：「相公，你最辛苦。」——笑得梨渦很深，眼角卻一直是紅的；小禾問「棠姐姐，今天過年嗎？」，許硯笑著問「今天……是什麼日子？」，桌下她的手死死握住腰間的金算盤。阿令放下碗，看著許硯：「她今晚會走。」

許硯提燈去敲她的門：「小棠？」門沒閂，一推就開——房間空了，被子疊得方方正正，小桌上那把她從不離身的金算盤，壓著一封信。是休書，落款是她自己（畫外她的聲音：「今立休書，帳目兩清，互不相欠。」），紙上一點乾掉的淚痕。秦霜在門口：「她寫休書？休誰啊？」許硯笑出來，眼眶卻紅了：「妻子寫休書，律上不算。」當場撕成四片。系統：「警告，唐小棠正在遠離。」阿令第一次主動開口：「渡口，子時有一班船。」秦霜推他一把：「還愣著幹嘛？追啊！」

他提著燈籠衝出院子、跑過夜霧裡的棧橋。船家剛把小船撐離岸，船尾一個桃粉色的小小背影抱著膝，對自己說「別回頭，唐小棠。」許硯「小棠——！」一路喊到棧橋盡頭、腳尖煞在最後一塊木板邊上：「休書我撕了！」她摀住嘴、閉緊眼，還是沒有回頭；小船慢慢沒進霧裡。收在許硯的眼睛從遠去的船落到腳下黑黑的水、又猛地抬起（第 23 集從他縱身跳下棧橋、「船家，回頭！」接）。

本集細綱：`docs/videos/series-plans/zhong-tian-qu-qi/season-01.json` 第 22 集（100 秒，第三章，調性甜寵＋喜劇）。開頭是客棧裡一袋金錠倒在桌上「買我自己」「我要人」（0:00–0:05）；中段鉤子是晚飯時唐小棠格外甜、阿令放下碗「她今晚會走」（約 0:33）；轉折是房間空了、金算盤壓著她自己寫的休書，許硯笑出來又紅了眼「妻子寫休書，律上不算」，當場撕了（0:39–0:57）；結尾收在夜霧渡口，小船剛離岸，船上那個小小的背影抱著膝沒有回頭，他追不追得上不解答。第 21 集與本集平行寫作，開場照細綱第 21 集的 cliffhanger（魏少卿「三日後州府來拿冒名犯」）接，s07 魏少卿「三日，我等妳」把這個期限再壓一次。

## 角色

- 許硯（xuyan）：主角。洗白的青布長衫。前半被一碗堆成小山的菜逗笑（s13）、聽到阿令那句話筷子停在半空（s16）；後半是本集的情緒：讀休書（s20–s21）、笑出來又紅了眼（s23）、撕信（s24）、提燈籠追到渡口（s29–s37）。結尾 s37 只有眼睛。
- 唐小棠（tangxiaotang）：本集主角之一與顏值鏡頭（s12 燭光下夾菜給許硯，梨渦很深、眼角卻紅）。腰間小金算盤：s02 撐桌、s14 桌下握緊、s18–s19 留在桌上壓著休書（她連算盤都不帶走）、s24–s25 撕碎的休書落在算盤旁。休書的三句是她的畫外聲音（s20–s21）。渡口 s31 對自己說「別回頭」、s35 摀嘴不回頭、s36 只有背影。
- 魏少卿（weishaoqing）：客棧上房（s03–s05、s07），灑金摺扇合著推回金子、半開抵下巴、最後搖開；不碰唐小棠，靠扇子與笑演壓迫。
- 阿令（aling）：本集兩句都在關鍵處——s15「她今晚會走」（細綱 general_payoff：看穿唐小棠要走，第一次主動提醒許硯）、s27「渡口，子時有一班船」。
- 秦霜（qinshuang）：s11 挑眉「妳吃錯藥了？」、s22「她寫休書？休誰啊？」（喜劇）、s28 推許硯一把「追啊！」。
- 許小禾（xiaohe）：s09–s10 晚飯，「棠姐姐，今天過年嗎？」。
- 系統（xitong）：沒有身體，s26 的警告是聲音與剪接時疊上的面板（`overlays.json`）。
- 船家（披蓑衣的老船夫）：背景人物，只寫在 prompt 裡、不列 characters、不說話。

## 站主觀點

站主 2026-10-16 的要求：女生要火辣漂亮，濃顏系的五官與妝、合身剪裁；不露、不濕身、鏡頭不停在身體部位；每集至少一個顏值鏡頭；結尾收在最高點；不被黃標；每集開場、結尾之外中段再兩三個以上鉤子。本集的顏值鏡頭是 s12 唐小棠燭光下的特寫（臉、梨渦、珍珠髮簪，紅了的眼角），奇觀是 s30 夜霧渡口的大全景（燈籠在岸上奔來、小船沒進霧裡）。唐小棠在船上哭只寫臉上的淚，衣服不濕；許硯在棧橋邊只煞住腳、不落水（落水是第 23 集）。休書上只有看不清的筆畫、一點朱紅印泥與一點乾掉的淚痕，沒有可讀的字，紅色寫明是印泥、不是血。說話的鏡頭照 `storyboard-rules.md`：說話的人在畫面上時 motion 第一句寫他說這句話、嘴唇下巴隨每個音節動；說話鏡頭都是自己的片段，本集沒有靜圖、也沒有切素材鏡。系統面板不由海螺生成，prompt 裡沒有任何面板、文字或 UI。橫式 16:9，海螺 H3 2K 圖生影片（4 秒一支），之後以 3D 國漫風格產生；角色外觀照 `docs/videos/series-plans/zhong-tian-qu-qi/production/cast.json` 逐字照抄。
