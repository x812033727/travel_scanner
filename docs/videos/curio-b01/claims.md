# B01 旁白與出處對照

每一句帶事實的旁白對到 [`../history-curiosity/topic-checks/B01.md`](../history-curiosity/topic-checks/B01.md) 的一列（#n）。
查核日期一律 2026-10-31；網址在 `video.json` 的 `sources`。流傳的說法（扁擔挑風琴翻過箱根、音叉握柄像車輪）在旁白裡標成「據說」「相傳」「流傳一個說法」；
只有單一來源的（螺旋槳產量與員工數、本田宗一郎幫忙設計加工機、功學社持股 49%、功學社早年代理鋼琴與音樂教學）旁白說出是誰說的。

不說紅蜻蜓是因為車身紅、不說山葉是山葉機車的母公司、不說 2017 年的設計展、不說台灣山葉機車是台灣或功學社的公司、
不講台灣山葉機車確切的成立年、不講河合小市、不講商標歸屬或品牌費。
