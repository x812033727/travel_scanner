# X07 GoPro Karma｜製作、上架交接

**目前交付的是已通過三份獨立審查的前製包：逐句稿、分鏡、來源矩陣、Treatment、兩支 Shorts 剪輯稿與報價關卡。** [來源審查](reviews/source-review-v7.md)及兩份[敘事盲評 A](reviews/blind-a-v7.md)、[敘事盲評 B](reviews/blind-b-v7.md)均綁定本版稿件 SHA 並通過。 尚無本集付費生成的圖片、繁中 TTS、實測時間軸、配樂、繁中 CC、縮圖、`final.mp4`、YouTube 上傳包或影片 ID，因此也沒有可點的 Studio 片尾連結。已配對影片工具可讀取進度；本集須先完成全項報價與正式品牌素材選定，再交工具進入媒體製作及 QA，不能把 repo 檔案冒稱成成片。

## 鎖版到成片

1. 本版 `video.json`、`shorts.json` 已鎖 SHA；另一位來源審查者逐句及原生卡核對了 [SEC 原件](source-notes.md)，兩位未看來源矩陣的敘事讀者各自只讀 [逐句稿](script.md) 盲評，均 PASS。改稿或卡片必須重驗受影響項；`lint` 必須保持 0 錯誤、0 警告。
2. 讀 [US$25 全項報價關卡](production-quote.md)，先用乾跑取得當期供應商價格、最壞重試與稅額；超上限或缺價不得付費。通過後用 `Gemini Sulafat` 製作台灣華語單人旁白，逐句轉錄及對稿；量實際 30–60 秒濃縮開場與**至少 8 分鐘實質正文**，不把 5 秒片頭或 21 秒片尾充作正文。
3. `format: drama`、MiniMax `image-01`、精確 `look: {"preset":"cute-mystery"}`；超過七成正文場景須為插畫。插畫為匿名無標誌概念示意，不得描繪未有證據的墜毀、傷者、真實店面或商標。原生卡才顯示年份、金額、來源與排名範圍；用一首輕快、好奇、微懸疑、無人聲的正文配樂。圖片評審及人工觀看均確認畫面不與來源相反。
4. 正式品牌素材必須是站主選定的 **5 秒片頭**與 **21 秒 v4 結束畫面片尾**，依 [BRANDING.md](../BRANDING.md) 採用。時間順序：第一章 30–60 秒濃縮開場 → 5 秒片頭 → 其餘五章正文及三句片尾口播 → 21 秒動畫。結尾三句回答開場問題、提出與故事相連的留言題、給訂閱理由；旁白不點名下支影片。
5. 合成後產出可關閉的**繁中 CC**，不要燒進 16:9 長片畫面。檢查完整音畫、句子順序、字卡分母、縮圖與上下架文案、片頭片尾格數及實際音量，再走 QA、成片核准、上傳包。英文、日文、韓文配音或字幕由成片後既定選語流程處理，不因這份前製稿自動產生。
6. 長片核准後，按 [兩支 Shorts 剪輯稿](shorts.md) 用主片逐字句與關鍵影格做 9:16 `from-episode`，使用相同頻道聲音；若需再生成語音或複查，費用計入 [總帳](production-quote.md)。逐支量 25–55 秒、驗字幕安全區及 Shorts QA。若最終逐句稿變更，依新的句 ID 調整剪輯表，不沿用未查核的舊句。

## YouTube 的真正連結

- 長片縮圖左上以**橘色大字 `GoPro`** 寫品牌名，主字以鎖版稿為準；品牌字與數字都由原生後製文字呈現，圖不畫商標或排名圖。YouTube 標題、說明與一手來源 URL 以 [video.json](video.json) 的 `youtube` 欄位為準，審過後再打上傳包。
- 21 秒片尾的兩個影片外框與訂閱外框只是動畫，**可點連結必須在 YouTube Studio 設**。長片上傳取得真實 ID 後，於 Studio「片尾」從模板影片 `oxEtlA8GWas` 匯入「最符合觀眾喜好」影片｜訂閱｜「最新上傳」影片，將三個元素開始時間拉至全片尾段第 4 秒（全片結尾前 17 秒）。在 Studio 預覽與已上傳影片實點三項，紀錄影片 ID、URL 和檢查時間；不要把模板 ID 當成新片 ID。
- Shorts 上架後各自設定「相關影片」指向本集已公開長片，實點驗證；本包沒有長片 ID，因此沒有可填的目標連結。外部引用可以使用真實 SEC URL；不得用尚不存在的 YouTube URL 佔位。
