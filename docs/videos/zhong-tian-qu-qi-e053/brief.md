# 《種田娶妻打天下》第 53 集〈渡口截車〉

## 故事前提

第 52 集收在州府大堂：杜鐵撞進來，「囚車天沒亮就出了北門」「押車的不是州府的人」「出了城，人就沒了」。第 53 集直接上路：北門外的官道上，阿令勒馬原地一個迴旋，從馬上朝許硯伸手：「上來。」一把把他拉上馬背（細綱的 hook）。許硯死抓著馬鞍：「等等，」「我不會騎馬！」阿令回頭，嘴角極輕地一動：「抓緊。」棗紅馬衝出城門，許硯一手往天上一舉：「衝——！」他在馬上一路顛：「阿令，」「妳在哪學的騎馬？」阿令頭也不回：「別說話，」「會咬到舌頭。」（她不回答。）系統：「強制任務：救回秦霜。」「剩餘時間：兩天。」王二牛騎著騾子、帶著四個柳溪少年追上來：「硯哥！」「柳溪的兄弟來了！」「阿令姑娘騎太快，」「我們追了一夜！」阿令看路上的新車轍：「車轍是新的。」「往渡口去了。」

北邊渡口的淺灘上，囚車停在齊膝的河水裡，秦霜在粗木籠裡搖著木欄，十幾個穿皂衣、帶刀的打手圍成一圈。鄧押司拍一下籠欄：「天黑前過河。」「到了對岸，就沒有這個人。」秦霜瞪著他：「你們不是州府的人。」押解頭目鄧押司把過長的刀整把拔出：「州府辦差，」「閒人滾開！」王二牛吞口水：「十幾把刀……」「我們才幾個？」（細綱的衝突。）許硯解下綁在馬鞍邊的紅纓長槍：「不用打贏，」「把槍送到她手上就好。」秦霜看見他：「許硯！」棗紅馬衝進淺水，許硯把槍高高拋出去：「秦霜——接著！」（細綱的 mid_hook，0:55 左右）秦霜在籠裡一把接住：「來得正好。」許硯握拳：「接到了！」她用槍桿撬斷籠門，躍進河裡炸開一片白浪，一槍平掃，兩把刀同時飛上半空落進河裡（細綱的奇觀）。王二牛掄扁擔掃倒一個：「看棍！」「硯哥，」「我打中了！」秦霜立在齊膝的河水裡，高馬尾甩出一道水弧（細綱的顏值鏡頭），一槍對三個，一個接一個挑落水裡，槍尖對準鄧押司：「現在，」「換我押你。」系統：「強制任務完成。」

許硯站在水裡高舉追回令：「州府追回令！」「誰還敢動？」打手們把刀放低、互看一眼。鄧押司一把抓住阿令的馬韁：「我知道她是誰。」許硯一步擠進他和馬之間：「她是誰，」「她自己說。」（細綱的 turn。）馬上的阿令握韁的手鬆了一點，系統：阿令好感五十九。秦霜一槍敲在鄧押司的指節上：「手拿開。」鄧押司一路退到水邊的木筏，從衣襟裡慢慢抽出一封摺舊的信：「放我走，」「給妳爹的信。」秦霜的臉一下子白了：「我爹的……」「信？」許硯放下追回令、退半步：「秦霜，」「妳決定。」鄧押司在畫外低笑：「要信，」「就放我走。」秦霜的眉頭狠狠擰緊（細綱的 cliffhanger，choice，「秦霜要放走仇人，換爹的信嗎？」）。

本集細綱：`season-01.json` 第 53 集（120 秒，第一季第六章第三集，調性沙場＋權謀，lead_arc wins）。satisfaction 兩個都入鏡：rescue（s20–s25）、counter_kill（s25–s30）。general_payoffs 全部入鏡：秦霜被救出（s22–s25）；王二牛和柳溪少年們第一次跟著許硯出村打仗（s09–s10、s17、s27）；阿令聽見許硯拒絕從別人嘴裡聽她的身分（s35–s37）。
