# 正式站匯入交接

截至 2026-10-20，五集已完成企劃、逐來源重查、獨立雜湊收據與正式編譯。匯入檔是本目錄的 `stories.json`（約 68 KB），不是 `stories.draft.json`。目前沒有任何一集匯入或製作成片。

## 正式工人開始前的兩項前置

本工作區另修正了 `tools/video/automation/story.mjs`：此系列的精確 `cute-mystery` 外觀會用奇聞檔案局的 `CURIO_MUSIC`，且新系列在付費畫圖前檢查插圖至少 70%、連續卡片最多三張。**先把這段程式變更部署到正式故事工人，再匯入企劃清單**；目前只在工作區修改與測試，不能假設正式站已套用。若先匯入，正式工人可能使用舊配樂與舊畫面檢查開始製作。

## 需要後台帳號完成的匯入操作

1. 程式變更部署後，使用有 `content.manage` 的帳號登入正式站 [影片後台的故事分類](https://mokaair.com/zh-TW/admin/videos?tab=reviews&category=story)，找到「匯入企劃清單」。這項權限來自後台匯入 API；已配對的影片工具權杖沒有管理員匯入權限。
2. 選擇本目錄的 `stories.json`，或貼上完整內容。畫面應解析為 **5 個故事，作品 `brand-stories-new-20261020`**。「只匯入前幾個故事」留空；「建立作品時的每日支數」選「照檔案」（檔案設定為每天 1 支）。
3. 按「試跑」。預期 `accepted=true`、新增 5、更新 0、拒絕 0，且作品會按檔案建立。這裡必須看**正式站**的報告：本機的相同結果不能證明其他系列沒有排隊同題。若正式站報告有拒絕、同題或非預期更新，暫勿寫入，保留報告以便換題及重查。
4. 只有正式站試跑確認上述結果，才按「確認寫入（新增 5、更新 0）」。寫入後系列會有五集待做，依正式工人的排程與關卡逐集製作。

正式站上次成功唯讀預查已列出 54 支漫劇影片，沒有這五集的新影片 slug；指定系列回 404。此查詢不會列出其他系列尚未開工的企劃，所以第 3 步仍必須執行。正式站唯讀設定顯示自動化與故事配樂已啟用；實際工人是否開始仍受每日限額、同時製作上限與待上架緩衝限制。此後雲端環境對 `mokaair.com` 的 CONNECT 回 403；已保存網路設定草稿但尚待發布，代理暫時不能再讀正式站狀態。

匯入成功後，再以已配對影片工具唯讀核對系列與首集狀態，依真實工人產物核對劇本、事實、插圖比例、配樂、時長與成片。每集標題應以 ` | 品牌故事` 結尾。五集排完後要繼續做新的題目，仍需先完成新批次查核與匯入；不能把這五集的查核直接套用到新片。追加時檔案必須包含原五集與新集，集數連續；正式站既有系列的 `planned_episodes` 不會被匯入檔更新，追加前要在後台調高，若已完結也要恢復進行中。
