# App 01：獨立原生錄製清單

狀態：**pending_capture**。本課只讀建立基線，不修篩選；03才做功能。目標12–18分鐘，正文至少8分鐘。共用01教材與真值，使用全新的01-app副本、App聊天及獨立證據。

目前工具明確禁止原生電腦控制；沒有實際App畫面，不模擬按鈕、選單或模型回覆。下列是操作runbook，不是已錄製結果。官方來源2026-10-11已實際開啟：[Projects and chats](https://learn.chatgpt.com/docs/projects)、[Integrated terminal](https://learn.chatgpt.com/docs/integrated-terminal)、[Features](https://learn.chatgpt.com/docs/features)。錄製時用當日畫面填入實際入口與標籤。

## 先備及準備

- 01教材完整ZIP，留新start、reference和challenge副本；先核對五檔app.js/core.mjs/core.test.mjs/index.html/style.css，無npm依賴。
- 本機Node與Python能執行，App登入由操作者完成；記App版本、OS、模型/模式與時間，不錄驗證碼、帳號、金鑰或私人無關專案。
- 明確使用本機專案，確認目前實際路徑為01-app的start，不是repository、reference、CLI錄製副本或遠端環境。
- 開始前保存五檔SHA-256。錯誤或未能執行都留原紀錄，不重錄成假成功。

## 完整送入App的提示

使用本課baseline-prompt.txt的完整文字，送在原生專案聊天輸入處；不要貼在終端機，也不向另一個CLI聊天轉送。實際入口名稱需由當日UI確認。提示要求讀五檔、實跑test、觀察/假說分開、HTTP說明與下一輪目標/範圍/驗收；不修改任何檔案，不修刻意失敗。

工具若被權限或環境阻擋，記實際錯誤及NOT RUN；沒有工具結果就不能填2/1實測。讀者可親自重跑，但必須標其來源，不能說是App模型自動執行。

## 讀者自己操作的終端機與瀏覽器

在01-app起點的終端機：

```powershell
Get-Location
Get-ChildItem -Name
node --test core.test.mjs
$LASTEXITCODE
py -m http.server 4173 --bind 127.0.0.1
```

瀏覽器輸入 `http://127.0.0.1:4173/`；兩筆、一筆完成→未完成篩選起點仍兩筆，列為03待做；新增和完成→重新整理仍保留。停止服務用Ctrl+C，再換reference副本，用同一個來源重設練習專用資料；不要清除其他網站儲存。reference3pass為作者答案，不宣稱App本輪生成。

## App版可成立的學習成果

1. 觀眾只靠本版材料，能選對本機專案、正確送只讀要求、查看並判讀工具结果。
2. 分清原始2/1、作者reference3/0、模型未實作；知道核心測試無法替代網頁驗證。
3. 完成一次真實排錯與兩版獨立比較，再交03的範圍及驗收。不能用CLI版補缺漏。
