## 同章快取評估與修訂

`curio-episode` skill 優先考慮同章合格圖退路。已逐一查看四個目標鏡頭所在章節的選圖、旁白與 `data.camera`；[QA3 候選](keyframes-qa-3.md#同章退路與付費界線) 的畫面有的缺關鍵動作，有的緊貼重複，而且**沒有一張在不改目標鏡頭運鏡的情況下可安全命中圖片快取**。圖片快取鍵含組合後的 prompt／camera／seed；只抄來源提示詞但保留目標運鏡會產生新圖片請求。即使複用同一圖，Gemini 逐鏡評審仍可能另收費。因此沒有把候選圖冒充成已完成的零成本退路。

| 鏡頭 | QA3 已證實問題 | 此版提示詞的最小變更 |
| --- | --- | --- |
| `brief-window` | 原選圖上下黑邊；大開關動作也不清。 | 讓匿名成人**穩住**箱式接收器的開關，無字錶針停穩；房間牆面填滿畫框，避免另加戲劇式邊框。 |
| `more-marks` | 三張分離紙直接反轉旁白「同一卷紙」。 | 從**一個紙卷**拉出一條相連紙帶，兩組墨跡在相連紙面上相隔。 |
| `line-of-sight` | 波束射向畫面上方而未碰地球儀。 | 去除人物與檯燈兩個搶光源的物件，左側星體模型的**單一道光落在右側地球儀表面**，落點明亮。 |
| `beam-away` | 光從檯燈而非星體來，且人物／動作未過。 | 同一左右關係下，左側星體模型的光**朝左離開桌面**，右側地球儀在陰影中，兩者間有暗處。 |

這些是可供一次受控試圖的文字準備，不把第三輪提示詞當成已驗收圖片。系列 skill 對反覆重畫有停手機制；主代理若判定本集已達可再修稿的上限，應改評估卡片或由站主裁定，不因帳上仍有額度而自動擴批。
