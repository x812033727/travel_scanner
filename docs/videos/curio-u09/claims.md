## 不使用的說法

| 不使用 | 原因／替代 |
| --- | --- |
| 劍橋收到「外星人的訊息」。 | 將待驗假設誤當結論；用「神祕訊號」「當時不熟悉的規律脈衝」。 |
| 8 月 6 日她已看到每 1.337 秒一次。 | 把初始紀錄與 11 月 28 日快紀錄合併。 |
| 每晚固定鐘點傳來一模一樣的訊號。 | 恆星時不是民用鐘點；脈衝強度與可觀測性並非恆定。 |
| 所有人都認真相信外星人，或所有人始終完全沒想過。 | 當事人回憶的視角不同；區分暱稱玩笑與待驗假設。 |
| 一量都卜勒就證明宇宙沒有外星人。 | 觀測只限制所測模型，沒有這種證明能力。 |
| 第二顆一出現就嚴格證明第一顆是中子星。 | 多個相似來源使自然族群解釋更有吸引力；物理模型仍待形成。 |
| 1968 年 2 月論文宣布快速自轉中子星。 | 原件寫 oscillations；旋轉解釋必須另接 Gold。 |
| 諾貝爾獎證明誰偷走了誰的成果。 | 未由本集調查證成，而且偏離訊號身分主線。 |
