## 寫稿時逐項守住的邊界

| 可能誤說 | 正確用法 |
| --- | --- |
| 「2008 年 Garmin 七成收入都是車用導航機。」 | G2/G3 的逾七成是 **automotive/mobile 事業**，其中還有手機／軟體等產品；nüvi 產品系列約占**全公司** 64%，可單獨說。 |
| 「手機在 2008 年已讓公司倒退。」 | G2 在 2008 用 **could**；G5 在 2011 用 **has halted**，且那是公司風險披露的因果判斷。2008–2010 數字的變化還同時受市場成熟、售價、車載導航與景氣等因素影響，無法拆出手機的份額。 |
| 「nüvi 從 64% 掉到 48%，所以汽車事業只剩 48%。」 | 64%／48% 是 **nüvi 產品線／公司總營收**；2011 汽車／行動**事業**約 58%，分母相同但分子不同。2008 的 64% 與 2011 的 48% 也不是連續每年都下降：G5 列 2009 約 63%、2010 約 54%。 |
| 「2010 比 2008 年少了 19%。」 | G4 的 -19% 是 automotive/mobile **2010 相對 2009**；2008→2010 要直接對照 G3/G4 的 US$2,538.411m→US$1,668.939m，不借用年比百分比。 |
| 「Forerunner 610／910XT 或某款手錶救活 Garmin。」 | G5 只能證明 2011 年推出及當年 Fitness 成長 24%；G6 證明 2025 五事業的總量，不能把十多年結果分配給個別型號或單一決策。 |
| 「2011 年已經決定 2025 年五部門的排名。」 | 本包的 G5 與 G6 相隔十四個財年；G6 的 2024 對比列也不能補出中間每年的交叉。可以報兩端文件的結果，不能編造換位發生的日期、內部決策或單一成因。 |
| 「舊導航機事業從 73% 縮到 2025 的 Auto OEM 9.2%。」 | 兩年**部門定義不同**，且 2023 大頁顯示個人導航機現列 Outdoor；G6 的 Auto OEM 是現行車廠供應，不能做連續市占或部門衰退圖。 |
| 「72.45 億是淨利，代表靠手錶賺兩倍。」 | G6 7,245,519 **thousand USD 是 2025 全年營收**，換算約 72.46 億美元；2.07 倍是與 G3 2008 **全年總營收**的名目美元比較，並非淨利或手錶營收。 |
