# S24 阿基米德、金冠與「找到了」：來源查核

查核日：2026-10-19。金冠與浴盆的整段古代敘事出自**同一位作者維特魯威**《建築十書》第九書序言 9–12 節；英文譯本和拉丁原文是同一作品的兩種文本，不能當兩名獨立目擊者。維特魯威是在阿基米德之後記述此事，這不是浴場或王宮當場留下的紀錄。普魯塔克〈馬塞勒斯傳〉另述兩人合作的脈絡，並未在所讀段落講皇冠。

## 能說與不能說

- `E8014–8021`／`L27277–27281`：希羅委託工匠做供奉神明的金冠，交出準確重量的金；交貨的皇冠做得精美，重量相符。故事沒有交代皇冠精確質量、形狀、尺寸或工匠名字。
- `E8023–8027`／`L27283–27286`：**有人指控**工匠取走金、換進同等重量的銀；希羅請阿基米德想辦法。指控在測試前尚不是已證實的結果。
- `E8027–8033`／`L27286–27292`：維特魯威敘述阿基米德進浴盆，隨身體浸入而見水溢出，歡喜地奔回家，路上反覆喊希臘語「找到了」。拉丁本直接保留希臘字 `ευρηκα ευρηκα`，因此那兩聲不是英譯者自行加的；**仍只是一位後來作者的傳述**，不能證明阿基米德在場確實喊了。
- `E8035–8054`／`L27294–27310`：方法段拉丁文以 `dicitur`（據說）開頭。故事說他做兩塊與皇冠**等重**的純金、純銀塊，容器每輪裝水到邊，分別放銀、金、皇冠；取出樣本後按補到同一水位所需的水量比較。銀塊比等重金塊排出更多水；皇冠比等重金塊排出更多水。維特魯威據此說摻銀與工匠偷金被揭露。
- 物理推論：物體完全浸沒時排開水的體積對應它的體積；固定重量下，銀比金佔更多空間。若皇冠比等重純金塊排水多，皇冠的體積不符該純金參照，與先前摻入銀的指控相合。**單憑這個差異，不能唯一辨認哪種材料造成差異**；《建築十書》未報實際溢水數字、量器精度或銀的比例，也未提供可核對的當場實驗紀錄。影片不把方法說成已現代重做或證明口號真實。
- `P19092–19097` 說希羅請阿基米德把幾何思考變成能實用的機械。該段至 `P19131` 沒有皇冠、洗澡或喊聲。這只能說明本集查到的另一部古代傳世文本**沒有在該段補上現場證人**；普魯塔克的沉默不能證明維特魯威的浴盆故事是假的。
- 這是**溢水體積比較**，不是「把皇冠放水裡再秤變輕多少」；不要把後者寫進這段文本。方法需要每次回到同一滿水起點，這點在 E8040–8042、E8045–8051／L27296–27308 可見。影片只說邏輯與記載的操作，不聲稱古代量測必然達到某精度，也不聲稱絕不可能。

## 畫面邊界

用 `cute-mystery` 的可愛插圖：金冠、秤、浴盆、滿水容器與量杯是幫助理解的示意，不畫成維特魯威所見的實物。喊叫段可畫水面上的上半身、裹身屏風或背影，不靠裸體細節吸引觀眾；原文的希臘字如果上畫面，應由後製文字呈現，不交給圖片模型畫。浴場、王宮和作坊的面貌都不是可考的重建。不得使用付費插圖或語音，直到稿子與獨立盲讀關卡完成。
