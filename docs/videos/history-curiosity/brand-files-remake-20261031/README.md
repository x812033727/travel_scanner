## 規則差異

分兩層：這三支當時照什麼做（都早於 2026-10-25），以及就算同一天做，品牌故事和奇聞檔案局還差在哪。

### 第一層：舊片的規則 → 2026-10-25 起的規則

這一層兩個系列共用（`channel-review-20261025-story-series/README.md`）。

| 項目 | 舊片當時 | 現在 |
| --- | --- | --- |
| 長度 | 10 分鐘，正文約 2,100–2,600 字 | 13 分鐘，正文約 3,500 字 |
| 語速 | 同期量到約 3.3 字／秒 | 目標 4.5 字／秒 |
| 開場 | 一個場景＋三到四個預告句 | 利害 → 場景 → 最多兩個預告 → 一句承諾句 → 問題 |
| 口吻 | 唸一份資料，同期的片「你」只有 0–4 次 | 每章至少一句「你」、一句旁白自己的反應；每千字少於 2 個「你」時 lint 警告 |
| 字幕 | 不燒，只有 CC | 奇聞檔案局燒繁中字幕，其他語言 CC（10-31 定案） |
| 縮圖 | 深色小字＋標籤膠囊 | layout d：圖滿版、黃字黑邊大標、白字副標 |
| 標題 | 平靜的問句 | 名字在前 6 字＋利害詞＋數字＋問號 |
| 盲評 | 舊題目 | 系列版題目 `STORY_SERIES_PANEL_QUESTIONS` |

語速、字幕、「你」的數字量自同期別的集數（H01 v2、S01、C01），這三支本身沒有重量。

### 第二層：品牌故事 → 奇聞檔案局

畫風（`cute-mystery`、`image-01`）、45 秒一個鉤子、配樂、片頭片尾、開場五步都一樣。真正不同的是：

| 項目 | 品牌故事 | 奇聞檔案局 |
| --- | --- | --- |
| 片子在講什麼 | 一門生意的因果主線，六章（hook、origin、idea、engine、turn、now） | 一份檔案：流傳的版本 → 紀錄 → 目前最站得住的解釋 |
| 收尾 | 回答開場的問題＋留言題＋訂閱 | 蓋「存檔」或「未結」章＋留言題＋訂閱 |
| 查核 | 匯入前由第二個人查企劃，工人再逐章查核、聽眾審稿 | 大綱由站主選，正式稿再獨立查核與盲評 |
| 站主關卡 | 免關卡，工人自動往下做 | 大綱、旁白、分鏡、成片都等站主看 |
| 標題與清單 | 網站自動補「｜品牌故事」 | 標題自己寫「｜奇聞檔案局」，類別用 `explainer` |
| 縮圖 | 左上大字公司名（`thumbnail.brand`） | 沒有這個欄位，公司名要放進 `headline` |
| 圖裡的名字 | lint 擋提示詞出現 `names` 裡的品牌與人名 | 只有撰稿規則寫不畫商標，**lint 不擋**，要人工注意 |
| 真人 | 一般化，不對應真人長相 | 過世 70 年以上可畫卡通，其餘不畫本人 |
| 比例 | `story-everyday-*` 另有規定 | lint 硬擋：插圖至少 70%，連續卡片最多 3 張 |
| 備份資料夾 | 依 slug 進「品牌故事」 | 依 slug 進「奇聞檔案局」 |

三支的真人界線：Ray Dolby（2013 年過世）、Min Kao（在世）、Gary Burrell（2019 年過世）都不畫本人；
Michelin 兄弟（1931、1940 年過世）可畫卡通。

## 重製計畫

**路線：本機漫劇格式，slug 用 `curio-w0N-*`，旁白與插圖走網站的頻道聲音和 MiniMax**，跟 S 軸的做法一樣
（skill `curio-episode`「主機不能用、要在本機從零做」與 §在雲端環境做旁白與插圖）。不走主機後台的原因：

1. 網站沒有「奇聞檔案局」這個類別。系列是靠 `curio-` slug 認的（lint、備份資料夾、盲評題），主機單集的 slug 是 `one-off-…`，lint 的系列檢查和備份分類都不會生效。
2. 主機 `MYSTERY` 只認 H、M、P、U、L 五軸，開場也寫死歷史懸案等題材；加新軸要改提示詞、部署，部署前主機還不能有未完成的 cute-mystery 單集（S、F、G 兩張票也還沒做）。

舊片不能改 slug 也不能沿用：稿子要從 2,100 字重寫到 3,500 字，等於新片，所以不走重用插圖的 recut。

步驟：

1. 讀三支舊片在網站上的狀態（有沒有上 YouTube、語言做到哪）。
2. 每集寫 brief 與大綱，站主選。
3. 寫稿 → 獨立查核 → 盲評 `narrative` → `lint` 0 錯誤。
4. 旁白 → 站主聽 → 插圖整集一次畫 → 分鏡 → 配樂 → 成片 → 品管 → 上架包。
5. 新片核准後才處理舊片：還沒上架的在後台放棄；已上架的由站主決定私人或刪除。新片上架前舊片不動。
6. Garmin 舊片不再解卡做語言（票 `2026-10-21-brand-stories-seiko-garmin-rolling-suitcase` 裡那一支）。
