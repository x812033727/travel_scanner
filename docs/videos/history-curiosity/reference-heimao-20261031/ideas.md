# 依黑猫研究院的題目公式發想的新題（2026-10-31）

公式：**人人認得的名字＋一個反常的問題＋誰在收錢或誰被騙**，再加奇聞檔案局要的「流傳的版本會被紀錄修正」。

這些題目不在他的清單裡，用關鍵字比對也不在我們的題庫裡。**內容是憑既有知識寫的，都還沒查核**，開題前要逐條對一手來源，查不到就改題或拿掉。代號要等站主選了才編。
