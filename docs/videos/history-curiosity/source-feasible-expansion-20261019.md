本表只盤點在此雲端**實際重開**的固定版本全文或圖像。它不是劇本、事實簽核或媒體開工單。下列四題都不重複已認領的 S01／S09／S18，也不與現有 S01–S36 題目相同；編號只是接續候選，正式認領時再鎖定。

## 現有候選的停拍界線

### S27｜維京頭盔的角

- 可重開的**後世舞台圖像**：[1916 年《The Mentor》全文中 Gustav Siehr 圖說](https://github.com/GITenberg/The-Mentor-The-Ring-of-the-Nibelung-Vol-3-Num-24-Serial-No-100-February-1-1916_51502/blob/bd1e2b6e0aea659847d7390b69c02cddfc8c3488/51502-h/51502-h.htm#L1328-L1335)與[該圖](https://github.com/GITenberg/The-Mentor-The-Ring-of-the-Nibelung-Vol-3-Num-24-Serial-No-100-February-1-1916_51502/blob/bd1e2b6e0aea659847d7390b69c02cddfc8c3488/51502-h/images/illus23b.jpg)；圖中的 Hagen 演員戴有角頭具，圖說稱 Siehr 在 1876 年創演 Hagen。**圖說未給照片拍攝年份**，Hagen 也是舞台上的日耳曼傳說角色；這張圖不能證明 1876 年首次發明角盔，更不能證明維京戰士戴角。固定全文 `51502-0.txt` SHA-256 `e441a900f0ef8aa893af9d4fd1dd3e2b7a066442640d8537573839cbbecede9b`；圖檔 SHA-256 `a74b331ee21c728c0bd5880c331dba362f730e79ee38185c8e968e29bcf69bb7`。
- 缺的關鍵層是**可重開的考古館藏紀錄／發掘報告**及可定年的 19 世紀服裝原稿。丹麥 Nationalmuseet 的 Viksø、Viking helmets 頁、挪威館藏頁，以及 Durham 的 Yarm helmet 接受稿，在本環境 `curl` 均被代理擋為 403；Google／維基轉述與私人部落格不能充當已讀館藏。私人書目頁提到 Caple 2020 的 Yarm 頭盔，但原論文未重開，不能沿用舊卡「唯一留存的維京頭盔」說法。
- **狀態：暫緩前製與付費媒體。** 可以說「1916 年印刷品保留了一幅有角舞台形象」；還不能說「Wagner 在 1876 年創造維京角盔」或從目前未核考古樣本推出「每個維京人都沒有角」。

### S21｜鬱金香狂熱

- 可重開的**1841 年後世敘事原件**：[Charles Mackay, *Memoirs of Extraordinary Popular Delusions*, 卷一〈The Tulipomania〉](https://github.com/GITenberg/Memoirs-of-Extraordinary-Popular-Delusions---Volume-1_636/blob/42c756e4bb6ce450a4d943361045b4e0cf89e188/636.txt#L3276-L3560)。書自身標 1841 年（第 41–48 行）；第 3480–3506 行稱各階層參與、商人破產，第 3550–3556 行稱荷蘭商業多年受創。這些行只能證明 **Mackay 寫了這些話**，不能作為 1637 年每筆交易或全國經濟結果的直接帳簿。固定全文 SHA-256 `52a8742a5b6042e86e2974a51a303b03756653120bc751519c835869b80c088e`。
- 未找到能在此環境完整重開並固定版本的 1636–37 年荷蘭契約、成交帳、法院紀錄或諷刺小冊全文；GitHub 原文檢索 `Floraes Mallewagen`、`Waermondt`／`Gaergoedt` 只找到書目或轉述。當代館藏與學術原站的請求受代理 403，Anne Goldgar 的研究亦未取得可逐頁核對的全文。
- **狀態：暫緩前製與付費媒體。** 若改題為「1841 年 Mackay 怎麼寫鬱金香故事」，此書可作一手材料；若仍要回答「1637 年到底有多瘋／有多少人破產」，必須先補一組同時代契約或法院材料及可覆核的現代研究。不能從檔案未讀到破產案，推論當時沒有破產。

### S29｜曹沖稱象與《雜寶藏經》的另一個船量象故事

- 可重開的[陳壽《三國志》〈曹沖傳〉固定版](https://github.com/Ancient-China-Books/sanguozhi/blob/10a0b1ab3019d8821262f7402366d14fb4aaa102/OEBPS/Text/020.htm#L19)記孫權送來巨象、曹沖提出把象放在大船上刻水痕，再「稱物以載之」；這裡**沒有指明第二次載的是石頭**。固定 HTML SHA-256 `dec2ae1713a56e2a33d367d691904004db60740f9490023b52695bfd3740bbc8`。
- 可重開的[CBETA《雜寶藏經》〈棄老國緣〉固定 XML](https://github.com/cbeta-org/xml-p5/blob/dbdea41071e1e260ad84b72faefd4587333cf76d/T/T04/T04n0203.xml#L657-L685)另寫一位被藏起的老父回答天神的難題：把**白象**放船上、畫水線，再以**石頭**載船至同一水線。XML 第 9–12 行標「元魏 吉迦夜共曇曜譯」；元魏為曹沖 208 年去世後的朝代，檔案**沒有給此故事最初形成的日期**。固定 XML SHA-256 `0b0d59c2c02da42fae95e3ed48f64e20813602b6f48032770a0ce557a6ff90b1`。
- **狀態：可進一步前製，未核准劇本／媒體。** 兩個傳世文本都可逐字對照相同測重方法與不同的主角、場景、載重物；時間層只證明現存漢譯晚於曹沖，**不能推出誰抄誰、故事傳播方向或曹沖當時必定親自發明**。原題卡「可能來自一部佛經？」宜改為「兩個船量象故事，哪一個文本先寫下來？」前製需再核《雜寶藏經》譯者年代、文本流傳與《三國志》成書年代，避免把後出的漢譯誤說成曹沖讀過的那一本。

### S31｜楊貴妃的荔枝如何送到京師（待補路線證據）

- 可重開的[《新唐書》〈楊貴妃傳〉固定版](https://github.com/Ancient-China-Books/xintangshu/blob/199229e8a0905688df7433fb0304c847303f85e8/OEBPS/Text/4206.html#L77)說「妃嗜荔支，必欲生致之，乃置騎傳送，走數千里，味未變已至京師」。本地該 HTML SHA-256 `862fd9bb743d6e5e350780633e91251c37fc81b84bc5323b1fc12c75f74b8125`。這是後出史書敘述，可說它**記載**專騎傳送與距離概稱；不可把「數千里」換算成未記載的日速、站數或唯一走線。
- 同一固定《新唐書》[〈禮樂志〉](https://github.com/Ancient-China-Books/xintangshu/blob/199229e8a0905688df7433fb0304c847303f85e8/OEBPS/Text/4134.html#L15)寫楊貴妃生日長生殿奏新曲，適逢「南方進荔枝」而名〈荔枝香〉；該 HTML SHA-256 `4583324b26f65367c147f8ada00736a80f2e178a008a2618d8b75ca0296abf63`。此句只說南方，不能據此給所有貢果定位園地或驛路。
- 可重開的[《舊唐書》〈白居易傳〉固定版](https://github.com/Ancient-China-Books/jiutangshu/blob/db064a0c05713f01d3da591949fc9b0c9ed9614d/OEBPS/Text/4064.html#L80)引白居易《荔枝圖序》：「荔枝生巴、峽間」與離本枝後一日至數日色香味變。該 HTML SHA-256 `81cbffc65ce8ca1581000247182f81c5500154ac7dd16f99611a8f8a62043d13`。白居易在談他所見巴峽荔枝的物性，**不是**說楊貴妃的貢果一定來自巴峽。
- S31 作者另獨立重開[杜牧《樊川文集》〈過華清宮絕句三首〉](https://github.com/garychowcmu/daizhigev20/blob/4a6d6f2088825f132521d848c2ea86cf9c9a7620/%E9%9B%86%E8%97%8F/%E5%9B%9B%E5%BA%93%E5%88%AB%E9%9B%86/%E6%A8%8A%E5%B7%9D%E6%96%87%E9%9B%86.txt#L257-L263)，固定轉錄文字 SHA-256 `f6a2c78a1da55168b03e7556ac4a57c7c7f64c74b63ffe4af2d56558cceb42d1`；及[白居易《白氏長慶集》〈茘枝圖序〉](https://github.com/garychowcmu/daizhigev20/blob/4a6d6f2088825f132521d848c2ea86cf9c9a7620/%E9%9B%86%E8%97%8F/%E5%9B%9B%E5%BA%93%E5%88%AB%E9%9B%86/%E7%99%BD%E6%B0%8F%E9%95%BF%E5%BA%86%E9%9B%86.txt#L6047-L6048)，固定轉錄文字 SHA-256 `6074f3b5cc14e45b4c1c18edfddd7ec814709038f8351bb7cbcde17b66ddbb81`。該儲存庫沒有在文字頁說明底本的校勘版本；題材使用時應稱數位轉錄，不能冒稱特定版次。杜牧詩的「一騎」是文學描寫，不是速度／驛路量測。
- 狀態：可進一步研究，但還沒有可重開的當時驛傳簿、指定果園或整條運送路線紀錄；待核唐代驛傳規制及來源交叉查核後再寫 8–10 分鐘劇本。不能把詩句的「一騎」當驛路實測，也不能從《新唐書》相鄰嶺南官員進獻段落直接推定楊妃荔枝的產地。

## 順序建議與重開方法

**先做 S38。** 佩皮斯日記已有連續三天、第一人稱、可見行動和具體物件，開場與章節可以順著日記日期走；需補的是 1666 年版本註解與城市全貌，不影響把原文作為故事主線。S37 次之，特別適合做「作者親見與聽來」的來源分層。S39／S40 有完整早期文本，但原文及互證多一關。

以上資料以 `git clone --filter=blob:none --depth=1` 從 GITenberg 重開，執行 `git rev-parse HEAD` 鎖定提交，再讀完整檔案與所列段落；本表的 SHA-256 是這次本地重開的原始文字檔。S27／S21 因核心時代層缺源，仍只保留試查記錄，不建立劇本、語音或插圖。
