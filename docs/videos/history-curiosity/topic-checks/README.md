## 2026-10-11 第二批（新題）查核結果

第二批每題一個研究代理（約 27 萬到 40 萬 token、25 到 45 分鐘、開 40 到 100 個網址）加一個獨立覆核代理（約 24 萬到 28 萬 token）。到目前為止沒有一題的主幹被推翻，但每題都改掉原卡一到四處講滿的地方。這個網路的限制：web.archive.org 的存檔頁對代理回「Blocked by egress policy」或連線被重設，只能用 availability API 確認有存檔；Commons 的 API 回 429（改讀檔案頁 HTML）；nytimes.com、Britannica、JSTOR、DTIC、ScienceDirect 回 403——只靠存檔的來源在覆核時判 UNOPENED，換個網路可以補開。
