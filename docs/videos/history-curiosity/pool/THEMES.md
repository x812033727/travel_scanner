## T01 海底那幾聲怪響，後來各是誰？

**追問：** 水下麥克風錄到的三種『怪聲』，答案為什麼一個是冰、一個是鯨、一個是魚？

**為什麼接成一集：** 三題都是同一種儀器（水下監聽）錄到、被當成神秘訊號的聲音；答案各不同，排在一起才看得出『誤判』是怎麼發生的。單一題都只有一個轉折。

| 開場：一台聽潛艇的麥克風 | 60 | 水下監聽為什麼錄得到幾千公里外的聲音；三個未解的聲音同時登場。 | M07 |  |
| Bloop：比藍鯨還大的聲音 | 150 | 1997 年的錄音、被猜成巨型生物，後來 NOAA 對上冰山崩裂的冰震。 | M07 | 冰震的對照錄音找不到就縮成 90 秒 |
| 52 赫茲：一隻頻率對不上的鯨 | 150 | 1989 年起每年錄到同一個聲音，會跟著季節移動；身分到今天沒人看過。 | M23 |  |
| 瑞典的『蘇聯潛艇』 | 150 | 海軍追了十幾年的典型聲音，1996 年交給生物學家，答案是鯡魚的氣泡。 | M26 | 查不到瑞典官方承認的文件就刪 |

**用到的題與來源：**
