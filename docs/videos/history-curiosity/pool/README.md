## 去重與淘汰怎麼做

- **自動合併**：只有完整題目正規化後相同才自動合併。
- **編輯合併**：其餘的合併要編輯比較**核心答案**後寫理由。換地點、換年份、換主角不算新題；同一類別也不是合併理由，那種情況排進同一個題案。
- **找比較對象**：
  - 詞面相似（題目、紀錄、案件鍵的雙字詞）對中文標題幾乎抓不到真重複；
  - 所以另跑本機語意近鄰（釘版 MiniLM，見 `tools/video/curio/pool/semantic.py`），每題讀 top-10，並對原來如此事務所的核心題讀 top-3；
  - 分數只是候選，不會自動合併。
- **已製作的題鎖定**：可以吸收重複題，自己不能被併掉、淘汰或轉 Shorts。
- **處置的規則**：
  - 淘汰要寫重新收錄的條件；
  - 轉出要寫去哪個系列；
  - 每個原 ID、來源與理由都保留。
- **作者第一輪處置**之後，有一位非作者覆核者逐條判讀（[收據](reviews/legacy-review-20261101.json)）：
  - 114 條同意 92、不同意 7、建議修改 15，另指出 25 項漏處置；
  - 全部照覆核改判，理由都標「非作者覆核改判」。

## 片長規則

- 長片 8–13 分鐘，看素材決定（站主 2026-11-01：「≥8 分鐘都可以」）。
- 題案的章節秒數合計必須等於目標；每章至少 30 秒，每章要寫「新增理解」與刪段條件。
- 一個核心題只能進一個題案。
- 撐不住就剪短、合併或撤案，不用重述、停頓或慢唸補時間。

這條只套用在這個池排出來的題案；已製作與製作中的集照舊。curio-episode skill 與 lint 仍寫 13 分鐘，題案真的採用時要另開票同步，並先問站主。
