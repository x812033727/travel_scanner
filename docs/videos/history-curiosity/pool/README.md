# 奇聞檔案局素材池

這是奇聞檔案局（`curio-*`）自己的素材池。做法比照原來如此事務所的素材池（x812033727/travel_scanner#1971）：
- 依核心答案去重；
- 整理可追溯的來源；
- 太薄或無聊的題合併、淘汰、轉 Shorts 或轉到別的系列，每一筆都留理由；
- 影片題案看素材排 **8–13 分鐘**，不為片長硬湊。

## 寫回題庫

`../topics.json`、`../topics-fg.json` 每一題加了 `pool` 欄位，記素材池的處置：
- `status`：
  - `selected` 入選
  - `reserve` 候補
  - `held` 暫緩
  - `produced` 已製作
  - `merged` 併入別題，`core` 是併入的主題
  - `shorts`
  - `excluded` 淘汰或轉出
- `theme`：排進的題案。
- `screened_in`：做過篩選研究的批次。

已有工作目錄或分支草稿、卻還標 candidate／checked 的 43 題改成 `scripted`，並補上 `video`。

**這個欄位由工具產生，不要手改。** 題目卡原文（title、hook、finding）不改：
- 篩選研究改寫後的題目與來源，以素材池為準；
- 篩選研究不算 topic-checks 的完整查核，所以不會把題目改成 `checked`。

## 去重與淘汰怎麼做

**合併**
- 只有完整題目正規化後相同才自動合併。
- 其餘合併要編輯比較**核心答案**後寫理由。換地點、換年份、換主角不算新題；同一類別也不是合併理由，那種情況排進同一個題案。

**找比較對象**
- 詞面相似對中文標題幾乎抓不到真重複。
- 所以另跑本機語意近鄰（釘版 MiniLM，`tools/video/curio/pool/semantic.py`）：每題讀 top-10，並對原來如此事務所的核心題讀 top-3。
- 分數只是候選，不會自動合併。

**已製作的題鎖定**
- 可以吸收重複題，自己不能被併掉、淘汰或轉 Shorts。

**處置的理由**
- 淘汰要寫重新收錄的條件，轉出要寫去哪個系列。
- 每個原 ID、來源與理由都保留。

## 舊題目卡的篩選研究（wave2）

做法：
- 題庫裡 139 張從沒查過的舊題目卡，加上第一批 3 題待查的新題，分給 12 個研究代理，每個約 12 題。
- 預設懷疑卡片上的每個年份、數字與引句。
- 至少兩個可讀來源，其中一個是一手或機構來源，才收。
- 五位非作者覆核者逐題重開關鍵來源，並抽查研究代理改卡的地方。

結果：
- **每張收下的卡都至少改正一處錯誤**，寫在 notes 的「原卡：…；查到：…」。例如：
  - H08 南澳無名男子：警方從沒確認身分；
  - F01 灰姑娘：1812 年是金拖鞋；
  - F06 睡美人：佩羅版沒有吻；
  - P04 千禧蟲：國防部衛星情報站停擺了三天；
  - U06 金唱片：問候語標的是廈門話，不是台灣人錄的。
- 系列 README 的 F01 試播示範開場引用了 1819 年版的台詞，已一併改正。

整合時發現一個問題：覆核者的「修改」欄位有很多寫的是修改指示（「把『X』改成『Y』」），而不是改好的文字。這些欄位已逐條對照原文套用指示改寫，覆核收據保留原本的指示。

素材審視（[reviews/material-20261111.md](reviews/material-20261111.md) 的〈資料問題〉）找到的四件事，修在匯入（`tools/video/curio/pool/core.mjs`）與批次備註，入選、題數與題案都沒變：

- **scope**：舊題的 scope 原本是題目卡的「待查：…」，那是待辦，不是限制。現在有題級查核檔的，照錄它寫下的「不能講」「不要說的話」「不說滿」「不能畫、不能講細節的」與〈流傳但查不到〉〈不講的事〉（`scope_source` 指向該檔）；已製作、重做或有分支草稿的題指向集數工作目錄；其餘標 `scope_status: "not_yet_scoped"`，QUESTIONS.md 與 index.html 顯示「範圍未界定」，題目卡的待查事項另存 `card_facts_to_verify`。目前沒有入選題是範圍未界定。
