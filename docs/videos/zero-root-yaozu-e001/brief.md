# 《長燈村：零靈根的我被一村妖祖養大》第 1 集〈問天石，零〉

## 故事前提

十八歲的陸拾背著奶奶醃了三個月的菜，上玄穹宗的問天台測靈根，想當仙人寄錢回家。問天石在他手下一點光都沒有，全場哄笑；滿場只有一個白衣少女不笑，從隊伍裡走出一步盯著他。天才嚴少淵一按就亮出百年一見的金紅雙色光柱，回頭嫌他的醃菜臭。長老嚴崇叫執事拽他下山，兩個人拽不動他，嚴崇的念珠停了：「零靈根……哪來這把力氣？」嚴少淵一腳踢翻醃菜罈，陸拾第一次對仙門的人握起拳頭，嚴少淵把劍頂出一指等他出手；宗主千金雲知意擋在中間，撿起還能吃的菜，又在山門外塞給他一個饅頭：「回家再打開。別讓人看見。」陸拾走進黃昏的霧路，頭頂一根樹枝沒風自己晃，倒垂下一張猴臉。

本集細綱：`docs/videos/series-plans/zero-root-yaozu/season-01.json` 第 1 集（95 秒）。本集是全劇第一集，開頭 3 秒最要緊：第一格就是手拍上黑石、石頭全黑、嚴崇拖長音說「零——。」，不先拍任何全景。
