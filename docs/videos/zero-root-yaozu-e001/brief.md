# 《長燈村：零靈根的我被一村妖祖養大》第 1 集〈問天石，零〉

## 故事前提

十八歲的陸拾背著奶奶醃了三個月的菜，上玄穹宗的問天台測靈根，想當仙人寄錢回家。問天石在他手下一點光都沒有，全場哄笑；天才嚴少淵一按就亮出百年一見的金紅雙色光柱，回頭嫌他的醃菜臭。長老嚴崇叫執事架他下山，兩個人架不動他；嚴少淵一腳踢翻醃菜罈，宗主千金雲知意擋在中間，撿起還能吃的菜，又在山門外塞給他一個饅頭。陸拾走進黃昏的霧路，頭頂樹上倒垂下一張猴臉。

本集細綱：`docs/videos/series-plans/zero-root-yaozu/season-01.json` 第 1 集（95 秒）。開頭 3 秒是手按黑石、石頭不亮、嚴崇拖長音說「零」；中段是金紅光柱與「什麼味道？」；結尾收在猴臉貼到鼻尖前一寸的「嘻」。

## 角色

- 陸拾（lushi）：主角，零靈根、文盲、力氣大，護著奶奶的醃菜。
- 嚴崇（yanchong）：玄穹宗外門長老，主持問天大典。
- 嚴少淵（yanshaoyuan）：嚴崇之子，雙色光的天才，當眾羞辱陸拾。
- 雲知意（yunzhiyi）：宗主之女，替陸拾撿菜、塞饅頭（饅頭裡藏的東西第 3 集揭曉）。
- 外門弟子（dizi）：起鬨的群眾代表。
- 山魈（shanxiao）：結尾倒掛的山鬼，第 2 集接住。
