## 品牌與保養建議

- **品牌比較**：沒有。片中只說「有一家手機公司」「有的手機公司」（p045、p163），哪一家記在 `claims.md`；不點名、不比較，合格。
- **危險或沒有來源的建議**：
  - p019「拆開這顆老電池」配上 `battery-open` 的 tiny screwdriver，等於示範拆電池，跟 p186 的警告矛盾。
  - p124「插上電就能再打開」：`claims.md` 自己標明來源沒有這句。觀眾若遇到電池其實已鼓脹，這句會鼓勵他繼續充電。
  - p188「有怪味」、「也不要充電」：方向安全，但來源只有「懷疑損壞就停用」；在 `claims.md` 標成我們舉的例子，或只留「鼓鼓的、很燙」。
  - p097 冷凍庫、p184–p186 自己拆，都被正面推翻，處理得好；p040 要「請大人」打開設定，合適。

## 插圖提示詞風險

| 風險 | 鏡頭 | 說明 |
| --- | --- | --- |
| 內容與安全訊息矛盾 | `battery-open` | 電池旁放螺絲起子，像在教拆電池 |
| 畫面早於比喻 | `bottle-tease` | p016–p017 講「手機自己決定」「電池裡長東西」，畫面卻是還沒介紹的水垢瓶 |
| 提示詞打錯 | `phone-busy` | 「glowing softly glowing brightly」字串替換重複 |
| 物件不合理、會被畫成普通瓶子 | `spout`、`bottle-left`、`cup-short`、`trickle-cup`、`snail-sip` | 塑膠水瓶加「very thin narrow spout」，模型多半畫成一般瓶口，壺嘴窄這個重點就畫不出來 |
| 比喻物件漂移 | `wide-spout`（big jug）、`full-pour`（tall bottle、沒黃瓶蓋）、`kettle`／`kettle-crust`（金屬熱水壺） | 熱水壺是比喻來源可以保留，其餘應是同一個水壺 |
| 大小比較、數量 | `two-bottles`、`bottle-eighty`、`bottle-shrunk`、`shelf-bottles` | 「slightly smaller」單張沒有參照看不出變小（`bottle-shrunk`）；一排瓶子數量模型數不準，好在意思不靠數字 |
| 剖面圖、易成 3D 或示意圖 | `battery-layer` | cutaway 電池常畫成 3D 渲染或附標註字 |
| 發光螢幕可能長出圖示或字 | 所有「glowing softly」的手機（`kid-park`、`phone-glow`、`phone-busy`、`bedside`、`snail` 等） | 發光面容易冒出電量圖示、時鐘；`phone-dark`、`case-off`、`swollen` 不發光較安全 |
| 物件長臉 | `swollen`（像小枕頭的鼓背）、`kettle`、`snail` | 可愛畫風下鼓起的手機、熱水壺常長出臉；蝸牛本來就有臉，可接受 |
| 會冒字 | `hot-car`（車牌）、`charger`（插頭、充電器上的商標）、`half-bottle`（便當盒） | 車子整台入鏡容易出現車牌亂碼 |
| 複雜手勢、數數 | `kid-three`（數手指）、`kid-twenty`（捏手指）、`chief-spout-you`（假裝倒水）、`kid-brush`（刷的動作沒有道具）、`kid-charger-q`（拿線） | §3.1、§10.1 列為最常退件的寫法 |
| 方向 | `pour-glass`、`full-pour`、`bottle-left`（tipped over a cup） | 水流方向偶爾畫反，但意思不靠方向，風險中等 |

## 改進建議（都不加新事實）

1. **p019 與 `battery-open`**：台詞改成「這一集，我們就來看看這顆老電池裡面」，提示詞拿掉 screwdriver，避免示範拆電池，也不跟 p184–p186 打架。
2. **p124**：刪掉「插上電就能再打開」，只留「它沒有壞」或「它多半沒有壞」（跟 p009 一致）；p188 的「有怪味」「也不要充電」在 `claims.md` 標成我們舉的例子，或刪到只剩「鼓鼓的、很燙」。
3. **比喻物件統一**：從 `bottle` 起所有水壺鏡頭用同一個寫法（例如帶壺嘴、黃蓋的透明水壺），`spout`、`wide-spout`、`trickle-cup`、`cup-short`、`bottle-left`、`full-pour` 一起改；「壺嘴寬窄」才畫得出來，主線也不漂。
4. **`bottle-tease`（p016–p017）換畫面**：改用已有的 `phone-dark` 式手機特寫或 `battery-open` 式電池特寫，讓水壺第一次出現在 p022–p023；順手修 `phone-busy` 重複的「glowing softly glowing brightly」。
5. **高風險提示詞改寫**：`kid-three` 改成雙手出鏡外或閉眼笑；`chief-spout-you` 改成攤開一手；`kid-brush` 拿掉刷的動作；`battery-layer` 改用 `bottle-crust` 式的水垢瓶（比喻已講過，不用剖面）；`hot-car` 改成擋風玻璃下手機特寫、不拍整台車；`bottle-shrunk` 改成兩瓶並排或併入 `bottle-eighty`。
6. **沒頭沒尾與小問比例**：p171 刪「也不用教它認識壺」；回音式追問 p053、p072、p102 併進所長的句子，第四章 p164–p191 把充電器與壞電池兩問併成一輪，讓小問回到約 25% 字數、第四章不像清單。p001 若小問是跑進事務所報案，`kid-park` 改成事務所裡拿著手機的鏡頭，公園留給 `squirrel` 與 `phone-dark`。
