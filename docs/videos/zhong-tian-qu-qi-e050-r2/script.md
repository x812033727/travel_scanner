## 劇情

放榜當夜，州城客棧大堂掛滿燈籠，周員外的兩個家丁挑進一擔賀禮。周員外說來賠罪；許硯問他倒著走了一條街，腳還好嗎；
周員外說腳酸是小事，當年退婚是他瞎了眼。唐小棠一眼估出人參、銀子、玉如意少說三百兩；許硯扶起周員外：那筆舊帳，跟我算不著，禮請帶回去，從今往後兩清。
秦霜笑唐小棠心疼就去追。程山長來討一杯酒，回敬一句「樹大招風，往後小心」。許大郎舉杯敬堂弟，眼睛卻越過杯沿盯著秦霜；掌櫃宣布今晚酒錢全免。
秦霜放下沒喝的酒，說跟我上樓，我有話要說。秦霜的房裡，他把懷裡的白玉佩放到圓桌上，她拿起來放進他掌心：那天在你房裡看見它說沒什麼，是騙你的，這是我爹的，我爹就是鎮北將軍秦烈山。
許硯說他知道，杜叔說過，她說他聽。她說爹貼身戴了二十年，怎麼會在他書箱裡她也不知道；他說玉包在舊書箱的油布裡，誰放的他真的不記得。
他答應見到她爹時一起親手還給他；系統宣布支線完成，難得誇他一次。樓下忽然一片騷動，州府衙役舉著火把衝上樓，門板被一腳踹開：
「罪臣之女秦霜，私逃軍籍，拿下！」樓梯最下面，許大郎站在人群最後。
