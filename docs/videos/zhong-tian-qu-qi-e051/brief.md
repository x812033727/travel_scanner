# 《種田娶妻打天下》第 51 集〈跟他們走〉

## 故事前提

第 50 集收在州城客棧的解元夜：秦霜剛把玉佩放進許硯手心、說出她爹是秦烈山，門板就被一腳踹開，州府衙役擠滿樓梯：「罪臣之女秦霜，私逃軍籍，拿下！」許大郎站在人群最後面。第 51 集從同一個畫面接下去：秦霜一把抄起門邊的紅纓長槍，帶頭的衙役刀出鞘一半：「敢拒捕？」「就地格殺！」許硯的手從上面蓋住她握槍的手：「跟他們走。」秦霜猛一轉頭：「你說什麼？」許硯：「在這裡動手，」「就真成逃犯了。」「我接妳。」（細綱的 hook。）秦霜看了他整整三秒，手指從槍桿上鬆開，把槍靠回桌邊，自己伸出雙手：「我自己走。」（細綱的 turn。）鐵鏈套上她的手腕，系統彈出：「強制任務：三日內救回秦霜。」「失敗：秦霜好感清零。」衙役押著她下樓，滿堂客人的酒杯停在半空，一個戴舊草帽的人從街門溜出去。秦霜在樓梯上回頭：「許硯。」「說話算話。」他抓著欄杆：「算話。」

當夜的大堂，唐小棠把一錠銀子推到衙役面前：「差大哥，」「公文抄一份給我。」第二錠「喀」地落下：「再加一錠。」衙役把銀子掃進袖子、把一張摺紙壓在桌上：「天亮前，」「您沒見過我。」唐小棠把抄本放到許硯面前：「逮捕公文的抄本，」「唐家的錢買的。」她撥兩顆算盤珠：「記帳上，」「你慢慢還。」許硯今晚第一次笑出來：「好，」「我還。」

天一亮，晨霧裡一匹棗紅馬衝過空無一人的州城長街（細綱的 mid_hook 與奇觀，0:52），阿令在客棧門前猛勒韁繩，馬人立起來。許硯跨出門口：「阿令？」她翻身下馬，木簪挽起的黑髮被風吹亂，看都不看旁人，直直走向他（細綱的顏值鏡頭）：「人呢？」「州牢。」「三天內要救出來。」唐小棠瞪大眼：「柳溪到這裡，」「妳騎了一夜？」阿令拍掉袖子的灰：「鏢局半夜敲門。」「小禾交給韓伯了。」唐小棠收起笑，從袖裡抽出一封信：「還有，」「爹在京城的人來信了。」「魏少卿一個月前，」「帶著一個畫師回京了。」許硯皺眉：「畫師？」「他要畫誰？」站在他旁邊的阿令，抬到袖口的手停在半空（s01-t12 的 setup：魏少卿回京城對誰說了什麼，第 58 集收）。唐小棠遞出抄本：「這是逮捕公文的抄本。」阿令一抖攤開，指尖停在下方那方朱印上，鳳眼一瞇：「這印，」——眼睛抬起來看許硯：「是假的。」（細綱的 cliffhanger，reveal，「阿令怎麼一眼看出印是假的？」）

本集細綱：`docs/videos/series-plans/zhong-tian-qu-qi/season-01.json` 第 51 集（100 秒，第一季第六章第一集，調性權謀＋甜寵）。hook 是「跟他們走」「我接妳」（line，0:00–0:14）；mid_hook 是阿令從柳溪連夜騎快馬趕到（s21–s24，0:52–1:02）；衝突是動手就坐實私逃、不動手秦霜就被押進州牢（s02、s06）；turn 是秦霜看了他三秒、自己伸出雙手（s08–s09），系統彈出強制任務（s11），唐小棠拿唐家的錢買來公文抄本（s15–s18）；cliffhanger 是阿令只看一眼朱印「這印，是假的」（s32–s35，reveal）。satisfaction 兩個都入鏡：reversal（s08–s09）、hidden_power（s15–s18、s33–s35）。general_payoffs 全部入鏡：客棧裡沒流一滴血、秦霜沒被坐實逃犯（s08–s13）；唐萬金在京城的眼線來信、魏少卿一個月前帶著一個畫師回京（s29–s31）。setup s01-t12：s29–s31。
