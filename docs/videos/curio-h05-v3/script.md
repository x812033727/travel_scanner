# D.B. Cooper 跳機，FBI 查 45 年還沒真名？｜奇聞檔案局

## 場景

### 一個男人掏現金，買了一張到西雅圖的單程票

#### 1. open-stake

旁白（對觀眾說，帶一點挑釁）：一個人拿到二十萬美元，從飛機上跳進夜裡，美國聯邦調查局查了將近四十五年。

#### 2. open-stake-b

旁白（短句，收著）：你大概也聽過流傳的說法：一個跳傘高手，帶著錢逍遙法外。

#### 3. open-airport

旁白（沉穩進場景）：一九七一年感恩節前一天的下午，美國波特蘭機場。

#### 4. open-counter

旁白（平平講，像沒事）：一個穿西裝、打黑領帶的男人，掏現金買了一張到西雅圖的單程票。

#### 5. open-ticket

旁白（放慢）：票上的名字，是丹庫柏。

#### 6. open-phone

旁白（對觀眾，帶一點得意）：可是你聽過的叫迪比庫柏，這兩個字母，票上根本沒有。

#### 7. open-boy

旁白（收著，停在這裡）：八年多以後，一個八歲男孩在河邊挖沙，手碰到了一樣東西。

#### 8. open-promise（big）

旁白（承諾句，篤定）：這份檔案，我們就從這張二十美元的機票翻起。
旁白（問句上揚，停一拍）：他留下了那麼多東西，這個人到底是誰？

#### 20. note-circle

#### 24. note-window

#### 25. note-who

### 對講機裡，他只回了一個字

#### 51. jump-warn

旁白（壓低）：有記載說，地面還告訴過機長，有位調查局專家認為，他跳下去之後會把飛機炸掉。

#### 52. jump-cargo

旁白（對觀眾，緊繃）：換成你坐在駕駛艙，接下來這段路，載的是一個空機艙，還是一顆炸彈？

#### 53. jump-fly
