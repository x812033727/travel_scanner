# 《種田娶妻打天下》第 45 集〈榜上無名〉

## 故事前提

第 44 集收在州城客棧的樓上客房：秦霜背對他站在窗前，聲音發抖「若我是罪人之女，」「你還要我嗎？」，許硯的嘴唇剛張開（「知道真相後，他會怎麼回答？」）。第 45 集第一秒就給答案：許硯走到她身後「妳是秦霜，」「我只認這個。」（s01，細綱的 hook）；她側臉上一滴淚滾下來（s02），系統「秦霜好感度，」「加四，五十二。」（s03，general_payoff：秦霜好感 52，因為他只認她這個人）。她轉過身，眼眶紅著卻笑了，劍眉一挑：「傻子。」（s04，細綱的顏值鏡頭），許硯：「傻子才認得準。」

她捶他一下：「我說我是軍戶孤女，」「是騙你的。」（setting 的秦霜：自稱軍戶孤女），許硯逗她「將軍家，」「也算軍戶啊。」；她收起笑：「窩藏罪人之女，」「你不怕？」，「怕啊。」「怕妳跑了。」；她往門口瞄一眼「罪人之女這件事，」「別讓第三個人知道。」，「我嘴很緊。」——房門沒關緊，留著一指寬的黑縫（s12）。

樓梯轉角，許大郎整個人貼在木板牆上，臉朝著樓上（s13，細綱的 mid_hook），嘴唇幾乎沒動：「秦烈山……」「罪人之女？」，拇指沿著草帽簷那道剪掉繩子的淺色印子摸過去、停在斷線頭上（s15，第 42 集 m05 的提示延續：只拍印子與手，不說繩子是什麼、不說河邊），嘴角一勾「這可值錢了。」，把草帽戴回頭上、溜進漆黑的大堂（state：許大郎知道了秦霜的身分；他要拿去賣給誰，這集不說）。

第二天的客棧大堂，唐小棠繞著桌子走「放榜還要兩天？」「我等不了！」（細綱的衝突：放榜前榜單是祕密），許硯：「榜單是祕密，」「誰都看不到。」，她眼睛一亮「祕密，」「都有價錢。」，掀開一盒亮晶晶的白糖（許家糖坊做的）。秦霜：「榜房有兵守著。」，唐小棠抱起糖盒眨眼：「兵守門，」「書吏娘子守廚房。」。夜裡的榜房門口，書吏娘子眼睛發直「白糖？」「一整盒？」「看一眼，」「就一眼！」（細綱的 turn；general_payoff：唐小棠買通榜房的門路）。一卷長長的草榜整條攤開，燭光一路照下去（s26，細綱的奇觀）；唐小棠的手指一列一列找「清水縣……」「許……」，甜笑一點點收掉：「沒有？」。門口書吏娘子催「好了沒？」「快點！」；桌頭單獨擺著一張首卷，她念出第一列「以水車引水……」，臉一下子沒了血色：「這是他的文章。」

當晚唐小棠衝回客房（s32），喘著氣：「你的名字，」「不在榜上。」，許硯「不在？」，秦霜的手落到柴刀上；唐小棠聲音發抖：「榜首是魏珣，」「他的策論寫的是水車。」收在許硯的臉僵住、手指扣住桌沿（細綱的 cliffhanger，reversal：「他的文章怎麼到了魏珣名下？」；第 46 集從州府門口的大鼓被擂響「學生許硯，卷子被換！」接）。
