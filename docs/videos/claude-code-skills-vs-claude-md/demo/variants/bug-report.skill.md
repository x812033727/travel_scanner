# 處理回報的錯誤

1. 先讀 src/units.mjs 裡出錯的那個函式，讀完再改。
2. 回覆的開頭寫「重現：」，後面接輸入和實際的輸出。
3. 只改出錯的那個函式，其他函式不要順手整理。
4. CHANGELOG.md：在「## Unreleased」底下加一行，
   用「- [fix] 」開頭，寫修了什麼。
5. 版號不要動，README.md 不要動。
6. 回覆的最後一行固定寫：下一步：請回報的人確認
