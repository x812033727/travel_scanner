## 問題

主軸：童話原版（F 軸）。

觀眾會打的字：「灰姑娘 原版」「格林童話 原版 灰姑娘」「灰姑娘 姊姊 切腳」「灰姑娘 鴿子 啄眼」「玻璃鞋 由來」「仙履奇緣 原著」。

大部分人相信的版本：灰姑娘有神仙教母、南瓜馬車和玻璃鞋，午夜十二點魔法消失；網路上流傳的「格林原版」是姊姊切腳、母親說「當了王后就不用走路」，
最後被墳上榛樹的鴿子揭穿，好像原版很血腥、後來被改溫和了。

## 一句答案

格林兄弟 1812 年初版裡沒有神仙教母、南瓜和玻璃鞋：鞋是金的，母親在試鞋時偷偷給刀，大女兒切一塊腳跟、二女兒切腳趾，城門上的鴿子揭穿她們；
7 年後的 1819 年第二版沒有變溫和，反而加上榛樹、「當了王后就不必再走路」與教堂前後的啄眼。南瓜和玻璃鞋在 1697 年巴黎那本一般歸在佩羅名下的
故事集裡就有了，比格林初版早 115 年，格林兄弟在初版的注釋裡說它「不算他講得最好的」；美國電影學會目錄記迪士尼 1950 年《仙履奇緣》的原著是佩羅那一篇。
〔#1–#17〕

## 站主觀點

沿用系列守則：講檔案不講結論。每一句只講一個版本，講到初版的地方照 1812 年的原文，只出現在 1819 年以後的細節都說是第二版（`topic-checks/F01.md`
〈來源不一致〉）。不說南瓜和玻璃鞋是佩羅發明的（只查了佩羅版，沒查更早的版本），只說「在佩羅版就有、格林各版都沒有」；不說迪士尼「照佩羅拍」，
只說 AFI 目錄記的原著是佩羅那一篇。不說格林童話整體越改越溫和或越血腥，只說灰姑娘這一篇剛好反過來。切腳、啄眼只用說的，不形容過程與疼痛。

## 原因（照故事發生的順序，也是章的順序）

- **初版 p.88–90**：有錢人家的妻子臨終要女兒在墳上種小樹、用眼淚澆；後母帶兩個女兒進門，灰裙子、灰裡的豆子、睡在灶邊，名字的由來；國王辦三天的舞會〔#7、1812 p.88–90〕→ 第 2 章
- **初版 p.90–93**：扁豆、兩隻白鴿、第一晚只能爬上鴿舍偷看、鴿舍被拆、野豌豆、「半夜以前要回來」〔#8、#9、1812 p.90–93〕→ 第 3 章
- **初版 p.93–96**：銀色禮服與銀鞋、六匹黑馬、王子只要她、半夜以前離開、「是坐六匹黑馬那輛車的嗎」〔#8、#9、1812 p.93–96〕→ 第 4 章
- **初版 p.96–99**：金色禮服與金鞋、六匹白馬、樓梯上的瀝青、十二點敲完馬車消失、告示、輪到兩個姊妹〔#8、#9、1812 p.96–99〕→ 第 5 章
- **初版 p.99–101**：母親給刀、大女兒切腳跟、城門上的鴿子、二女兒切腳趾、左腳穿上金鞋、「鞋裡沒有血」、初版到此結束〔#1–#3、#5、#6、#10〕→ 第 6 章
- **1819 第二版與 1857 第七版**：榛樹枝、騎馬、沒有馬車與午夜、順序對調、當場遞刀與「當了王后就不必再走路」、鴿子在墳上的榛樹、教堂前後啄眼〔#3–#8、#10〕→ 第 7 章
- **佩羅 1697**：巴黎、Claude Barbin、〈Cendrillon, ou la petite pantoufle de verre〉、仙女教母、南瓜、老鼠與蜥蜴、玻璃鞋、姊妹沒動刀、被原諒並嫁給貴族；格林 1812 年附注的評語〔#12–#15〕→ 第 8 章
- **迪士尼 1950**：AFI 目錄的原著欄是佩羅那一篇；片子另加的情節（繼母絆倒侍從、鞋子摔碎）〔#16、#17〕→ 第 9 章與結檔

## 大綱的兩個選項

- **A（推薦，採用）說書版：從第 88 頁講到第 101 頁，再打開三本書。** 前三分之二照 1812 年初版把整個故事說完，後三分之一依序打開 1819 年第二版、
  1697 年的佩羅版、1950 年的 AFI 目錄。為什麼：這是 README §一集怎麼講（說書版）定的做法；觀眾想聽的是「原版到底怎麼講」，故事本身就是鉤子，
  後三分之一的版本對照是這個頻道自己的考據（YouTube 非原創內容政策下的原創證據）；主角（初版的灰姑娘與那隻金鞋）從開場一路帶到結尾。
- **B 版本年表：1697 → 1812 → 1819 → 1857 → 1950，一版一章。** 每一章比較一版改了什麼。為什麼不選：故事被切成五段、從頭到尾沒有完整講過一次，
  聽起來像清單（盲評第 4、12、13 題的風險）；開場只能丟一張對照表，留不住人；也不是 README 定的說書版。

**主線**：從 1812 年那本書第 88 頁的一張病床，走到第 101 頁城門上的鴿子，再走到「那南瓜和玻璃鞋在哪一本書裡」的答案。
