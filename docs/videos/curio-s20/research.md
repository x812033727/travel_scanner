## 已重開的同時代文本

[Armand Dayot 編，*Le musée du Louvre*, tome deuxième（Paris: Pierre Lafitte, copyright 1913），〈La Joconde〉](https://github.com/GITenberg/Le-musee-du-Louvre-tome-2-of-2_54835/blob/4a9656edddcc1fc67b169145e04766d93969c7a7/54835-0.txt#L4617-L4652) 可從 GitHub 固定 commit 全文重開；[扉頁與出版年](https://github.com/GITenberg/Le-musee-du-Louvre-tome-2-of-2_54835/blob/4a9656edddcc1fc67b169145e04766d93969c7a7/54835-0.txt#L53-L82) 列明由法國美術總監察員 Dayot 編輯、1913 年版權。此雲端下載的完整 UTF-8 轉錄檔 SHA-256 為 `bbbc054b0262910f7e8248f23aba64a01249b4374eaea4ad49d122e9b16eeb34`。轉錄本說明保留原文拼字、只修明顯排印錯誤；它仍是後來數位化的 1913 年書，並非 1911 年警察紀錄。

該段記作者回想 1911 年八月「La Joconde a été volée!」的消息，說畫作不在 Salon Carré 時，這個收藏室失去其「最美的鑽石」；又說透過調查與一位義大利古物商的機警找回後，畫像回到原處、觀眾更多。這是**當時美術書如何描述失竊、找回與聲望**的證據，能提醒劇本不要把她說成失竊前完全無名；它的崇敬修辭也不能轉成可量化的全球知名度或精確觀眾人數。書中這段**沒有**四根釘子、具體失竊日、警察如何詢問畢卡索、阿波里奈爾的羈押、佩魯賈姓名／動機或找回的確切日期；不能拿它替那些主張背書。
