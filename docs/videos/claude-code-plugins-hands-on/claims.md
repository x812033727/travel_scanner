1. 第一章的計分表把 hook 那一列分開寫：「清單上有」那一格寫的是「外掛在清單上」（清單沒有 hook 這一欄），「效果在」那一格是「另跑 1 次（g1）：1／1」。旁白分成兩句（Skill 和 subagent 在清單上、也都被呼叫；守門每一筆修改都有執行），不說三個零件都在清單上。
