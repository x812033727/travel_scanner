## 同一批集數上兩個頻道的注意事項

第 1–30 集已經在 @Mokaair 上架，摩卡劇場再上一次是同一位創作者的作品，不是盜用。但 YouTube 可能把兩邊當成重複內容，互相分走推薦。所以：

- 摩卡劇場用**新的切法**（一季合輯、十集一段的篇章合輯），不重傳 @Mokaair 那 6 支五集合輯原檔。
- Shorts 重新從成片裁一次，標題和封面用新的，不直接下載 @Mokaair 的檔案重傳。
- @Mokaair 的《種田》舊片留著，但加置頂留言導到摩卡劇場（[`mokaair-crosspost.md`](mokaair-crosspost.md)）。
