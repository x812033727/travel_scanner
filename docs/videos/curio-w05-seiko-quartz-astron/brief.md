# Seiko 那支 45 萬日圓的錶，真的打垮了瑞士錶業？

## 問題

主軸：生意與品牌的奇聞。

觀眾會打的字：「Seiko 石英錶」「Astron」「石英危機」「瑞士錶 為什麼 倒」「精工 打敗 瑞士」。

大部分人聽過的版本（流傳）：Seiko 做出石英錶 Astron，一支錶打垮瑞士錶業，還把專利公開給全世界。

## 一句答案

Astron 確實是第一支上市的石英腕錶〔#1、#23〕，但瑞士的原型和比賽成績更早，上市只晚不到四個月〔#15、#21〕；瑞士約九萬人掉到三萬三的那段崩落，同時壓著 1973 年後的瑞郎大漲、被法規凍住的生產體系和日本的量產〔#30、#36、#38〕，各占幾成沒有人算清楚〔#47〕，所以案子蓋「未結」。公開專利是 Seiko 自己的說法，年份與條件查不到〔#27、#27a〕。

沿用系列守則：講檔案不講結論，流傳的版本標成流傳的版本，查不到就說查不到（總產量、公開專利的條件、各原因的比重）。不捧 Seiko 也不替它脫罪：學界自己也沒有一致（Donzé 經 swissinfo 說「迷思」，他 2011 年論文又寫日本競爭引發危機）〔#38、#39、#40〕。結論「三件事疊在一起，石英壓上去」標成我的解讀。
