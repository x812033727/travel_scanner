## 配鏡及後續關卡

腳本、視覺 Markdown 和 JSON 都是同序的 81 個唯一 ID；Markdown 的 81 列與 JSON 的 kind、景別／卡文、prompt／note 逐列一致。JSON 為 72 個 shot、9 個 stats，最長連續字卡 2；look 僅有 preset=cute-mystery，模型 MiniMax image-01；shot prompt 沒有 Bialetti、Moka、Alfonso、Renato、Campani 或其中文姓名，亦未要求畫商標、可讀字、真實廣告或受保護小鬍子。卡片的日期、號碼和來源字句只在後製。5 秒片頭在 c160108 後、21 秒 v4 片尾在 c160610 後。少數雙人物／多場景構圖屬後續模型實圖驗收風險；本次 PASS 只涵蓋提示詞所主張的內容與來源，不保證生成圖會依字面執行。

**尚未量得**真實 TTS 的開場 30–60 秒、正文至少 480 秒、每 30–45 秒鉤子間距，也未按實際鏡頭秒數量插圖占正文至少 70%。81 鏡中 72 張插圖的張數比例不能替代時間比例。兩位只讀新版旁白的盲讀、站主劇本及逐鏡批准、整支媒體預算批准和生成後逐張檢查仍是獨立關卡。沒有付費生成、匯入、上傳、發布、合併或部署。
