## 判定

- 通用 39 / 50（≥ 35）、系列附加 70 / 90（≥ 63），最低分 6（可做性），沒有低於 6 的項目：**稿子關通過**。
- 可做性只有 6 分，問題主要在畫面組成，不在台詞。進分鏡之前應先照下方「所長鏡頭比例」重排，否則分鏡關（角色一致、畫面單調）很可能卡住。
- brief 的開拍順序裡，`verify-1.md` 逐主張查核與 `narrative` 盲評還沒做；本評分不取代這兩步。

## 所長鏡頭比例（README §3、§10.1–10.2）

- 所長 53 鏡（42%），照語音時間約 51%；§3 的目標是約 15–20%。小問也有 55 鏡，兩個角色合計 85%，物件插入只有 15%。
- §10.1–10.2：P07／P14 卡最久的就是「角色一致」，角色鏡頭越多，每輪漂移的張數越多。這集 108 張角色鏡頭，比 P14 還多。
- 所長 53 鏡幾乎全是「白牆前點頭、微笑、舉一根手指」，同一個姿勢連續出現，看起來會很單調，也沒有幫台詞講任何東西。
- 機制台詞放在物件圖上更好讀。可以移過去、而且不用新增事實的所長台詞（用現有的圖或同一張圖的變體）：
  - P波／S波：chief-updown p040、chief-p-name p041、chief-big-guy p046、chief-order-yes p049 → messenger／big-wave
  - 速度與距離：chief-count p054、chief-p-lead p056、chief-far-rule p120–p121 → speed（同一條路）
  - 測站：chief-referee p064–p065、chief-station-listen p069–p070 → station／station-first
  - 電腦：chief-what-see p078–p079、chief-takes-time p081–p082、chief-48 p085–p086、chief-estimate p088 → computer
  - 電與基地台：chief-overtake p094–p095、chief-if-fast p097–p098、chief-broadcast p103、chief-together p108–p109 → wires／tower／phones-many
  - 城市：chief-49 p127 → city-far；chief-update p165–p166 → city-calm；chief-taipei-felt p163 → city-shake
  - 盲區與花蓮：chief-blind-name p133、chief-blind-see p135–p136 → blind-village；chief-hualien-near p147–p148 → hualien

- 這樣約可移 28 鏡，所長剩約 25 鏡（約 20%），留給轉向觀眾、賣關子與「接住上一句」的句子（p019、p022、p059、p091、p130、p174、p184、p191）。

## 改進建議（都不加新事實）

1. **所長鏡頭從 53 鏡降到約 25 鏡**：把上面列的約 28 句機制台詞移到現有的物件圖或它的變體上，所長只留轉向觀眾與接話的句子。
2. **先修高風險提示詞**：messenger、blind-village 改成不靠方向的大小對比；station、computer、手機加 `plain smooth unmarked`；kid-four-km 的五根手指、kid-blind 的遮眼、數手指的四鏡改成雙手出畫或閉眼；防災兩鏡（p177–p180）改用小孩在桌邊的畫面。
3. **p159「而且只差一點點」改成「只差一點點，手機就要響了」**；p056 改成「大約十三公里，已經領先大個子大約五公里了」。
4. **p142 先回答小問**：在「還記得電腦算的是估計嗎？」前加「不一定。」，讓 p141 的問題有直接的答案。
5. **開場補一句承諾**：在 p021 與 p022 之間（或 p022 前半）加一句所長的承諾，例如「這一集，我們就一步一步，把那幾秒找出來。」
