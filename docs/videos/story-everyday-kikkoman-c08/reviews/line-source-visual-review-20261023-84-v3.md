## 精確 HOLD 與建議修法

1. **C08-V3-V01｜c080513 逐鏡（來源通過、配圖 HOLD）**：K7 的本句是空氣接觸使生醬油顏色與香氣變化。現圖卻同時亮出舊玻璃瓶、尚未旁白揭露的軟袋及「未來瓶」空位，像產品年表，提早回答下一句並沒有呈現本句的變化。改成匿名成人打開通用生醬油瓶、觀察兩份放置狀態不同的醬油顏色的**概念**鏡頭，或單純打開容器使空氣進入的動作；勿拍成實驗證明、精確產品或可聞到香氣的圖。
2. **C08-V3-S01/V02｜c080605 旁白與逐鏡（HOLD）**：J1 支持 c080604 的調查摘要，但沒有完整問卷。現句的「我們沒看到完整問卷題目，不能把這說成……」在聲道上宣告**本審查的工作過程**，接著畫一位研究者看空白問卷。品牌故事 skill 說「查核過程不進旁白」，此處也打斷了舊瓶形如何被辨識的 payoff。建議用 J1 已列出的正向、可核對故事句替換，例如：「特許廳人員還列出一條線索：同一瓶形用了五十六年以上，長年在日本店頭與廣告出現。」J1 第 15 頁明列 same form for more than 56 years、全日本店頭販售與長年廣告；這是**列示證據**，不推它單獨造成六成辨識。對應畫面改成通用無字舊玻璃瓶在不同年代的匿名餐桌／貨架接力，或一張只標逾 56 年的後製卡。**問卷題目與呈現方式未知、不許畫無字空瓶選擇題**，保留在來源補充與逐鏡證據註記，不進口播。
3. **C08-V3-D01｜script-source-addendum.md 印刷頁 23 的 R1 表格列**：預裝且可量產設計要求實際在 script c080215；補充表仍把它標成 c080213–c080214，兩者分別是 K4 的選設計師與 K1 的桌上用品目標。把該索引改為 c080215（其餘 c080414–415、c080501–503 依實際用途保留），不要把 R1 冒作 c080213 的來源。**文件一致性 HOLD，不表示 c080215 旁白失實。**
4. **C08-V3-D02｜visual-plan.md 標題**：標題仍稱「奇聞檔案局逐鏡方向」，但本件是 story- 品牌故事；curio- skill 在此只供插圖手法。改成「品牌故事逐鏡方向」以免後續錯用系列與路線。**文件一致性 HOLD。**
