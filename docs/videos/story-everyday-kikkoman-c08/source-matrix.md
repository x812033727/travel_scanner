## 尚缺原件與停線問題

1. **1955–1961：**當年一公升瓶的顧客調查、設計委託書、第一張草圖、逐件原型與測試紀錄未找到。K1 的「三年多」和 M1 的「近百模型」是後來敘述，不應製作成有確定順序的紀錄片重演。
2. **1961 市場：**首日販售日期、初期銷量、桌上瓶與一公升瓶之間的替代率、瓶形帶動銷售的因果資料未找到。銷售成果只能按可驗的年期和口徑講，不把設計獎或 MoMA 收藏當銷售證明。
3. **2018 商標：**公司新聞稿和約 0.79 MB 同稿 PDF 可讀，JPO 第 6031041 號原始登錄尚未取得；若正式稿解釋法律權利的範圍，先核原件。這個 2018 節點不等於 1961 年公司就預先計畫取得形狀商標。
4. **畫面授權：**MoMA 館藏與公司歷史照片有使用條款；本集只用匿名可愛插畫及後製自製功能示意。歷史原圖若要直接入片需另處理授權。
5. **長片容量：**本 Treatment 的約十分鐘只是節拍估算。正式第 2–6 章 TTS 需至少 480 秒，來源不夠則縮短或改題，不能重述「經典」「暢銷」或虛構消費者對話填滿時數。
