## 審稿與製作界線

- 主角始終是同一支「要直接從工廠走上桌面」的瓶子；六章順序是大瓶轉注陶壺 → 商品兼桌上器皿的委託 → 手握與放置 → 嘴尖解法 → 1961 年上市與可補充 → 後來的館藏和立體商標。章末問題在下一章得到具體回應。
- 1918 年 1.8 L 大瓶導入、回收再用、1961 年 150 mL 小瓶可再填充按公司容器史 K2a；兩種續用不代表同一物流，也不證明每戶實際續用。1955 年需求、三年多與 2018 年商標按公司事後說法。GK R1 第 23–24 頁的大瓶轉注陶壺、預先裝醬油且可量產、握法、較寬的補充開口和廚房／餐桌對照，都歸屬參與設計者的多年後回顧，不能推成每戶做法、當年銷售比例或設計帶動銷量。
- MoMA 的一點八公升、近百模型、葡萄酒流動性比喻與瓶口解釋均按 2015–16 策展標籤。館方列出的原型難題是**防滴與控制流量並存**；對嘴尖內收角度具體說明的是少積液、少滴，未提供最終流量量測。沒有當年的問卷、設計契約、逐件原型與 JPO 原始登錄。不能稱史上第一支桌上醬油瓶，也不能保證絕不滴漏或推導購買、出貨因果。
