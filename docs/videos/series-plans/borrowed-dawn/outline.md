# 借來的黎明｜十季總綱

誤入異世界的維修學徒發現，繁榮的魔法文明正把休止的代價轉嫁給看不見的人；他與醫師、負罪軍人及守林者，必須在世界失效前建立能讓所有人活下去的退場方法。

分類 anime，120集，封閉結局。播出時段約30分鐘，正文約22分鐘；原定規格不縮為現行短漫劇。
