# 符師與他的鬼

> 搭檔死後一年回來坐在他桌上，只有他看得見；一個寫不出符的符師和一個鬼，要查出全城的命被誰借走。

架空的昭國都城臨淵城，「陰陽司」管鬼怪與符籙。符師沈無咎一年前在一樁案子裡失去搭檔謝清晏，也失去了符力，如今只能在文書房抄卷宗。燈會第一夜，清晏坐在他桌上笑著說「沈大人，你袖子裡有我」——他是只有無咎看得見的鬼，綁在無咎一年前以血寫下、卻始終沒有燒掉的那張送行符上。河上撈起一具一夜白頭的少女屍身，兩人被迫聯手查「借命符」：把窮人的壽數借給權貴的禁符。案子往上追，批文的印是恩師陸崢的，燈油是太師府送的，大理寺少卿韓頌要藉此關掉陰陽司，而一百二十歲、皮膚像三十的太師宗澹，每日換一張子符續命。無咎想要的只有一件事：把清晏留住；他害怕的只有一件事：燒那張符。他不知道的是，一年前將死的人是自己，清晏用借命符把壽數借給了他；他這一年活的，是清晏的命。燒了母符，全城的借出者拿回壽數，清晏的魂是散、還是回？兩個會為彼此死卻絕不說出口的人，只用一張符、一截袖口和數三秒，把話說完。
