# 符師與他的鬼｜第 4 篇：母符

## 本篇

燒了母符，清晏是散還是回——以及一個不記得這一年的人，會不會說出同一句話。

- 賭注：城裡所有借出者的命與清晏的魂：燒母符全城拿回壽數，但無咎的心會停、清晏的魂會散。
- 核心問題：燒了母符，清晏是散還是回？
- 起點：陸崢已死，真母符在燈心；宗澹要無咎做第八個執行者；燈油被太師府拉走。
- 終點：母符焚毀、宗澹化灰、無咎本命復；無咎燒掉送行符讓魂歸體，清晏還陽、不記得這一年；燈會散場。
- 篇末轉折：清晏醒來不記得這一年，第一句卻是「沈大人，你袖子裡有東西」。
- 規劃時段：90–120 分；秒數與鏡數由劇本與 TTS 決定。

### 第 31 集：太師府

**一句話**　宗澹召無咎，要他做新的執行者，「你身上的命是借的，你比誰都懂」；清晏在暖閣子符牆上找到陸崢的名字；無咎假意答應。

| 主要衝突 | 子時，宗澹沒到大燈，而是派車把無咎接進暖閣。他知道陸崢死了、母符不在陸崢身上、無咎活在借來的命上：「做我的第八個執行者，母符上你那三十一年，我讓它不動。」清晏在子符牆上一張一張翻副聯；宗澹的臉朝牆那邊偏了偏，沒攔。 |
| 中段轉折 | 清晏翻過的每一張副聯，符腳都是同一行小字，他看了一眼爐火，念給無咎聽：「憑此領壽，毀之不止——沈大人，這面牆燒了也沒用，燒掉的只是他領壽的憑據，外頭的人照樣老，壽數全堆在母符上等他掛一面新牆；燒了，你的假答應也就破了。」他沒碰爐火，繼續往下找，在牆角最舊那排找到陸崢那一格：木牌「陸」字底下刻著「七」，鉤子上是空的——帳清了，副聯已經摘走；貼身那一聯四十年都在師父腕上，他在符房親手抽出來過。宗澹指著牆上那塊空牌：「那一格空了一年，留給第八個。你答應，清晏的名字我第一個劃掉。」無咎低頭：「規矩是——執行者先借。」他伸出手腕。 |

### 第 32 集：暖閣

**一句話**　無咎在暖閣看見宗澹每日「換」一張副聯續命，找到大燈燈心的鑰匙在藥爐裡；府外大理寺圍府被禁軍擋住，爬牆送信的阿七被擋下牆，哭聲傳進暖閣。

| 節拍 | 內容 |
| --- | --- |
| 開場鉤子（畫面） | 「他每天早上，換一張命。」 |
| 主要衝突 | 清晨，宗澹在藥爐前開始他每天的換符：解開衣襟，揭下貼在身上的昨日那張副聯，捏在指間慢慢撫平，還沒往牆那邊走——換一張命。無咎被留在暖閣「學規矩」，清晏穿過藥爐底座，看見爐膛裡一把銅鑰匙，齒形對得上燈心火裡那個鎖孔：銅蓮座的。宗澹朝藥爐偏了一下頭，又轉回去。封死的窗板外傳來列陣的腳步與喝令；旁白交代：大理寺圍了府，禁軍擋在門口。 |
| 中段轉折 | 封死的窗板外一聲悶響，接著是阿七的哭聲和半句「無咎大人」；旁白交代：爬牆送信的阿七被禁軍擋下牆來，傷了手臂，大理寺的人把他拉了回去。無咎在暖閣聽著阿七的哭聲，臉沒動；宗澹捏著那張舊副聯轉身走到子符牆前，把它掛回鉤上、伸手去摘另一格那一張——就在他背對藥爐的這一瞬，無咎把手伸進爐火，攥住鑰匙收回拳裡，一聲沒叫。 |
| 爽點 | 前半／藏拙露鋒：清晏穿過藥爐底座，在火裡看見一把銅鑰匙，回頭對無咎比了一個「燈」的手勢。<br>後半／首殺／首通：無咎趁宗澹背對藥爐、把舊副聯掛回鉤上的那一瞬，把手伸進爐火攥住銅鑰匙、收回拳裡一聲沒叫——燈心的鑰匙第一次到了陰陽司手上。 |
| 結尾懸念（危機） | 宗澹貼好新的一張、繫上衣襟，轉回身看見無咎攥緊的拳頭，笑了：「拿吧。鑰匙開得了燈心，開不了燈——母符只有那盞燈的火燒得掉。今晚沒有油，燈會熄。」封死的窗板外，車輪聲一輛接一輛輾過去——太師府的車正把最後一車燈油拉走。清晏：「沈大人，油在他手上。」 |

### 第 33 集：燈心

**一句話**　他們回到大燈，母符就在燈心，清晏名字旁寫著「借予沈無咎」；無咎明白燒母符他就會失去借來的命——除非本命還在；清晏：「你本命還在，只是被蓋住。」

| 節拍 | 內容 |
| --- | --- |
| 開場鉤子（反轉） | 「我的名字旁邊，寫著借予沈無咎。」 |
| 主要衝突 | 無咎纏著手回到大燈，燈焰因缺油矮了一半；他用鑰匙打開銅蓮座，母符攤開在面前：幾十個名字，清晏的名字旁「借予沈無咎，執行，陸」。老尤把最後一桶私藏的清油抱到燈台下，按住桶蓋沒倒：「還不是時候。」 |
| 中段轉折 | 無咎算出來了：母符拿出蓮座也沒用，別的火點不著它，只有這盞燈的火燒得掉；燒母符，壽數歸還——清晏的三十一年回到清晏身上，他的借命就斷；本命若已斷，他當場死。清晏在燈心旁說：「你本命還在，只是被蓋住——你的血寫得出送行符，那就是本命的血。」 |
| 爽點 | 前半／首殺／首通：銅蓮座打開，母符第一次完整攤在人的面前，幾十個名字一列列，無咎用纏著布的手把它攤平。<br>後半／反轉：「你的血寫得出送行符，那就是本命的血。」——第 5 集那張血符，原來一直是無咎本命還在的證據。 |
| 結尾懸念（揭露） | 老尤在燈下說出藏了十年的話：「太師府的油，我灌了十年，連燈骨裡那疊白紙都是油車寄在我鋪裡的。那油年年摻著東西——燈一亮，母符就燒不掉。」他把一小瓶油舉到燈前，油裡浮著一層朱砂。 |

### 第 34 集：本命

**一句話**　溫檀與韓頌翻出古籍：借命歸還時本命若未斷則復；但要確定，得先讓借命停一瞬——無咎必須在燒符時「死」一次。

| 節拍 | 內容 |
| --- | --- |
| 開場鉤子（危險） | 「燒符的時候，你得先死一次。」 |
| 主要衝突 | 溫檀與韓頌翻完最後一箱古籍，找到兩句。一句是頁注：借命蔽本命，餘息可血留一符，不復成術——一年前那張血符用的確實是本命的餘息，清晏猜對了一半；另一句：借命歸還，本命未斷者復。但那口餘息如今還在不在、本命斷沒斷，只有借命停下那一瞬才知道——母符燒掉那一刻無咎的心會停，停多久沒人寫。清晏聽到「心會停」，穿牆出去。 |
| 中段轉折 | 無咎追到冰窖，清晏坐在自己的屍身旁，第一次背對他說話：「一年前你倒在地上我看著，這次換我看第二次？」無咎蹲下，把送行符放在石台上、兩人中間：「數三秒。三秒之內我醒，你就別走。」 |
| 爽點 | 前半／升級：溫檀念出「本命未斷者復」，韓頌在旁邊把整箱禁書一本一本歸位——大理寺少卿替陰陽司整理禁卷。<br>後半／反轉：「一年前你倒下我看著，這次換我看第二次？」——清晏說的是他自己親眼看過的那一夜。 |
| 結尾懸念（情感） | 清晏看著那張符很久，伸手把它推回無咎那邊：「三秒。多一秒我就掀了你的冰窖。」門外韓頌喊：「宗澹的禁軍進城了，往陰陽司來。」清晏的輪廓在冰窖的白裡亮得像燈。 |

### 第 35 集：宗澹的帳

**一句話**　宗澹到大燈下說出九十年的帳：每一任司正都是他的借命執行者，「陸崢是第七個」；他要無咎當第八個；清晏站在燈心，第一次被宗澹看見。

| 節拍 | 內容 |
| --- | --- |
| 開場鉤子（台詞） | 「九十年，我換了七個司正。」 |
| 主要衝突 | 宗澹帶禁軍進陰陽司，在大燈下不動手，先算帳：借命九十年、七任司正、每一任先借出自己的命再替他執行，「陸崢是第七個，你是第八個」。無咎站在燈台一人高的底座上，母符在頭頂的燈心裡，槽底最後一層油撐著燈焰；老尤護著那桶還沒倒的清油，對著滿院禁軍只說了一句：「燈不會騙人。」 |
| 中段轉折 | 宗澹說出最後一筆：「一年前的借命符，是我讓陸崢遞給清晏的——我要的不是救你，是留一個活在借命上的符師，寫不出符、翻不了我。」清晏從燈心走到燈台邊，宗澹的眼睛跟著他動——他看見了。 |
| 爽點 | 前半／打臉：宗澹說「你是第八個」，無咎舉起那把燈心銅鑰匙：「燈心我開了。第八個執行者，先開了你的帳。」<br>後半／身份揭露：宗澹的眼睛跟著清晏從燈心走到燈台邊——燈裡母符的主人，一百二十歲，站到這盞燈的光下，第一次看見清晏。 |

### 第 36 集：母符的主人

**一句話**　宗澹看見清晏，甩出一張子符黏住他的魂；清晏躲進送行符；無咎把符貼在胸口；禁軍圍燈，大理寺衙役入院對峙；阿七爬上燈頂。

| 節拍 | 內容 |
| --- | --- |
| 開場鉤子（危險） | 「沈大人，他看得見我。」 |
| 主要衝突 | 宗澹踏上燈台，從袖裡甩出一張子符——是清晏自己的貼身聯，一年前那一夜陸崢從他腕上揭下、交回太師府的那一張；母符主人手上的子符，黏得住它繫著的那個魂。子符黏上清晏的袖口，他的輪廓開始散。無咎撕開左袖，把送行符抽出來攤開：「進來。」清晏扯下子符往符裡一縮，送行符燙得冒出白氣，無咎把符按在胸口。 |
