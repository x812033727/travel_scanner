# 她替公主試毒十年

> 替公主試毒十年的嘗使，一口一口嘗出太后的毒、皇帝的病、井裡的藥，最後嘗出自己是先帝的長女。

架空王朝「大燁」的皇宮裡，每道呈給皇族的菜都由「嘗使」先試七口。姜含章十二歲進司膳院，替長公主元霽試毒十年，她的舌頭嘗得出毒、產地、水源，還嘗得出「做菜的手」。太后壽宴上她試到第三口就嘗出雪蠶散，規矩要她吞下後只報毒名、不准指認來源；她吞了，然後當著滿殿說出毒名、廚子的手法與出自慈寧宮小廚。從那一口起，她被太后當刀、被公主當餌、被皇帝當戲裡的角，一路嘗出太后每日賜的解毒湯是抹記憶的「忘憂」、皇帝批奏摺的墨裡有攝政王的烏砂、全宮的病都出自玄泉井引水道的藥包，最後嘗出自己的血脈：她是先帝與淑妃的長女，先帝的遺詔藏在御膳簿封皮夾層，用只有嘗使家讀得懂的菜名密碼寫成。她想要的只有兩件事：活著，知道自己是誰。擋在前面的是掌司膳院的太后、要皇位的攝政王，以及那位從不吃她試過第一口的公主。
