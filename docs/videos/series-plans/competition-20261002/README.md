# 《喜宴未散，清算開始》｜三個月點閱競賽製作包

選片定案：**喜宴未散，清算開始（wedding-reckoning）**。更新日期：2026-10-02，台北時間。

**使用者最新指示是全部優化後，先製作前兩集繁中影片。** 40 集的最後優化指令已覆核，E1／E2 完整演出文字及繁中聲音預演已完成；E3–40 的完整演出稿尚未寫完。目前動畫生成為 **0 秒**，兩集聲音仍有辨字項目待查，尚未通過人工聽校或畫面驗收。

從 Codex 原有五部中選這部，因為婚禮拒簽的衝突容易跨語言理解、第一個反擊能在 30 秒內看見，姐妹信任能支撐兩小時的情感收束；主要角色為成人，亦較適合已規劃的 Veo Lite 首格路徑。這是編輯與製作判斷，沒有點閱預測或市場實驗可保證勝出。

## 已定的目標與本輪範圍

- 本輪只做 **E1／E2、自然台灣口音繁中配音、繁中可開關 CC 與對應畫面**，不自動追加 E3。
- 全片仍以原創完整長片為目標，規劃 120 分鐘、115–125 分鐘以實際成片量測；40 集是內部製作單位，不把 40 個片頭片尾接進長片。
- 動畫指定 Gemini API `veo-3.1-lite-generate-preview`、1080p、16:9、全動態；每份來源素材 8 秒，依表演剪取，禁止靜畫運鏡或尾格停格補時。
- 最終為 **zh-TW、ja、ko、en 四種角色配音／旁白＋各自可開關 CC**，不燒對白字幕、不額外加入 zh-CN。**整部繁中影片與 CC 完成，經使用者本人確認後，才開始日韓英產線實作、台詞適配、試音、配音、混音與 CC。** 目前外語樣稿僅留存，不執行、不花費。
- YouTube 兩部完整主片各自公開滿三個月，以主片觀看次數判勝負；觀看數與成本分開評、最後一起比較，不設加權總分。四語音軌集中同一支主片，四語都須在競賽公開前驗收及掛載；日期未排定，現在不啟動倒數。

## 從這裡完成兩集

先處理辨字待查台詞、完成繁中聽校，再依實測剪輯製作角色／造型及關鍵影格，驗一鏡與開場動作後逐批完成 E1／E2。必須保留同臉換裝、拒簽撕展示副本、完整原件位置及無台詞動作；可見嘴部另驗口型，所有畫面窗口都要有有效動作。兩集完成混音及繁中 CC 後，以實際採用率、重試與成本校準後續製作，不為規劃容量補空白或停格。

目前已新增僅限本作兩集的受控執行器，**42 項離線測試通過，但尚未部署，執行 host 尚未配置，真實文件／劇本核准仍待完成**。離線測試不代表線上媒體生成已可用。全域 `drama_enabled` 維持 OFF，不為本案開啟其他作品或全域 queue；全域 clip 仍為 Omni 的歷史讀值不構成「必須先切全域模型」的前提。正式請求須由已部署、配置完成且經核准的本作範圍路徑鎖定 Lite、集數與支出，詳見[執行手冊](episodes/scoped-production-runbook.md)。
