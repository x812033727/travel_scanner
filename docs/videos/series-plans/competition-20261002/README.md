## 這一輪完成的是什麼

這是一份**最後優化的具體執行包**：已選片、逐集安排修訂、寫出開場樣稿、設定四語交付與競賽規則。並非40集完整台詞已全部定稿，也沒有產生音檔、動畫、CC、縮圖或上架成品。候選聲線不等於實際試音；字幕文字不等於已按聲音對時。

原故事單一來源仍是 [source.mjs](../binge-five-20260928/wedding-reckoning/source.mjs)。本包是送入下一輪writer/verifier的**新增製作指令**，不是worker會自動讀取的設定。不可只把檔案放進Git就宣稱正式後台已採用。

下一輪必須逐集將本包對應列及已接受台詞納入writer輸入，保留既有設定／總綱／細綱／連貫性上下文，經verifier檢查再形成 `video.json`。每集需存「來源hash＋本包hash＋實際採用台詞／分鏡＋檢查結果」；開場新台詞通過前，不得冒充既有source中的原句或正式核准。
