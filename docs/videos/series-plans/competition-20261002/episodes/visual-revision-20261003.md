## 已實看素材的問題

主代理與另一代理重看實際 S01 R02 首格、S01 R04 聯絡表及 S03 R03 首格，所得美術／導演問題如下；聯絡表檢查不聲稱完整實速播放或聽音。

| 問題 | 修正目的 |
| --- | --- |
| S01 正面置中、肩膀放鬆、大面積門板，像人物展示 | 讓人物、封閉出口與手中筆形成視覺關係；較近構圖與受壓姿態應傳達受困處境 |
| 眨眼和手指微動占主要變化，眉眼與姿態缺乏情緒 | 先定一個可讀表演目標，如壓住恐懼的戒備，再用視線、下顎及肩背支持它 |
| 火光均勻染橘，臉與衣服平；背景缺乏前後層次 | 確立光源、面部明暗與材質差別，讓注意力先到眼神和手，避免用裝飾或粒子代替美術 |
| S03 蕾絲比簽署資訊搶眼，紙張只有線與框 | 把構圖與細節集中到有敘事作用的手、筆和未簽欄；需要的文字經排版核對後合成 |
| 前五秒取樣中姿態大致相同，新增視覺資訊少 | 先以既有旁白做剪輯草稿，驗證觀眾能感受到的察覺／決定／動作；改鏡頭或時序要重綁相應來源與審核 |

上述建議按情境使用；靜鏡、低細節或平塗並非一律不合格。這次失敗在於美術與鏡頭選擇沒有服務被困危機和情緒。
