# 末班車上的第七個活人｜四篇四十集總綱

維修員程望搭上末班車，看見過世七年的母親在月台招手；原票目的地鋼印是 17，門底月台鋼印卻是 04。六名有座乘客以為必須推出一名亡者，才發現第七個活人被偽裝成售票人，而這班本應送瀕死者回家的列車遭到亡故列車長挾持。

每集目標三分鐘，以下時間為規劃，不是實際配音或成片時間。

## 全季張力地圖

| 1 | 0–30 分 | 從程望差點走下假月台，升至全車可能把活人當亡者推出去。 | 可以驗證的規則藏在哪裡？ | 第 10 集剝開紅漆，出現朝返程方向延伸的原始路線，列車有另一種用途。 |

## 第 1 篇：先活過第一站

恐懼中的第一件事是確認眼前的人還需要幫忙。

起點：六個座位各有一位乘客，售票人站在售票隔間裡；沒有人理解鋼印。

終點：程望找到原路白線，知道廣播能說謊，卻仍不清楚誰是真的母親。

| 集 | 標題 | 推進與新問題 |
| --- | --- | --- |
| 01 | 她在月台等我 | 母親影像誘程望跨門，小滿用相互矛盾的票印替他爭取核對時間。 |
| 02 | 還沒到的死期 | 徐浩要立即敲開車門，認為等下去就是死；程望把票面和徐浩腕上仍在走的錶並置，阻止他砸門引來假月台。唐綺注意六張票的白光伴隨不同節奏的輕嗒聲；程望貼耳隔間壁板，竟多聽見一組很弱的同類聲響，此時尚未確證它與心跳的關聯。 |
| 03 | 這次換我拉住妳 | 小滿被家人在出口等候的泛化通知誘到門邊，程望使用鋼印核對將她帶回。 |
| 04 | 紅字底下有白字 | 程望與護理師喬寧發現規則牌的新漆，售票人卻要求他們以缺一人為前提填表。 |
| 05 | 借來的名字 | 唐綺換走徐浩的票後叫不出自己的小名，程望把表面因果拆開，保住雙方原票。 |
| 06 | 窗上那天不是今晚 | 程望核對當晚末班車記憶，發現老事故的殘影混入乘客證詞，制服也不能證明售票人來自死者。 |
| 07 | 媽媽以前這樣敲門 | 程望跟著熟悉節奏找到白燈線路，卻拒絕因為認出母親聲音便開門。 |
| 08 | 票跟著誰的心跳 | 喬寧協助比對脈搏與票孔，證實交換車票不能交換命，弱光也不能立即判死。 |
| 09 | 把老人帶回座位 | 紅色電子牌無聲顯示「慢心跳是亡者偽裝」，徐浩抓住老人購物袋要他下去；程望扣住袋帶，小滿把票孔微光照到徐浩掌心。顧永第一次主動說不下車，並指出售票人站在票聲最清楚的位置；徐浩放手但尚未向他道歉。 |
| 10 | 覆漆底下那條線 | 程望揭下覆漆薄片，發現原始線路不是通往墓地，而是指向返程站。 |

## 第 2 篇：誰在開這班車

證據可以分清真假，卻不能讓失去變得不痛。

起點：原路拓印證明返程設計存在；乘客仍會被相同聲音誤導。

終點：確認列車本來救瀕死者、陸循為亡女維持循環，程望已支付一段永久記憶。

| 集 | 標題 | 推進與新問題 |
| --- | --- | --- |
| 11 | 只寫驗過的事 | 程望將拓印拆成可查證清單，阻止徐浩把猜測再寫成另一套命令。 |
| 12 | 售票人在怕什麼 | 何照承認聽命列車長，說出自己的票被扣；他知道票上有自己的名字、自己可能還活著，卻怕列車長扣票不還，不敢以乘客身分相認。 |
| 13 | 兩個一樣的敲門聲 | 列車長複製三短一長敲擊，程望用聲道與實物核對拒絕假母親的命令。 |
| 14 | 每一站都問同一句 | 小滿與唐綺用重複對白識破換景不換內容的幻月台，找到女孩木哨的差異。 |
| 15 | 玻璃後的事故條 | 原始事故走紙讓程望面對自己當年如何生還，母親的死不再只是他反覆責怪自己的片段。 |
| 16 | 團聚的收據 | 唐綺辨認自己的交換壓痕，程望確認失去小名記憶是先前交易所致，不是換票的懲罰。 |
| 17 | 急救櫃要一段回憶 | 連接廊裂隙困住顧永，程望交出最後共餐記憶換開急救櫃，與小滿拉回老人。 |
| 18 | 他不肯亮出自己的票 | 程望先把自己的原票攤給列車長驗，何照因此違令移開遮紙，名冊露出列車長和女兒都是七年前的亡者；陸循隨即多繞一圈假站，搶走兩分鐘。 |
| 19 | 白燈那頭是誰 | 白燈聲道指向未曝光的檢票紀錄，程望核對成功才接受真正母親在引導他。 |
| 20 | 紅拉桿壓住了什麼 | 程望將返程副頁、死亡名冊與當夜覆寫痕跡並讀，確認列車不是審判場所而是被操控的救援。 |

## 第 3 篇：最想相信的謊

拒絕用別人的未來，換一個不能成真的過去。

起點：知道列車本為救援，但沒有完成返程的條件。

終點：七人身份與機械流程齊備，小滿的搶救時限即將耗盡，必須付出告別的代價。

| 集 | 標題 | 推進與新問題 |
| --- | --- | --- |
| 21 | 地圖上的十七號 | 機械地圖上的 17 只有普通月台，沒有任何親人影像；徐浩因此懷疑，程望用原票和路線走紙三方核對。小滿拓下終點與時限欄，欄上的 00:17 正是她自己票上的截止；何照因原票仍被扣，透過通話口向陸循報出位置。通話口那頭沒有回話，陸循隔空降下地圖的遮板，但副本已在小滿手裡。 |
| 22 | 壓在白牌上的表框 | 最後一片紅覆片被陸循的留置表框壓在白牌上；程望不肯先填一個名字，親手卸下表框，喬寧撕掉假表，完整白牌才露出原規則，取代列車長的零和謊言。 |
| 23 | 他要加進清單的票 | 陸循拿女兒的票要求加進清單；程望不以單次無光下結論，請喬寧對照七年前的五月二十七日與票面死亡時間欄上早已過去的截止時間。照眾人對搶救時限的推測，陸安的搶救時限七年前就已過去，票孔不是當夜短暫變弱；陸循收回票，轉而亮起取自第17集交換記憶的飯桌幻景，飯桌旁還沒有人。 |
| 24 | 飯桌又擺上來了 | 幻景能重播程望交出的共餐片段，卻不能令他恢復感受，迫使他認清交易只會越拿越多。 |
| 25 | 兩張票換一頓飯 | 程望關閉自己最想要的幻景，拒絕跟亡母的影像走，握緊自己的原票，向真正母親承認自己還會難過。 |
| 26 | 不把誰劃掉 | 徐浩因小滿惡化而提出只救最快的幾人，程望以何照被漏算的原因阻止投票決定命運。 |
| 27 | 夾在門縫裡的名字 | 程望救回洩密過的售票人，原票、脈動與名字三方相合，七位生還者終於全部列入名單。 |
| 28 | 紅廣播一直改站名 | 何照領程望與唐綺讀取封存復位流程，將逃生從求奇蹟變成各人可分擔的四項工作。 |
| 29 | 她的票快不亮了 | 小滿的票孔出現停頓，喬寧照眾人對時限的推測，區分暫時心跳停止與時限已過，眾人守住她的返程資格。 |
| 30 | 最後一趟，不會再等 | 真正母親證實眾人先前對搶救時限的推測，並說明引導燈交接，程望得知救完活人就必須讓她永久離開。 |

## 第 4 篇：最後一段路

離開的人不必復活，留下的人可以重新生活。

起點：七人清楚條件與代價，但小滿的時限將盡；列車長仍不肯釋放拉桿。

終點：七人實際生還，兩個家庭的亡者沒有復活；程望帶著不可修復的記憶缺口往前走。

| 集 | 標題 | 推進與新問題 |
| --- | --- | --- |
| 31 | 電子牌提前亮了 | 程望將原票、原路圖與實體岔標逐一對齊，先排除電子牌偽造的終點。 |
| 32 | 每個人守一件事 | 何照、唐綺與顧永分工守路線、讀紀錄和穩住白燈，主角不再一人包辦返程。 |
| 33 | 窗外還有好多個家 | 乘客按原始流程切離幻景支路，親人影像陸續消失，剩下真正道路和必須交接的白燈。 |
| 34 | 檢票座上的那盞燈 | 程望用自己的原票完成引導交接，母親在他接穩黃銅燈後結束滯留。 |
| 35 | 陳列盒裡的木哨 | 何照從陳列盒取出裂開的木鳥哨，程望親手交還陸循，讓他看見真實女兒的遺物而非可以重播的幻景。 |
| 36 | 最後一根拉桿 | 陸循鬆開拉桿停止挾持，選擇留在無乘客的循環端處理自己造成的殘留。 |
| 37 | 門外傳來站聲 | 返程門開而小滿無法自己站立；程望、喬寧、何照仍與她同在門內，先核對原票、實體17鋼印和返程箭頭，不能因聽到普通站聲就搶先跨門。黃銅白燈照見實體17，箭頭與原票一致。驗證完成才放行：清單上顧永、徐浩、唐綺三行先畫上通過記號，三人已先過門；程望與喬寧扶小滿跨門，何照確認清單七行均已標記後最後離開。 |
| 38 | 監視器還在響 | 醫院名單確認七人生還，何照恢復本名，乘客開始為活著的生活互相照顧。 |
| 39 | 那則沒聽過的留言 | 程望終於播放母親舊留言，接受聲音能留下但已失去的共餐感受不會恢復。 |
| 40 | 這一站是今天 | 程望搭上普通白天列車，替顧永與小滿扶住車門，把曾經只想回到過去的手伸向當下。 |
