# 朕不是你們的替死鬼｜四篇四十集總綱

群臣把一名庫房女吏扶上皇位，準備在登基第三十天讓她替饑荒與虧空陪葬。她登基後做的第一件事，是撤掉自己的御膳，先喝一口災民正在吃的粥，再把同一碗推到首輔面前。

每集目標三分鐘，以下時間為規劃，不是實際配音或成片時間。

## 全季張力地圖

| 篇 | 時間 | 賭注 | 核心問題 | 篇末翻轉 |
| --- | --- | --- | --- | --- |
| 1 | 0–30 分 | 第三十日祭天時的性命與城內斷糧倒數。 | 一枚受制於人的御印，能否換來一碗真正的粥？ | 從以為自己只是被輕視的新君，轉為確認自己是被預定犧牲的簽字者。 |
| 2 | 30–60 分 | 已參與救災的人會因她失敗而被追究。 | 在真正的身世被揭開以前，她能交付多少真實的承諾？ | 她以為可以用帝王身分對抗權臣，最後發現這身分也是權臣給的繩索。 |
| 3 | 60–90 分 | 弟弟性命、替代商路、群眾是否願意接受知情的合作。 | 若代價是犧牲自己答應保護的人，留下來還有什麼用？ | 從設法保住皇權變為請眾人決定是否繼續給她救災權限。 |
| 4 | 90–120 分 | 能否在不犧牲無辜者、不偽造新血統的情況下重建供糧與政務。 | 眾人如何支持她，又如何保留攔住她的權利？ | 祭天的代罪臺變成共同驗證責任的公開桌，女主不再靠別人安排的身分留在位置上。 |

## 第 1 篇：先讓城裡的人活下來

命令值多少，要看有多少人真正收到糧。

起點：葉穗有冠冕與御印，沒有獨立官署、兵力或家族；仍相信皇族認親。

終點：第一批救急糧送到，軍商合作仍有限；她發現祭天真正要處死的是自己。

| 集 | 標題 | 推進與新問題 |
| --- | --- | --- |
| 01 | 萬歲先喝這碗粥 | 葉穗用同一碗粥讓登基宴無法繼續假裝太平，並找出自己能先動用的一筆糧。 |
| 02 | 先削我的宮宴 | 她以縮減宮宴為代價撥出現成糧額，卻發現御命在送達之前就被卡住。 |
| 03 | 滿帳空倉 | 帳本聲稱儀典糧充足，實際倉門後只有半垛麻袋；葉穗先把能用的糧分出，拒絕替不存在的糧簽收。 |
| 04 | 秤砣也會說謊 | 葉穗公開對秤，把原本會在分糧時消失的一截重量留下，卻暴露了官倉與關卡使用不同標準。 |
| 05 | 只護這一趟 | 葉穗用實物口糧換得禁軍一次護車，韓鐸卻在收到一張藥單後改變原定路線。 |
| 06 | 把大車拆成小車 | 葉穗與唐敏談妥額外車工，分批走仍開放的小道，拿到同一車糧被抽了兩次糧的收條。 |
| 07 | 有粥，也要有人看病 | 女主把施粥與醫棚接在一起，弟弟主動接手車工；羅杏看見那張沒簽的足額收訖上的承責用語後異常驚慌。 |
| 08 | 讓命令走出門 | 葉穗利用每件公文應有的送達回執逼開文簿房封鎖，看到自己的族譜證明竟與上月檔案共用新紙。 |
| 09 | 同一袋糧收兩次 | 女主讓商家與街坊當面對收條，發現雙重徵糧是固定流程、還牽涉軍糧欄；她保住了原件，唐敏的糧車卻被扣在關內。 |
| 10 | 祭天名冊上的人 | 她順著轉撥責任找到祭天罪詔，確定自己只被留了三十天，另一份繼位草約已先備好。 |

## 第 2 篇：每一次合作都要付帳

信任不是一次表態，是每次兌現。

起點：葉穗知道祭天殺局，但首輔仍掌握文書與糧路。

終點：女主取得有限軍商信任並救出被扣家屬，卻確認自己連皇族身分都是偽造。

| 集 | 標題 | 推進與新問題 |
| --- | --- | --- |
| 11 | 照你們的日子祭天 | 葉穗假意接受祭天行程，以籌備名義取得公文追送權，讓首輔把自己的祭天日程寫進紙面。 |
| 12 | 關卡不是誰的錢袋 | 女主撤掉查無設立文書的臨時私卡，唐敏取得一條可談合作的商路，韓鐸的沉默也露出原因。 |
| 13 | 讓車替命令作證 | 當反對者聲稱撤卡只會放進劫糧者時，葉峻帶回一車可逐戶核對的救命糧。 |
| 14 | 誰欠誰的糧 | 何靜把重複收條與所謂借據疊在一起，證明街坊遭偽造債務，追出侵吞鏈中的轉抄方法。 |
| 15 | 糧商不收空頭萬歲 | 女主與唐敏訂下限期付款、不得強徵車工的協議，意外看見北倉條款與自己認親用紙來自同一批。 |
| 16 | 先把欠的餉送到手 | 葉穗把已追回的重複抽糧按公開順序折給值守軍戶當欠餉，延後的一筆貨款也當面說清。 |
| 17 | 統領收到的那封信 | 韓鐸交出妹妹被扣與軍餉私借的雙重威脅，葉穗選擇先解開人質而非逼他立刻反首輔。 |
| 18 | 換診的那一天 | 羅杏依法轉送病患，韓芮帶出移送紀錄；女主不以救命恩情索取無限兵權。 |
| 19 | 養母沒有燒掉的紙 | 首輔威逼羅杏交出舊紀錄，葉穗靠先前紙批線索追到醫舍，聽見養母承認認親文書有假，首輔卻帶走了能拆穿她的副本。 |
| 20 | 把三份日期放在一起 | 三份可交叉核對的日期證明葉穗不是皇族，她必須決定是否繼續借謊言完成救災。 |

## 第 3 篇：糧車後面的條件

守住位置若要出賣他人，留下來便沒有意義。

起點：女主知道假身世，群眾仍未知；真正皇族帶北倉糧與秩序承諾入城。

終點：葉穗拒絕婚姻與殺弟交易，搶在祭天前坦白假血統，失去以身分發令的保護。

| 集 | 標題 | 推進與新問題 |
| --- | --- | --- |
| 21 | 有糧的皇族 | 蕭承越以真族譜和北倉糧入城，葉穗承認他的資源價值，同時要求把附帶條件放到桌上。 |
| 22 | 讓受災的人自己說 | 葉穗開放街坊帶收條陳情，第一次聽到有人寧願換一位有糧的君主，也看到弟弟救災路線的證人。 |
| 23 | 鎖住的不是空倉 | 豪族集體封倉，女主拒絕立即強徵，把僅剩的存糧與小商戶供應時間公開，爭取短期替代。 |
| 24 | 被扣住的軍糧 | 首輔以欠款未清卡住禁軍口糧，何靜找到軍糧其實曾被轉入同一私倉的紀錄。 |
| 25 | 被抓的運糧人 | 葉峻因冒用過期牌被捕，女主擋下未經核實的劫糧罪，卻留不住弟弟，自己知情未報的事也被賈勳拿去指她徇私。 |
| 26 | 親人也不能免帳 | 受糧戶與商人完成糧源去向核對，葉峻洗清劫糧罪，但接受冒牌停運與補登處分。 |
| 27 | 不是誰的私印 | 葉穗在朝議承認救災權需要邊界，提出有限期的公開核帳安排，保住正在運轉的小額糧約。 |
| 28 | 一場婚姻，一顆人頭 | 蕭承越屏退旁人，提議以婚姻替她的假身世補合法性，條件是處死葉峻並追認北倉舊款。 |
| 29 | 留給她的最後一頁 | 首輔把真實收養副本夾入祭天罪詔的附件，女主從送達簿得知，轉而準備公開自己的完整知情時間。 |
| 30 | 朕有話要說 | 葉穗提前向全城承認假血統，交出查證檔案與自己的知情責任，請大家把救災與是否留她分開決定。 |

## 第 4 篇：先看帳，再叫萬歲

真正的支持允許提問，真正的權力承擔限制。

起點：假身世公開、停糧令抵達，女主被質疑；小商路與現場收條仍是真實成果。

終點：首輔被依法控制，北倉壟斷瓦解；數月後各方議約擁立葉穗，她以本名宣誓，接受持續核帳。

| 集 | 標題 | 推進與新問題 |
| --- | --- | --- |
| 31 | 有人留下，有人轉身 | 部分商戶退約、百姓要求女主離開，葉穗先兌現退款與口糧清單，才提出限期共管救災。 |
| 32 | 刀守的是哪條路 | 韓鐸拒絕用禁軍驅散領糧百姓，簽下有限護運條款，替代糧路終於送來足以解除一日倒數的新糧。 |
| 33 | 三張桌拼成一本帳 | 商人運單、街坊原條與官府底冊公開並列，假借據的全流程被查清，賈勳不能用交證換全身而退。 |
| 34 | 午間送到的調兵令 | 首輔假傳調兵令，女主靠早已保存的送達回執發現新令重複用了舊送達號，韓鐸因此能有據拒令；首輔隨即讓內廷帶走何靜，把祭天提前。 |
| 35 | 同一張約，兩個主人 | 女主把北倉附約與賈勳交出的底冊交叉對照，逼蕭承越面對一張原本保護他、現在會被用來代罪的共同草約。 |
| 36 | 祭天臺上的核帳桌 | 女主把本來要宣讀罪詔的祭臺改成核帳桌，讓偏秤、雙稅、假軍糧和首輔私倉接成完整責任鏈。 |
| 37 | 交出那枚調兵印 | 韓鐸依公開證據與共同見證控制首輔，葉穗拒絕當場處死，把處罰與追回糧款留下正式程序。 |
| 38 | 讓下一道命令也能被問 | 女主與糧吏、商戶、街坊訂立限期政務條款，同意自己的任命、支款與指令都留公開副本；知情審查給她記下一過，北面兩州也退回了邀請。 |
| 39 | 第一批新糧 | 數月後首批回耕新糧入倉，眾人看到不完整但可持續的恢復，女主也接到各方正式議約的回覆。 |
| 40 | 先看帳，再叫萬歲 | 葉穗在已協商完成的擁立儀式上以本名宣誓，把糧帳放在自己與民眾之間，接受第一個公開追問。 |
