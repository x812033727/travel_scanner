第三輪修正（提交 `572bb9c98`）之後，十部作品各由一名沒有寫過它的代理完整讀過設定集、四十集細綱、連貫性表與包裝，再由主審抽驗約四十處原文。這份文件記下當時找到的問題，以及哪些在本輪修了、哪些留給站主決定。

- **行號**指第三輪修正後、本輪修正前的來源檔（`572bb9c98`），封存在 `reviews/round-03/<slug>.source.mjs`（Codex 五部）與 git 歷史（Claude 五部）。本輪修正後行號會位移，請以引文為準。
- **分級**：「必修」是確定的矛盾，撰稿或觀眾會出錯；「小修」是確定而改動很小的不一致；「留待決定」需要站主或作者取捨，本輪沒有動。
- 這是文字企劃的稽核。沒有看成片、沒有試聽、沒有上網查同名或相似作品；相似度的判斷都來自記憶，需要另行查證。
