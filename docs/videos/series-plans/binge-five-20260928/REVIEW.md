## 實際修正重點

### 喜宴未散，清算開始

- 司儀催簽未登記；遠端訊息可能變成多出的發聲角色。 → 由顧承川催簽；28 集知夏與31 集叔父以文字訊息出現。
- 叔父「妳記得的辦法」暗示知曉重生。 → 改為只針對當前查帳辦法，知情範圍備註同步。
- 淑雲救援位置跳動，火場六集未交代並行時間。 → 固定在安全側以通訊引導；29–38 集補時刻，30–35 為約八分鐘救援的交錯視角，不逐集順延三分鐘。
- 33 集鉤子說愛人正在鎖門，與妹妹視角及當集實際棄人行為不符。 → 改為「他先走了，把人留在裡面」，直接兌現本集行為。

### 末班車上的第七個活人

- 交換所得才可播放私人記憶，卻在交換前演出小滿家人及徐浩女兒的私密幻景，造成反派權能矛盾。 → 規則改為僅能使用封存事故、自己女兒記憶、可見物件與已聽聲線；母親取自舊引路紀錄，小滿/徐浩只有泛化門景與通知，私人共餐仍須 17 集正式交換後才能播放。
- 何照只記得一個照字卻沒有三步記憶交換，無法解釋失憶來源。 → 明寫始終記得全名，只因害怕報復不敢說出；27 集取回自主與證票資格，不是魔法恢復記憶。
- 上鎖抽屜鑰匙在陸循手中，後期取票突然出現後側槽。 → 場景設定和第 4 集可見卡票清理槽，第 12 集交代位置、機械扣和先前不敢使用的原因，再於 26–27 集回收。
- 泛化廣播和結尾吃飯聲的演出未完全對應已登記聲線，包裝缺必備標籤。 → 第 3、27 集把陸循加入 cast，第 33 集以陸循替換無本集動作的程望；第 39 集由唐綺邀吃飯，tags 補漫劇、AI漫劇、一口氣看完。

### 朕不是你們的替死鬼

- 第16集說妹妹翌日跨城轉送，第18集卻到第13日才救出，中間缺一天的攔截理由。 → 第17集明定第12日由羅素具名承擔翌日公開轉診，以軍隊不得入院為條件換暫緩當日移送；回執與次集日期一致。
- 第23集兩日存糧原未交代如何維持到第32集九日後的新糧。 → 第24集追回實物扣糧支應20至21日，第26集預付小單支應22至23日，第28集另一預付小單減配支應24至26日；第31集只剩本日，32集才完成可連續護運的新批。
- 第9集關門扣原件的即時危機未解除，第10集已跳至文簿房。 → 第9集讓賈勳面對具名扣人扣件責任而開門，持單者帶原件離開，只留下互認抄件與傳核單銜接第10集。
- 第20集鉤子把假血統說成名字也是敵人所造，與養母命名及結局本名簽字矛盾。 → 鉤子改為身分造假，轉折保留本名真實，血統與名字清楚區分。
- 少量簡體字混入繁中企劃，正字轉換後亦出現程式、處死物件等不合古代語境的詞。 → 作者完成繁中正字並修回程序、處死對象、局部、支持、權限及回耕等用語，重新通過語法與 source 驗證；角色與證據名稱一致。

### 這座城欠他一盞燈

- m04 原將第31集設為全部揭曉，但答案包含實際救出女兒，當集只完成託付。 → 作者把正式回收改到第36集，31列入進展並明定局部回收，36加入m04回收；32等待、36救出、38重逢依時間接續。
- 第35集原先已封存盒子，收尾卻又在公司車離開前找到頁面，原件與副本交接順序不清。 → 有權保管者先見證逐件核對、發現批准頁並複製，再封原件到公權保管；宋振南改在門口索副本，36由見證者依交接單帶副本出室，原件未隨公司車離開。
- 北側服務通道、轉運中心高處與東側排水觀察廊的連接原未明定，容易把局部可通行誤當全線安全。 → 作者補明北側共用幹線、南支轉運區、東端集合點與觀察廊，各支路各自勘查；人物進場、主角受傷撤出和女兒獲救分開處理。
- 繁中正字轉換留下審批流透過、未驗專案、步驟與引數等語境不合的詞，紙本證據亦混用儲存。 → 作者先完成繁中正字與核心用語修復，root再作審批流程通過、未驗項目、參數、安全轉移時間及紙本保存等純文案校訂；本覆核重新確認雜湊，故事與責任設定未改。

### 世人忘我，死敵記我

- 救援畫第 3 集交江照，第 32 集又由胡娘交回，缺少中途轉移。 → 江照一直保存原畫；胡娘第 32 集在他面前添寫新日期，畫仍回到他的紙包。
- 第 34 集末元衡現身，與四名已列角色形成額外具名角色。 → 第 34 集只呈現門口阻擋的劍，持劍者留鏡外，元衡第 35 集才露面。
- 底簿設定藏於坊中，第 22 集卻在南渡工具櫃取得。 → 設定明確分藏上頁與診記於坊、下頁於南渡舊櫃，交代材料到場才可安全進入；第 23 集才合併核對。
- 標題及描述說每次救人都抹記憶，與普通援助無代價不符。 → 限定動用禁術或守淵之力時觸發，範圍改為故事明訂的全城；一般援手不奪記憶。
- 少年互保契由兩人立下，仍需合理解釋為何不早知祁硯的記憶例外。 → 江照僅知少年平安結約定，不知未登錄條款效果；祁硯有事先存在的頭傷缺憶，紅繩先藏袖內，兩頁與診記到第 23 集才核對。
- 繁簡混用及自動轉換詞影響古代語境；結尾口味回收需明確。 → 統一繁體並修回登錄、局部、卸壓、保存等詞；第 40 集明寫兩碗麵，江照不吃苦葉，對應第 13 集祁硯替他挑掉。
