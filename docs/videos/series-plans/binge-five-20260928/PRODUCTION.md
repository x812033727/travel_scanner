# 製作與交接

## 每三分鐘如何拍得緊湊

| 規劃秒段 | 用途 | 驗收 |
| --- | --- | --- |
| 0–8 | 一句話或動作讓眼前危險、矛盾成立 | 不先報集名，不先講世界史 |
| 8–30 | 主角立即判斷或行動，給第一個具體回報 | 回報要在畫面或對白中發生，不能只是旁白說他很厲害 |
| 30–75 | 試方法、承擔限制，推進人物關係 | 至少取得新情報、改變決定或改變局勢 |
| 75–120 | 新資訊改變策略，給第二次回報 | 大反轉使用前面已可看見的線索 |
| 120–170 | 回報的代價或對方反制，收掉本集問題 | 不能把所有答案拖到下一集 |
| 170–180 | 接續動作、選擇、揭露或情感 | 接下一集時不重播、不總結；最終集已閉合 |

這是編劇與剪輯的起點，不是鎖死每鏡時長的模板。以旁白及角色實際台詞建立時間軸後重新分配；情緒節拍約20–30秒有變化，但允許有意義的停頓，不為達標胡亂剪鏡。每個satisfaction的planned_seconds是編劇目標，不是假裝已量測。

一集以約30鏡為初始估算，hybrid最多12鏡動態；實際鏡數由動作與配音決定。長鏡可保留表情，短鏡用於選擇或揭示；不連續用同張圖縮放掩蓋應該演出的重大動作。文字面板與文件只留觀眾需要看到的一項關鍵內容。

## 首部三集校準

使用《喜宴未散，清算開始》第1–3集，維持本包開場與故事順序。

1. 固定人物設定圖、聲音池及發音表，先完成三集台詞與具體分鏡。
2. 以實際TTS量鉤子結束時間、第一次回報、總長及停頓，重寫超長句，而不是加速整片掩蓋問題。
3. 檢查婚宴到會談室的角色髮型、衣著轉換、銀表、金領帶夾、授權原件與副本的持有人。
4. 以正常速度連看九分鐘：不重述前情，撕文件後要查清具體授權範圍；配角不能替女主作所有決定。
5. 留下媒體費用、重做比例、各階段時間、素材雜湊與QA結果；沒有實際帳單前不把估價當成本。
6. 經媒體品質驗收後完成第一部，再依順序做末班車、城市、女帝、仙俠。媒體階段可銜接既有[合集 pilot 任務](../../../../tasks/open/2026-09-27-video-binge-pilot.md)；本企劃任務結案不代表 pilot 完成，本輪也沒有認領或修改該任務。

## 每部成片驗收

- 主線40集皆完成；不可為湊完工跳過一集，或刪掉有關鍵伏筆的段落而只改章節號。
- 合計115–125分鐘，無逐集標題卡、重複前情、重複片尾。章節時間使用實際編譯時間軸。
- 開場承諾前三分鐘開始兌現；第20集轉變觀眾理解，第30集改變主角策略；最後十分鐘交代反派、同伴、代價。
- 每個大反轉能指回兩項前置線索。人物沒有取得尚未知的情報，傷勢、天候、道具與位置不跳變。
- 正常速度完整觀看兩小時，登記可刪的重述、讀不清的畫面、視覺單調、聽不懂的句子及情緒失速；修正後只重驗受影響部分和銜接。
- 既有pipeline的lint、音訊、分鏡與成片QA、字幕、metadata、links、thumbnail與disclosure等檢查需由實際產物通過。本文件不能代替這些檢查。
- 設定圖、音樂與音效使用原創或已授權素材；不借用真人聲音或人臉假裝背書。
- 舊核准若與檔案雜湊不同必須重新審核；不能靠--force掩蓋過期素材。

## 包裝與上架

每部三個標題搭三份明顯不同、由前三集可取得素材的縮圖構圖。縮圖尚未生成；定稿用實際關鍵影格，保留主角表情與一個核心物件，大字不超過12字，手機縮小仍能讀。

每部packaging.md的description是主體文案，**不是已符合最終5,000位元組預算的完整YouTube說明欄**。實際40章時間碼加入後，交由現有metadata planner按剩餘預算縮寫，保留必要揭露；四語標題/說明與五語CC也等最終台詞與時間軸確立後產出。

上架包需具備實際final.mp4、thumbnail.jpg、五語字幕、以實際時間碼產生的章節、metadata、UPLOAD.md與QA結果。由站主在Studio處理上傳與公開時間；本批沒有代上傳或操作公開狀態。

## 點閱與觀看表現

目標是每部累積超過100萬次觀看，不將觀看次數冒充100萬位獨立觀眾，不用購買假流量達標。沒有拿到頻道基線前，不宣稱某題材一定比另一個更容易破百萬。

具備使用資格時，使用YouTube原生A/B測試比較最多三組標題/縮圖。官方以觀看時間相關結果判定；測試中修改標題或縮圖會中止測試，因此不要每日手動換圖而誤認成同一場實驗。[官方標題與縮圖測試說明](https://support.google.com/youtube/answer/16391400?hl=en)（本對話2026-09-28查閱）

第一輪留存資料處理完成後檢查0:30、3:00及約30/60/90分鐘。對照同頻道相近長度基線；沒有同類基線時用Studio提供的相近長度比較，先記錄再形成內部標準。尖峰可能代表重看，也可能代表難懂；凹點可能是跳過或離開，回看片段後才判斷。[官方觀眾續看率說明](https://support.google.com/youtube/answer/9314415?hl=en)（本對話2026-09-28查閱）

手動成效紀錄欄位：作品、發布日期、資料日期、流量來源、曝光、CTR、觀看次數、平均觀看時間、0:30/3:00/30:00/60:00/90:00留存、最大流失片段、測試版本、變更與後續結果。未發布的欄位維持未量測，不填零當成實測。發布後48小時可先查資料是否就緒，第7與28日再檢視；這是交接建議，沒有建立排程或自動通知。
