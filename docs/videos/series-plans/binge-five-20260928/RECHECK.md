### PR 封裝補充

提交前另確認儲存庫要求所有文字使用 LF 換行；原先 CSV 使用 CRLF，會在 Git 正規化後與 manifest 雜湊不符。產生器已統一輸出 LF，保留 UTF-8 BOM 與全部表格內容，並重建五份 CSV 與 manifest。新增測試先重現舊版失敗，再確認修正後通過；回歸測試總數增為 17 項。五部故事來源及獨立審查雜湊不變。

## 下一階段才可確認的項目

每集的 5／8／30 秒、兩次回報與約三分鐘片長，目前仍是編劇節拍與文字估算。200 集細綱不是 200 集完整台詞稿，不能僅憑欄位通過就宣稱實際觀看緊湊。聲音分配也仍是待試聽選角。

先完成《喜宴未散，清算開始》前三集約九分鐘試製，實際檢查配音時長、角色與字幕一致性、兩次回報是否演得出來、場景切換與成本，再套用到整部及後續作品。最終需正常速度完整看片，才能驗收 115–125 分鐘成片與連續觀看節奏。

這次完成的是文字企劃覆核；沒有建立後台作品、啟動付費生成、上傳或發布。未進行全網權利檢索，編輯原創性判斷不等於權利保證；點閱目標仍須以發布後數據評估。
