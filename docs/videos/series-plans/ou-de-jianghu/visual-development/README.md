## 能力與完成狀態

目前 `tools/video/media/look.mjs` 的 `sheetPrompt` 只讀基底 `appearance`／`sheet_prompt`，預設定妝板是正面、3/4 與全身並排；`--file` 指專案 JSON，不能拿 PNG 當匯入。`keyframes.mjs` 使用每角色已選的基底圖，`shot_looks` 覆寫當鏡外觀文字，不自動讀各狀態的獨立圖。現有 `series-store.mjs` 已有跨集共用，沿用它，不另造第二套核准庫。

因此「外部概念圖已畫好」「動畫參照包齊」「正常 look 已核准」「關鍵影格真正引用」「動畫小樣實看接受」是五個不同結果。第 7 張票補正式匯入，第 8 張票驗真圖接線；這輪不寫假的 `characters/manifest.json`、`choice.json` 或 approval，也不把任務檔當媒體完成證明。

未來變更臉、服飾錨點或 palette 時先列受影響角色／造型／鏡頭與成本，再依既有變更單處理。清冊另綁造型來源 SHA，因目前原生 `lookHash`／`sheetKey` 不含 `shot_looks`；這只是前期檢查約束，不是已實作的新管線保證。
