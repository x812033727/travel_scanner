## 每個角色要交付的圖

尺寸、張數、表情數與姿態數均為**編輯建議**；執行前按實際模型支援及預算鎖定，不是供應商保證。原始最大可用尺寸保留；不能只放大低解析度就宣稱細節足夠。圖內不生成標籤，角色ID、視角、版本用檔名／聯絡表標示。

| 類型 | 内容與建議格式 | 驗收重點 |
| --- | --- | --- |
| 中性頭像 | 正面、平視、低情緒；方形，長邊至少1024px作目標 | 髮際、臉型、眼眉鼻口、年齡一致；臉上原有左右錨點不鏡像 |
| 主畫像 | 3/4半身、冠與髮飾完整，4:5，長邊約1600px以上作目標 | 胸前衣層、氣質、手持物合理；無複雜背景或戲劇光掩蓋身份 |
| 全身定妝 | 中性站姿、足底至冠頂完整，2:3，長邊約2048px作目標 | 鞋足、衣擺、武器與配件完整；不要裁掉識別錨點 |
| 多視圖 | 正、背、左右側、左右3/4，同尺度中性光；各視圖有獨立檔 | 臉、髮長、冠高、衣層、左右與配件跨角度一致；不能水平翻圖處理不對稱 |
| 表情 | 平靜、警覺、壓怒、意外、忍痛、克制悲傷6格作起點，依角色調整 | 同一張臉，不能表情一變就換年齡；遮面角色用可見區域演，不擅自揭面 |
| 姿態／動作參照 | 日常、對峙、角色典型行為3類作起點，每類準備→動作→收勢 | 重心與四肢可讀、手袖不黏成一塊；這是靜態分解，不等於已生成動畫 |
| 局部細節 | 冠髮、衣層、手／袖口、識別道具；必要時獨立左右圖 | 數量、材質與持物位置可重複；無歸箭與念珠等另附尺寸對照 |
| 共同比例板 | 同足底線、全體身形和黑色剪影；旁列比例提案 | 縮小不靠姓名也能分人；不把提案身高當故事既定數字 |

第一集畫像票的最低單位為9人×3用途＝27份採用視圖。視圖可以直接沿用前一步合格成品；這不是27次付費請求，也不是27張都能拿去做動畫的保證。候選、拼板及重複裁切不重算角色完成度。三視圖拼板供審閱；下游模型需要的參照組合由實際匯入能力決定。

- 姬無霜與洛青衍頸後月牙胎記：各一張位置／構圖細節參照；平時被髮／領遮住，不改成脸上印記。姬無霜左眼外霜花印另外保留。
- 姬無霜右手金印：第1集一道，後續兩道及割傷／包紮依實際鏡頭；手部細節與中性肖像分開。未定後續狀態標待劇本確認。
- 第5集鬼燈偽裝：全臉青面具與鬼燈袍設計獨立，來源仍指向該shot；不自動把`ji-wushuang`或`guideng-jun`放回刻意留空的`characters`。
- 紗女／無名劍客淡影是場景光下的異常，不畫透明身體，不揭紗或面具。赤羽遮口鼻、劍客遮上半臉、紗女白紗遮上半臉，三者分清。
- 第一集黑風：抽象氣流、遮擋與場景反應依原鏡頭；不提前畫出褚無常的正臉。

## 可直接沿用的提示與檔案規格

每張图先取 `asset-inventory.json` 指向的原始英文 `appearance`，再加本張用途。全域style沿e001 `look.style`，排除寫實皮膚、3D塑膠、木偶臉／提線、Q版及文字水印；不用既有布袋戲角色名稱當美術捷徑。

提示結構：`既有畫風 + 精確角色appearance + 本次單一視角／姿勢 + 中性柔光與簡單背景 + 必須完整可見的錨點`。編輯已採用圖時把它當來源參照；不是把文字抄一次就宣稱同一張臉。表情／姿態用角色行為寫，不替原本無武器的人加武器。局部圖只描述該局部，不把整段人像描述接入手部插鏡。

媒體存放於repo外作品工作目錄，例如 `<ART_WORKDIR>/ou-de-jianghu/characters/<id>/<base-or-look-id>/v001/<view>.png`。檔名是方案，不是本輪已存在路徑。每批紀錄：

| 欄位 | 內容 |
| --- | --- |
| 身份／用途 | character_id、look_id（基底記base）、view、episode／shot範圍 |
| 來源 | repo commit、cast／setting／video SHA、appearance來源pointer、採用參照圖SHA |
| 製作 | prompt版本／SHA、生成或編輯工具與模型、實際尺寸、take、圖檔SHA、原檔位置 |
| 審查 | generated／reviewed／owner_accepted分開，問題清單、審查者、使用者原話與版本 |
| 管線 | 正常look／judge／選用紀錄、實際被keyframes讀入的reference；未接入填not_integrated |

對外清冊不存憑證、私人帳號或個人機器路徑。拒絕／失敗候選保留理由；結果未知先查收據，不重買同一張。造型改動需列受影響下游，重新確認來源綁定。

## 完成判定

此輪完成的是規格與8張待辦；圖片狀態全部維持`specified_not_generated`。後續必須實看圖檔確認身份與角度一致，才能推進相應任務。最後仍要用真實連續鏡頭驗臉、衣冠、手／道具、表演與剪接；漂亮畫像、多視圖、judge分數都不能單獨證明動畫品質。
