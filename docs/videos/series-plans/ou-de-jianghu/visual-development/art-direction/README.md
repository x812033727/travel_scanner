## 進正式定妝前要修正的事

1. **沈歸鶴白紙扇完全合攏。** v2 仍有扇骨散開的楔形，另做合扇及右手持扇的局部參照；白冠、單羽、鶴紋與雲紋固定母版。
2. **姬無霜補清楚的足部與手袖。** 保留華麗長袍的主畫像，另做中性定妝與局部圖，交代鞋足、左右手指及袖口結構。霜花記以角色左眼為準，不能鏡像。
3. **三人的冠飾、掛飾與繡紋固定母版。** 胸像與全身像目前能辨識同一方向，但不宜視為細節逐一相等。鎖定主紋的位置、冠的各層、垂鏈數量與連接點，再出其他角度。
4. **統一畫法，保留人物差異。** 寂聞的皮膚肌理與硬陰影較強，沈、姬較柔；下一輪統一線稿、明暗與材質規則，不把三人修成同一張臉，也不因動畫尚未測試就擅自刪掉已接受方向的華麗裝飾。
5. **按用途輸出獨立圖並補實際參照。** 規格沿 [production-list.md](../production-list.md)，先完成正面頭像、3/4 半身與中性全身，再補左右側、背面、表情及姿態。單一拼板與裁切不能替代缺少的視角。

## 後續交接與狀態邊界

這批圖可作美術定調候選與下一輪修訂來源。把具體問題修完、記錄採用圖 SHA，並取得相應圖像的實際接受紀錄後，才推進正式角色資產。其餘首集六位沿相同畫風展開；不必先完成全季角色。

外部 PNG 接入正常 look、judge、choice 與跨集引用仍由匯入能力任務處理。本包沒有建立 runtime manifest、寫入正常 look 核准或證明 keyframes 真正引用。後續連續鏡頭還需驗證轉頭身份、冠鏈、袖層、左右特徵及持物的穩定性；靜態畫像和風格接受不代表動畫已驗證。
