## 13｜一筆小錢，一個條件（100 秒｜結尾：升級）

**前 3 秒**：清晨，周野盯著面板那行「別信周岸」，門外周岸敲門：「哥，梁總匯錢了。」

①啟程資本的匯款單只有一筆小錢，附一個條件：蘇寧每週來查帳；周野看著「別信周岸」四個字，把它記在心裡沒說。
②小隊在車行二樓開會，四個人擠一張桌子，野路小隊改名「野路配送」，大強把招牌寫錯一個字（鏡頭只給他尷尬的臉），小米笑到從椅子上掉下來。
③周岸送來一箱印好的保溫袋當賀禮，上面是野路的名字；周野收下，面板沒反應。
④蘇寧第一次來查帳，把帳本翻了三遍，只說「單據順序錯了」，把一疊重排好放回去。
⑤面板備忘：「兩週後，速達補貼大戰。」周野把河西路到新區的地圖攤在桌上，拿紅筆圈了三個區：「這三個區，提前佔。」

- 中段鉤子：周岸送保溫袋，面板沒反應
- 帶走的問題：梁啟為什麼只投一筆小錢？補貼大戰會照記憶來嗎？
- 爽點：公司成立、招牌掛上（前半，first_clear）；地圖圈區（level_up）
- 奇觀：車行二樓一桌子人，窗外整條河西路的霓虹亮起，紅筆在地圖上畫出三個圈
- 顏值：蘇寧翻帳本時鮑伯頭垂下一側，手指停在一張單據上，抬眼看周野一秒

## 14｜小米把客人的餐吃了（95 秒｜結尾：危機）

**前 3 秒**：小米坐在路邊，嘴裡塞滿飯，手機響：「客人問餐呢？」

①小米餓到把客人的便當吃掉，客人在電話裡罵；周野接過電話，十分鐘內自己補一份送到，多送一杯飲料。
②客人反而留了五星，寫「老闆親送」；小隊的評分第一次超過站點。
③趙強帶人堵在河西路口，要查野路的「無照配送」；周野掏出梁啟那筆投資的公司登記影本，趙強的臉綠了。
④小米偷偷把客人沒喝完的飲料也喝了，被阿輝一巴掌拍在安全帽上。
⑤深夜，趙強的手機跳出一張罰單：河西站點違規，罰款；他盯著那張罰單的來源，臉色更難看——不是野路報的。

- 中段鉤子：公司登記影本把趙強堵回去
- 帶走的問題：罰單是誰報的？趙強會怎麼反擊？
- 爽點：補一份餐換五星（前半，reversal）；登記影本堵趙強（face_slap）
- 奇觀：俯拍河西路口，四台黑色野路電動車與十幾台紅色速達車面對面停成兩排
- 顏值：小米掀開雨衣帽子，嘴角還沾著飯，笑得缺一角的門牙全露出來；林晚秋從車行門口探頭，叉著手臂看熱鬧

## 15｜補貼大戰，前一晚排好人（110 秒｜結尾：揭露）

**前 3 秒**：速達 App 跳出一張紅底公告：全市補貼翻倍，今晚零點起。阿輝看著手機：「老闆，真的來了。」

①補貼大戰照記憶爆發，野路小隊前一晚就睡在三個區的路口；零點一到，別人還在滑手機，他們已經在跑。
②第一個小時野路跑出全站三天的量；錢經理第一次出現在站點，問趙強「野路是誰」。
③小米在新區跑到迷路，面板沒給周野地圖，他靠自己在河西長大的記憶一條巷一條巷報給她。
④蘇寧半夜打電話問一句：「你怎麼知道是今晚？」周野說：「猜的。」她說：「猜得準的人最危險。」
⑤天亮，周岸笑著出現在站點門口，身邊站著錢經理：「哥，介紹一下，我新客戶。」

- 中段鉤子：錢經理問「野路是誰」
- 帶走的問題：周岸跟錢經理是什麼關係？
- 爽點：零點前排好人、第一個小時跑三天的量（前半，hidden_power）；蘇寧那句「猜得準」（甜）
- 奇觀：零點整，四個路口同時亮起車燈，電動車從四個方向衝進新區
- 顏值：蘇寧在落地窗前講電話，只亮一盞桌燈，銀錶反光；小米在霓虹底下回頭大喊「老闆左轉還是右轉」

## 16｜她為什麼幫我（100 秒｜結尾：抉擇）

**前 3 秒**：蘇寧把一份報表放在周野面前：「你的帳，我重做了一份。」

①蘇寧重做的帳把野路的現金流算到三個月後，每一步都標了日期；周野看到她在三處用紅筆圈起來，都是梁啟錢進來的那幾天。
②她問他要不要把帳做兩份，一份給梁啟看、一份自己留；周野問為什麼，她說「這是我的事」。
③趙強聯合錢經理推出「站點優先派單」，野路的單少了三成；周野照記憶知道這規則一週就會被平台收回。
④林晚秋看見蘇寧坐在車行二樓，兩人第一次對上眼，林晚秋把一杯水放在她面前，蘇寧說謝謝，誰也沒笑；小米在旁邊吃掉了兩個人的點心。
⑤蘇寧走到樓梯口回頭：「明天梁總約你吃飯，別去。」她沒說為什麼。周野站在窗前，面板沒有備忘。

- 中段鉤子：「帳做兩份」
- 帶走的問題：蘇寧在查什麼？去不去梁啟的飯？
- 爽點：三個月的現金流表（前半，rescue）；周野預判派單規則一週內收回（hidden_power）
- 奇觀：報表上三個紅圈在車行燈下像三個靶心
- 顏值：林晚秋把水杯放到蘇寧面前，手上有油，蘇寧的手白而乾淨，兩隻手在同一張桌上；蘇寧回頭時鮑伯頭掃過肩

## 17｜面板說規則一週收回，結果變成一個月（105 秒｜結尾：危機）

**前 3 秒**：面板備忘：「站點優先派單，七日後取消。」周野把備忘念給小隊：「撐一週。」

①小隊撐了一週，規則沒收回；平台公告：延長一個月。周野站在站點公告欄前，第一次當著小隊的面說「我錯了」。
②面板：「校驗失敗：記憶偏差。」黑屏；周野回想：規則是誰寫的？
③大強說他在速達總部送餐時看過一間新辦公室，門口掛著「岸行」。周野沒說話。
④林晚秋提議小隊接車行的客人修車順便送車，撐過這一個月；老柯在後面哼了一聲，把三台試車的鑰匙丟出來。
⑤錢經理的車停在車行門口，副駕下來的是周岸，手裡拿著一份文件：「哥，速達的新派單規則，是我寫的。」

- 中段鉤子：大強說的「岸行」
- 帶走的問題：周岸替速達寫規則？面板為什麼又錯在他身上？
- 爽點：林晚秋出車、老柯丟鑰匙（前半，rescue）；周野當眾認錯反而讓小隊沒人走（感人）
- 奇觀：公告欄前一排騎手的背影，公告上的紅字周野一個字一個字看（字不給看清）
- 顏值：林晚秋坐在試車上發動引擎，馬尾被風吹起，回頭對周野揚一下眉

## 18｜兩兄弟，同一條記憶（110 秒｜結尾：揭露）

**前 3 秒**：周岸把文件攤在桌上：「哥，規則是我寫的，但我可以幫你開個後門。」

①周野沒接文件；他問周岸怎麼知道平台要改規則，周岸笑：「做生意的感覺。」
②周野照自己的記憶寫下一個月內平台會改的三條規則，封在信封裡交給蘇寧：「一個月後開。」
③第一條規則三天後就改了，跟周野寫的一樣；蘇寧看著信封沒說話，拿出筆記本記下日期。
④小隊靠修車送車熬著，小米練會修輪胎，大強修壞一台被老柯罵；周母送來一籃包子，說是「給晚秋的」。
⑤周野翻周岸落在車行的筆電包，掉出一本手寫筆記本，第一頁的日期是半年前，寫的是野路成立那天的事。

- 中段鉤子：信封交給蘇寧
- 帶走的問題：周岸半年前就知道野路？他的筆記本裡還有什麼？
- 爽點：三天後規則照寫的改了（前半，hidden_power）；小米學會修輪胎（first_clear）
- 奇觀：周岸的筆記本從包裡滑出來，攤開的那一頁密密麻麻畫滿線
- 顏值：蘇寧在車行二樓窗邊記日期，筆尖停住抬眼看周野，窄眉微動

## 19｜把罰單的日期改掉（100 秒｜結尾：升級）

**前 3 秒**：錢經理把一張罰單拍在野路桌上：「違規跨區，停權七天，從今天起。」

①停權七天正好是補貼最後一週，野路會錯過整個大戰；周野看面板：「可複寫。」
②他用掉手上的一次複寫（第二次用，第 12 集解鎖的那一格），把罰單的生效日改到補貼結束後；錢經理回到辦公室，發現系統日期自己跳了。
③趙強被錢經理罵了一頓，罰單上的「報案人」是錢經理自己的人——趙強第 14 集那張罰單也是這麼來的。
④小隊補貼最後一週跑贏全市排名第三，大強把獎金全拿去買保溫背包；小米買了一箱泡麵。
⑤面板：「複寫完成。校驗中。」同一時間，周岸在岸行辦公室翻筆記本，把一行字劃掉，愣了一秒，又劃回來。

- 中段鉤子：系統日期自己跳
- 帶走的問題：複寫有沒有代價？周岸為什麼對著筆記本愣？
- 爽點：複寫改罰單（前半，reversal）；全市第三（level_up）
- 奇觀：速達總部螢幕牆上野路的名字跳到第三，一排紅色站點名往下掉
- 顏值：林晚秋用抹布擦掉周野臉上的油，手停了一秒，兩個人都沒說話

## 20｜周岸忘了什麼（100 秒｜結尾：情感）

**前 3 秒**：岸行辦公室，周岸對著筆記本的一頁發愣：「這一行……是我寫的？」

①觀眾看見：周岸筆記本上一行寫了「罰單」的日期，他完全不記得寫過，把那頁撕掉。
②周野在車行二樓算帳，蘇寧查帳時發現野路多了一筆沒來源的錢，是周岸匿名匯的；周野讓她原封退回。
③林晚秋跟周野說想把車行改成換電點，老柯在門口聽到，把扳手摔在地上：「這是你媽留下的店。」
④周野陪林晚秋在碼頭倉後面坐到天黑，她說小時候媽媽在這裡修車，他說「我也有人在這裡等我」，沒說是誰。
⑤老柯深夜一個人在車行後屋，對著牆上一張兩個年輕人的合照看了很久，照片裡另一個人穿橄欖綠夾克。

- 中段鉤子：周岸撕掉那一頁
- 帶走的問題：周岸為什麼會忘？老柯照片裡的人是誰？
- 爽點：匿名匯款原封退回（前半，villain_humbled）；林晚秋說出媽媽的事（感人）
- 奇觀：碼頭倉後面整排紅磚牆被夕陽染成橘紅，兩個人坐在堤上，影子拉得很長
- 顏值：林晚秋側臉對著河，眼睛紅了一下又忍回去，馬尾散了幾根被風吹起

## 21｜錢經理的飯局（105 秒｜結尾：危機）

**前 3 秒**：面板備忘：「錢經理今晚飯局，野路合約可談。」周野換上唯一一件襯衫。

①他赴約，餐廳裡只有錢經理和趙強，合約沒有，有的是「野路併進速達，你來當站長」。
②面板：「校驗失敗：記憶偏差。黑屏。」周野當場起身走人。
③沒面板的一夜，速達放出「河西路限時加倍」搶野路的客，周野靠小米和阿輝的腿一條巷一條巷追單，大強守住最後一個路口。
④趙強在飯局上喝多了，說溜嘴：「錢經理約的，本來還有一個人要來。」
⑤天亮，周野收到小隊的單量：野路贏了。他抬頭看對街，岸行的車從餐廳門口開走，副駕是周岸。

- 中段鉤子：黑屏，當場走人
- 帶走的問題：飯局本來要來的人是周岸？他跟錢經理談了什麼？
- 爽點：一夜用腿贏了加倍（前半，counter_kill）；當場起身（hidden_power）
- 奇觀：凌晨的河西路，三台電動車的燈在巷子裡穿梭，像三條黃線
- 顏值：小米騎車穿過晨霧回頭對周野比大拇指，雨衣帽子飛起來；周野靠在牆邊看天亮，襯衫袖子推到手肘

## 22｜第一個換電點（110 秒｜結尾：升級）

**前 3 秒**：林晚秋把車行的招牌卸下來，老柯站在門口：「我沒答應。」她說：「你也沒拒絕。」

①林晚秋照周野的圖把車行一角改成換電櫃，老柯嘴上反對，手上幫她接電線。
②第一塊模組電池插進去，燈亮了；小隊四台車先換，三十秒一台，阿輝說「比加油快」。
③周野把換電點的數據傳給蘇寧，她回了三個字：「這才是。」
④老柯在後屋拿出一塊二十年前的舊電池模組，比對新的，兩塊一樣大；他什麼都沒說，把舊的放回抽屜。

- 中段鉤子：三十秒換一台
- 帶走的問題：老柯那塊舊電池是誰做的？面板自己的記憶是什麼意思？
- 爽點：第一塊電池亮燈（前半，first_clear）；蘇寧的「這才是」（甜）

- 顏值：林晚秋接完電線站起來，額頭一層汗，用手背擦，顴骨上一道新油漬，笑了整張臉

## 23｜哥，我幫你談的（105 秒｜結尾：抉擇）

**前 3 秒**：周岸把一份合約放在換電櫃上：「速達要把換電點全市鋪開，我幫你談的。」

①合約上是岸行跟速達的合作，野路只是「設備供應」；周野看到簽名欄旁邊的日期，是飯局那天。
②周野直接問：「飯局你在？」周岸笑：「我幫你擋了併購。」沒否認。
③梁啟約第二天開投資會，決定要不要追加投資野路；蘇寧打電話來，只說「帶上你那個信封」。
④小隊在車行慶祝第一個換電點滿月，小米把蛋糕吃掉三分之一，大強把蠟燭插反；周母來送包子，順手把林晚秋和蘇寧按在同一張桌子，自己坐中間。
⑤周野站在換電櫃前，面板備忘：「明天投資會，可複寫。」他看著周岸的合約，再看那行「別信周岸」：簽，野路跟著岸行鋪全市；不簽，從頭來。

- 中段鉤子：「飯局你在？」
- 帶走的問題：簽不簽？信封裡的三條規則要拿出來做什麼？
- 爽點：周野直接問飯局（前半，reversal）；周母把兩個女主按在同一桌（喜劇）
- 奇觀：換電櫃綠燈下，周岸的合約與面板的青綠色框疊在同一個畫面裡
- 顏值：林晚秋和蘇寧同桌，一個手上有油、一個手上有筆，周母在中間笑，兩個人都別開眼；蘇寧低頭時睫毛在燭光裡動了一下

## 24｜半年前的會議紀錄（165 秒｜結尾：反轉）

**前 3 秒**：啟程資本會議室，梁啟兩手平放桌上：「追加還是撤資，今天定。」周岸坐在他右手邊。

①周岸先報：岸行與速達的全市合作，野路做設備；梁啟聽完，看周野。
②周野沒簽周岸的合約，拿出蘇寧保管的信封：一個月前寫的三條規則，三條都改了；他說「我不是猜的，我知道」。
③梁啟問「怎麼知道」，周野說「做過一個很長的夢」；周岸的笑停了，蘇寧的筆停了。
④梁啟決定追加，條件是野路獨立、不併進岸行；面板：「複寫 ×4 解鎖。」周岸拍手：「哥厲害。」出門時周岸對周野說「哥，夢裡有我嗎」，周野沒答。
⑤散會後蘇寧留下來整理檔案，從梁啟的舊檔裡抽出半年前會議紀錄的影本，一頁一頁翻：野路成立、補貼大戰、換電點，周野這三個月每一步都寫在上面，日期都比事情發生早；她把紀錄翻到最後一頁看簽名，筆跡不是梁啟的。她抬頭看會議室門外，周岸正回頭對她笑。

- 中段鉤子：「我不是猜的，我知道」
- 帶走的問題：半年前誰寫下周野這三個月的每一步？周岸那句「夢裡有我嗎」是什麼意思？
- 爽點：三條規則全中、梁啟追加（前半，public_vindication）；野路獨立、不併岸行（villain_humbled）；複寫 ×4（level_up）
- 奇觀：會議室落地窗外整條河，蘇寧一個人坐在長桌盡頭，一頁一頁翻紀錄，窄眉越皺越緊
- 顏值：蘇寧翻紀錄時鮑伯頭垂到臉側，手指停在簽名上，抬眼的那一秒眼神第一次有了溫度以外的東西——怕
