# 《我的重生系統是二手的》｜第一季 72 集企劃包

被弟弟騙走設計、被平台裁員的外送員周野，在雨夜車禍前一秒重生回十年前——就是他把圖紙交給弟弟的那一天。腦中亮起的「重啟面板」給他未來十年的記憶與每做對一件事的獎勵，可是右下角有一行褪色的小字「使用者：2／2」，記憶偶爾對不上現實：有人在他之前用過這條線，而且改過。他先用一條備忘攔下一份騙人的合約，再用外送小隊跑出讓投資人停手的數據，第三篇才知道這張設計圖是父親二十年前沒做成的東西，第 44 集靠父親停在兩點十七分的錶救下父親，第 60 集才聽到弟弟說：「哥，這條線我用過了，你以為是誰留的筆記？」

- 類型：都市重生＋系統＋商戰打臉＋慢熱多女主，輕喜劇；**3D 國漫 CG 動畫**（站主 2026-10-28 定）；全部架空，不寫真實公司、品牌、股票、新聞事件
- 規模：**第一季 6 篇 × 12 集 = 72 集**；每集約 90–120 秒，篇末 150–180 秒
- 來源：站主 2026-10-28 在規劃 session 定下題材、畫風與路線、故事核心（三個候選裡選 A「二手重生系統」）；由 Claude 照《種田娶妻打天下》的寫法規則、《修仙獎勵》的企劃包形狀寫成

## 讓人停不下來的規則（跟《種田》《修仙》同一套）

- 每集三個不同的鉤子：前 3 秒、中段、結尾；①到⑤是依序發生的五件事，笑點只放①到④，⑤不收笑話。
- 收在最高點：結尾類型（危機／揭露／抉擇／反轉／情感／升級）相鄰兩集不重複；篇末與季末收在反轉。
- 每集至少兩個爽點，第一個在前半；主角不連兩集輸；連續四集至少收一條線。
- 面板有代價：記憶只給方向、複寫要靠幫人與做出東西解鎖、被前任改過的事記憶會錯、每次複寫有人（周岸）在付錢；面板是周野的主觀鏡頭，剪接疊上，不由模型生成。
- 女主不是獎品：林晚秋、蘇寧、顧心各有祕密與自己贏的戲；第一季不定官配。
- 不黃標、顏值、架空：見設定集。
