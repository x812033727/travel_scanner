## 01｜獎勵怎麼是口鍋（120 秒｜結尾：揭露）

**前 3 秒**：清晨雜役院，宋管事展開清退名單，念的第一個名字是「江小滿」。「下月初一，下山。」

①清退令：雜役滿三年無修為者逐出山門，下山只有一條妖獸道；江小滿排第一，倒數三十日，窮到拿撿來的破書墊灶。
②夜裡受傷的內門首席沈照雪倒在院外，他把唯一的晚飯分她一半；首席為什麼在雜役院，他沒力氣問。
③破書在灶火裡亮起「百工仙錄」，第一個獎勵是一口壓力鍋；他嫌棄地倒入最便宜的碎靈米。
④師姐吃完，蒼白的臉回血，默默把碗推回來：「再一碗。」面板：靈力恢復 3%。
⑤鍋突然尖叫，他跳開；面板最底下浮出一行小字：「百工仙錄・第二次開啟。」

- 中段鉤子：破書亮起、鍋從字裡落到灶上
- 帶走的問題：第一次開啟的人是誰？
- 爽點：碎米煮出讓首席回血的飯（前半，藏拙露鋒）；破書是仙器（升級）
- 奇觀：灶火裡的破書浮出藍金色的字，一口鐵鍋從字裡落到灶上
- 顏值：沈照雪靠在門邊，灶火映著蒼白的側臉，接碗的手指在抖

## 02｜師兄拿劍換飯（110 秒｜結尾：危機）

**前 3 秒**：鍋還在叫，江小滿對著鍋作揖：「仙器大人，是我不對。」面板：排氣口堵塞。

①他疏通排氣，蒸汽把晾著的褲子噴上屋頂；沈照雪一劍把褲子挑下來，兩人都裝沒看見。
②第二鍋成功；他問她昨晚為什麼在雜役院，她答「巡夜」，可內門首席從不巡雜役院。
③香味引來翻牆的胖師兄何大勇，身上沒錢，把劍往桌上一拍：「押這個，盛滿。」
④何大勇吃完三碗覺得自己無敵，跑去挑戰內門弟子；江小滿對著那把劍發愁：「這能煮嗎？」
⑤院門被撞開，兩個雜役把何大勇抬進來，他臉色慘白、嘴唇發青，手指著鍋：「你的飯……」

- 中段鉤子：師兄押劍
- 帶走的問題：飯有問題嗎？師兄會不會死？
- 爽點：一劍挑褲子（喜劇）；碎米飯讓人搶著押劍（前半，first_clear）
- 奇觀：蒸汽柱把一條褲子直直頂上屋脊
- 顏值：沈照雪收劍時側頭看屋頂，忍住笑

## 03｜吃飽跟無敵，是兩回事（110 秒｜結尾：揭露）

**前 3 秒**：何大勇一口氣喘上來：「……太好吃，吃太撐才打輸的。」全院鬆氣。

①沈照雪解釋靈食只補消耗、不加修為，鍋有限制；面板也寫「同一件事不能無限刷」。
②江小滿拿明天的米錢替師兄買傷藥；倒數剩二十七日，面板：「改善他人處境，進度 +1」。
③他第一次看懂規則：做有用的東西、改善生活、建立合作才有獎勵；他一邊算米缸一邊算日子。
④隔天何大勇帶來十幾個外門弟子，碗筷自備：「飯有用，老闆還管售後！」
⑤人群後一身黑紅勁裝的執法堂女弟子陸昭看見灶邊盛飯的沈照雪，愣住：「首席？妳怎麼在這……」她端著碗的手停在半空。

- 中段鉤子：面板第一次說明規則
- 帶走的問題：首席到底為什麼天天來？
- 爽點：師兄活了還帶客（前半，reversal）；面板進度第一次跳（升級）
- 奇觀：十幾個弟子翻牆跳進小院，頭盔、劍鞘都拿來裝飯
- 顏值：沈照雪盛飯的側影，白衣袖口沾了一點飯粒；陸昭在人群後站得筆直，高馬尾被風吹到肩前

## 04｜來吃飯，請自備碗筷（120 秒｜結尾：反轉）

**前 3 秒**：沈照雪把碗放下，冷冷：「督促雜役，不行？」陸昭單膝一跪，馬尾一甩：「弟子多嘴。」

①客人擠滿小院，有人用頭盔裝飯；江小滿規定插隊者洗鍋，沒人理他。
②沈照雪端碗站到隊尾，所有人瞬間排成一直線。
③面板獎勵「定量勺」，一勺就是一碗；第一枚靈石落在碗裡，他捧著看了三息。
④宋管事帶人闖進來：「誰准你拿宗門的米賺錢？」翻開糧冊，江小滿的領糧量是實際的兩倍。
⑤宋管事把糧冊一合：「偷米加私販，不用等初一。明天，你就下山。」面板倒數從二十六日跳成一日。

- 中段鉤子：師姐排隊
- 帶走的問題：帳是誰改的？明天真要下山？
- 爽點：師姐排隊眾人歸位（前半，villain_humbled）；定量勺（升級）
- 奇觀：俯拍小院排成一直線的隊伍，隊尾一襲白衣
- 顏值：沈照雪端碗站在隊尾，陽光從牆頭斜下來；陸昭跪下又起身，抬眼時眼神一點都不服

## 05｜毒可能在鍋底（120 秒｜結尾：揭露）

**前 3 秒**：顧長老的手按在鍋蓋上：「他說飯裡有邪藥。那我先吃。」

①宋管事指控飯裡混邪藥，請顧長老驗毒，要連人帶鍋一起處置。
②顧長老吃一口，神情突然凝重，眾人屏息。
③他把小碗換成大碗：「毒可能在鍋底。」三碗下肚，驗出只是低階靈米，眾人反而搶著買。
④顧長老當眾裁定：私販不成立，偷米另查，下山令暫緩；江小滿指出雜役院只有兩口米缸，帳上的量根本裝不下。
⑤人散後，顧長老一個人翻過鍋底，看見一枚被煙燻黑的小印，手指發抖：「這鍋……你從哪裡來的？」

- 中段鉤子：小碗換大碗
- 帶走的問題：顧長老認得這口鍋？
- 爽點：大碗驗毒打臉（前半，face_slap）；當眾撤下山令（public_vindication）
- 奇觀：白鬚長老端著大碗蹲在灶邊，一院弟子伸長脖子
- 顏值：江小滿鬆了口氣靠在灶邊，額頭的汗被灶火照亮

## 06｜這鍋不吃靈石（100 秒｜結尾：危機）

**前 3 秒**：江小滿：「撿的。」顧長老盯了他三息，把鍋放回灶上，什麼都沒說。

①宋管事反咬偷米、停發雜役院的宗門糧；江小滿沒米可煮，倒數剩二十四日。
②他異想天開把靈石往鍋裡放，面板「不可食用」，連鍋蓋都扣不上。
③顧長老看不下去，教他辨出煉丹後仍可食用的藥材邊料；他問長老為什麼幫，長老只說：「我欠人一頓飯。」
④藥渣飯出鍋，香氣翻出院牆；沈照雪吃了一口，第一次笑出來。
⑤窗戶炸開，一隻宗門靈鶴衝進來，一頭扎進鍋裡；天上還有一整群正在俯衝。

- 中段鉤子：靈石不可食用、鍋蓋扣不上
- 帶走的問題：顧長老欠誰一頓飯？鶴群要幹嘛？
- 爽點：藥渣變靈飯（前半，藏拙露鋒）；長老站隊（rescue）
- 奇觀：一群白鶴從雲裡俯衝，撞穿小院的窗紙
- 顏值：沈照雪第一次笑，眼尾彎起來，手裡還端著碗

## 07｜仙鶴吃霸王餐（110 秒｜結尾：升級）

**前 3 秒**：鶴嘴從鍋裡拔出來，叼著一團飯；江小滿撲上去：「那是我的！」

①鶴群偷吃，他追得滿院亂飛，抓不到還被啄破新衣。
②鶴舍女弟子白鷺騎著一隻靈鶴落進小院，發現挑食多日的鶴群終於肯吃，當場訂下每日飼料。
③鶴舍拿可食用的鶴蛋抵帳，他立刻加做蛋炒飯，排隊的人又多一倍；面板：「與鶴舍建立合作」。
④沈照雪看他顛鍋，忽然問：「你顛鍋的時候，不覺得手心熱？」
⑤他再顛一次，飯粒在空中散開又聚攏，手心竟留住了一瞬靈氣；面板：「靈氣留存：一息。」

- 中段鉤子：鶴舍下訂單
- 帶走的問題：漏靈的經脈怎麼留得住靈氣？
- 爽點：靈鶴只認他的飯（前半，first_clear）；一息靈氣（level_up）
- 奇觀：飯粒在空中散成一圈金光再落回鍋裡

## 08｜我的第一招叫顛鍋？（120 秒｜結尾：揭露）

**前 3 秒**：江小滿連吃三碗靈飯盤腿打坐，靈氣照樣從經脈漏光；面板：「留存：0。」

①他以為能修仙了，吃撐了還是漏；沈照雪說她「見過」這種經脈，眼神躲開。
②她教他出手前短暫蓄力；他練劍總失敗，顛鍋時反而做得到。
③面板記錄第一項自創技巧「瞬息蓄靈」，他興奮得把鍋蓋震上屋頂。
④宋管事帶人封灶：「你看，果然擾亂修行。」被派來的陸昭把封條貼上鍋蓋，貼得很慢，貼完多看了沈照雪一眼。
⑤江小滿湊近看，封條上的章不是宗門的，是「仙盟巡使」；沈照雪一看，臉色變了。

- 中段鉤子：瞬息蓄靈
- 帶走的問題：仙盟巡使為什麼管雜役院的灶？

- 顏值：沈照雪教他蓄力，兩隻手隔著半尺同時握拳；陸昭貼封條時低頭，睫毛在燭光裡一動不動

## 09｜搶鍋的人先洗澡（120 秒｜結尾：危機）

**前 3 秒**：宋管事的打手抱著鍋走出院門，江小滿追出去：「鍋還是熱的！」

①宋管事聲稱換個人也能煮，嫌排氣吵，用符紙封住出口。
②江小滿衝進去揭符，湯汁仍噴了宋管事滿身；他護住旁邊的小弟子小石頭。
③打手拔刀要砍，他下意識用顛鍋的節奏蓄靈，一勺敲在刀背上，刀脫手飛出，全院安靜。
④宋管事惱羞，扣光他的飯錢作罰金；小石頭悄悄說：「每月發糧前，他都往米袋摻糠。」
⑤「摻出來的好米呢？」「後山。每月有人來收，馬車上掛的是仙盟的燈。」

- 中段鉤子：一勺敲飛刀
- 帶走的問題：好米藏在後山哪裡？仙盟收米做什麼？
- 爽點：一勺敲飛刀（前半，hidden_power）；宋管事滿身湯（villain_humbled）

## 10｜好米怎麼在豬圈（120 秒｜結尾：抉擇）

**前 3 秒**：夜裡後山，靈豬圈旁堆著蓋草席的米袋，袋角印著仙盟貨站的編號。

①江小滿循米袋標記找到後山，好米藏在靈豬圈旁準備轉賣。

- 中段鉤子：憑據上的名字

## 11｜別人的成本，是我的售價（130 秒｜結尾：情感）

**前 3 秒**：驗飯台上兩口鍋，膳堂首席廚娘宋綰綰一身桃紅、端出精米靈肉，笑得很甜；江小滿這邊只有碎米、藥渣和鶴蛋。

①觀眾覺得他輸定，他卻先算出對方一份的成本能做自己十份。
②定量勺配新學的火候，低價靈飯的香氣壓過對手。
③宋綰綰借整理步搖的動作把一粒丹藥彈進鍋裡，被沈照雪察覺；江小滿沒拆穿，只請顧長老「驗鍋底」。
④宋管事見勢不對，當眾轉頭指向沈照雪：「內門首席夜夜到雜役院吃剩飯，為了什麼？經脈好好的人，會天天來？」

- 中段鉤子：對手加丹藥
- 帶走的問題：師姐的經脈怎麼了？
- 爽點：成本算術（前半，藏拙露鋒）；香氣壓過對手（face_slap）

## 12｜賺到第一桶金，床塌了（160 秒｜結尾：反轉）

**前 3 秒**：顧長老從對手鍋裡夾出一粒丹渣：「這碗，不算。」
