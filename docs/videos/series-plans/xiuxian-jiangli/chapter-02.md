## 13｜修屋頂，送面鏡子（120 秒｜結尾：揭露）

**前 3 秒**：少女從斷成兩截的床板裡坐起來，拍掉頭髮上的瓦片：「你家屋頂不結實。」

①阿璃砸壞床，還嫌屋瓦不結實；江小滿要她做工抵債，她一口答應，條件只有一個：「管飯。」
②兩人修屋頂，她在屋脊上跳來跳去像隻猴；沈照雪冷眼看，問她師承，她答「山裡」。
③面板獎勵「留影鏡」，一次只能錄一小段；他立刻架在灶邊抓夜裡的偷飯賊。
④白天阿璃力氣大得不像人，一手提起一整缸米，另一手還在啃餅。
⑤鏡子裡，半夜的阿璃抱著米盆把生靈米當零嘴嚼，吃完把一個發光的東西塞回米缸底。

- 中段鉤子：留影鏡落地
- 帶走的問題：米缸底藏了什麼？
- 爽點：屋頂一天修好（前半，first_clear）；留影鏡（升級）
- 奇觀：阿璃從屋脊翻身落地，腳下一片瓦都沒碎
- 顏值：阿璃在屋脊上迎著夕陽回頭，兩條辮子的紅繩飛起來

## 14｜師姐，妳也偷吃？（110 秒｜結尾：危機）

**前 3 秒**：江小滿把手伸進米缸底，摸到一個冰涼的東西；身後阿璃的聲音：「別動。」

①阿璃堅稱夢遊、不認帳，搶先一步把米缸底的東西摸走塞進懷裡：「我的。」
②江小滿繼續查鏡子，竟錄到沈照雪半夜御劍落進院裡找剩飯；她要求刪掉吃飯那段，卻讓他留下御劍落地那段。
③陸昭白天來院裡「巡查」，看了鏡子一眼，親手把吃飯那段替首席刪了：「首席的事，我管。」
④他重看影像，發現阿璃腕上的靈印在鏡子裡亮著，是一個圖樣。
⑤院門外有人舉著畫著同一圖樣的追捕令：「見過這個逃犯嗎？」身後站著十幾個灰衣人。

- 中段鉤子：錄到師姐御劍來吃剩飯
- 帶走的問題：阿璃是逃犯？
- 爽點：抓到師姐偷吃（前半，喜劇反轉）；陸昭站隊（rescue）
- 奇觀：鏡中沈照雪御劍落進小院，劍光照亮一院晾著的碗
- 顏值：沈照雪在鏡中落地，衣擺還在飄，伸手拿碗那一下一點都不首席

## 15｜辛苦半天，獎勵肥皂（120 秒｜結尾：反轉）

**前 3 秒**：江小滿把一整鍋飯端到門口：「來，先吃飯再找人。」排隊的人潮把灰衣人擠到牆邊。

①他用外送人潮擋住灰衣人，阿璃趁亂用布把手腕纏起來，躲進廚房。
②灰衣人頭子申九亮出仙盟銅牌，宗門不能攔；他給三日，三日內交不出人就搜山。
③江小滿替常客做出標記米水比例的量勺，第一次製品成交；面板獎勵「去垢皂」配方，他失望得差點關掉面板。
④阿璃看見配方底下「可清除低階外附靈印」，搶過去就往澡房跑。
⑤她進澡房的同時，申九手裡的追蹤符「噗」地熄了；他抬頭，看向雜役院。

- 中段鉤子：三日搜山
- 帶走的問題：追蹤符熄了，追兵會不會直接衝進來？
- 爽點：人潮擋人（前半，reversal）；肥皂洗掉靈印（hidden_power）
- 奇觀：十幾張追蹤符同時熄成灰，一片片落在灰衣人的掌心
- 顏值：阿璃纏手腕時低頭咬住布頭，辮子垂到胸前

## 16｜妳的臉怎麼也洗掉了（120 秒｜結尾：揭露）

**前 3 秒**：澡房門開，阿璃頂著一頭水出來：「洗掉了！」臉上卻多了一道淡金色的紋。

①追蹤印洗掉，阿璃高興得又往臉上抹一把，易容術跟著消失：眉心一道金紋、耳尖微尖。
②江小滿拿著毛巾僵在原地；沈照雪正好推門，看一眼她的臉，劍已經出鞘。
③阿璃承認自己是妖族，追捕令上的逃犯就是她，但否認盜走族中的鎮脈珠。
④陸昭從牆頭翻進來報信：灰衣人去了長老堂，顧長老壓著搜山令沒簽。
⑤沈照雪劍尖不動：「那你解釋，追兵為什麼說你害死了自己的族人。」阿璃懷裡的東西掉在地上，是半顆鎮脈珠。

- 中段鉤子：妖族身分
- 帶走的問題：她手上為什麼有半顆珠？
- 爽點：真容揭曉（前半，identity_reveal）；顧長老擋搜山（rescue）
- 奇觀：水珠從她臉上滑下，底下的真容像從霧裡浮出來
- 顏值：阿璃的真容：眉心金紋、濕髮貼在臉側、虎牙咬著唇

## 17｜肥皂也有洗不掉的東西（110 秒｜結尾：危機）

**前 3 秒**：半顆鎮脈珠在地上滾，阿璃撲上去按住：「這是我從貨站搶回來的那一半。」

①阿璃說她追查鎮脈珠去向，查到仙盟貨站，搶回半顆就被栽贓殺族；另一半還在貨站。
②江小滿想替她洗掉妖氣，面板提示：只能清外附印記；妖氣是她自己的，洗不掉。
③他改洗掉她沿途沾上的追蹤粉，倒進污水桶；申九的符紙全指向污水桶，一桶髒水噴了他滿臉。
④沈照雪出面拖住追兵，決定去仙城核實轉運紀錄；江小滿要跟，她看他一眼：「你先學會跑。」
⑤當晚客棧裡，申九對著傳訊符低聲說：「首席護著那個雜役。照裴大人說的辦。」

- 中段鉤子：污水桶騙符
- 帶走的問題：裴玄衡要對首席怎麼辦？
- 爽點：污水桶騙符（前半，reversal）；申九滿臉髒水（villain_humbled）
- 奇觀：幾十張符紙在空中齊齊轉向，指向一個污水桶
- 顏值：沈照雪單手持劍橫在門前，一步不讓，髮絲被風吹過臉

## 18｜一起練功，怎麼送這個（120 秒｜結尾：情感）

**前 3 秒**：江小滿在院裡跑第一圈就趴下；沈照雪用木劍戳他的背：「起來。」

①他請師姐教保命身法，答應認真練；陸昭坐在牆頭看，第一次笑出聲。
②兩人立下固定陪練的約定，面板解鎖關係獎勵；白鷺騎鶴送飼料錢來，正好看見獎勵落地。
③獎勵是一對寫著「雙修」的蒲團；三個女的同時沉默，江小滿想把它塞進米缸。
④看完說明才知道是近距離同步吐納；沈照雪坐下試，第一輪他就覺得胸口像被什麼壓住。
⑤阿璃好奇掐了江小滿一下，沈照雪倒抽一口氣；可她臉上的痛，明顯比他重得多。

- 中段鉤子：蒲團落地
- 帶走的問題：為什麼她比他還痛？
- 爽點：關係獎勵解鎖（前半，level_up）；蒲團誤會（喜劇）
- 奇觀：兩個蒲團同時亮起一圈淡金色的光環
- 顏值：沈照雪盤坐閉眼，睫毛顫一下，額角一滴汗滑下

## 19｜妳拔刺，我叫什麼（110 秒｜結尾：揭露）

**前 3 秒**：面板：「同步吐納會同步痛感；離座即可中止。」江小滿：「早說！」

①兩人先約好停止手勢，再次試用；陸昭自告奮勇當裁判，被兩人同時趕走。
②師姐拔掉指尖一根小刺，自稱能替她擋劍的江小滿叫得比她還大聲。
③笑鬧後，他終於穩住一整輪吐納；面板：「靈氣留存：三息。」
④他得意伸懶腰，腳一抽筋，兩人同時僵住。
⑤僵住的那一瞬，他清清楚楚感覺到：她那邊的靈氣，也在往外漏，跟他一樣。

- 中段鉤子：三息留存
- 帶走的問題：師姐的經脈也壞了？
- 爽點：拔刺叫聲（前半，喜劇）；三息留存（level_up）
- 奇觀：兩人同時蜷起來，蒲團的光環閃了一下
- 顏值：沈照雪忍痛皺眉又忍不住笑，難得的表情

## 20｜出遠門，先把鍋帶上（120 秒｜結尾：危機）

**前 3 秒**：木劍第三次打空，江小滿的褲子掛在牆頭。沈照雪：「勉強。」

①師姐考核身法，他躲過三次木劍，代價是褲子；勉強獲准同行。
②第一件收進行李的是鍋；小院熟客預付飯錢，白鷺說她每三天騎鶴送一次貨，順便看鍋。
③阿璃拿出指向仙城貨行的轉運木牌，是她搶珠時順手摸的。
④陸昭留下看院子，臨走塞給沈照雪一小瓶藥，兩人眼神交換；江小滿假裝沒看見。
⑤剛進仙城，商鋪少女唐酥攔住他：「你那半塊肥皂，我買。」她身後鋪子的招牌，掛著商盟的燈。

- 中段鉤子：轉運木牌
- 帶走的問題：商盟的人怎麼知道他有肥皂？
- 爽點：考核過關（前半，first_clear）；熟客預付（general payoff）
- 奇觀：仙城城門內，千家鋪子的靈燈同時亮起
- 顏值：唐酥整個人擋在路中間，鵝黃裙擺一轉，笑得眼睛彎成一條線

## 21｜她比我還會賺（120 秒｜結尾：揭露）

**前 3 秒**：唐酥看著去垢皂洗乾淨一件舊法器，眼睛亮得像靈石：「配方，開個價。」

①唐酥要買配方；江小滿以為遇到冤大頭，才發現她已經向旁人收了三倍清洗費。
②一把洗乾淨的劍露出失主刻名，攤販搶劍逃跑；沈照雪一步攔下，留影鏡存證。
③主角賺到第一筆城中賞錢；唐酥當場把賞錢分成三份，自己拿最大份，理由是「場地費」。
④唐酥看見轉運木牌，臉色變了：「這家貨行，你們碰不起。」
⑤入夜，唐酥在鋪子後面燒掉一張紙，紙上是商盟的印，和「雜役江小滿」五個字。

- 中段鉤子：劍上的刻名
- 帶走的問題：唐酥是誰的人？
- 爽點：三倍清洗費（前半，喜劇）；抓攤販拿賞錢（first_clear）
- 奇觀：一劍洗出的刻名在陽光下金光一閃
- 顏值：唐酥撥算盤時手指翻飛，火光照著她把紙燒掉的側臉

## 22｜洗掉的不是污垢，是身價（120 秒｜結尾：危機）

**前 3 秒**：唐酥把一盤靈玉推到他面前：「先替我驗這批，再談消息。」

①肥皂洗掉表面偽裝靈光，滿桌寶玉變成普通石頭；唐酥心疼得差點坐下，下一刻把肥皂改標「驗寶皂」。
②假貨商想反咬，江小滿當眾再洗一塊，圍觀者立刻包圍攤位。
③上游供貨者是倪氏貨行；倪綺，仙城最美的女掌櫃，親自坐轎來，笑著賠了假玉的錢。
④她臨走看了阿璃纏布的手腕一眼：「小姑娘，手受傷了？」
⑤當晚，倪氏貨行的夥計在小院外的每一條路上撒下追蹤粉。

- 中段鉤子：倪綺下轎
- 帶走的問題：倪綺認出阿璃了？
- 爽點：驗寶皂打臉假貨商（前半，face_slap）；倪綺當眾賠錢（villain_humbled）
- 奇觀：滿桌靈玉的光一塊一塊熄掉，像吹蠟燭
- 顏值：倪綺下轎：墨綠織金長裙、狐狸眼，把一袋靈石放在桌上時手指一彎

## 23｜鏡子只能錄這麼一點？（120 秒｜結尾：抉擇）

**前 3 秒**：唐酥抱著一箱「退貨」走進倪氏貨行，江小滿跟在後面假裝抄貨號。

①唐酥藉退貨進貨行；阿璃找到鎮脈珠的轉運編號，卻引起掌櫃懷疑。
②江小滿故意算錯賠款，吵得掌櫃離座；沈照雪守在門外，手一直按著劍。
③留影鏡最後一段容量錄下帳頁：鎮脈珠在被控失竊前，已登記送往仙盟貨站，簽收人裴玄衡。
④掌櫃察覺不對，把原帳扔進火盆；倪綺從樓上下來，笑著說：「燒了也沒關係，我記得。」
⑤她看著江小滿：「我可以替你作證。條件是，把那口鍋賣給我。」

- 中段鉤子：帳頁錄到了
- 帶走的問題：賣不賣鍋？
- 爽點：故意算錯支開掌櫃（前半，藏拙露鋒）；錄到帳頁（first_clear）
- 奇觀：帳本在火盆裡捲起來，一頁頁變黑
- 顏值：倪綺倚在樓梯扶手上，一隻手撐著下巴看他，披帛垂到樓梯下

## 24｜追個逃犯，追出一間店（150 秒｜結尾：反轉）

**前 3 秒**：江小滿：「鍋不賣。飯可以賣妳一輩子。」倪綺笑了。

①唐酥一桶退貨洗液潑熄火盆，搶下半本殘帳，順勢大鬧索賠。
②殘帳證明阿璃的罪名有問題，但仍缺完整證據；倪綺沒作證，只留一句「下次見」。
③唐酥提出合夥開店，用修補與清洗生意接觸貨行客人；江小滿投錢、師姐護持、阿璃搬貨，面板「建立合作」。
④第一張訂單寫著：「能讓飯放幾天，靈氣還不散嗎？」
⑤唐酥送走客人，在鋪子後門跟一個灰衣人低聲說：「人我留住了，鍋他不賣。」灰衣人：「商盟不急。」

- 中段鉤子：合夥開店
- 帶走的問題：唐酥到底幫哪邊？
- 爽點：潑熄火盆搶帳（前半，reversal）；四人合作成立（first_clear）；殘帳證明冤案（public_vindication 一半）
- 奇觀：一桶洗液潑進火盆，白煙沖上貨行的雕花樑
- 顏值：唐酥在後門回頭，笑還掛在臉上，眼睛已經冷了
