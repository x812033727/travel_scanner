## 61｜這堆破爛，比我值錢（120 秒｜結尾：揭露）

**前 3 秒**：封鎖令貼滿妖城，江小滿把壓力鍋藏進米缸：「違禁品，先躲一下。」

①眾人拆銅盆、壞燈座做替代件，第一次試機就冒煙；紅綃一掌拍熄，連桌子也拍塌。
②主角發現材料混雜，需要分類重熔；唐酥想把挑出的好料標成「古董」，被師姐翻回「廢料」牌。
③白玉宗的雜役託白鷺的鶴送來攢下的標準銅件，小石頭的字條：「老闆，雜役院的米缸還空著。」
④顧長老也送來舊丹爐，附言：「借的，刷乾淨還我。」妖王想幫忙刷，被桂婆搶走鍋鏟。
⑤包銅件的紙是仙盟的內部公文：「清點妖城百工坊舊物，三日內上繳巡使。」江小滿看向米缸裡的鍋。

- 中段鉤子：鶴群送銅件
- 帶走的問題：裴玄衡要百工坊的舊物做什麼？
- 爽點：雜役送銅件（前半，rescue）；古董翻回廢料（喜劇）
- 奇觀：一群白鶴落在妖城城頭，每隻腳上綁著一包銅件
- 顏值：沈照雪翻牌時袖子一甩，月白劍裝在廢料堆裡最乾淨

## 62｜風扇轉得很努力，就是沒用（110 秒｜結尾：危機）

**前 3 秒**：供靈網裝好，風扇轉了半刻，儲靈槽一格都沒亮；阿璃：「它在偷懶。」

①周圍沒有足夠散靈可收；眾人測出城外靈植在日照時會散出少量靈氣，長期白白流失。
②循環器搬到田邊，雞群搶著蹲在出風口；紅綃要烤雞，被桂婆用鍋鏟趕走。
③主角限制收集量，保留靈植生長所需；第一條支線亮起，醫館的燈亮了。
④唐酥指著西斜的太陽：「晚上呢？」沒有人答。
⑤入夜，散靈歸零，支線一盞一盞熄；育幼堂裡孩子開始哭，紅綃握刀的手在抖：「再熄一盞，最小的那個撐不過。」

- 中段鉤子：第一條支線亮起
- 帶走的問題：夜裡的靈從哪來？
- 爽點：第一條支線亮（前半，first_clear）；雞蹲風口（喜劇）
- 奇觀：田邊風扇轉起來，整片靈植的葉尖同時飄出細小光點，被吸成一條線
- 顏值：紅綃在田邊，赤紅甲反著夕陽，豹耳抖了一下

## 63｜把白天，裝進喜酒瓶（120 秒｜結尾：升級）

**前 3 秒**：唐酥從婚宴倉庫踹出一排喜酒瓶：「這些，退不了貨。」

①瓶上的聚靈釉本就能減少酒液散靈；江小滿試著改成小型儲靈瓶。
②第一只因超量裂開，酒噴了妖王一臉；他舔了一口：「好酒。」
③降低單瓶容量，改用大量瓶組輪流充放；宋綰綰算出每瓶的時辰表，白鷺的鶴群排隊搬瓶。
④滿倉「百年好合」排列整齊，阿璃笑他娶了一整倉；沈照雪什麼都沒說，把一個瓶子上的紅紙撕了。
⑤入夜，瓶組接上，育幼堂的燈亮到天明；面板：「供靈網・第一夜」，下一行：「覆蓋：一成。」江小滿看向城裡還黑著的九成：「找人。」

- 中段鉤子：瓶組輪流充放
- 帶走的問題：剩下九成怎麼辦？
- 爽點：酒噴妖王（前半，喜劇）；第一夜撐過（level_up）
- 奇觀：滿倉喜酒瓶同時亮起淡金色，像一倉的燈籠
- 顏值：沈照雪撕紅紙時的側臉，燈光從瓶子裡照上來

## 64｜修仙第一課，擰螺絲（120 秒｜結尾：危機）

**前 3 秒**：招工的木牌掛出去，排隊的是挑擔的、洗衣的、賣糖的；鐵山：「他們連靈石都沒摸過。」

①招工來的多是沒有修為的居民，工匠擔心教不會。
②江小滿用定量勺、刻度模板，把工序拆成能重複操作的步驟；陸昭把步驟念成執法堂的條例，居然很好記。
③妖王要示範，第一顆接頭就擰壞，被桂婆接手教訓：「王座坐太久，手廢了。」
④普通人做出的零件通過測試，眾人歡呼；面板亮出百工舊印，妖王看著那個圖樣，臉色變了。
⑤仙盟執法隊進城清點銅器，申九帶隊；妖王把一把舊扳手塞進袖子，低聲對江小滿說：「這個印，他們找了二十年。」

- 中段鉤子：妖王被阿婆教訓
- 帶走的問題：妖王藏的扳手是什麼？
- 爽點：妖王被阿婆教訓（前半，villain_humbled）；普通人零件通過（public_vindication）
- 奇觀：一百個普通人同時把零件舉過頭，燈一排排亮
- 顏值：陸昭念條例時高馬尾一甩，居民跟著喊口令

## 65｜我爹也嫌這東西難用（130 秒｜結尾：揭露）

**前 3 秒**：執法隊走後，妖王把舊扳手拍在桌上，刻印與面板上的印一模一樣。

①扳手是二十年前一對夫婦留在妖城的，他們替平民設計供靈器，妖王那時還是王子。
②隨附的筆記頁邊互相吐槽圖紙難看，江小滿讀得發笑；沈照雪看他笑，自己先紅了眼。
③翻到後面是裴玄衡的查抄命令：「百工坊拒交技術，清算。」
④最後一頁是送養記錄：「江氏子，送白玉宗雜役院。」接收印是白玉宗的，名字是他的。
⑤他抬頭，顧長老站在門口，第 34 集沒答的話終於答了：「那家人，就是你爹娘。」

- 中段鉤子：查抄命令
- 帶走的問題：爹娘還在嗎？
- 爽點：筆記互相吐槽（前半，喜劇）；身世揭曉（identity_reveal）
- 奇觀：扳手的刻印、面板的印、鍋底的印三個疊在一起
- 顏值：沈照雪站在他身後，手伸出去又收回來

## 66｜原來獎勵沒有發錯（130 秒｜結尾：情感）

**前 3 秒**：江小滿：「他們為什麼不交？」妖王：「交了，這些東西就只有仙盟能用。」

①妖王說父母拒絕交出技術獨占權，工坊遭清算，孩子被送走保護；書物流入宗門廢料，才讓他重新撿到。
②面板第一次顯示：「第一次開啟：江硯秋、江書沅。第二次開啟：江小滿。」
③仙錄按實作成果開放配方，任何願意學的人都能用；唐酥看著「開放」兩個字，算盤停了。
④母親的註記在最後一頁：「先讓孩子吃飽，再想神劍。」阿璃把紙遞給他，自己先哭。
⑤江小滿把第一張配方貼到工坊牆上，桂婆、鐵山、挑擔的居民一個個圍上來；他轉頭對沈照雪說：「我娘說的，跟妳第一晚那碗飯一樣。」她沒說話，把第二張貼上去。

- 中段鉤子：第一次開啟者的名字
- 帶走的問題：配方公開了，鋪子還活得下去嗎？
- 爽點：第一次開啟者揭曉（前半，identity_reveal）；配方上牆（first_clear）
- 奇觀：配方一張一張貼滿工坊的牆，居民舉著燈看
- 顏值：沈照雪貼第二張配方，手指按平紙角，眼睛是濕的

## 67｜免費教，修壞照收錢（120 秒｜結尾：揭露）

**前 3 秒**：唐酥衝進工坊：「你把配方送了？」江小滿：「送方法，不送手藝。」

①唐酥以為連生意都送了，江小滿解釋：配方公開，合格零件和維修仍然有價值；唐酥算了三遍，笑了。
②各地匠人帶著試作品來學，現場先比誰的鍋最醜；柳承鋒也來，帶一口自己做的鍋，最醜那口。
③新製的小工具比武器更受居民歡迎，商盟斷料逐漸失效；顧長老邀請其他宗門共同驗看供靈網與罪證。
④裴玄衡親自來查驗，裴清音跟在後面；江小滿先遞上價目表：「拆壞要賠。」
⑤裴站在配方牆前，伸手撕下第一張；唐酥攔住。裴看著紙上的字跡：「這張紙的主人，二十年前也這樣攔過我。」

- 中段鉤子：比誰的鍋最醜
- 帶走的問題：裴玄衡跟父母發生過什麼？
- 爽點：唐酥算三遍笑了（前半，reversal）；柳承鋒最醜的鍋（喜劇）
- 奇觀：幾十口形狀各異的鍋排在廣場上，每口都冒著氣
- 顏值：裴清音站在裴身後，銀灰衣、筆不停，聽到那句話時筆停了

## 68｜這張帳單，請大聲念（130 秒｜結尾：危機）

**前 3 秒**：裴玄衡：「設備危害靈脈。」江小滿：「那就測。」測流符插進地裡。

①現場測流：新網只收散靈，真正抽脈的反而是商盟設備；數字在各宗門面前浮出來。
②唐酥公開原始帳、查抄令與工匠證詞；倪綺的收款簽名、宋管事的證詞逐項對得上，宋管事是宋綰綰帶來的，跪著念自己的供詞。
③裴要求帶走封存，被其他宗門制止；裴清音在記分簿上寫下「證據：對得上」，裴看了她一眼。
④裴忽然笑了：「你們以為抽脈的是我？」他把一張仙盟批文丟在地上，落款是仙盟盟主。
⑤眾人愣住的一瞬，他搶走舊管線總閥符，身形一閃上了城樓：「設備，我自己拆。」總閥一關，舊管線開始倒灌。

- 中段鉤子：宋管事跪著念供詞
- 帶走的問題：他要毀證據，還是要毀整座城？
- 爽點：測流打臉（前半，face_slap）；宋管事念供詞（betrayer_punished）
- 奇觀：測流的數字像金色的字浮在整個廣場上空
- 顏值：宋綰綰扶著舅舅，低著頭，木簪上纏了一條白布

## 69｜你關你的，我開我的（120 秒｜結尾：抉擇）

**前 3 秒**：舊管線熄滅，全城燈滅；裴在城樓上等驚慌，醫館的燈卻還亮著。

①江小滿早已把重要城區切到新網，準備的瓶組開始供靈；桂婆帶著居民一條街一條街接線。
②裴惱怒調用私接靈流的法器強攻，三條外接靈流從城外三座山拉過來；沈照雪與妖王擋第一波，紅綃擋第二波，陸昭擋第三波。
③主角發現法器三條外接靈流輪換時會出現短暫空隙；裴清音站在城樓上看著記分簿，一動不動。
④留影鏡剩餘靈力只夠錄最後六息；唐酥：「誰去引他出招？」沒人答。
⑤江小滿把鏡子塞給唐酥，踏上劍：「我去。半顆蓮，夠用一次。」沈照雪抓住他的袖子，他把袖子從她手裡抽出來。

- 中段鉤子：三條靈流
- 帶走的問題：一次，夠嗎？

- 顏值：沈照雪抓袖子那一下，指節發白

## 70｜鍋碗瓢盆，也能養出劍仙（150 秒｜結尾：揭露）

**前 3 秒**：第一擊擦過劍尖，江小滿踏劍側滑，第二擊從下面來。

①他踏劍避過前兩擊，第三擊擦傷肩膀，新買的袖子破了。
②唐酥從六息影像看清換流順序，阿璃與工匠依次切斷外接點；第三個外接點在城樓上，裴清音走過去，用記分的筆挑斷了符線。
③裴回頭：「清音。」她：「比武那天我記下四個字，今天用上。」師姐擋下追擊，替他爭取最後一瞬。
④江小滿以「一息斷流」斬開主接環，法器崩解，其他宗門立即制住裴玄衡；他落地，先看破袖子：「這件才剛買。」
⑤裴被押走時回頭，第一次提高聲音：「江硯秋沒死。海工坊的門，你打不開。」江小滿手裡的劍掉在地上。

- 中段鉤子：裴清音挑斷符線
- 帶走的問題：父親還活著？海工坊在哪？
- 爽點：裴清音倒戈（前半，reversal）；一息斷流斬法器（counter_kill）

- 顏值：裴清音挑斷符線時銀灰衣在風裡，第一次露出表情

## 71｜祖師爺，您的飯糊了（120 秒｜結尾：情感）

**前 3 秒**：涉案設施被接管的告示貼上，阿璃的懸賞像被撕成兩半，她自己撕的。

①設施接管，被奪材料陸續返還，阿璃的冤案正式洗清；妖王當眾封紅綃為將軍，紅綃第一件事是找陸昭再比一場。
②普通工匠做出第一批靈器，居民要替江小滿立祖師像，鐵山已經在刻，刻成了一口鍋。
③他正被誇得飄飄然，顧長老衝出來：「慶功飯糊了！」
④他狼狽回廚房，女角都留下來幫忙：師姐縫袖、阿璃遞食材、唐酥算修店帳、宋綰綰搶鍋鏟、陸昭守門、白鷺的鶴偷吃、紅綃洗碗跟桂婆搶水。
⑤一桌人坐滿，他看著手裡的鍋鏟，忽然不想再抱怨自己命苦；沈照雪把縫好的袖子遞給他：「下次，別自己抽出來。」

- 中段鉤子：慶功飯糊了
- 帶走的問題：海工坊怎麼去？

- 奇觀：一桌人、七個女角、一鍋糊飯，全城的燈在窗外
- 顏值：沈照雪縫袖子時低頭，燈光，線咬斷那一下

## 72｜打贏了，獎勵洗衣機？（170 秒｜結尾：反轉）

**前 3 秒**：新店重新開張，面板：「百工共學 100/100」；江小滿閉上眼：「這次一定是神劍。」

①獎勵落地，是「潮汐洗衣桶」；全場安靜三息。
②他氣得丟進髒襪子，桶卻自己換水、翻洗、甩乾；七個女角圍著看，比見神劍還認真，阿璃把自己的衣服也丟進去。
③附冊同時解鎖海工篇，留下父母最後通信的霧海工坊地址；唐酥已經在算船票。
④眾人正討論出海，桶裡吐出一件縮小的長袍，妖王推門：「我的衣服呢？」
⑤桶底還浮著一封信，用霧海工坊的紙寫的，落款日期是上個月；面板最後一行亮起：「百工仙錄・持有者：2。」

- 中段鉤子：海工篇解鎖
- 帶走的問題：另一個持有者是誰？

- 奇觀：洗衣桶轉起來，水面浮起一圈圈潮汐狀的光
- 顏值：七個女角圍著桶，燈光從桶裡照上來，每一張臉
