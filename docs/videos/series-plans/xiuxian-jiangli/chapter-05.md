## 49｜新郎呢？新娘呢？（120 秒｜結尾：危機）

**前 3 秒**：妖王府門口，紅綃的雙彎刀架在陸昭的鐵尺上：「宗門的人，先過我。」

①眾人帶貨到妖王府，紅綃與陸昭一見面就比劍，三十招不分勝負，阿璃一人一腳踹開：「都是自己人！」
②滿院喜字，卻找不到新人；妖王坦白婚宴採購是避開商盟監視、邀他們入境的藉口。
③唐酥先翻帳本：「救命另算，喜字不退。」妖王抱著一疊喜字愣住。
④阿璃帶大家看失去靈氣的城區：靈草枯成灰，井水沒了光。
⑤地下室掀開，一排仿製循環器嗡嗡轉著，每一臺底下都接著一根深入靈脈的抽取針，針上滲出黑色的靈氣。

- 中段鉤子：婚宴是假的
- 帶走的問題：誰在抽妖界的靈脈？
- 爽點：阿璃一腳踹開兩個高手（前半，hidden_power）；喜字不退（喜劇）
- 奇觀：地下室裡上百根抽取針同時插進發光的靈脈，像一片黑色的針林
- 顏值：紅綃與陸昭刀尺相抵、臉對臉，一個露尖牙一個抿唇

## 50｜連錯字都抄了（110 秒｜結尾：揭露）

**前 3 秒**：妖城工匠把一臺壞機砸在江小滿腳邊：「你賣的假貨！」

①工匠認定他賣假貨；他拆開外殼，發現連自己當初寫錯的那個字都被照抄。
②真正內部卻完全改了：回收散靈變成強行抽脈，分流口被焊死。
③他關閉一組抽取閥，旁邊枯黃的草葉在眾人眼前慢慢回綠；工匠不吭聲了。
④紅綃踢了機器一腳，機器突然響起「欠費催繳，三日內繳清靈脈分成」。
⑤唐酥臉色一白：「這聲音我天天聽。」是倪綺的聲音，商盟在妖城收的不是費，是靈脈。

- 中段鉤子：草葉回綠
- 帶走的問題：商盟抽妖界的靈脈，送去哪裡？
- 爽點：連錯字都抄的打臉（前半，public_vindication）；關閥草葉回綠（first_clear）
- 奇觀：枯草從根部往上一寸一寸泛綠，圍觀的妖族跪下去摸
- 顏值：唐酥聽到那聲音時手裡的算盤停住，眼睛慢慢瞇起來

## 51｜妖王，去洗碗（120 秒｜結尾：危機）

**前 3 秒**：育幼堂裡，六歲的團團把喜糖紙塞進嘴裡嚼，青蘿輕輕把紙抽出來。

①幼妖餓得咬喜糖紙；江小滿把婚宴食材改煮易吸收的靈粥，宋綰綰掌勺，一鍋接一鍋。
②妖王嫌一碗太少要加，下一刻被宋綰綰塞了一盆碗：「吃完的去洗。」妖王真的去洗了。
③面板達成「百人共食」，獎勵多層蒸架，他立刻擴大出餐；白鷺的鶴群一趟趟從院裡飛到各街口送粥。
④保鮮匣送往醫館，青蘿用它保存快要散靈的藥材，第一次對他點頭。
⑤最後一批糧袋運到，袋上印著商盟的字：「妖界欠繳，禁止出售。」糧只夠三天。

- 中段鉤子：妖王洗碗
- 帶走的問題：三天後吃什麼？
- 爽點：百人共食（前半，level_up）；妖王洗碗（villain_humbled 的喜劇版）
- 奇觀：十幾隻白鶴各叼一只保鮮匣從妖城上空飛過，街口的人仰頭
- 顏值：青蘿在醫館燭光下打開保鮮匣，紫色豎瞳映著藥材的光

## 52｜公主的懸賞畫得太醜（110 秒｜結尾：抉擇）

**前 3 秒**：運糧人展開懸賞單，上面的阿璃畫得像一隻生氣的猴子。

①運糧人拿出阿璃的懸賞單；她說自己正是因為查到抽靈機才被追殺。
②唐酥看著畫像：「難怪一直抓不到你。」紅綃笑到趴在車上。
③江小滿用皂清洗糧袋的假商標，露出底下的貨站編號，與仙城殘帳上的接收站一致。
④他決定送一袋「糧食」回去，袋底只藏一面留影鏡；鏡子只剩最後一段容量。
⑤守衛會檢查每一袋，送糧的人進得去未必出得來。唐酥問：「誰去？」陸昭與紅綃同時開口：「我。」

- 中段鉤子：假商標下的編號
- 帶走的問題：誰去送？進去的人出得來嗎？
- 爽點：懸賞像太醜（前半，喜劇）；皂洗出編號（first_clear）
- 奇觀：皂水一抹，整車糧袋的假商標像蛇皮一樣捲起來剝落
- 顏值：陸昭與紅綃同時開口，又同時瞪對方一眼

## 53｜關鍵證據，是一個屁股（120 秒｜結尾：揭露）

**前 3 秒**：貨站大門，扮成運糧人的陸昭低著頭，守衛申九抱怨：「空袋也要收費。」

①陸昭扮運糧人進站，紅綃扮押車的妖族奴工；申九一邊收費一邊嫌。
②藏在袋底的鏡子錄到工人運作機台，眾人滿懷期待取回。
③打開一看，大半影像被一個背對鏡頭蹲下的屁股擋住，是申九的；阿璃笑到從屋脊滾下來。
④江小滿從他挪開的那一瞬，看清管線通向哪間庫房。
⑤他把那一格放大：門牌寫著「鎮脈珠保管室」，門邊守著的人，正在對一面鏡子說話。

- 中段鉤子：屁股擋鏡頭
- 帶走的問題：保管室裡是另一半珠嗎？守衛在對誰說話？
- 爽點：陸昭混進貨站（前半，藏拙露鋒）；屁股（喜劇）；看清庫房（first_clear）
- 奇觀：留影鏡的光影在妖王府的牆上放大成一整面，眾人圍著看一個屁股
- 顏值：陸昭扮運糧人時把馬尾塞進斗笠，抬眼那一下還是執法堂的眼神

## 54｜我們是來送喜糖的（120 秒｜結尾：抉擇）

**前 3 秒**：唐酥捧著三層婚禮禮盒站在貨站門口，笑得比喜字還甜：「替妖王答謝商盟。」

①唐酥帶婚禮禮盒拜訪貨站，聲稱替妖王答謝；申九拆開只有便宜喜糖，邊嫌邊吃。
②江小滿趁交接混進庫房，找到另一半鎮脈珠，被鐵爪接在抽靈設備的總管上。
③原始記錄就在旁邊的鐵櫃裡：商盟收珠的日期，早於所謂失竊日期整整半個月。
④他剛收好記錄，面板跳出警示：拔珠會讓整個貨站的抽靈設備倒灌，珠不拔，妖界的靈脈今晚再枯一城。
⑤他的手放在珠上。門外唐酥的聲音越來越大，是在拖時間。他握緊了。

- 中段鉤子：另一半珠
- 帶走的問題：拔還是不拔？
- 爽點：喜糖混進貨站（前半，藏拙露鋒）；原始記錄到手（public_vindication 的證據）
- 奇觀：半顆鎮脈珠被鐵爪抓在總管上，珠光一跳一跳被吸進管裡
- 顏值：唐酥在門口拆禮盒給守衛看，笑容一秒不掉，眼睛往庫房門瞟

## 55｜雙修蒲團還能這樣用？（130 秒｜結尾：危機）

**前 3 秒**：珠離開鐵爪的瞬間，封庫陣「轟」地亮起，鐵門落下，把他跟珠一起鎖在裡面。

①庫門隔絕聲音，兩側機關必須同時操作；外面沈照雪拍門，他聽不見。
②她想起蒲團：分到半顆蓮後她只撐得住一次完整同步，她把這一次用在門外。
③蒲團從通風口遞進去，兩人在門兩側同步吐納；他突然被一陣掐痛嚇到，才明白她在用痛感報節奏。
④兩人照約定配合，第三次對上節奏，機關同時轉動，鐵門升起；他抱著珠滾出來，她靠在牆上喘。
⑤珠取下了，可遠端有人啟動了設備銷毀程序，整座貨站的管線開始倒灌，黑色靈氣從地縫冒出來。

- 中段鉤子：痛感報節奏
- 帶走的問題：誰啟動了銷毀？倒灌會傷到靈脈嗎？
- 爽點：蒲團隔門開機關（前半，hidden_power）；她的唯一一次用在他身上（情感）
- 奇觀：鐵門兩側兩個蒲團的光環隔著門對上，門縫裡透出一線金光
- 顏值：沈照雪隔門閉眼，額角的汗滴到蒲團上；門開時她第一個動作是伸手扶他

## 56｜我煮過會爆的鍋（120 秒｜結尾：揭露）

**前 3 秒**：紅綃拔刀要砸管線，江小滿撲上去抱住她的手臂：「別砸！裡面有壓力！」

①抽靈機倒灌污濁靈氣，紅綃要砸；他攔住：管線仍有壓力，硬砸會傷到靈脈。
②他借壓力鍋排壓的經驗分段關閥，師姐封住斷口，紅綃用兩把彎刀卡住機件穩住。
③快完成時他翻到背面，才發現還有一排閥；三人對看一眼，重來。
④最後一個閥關上，倒灌停了；儲靈顯示剩餘靈流只夠維持少數城區。
⑤他擦掉閥門上的黑灰，閥身上刻著一枚印，跟他鍋底的、殘爐底的一模一樣：百工坊。

- 中段鉤子：背面還有一排閥
- 帶走的問題：抽靈設備為什麼用的是百工坊的設計？
- 爽點：分段關閥救靈脈（前半，rescue）；三人配合（first_clear）
- 奇觀：黑色靈氣從地縫退回去，整座貨站的管線由黑轉灰再轉透明
- 顏值：紅綃雙刀卡在機件上、咬牙撐住，馬尾被氣流吹得豎起來

## 57｜這次，我能用自己的名字（130 秒｜結尾：危機）

**前 3 秒**：阿璃把兩個半顆鎮脈珠合在掌心，珠光合成一圈，妖王府滿院的人跪了下去。

①阿璃帶回完整的鎮脈珠，公開原始交接記錄。
②貨站管事否認，唐酥翻出他的收款簽名，貨站工人也出面作證。
③妖王當眾撤回對女兒的追捕，父女相認；他抱住她的時候，還抱著那疊喜字。
④阿璃擦掉眼淚，第一件事是要求把那張醜得要命的懸賞像撤下，紅綃說她已經留了一張。
⑤醫館傳來消息；青蘿帶他到育幼堂，把燈一盞盞吹熄：「入夜降溫後，現有靈氣就是這樣，護不住孩子。」團團仰頭：「燈不亮了。」

- 中段鉤子：父女相認
- 帶走的問題：今晚孩子怎麼辦？
- 爽點：管事被收款簽名打臉（前半，face_slap）；撤回追捕（public_vindication）
- 奇觀：兩個半顆珠合成一顆，珠光從妖王府散到整條街
- 顏值：阿璃擦眼淚時虎牙咬住唇，妖王的赤金瞳孔濕了

## 58｜喜字別拆，能救命（120 秒｜結尾：升級）

**前 3 秒**：江小滿爬上梯子拆婚禮燈串，工匠在底下喊：「連燈芯都要賣？」

①他拆開燈串，工匠以為他連燈芯都要賣。
②燈串原本能均分靈流，配上循環器成了臨時供靈網；宋綰綰把廚房的靈火接進去當第一個源頭。
③流量有限，只能優先供應醫館與育幼堂；妖王那張會發光的豪華王座被迫熄了，他抱著王座不肯放，阿璃一句「父王」他就鬆手。
④孩子們的屋子亮起來，團團第一個拍手；他把喜字貼到各支線上：「正好當分區牌。」
⑤燈串一路亮到育幼堂最後一間，面板跳出一行他沒見過的字：「公共供靈網：進度 1 / 100。」

- 中段鉤子：王座熄、育幼堂亮
- 帶走的問題：一百是什麼？
- 爽點：燈串變供靈網（前半，reversal）；王座熄孩子屋亮（情感）；進度條出現（level_up）
- 奇觀：婚禮的紅燈串在夜裡從王府一路亮到育幼堂，像一條紅色的河
- 顏值：青蘿站在亮起的育幼堂門口，紫瞳映著紅燈，第一次笑

## 59｜借一下你的床（110 秒｜結尾：情感）

**前 3 秒**：江小滿盯著妖王的床柱：「這個，是導靈銅吧？」妖王抱住床：「不行。」

①導靈銅不夠，他盯上妖王床柱的裝飾；妖王死抱著床。
②阿璃直接指出父親還藏著幾件同材質的酒器，妖王連酒器一起交了出來。
③拆下的零件讓城區輪流供靈；他御劍穿街接上最後一盞燈，這回沒撞晾衣繩，落地很帥。
④落地太累，他靠牆睡著；報修的人群湧上來，妖王抱著枕頭從屋裡出來：「那我睡哪？」
⑤沈照雪橫劍擋在他前面，對人群只說一句：「讓他睡。」阿璃把妖王的枕頭輕輕塞到他頭下。

- 中段鉤子：御劍接燈
- 帶走的問題：他還能撐幾天？
- 爽點：御劍穿街（前半，level_up）；妖王交酒器（喜劇）
- 奇觀：他踏劍穿過整條亮著紅燈的街，燈影在劍身上流過
- 顏值：沈照雪橫劍擋人群，側臉被紅燈照著；阿璃蹲下來塞枕頭，辮子垂到他臉上

## 60｜救活一座城，鍋卻成了違禁品（160 秒｜結尾：反轉）

**前 3 秒**：居民推來一車巨殼果，江小滿敲了半天敲不開：「這要怎麼剝？」

①居民送來謝禮，一車不知道怎麼剝的巨殼果；紅綃一刀劈開，裡面的果肉亮得像靈石。
②面板完成「百戶安居」，解鎖公共供靈網圖紙，進度條的一百是一百戶。
③城外山道上一隊玄色官袍的人馬上山；裴玄衡親自到妖城，在王府門口宣讀封鎖令：私通妖族、封鎖材料供應、壓力鍋列為違禁靈器。
④唐酥收到封店通知，宋綰綰抱住鍋，陸昭的鐵尺出鞘又被沈照雪按下；裴從頭到尾沒提高聲音。
⑤裴玄衡看江小滿第一眼，停了一下：「你長得像一個人。」江小滿從地上撿起妖城的廢零件：「那就試試，哪些能自己做。」

- 中段鉤子：封鎖令
- 帶走的問題：裴玄衡說的那個人是誰？
- 爽點：百戶安居（前半，level_up）；當面撿起廢零件（reversal）
- 奇觀：玄色官袍的隊伍沿山道上來，紅燈串一盞盞被封條蓋住
- 顏值：裴玄衡站在喜字底下，玄袍一絲不亂，看他的那一眼有一絲動搖
