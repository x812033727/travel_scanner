# 《我的修仙獎勵是不是發錯了？》｜第一季 72 集企劃包

白玉宗雜役江小滿被列在清退名單第一名，三十天內拿不出修為就要走妖獸道下山。撿來墊灶的破書在他手裡亮起「百工仙錄」，第一個獎勵是一口會叫的壓力鍋。獎勵讓人猜不到，用法讓人想不到，後果又能順理成章地鬧大：鍋、定量勺、留影鏡、去垢皂、雙修蒲團、保鮮匣、靈氣循環器、精密刻刀、蒸架、洗衣桶。他先靠一口鍋養活自己，再靠手藝留住夥伴，最後練出能保護大家的劍；第 66 集才知道這本仙錄是失散的父母留下的，獎勵沒有發錯。

- 類型：修仙＋系統＋生活用品反差喜劇＋慢熱多女主；3D 國漫 CG 動畫（站主 2026-10-27 定）
- 規模：**第一季 6 篇 × 12 集 = 72 集**；每集約 90–120 秒，篇末 150–180 秒
- 來源：站主請 Codex 寫的 72 集綱要（2026-10-27），由 Claude 照《種田娶妻打天下》的寫法規則全部重寫；評估與五個病因在 PR #1893 的說明
- 製作：片段在 Colab 的 GPU 跑開源 H3（skill `minimax-h3-colab`），設定圖與關鍵影格用產線的 `look`／`keyframes`，見 [production/colab/README.md](production/colab/README.md)

## 讓人停不下來的規則（跟《種田》同一套）

- 每集三個不同的鉤子：前 3 秒、中段、結尾；①到⑤是依序發生的五件事，笑點只放①到④，⑤不收笑話。
- 收在最高點：結尾類型（危機／揭露／抉擇／反轉／情感／升級）相鄰兩集不重複；篇末與季末收在反轉。
- 每集至少兩個爽點，第一個在前半；主角不連兩集輸；連續四集至少收一條線。
- 面板有代價：獎勵要靠做出有用的東西、改善生活、建立合作解鎖；道具要材料與靈力；同一件事不能無限刷。
- 女主不是獎品：沈照雪、阿璃、唐酥各有祕密與自己贏的戲；第一季不定官配。
- 不黃標、顏值：見設定集。
