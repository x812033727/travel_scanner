## 25｜開店第一天，先被當騙子（120 秒｜結尾：危機）

**前 3 秒**：唐酥掛出招牌「一碗飯抵三日苦修」，江小滿扛著梯子要拆：「這叫詐騙！」

①招牌太誇張，他急著改；對門鋪子同一天開張，老闆娘是宋綰綰，招牌「膳堂正宗」。
②倪氏派人來挑戰，要求讓修為低微的老搬運工石伯試吃。
③石伯吃完，扛起平常得休息半天才抬得動的石箱走過整條街；眾人驚嘆，他第一句卻是找僱主加薪。
④客人排滿街；宋綰綰在對門二樓端著茶看，笑著喊「借你的鍋看看？」被阿璃一句「借妳的臉嗎」頂回去。
⑤江小滿打開米缸：空的。門外商盟的告示剛貼上：「靈米自今日起，只售商盟會員。」

- 中段鉤子：石伯扛石箱
- 帶走的問題：沒米怎麼開店？
- 爽點：石伯扛石箱（前半，public_vindication）；加薪（喜劇）
- 奇觀：老搬運工單手扛起石箱走過整條街，兩邊鋪子的人探出頭
- 顏值：宋綰綰倚在對門二樓欄杆端茶，木簪斜插、笑不到眼睛

## 26｜系統送我剩飯盒（110 秒｜結尾：揭露）

**前 3 秒**：唐酥從後門拖進一袋米：「別問哪來的。」江小滿：「商盟的印還在袋子上。」

①唐酥說是「人脈」；客人想帶靈食回家，普通飯盒留不住靈氣。
②江小滿反覆試作，解鎖「保鮮匣」；阿璃嫌它像小棺材，偷偷刻上「飯之墓」。
③帶回家的飯仍有補益；白鷺騎鶴來，說鶴舍也要，連送藥材的人都來詢價。
④唐酥接下一車靈果保鮮訂單；江小滿指著匣子：「我只有這一個。」
⑤夜裡留影鏡拍到宋綰綰翻牆來「借鍋」，裙擺勾在牆頭；阿璃看鏡子時，看見畫面角落，唐酥在後門收下第二袋米，交米的人是申九。她沒說。

- 中段鉤子：保鮮匣落地
- 帶走的問題：唐酥收商盟的米要做什麼？阿璃會說嗎？
- 爽點：保鮮匣（前半，升級）；飯之墓（喜劇）
- 奇觀：保鮮匣合上時一圈淡光把飯香封在裡面
- 顏值：宋綰綰翻牆裙擺勾住，氣得跺腳，步搖換成木簪也在晃

## 27｜限量一個，她接了一百單（120 秒｜結尾：危機）

**前 3 秒**：唐酥：「我接的是運送服務，不是賣匣子。」她把配方拍在他面前：「量產。」

①第一批為省料做得太薄，靈氣漏得比他本人還快；阿璃把漏氣的匣子排成一排，說像墓園。
②加隔板成功，算完成本只剩兩文利潤；師姐提醒匣子能回收，唐酥立刻改收押金。
③宋綰綰買走十個退九個，留一個拆；唐酥把押金翻倍。
④倪綺的轎子停在門口，買走一只空匣：「這破木盒，我也會做。」
⑤她臨走把一枚靈石放在鍋蓋上：「鍋的訂金。」轎子走遠，靈石開始發燙，面板跳字：「檢測到探測靈印，正在讀取鍋底刻印。」

- 中段鉤子：押金翻倍
- 帶走的問題：倪綺在讀鍋底的什麼？
- 爽點：押金翻倍（前半，喜劇）；量產成功（first_clear）
- 奇觀：一百個保鮮匣在院裡排成方陣，同時亮起
- 顏值：倪綺隔著轎簾伸出一隻手把靈石放下，翡翠簪在簾縫裡一閃

## 28｜仙子一劍，按次收錢（130 秒｜結尾：情感）

**前 3 秒**：江小滿用鍋鏟把發燙的靈石鏟進水桶，「滋」一聲，面板：「讀取中斷。」

①鍋沒事；客人要新品，他擺出留影鏡，誤放阿璃偷吃的影像；阿璃當場付錢要求刪除，唐酥眼睛亮了。
②沈照雪同意錄基礎劍式，鋪子推出付費觀摩；宋綰綰也買票，坐在最後一排偷學。
③江小滿看鏡中師姐收劍時微微抖手，主動撤下暴露舊傷的片段。
④當晚蒲團上，她第一次自己說：經脈在漏，首席的位子撐不了多久；第 1 集到雜役院，是顧長老讓她去看那個撿到破書的雜役。
⑤「那後來呢？」她看著他：「後來是我自己要來的。明天練劍，替我看看。」

- 中段鉤子：付費觀摩
- 帶走的問題：她撐得了多久？
- 爽點：付費觀摩開張（前半，first_clear）；撤片段護她（情感）
- 奇觀：鏡中劍光一式一式在院裡重播，圍觀弟子跟著比劃
- 顏值：沈照雪在蒲團上側過臉，燭光，第一次露出倦意

## 29｜人還沒紅，假貨先到了（120 秒｜結尾：反轉）

**前 3 秒**：客人抱著一箱腐壞靈果砸在櫃檯：「賠！」匣子上沒有本店刻紋。

①街上出現假攤販，連雜役衣服和摳門語氣都學了；江小滿追人，熟客反把他當成冒牌貨攔住。
②阿璃從屋頂連跳七家，真正的假販子被師姐抓回；仿匣裡用的是會吸走靈氣的便宜木料。
③假販子供出貨源：對門。宋綰綰攤手：「我也是買的。」
④唐酥決定把工序公開展示讓客人認得真貨；江小滿不解，公開了不是更好仿？唐酥：「仿得出工序，仿不出鍋。」
⑤展示到一半，宋綰綰從人群裡走出來，把一枚印章放在桌上：「這是我舅舅的。假匣的刻紋用的是它。他現在在商盟當差。」她眼眶是紅的。

- 中段鉤子：假販子供出對門
- 帶走的問題：宋綰綰是敵是友？
- 爽點：抓假販（前半，counter_kill）；工序公開反讓仿品滯銷（reversal）
- 奇觀：阿璃在屋頂連跳七家，落在假販子面前，瓦片一片沒碎
- 顏值：宋綰綰放下印章時低頭，睫毛是濕的

## 30｜小院升級，獎一臺破風扇（110 秒｜結尾：危機）

**前 3 秒**：四人把倉房最後一面牆推起來，面板：「居所升級。」

①存貨增加，四人修好與店相連的倉房；面板獎勵「靈氣循環器」，外形像吱呀作響的風扇。
②江小滿對著丹田吹，修為毫無變化；阿璃對著臉吹，頭髮全炸開。
③移到蒸鍋旁，逸散靈氣竟能回收進儲靈槽；四人第一次看見「散靈」變成存得住的東西。
④阿璃把一盆成熟靈蔥放到出風口；隔天清晨，白鷺的鶴在院外盤旋不肯落地。
⑤滿屋蔥味濃得嗆人，街上的人以為失火；商盟查驗隊跟著味道上門：「誰家在用靈氣設備？」

- 中段鉤子：散靈回收
- 帶走的問題：查驗隊要查什麼？
- 爽點：居所升級（前半，level_up）；散靈回收（hidden_power）
- 奇觀：風扇轉起來，蒸鍋上的白氣被吸成一條細線鑽進儲靈槽
- 顏值：阿璃頭髮被吹成獅子，沈照雪笑到扶門

## 31｜這根蔥，比肉還貴（110 秒｜結尾：揭露）

**前 3 秒**：查驗隊進門被蔥味嗆出眼淚，隊長一邊流淚一邊問：「設備呢？」

①江小滿說只是風扇；陸昭以執法堂名義到場，「宗門器物，宗門自查」，把查驗隊擋在門外。
②靈氣集中補給過頭，他替風扇加上分流口；靈蔥切一小段就能調一鍋湯，唐酥改按段賣。
③阿璃偷吃半根，知道價格後主動把剩下半根藏起來。
④商盟文書送達：「用靈氣設備，另繳供靈費。」落款是倪氏貨行代收。
⑤陸昭臨走壓低聲音：查驗隊長的臉她認得，是第二篇來搜山的灰衣人申九，換了商盟的衣服。

- 中段鉤子：一段蔥一鍋湯
- 帶走的問題：仙盟的人為什麼穿商盟的衣服？
- 爽點：陸昭擋查驗（前半，rescue）；一根蔥比肉貴（喜劇）
- 奇觀：一根靈蔥切下一段，整鍋湯浮起翠綠的光
- 顏值：陸昭黑紅勁裝站在門口，鐵尺橫在胸前，一步不退

## 32｜我撿剩下的，也要收錢？（120 秒｜結尾：危機）

**前 3 秒**：江小滿一掌拍熄靈火，風扇停了：「它只撿剩的。」

①關掉靈火，循環器停止蓄能，證明只回收散靈；唐酥逼查驗者當場承認沒有用商盟供靈。
②倪綺轉頭推出「不用靈石的循環器」，價格便宜一半，指定對門代售；宋綰綰拒絕了。
③江小滿拆開仿品，裡面藏著會耗盡的劣質儲靈石，還少一道限流符。
④受僱匠人魯七來借留影鏡，想記下自己做工的數量討工錢；唐酥借了，還多塞了一面。
⑤夜裡唐酥去巷子見申九。申九：「倪掌櫃說，鍋不賣，就讓鍋出事。明天斷料。」唐酥：「我知道了。」

- 中段鉤子：仿品拆開
- 帶走的問題：唐酥會告訴他嗎？
- 爽點：關火證明打臉（前半，face_slap）；拆仿品（public_vindication）
- 奇觀：仿品拆開，劣質儲靈石一顆顆黑掉
- 顏值：唐酥在巷子裡，算盤抱在胸前，燈籠只照亮半張臉

## 33｜買不到材料，我去收破爛（120 秒｜結尾：抉擇）

**前 3 秒**：清晨，唐酥把一張紙拍在桌上：「今天起全城斷料。別問我怎麼知道的。」

①倪綺聯合商行斷料，訂單做不出來；唐酥知道得太早，阿璃盯著她，什麼都沒說。
②江小滿帶大家去廢器場，唐酥一路嫌髒；阿璃打開一個漂亮法器盒，被殘留煙灰噴成黑臉。
③師姐辨出可用符線，拆舊件反而降低成本；白鷺騎鶴運回一車廢器。
④新貨剛做好，商盟堵門：「有人舉報，你們收了宗門贓物。」
⑤阿璃把唐酥拉到後院：「舉報的人是誰，妳知道。」唐酥咬唇：「我現在說，鋪子今天就沒了。」阿璃：「那妳選。」

- 中段鉤子：廢器場
- 帶走的問題：唐酥選哪邊？
- 爽點：廢器場撿到寶（前半，first_clear）；拆舊件降成本（reversal）
- 奇觀：廢器場：成山的破法器在夕陽下泛著雜色的光
- 顏值：阿璃黑臉只剩眼睛是白的，氣得辮子都翹起來

## 34｜這口爐是我炸的（130 秒｜結尾：揭露）

**前 3 秒**：商盟指著廢器上的白玉宗標記：「封店。」江小滿：「等我洗個臉。」

①他用皂洗掉新加的外附標記，露出底下的報廢刻號；商盟還要狡辯。
②顧長老趕來認出殘爐：「這口是我炸的，那口也是。你要查哪一口？」眾人當場解圍。
③人散後，顧長老翻過殘爐底部，一枚印，跟江小滿鍋底的一模一樣。
④他第一次說：這印是「百工坊」的，一對夫婦開的，替平民做器物，被仙盟查抄；當年奉命炸爐的人是他，他欠那家人的，不只一頓飯。
⑤「那家人呢？」顧長老沒答。街外連聲爆響，倪家的仿機炸了。

- 中段鉤子：顧長老認爐
- 帶走的問題：百工坊的人去哪了？
- 爽點：皂洗標記（前半，face_slap）；「這口是我炸的」（villain_humbled）
- 奇觀：殘爐底部的印在皂水裡浮出來，與鍋底的印重疊
- 顏值：沈照雪護在江小滿身側，手按劍，看顧長老的眼神變了

## 35｜他的東西炸了，怪我的設計（120 秒｜結尾：危機）

**前 3 秒**：仿機過載燒壞一整片靈草，倪綺站在焦土上：「原版的缺陷。」

①倪綺指控原版就有缺陷；江小滿要求同時拆機，對方只交出燒黑殘件。
②唐酥買來未拆封仿品，她知道倪氏哪個倉有存貨；藏匿靈石與被省掉的限流符當眾露出。
③倪綺聲稱是主角換貨栽贓；宋綰綰站出來作證仿品是倪氏直送，倪綺看她一眼：「妳舅舅的事，還沒完。」
④魯七站出來，鏡中正錄著倪綺在工坊說：「少裝一道，誰看得出來？」
⑤倪綺不慌，拍了拍手：商盟執法隊到，「仿機傷人，原版同罪，兩家都封。」貼封條的人是申九。

- 中段鉤子：未拆封仿品露餡
- 帶走的問題：兩家都封，怎麼翻？
- 爽點：仿品露餡（前半，face_slap）；鏡中錄音（public_vindication）
- 奇觀：焦黑靈草田上十幾臺仿機還在冒煙
- 顏值：倪綺站在焦土上，披帛被熱風吹起，笑容一點沒變

## 36｜生意剛做大，妖王下單了（170 秒｜結尾：反轉）

**前 3 秒**：魯七把一本工帳拍在封條上：「倪氏少裝的那一道，我每一臺都記了。」

①工帳證明仿品與原版設計不同；顧長老與陸昭以宗門名義解封小院，倪綺被追究賠償，申九撕封條時手在抖。
②江小滿承接壞機回收，第一次把修理做成穩定生意；面板獎勵精密刻刀，能可靠量產細小符線。
③唐酥接到天價訂單，署名「妖王府」；申九同時找上門，要她把訂單交給倪氏。
④唐酥把訂單和那張商盟的紙一起攤在飯桌上：「我是商盟派來盯你的。從今天起不是了。」阿璃把一碗飯推給她，沈照雪把劍從桌上拿開，江小滿說：「押金不退。」
⑤阿璃看見訂單上的印記，臉色全變：「這是我父王的印。」附函只有一句：「循環器，務必親送。」

- 中段鉤子：妖王府訂單
- 帶走的問題：妖王為什麼點名要親送？
- 爽點：工帳翻盤（前半，betrayer_punished）；唐酥反水被接納（reversal）；刻刀（level_up）
- 奇觀：一桌人、四碗飯、一張訂單、一枚妖王的印
- 顏值：唐酥攤開紙時手在抖；沈照雪把劍從桌上拿開那一下
