# 潮退之後｜四篇四十集總綱

保險理賠調查員宋以寧回到十五年前燒死弟弟的海線小鎮，一件詐騙車手的溺死理賠案讓她發現那場「電線走火」是一張五人桌合夥點的火。她一篇掀一個人；掀到最後，掀開的是整個鎮的沉默，和她自己的母親。

每集目標 60 分鐘（55–62）。以下的分鐘數是規劃位置，劇本與剪接後重量。

## 每集高潮的規則

寫進每一集的細綱，不是口號：

| 位置 | 規則 |
| --- | --- |
| 0–3 分 | 冷開場鉤子：不重播前情，直接進一個問題、一個危險或一個違和的畫面 |
| 約 15 分 | 第一次局勢改變：新情報、新對手、新代價，主角的計畫要改 |
| 約 30 分 | 第二次局勢改變：通常是反制或翻轉，主角失去某樣東西 |
| 約 45 分 | 本集高潮：一次正面對決、一次拿到手、或一次失手 |
| 最後 5 分 | 接續收尾：新的懸念，下集開場能直接接；懸念類型輪換（danger、reveal、question、choice、arrival），連續兩集不重複 |
| 每集 | 至少一次「具體回報」：觀眾看得見的小勝、小敗或小真相；情報、關係或處境至少改變一樣 |
| 每篇 | 第 1 集與第 10 集有以寧的口白；其餘沒有 |

## 第 1 篇：名冊（1–10）

一份保單，能讓一個死去的人替活著的人還債。

起點：以寧 33 歲，在台北做理賠調查十五年，接到鹽澳一件車手溺死案；她十五年沒回家過中秋。終點：黃添財被檢調約談、開發案暫停；以寧被公司停職、鎮上知道她在查什麼；她拿到的「名冊」其實是上船名單。
