# 給企劃 AI 的分鏡交辦：每一鏡要寫清楚的事

通用版（給任何 AI 漫劇）在 `.agents/skills/animation-preproduction/references/storyboard-shot-spec.md`；這份是《種田》要直接貼給企劃 AI 的版本。

站主 2026-11-05：第 1 集重製版 r2 的第一批草稿，辦公室兩鏡許硯穿成古裝、二牛三鏡背上多一個大甕，
很多對話近景幾乎不動。原因都是分鏡沒寫到、製作端只能用角色的預設外貌去猜。**這些要在寫分鏡時就定好**，製作端照抄，不再自己補。
製作端開拍前會用 `colab/runs/_scripts/preflight-prompts.py` 檢查，但檢查只能擋錯，不能替分鏡補內容。

下面是可以直接貼給企劃 AI 的交辦。

---

## 交辦（貼給企劃 AI）

寫《種田娶妻打天下》的分鏡時，每一鏡都要寫齊下面九項。寫不出來的項目，代表這一鏡還沒想清楚，先想清楚再交。

1. **服裝**：畫面上每個人穿哪一套。跟他平常的樣子不同時要寫明，例如「許硯：現代西裝（開場）」、「阿令：拿掉鐵鐐後」。
   第一次出現的新服裝，要列進〈本集需要的造型〉，讓製作端先在 `cast.json` 開 `shot_looks`、畫參考圖。
2. **道具**：誰手上、肩上、背上拿著什麼。沒寫就是兩手空空。
   角色的基本外貌不帶道具，這一鏡要扛扁擔、拿刀、提燈，就寫在這一鏡。
3. **畫面裡有誰**：人數，以及每個人在畫面的哪裡（左／右／前景／背景）、面向哪裡。
   背對鏡頭、只露肩膀、只有一隻手的人要寫明。聲音在畫外的人寫「畫外」，不要讓他出現。
   同一個人在一鏡裡只能出現一次。
4. **每個人的動作**：寫成一段路徑：從哪裡開始、預備動作、主要動作（要有重量）、停在哪裡。
   例如「趙捕頭從院門大步走過來，紅紙在手裡甩動，停在許硯一臂外」。
   **畫面上的每個人都要有動作**，連聽話的人也要（點頭、退半步、手放下來）。不能只寫表情。
5. **運鏡**：一鏡只寫一個：固定、慢推、拉遠、跟拍、環繞、搖鏡。
   說話的近景不要只寫固定，至少慢推，或配合人物的動作。
   推近要寫從哪個景別推到哪個景別。
6. **景別與構圖**：全景、中景、近景、大特寫、過肩、雙人鏡。對話一來一往用過肩與反打，寫清楚誰的肩、拍誰、視線看誰。
7. **文字與紙**：畫面裡有信、告示、履歷、帳本、聖旨時，寫明「背面朝鏡頭」、「摺著」、「虛焦」或「側邊」。
   不寫紙上的內容：模型畫出來的字都是假字。要讓觀眾知道內容，用台詞或系統面板。
8. **台詞**：
   - 誰說、對誰說、語氣，一句一行。
   - 嘴在畫面上的人才對嘴；**內心獨白標「心裡話，嘴閉著」**。
   - 五個字以內的喊叫（「哥！」「衝！」）標「短喊」。製作端會改成「張嘴喊」，不把字放進畫面描述，免得被畫成字幕。
   - 系統的話標「系統」，用剪接疊面板，不畫在畫面裡。
9. **秒數**：估這一鏡的長度，等於台詞總長（中文約每秒 4.5–5.5 字）加動作時間。
   超過 6 秒的鏡標出來（製作端會買 8–12 秒），不要靠慢放。

**角色的特別規則**（每次都要照寫）：

- 唐小棠：用高立領的定妝照（`tangxiaotang-portrait-t2`）。近景構圖寫「下巴以上」；中景以上寫「襦裙從立領到腰一件闔上」。
- 系統：只有聲音和面板，不寫在畫面裡。
- 預設表情不笑，稿子寫了笑才笑。

## 其他常犯的錯（依第 43–56 集與 r2 的經驗）：分鏡裡要先寫好的

| 會出錯的地方 | 實際發生過 | 分鏡要怎麼寫 |
| --- | --- | --- |
| **同一人出現兩次** | 第 54–56 集：特寫的人又站在背景裡（場景圖裡有人形、或角色的角度圖被當成第二個人） | 寫明「身後只有○○（牆、夜空、樹）」；近景、特寫標「不用場景圖」；人多的鏡寫清楚總人數 |
| **人數不對** | 「三個女子」只畫兩個、六十個少年變兩排同樣的人 | 寫實際人數與排法，例如「一排五人靠一根漂流木」；群眾寫「約○人、站成○」 |
| **群眾與配角穿現代衣服** | 第 55 集被綁的手下穿綠色軍服、大簷帽；拿信的手穿西裝袖、白襯衫袖口 | 群眾、士兵、騎兵、刺客都寫朝代衣著：「宋式交領短打、布包頭」「圓領袍、黑幞頭」；只拍手的插鏡寫袖子的樣子，或寫「只拍指尖、袖子不入鏡」 |
| **場景圖裡的時代錯誤道具** | 第 50 集客棧桌上的現代玻璃酒瓶 | 用到有道具的場景，寫明桌上有什麼（「陶甕、陶杯」）；不要寫「酒瓶」「酒杯」，寫「陶甕」「小陶杯」 |
| **假字** | 信、告示、匾額、招牌、履歷都會長出亂碼 | 見第 7 項；招牌和匾額寫「空白」或「不入鏡」 |
| **台詞被畫成字幕** | 第 53 集 s05「衝——！」燒進畫面 | 見第 8 項；分鏡的畫面欄不要放台詞原文 |
| **鏡中切、溶成遠景** | 第 55 集 s15、s43，第 56 集 s04、s13：特寫一秒就切成遠景，或結尾溶掉 | 寫「整鏡都是這個景別，不切、不溶」；一鏡要兩個景別，就拆成兩鏡 |
| **插鏡開頭是空景** | 信、碗、米缸的插鏡，開頭一秒是整個房間 | 寫「第一格就是這個特寫」 |
| **鏡頭裡的人不動** | r2 的對話近景動量只有 2–5（目標 ≥ 7） | 見第 4、5 項：每個人都要有動作，運鏡至少慢推 |
| **預設在笑** | 報壞消息時角色在笑 | 每鏡寫表情；沒寫就是嚴肅 |
| **光腳** | 全景、中景常畫成光腳 | 全景寫「穿布鞋」（製作端也會補） |
| **畫風不同的人** | 第 56 集 s21 的望樓少年畫成 Q 版大頭 | 有台詞或正面的配角都要有定妝照；沒有的寫「只拍背影」，不要讓模型自己發明 |
| **唐小棠低胸** | 第 45、55、56 集 | 見特別規則：近景下巴以上 |
| **連戲：位置與視線** | 前一鏡在左、下一鏡跑到右；對話時兩人看的方向不對 | 每場戲開頭寫一次軸線：誰在左、誰在右、門在哪；每鏡寫視線看向畫面左或右 |
| **連戲：時間與光** | 第 55 集用了月夜的村口場景圖拍早上；白天出現月亮 | 每場寫時間與光（黎明霧、正午、傍晚斜光、夜裡火光）；換場才換光 |
| **連戲：道具與傷** | 鐵鐐、玉佩、信、草編兔子前後鏡不一致 | 列在〈本集需要的造型〉：哪一鏡拿到、哪一鏡放下或拿掉（例如阿令第 2 集 c01 拿掉鐵鐐） |
| **馬、轎、車** | 騎馬的人下一格馬不見了 | 寫清楚人在馬上還是已經下馬、馬在畫面的哪裡 |
| **片段不夠長** | 加了台詞後五鏡要重畫 | 見第 9 項；改台詞時一起改秒數，並通知製作端哪些鏡變長 |
| **系統面板** | 面板由剪接疊上，模型畫的面板會有假字 | 畫面欄寫「臉被面前的藍光照亮」，不寫面板內容；面板文字另外列在〈面板〉欄 |

## 改稿時要一起告訴製作端的事

- 哪幾鏡的台詞變了、變長了（片段可能要重畫）。
- 有沒有新角色、新造型、新場景（要先畫參考圖）。
- 換了聲音或語氣的角色。
- 已經拍好的鏡頭能不能沿用。不能的話，原因是什麼。

## 每集附在分鏡最後的三張清單

1. **本集需要的造型**：每個角色本集用到的服裝與道具。跟 `cast.json` 不同的，標「要新開 look」。
2. **本集需要的參考圖**：新角色、新場景、同一角色的新造型，例如拿掉鐵鐐的阿令。沒有參考圖的人，寫明「只拍背影」或「只露肩膀以下」。
3. **長鏡清單**：超過 6 秒的鏡和預估秒數。

## 交出去之前自己對一遍

- 有沒有人「站著」、「看著」卻沒有動作？
- 換裝、拿道具的鏡頭，前後鏡連戲嗎？
- 畫面上有沒有紙、字、招牌？都寫成背面或虛焦了嗎？
- 唐小棠的近景寫「下巴以上」了嗎？
- 內心獨白和短喊都標了嗎？
