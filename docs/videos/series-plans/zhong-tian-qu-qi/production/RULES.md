## 五、每一集怎麼做（站主 2026-11-07）

1. **自己審、自己改**：挑片後、剪完後各一次獨立審片；嚴重與中等的自己修好再給站主，輕微的接受（流程在共用 [`REVIEW.md`](../../../drama/REVIEW.md)）。
2. 有要檢討的就記教訓（skill 規則、寫稿說明、preflight）。
3. 一集做完就推這一集的備份分支與共用分支，以後重做需要的檔案全部在裡面（見第七節）。
4. 刪本機檔案前兩件都要成立：備份核對過（`verify-episode.py` 0、`coverage.py` 0、另一個代理到 GitHub 逐檔核對），**而且**這集已送上後台，
   在後台確認成片、字幕、封面都在。只刪那一集。站主：「當然要後台都送上也都有才能刪除」。
5. 前一集在跑的時候，先做下一集的前置（轉真人版提示詞、preflight、需要的參考圖）。

另外：

- **審片時機**（2026-11-07）：挑完片、精修前一次（連戲表的草稿模式加獨立審片）；剪完再一次全部檢查與獨立審片。站主：「這些在審片時應該要看到吧？」
- **表情**（2026-11-08）：「應該每個都要有表情，除非是劇情要求要沒表情」。第 1 集站主選只重拍最嚴重的 4 鏡（s02、s18、s19、s24），其他接受。
- **自己定時檢查**（2026-11-06）：容器會重啟，排程每小時兩次喚醒同一個對話，看批次與 pod，不要等站主問。
- **分鏡交出去之前三道檢查**（2026-11-06，站主問「這個審片機制有定義新規則了嗎」之後定的）：見 `WRITING.md` 第十二節。
