# e901-live 視線審查（種田娶妻打天下 第 1 集・真人版）

審查日：2026-11-08。依站主新規則：「很多幕都是看前面，不會面對對方說話」——說話的人要看著對方（側臉或四分之三側臉，眼睛落在對方身上），不可看鏡頭；一排人一起面對鏡頭像拍照，不像對話。

- 成片：`~/mokaair-work/videos/_live-e901/zhong-tian-qu-qi-e901-dh/cut/e901-live.mp4`（269.83 秒），鏡頭起點取自 `final.log`，台詞起點與長度取自 `e901-live.lines.json`。
- 劇本：`docs/videos/zhong-tian-qu-qi-e001-r2/video.json` 各鏡的 `prompt`、`motion`（誰在哪、對誰說）。
- 做法：每句台詞在 `[start, start+len]` 內平均取 6 格（成片時間軸），看說話者與聽者的眼睛方向。表中時間是成片秒數（前半段用 `select=between` 抽格的時間戳可能差 ±0.15 秒）。
- 不審：系統音（a04、a08、a10、a41、a42、a44）、內心獨白（a09、a16、a45）、畫外（a01 面試官、a22 趙捕頭在 s20 踹門插入鏡）、背對鏡頭（a03 s03、a24 s22）。a28（s26 鐵鐐插入鏡，趙捕頭不在畫內）也不審。
- 等級：**OK** = 看著聽者，或朝聽者那一側看出畫；**輕微** = 偶爾掃過鏡頭，或方向偏了但沒有看鏡頭；**中等** = 約一半時間看鏡頭、看錯人，或聽者盯著鏡頭；**嚴重** = 重要台詞大半時間對著鏡頭說。
- 「可修剪？」：每句台詞幾乎佔滿整個鏡頭（音訊不能動），能剪掉看鏡頭的格子又不切到台詞的情況很少，所以多數寫「否」。

規律：問題幾乎都出在「單人正面中近景＋推鏡，聽者在畫外」的鏡頭（s02、s09、s17、s19、s28、s29、s32、s35）。prompt 寫了「eyes on X off screen right」，但人物在畫面正中、正對鏡頭構圖時，模型在推鏡過程中會把眼睛拉回鏡頭。兩人側臉相對（s11、s31）或過肩鏡頭（s10、s15、s27、s34 第二句）幾乎都對。
