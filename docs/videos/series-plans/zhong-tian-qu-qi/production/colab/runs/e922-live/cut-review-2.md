## 一、第一次看的觀眾（不看稿子，只看成片與字幕）

**看懂了什麼**

- **0:00–1:01，客棧**
  - 粉衣丸子頭的姑娘（一直背對我）一個人來找藍袍拿扇子的公子：「我一個人來的，有一筆帳想跟你談。」他問許秀才捨得放她出門？她說他不知道，這是他們之間的事。
  - 她把一袋金錠倒在桌上：「我拿它買我自己。」他用扇子把金子推回來：「我要的，是人。」又威脅許家的鋪子、紙坊別想安寧。
  - 她問怎樣才肯不碰許家；他說三日內自己到碼頭上他回京的船。她把金子收回袋子：「好。我上了船，你就不准再找許家。」「一言為定。」
  - 我懂了：**她要拿自己換許家平安，三天後要走。**這個交易講得很清楚。
- **1:01–2:14，晚飯**
  - 她帶滷肉回家，對每個人都很甜，小女孩問「今天是過年嗎」，她叫書生「相公」、一直夾菜；書生摸不著頭腦。桌下她的手緊握著一把金算盤——**我知道她在硬撐**，這一鏡很好。
  - 她回房後，白衣女子說「她今晚會走，下午我在渡口看見她問船家時辰」，馬尾女子說「昨晚那個搖扇子的，說的就是三日」；書生心裡說等小禾睡了去敲她的門。
- **2:14–3:16，房間**
  - 書生提燈敲門，房裡空了，桌上一張摺紙。她的聲音念出休書：「唐小棠自請離去……相公，你別來找我。」馬尾女子：「她寫休書？她是妻子，休的是誰啊？」書生紅著眼笑：「妻子寫休書，律上不算。」撕了。
  - 紅框面板「警告，唐小棠正在遠離」，接著一個電子音說了一句（**沒有字幕**，我聽到「休書撕了，人也不會自己走回來」），書生「不用妳說，我這就去把她追回來」。白衣女子說子時開船、已經亥時末；馬尾女子推他：「追啊！燈籠就在屋簷下！」
- **3:16–3:29，渡口與結尾**
  - 他提燈籠沿棧橋跑、喊「小棠——！」；船上她抱膝背對：「別回頭，唐小棠。回頭，就走不了了。」他舉燈籠：「休書我撕了！妳寫的不算，聽見沒有！」鑼一響、黑。

**哪裡困惑**

1. **3:15–3:25 船就在他旁邊。**他跑上棧橋時，旁邊停著一條空的竹篷船；最後一鏡他站在棧橋盡頭，她的船貼著棧橋、伸手就碰得到，船夫還站著。我第一個念頭是「那你跳上去啊」，「追不上」的感覺沒有出來（嚴重 1）。
2. **0:45–0:52 她去哪了？**公子說「三日」那一鏡是整個房間的全景，桌子右邊她站的位置空著；前後幾鏡她明明站在桌前（中等 1）。
3. **2:51–2:57 系統第二句沒有字幕。**只看字幕的人只看到「不用妳說」，不知道他在回誰（中等 2）。
4. 「三日」：上一集的「三日後州府來拿冒名犯」，這一集變成「三日內上我回京的船」。秦霜一句「說的就是三日」把兩者接上了，但州府那件事這集沒再提，我不確定這筆交易是不是也撤了州府的事（稿子的設定，不算剪接問題，見第四節接戲）。
5. 客棧裡公子的近景背後有帘子、掛畫、一盤盤點心，全景與桌面插鏡只有一壺兩杯、空屏風，像兩個房間（輕微 3）。
6. 1:05 那唯一一張她的正臉，頭上是一個髻、插花、長緞帶，跟一整集看到的雙丸子短緞帶背影不一樣；認得出是她，因為粉衣（輕微 4）。

**哪裡無聊**

- **1:40–2:04（s21–s24）**：阿令、許硯、阿令、秦霜四個近景，每句中間都有約 1 秒的停頓（107.0–108.1、114.3–115.3、119.5–120.6），資訊對，但節奏一路往下沉。停頓都在片段原聲裡，剪不掉，只能接受。
- **3:11–3:15 院子**：他提著燈籠從屋前走到院門，步子是走不是跑，最後一秒站在門口（見第五節）。
- 其他都撐得住：客棧的交易、晚飯她的甜、算盤插鏡、休書念白、撕紙、「追啊」都有勁。

**結尾想不想看下一集**：**想，但被船的距離削弱了。**

- 她自己寫休書離開、他提燈追到渡口、她心裡說「回頭就走不了」、他喊「妳寫的不算」，情緒到位；鑼在黑畫面響完，收得乾淨。
- 只是船就在他腳邊，看起來不是「來不及」，而是「他為什麼不上船」。下一集稿子是他涉水追船，船若緊貼棧橋，涉水也說不通（嚴重 1）。
