# 《種田娶妻打天下》｜五季 300 集穿越種田短劇企劃包

失業的農學碩士許硯一覺醒來成了欠債的窮秀才，官府一紙配婚令塞給他三個老婆，腦中的「良緣系統」說：讓她們愛上你，就給你改變世界的獎勵。三個老婆，一個是逃出宮的長公主，一個是罪臣將門之女，一個是逃婚的江南首富千金。他用肥皂、白紙、水車和高產糧種把破屋撐成一座堡，把山賊收成兵，一季多娶一位妻子，最後打下天下。

- 類型：真人電影感架空古裝・穿越＋系統＋多妻＋種田發家＋爭霸，輕喜劇調性
- 規模：**5 季 × 60 集 = 300 集**（60 集是每季保底，見〈擴充點〉）；每季 6 個篇章 × 10 集
- 單集：**50–180 秒**；篇章最後一集至少 120 秒
- 製作：海螺（MiniMax Hailuo）圖生影片＋後製系統面板，見 [plan.json](plan.json)
- 結局：第五季收掉主線，第 300 集最後一格留第二部的口子

## 參考劇與原創聲明

站主指定參考《萬里江山入我懷》。本劇**只學它的套路**：現代人穿越成窮秀才、官府強制配婚、系統綁定靠妻子好感換獎勵、幾位隱藏身分的妻子（公主／將門女／商賈千金）、用現代知識發家、收服山賊、亂世稱王。朝代（大衡）、人名、勢力、劇情與台詞全部原創，不搬原劇的任何情節或台詞；架空朝代不對應任何真實國家或歷史事件。

## 讓人停不下來的規則

每一集都要過 `validate.mjs`：

- **一集三個鉤子**（站主：一集一定要兩三個以上）：前 3 秒（`hook`）、片長一半（`mid_hook`）、結尾（`cliffhanger`），三個必須是不同的事。
- **收在最高點**：每集切在刀落下前、門打開的瞬間、答案說出口前一個字、系統彈出一個要命的任務；`cliffhanger.question` 寫出觀眾帶走的問題，下一集前 10 秒接住它。相鄰兩集的結尾類型（危機／揭露／抉擇／反轉／情感）不重複；每季最後一集收在反轉。
- **爽點**：每集至少兩個，第一個在前半（打臉、身分揭露、反殺、當眾平反、反派低頭、藏拙露鋒、及時救場……）。
- **主角不連輸**：許硯不會連兩集只受挫；任何連續四集至少收一個伏筆。
- **系統有代價**：好感度只能靠真心換；獎勵只給方法，人和材料要自己找；每位妻子都有自己贏的戲。
- **謎團照表揭**：12 條長線謎團各在指定的那一季揭曉一次；每季的短線懸念季內收完。
- **不黃標**：一夫多妻只寫成一家人，洞房一律喜劇或切走；上架標題擋掉「血、屍、裸、性感、火辣、慘死、自殺、血洗、屠、斬首、凌遲、酷刑」等字；畫面規則見設定集。

| --- | --- |

| 2 | 篇章 4 之後：柳溪堡群像，每集一個流民的故事 |
| 3 | 篇章 3 之後：草原生活篇，阿蘭朵帶他認識朔漠 |
| 4 | 篇章 3 之後：青州醫館單元，每集一個病人 |
| 5 | 篇章 2 之後：江南諸城，一城一計 |

擴充時：在 `outline.json` 插入篇章、後面的集數順延，照 [authoring.md](authoring.md) 寫，重跑檢查。

## 等站主決定

1. **畫面比例**：建議照《長燈村》用 16:9 橫式。
2. **預算**：一集約 2,600–3,300 點，一季約 16–20 萬點；建議先拍第一季第一篇章 10 集（約 3 萬點）看留存。
3. **聲音**：許硯、三位妻子、系統（電子女聲）、錢員外、魏少卿先做試聽頁讓站主挑。
4. **第 300 集**：要留第二部的口子（現在的寫法），還是收死。
