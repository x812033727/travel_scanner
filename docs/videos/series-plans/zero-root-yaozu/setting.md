# 長燈村：零靈根的我被一村妖祖養大｜設定集

測出零靈根被仙門退貨的文盲少年回到村裡，才發現從奶奶到村口傻大個，全村三百口人都是上古大妖，而他們等了三百年，等的就是他。

## 前提

三千年前，九個自稱神明的「九曜」吞掉了舊神，挖走真神燭陰的左眼掛在天上當「天眼」，再把「靈根」賜給人間的嬰兒，等修士飛升時連人帶靈氣一起收割。燭陰沉睡前用最後的力量畫出萬妖圖，把天下妖靈藏進圖裡，並讓一位凡人「守圖人」世世輪迴看守。第九十九世守圖人顧長夜三百年前戰死，圖光黯淡，五隻他親手養大的小獸在仙洲邊緣建起長燈村，化成凡人等他轉世。第一百世的守圖人，就是被他們從河上撿回來的陸拾。

## 世界

- **仙洲**：人族與仙門所在的大陸；京城、玄穹宗、捉妖司都在這裡。
- **長燈村**：仙洲西北邊緣、山海古墟腳下的小村；家家戶戶日夜掛燈，燈光連成「圖影」，天眼看不穿。
- **山海古墟**：舊神時代的廢墟，第三季整個打開；內有舊神遺物、真文石碑與沉睡的巨獸。
- **大荒**：仙洲以北的妖域，妖皇窮奇的領地；黃沙、骨林、會走路的山。
- **海外諸國**：東海外三十六國（羽民國、一目國、長臂國、無腸國、女子國、鬼國等），各自是一個規則不同的異世界。
- **鍾山**：極北之地，燭陰沉睡的山；永夜。
- **天闕**：九曜的上界宮殿「天機城」：從外面看是白金色仙宮，走進去是一座用光齒輪、靈氣管與萬枚水晶靈根槽運轉的巨型收割機關（第五、十季的科幻奇觀）；天眼懸在它的正下方。
- **歸墟**：東海盡頭的無底深淵，萬水歸處；第九、十季仙洲往這裡沉。

## 勢力

- **玄穹宗**：仙洲第一大宗，管問天石測靈根；宗主雲擎是九曜在人間的守門人。
- **捉妖司**：朝廷的獵妖衙門，司主白無咎；暗中把妖丹賣給玄穹宗做「養根丹」。第九隊是被丟掉不管的雜牌隊。
- **九曜**：九個偽神：日、月、火、水、木、金、土、風、雷九曜，由不算在九曜之內的曜主明熾統領；靠天眼看人間、靠靈根收割人間。月曜第五季被斬後剩八曜；第十曜是第六季成神的嚴少淵。
- **大荒妖族**：妖皇窮奇厲鋒統領；恨守圖人，因為三百年前顧長夜把他的族人強收進圖裡。
- **零靈根者**：第五季陸拾聚起的凡人與零靈根散修；不受神印控制。
