# 第 3 季《座次》逐集細綱

主題：她不坐別人排好的位子，連愛也是。

開季：望山廳，兩兄弟擠在同一束追光裡等她選；全廳的手機對著燈控室的玻璃。她有三十六盞燈、一間平均三百席的戲院、一個被叫做『替身』的光替，和一個六年沒叫過她名字、現在當眾說『我也追』的前任。

季末：三個謎團揭開：她為什麼從不上台謝幕（十六歲在學校的成果發表上忘詞，全場笑了三分鐘，燈一直照著她沒人切；交接晚宴那陣笑是第二次）；祁晟書房上鎖的抽屜裡是什麼（六張一年一張、從沒念過的介紹詞，第七張寫到交接晚宴那天停筆）；祖父鎖在閣樓的鐵皮燈箱裡是什麼（一盞他自己焊的追光燈和六十年前《月出之前》的首演節目單——『燈光：祁望山』印在所有演員前面，祁家是做燈起家的）。她把望山廳的光全關了說『我不是獎品』，在燈單第一頁立了四條規矩，第四條是她約人；祁晟買票坐第一排、到老范店裡擦了一週燈片；海報上第一次印了她的名字；祁朔在空戲院替她打光，『妳說切，我就切』，她從站兩秒到站滿三十秒；殷蔓在派對上敬『不敢上台的人』，祁朔把派對的燈關了三秒；初一戲院第一次坐滿六百一十二席，她用祖父的燈打在祁朔身上；家宴上她把首演節目單放在長桌中間；燈從三十六盞變七十二盞。最後一集，初一家宴，祁夫人把她的名牌擺在祁晟旁邊的長媳位，末座另有一張祁朔的鉛筆字，祁晟站起來把第七張介紹詞念完；全桌等她坐下，鏡頭停在她拉開椅子的那隻手。

## 篇章 1〈我不是獎品〉

### 第 121 集（本季第 1 集）〈主推桿拉到底〉｜128 秒

**上架標題**：前任和他弟弟擠進同一束光當眾追她，她一把拉下主推桿，八百人的宴會廳瞬間全黑

- 一句話：卓映要在兩兄弟當眾說『追』、全廳八百人等她把光給其中一個的這一刻，不被當成獎品地收掉這一晚。
- 前 3 秒（畫面）：二樓燈控室的玻璃後面，她的手停在主推桿上；樓下兩兄弟擠在同一束追光裡抬頭。小葵小聲問：「光給誰？」
- 中段鉤子：全黑的廳裡，廣播喀一聲，她的聲音很平：「兩位祁先生，」「我不是獎品。」「燈光設計卓映，」「今晚收工。」
- 加鉤 1：緊急照明亮起一片綠，祁晟三步併兩步衝上二樓；燈控室裡只剩她的耳機掛在台邊還在晃，消防門半開，夜風灌進來。
- 衝突：祁商合作酒會上，祁朔和祁晟先後走進那束給訂婚的光說要追她，祁夫人在台下等她收光、殷蔓的手機舉得最高；她要在不被當成獎品的前提下收掉這一晚。
- 轉折：所有人以為她會把光打在其中一個人身上，她把整座廳的光都收走——誰都不給，自己從消防梯離場。
- 爽點：前半・當眾平反、後半・反轉
- 結尾（抉擇）：消防梯轉角，夜風很冷；她的手機同時亮起兩通來電，一個寫著「祁晟」，一個寫著「祁朔」。她的拇指停在螢幕上方。
- 觀眾帶走的問題：兩通電話同時打來，她接哪一通？
- 奇觀：八百人的望山廳一秒全黑，只剩出口標示與緊急照明的綠光，兩兄弟一前一後的剪影立在中央走道上。
- 顏值：卓映在燈控台冷藍的光裡摘下耳機，推桿的指示燈照亮她側臉最後一秒，然後她隱進黑裡。

### 第 122 集（本季第 2 集）〈全城一張黑照〉｜112 秒

**上架標題**：她關掉整座宴會廳就走，隔天全城群組只剩一張全黑照片，前任的特助卻開來一卡車新燈

- 觀眾帶走的問題：祁夫人要她賠全暗三分鐘，她怎麼回？
- 奇觀：一整排手機螢幕亮在改衣店的縫紉機上，每一支都是同一張全黑的照片，只有角落一點綠色的出口標示。

### 第 123 集（本季第 3 集）〈三分鐘，我扣〉｜106 秒

**上架標題**：前任的媽要她賠宴會全黑三分鐘，她把發票改成扣三分鐘，再寫下第三條：要追，去買票

- 一句話：卓映要用一張發票和三條規矩把『誰說了算』拿回來，可祁家最擅長的就是替人算帳。
- 前 3 秒（反轉）：她拿起計算機按了幾下，在發票上補一行：「全暗三分鐘，」「我扣。」設計費照市價，只少三分鐘的錢。
- 中段鉤子：她當著梁衍寫下第二條：「二、不准送燈。」梁衍念了一遍，回頭對司機說：「掉頭。」二十四盞新燈原車開走。
- 加鉤 1：初一戲院的售票口，小葵把燈單第一頁的影本貼上玻璃，第三條的墨還沒乾：「三、要追，」「去買票。」

- 轉折：觀眾以為她會跟祁夫人硬碰，她只是把帳算到分鐘：酒會的燈她打了，錢照算，全暗那三分鐘她自己扣——祁家反而得付她整晚的設計費。
- 爽點：開場・打臉、後半・當眾平反
- 結尾（揭露）：傍晚，初一戲院的售票口，一枚銀色袖扣擱上檯面。祁晟抬頭看了一眼玻璃上的第三條：「第一排。」「正中間。」小葵的筆掉在地上。
- 觀眾帶走的問題：祁晟真的照她的規矩來買票了？
- 奇觀：售票口玻璃上貼著手寫的三條規矩，夕陽從背後照進來，三行字的影子落在祁晟的深灰西裝上。
- 顏值：祁晟在售票口的夕照裡低頭扣上西裝扣子，抬眼的瞬間，銀色袖扣反了一下光。
