# 《保鏢只想吃飽》｜五季 300 集都市異能喜劇動作企劃包

夜市炒麵攤老闆林大楠愛錢、摳門、一碗麵算到蔥花；一場雷雨之後他會『走一步』——眨眼跨到十步外，過程沒人看得見，代價是一步餓一碗。單親女老闆沈硯用三倍薪水把他從攤子後面挖來當保鏢；前夫家族的刺殺一次次撞上一個邊吃邊打的影子，而另一個會走的人，不餓。

- 類型：真人電影感現代都市異能喜劇動作・小人物逆襲＋有代價的異能＋保鏢護主＋身世反轉
- 規模：**5 季 × 60 集 = 300 集**；每季 6 個篇章 × 10 集
- 單集：**90–180 秒**；篇章最後一集至少 120 秒；每集 **3–5 個鉤子**
- 製作：海螺（MiniMax Hailuo）圖生影片，見 [plan.json](plan.json)
- 結局：第五季收掉主線，第 300 集最後一格留第二部的口子

## 參考劇與原創聲明

2026 年 1–10 月紅果熱度合併榜第 7 名《隱身侍衛》（套路拆解在 [reference.md](reference.md)）。本劇**只學它的套路**：有缺點的小人物得到有代價的異能、成為女老闆的保鏢、能力用完會餓的反差喜劇、刺殺一次次被破、幫雇主贏回家業、身世反轉。能力的形式（『一步』、一步一碗、有人握手就不餓）、人物、公司背景、家族恩怨（影衛林家）、劇情與台詞全部原創，不搬原劇任何情節。

## 讓人停不下來的規則

每一集都要過 `../lib/validate.mjs`，規則與《種田娶妻打天下》相同，另加：

- 每集 **3–5 個鉤子**：hook、mid_hook、cliffhanger 必有，可加 `extra_hooks` 0–2 句，全部必須是不同的事。開場允許是接地氣的一格再翻轉。
- **『走一步』用剪接不用特效**：前一格在、後一格不在、再一格在十步外；每集至少一次。
- **每集一個吃的笑點**：救完人先要吃的、擋完刀先報帳。
- **步數與饅頭是進度條**：一季多十步、口袋從三個饅頭到保溫袋到空的（有人握著手）。
- **小石頭的畫**：一季一種變化（黑影 → 有臉 → 兩個 → 手牽著 → 攤前三人）。
- **每季末身世露一分**：還有一個會走的 → 底下有東西 → 林九 → 血脈 → 父親。
