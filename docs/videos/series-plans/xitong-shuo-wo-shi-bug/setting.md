# 系統說我是 BUG｜設定集

加班猝死的程式設計師醒在異世界的垃圾坑裡，系統面板只給他一個技能：【撿垃圾】。直到他發現，別人丟掉的廢技，他都撿得起來、疊得上去、改得了名。

## 前提

九域是一個人人十六歲覺醒系統面板的世界：一人一職業、一到三個技能槽，技能由面板發，廢掉的技能可以「捨棄」換回一點靈石。江河在凌晨三點改完最後一個 bug 後猝死，醒來躺在新手鎮「落石鎮」的垃圾坑裡，面板上寫著：職業「無」、技能「撿垃圾 Lv.1」、技能槽「∞」。當天他被白鹿公會的測試官當眾判為廢人。可是當晚他在垃圾坑裡撿起一顆別人捨棄的技能殘片，面板跳出一行他看了十年的字：「是否安裝？」從此，所有被九域丟掉的廢技——走路不累、聽力+1、辨味、算帳、縫補、點火——都進了他的技能槽，而他是這個世界唯一會「把兩個廢技合併、再改名」的人。第一季：他從落石鎮的廢人，一路撿到白鹿公會會長親手捨棄的那個技能，才發現這個系統，是有人寫的。

## 世界

- **落石鎮**：第一季的新手鎮：一條主街、一間酒館、一座白鹿公會分部、鎮外的垃圾坑與廢礦；鎮民看不起沒職業的人。
- **灰岩廢礦**：鎮外的廢棄礦坑，面板標示為「一級副本・灰岩」，十年沒人通關；裡面有被丟棄的技能殘片和一隻守坑的石魔。
- **白鹿城**：第一季後半的大城：白鹿公會總部、技能拍賣行、覺醒塔；全城的技能殘片都往這裡的「捨棄池」丟。
- **捨棄池**：白鹿城地下，所有人捨棄的技能最後流進去的地方；對別人是垃圾場，對江河是寶庫。

## 勢力

- **白鹿公會**：九域最大的公會，壟斷技能測試與捨棄池；會長白珩的技能是「鑑定」，他能看見別人的面板。
- **落石酒館**：鎮上唯一不問職業的地方，老闆娘收留沒職業的人；第一季的據點。
- **拾荒者**：靠撿殘片賣給公會過活的人，被鎮民叫垃圾佬；江河第一批朋友。

## 調性

- **打臉爽**：叫他廢人的人當場被廢技打臉：測試官、公會新人、城裡的拍賣官；每集至少一個，篇章結尾那集打最大的那張臉。
- **面板爽**：面板跳字的那一刻：「是否安裝？」「合併成功」「技能改名」；旁白念面板像讀 log，一個「叮」就是爽點的標記。
- **喜劇**：程式設計師的職業病：把面板當 bug 看、把合併當重構、把公會當產品經理；小鐵的「哇」與老闆娘的罵。
- **懸疑**：系統為什麼會說人話、白珩為什麼看得見面板、捨棄池底下有什麼；每篇章一條短線。
- **感人**：被捨棄的人把自己當垃圾：千凜、老闆娘、小鐵；江河撿起的不只是技能。
- **戰鬥**：廢技的戰鬥：用「聽力+1」聽石魔的腳步、用「點火」照亮礦坑；每場戰鬥都靠合併出來的技能贏，不靠數字。

## 不黃標（廣告友善）

YouTube 廣告友善（不被黃標）：暴力、成人內容、令人震驚的內容、粗話、危險行為都避開或降級。

- 戰鬥不拍血、傷口、斷肢；魔物倒下只拍碎石與塵土，人倒下只拍剪影。
- 江河的「猝死」只拍辦公室的螢幕光、倒下的鍵盤與黑掉的畫面，不拍身體。
- 千凜被「勸捨」的過去只拍她空的刀鞘與面板上灰掉的那一格。
- 不拍自殘、自殺；「捨棄技能」是面板上的一個按鈕，不是儀式。
- 台詞不用髒話；「廢人」「垃圾佬」這類羞辱可以，但不罵族群、不羞辱女性。
- 標題與縮圖：不放血、屍體、驚恐的臉；用面板大字、主角眼神、技能名。
- 不借用任何真實遊戲的名稱、道具、地圖或介面樣式；每支上架勾選『經過變造或合成的內容』揭露。

千凜要美得冷、老闆娘要美得暖；美在臉、眼神與動作，不在暴露。

要：

- 每集至少一個顏值鏡頭：逆光的側臉、面板藍光照在眼睛上、馬尾被風吹起。
- 江河要撐得起縮圖：疲倦但眼神亮，面板的藍光是他的打光。

不要：

- 鏡頭不停在胸部、臀部、腿部；不寫露背、低胸、透視。
- 不拍沐浴、濕身、更衣；兩人同框只在結尾一鏡，距離一步以上。
- 縮圖與標題不用身材當賣點。

## 畫面

貼圖漫劇（manga 等級，MiniMax image-01，anime-2d）：乾淨的動漫線稿、賽璐璐陰影、畫意的背景、戲劇性的輪廓光；落石鎮是土黃與暗綠，灰岩礦是灰與藍光，白鹿城是白與銀。系統面板一律畫成角色旁邊的半透明淡藍光板，不寫可讀的字，面板的內容全由旁白念。

- 一張圖一個人：主要角色各自單獨入鏡，第二人縮小、背對或出畫；雙人同框只留每集結尾一鏡。
- 每張圖是一個清楚的畫面：景別、地點與時間、正在發生的事、視線落點。
- 面板上不寫字：圖裡只有發光的空白面板，旁白讀內容；技能名由旁白用「叮」帶出。
- 每 3–5 秒換一張圖、每 20–30 秒一個鉤子；運鏡只用推近、拉遠、搖、漂移，相鄰鏡頭輪替。
- 角色設定圖是臉的參考（subject_reference 一次只收一張臉），每個角色的外貌文字固定不改。

奇觀：江河第一次看見面板：垃圾坑裡抬頭，淡藍色光板浮在他眼前；殘片撿起來的那一刻：掌心一粒碎光，面板問「是否安裝？」；合併成功：兩粒光在他掌心絞成一粒，技能槽多出一格發光的名字；石魔的晶眼在黑暗中亮起，江河手裡只有一簇小火；白鹿城的捨棄池：地下湖面上漂滿別人丟掉的技能碎光；白珩的眼鏡反光裡第一次看不見面板的字

母題：「叮」：每次面板跳字；第一季最後一聲「叮」是它說人話；撿：他撿技能、撿人、撿一個鎮；空的刀鞘：千凜的，第 29 集才有東西放進去；垃圾坑：第一集醒來的地方，第三十集回去的地方
