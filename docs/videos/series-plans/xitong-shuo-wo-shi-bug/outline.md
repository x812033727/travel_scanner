# 系統說我是 BUG｜總綱

一個被系統當成垃圾回收程序載入的程式設計師，在一個人人只有一到三個技能槽的世界，把所有被丟掉的廢技撿回來、合併、改名；第一季他從落石鎮的廢人撿到白鹿公會會長親手捨棄的那顆「管理員」，才知道系統是有人寫的。第二季他學會卸載與改寫，第三季他找到寫系統的人。

**結局**：第一季最後一集：江河把「管理員」殘片放進技能槽，面板用人的語氣說「歡迎回來」，白珩第一次看不見他的面板；最後一格，面板下方多出一行灰字：「上一任回收程序：已刪除」。

## 第 1 季《撿垃圾的人》（第 1–30 集）

主題：被丟掉的東西，撿起來的人說了算。

開季：凌晨三點的辦公室，江河改完最後一個 bug 倒在鍵盤上；醒來躺在落石鎮外的垃圾坑，面板：職業「無」、技能「撿垃圾 Lv.1」、技能槽「∞」。白鹿公會分部的測試日就是今天。

季末：江河的技能槽裡有三十個改過名的技能，落石鎮的拾荒者都跟著他撿；千凜拿回「斬鋼」；石魔被撿走了【辨聲】後第一次有人通關灰岩；白珩在白鹿城的覺醒塔頂當眾看不見江河的面板；江河撿起白珩捨棄的「管理員」，面板說了第一句人話。

### 篇章 1〈垃圾坑〉第 1–5 集｜面板爽、打臉爽、喜劇

第1集冷開場：凌晨三點，螢幕上的 bug 修好了，江河倒在鍵盤上；黑畫面裡一聲「叮」：「檢測到宿主結束。是否讀檔？」醒來在垃圾坑，面板只有「撿垃圾 Lv.1」。白鹿分部測試日，測試官唐測當眾宣布他是「無職業的廢人」，鎮民笑他。當晚他回垃圾坑，撿起一粒碎光，面板問「是否安裝？」——走路不累 Lv.1。他把「走路不累」和撿來的「聽力+1」放進同一格，面板跳出從沒人見過的字：「合併？」合併成「潛行」。他潛進公會分部，聽見唐測把拾荒者交來的殘片報成「無價值」自己私吞。小鐵拜他當師父；酒館老闆娘阿桂收留他。篇章最後：他當著全鎮用「潛行」把唐測藏在倉庫的三十顆殘片倒在測試台上。

- 短線：唐測私吞的殘片要賣給誰；垃圾坑裡那顆撿不起來的黑色殘片是什麼；酒館老闆娘為什麼不問他的職業
- 篇章結尾：唐測被拾荒者圍住時，從懷裡摸出一顆殘片捏碎——面板跳出紅字：「檢測到技能被銷毀：斬鋼（持有人：千凜）」。酒館角落，一個空刀鞘的女人抬起頭。
- 奇觀：垃圾坑裡第一次亮起的淡藍面板；兩粒碎光在掌心絞成一粒；三十顆殘片嘩啦倒在測試台上。

### 篇章 2〈空刀鞘〉第 6–10 集｜感人、戰鬥、面板爽

千凜是三年前被白鹿公會「勸捨」掉主技能的劍士，現在只剩一個廢技「握力+1」。她不信江河，直到看見他把拾荒者的廢技合併出「辨聲」。灰岩廢礦的石魔十年沒人打得過，公會懸賞通關。江河帶千凜與小鐵進礦：用「點火」照路、「辨聲」聽石魔的腳步、「握力+1」讓千凜握住一根斷鋤頭。石魔腳邊躺著一顆被丟了十年的殘片。他們沒打倒石魔，但撿走了那顆殘片，石魔的晶眼第一次暗下去。篇章最後：江河把殘片放進千凜的空格——不是斬鋼，是「辨聲 Lv.3」，千凜十年來第一次聽見刀鞘裡的風。

- 短線：石魔為什麼守著一顆廢技；千凜的斬鋼殘片到底碎了沒有；公會懸賞通關灰岩的真正目的
- 篇章結尾：唐測帶著白鹿城來的人出現在礦口：「會長要見那個撿垃圾的。」他身後的人攤開面板——江河看見自己的名字出現在別人的面板上。
- 奇觀：石魔胸口的晶眼在黑暗中亮起；千凜用一根鋤頭擋住石魔的一掌；礦坑深處漂著一粒十年沒人撿的光。

### 篇章 3〈鑑定〉第 11–15 集｜懸疑、打臉爽、喜劇

白珩會長親自到落石鎮。他的技能「鑑定」能看見別人的面板，他當眾讀出江河的技能槽：「∞」——全鎮第一次知道這個廢人有什麼。白珩不殺他，邀他加入公會，開價一百顆殘片。江河用「算帳」廢技當場算出公會十年來從落石鎮抽走的殘片數，白珩笑著承認。江河拒絕。公會斷了鎮上的殘片收購，拾荒者沒飯吃；江河教他們合併廢技換錢：縫補＋辨味＝「鑑布」，點火＋算帳＝「煉爐」。篇章最後：落石鎮第一次不賣殘片給公會，拾荒者在酒館門口排隊讓江河合併技能。

- 短線：白珩為什麼不直接搶他；白珩自己的三個技能槽裡有什麼；面板載入變慢是怎麼回事
- 篇章結尾：白珩離鎮前留下一句：「你撿得起別人丟的，那你知不知道，有人丟過你？」江河的面板第一次卡了一秒——載入中。
- 奇觀：白珩摘下眼鏡讀他的面板，兩人之間浮著同一塊光板；酒館門口排到街尾的拾荒者。

### 篇章 4〈捨棄池〉第 16–20 集｜戰鬥、懸疑、感人

千凜決定去白鹿城找回斬鋼。江河帶小鐵同行。白鹿城的技能拍賣行、覺醒塔、地下的捨棄池：全城捨棄的技能流進地下湖，湖面漂滿碎光。江河下去撿，面板載入越來越慢，技能槽過了二十格。他在池底撿到一顆黑色殘片，面板第一次沒有問「是否安裝」，而是跳出一行字：「別撿那一顆。」他撿了。黑殘片裡是一段別人的記憶：十年前有人也在這個池底撿東西。篇章最後：公會的人在池口等他們，千凜用「辨聲」聽出埋伏，兩人第一次並肩。

- 短線：黑色殘片裡的記憶是誰的；捨棄池為什麼有人守；小鐵的技能槽為什麼多了一格
- 篇章結尾：白珩站在覺醒塔頂俯視捨棄池：「他撿到那顆了。」身邊的人問要不要殺，他說：「不，讓他撿完。」
- 奇觀：地下湖面漂滿千萬粒碎光；江河站在湖心的黑殘片前，面板的藍光變成灰色；覺醒塔頂白珩的剪影。

### 篇章 5〈當機〉第 21–25 集｜面板爽、打臉爽、戰鬥

面板當機：第二十九個技能安裝完，江河眼前的光板黑了三秒，三秒內他什麼都看不見、什麼技能都用不了。白鹿城的技能大會上，白珩邀他上台「鑑定」，當眾讀出他的技能槽——這次白珩讀不出來，面板是黑的。江河在三秒的當機裡靠千凜的「辨聲」與小鐵的喊聲撐過台上的三次攻擊。面板回來時，他學會第一件事：合併可以減少技能數。他把十個廢技合併成一個「拾荒者」，技能槽從二十九變二十。篇章最後：他當眾把「拾荒者」安裝給小鐵，小鐵的面板多出第二格——九域第一次有人的技能槽變多。

- 短線：當機的三秒誰保護了他；白珩為什麼讀不出黑掉的面板；斬鋼在白珩的第三格裡
- 篇章結尾：白珩在台上第一次失態，摘下眼鏡：「你的面板，為什麼有管理員的字體？」
- 奇觀：黑掉的面板、三秒的全黑畫面只剩聲音；十粒光絞成一粒；小鐵的面板多出一格時全場的臉。

### 篇章 6〈管理員〉第 26–30 集｜懸疑、戰鬥、打臉爽、感人

白珩的三個技能槽：鑑定、斬鋼、還有一個他自己捨棄過、又撿回來的「管理員」。江河終於懂：白珩不是寫系統的人，他只是撿到了管理員權限。覺醒塔頂的最後對決沒有打：江河用「潛行」進塔、用「辨聲」找到白珩私藏殘片的第三格、用「拾荒者」從別人的面板裡撿——他從白珩的面板上撿走了斬鋼，還給千凜。白珩捨棄「管理員」要銷毀它，殘片掉下塔頂，江河在垃圾坑裡撿起來——他醒來的那個坑。篇章最後：安裝。面板說了第一句人話：「歡迎回來。」

- 短線：管理員殘片為什麼掉回落石鎮；系統的第一句人話是對誰說的
- 篇章結尾：面板下方多出一行灰字：「上一任回收程序：已刪除」。江河抬頭，垃圾坑邊站著白珩——他也在笑。
- 奇觀：覺醒塔頂的兩塊面板相對；斬鋼放回千凜的空刀鞘，刀鞘第一次有刀光；垃圾坑裡那顆最後的殘片。
