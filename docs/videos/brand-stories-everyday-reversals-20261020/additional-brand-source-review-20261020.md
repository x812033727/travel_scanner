# 獨立新增題材｜Adobe 一手來源初查

2026-10-20。這份紀錄只查核[獨立題材候選](additional-brand-candidates-20261020.md)中的 **Adobe Creative Cloud**。下列四份 SEC 申報均直接開啟、回 HTTP 200；本紀錄可支持選題的財務與產品主線，並非六章 Treatment、逐字稿或付費製作核准。訂閱收入與產品收入都是 **Adobe 公司整體**的財報分類，不能當成 Photoshop 或 Creative Cloud 單一產品的收入。

| 財年與一手申報 | 本文可核對的內容 | 敘事用途 |
| --- | --- | --- |
| [2012 Form 10-K](https://www.sec.gov/Archives/edgar/data/796343/000079634313000008/adbe10kfy12.htm)（截至 2012-11-30） | 「Financial Performance Summary for Fiscal 2012」稱公司營收仍主要來自**永久授權**，訂閱收入占總營收 **15%**，高於 2011 年的約 **11%** 與 2010 年的約 **10%**。產品介紹把 Creative Cloud 稱為持續會員服務，可下載並安裝最新版 Creative Suite 桌面軟體。 | 起點不是「把軟體搬上雲端就不用安裝」；使用者仍可安裝桌面程式，變的是取得更新與付費的方式。 |
| [2013 Form 10-K](https://www.sec.gov/Archives/edgar/data/796343/000079634314000004/adbe10kfy13.htm)（截至 2013-11-29） | 「Financial Performance Summary for Fiscal 2013」列訂閱收入占比 **28%**（2012 年 15%、2011 年 11%）。公司在策略段明說，要把既有創意軟體使用者從永久授權轉向訂閱，同時吸引新客戶，並把未來新功能集中在 Creative Cloud 產品。 | 這份同期文件證明「轉向訂閱」是公司明示的策略，而非後來用數字倒推的故事。 |
| [2015 Form 10-K](https://www.sec.gov/Archives/edgar/data/796343/000079634316000224/adbe10kfy15.htm)（截至 2015-11-27） | 「Revenue」表列 **2013／2014／2015 財年訂閱收入占總營收 28%／50%／67%**，產品收入占比 **61%／39%／24%**；訂閱收入金額分別為 **US$1,137.9／2,076.6／3,223.9 million**。2015 財年總營收 **US$4,795.5 million**。 | 轉型中間三年的分類變化可做時間軸；產品收入占比下降與訂閱收入占比上升須一起展示，避免只講單一年度營收。 |
| [2025 Form 10-K](https://www.sec.gov/Archives/edgar/data/796343/000079634326000003/adbe-20251128.htm)（截至 2025-11-28） | 「Revenue」表列 2025 財年訂閱收入 **US$22,904 million，占總營收 96%**；產品收入 **US$325 million，占 2%**；總營收 **US$23,769 million**。同表 2024／2023 訂閱占比為 95%／94%。 | 可交代十多年後的公司整體收入結構，與 2012 年的 15% 並列，作為結尾可核對的現況。 |

**可支持的主線：**「Adobe 從永久授權走向 Creative Cloud 訂閱時，收入帳目如何換軌？」從 2012 年公司仍以永久授權為主、桌面軟體仍需下載安裝開場；以 2013 年明示的策略作決策轉折，再用 2013–2015 年的訂閱／產品收入比例呈現過渡，最後以 2025 年公司整體 96% 訂閱收入收束。標題若提 Photoshop，正文與字卡必須清楚說明這些比例屬於**整間 Adobe**，不是 Photoshop 銷售拆分。

**不能推論：** 收入分類的變化不能單獨證明使用者喜歡訂閱、創作者全部轉換、客戶數或客戶留存增加，也不能把 2013 年公司總營收的變動全歸因於 Creative Cloud。年報沒有提供「盒裝 Photoshop」專屬的收入拆分；「產品收入」亦不等於全部永久授權，須按各財年收入認列註解再核對。2012 與 2015 年各表的欄位以當時申報口徑解讀，不把 2025 年 96% 說成 Creative Cloud 一項產品的比例。

Sony Walkman、Domino’s、Nintendo Wii、FedEx、Nespresso 仍只在候選表中提供一手資料**入口**，本輪未讀它們的原始文件，沒有資料可升格。Adobe 後續仍須補產品公告與創作者當時的可歸屬反應，完成六章因果、逐句來源、去重及另一位查核者覆核，才可決定是否排集。
