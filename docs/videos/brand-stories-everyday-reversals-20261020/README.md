本系列沿用品牌故事與奇聞檔案局的固定規格：`kind: story`、`format: drama`、MiniMax `image-01`、精確 `look: {"preset":"cute-mystery"}`；正文目標約 10 分鐘且至少 8 分鐘，第一秒進具體場景，30–60 秒開場後接 5 秒片頭；每 30–45 秒有可回收的鉤子，至少 8 組伏筆，每章留下下一個具體問題。插圖占正文至少七成，兩張插圖之間至多三張資料卡。只有台灣口音說書旁白、可關閉的繁中 CC 與既定輕快神祕配樂；英／日／韓由站主看過成片後逐片選。21 秒 v4 片尾由站主品牌素材提供。圖片提示詞只寫匿名人物、動作、無商標物件、時間地點與光線，不寫品牌名、可讀字或真人臉；插畫只是情境圖，數字放後製字卡。
