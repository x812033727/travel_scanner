# 品牌故事：日用品的意外轉身

2026-10-20 企劃候選。站主要求另開全新題材系列並製作影片；首集選 Crocs，後兩集暫排 Tupperware、Moleskine。三題出自[未查核的備選題庫](../story-plans/brand-stories-100/reserve.json)，不在已核准的 100 題、樂高等五集或現有改編五集之內。這個選題與順序是本次編輯提案，**沒有把備選題庫當成已查核資料**。

| 集 | 暫定觀眾問題 | 查核重點 |
| --- | --- | --- |
| 1 Crocs | 洞洞鞋紅遍世界，為何公司仍可能在 2008 年大虧？ | 年報的實際損益、庫存與擴張，以及「賣得好」對應的年份；不可把單一原因說成定論。 |
| 2 Tupperware | 家家都有的保鮮盒，賣盒子的公司為何走到重整？ | 家庭派對通路、2024 年法律程序、2026 年品牌與營運主體；公司和產品不可混為一談。 |
| 3 Moleskine | 1997 年才出現的品牌，怎麼賣出「傳奇筆記本」的故事？ | 公司成立及品牌命名時間、舊式筆記本的歷史敘述；不可暗示現代品牌曾供應早年的藝術家。 |

首集的[六章敘事與來源待查表](C01-crocs.md)已列出。它是寫稿前的取證清單，**不是逐字稿、完整分鏡、獨立來源審稿、正式匯入檔或成片**。Crocs 的核心年份和財務說法在一手資料可讀前都不得進旁白。後兩集也須各自完成 Treatment、六章企劃、逐條來源查核和另一位審稿人的 hash 綁定審查。

本系列採既定品牌故事規格：`kind: story`、`format: drama`、MiniMax `image-01`、精確 `look: {"preset":"cute-mystery"}`；正文目標約 10 分鐘、至少 8 分鐘；首秒進故事、30–60 秒開場、每 30–45 秒推進一個可回收的鉤子。圖片不含商標、可讀文字、真人肖像或版權角色；沒有吉祥物。正文只有台灣口音旁白與可關閉繁中 CC，英／日／韓由站主看過成片後逐片選。品牌名不寫入圖像提示詞；旁白、後製字卡與縮圖文字可依核對後的劇本使用。站主選定的 5 秒片頭放在開場之後，正文後接 21 秒片尾及 Studio 可點元素。

目前已配對的影片工具可讀正式進度與媒體設定；新作品仍需在正式站建立 `kind: story` 的系列與集數，普通後台「新增系列」建立的是漫劇，不能代替專用 `video-story-import`。工具權杖不能取得工人工作區或站主品牌片頭／片尾。這台雲端也沒有正式主機 SSH 入口。沒有完整原始檔時，不能借另一集的核准或手寫 `auto.json` 當成本集收據。

生成前須以**整支**列出確切圖片張數、重畫上限、旁白、文字模型、圖片評審、轉錄、配樂、稅費與總額，交站主一次核定；每片總額不超過 US$25。此新 slug 目前沒有正式站的專用全項目預算帳戶，媒體工具的 US$200 全域上限不能替代它。來源未查核、台詞與分鏡未定稿，現階段沒有可供核准的完整報價，也沒有任何新付費生成。

網路與正式素材的具體缺口在[首集來源待查表](C01-crocs.md)。`cloud-environment-onboarding:setup` 的設定草稿已加入 Crocs 與 SEC 的官方網域，但草稿必須在雲端環境設定中儲存並發布才會生效。發布後應先讀原始資料、獨立查核，再寫逐字稿與分鏡；成片之後仍需實測正文時長、看片、QA 與站主核准。
