# C01 Crocs｜熱賣的鞋，為何讓公司在 2008 年轉虧？

狀態：**Crocs 一手申報已核對；逐字稿、分鏡與獨立逐句審稿仍在製作。** 本集問的是同一款鞋帶動高速擴張後，訂單降溫如何同時碰上產能、庫存、退貨與減值。片中插畫只作情境示意，不能冒充 Crocs 當年的廠房、員工或店面。

| 段落 | 故事推進 | 已核對、仍須小心表述的事實 |
| --- | --- | --- |
| 開場 0:00–0:45 | 鞋還在賣，年報卻出現持續經營警示。 | 2007 年鞋量約 4,690 萬雙、2008 年約 3,530 萬雙；2008 年淨虧 1.851 億美元。會計師表達「重大疑慮」，**不是已宣告破產**。 |
| 起點 | 從水上活動用鞋到更廣的日常市場。 | 公司於 1999 年成立；2002 年開始在美國以 Crocs 品牌賣鞋。Croslite 由 Crocs Canada／Foam Creations 開發，2004 年被 Crocs 收購。 |
| 點子 | 初期一款六色，需求快速拉高。 | 2006 年營收 3.547 億美元，2007 年 8.474 億美元；鞋量從約 2,160 萬雙到 4,690 萬雙。 |
| 生意機器 | 公司為需求擴充產品、產能及供應。 | 2007 年產品已超過 250 款，2008 年超過 270 款；不把「擴品」說成唯一虧損原因。 |
| 轉折 | 第一季仍成長，後兩季轉跌，費用與存貨跌價放大損失。 | 2008 年第一季營收同比仍增約 40%，第二季持平，第三、四季下滑。全年營收 7.216 億美元；認列存貨跌價 7,626 萬美元。公司列出景氣、核心產品成熟、廉價仿品與擴品銷售難題等多項因素。**2008 年底帳面存貨比 2007 年底低，不可說年底庫存暴增。** |
| 之後 | 縮整後直到 2010 年才轉盈；最後區分品牌與集團。 | 2009 年營收 6.458 億美元、淨虧 4,208 萬美元；2010 年營收 7.897 億、淨利 6,773 萬美元。2025 年 Crocs **品牌**營收 33.258 億美元；2026 年上半年品牌營收 17.679 億美元。2025 年集團因 HEYDUDE 減損等淨虧，2026 年上半年集團淨利 3.424 億美元，不能把兩者混作品牌鞋款獲利。 |
