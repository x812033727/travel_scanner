# X10｜兩支 9:16 濃縮影片剪輯說明

唯一權威逐字稿是 [shorts.json](shorts.json)，由 `node docs/videos/story-everyday-ebay-paypal-x10/compose-shorts.mjs` 產生；其中每句旁白逐字取自目前 [video.json](video.json)，並引用現有插畫 shot ID。任何主片修稿先重建主片及 Shorts，再按新 SHA 重新審查。本檔只說剪輯意圖，不能代替 Shorts 的權威 JSON。

每支 Short 的 `shot` 現由生成器逐句驗證：該句旁白必須出現在所選主片**同一插畫鏡頭**，不能只靠場景 ID 存在或借相鄰數字卡。9:16 成片須逐支實測 **25–55 秒**，同主片台灣華語 Sulafat 聲音與 `cute-mystery` 插畫，繁中字幕留安全區。從主片來源素材剪，不另造不同的企業標誌、網站 UI 或數字。每支結尾可用非口播的「完整長片請看頻道」卡；上架前須以 YouTube Studio 插入真正可點的長片連結，實點測試後才在交付中列 URL。目前主片與 Shorts 均未生成，沒有可點 Studio 連結。
