# X14 Airbnb｜製作、動畫與連結交接

**交付級別：離線前製。** 目前沒有音檔、MiniMax 插畫、合成 MP4、頻道選定的正式 5 秒片頭或 21 秒 v4 片尾工作檔，也沒有可驗證的 YouTube 長片／Shorts ID；`youtube.video_id` 維持 `null`。稿件與 PR 不等於已上架影片。

1. 鎖定 `video.json` 與 `shorts.json` 的精確 SHA，完成另一位代理逐句一手來源覆核和**兩名未讀前評的盲讀**；任何旁白、數字卡、縮圖文字或 Shorts 改稿都須重編並重審。片中匿名日曆是概念示意，不能講成真實房東或真實訂單。正式 Sulafat 音檔須量到正文 ≥8:00；扣除開場、結尾三句與動畫，不以靜音、留白或卡片停留補時。
2. 用已配對工具讀回**本集**費用 ledger、全站評審／配樂額度與乾跑價，核對[US$25 硬上限](production-quote.md)。TTS 後逐句複查三、四月**合計**與全年、gross 與 net、房東支援的 25% 分母、Q4 與全年、US$868.5m 全年權證及兩支 Short 的關鍵數字。圖片先小批人眼檢查，再擴到待生圖的 90 鏡；品牌名、日期、數字及分母只上後製卡。配樂設定在 `video.json`，缺少配樂不能稱正式成片。
3. 取得**頻道選定**的正式 5 秒片頭和 21 秒 v4 片尾；片頭接在第一章濃縮開場後，三句收尾之後接片尾。按[分鏡與字卡計畫](visual-plan.md)合成，輸出可關閉繁中 CC，不燒字幕。兩支 Shorts 各自 25–55 秒，十六拍使用 14 個匿名插畫來源與 2 個重新排版的原生 9:16 數字卡，不把長片的 16:9 數據卡縮入手機版；數字由原生短字卡排版，需檢查 9:16 安全區、字卡可讀性、字幕、響度和完整句尾；Shorts 不插長片的 5 秒／21 秒動畫。
4. 長片說明欄使用 `video.json.youtube.description` 的 **SEC 原始網址**；Shorts 使用各自 `shorts.json.links`。先取得真正的長片 URL，再放入兩支 Shorts 的說明及 YouTube「相關影片」功能。不得以假 `youtube.com/watch`、猜測 ID 或「待填」文字冒充可點連結。正式長片 21 秒結束畫面在 YouTube Studio 設真實可點訂閱和推薦影片元件，發布後逐一驗證。
5. 最後回填公開長片與兩支 Shorts 的真實 URL、可點片尾元件、CC、實測時長、媒體檔 SHA、來源網址及結算 ledger。未取得正式動畫工作檔與 Studio 存取前，本集保持本機前製；後續正式語言配音依站主在成片後手動選擇。
