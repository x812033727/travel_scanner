# X14｜Airbnb：預訂少四成後，平台怎麼走到首個全年獲利？

狀態：**一手來源企劃稿已按獨立覆核的 HOLD 項目修訂，待新檔案雜湊重新查核；尚無可配音逐字稿、成片或 PR。** 本集與 X01–X13 分開製作，不改原先核准的 100 題及它們的 SHA 綁定審稿。那份題庫 100 個 `stories` 中沒有 Airbnb；已在做的獨立 X01–X13 分別是 Adobe、Domino's、Netflix、Beats、Meta、WD-40、GoPro、Target、BlackBerry、eBay/PayPal、FedEx、Peloton、Spotify，沒有同一主角。

主問題：2020 年 3–4 月期間合計，Airbnb 平台上取消的夜晚與體驗席位，比同期新預訂的總量還多。訂單全年比 2019 年少 41%。到了 2022 年，平台卻公布首個按 GAAP 計算的全年淨利。這兩年間，房東、產品呈現、旅行需求和公司成本各發生了什麼？答案不能寫成「長住救了 Airbnb」或「砍人就帶來獲利」；原件只支持多個同時變化的事實，不能把其中一個算成獨立因果。

本階段交付：`source-matrix.md` 記錄 SEC 原始 HTML 的網址、取得位元組數、SHA-256、主張與限制；`treatment.md` 是一條事件線與六章節拍；`shorts-hooks.md` 是兩支各自完整的 Short 概念。四份核心來源皆小於工人 3 MB 讀取上限。2022 10-K 另作審稿者交叉核對，超出工人上限，不讓它承擔工人稿的唯一證據。

下一關由**未參與這份 Treatment 撰寫的代理**重新下載四份原件、逐項查核並對本包 SHA-256 出具覆核。之後再撰寫逐句綁來源的主片與 Shorts，交兩名不看 Treatment 的讀者盲評，量出實際旁白時長，最後才進付費製作。站主既定規格：`MiniMax image-01` 加精確 `look: {"preset":"cute-mystery"}`、故事正文至少 8 分鐘且目標約 10 分鐘、每 30–45 秒有實質新鉤子、開場濃縮後接正式 5 秒片頭、正文後接 21 秒片尾、繁中可關閉 CC、左上大字橘色 `Airbnb` 縮圖品牌名、整支付費成本不超過 US$25。正式片頭片尾資產與 YouTube URL 只在實際產出後填入。

選題邊界：2020–2022 是旅行重開、產品調整、成本管理與會計基期共同作用的時段。2020 年的 GAAP 虧損含上市相關非現金費用，不能拿 2022 與 2020 淨利差額當「疫情損失被賺回」；2021/2022 的長住比例是第四季 **gross nights booked**，不是全年客數；平台 GBV 包含房東收入等，與 Airbnb 收取的服務費收入不同。
