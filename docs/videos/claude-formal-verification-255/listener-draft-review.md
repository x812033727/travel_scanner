# 獨立草稿讀稿意見

這是繁中口白草稿的讀稿意見，不是原生 13 題收據，也不是未受提示的盲讀。第一次取檔時，我誤用包含全檔的標題／L ID 搜尋，輸出同時露出後段製作簡表、跨章鉤子及發音交接的文字；之後才只抽出「口白」閱讀。因此本件不能當作首次觀眾的乾淨盲讀證據。以下判斷引用的內容都來自口白；製作註記不能證明觀眾聽得懂。

讀取版本：`third-topic-script-draft.md`，日期標示 `2026-10-25 UTC`，檔內狀態為 `scratch口白草稿`；沒有獨立修訂號。讀取時全檔 SHA-256：`6852a412acd5108b3de2c14bd23cf2f63b3dc86f0d7b046a02cea4de3bc5133d`。全檔 236 行；口白位於實體行 7–143，共 114 個 L ID。沒有查閱其他研究、brief 或歷史檔，也沒有對外部研究主張做事實查核。

我能抓到的主線是：用 255 這個邊界，發現「程式修好」必須先說清楚驗收條件。第一例要同時接對、拒對；第二例要真的返回；最後再問 AI 的證明究竟由什麼檢查。這條線存在，但閱讀感受仍是兩個小程式教學加上一段研究解說。L005「Claude的程式證明研究公開」之後，直到 L083「這些結果，和新聞裡的正式證明，究竟差在哪裡？」才明確接回新聞；中段我會暫時忘記最初為什麼提 Claude。

最清楚的兩段是 L014–L019 的「二百五十五加一，先得到二百五十六」到「拿零和容量八比較」，以及 L068–L071 的「下一次卻轉回零」到「逾時是這次執行的觀察；循環，才是控制圖給的理由」。兩段都有具體數字、狀態改變與結果，我不需要先懂證明工具，也能跟上錯在哪裡。

開場四個問題都有文字上的回收。L001 的 255 由 L018「儲存值就成了零」回答；L002 的全部拒絕由 L044「長度零到七，也一個都進不來」回答；L003 的計數器由 L075「程式離開並返回它」回答；L004 的驗收由 L089「Rocq核心在編譯時，檢查AI寫出的證明」回答。前三個回收是可想像的結果，第四個最抽象。L092「答案是固定命題下的證明檢查」較像把概念再命名一次；真正回答「誰」的是 L089，而「怎麼知道檢查的是我要的事」還要一路聽到 L094–L099。

我會卡住的地方：

- L024「右側如果還先轉回八位元，左側再加寬也救不回來」、L025「請對照修正版整行」，預設我正看著程式碼。單讀口白時，我知道要保留 256，卻不知道左右側各指哪一部分。L020「請分開標」也像對剪輯者下指令，會短暫把我拉出講解。
- L035「把輸入拆成八個真假位元」到 L037「叫命題SAT」，工具出場很快。L036 的找錯問題聽得懂，但我還不知道「拆成真假位元」怎麼與前面 256 列測試相接，接著 L040 又說兩者逐值相符。我記住結果，未必記住求解器在這裡多回答了什麼。
- L094「一般版與加上錯誤檢查的版本」第一次出現兩個新的版本，與前面「錯版／加寬版」容易混在一起。L095「指定記憶體預算」、L114「指定錯誤」、L096「有限行為軌跡集合」又連續引進新概念。這段我只能大致抓到「保證有前提，而且沒保證終止」，沒辦法用自己的話說清楚實際比較了什麼。這是全稿最大的理解斷點。

章節銜接中，L042「但如果要求只剩零誤接受」接全部拒絕很自然；L055「如果任務換成數完就返回」與 L056「另一支獨立程式」也清楚告訴我換題，沒有讓我誤以為第一支程式開始計數。L083 把兩個範例接到正式證明，是必要的問題，但後面先進入 L085–L087 的函式庫／入口數量，我的問題會先被擱置。單靠口白，這些數量與本片的兩種驗收條件之間沒有很強的連結。

有重複感的地方主要在結果之後：L034「誤接受和誤拒絕，都是零」、L038–L040 的兩方向查詢、L112「兩種錯誤同樣都是零」，稍後又有 L051–L053 的雙零紀錄。每一次有不同用途，但連續聽像一再證明第一例已修好。L111「也能直接寫成，長度小於八」是實用發現，放在此處卻又開了一個版本，讓本來正要進入「全部拒絕」的節奏停一下。計數段 L075–L078 連續說離開、實際返回、全部返回、控制圖到出口，也略有同一結論重述的感覺。

結尾 L105「先讓預期結果能被明確判錯」是我能帶走的觀念；L106 用「合法輸入被拒絕」與「拿不到返回」再對回兩個範例，作用明確。L108「已變成能核對的修正紀錄」比較概括，沒有再增加一個容易記住的具體要求。L109「最常先寫哪一種要求？」若是希望觀眾留言，問題稍寬：我聽完知道兩種漏寫的條件，卻不太確定要回答自己的工作情境，還是從這兩種裡選一種。

我的優先建議是先讓 L094–L096 的研究命題能被一般觀眾復述，再刪減第一例的重複結算。前半段的數字故事已足以讓我跟上；後半段若仍只留下術語，我最後會記住 255 變零與計數器繞圈，卻很難把它們連成對新聞研究的理解。
