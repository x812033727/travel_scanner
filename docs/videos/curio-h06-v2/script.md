## 病院裡有人叫她公主

- [rbd5] 空白跟著她進了病院；後來，她以安娜・安德森之名聞名。

- [qwh4] 兩年前，尼古拉二世一家已在俄國遇害。

## 一九九五年，檢體進了實驗室
