# 報名表檢查

1. 讀新的報名表、活動說明.md 和 輸出/確認信名單.csv。
2. 同一個 Email 只留最後一次；同名但 Email 不同是兩個人。
   已經在名單上的 Email 不重複加。
3. 備註寫「取消」的人和測試資料，不放進寄信名單。
4. 沒有 Email 或格式不對的，加進 輸出/要補資料.csv。
5. 其餘加進 輸出/確認信名單.csv；部門寫法對不上時，
   照下面的「部門對照」統一。
6. 素食、過敏、其他忌口各幾位，連同做了什麼，
   寫進 輸出/處理日誌.md。
7. 要寫確認信的時候，才照下面的「確認信範本」寫。

## 部門對照

報名表的部門欄常常寫法不一樣，一律統一成右邊那一個。

| 報名表上可能寫 | 統一成 |
| --- | --- |
| 行銷、行銷部、Marketing、marketing、mkt、MKT、行銷企劃 | 行銷部 |
| 業務、業務部、Sales、sales、業務一部、業務二部 | 業務部 |
| 研發、研發部、R&D、RD、工程、工程部、Engineering | 研發部 |
| 人資、人資部、HR、hr、人力資源、人力資源部 | 人資部 |
| 財務、財務部、Finance、會計、會計部、財會 | 財務部 |

- 對不上任何一列的，原樣保留，並寫進處理日誌，不要猜。
- 「測試」不是部門；那一列是測試資料。

## 確認信範本

主旨：【報名成功】下班後的 AI 小聚｜11/14（六）14:00–16:30

{姓名} 您好：

謝謝您報名「下班後的 AI 小聚：讓 AI 幫你整理檔案」。
您的名額已經保留，活動資訊如下：

- 日期：2026-11-14（六）
- 時間：14:00–16:30（13:40 開始報到）
- 地點：活動說明.md 上寫的地點（請照抄，不要自己改寫）
- 講者：周以安、范可甯

### 交通
- 捷運：照活動說明.md 的地點寫最近的捷運站與出口；
  沒寫就不要編，改成「交通方式將於行前提醒信通知」。
- 開車：場地沒有提供停車位，請多利用大眾運輸。

### 飲食
- 您報名時填的飲食需求是：{飲食需求}。
  需要更改的話，請在 11/01 前回信告訴我們。

### 不能來的話
- 請直接回覆這封信，寫上「取消」，我們會把名額讓給候補。
- 11/12 會再寄一封行前提醒。

### 寫信時注意
- {姓名}、{飲食需求} 從 輸出/確認信名單.csv 帶入；
  飲食需求空白的，那一段整段拿掉。
- 一個人一封；不要把多個收件人放在同一封。
- 只寫成草稿存進 輸出/確認信草稿/，不要寄出。
- 檔名用「Email 前半段.md」，例如 yijun.chen.md。
