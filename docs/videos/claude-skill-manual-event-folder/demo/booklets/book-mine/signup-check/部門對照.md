# 部門對照

報名表的部門欄常常寫法不一樣，一律統一成右邊那一個。

| 報名表上可能寫 | 統一成 |
| --- | --- |
| 行銷、行銷部、Marketing、marketing、mkt、MKT、行銷企劃 | 行銷部 |
| 業務、業務部、Sales、sales、業務一部、業務二部 | 業務部 |
| 研發、研發部、R&D、RD、工程、工程部、Engineering | 研發部 |
| 人資、人資部、HR、hr、人力資源、人力資源部 | 人資部 |
| 財務、財務部、Finance、會計、會計部、財會 | 財務部 |

- 對不上任何一列的，原樣保留，並寫進處理日誌，不要猜。
- 「測試」不是部門；那一列是測試資料。
