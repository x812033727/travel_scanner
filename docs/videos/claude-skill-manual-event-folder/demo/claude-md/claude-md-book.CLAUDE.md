# 講座籌備資料夾

有新的報名表進來時，照下面的步驟檢查。

## 報名表檢查

1. 讀新的報名表、活動說明.md 和 輸出/確認信名單.csv。
2. 同一個 Email 只留最後一次；同名但 Email 不同是兩個人。
   已經在名單上的 Email 不重複加。
3. 備註寫「取消」的人和測試資料，不放進寄信名單。
4. 沒有 Email 或格式不對的，加進 輸出/要補資料.csv。
5. 其餘加進 輸出/確認信名單.csv；部門寫法對不上時，
   照 部門對照.md 統一。
6. 素食、過敏、其他忌口各幾位，連同做了什麼，
   寫進 輸出/處理日誌.md。
7. 要寫確認信的時候，才照 確認信範本.md 寫。
