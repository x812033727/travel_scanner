# S28 司馬光破甕：史料與敘事界線

查核日期：2026-10-19。本文核對固定 commit 的五個電子轉錄：[S]《宋史》卷三百三十六〈司馬光傳〉、[J] 蘇軾〈司馬文正公光行狀〉、[Y] 朱熹編《宋名臣言行錄·後集》卷三、[W] 邵伯温《聞見錄》卷九，以及 [H] 邵博《聞見後錄》。[H] 只用來核對 [Y] 的來源標籤，這份轉錄**沒有找到**相同的球與破甕段。四份有關段落的古書都寫於事故之後，沒有一份是庭院裡的目擊紀錄。電子轉錄有簡繁轉換，以下引文改回繁體以供旁白使用，並非宋代原稿影像。

| 事項 | 可核原文 | 敘事界線 |
| --- | --- | --- |
| 救人場面 | [S] 82603：「群兒戲於庭，一兒登瓮，足跌沒水中，眾皆棄去，光持石擊瓮破之，水迸，兒得活。」其中「兒得活」**三個字**。 | 只可說史書這樣記載；沒有孩子姓名、事故精確日期、甕尺寸材質、石塊來源或擊打位置。開場的圖像是現代示意。 |
| 七歲與畫圖 | [S] 同段先寫七歲「聞講《左氏春秋》」，救人句未另標年歲；後接「其後京、洛間畫以為圖」。 | 七歲能直接歸到讀書，不能斷言破甕恰好七歲。[S] 記有畫圖，卻不附畫、畫工姓名或圖的去向；本輪未鑑定任何當年原畫。 |
| 蘇軾的取材 | [J] 卷五十一提七歲讀書、聽《左氏春秋》後回家講給家人聽、任官與修史，**沒有**破甕段；記《資治通鑑》「凡十九年而成」，對一事多說「考合異同而歸之一」；篇末：「軾從公游二十年，知公平生為詳，故錄其大者為行狀，其餘非天下所以治亂安危者皆不載。」 | 省略只證明這篇行狀未寫。不能據此判定蘇軾沒聽過，或事故沒有發生；篇末說的是整篇選材，不是對這件事的專門否定。修書細節只用來說明行狀的取材，不展開另一條修史故事。 |
| 球與甕並列 | [Y] 1065 的文彥博條目先記球入柱穴「不能取」，文彥博灌水使球浮出，再記司馬光「幼與羣兒戱，一兒墮大水瓮中巳沒……公取石破瓮，兒得出」。 | **沒有**「手伸不進去」的文字。這是兩件並列的童年事，不表示同日、同地或兩人相識；「大水甕」未給物理尺寸與材質。 |
| 仁智評語的較早文本 | [Y] 末尾：「識者知二公之仁智不凡矣【聞見後錄】」。[W] 卷九、固定轉錄第 195 行，已有球、破甕及「識者**已**知二公之仁智不凡矣」；[W] 有「公取石破**其**瓮」，與 [Y] 小異。[W] 自序署紹興二年，即 1132 年；序言說作者從前輩、家居鄉黨與遊宦所得的言行編書。 | 仁智評語不能歸作朱熹自己新添，也不是獲救孩子當場證詞。[W] 是較早可核文本；[Y] 是否直接抄自 [W] 未經證實，因它標的是另一本書。自序日期只為該書標時間，不能替破甕事件定年；採集舊聞也不是在場目擊。 |
| 書名標籤未對上 | [Y] 標【聞見後錄】，但這次所讀 [H] 邵博《聞見後錄》固定轉錄未找到球／破甕段；相近段落在其父邵伯温 [W]《聞見錄》。[H] 卷首提要稱邵博是邵伯温之子；原序說他接續先人《聞見》而著後錄，署紹興二十七年（1157 年）；[W] 自序署紹興二年（1132 年），兩序相隔二十五年。 | 不悄悄把《聞見錄》和《聞見後錄》當同一本。父子關係與兩篇自序的先後可核，但不能據此推出 [Y] 的直接抄錄路徑。可能是標籤、版本或轉錄差異；本輪無法定案。某一轉錄未找到，不等於所有《聞見後錄》版本都無此段。 |
| 兩種救援文字的差異 | [S]「登瓮，足跌沒水中」「眾皆棄去」「水迸，兒得活」；[Y]「墮大水瓮中巳沒」「羣兒驚走不能救」「兒得出」。 | [S] 多「登」的動作，[Y] 多「大」及驚慌與無法施救。兩書未交代差異的來源，不能合成一份更完整的現場證詞。 |

## 不進旁白的斷言

- 「宋代燒不出來這樣大的缸」缺可靠考古依據。甕與缸的詞義也不能憑一段傳記判作所有時代完全不同的器物。
- 不以《宋史》段落排列推斷司馬光破甕確切年齡，也不為器物補尺寸、材質、花紋、擊打點。
- [W] 雖比 [Y] 早，仍是後來記下的傳聞／言行記述；不能升格為目擊者。 [Y] 的【聞見後錄】標籤與本輪 [H]/[W] 的對照留下未解的版本問題。
- 史書記京洛曾畫圖，不代表這次看到了、鑑定了或使用了那張圖；影片圖像為 AI 卡通插畫。
