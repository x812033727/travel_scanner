## 一句答案

目前所知的維京時代頭盔和碎片，沒有一件有角〔#12〕：最完整的 1943 年挪威 Gjermundbu 頭盔是鐵做的、有「眼鏡」護目，墓是十世紀後半的〔#1、#2、#4–#7〕；
在斯堪地那維亞和英國，幾乎完整的只有兩頂〔#9、#10、#44〕；同一個世紀的《哈康之歌》與約一二二五年的《海姆斯克林拉》寫了不少頭盔，這次翻到的都沒有角〔#15、#16〕。
真正有角的 Viksø 頭盔 1942 年才在丹麥沼澤出土，是大約西元前九百年的儀式用品，比維京時代早了一千七百年左右〔#19–#24〕；十九世紀的人看到的七世紀銅模小人，1872 年的考古學家還說是鳥脖子〔#26、#27、#46〕。
角是借來的：文藝復興以來的學者從古書把高盧人的角給了古日耳曼人〔#33、#36〕；十八世紀的維京人戴翅膀〔#34〕；1875–76 年多普勒讓《指環》裡一些戰士和隨從戴牛角，那齣歌劇沒有維京人〔#28–#31、#45〕；
1870 年代末起插畫書一本本換成角，《勇者厄林》前八個插圖版是翅膀、1890 年第九版出現角〔#34、#35、#38、#47〕；有角頭盔沒有單一源頭〔#30〕；1961 年起連球隊都畫上角〔#41〕。
**所以：維京人的頭盔本來就沒有角；角，是十九世紀的人從古書和舞台上一路借來的——存檔。**

## 大綱

### A 案（採用）：一頂鐵盔缺的那對角

**主線**：主角是 1943 年挖出來的那頂碎鐵盔，和它缺的那對角。從挪威農家兒子的鏟子開始 → 那頂鐵盔長什麼樣子 → 它的同伴有幾頂、同時代的文字也沒有角 → 真正有角的丹麥青銅頭盔，卻早了一千七百年 →
它晚了六十六年才出土，十九世紀的人看到的是銅模小人，被說成鳥 → 角從古書、十八世紀的翅膀、1869 年的鷹翅、1875 年多普勒的考據 → 1876 年的舞台 → 插畫書一本接一本 → 球場和紀念品店 → 回到那頂鐵盔，存檔。

**轉折**（照被查出來的順序，一個比一個意外）：

1. 真的維京頭盔沒有角，有的是一副「眼鏡」；它出土時被兩支矛各刺了一下，是下葬儀式。→ 第 2 章
2. 這樣的頭盔少到一塊碎片被當成馬鞍配件放了一百三十四年；同時代的詩和後來的史書也沒寫過角。→ 第 3 章
3. 真正有角的頭盔確實挖到了，卻是西元前九百年的儀式用品。→ 第 4 章
4. 而且它比拜魯特的舞台晚了六十六年才出土；十九世紀的考古學家看著銅模上的小人，說那是兩隻鳥脖子。→ 第 5 章
5. 古書說日耳曼人「難得一兩個」有頭盔，角是從高盧人借來的；十八世紀的維京人戴翅膀；多普勒以為自己在考據。→ 第 6 章
6. 拜魯特的舞台上一個維京人也沒有，女武神還戴翅膀；而他也不是第一個，1851 年就有人畫過戴山羊角的拉格納。→ 第 7 章
7. 同一本小說前八個插圖版都是翅膀；「維京時代」這個名字跟戴角的維京人是一起長出來的；老家反而最慢。→ 第 8 章
8. 連博物館的紀念品店，都訂不到沒有角的商品。→ 第 9 章

### B 案：翅膀換角

**主線**：整集跟著「頭盔上的裝飾」走：十八世紀的翅膀 → 弗里喬夫的鷹盔 → 1869 年《勇者厄林》的鷹翅 → 1876 年舞台上的牛角 → 1890 年第九版換成角 → 1899 年挪威自己的插圖還是圓錐盔〔#33–#39〕。

- 好處：每一步都是同一個題材的前後對照，畫面清楚。
- 壞處：插圖原件幾乎都沒看到（S27.md〈還沒做的〉），只能照 FRANK 的文字重畫；考古那一半（真的頭盔、真的角）會被壓縮成一句，標題問的「為什麼沒有角」答得不夠。只留成 A 案第 6–8 章的骨架。

### 不採用的 C 案：相隔一年的兩個坑

**主線**：1942 年丹麥的沼澤、1943 年挪威的墳丘：一個有角卻早了一千七百年，一個是真的維京頭盔卻沒有角〔#1–#7、#19–#22〕，兩個坑來回切，最後才揭曉角是十九世紀戴上去的。
