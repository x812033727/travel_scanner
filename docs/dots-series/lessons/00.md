# OpenAI dots 完整教學：從第一個 dot 到六個實際應用

這套課程讓不需寫程式的使用者，從建立 dot、交辦一份小工作，走到旅遊、辦公、報表、學習、內容與專案六個應用。學習目標是能說清資料與限制、找到真正成果、驗證一次更新，並知道何時需要自己做決定。

目前是製作與驗收中的課程草稿：文章、提示詞與合成練習可供審閱；真實帳號操作、產品截圖、旁白、字幕與成片須逐項完成驗證。這裡沒有可播放的影片網址，也不把腳本估時寫成已製作影片。完整作品通過驗收後，才一次推出網站系列與播放清單。

:::summary
- 十六課從設定、交辦、連接與控制，進到六個可更新的應用。
- 每課有逐步操作、可複製提示、期待結果與完成檢查。
- 合成素材與實機成果分開記錄，文章與影片一對一驗收。
:::

## 先選一條適合自己的學習路線

第一次使用的讀者，依序做第 01–04 課。先理解產品分工，再建立 dot，交辦一份虛構讀書會準備清單，最後修正偏好與活動條件。先用貼上的合成資料，便能核對結果，不必在第一天連接私人郵件或公司帳號。

已經建立 dot 的讀者，可以先回第 03 課檢查自己的交辦方式，再做第 05–10 課。這一段學習工具與聯絡方法的分別、雲端和本機的環境、委派工作、排程、跨裝置接續，以及不同控制的作用。看懂入口只是開始，還要驗證資料真能讀到、成果可打開。

想直接做應用，可在第 03 課之後挑第 11–16 課之一，遇到連接、委派與排程再回基礎課。每個案例都有第一批資料與變更資料，先完成初版，再在原工作接續更新。不要一次把兩個版本全部交給 dot，否則很難確認它是否真的接續了新資訊。

## 跟著練習前，先確認帳號與來源

dot 目前依方案、地區、年齡及工作區設定逐步推出；符合資格也可能暫時沒有入口。建立從桌面 App 或桌面瀏覽器開始，手機 App 需要支援更新，手機網頁不支援。資格細節在第 02 課與官方 Access 核對，不能因為課程有畫面就保證每個帳號立即可用。

第一份練習只需要合成文字。Google 或 Slack 案例則要專用測試帳號，登入與授權由帳號持有人完成。聯絡方法、資料外掛和本機電腦分別連接；在 Slack 能傳訊，不等於已取得信箱資料或本機檔案。本機工作需要電腦上線、ChatGPT App 開啟，雲端也有自己的登入與來源。

六個應用的下載素材包含初始輸入、變更資料與驗收檢查。報表另有獨立重算材料，用來核對合成數字。檢查答案先保留給自己，在取得 dot 結果後再比較，避免它只把預期答案排成文件。素材中的角色、品牌、訂單與預算均為教學設計，沒有真實營收、預約或客戶成效。

## 每一課都走完「交辦、核對、更新」

先讀目標與適用條件，準備指定來源。把提示中的連結、日期與路徑換成自己的示範環境，再提交初版。若出現資料、登入、權限或決策請求，先辨認是不是本課範圍；重要憑證不貼進聊天或公開畫面。

收到結果後，開實際文件，核對日期、數字、狀態與來源。沒有資料的項目仍標待確認；例如場地能容納八人，不代表改成十人仍已確認。工作執行結束也不證明成果達標，更不代表草稿已寄出或公開。

接著加入變更資料，保留第一版，要求新版與差異。驗收除了新值正確，還要看原本限制是否保留：旅遊午休、報表合併規則、學習已完成內容、專案未批准延期，都不能被更新一併抹去。最後記錄待決事項與下一步，便能在同一份責任繼續工作。

```text 在 dots 對話使用課程練習
我正在做 dots 第[課次]課，這次只處理指定的合成資料。
請先回述目標、來源、限制與完成條件，再產出我能打開核對的成果。
缺少資料或工具時明確說明；不要把期待答案當成已取得的結果。
更新後保留原版，列出差異與仍待我決定的事。
目前只做草稿，不對外發送、購買、預約或發布。
```

> 操作提醒：每課的期待結果是驗收標準，真實帳號記錄纔是操作證據。排程須有一次實際執行，停止主工作、委派與未來排程要分別確認。

## 影片與公開交付的驗收方式

每支影片採逐步畫面示範，使用真實 dots 截圖、遊標指引與重點放大，搭配繁中臺灣口音旁白。目標正文八至十五分鐘，實際長度依合成後媒體量測；章節、字幕與可讀性也在成片核對。截圖缺少或帳號功能尚不可用的步驟保留待拍，不製造假的產品介面。

文章與影片一對一綁定，最終檢查包含可點來源、可複製提示、可下載素材與可播放網址。登入、私人背景、帳號、通知與側欄內容必須完成遮罩。影片上架由站主在 YouTube Studio 完成；公開後再核對字幕、章節、播放清單與站內連結。草稿、實測、成片與公開狀態分開，這套課程的完成以真實可用的最終交付為準。
