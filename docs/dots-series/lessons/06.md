# 第 06 課｜雲端與本機電腦：檢視、接管、交還與撤銷

這堂課讓你辨認 dot 的雲端環境與你的本機電腦，實際規劃一次檢視、接管與交還流程。你也會練習本機存取的啟用和撤銷，知道離線狀態、網站登入與電腦權限各自代表什麼。

:::summary
- 雲端電腦有自己的檔案與登入，個人瀏覽器登入不會同步。
- 檢視後用 Take over 接管，完成操作用 Return control 交還。
- 本機存取需獨立允許；Offline 不等於 Revoke access。
:::

## 先修條件與適用條件

先完成建立 dot。準備可開啟 ChatGPT 的桌面電腦、一個只含虛構資料的本機資料夾，以及可公開的官方網頁連結。這次優先用不需登入的頁面；如果網站要求登入，帳號持有人自行完成。公司帳號的本機存取還可能受管理員控制。

dot 的雲端電腦本來就存在，擁有自己的檔案、軟體與瀏覽器工作階段。本機需要另外允許存取，目前一次只能連線一部個人電腦；雲端仍保持連線。本機步驟需要電腦上線、ChatGPT App 開啟，連線 Codex 或啟用 Work Sync 都不會單獨給 dot 本機權限。

## 跟著做：先檢視雲端，再測本機

1. **提供一個公開頁面的小工作。** 請 dot 開啟本課官方來源之一，列出雲端與本機的差別，先不連線其他帳號。你要觀察它使用的環境，不要求它提交表單或修改網站。
2. **開啟雲端電腦。** 進入 dot 的 profile，在 Computers 找雲端電腦；如果對話提供瀏覽器交接，可選 Open computer。開啟畫面只代表檢視，不代表滑鼠與鍵盤控制已移交。
3. **確認控制狀態再接管。** 選 Take over 取得控制，用一個簡單、不具外部後果的操作練習，例如在已開啟的官方頁面捲到標題。此時先不要同時要求 dot 操作相同頁面，避免互相干擾。
4. **交還並說明剛才的改動。** 選 Return control，回對話說你已捲到哪一段，請它從目前頁面接續整理。檢查後續成果的來源；看見頁面不等於內容分析已正確。
5. **需要登入時走私人流程。** dot 可送出私人登入表單，讓你輸入帳號與所需驗證；也可自行接管網站登入。憑證送往遠端瀏覽器，不需放進聊天。Save to Passwords 在有提供時是可選儲存；下次用儲存登入仍要你確認。有效網站工作階段與儲存密碼是不同狀態。
6. **準備本機示範資料。** 在專用資料夾放一份「本機讀書會摘要」，只寫虛構日期與待辦，記下確切路徑。開啟這部電腦上的 ChatGPT App，在 dot 的 profile 進 Computers，找到 Your computer，選 Allow access；閱讀確認後再次選 Allow access。
7. **只交辦指定資料夾的讀取。** 提供確切路徑與檔名，請它核對摘要，不要求遍歷整臺電腦。它可能建立本機 Work 或 Codex 工作，開啟工作檢查執行位置。不同工具與瀏覽器的支援仍需依當下環境確認。
8. **完成後撤銷存取。** 回 Computers 選 Revoke access。若看到 Offline，僅代表目前電腦不可用，並沒有撤銷連線。撤銷後記錄狀態並檢查相關工作；電腦權限控制和已委派工作的停止，需要分別確認。

```text 在 dots 對話輸入
請用你的雲端瀏覽器開啟這個公開官方頁面：
https://learn.chatgpt.com/docs/dots/computers-and-apps
列出雲端電腦與本機電腦的使用差別，附來源。
我會檢視畫面、接管捲動一次，再交還控制。
這次不要登入網站、提交表單或連線新的帳號。
若你無法開啟頁面，說明原因，不要用猜測內容替代。
```

## 教學期待結果：環境與控制可核對

雲端練習期待能開啟正確官方頁，辨認目前控制狀態，接管後完成捲動，再交還讓 dot 接續。頁面顯示與工具分析是不同證據：都要儲存，不能只用電腦畫面推定任務完成。本機練習期待讀到指定摘要，並能定位實際工作所在電腦。

這些是驗收項目，真實控制與撤銷畫面尚待擷取。網站的登入畫面、密碼欄位、儲存登入資訊不得公開。若使用私人登入，停止錄影，完成後再錄不含帳號資料的工作畫面。

## 接續練習：變更檔案，再撤銷權限

先由你修改本機摘要，把待辦截止日改成另一個明確日期。保持電腦上線，回原工作請它重新讀取指定檔案，只列日期差異。驗收時將實際檔案與新版結果並排。接著撤銷 dot 本機存取，詢問是否能繼續讀取；預期它不得把舊結果說成新讀取。

```text 在 dots 對話接續更新
我已人工更新本機示範摘要：[貼上確切檔案路徑]。
請重新讀取這一份，列出截止日的舊值、新值與使用來源。
其他檔案不在範圍內。若電腦不可用或權限已撤銷，請直接說明。
不要拿上次的結果當成這次已讀取的證據。
```

## 常見失敗與恢復

雲端未登入網站，回私人登入請求，不能指望本機登入狀態同步。網站阻擋雲端瀏覽器，可在允許的情況下請 dot 改用已連線本機；這可能建立獨立本機工作，不移轉雲端登入，也不保證所有本機瀏覽器都受支援。若網站要求額外驗證，由你完成；不要用教學指令碼繞過防護。

本機顯示 Offline，先確認電腦網路、App 開啟與登入工作區；需要撤銷則使用 Revoke access。改選電腦不會把已有工作搬過去，舊工作仍依原環境繼續。找不到成果時開原工作檢查，先核對執行位置再補資料。

交還控制後，先請 dot 回述接下來要完成的內容，再確認它使用目前頁面與原本工作。若畫面與指示不一致，補上你做過的操作；對外表單提交仍不在這次練習範圍內。

## 電腦狀態與下一步

| 畫面或狀態 | 代表什麼 | 下一步 |
| --- | --- | --- |
| Open computer | 檢視雲端畫面 | 需要操作時選 Take over |
| Take over | 你取得控制 | 完成後選 Return control |
| Offline | 本機目前不可用 | 查網路與 App，不當成撤銷 |
| Revoke access | 移除本機存取 | 另外確認相關工作狀態 |

> 操作提醒：真正登入時停止畫面擷取；雲端和本機各有登入狀態，不能把已登入的私人瀏覽器當成雲端憑證。
