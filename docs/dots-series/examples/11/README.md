# 第 11 課：三日旅遊示範素材

本目錄全部為編輯設計的練習資料，未進行訂房、購票或實測 dots。`input-v1.md` 是第一輪需求，`change-v2.md` 是接續更新。金額為教學配置，不能當成市價或報價。操作只產出可檢查行程。

使用順序：先把第一輪需求及官方來源清單交給同一個 dot，儲存結果；再附上變更需求，請它更新原行程並列出差異。不要把 expected-checks 當成 dots 實際輸出。

官方來源於 2026-10-03 開啟正文查核；拍攝與出發前仍須重新查閱當天公告、票價及各景點狀態。旅遊日期與資料均為合成示範。

驗證紀錄至少儲存：兩輪訊息、兩輪行程、來源頁截圖、總預算重算、星期一休館安排檢查、待確認項目。錄影畫面不得包含真實旅客資料。
