# OpenAI dots 完整教學

目標交付：17 篇繁中生活科技文章（總目錄＋16 課）、16 支各有至少八分鐘正文的繁中影片，以及 YouTube 播放清單。全套完成真實帳號驗證與媒體驗收後一次推出。

**目前是製作中的候選教材，沒有發布。** 稿件、合成資料、離線測試、真實 dots 結果、成片、私人上傳及公開上線是不同狀態。本文不把其中一種當作另一種。

## 作者來源與編譯

- `lessons/00.md`–`16.md` 是網站原稿；官方來源及確認日期放在各篇最後。
- `docs/videos/dots-lesson-01/`–`dots-lesson-16/` 保存原創口播、鏡頭表與上架草稿；repo 外工作區的 `videos/01.md`–`16.md` 是凍結來源。估計時長不能當作實測時長。
- `sources/` 保存當日官方頁的來源紀錄。只採 OpenAI 官方文件，不把搜尋摘要當作操作證據。
- `examples/11`–`16` 是合成練習資料、變更輸入與作者計算基準。作者基準不是 dots 的輸出。
- `tools/dots-series/` 將 Markdown 編譯為現有 `ArticlePack`；`kind: life`，只含 `zh-TW`。
- 課程 API 沿用 `/api/v1/guides/series/dots?locale=zh-TW`；目錄網址 `/zh-TW/life/dots-guide`，各課 slug 為 `dots-lesson-01`–`dots-lesson-16`。
- 圖片沿用 `/guides/<slug>/`；練習下載用 `/dots-course/downloads/`。不改資料庫或文章區塊格式。

## 真實畫面與影片

實測只使用這套合成資料。登入、App 授權與桌面畫面由站主操作；代理不取用私人郵件、既有專案或其他對話作公開教材。既有 dot 的工作、設定、電腦與排程不拿來做停止或刪除測試。

截圖必須來自真實 dots 介面。游標、框選及放大是後製指引；不是連續錄影。公開圖片要能檢視及追溯擷取日期，排除私人側欄、帳號名稱與無關對話。原始截圖、音訊及影片在 repo 外保存。

初期先驗證 02／03 兩課樣本，確認步驟粒度、閱讀與旁白節奏，再展開全套。影片沿用 Mokaair 現有品牌與頻道聲音，只有繁中 CC；不能用片頭、空白停頓或慢播補足八分鐘正文。

## 完成與發布

`ACCEPTANCE.md` 列出逐課、六個案例及停止測試。發布前的 readiness gate 須核對實檔、SHA-256、媒體 probe、真實執行紀錄與覆核。沒有證據即維持待驗；`publish_holds.json` 保護這 17 個 slug，避免一般內容匯入意外公開。

全套就緒後，先完成部署預檢與內容 dry-run，再逐篇發布 16 課，全部核對後發布總目錄；同批安排影片及播放清單。採多階段主機發布時遵守 `ops/release/README.md` 的 hold 生命週期。任何階段結果不明，先讀回現況及日誌，不能盲目重送。

YouTube 最後上傳與公開由站主在 Studio 完成；我方交付成片、字幕、縮圖、說明、實際章節與逐支核對紀錄。以 17 個公開文章 URL、16 個可播放影片 URL 及播放清單 URL 作最後交付。
