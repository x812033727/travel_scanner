## 與既有規格不同的地方（這份文件優先）

1. 主題一律 `ai`、`productivity`、`ai-work`（照這個順序）。不帶 `finance`。
2. **不寫任何實測結果或分數。** 介紹 AI 工具的做法時，只寫官方說明的功能、方案與限制；
   提示詞範本可以寫，但不宣稱「實測效果」。
3. 公文、個資、勞動相關的規定只引用法規資料庫與主管機關原文（全國法規資料庫、行政院
   文書處理手冊、國家發展委員會檔案管理局、勞動部、個資法），不引用坊間教學。
4. 查證日一律是實際打開官方頁的日期（2026-10-05）。
