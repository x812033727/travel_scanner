# 第八批 ERRATA：規格與撰稿當天現況不同的地方（2026-09-22 起）

規格檔（`docs/travel-guides-batch-8/*.md`）不回頭改；撰稿或查核時發現規格與官方頁現況不同、或規格本身寫錯，
記在這裡。每條寫：哪一篇、規格怎麼寫、現況怎麼寫、文章怎麼處理。第七批的 ERRATA 仍然適用。

## 通則（協調者裁決，2026-09-22）

- **描述（description）最多留一個查證年月戳記**，例如「（2026 年 9 月查證）」；規格與第七批 README 要求的
  「寫查證年月、列查證的官方頁」那句方法句一律刪掉。開頭段最多一個出處語；「本文」不出現、「這篇」最多一次且只在開頭。
  依據 `docs/korea-food-specials/README.md` 讀者優先規則（2026-09-21 定案）。
- 規格標題或 summary 裡的「四個點」「兩個」這類自選數量，撰稿時改成不帶數量的寫法；時長、距離、票價、官方總數
  （「19 站」「六個半小時」）是事實，照寫。
- 規格逐段字數加總低於它自己點名的事實量時，以「容易寫錯的事實」逐條保住為優先，總字數守 README 的區間即可。
