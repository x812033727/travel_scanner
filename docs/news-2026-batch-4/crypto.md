# 補充規格：幣圈新聞

先讀 [`BRIEF.md`](BRIEF.md)。這份只寫幣圈**才有**的規則。

工作區 `docs/crypto-news-2026/`，slug 前綴 `crypto-news-`，`topics` 是 `["finance", "crypto"]`。

## 這條界線是站主定的，不是建議

**只寫法規、技術與產業運作，不碰行情。**

幣圈是 Google 的 YMYL 類別，而台灣《證券投資信託及顧問法》限制未取得許可者
為報酬提供證券投資分析與建議。站上財經垂直的既有政策是
「只講制度與方法，不推薦商品」（`taxonomy.py` 的 `finance` hub 導言），
幣圈沿用同一條，再收緊。

### 可以寫

- 主管機關的公告、法規、函釋、裁罰與登記名單。
- 交易所、託管業者、發行商的**合規事件**：取得或被撤銷許可、資安事件、停止服務、條款變更。
- 協議與技術：升級、規格、標準、開源實作的變動。
- 稅務申報實務（申報義務、表單、期限），以主管機關公告為準。
- 詐騙型態與一般人的自保方式。

### 不可以寫

- **幣價、漲跌幅、市值、交易量、ETF 資金流、歷史報酬。**
- **買賣時機、進場出場、「值不值得投入」、「該不該持有」。**
- **任何具體標的當成可以持有的東西。** 協議與資產只能以「法規或技術的對象」出現
  （「MiCA 對穩定幣發行人的要求」「以太坊的某次升級」），不能寫成選項。
- **殖利率、質押報酬、空投、獎勵數字。** 不管怎麼包裝都會被讀成報酬。
- **交易所、錢包、託管商的費率比較或推薦。** 也不放任何聯盟／追蹤連結。

不可避免的數字（罰鍰金額、許可家數、主管機關公告的費率表）可以寫，
因為那是**法規事實**，但必須有一手來源與 `checked_on`。

## 每篇必帶免責 callout

放在第 5 節之後、兩個 link 之前。所以幣圈篇會有**兩個** callout
（本文提醒 + 免責），這是刻意的。

```json
{"type":"callout","tone":"info","title":"這篇是資訊整理，不是投資建議",
 "text":"本文說明的是法規、技術與產業運作，不推薦任何加密資產、交易所、錢包或發行方，也不是投資建議，不含價格、漲跌幅與買賣時機。監理規定、登記狀態、上線時程與服務條件依主管機關與業者當期公告為準，本文查核日為 YYYY-MM-DD。加密資產價格波動大、可能全額損失，且部分服務不受存款保險或投資人保護制度保障；實際適用請以官方公告或合格專業人員的意見為準。"}
```

**「不是投資建議」這六個字一個都不能改。**
`pack_ingest.lint_document` 的 `finance_no_disclaimer` 是 **error**，逐字比對這個標記。
「不構成投資建議」「非投資建議」都會失敗。

### 其他語言用自己的標記，不是中文那句的翻譯

`lint_all` 是逐語系檢查的，而且不知道自己看的是哪個語系，所以五個標記任一命中即可。
翻譯時必須讓該語言的免責 callout 含有**該語言的標記**：

| locale | 標記（逐字） |
| --- | --- |
| zh-TW | 不是投資建議 |
| zh-CN | 不是投资建议 |
| en | not investment advice |
| ja | 投資助言ではありません |
| ko | 투자 조언이 아닙니다 |

`en` 的比對是 casefold 的，所以句子可以是 "This is not investment advice."。
其餘四語請直接包含表中字串。

## 一手來源的允許名單

幣圈的「官方網站」比 Apple 或 Google 模糊得多，所以這裡用白名單。

**主管機關與政府**
- 台灣：金管會（`fsc.gov.tw`、`law.fsc.gov.tw`）、中央銀行、法務部調查局洗錢防制處、
  財政部與各區國稅局、立法院、全國法規資料庫（`law.moj.gov.tw`）。
- 歐盟：ESMA、EBA、EUR-Lex 上的 MiCA 與其技術標準原文。
- 美國：SEC、CFTC、FinCEN、OCC、Federal Register（**`sec.gov` 實測 403，
  改用官方 RSS 或 Federal Register API**）。
- 其他：英國 FCA、日本 FSA 與 JVCEA、韓國 FSC／FIU、新加坡 MAS、香港 SFC、FATF、BIS。

**協議與標準**（技術題目用）
- `bitcoin.org` 與 BIP 原文、`ethereum.org`／EIP 原文／Ethereum Foundation 部落格、
  各鏈自己的治理論壇與 release notes、專案自己的 GitHub release 頁、
  具名稽核公司發布的稽核報告。

**業者**（產業題目用）
- 該公司自己的 newsroom、法遵公告、事故檢討、監理申報文件、法院文書或主管機關的裁處書。

### 一律不是來源

CoinDesk、CoinTelegraph、The Block、Decrypt、CoinMarketCap、CoinGecko、
Messari、Glassnode、Dune、Nansen、任何「幣圈新聞整理」、任何 KOL 貼文、
任何專案自己宣稱效能的行銷頁、任何價格或行情 API。

這些可以用來**找線索**；事實要回到一手來源讀到，讀不到就不寫，
並記進 `unverified_or_excluded`。

## 用語

- **法規語境寫「虛擬資產」**（台灣法規用語），**一般語境寫「加密貨幣」**。
  沿用 `docs/life-finance-series-brief.md` 的既有規定。
- 第一次出現可括號附英文。

## 機器擋不住的那一半

`finance_no_disclaimer` 只證明那段話在那裡。
**「有沒有變相推薦標的」「風險講得夠不夠」「這句會不會被讀成建議」機器讀不出來**，
那是每張批次票 Definition of done 裡由人逐篇看的部分。

不要試圖用正規表示式做這件事：會在這個垂直賴以為生的教育性句子上大量誤判，
還給人一種已經擋住了的錯覺。`finance_claim_language` 之所以是 warning 而不是 error，
正是這個道理。
