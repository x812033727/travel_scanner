## 給下一個代理的四條管道筆記

1. **`sec.gov` 的 403 是間歇性的，不要當常態。** 上一輪四種 UA／標頭組合全部 403，
   這一輪新聞稿 200／68,276、委員聲明 200／69,814，一次就過。
   上一輪因此擱置的題目**值得每輪重試一次**——這次就是這樣把最大的美國題撈回來的。

2. **金管會的關鍵字搜尋會安靜地回 0 筆。** 回 200、回幾乎一樣的 bytes、沒有錯誤訊息，
   看起來就像「窗口內沒有幣圈新聞」。**一定要再跑一次不帶關鍵字的列表**（`pagesize=60`
   夠蓋回一個多月），用日期而不是關鍵字篩。本輪的台灣題只有這條路徑找得到。

3. **行政院公報要先打首頁拿 cookie（`-c`），查詢字串要重複三組 `keywords`／`fields`／`logics`**，
   否則回 500。`advancedSearchResult.do?action=doQuery&keywords=<enc>&fields=text&logics=AND&keywords=&fields=text&logics=AND&keywords=&fields=text`。

4. **聯邦公報全文檢索這次是對的，和上一輪的「會騙人的零」相反。**

   9/22 刊登後 `tokenized`／`blockchain`／`stablecoin`／`crypto`／`digital asset` 五個詞同時命中它。
