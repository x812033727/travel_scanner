- SERP 定位為固定條件下的結果，官方不包含個人化搜尋歷史；未沿用供應商百分之百準確或固定回傳速度保證。
- Standard 任務建立與 Task GET 分開；Live 為單次回應，不概括所有 API 都支援相同批量與方法。
- 200 × 2 × 2 × 4 = 3,200 為原創查詢量範例，沒有引用過時每千筆低價推估帳單；depth 和附加功能需另算。
