## 主張與來源

- 桌遊活動網站、檔名與變數是原創教學例子，未安裝 Sass、執行編譯或修改任何應用程式建置設定。
- Sass Basics 有部分描述仍稱 CSS 不具巢狀功能；以 MDN 當前 CSS nesting 文件補正，不沿用過時的完全沒有變數／巢狀說法。
- Node Sass 2024 官方公告為結束維護，不從該歷史公告推論 LibSass 今日維護狀態。
- @use 一次納入僅針對同一次編譯，不承諾不同入口或 mixin 產生規則不重複。
- @import 棄用起點 1.80.0 已查證，不將未到的移除日期當成已發生，也不混同 CSS @import。
- watcher 不等於伺服器或自動重整；source map 公開範圍及產出規則分開確認。
- 封面與圖解全部自繪，無官方圖示或第三方素材。
