- MDN 核讀私有／共用快取、Cookie 非私有保證、no-cache/no-store 與版本網址；未將 HTTP 規則一律套到刻意覆寫的管理式快取。
- Cloudflare 核讀預設 HTML/JSON 不快取、兩種 TTL、HIT/MISS 含義；不把 MISS 當來源內容必然新。
