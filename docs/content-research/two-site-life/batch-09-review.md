## 編輯與主題界線

Meta 廣告篇使用拼布材料包例子，區分帳號、版位、素材與 Shopify 追蹤重複問題；Threads 採 2026 年官方開放資訊。Dcard 以便當袋區分 CPC／CPM 目標與官方創作者管道，不採舊代理限定說法。LINE 以修鞋服務區分 LAP、官方帳號、KYC 與轉換計數；AI 人像揭露沒有擴大為所有 AI 文字的統一標示義務，官方 PDF 只讀可取得文字，不虛稱圖像檢查。

ChatGPT 廣告查官方可用地區、帳務條件及 2026 年 9 月政策；台灣不在查證日的自助廣告地區清單。註冊與開放投放分開，不編造台灣推出時間、費率或廣告影響回答。官方新開放的歐洲自助地區沒有寫成只能透過合作夥伴購買。

ROI／ROAS 使用原創野餐墊數據：營收 16,000、完整成本 14,000、利潤 2,000，ROI 約 14.29%，ROAS 約 533.33%；漏記費用可能轉虧。圖解的數字與正文核對，不把廣告營收倍數當成淨利。

GA4 安裝、工作階段、GTM 三篇分別處理植物照護、二手樂器與帆布修補的量測任務。表單送出不一定成功，key event 非回溯；互動條件排除 first_visit／first_open／session_start 即使標記為重要事件。GTM 預覽、版本、發布分開；同意初始化不是給所有標籤提早執行，denied 不必然零請求。

UTM 以陶笛活動規範命名；Page location 與 Landing page + query string 對 UTM 的顯示差異查核，沒有沿用 UA 內部標記會新開工作階段的說法。短網址以種子交換管理目的地與存續；品牌網域的 DNS 所有權不代表轉址資料可自動搬家，不承諾未證實的匯出功能。

Clarity 以工具借用流程說明 DOM 重建、遮罩、同意與留存。Balanced 不等於全部個資都會遮住，新的遮罩不回溯舊資料；正常錄影與收藏／標記留存期限依官方文件區分，rage click 不直接解讀為情緒。

Google 商家以鐘錶維修區分到店、外出服務及純線上業務；Google 決定可用驗證方式。真實名稱、地址、管理權、營業時間及評論處理分開，沒有排名承諾，也不把贈品換評價寫成可行。

電子報規劃以街區散步社團建立用途與退出紀錄；查個資法現行第八、二十條，不把尚未施行條文混入。Gmail 的 48 小時處理要求不當成台灣法律寬限。Apple Mail 背景載入與機器點擊可能影響數字；原創 400 封送達、20 位點擊者為 5%，報名另算。

Kit 以衣物修補說明全域訂閱者、Tag／Segment、確認信及 Sequence 啟動條件；匯入表單會自動確認，不會因表單開雙重確認就再寄確認信，也可能觸發自動化。Mailchimp／MC4WP 以二手書交換說明 API key、表單訂閱與群組更新；第三方外掛 4.12.0 已移除未驗證表單退訂，舊 JavaScript 事件文件不當成仍可使用。WordPress 使用者同步不自動訂閱或退訂。

Brevo 以手工紙工作室區分寄件地址與網域驗證、匯入更新與封鎖、行銷停權與帳戶問題。新網域設定流程分批推出，NS 委派僅論子網域；不盲目覆寫既有 DMARC。封鎖按通道處理，停權不等於取消付費方案，外洩密鑰需撤銷更換。

簡訊以雨傘維修分開取件與行銷用途；Twilio 台灣的雙向不支援、網址登記及 SMSC 投遞回報是該供應商條件，不擴大為所有台灣業者規範。70／67 是常見 UCS-2 分段編碼單位，不假設表情一律一字；退訂須測既有排程。

聊天機器人以陶土小物服務界定回答與真人接手。Chatfuel 新文件 Tasks 已改 Automations，Manychat Live Chat 已改 Inbox。一般網站按鈕不必然開啟訊息窗；真人 7 天從最後互動起算。Manychat 暫停既有流程有中斷點，Chatfuel Timeout 可能交回 AI；模擬 Test chat 不模擬通道訊息窗。沒有沿用已棄用 Message Tags 當現行操作。

AdSense 申請與 WordPress 版位分為兩篇：前者以生活收納網站區分資格、內容、連接、審查、Ready、ads.txt 與收益；後者以紙模型下載流程檢查程式碼責任、單元、手機位移及回復。Site Kit 不能手動加入單元，登入時可能預設不顯示廣告。區域排除限頁內 Auto ads，頁面排除不接管手動單元。沒有固定篇數核准保證、固定收入或自己點廣告的測試建議。
