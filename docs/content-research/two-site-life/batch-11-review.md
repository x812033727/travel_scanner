## 編輯與主題界線

Figma 外掛以共讀專案區分檔案存取、外掛介面與網路清單，選取範圍不是安全界線；Community 素材與外掛授權分開。Figma AI 以共享廚房區分 First Draft、agent、原型互動與人員權限，沒有把 Coming soon 寫成可用功能；目前 agent beta 不扣 AI credits 的例外，與其他 AI 功能分開。訓練設定及聊天室預設分享皆依當前官方文件，未假設關閉設定可回溯移除資料。

AI 設計提示以洗衣店說明需求、未知資訊與可用性驗證，不把生成角色當成真實訪談。CSS 以工作坊報名說明盒模型，280＋16×2＋2×2＝316 與 border-box 內容 244 的原創算例明確；不把最後一條 CSS 一律視為勝出。SCSS 以桌遊頁區分原生 CSS、編譯、模組與輸出；Node Sass 已停止維護，Sass @import 棄用不等於原生 CSS @import 消失。

Lottie 以投影活動區分 JSON、.lottie、播放器與 WASM，沒有假設所有格式由同一播放器處理。動態偏好需在 JavaScript 播放流程處理，CSS 不會自動停止腳本動畫；WCAG 暫停條件保留例外。404 以展覽網站區分 HTTP 狀態、頁面文案及替代路徑，避免所有失效網址導首頁。CTA 以攝影詢問頁區分資訊、主要行動與完成送出，300 次造訪、30 次點擊、12 次詢問為假設例，未當成獨立人數或實際成效。

Canva 以二手書交換說明範本與輸出；透明 PNG、去背、品牌工具及授權依各自條件判斷。教育、品牌素材和一般內容不混用，PDF 裁切及壓平不保證隱私清除，SVG 也可能包含點陣內容。Eagle 以陶藝素材管理區分複製匯入、標籤、完整資料庫與雲端同步；不把放入多資料夾視為多份素材，也不把線上佔位檔當成完整備份。

Wix 以修鞋店使用 Wix Editor，沒有套用 Studio 或 Harmony 的介面；保存、預覽和發布分開，選單隱藏不等於限制瀏覽。付款提供者依台灣可用條件查核，不列互相矛盾的完整清單。Lovable 以工具借用網站核對當前逐步推出的整合 credits 計費，未沿用舊固定贈額；Cloud 預設權限、共用資料庫草稿、儲存空間公開限制與 Basic/Deep 掃描都明確區分。草稿中的既有資料變更不是隔離測試，發布與應用程式身分驗證也不是同一件事。

網站 AI 搜尋以手作展館區分索引、權限、引用與紀錄，檢索前檢查授權而非等模型讀取後才遮蔽。Notion 紀錄是人工設計，沒有宣稱資料庫自動連動搜尋。沉浸式翻譯以園藝社說明網頁、PDF 和字幕；依新版隱私政策區分翻譯供應商、文件上傳與暫存，不宣稱完全本機或全面零保留。標準 PDF、掃描文件及付費權益分開，術語與否定詞必須人工校對。

逐字稿以社區口述訪談區分 MacWhisper 本機模型、雲端轉寫、翻譯和 AI 摘要；不因工具名稱就保證資料不外傳。繁簡混用與說話者辨識需人工修正。Whisper Desktop 依 Const-me 官方專案與 2023-07-22 的 1.12.0 發布資料，不引用仿冒網域或作者速度比較，也不把舊版本等同停止維護。

Adobe Podcast 以市集訪談區分原始檔、增強輸出與分離音訊。2026-08-30 之後的新訂閱管道和既有 Premium 用戶不同，依 Firefly Pro 與官方變更 FAQ 整理，未沿用舊試用或不限量宣傳。Free/Premium 容量、時長、每日量及影音差異分開；模型分離音訊不等於取得原錄音分軌，也不等於清除配樂權利。

OBS 以報名表錄影區分場景、來源、混音及分軌。Windows 應用程式音訊與 macOS 原生音訊依版本條件說明，未宣稱所有系統都需要虛擬音源。MKV、一般 MP4 與新版 Hybrid MP4/MOV 分開，沒有沿用所有 MP4 都無法復原的舊結論；Remux 不會修好模糊畫面或改變編碼相容性。沒有虛構錄影實測。

Premiere 以自行車維修店區分 .pproj、原始媒體、序列與代理檔。台灣頁的 7 天試用及後續計費有查證，不列未確認售價；Organize Media 與 Copy media 分開。預設正式輸出使用完整來源，但 Use Proxies 可改變輸出，因此仍需檢查。Project Manager 按選定序列與選項收集，不能保證所有字型、外掛及外部依賴都已帶走。

教學影片以虛構值班名單安排目標、分鏡、停頓與跟做。UIC 指南僅查教學概念，未重用其非商用圖表或文字，也未沿用固定注意力或片長數字。W3C 字幕、重要視覺描述及描述性文字稿各自處理，不把有人旁白等同視覺資訊完整，也不宣稱已符合某級 WCAG。沒有學員或影片實測。

Frame.io 以陶藝展宣傳片查 V4 文件，未混用 Legacy 角色或分享流程。共享資料夾和版本可動態改變接收者看到的內容，Secure sharing 的 Enterprise 條件保留。Internal Comments 與回覆可見性、未登入留言的工作階段限制、匯出篩選結果均有說明。Mark As Complete 不取代最終交付確認；Mounted Storage 保存歷程與手動交付版本不同。
