Remote Control 讓你從手機或瀏覽器接續本機 Claude Code 工作階段。它同步的是操作入口與對話，檔案讀取、命令及本機工具仍在原本電腦執行。本篇會在待辦專案啟用連線，用手機完成一次只讀檢查，再練習中斷與恢復，讓你知道工作實際在哪裡發生。

先準備已登入的 CLI、可信任的專案資料夾，以及使用同一 claude.ai 帳號的手機或瀏覽器。官方需求列出支援訂閱方案，Team／Enterprise 另需擁有者啟用組織設定；API 金鑰、第三方模型供應商與部分自訂端點設定不適用。請先核對[帳號與平台](article:claude-code-accounts-and-access)，不要只憑能啟動 CLI 就假設遠端入口一定開放。

## 先完成本機基準

在電腦終端機進入已解壓縮的練習專案，確認 claude --version 與 claude doctor 正常。至少先在該專案啟動一次 claude，完成登入與工作區信任確認。不要選整個使用者家目錄；本次只需要練習資料夾中的檔案。

```bash 電腦終端機：已進入練習專案後執行
claude --version
claude doctor
claude
```

先要求讀取 README 並回報測試指令，確認本機本來就能工作。若這一步失敗，先處理安裝或專案問題，再啟用 Remote Control。把功能逐層確認，才能分辨手機連線問題與原本工具執行失敗。

## 選擇啟動方式

如果已經有對話，使用斜線指令讓目前 session 開放接續。本篇採這條路線，因為它能保留你剛才的對話脈絡。第一次啟用時閱讀確認畫面，再依需要開啟連線。

```text 本機 Claude Code 對話框：接續目前工作階段
/remote-control Todo 練習
```

若你希望終端機主要作為等候手機連線的服務，可在 shell 執行 claude remote-control。這是終端機命令，不是對話內斜線指令。官方還提供其他啟動參數；初學先使用一種方式完成單一工作，不必一次啟動多個並行 session。

```bash 電腦終端機：另選服務模式時使用
claude remote-control
```

| 啟動位置 | 指令形式 | 適合情況 |
|---|---|---|
| 已開啟的 CLI 對話 | /remote-control | 接續眼前的對話 |
| 一般終端機 | claude remote-control | 啟動等候連線的服務模式 |
| VS Code Claude 面板 | /remote-control | 接續擴充功能工作階段 |

VS Code 的同名指令有自己的介面行為，例如不接受 CLI 同樣的名稱參數，也不一定顯示 QR code。使用時依所在介面的官方說明操作，不能把不同入口的所有參數互相混貼。

## 從手機或瀏覽器連進同一個 session

使用終端機提供的 session 網址，或顯示 QR code 後用手機掃描。服務模式可以按空白鍵切換 QR 顯示；也可直接在 Claude App 的 Code 清單找對應名稱。確認登入帳號與組織正確，再檢查電腦圖示和線上狀態。

```text 手機或瀏覽器中的 Remote Control 對話框
請回報目前工作目錄，並讀取 model.js。
用兩筆待辦示範 toggleTodo 依識別碼切換完成狀態的結果。
這次只讀取與說明，不修改檔案，也不新增工作階段。
```

回到電腦確認同一則訊息出現，並把回報路徑與本機位置對照。若它讀到另一份材料，先停止後續修改，查明選錯的 session 或資料夾。第一次驗證不需要動用資料庫、部署工具或私人檔案，用只讀操作就足以確認連線方向。

## 理解權限與附件

手機可以回應支援的權限提示，但可選模式與終端機不完全相同。先看清楚它要讀哪個檔案、執行哪個命令，再根據任務決定。某些終端機專用指令無法從手機執行；需要管理外掛或切換本機歷史時，回到電腦處理。

從手機附上照片或檔案後，Claude 可以在本機工作階段使用它們。若要將素材納入網站，要求回報保存位置與檔案名稱，再檢查是否放到正確專案。附件傳送成功不等於已建立 Git 提交，也不代表已上傳到網站。

## 中斷與恢復連線

電腦睡眠或網路中斷時，工作無法以正常連線狀態繼續；官方提供上線後的重新連接機制。恢復後先查看狀態與最新訊息，確認中斷前的指示是否已送達。對可能產生外部結果的任務，尤其不要用重送來猜測成功與否。

在互動 CLI 再次開啟 /remote-control 的狀態面板，可以查看網址、連線情況及中斷選項；中斷遠端連線不一定結束本機對話。服務模式若要停止，回到原終端機依畫面或 Ctrl+C 結束程序，再確認遠端已無法繼續操作該服務。

> Remote Control 不會把電腦搬到雲端。需要筆電關機後持續執行的任務，應改用雲端工作，並另外準備雲端能取得的程式版本與環境。

## 排錯與完成判準

登入錯誤先查 claude.ai 資格與組織開關；端點不支援先查是否使用代理或第三方供應商；連線不可用也可能與組織環境設定有關。若設定是公司管理的，不要自行移除它來湊成功，應向管理員確認這項功能是否被允許。

小練習是完成一次手機只讀訊息，主動中斷遠端連線，再從電腦確認本機對話仍可使用。重新啟用後核對工作名稱與路徑，重做同一個只讀檢查。完成判準包含連得上、知道在哪裡執行、能自行中斷，以及能辨認連線恢復後的最新狀態。接著再讀[跨裝置流程](article:claude-code-cross-device-workflow)整理程式版本的交接方式。
