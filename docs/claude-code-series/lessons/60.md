這一頁集中整理常用命令、提示詞與設定範本，適合學完後快速查找。每個範例都標示輸入位置，詳細條件與排錯連到專篇。範本中的路徑、識別碼與假值要先替換，不能直接把範例當作目前專案的真實狀態。

需要循序學習時，返回[完整總目錄](article:claude-code-tutorials)選擇路線。命令依官方文件於本系列查證日期核對，實際可用項目仍受版本、平台、登入方式與組織政策影響；先用目前環境的 help 查看支援情況。

## 終端機命令速查

```bash PowerShell 或 macOS／Linux 終端機：依用途逐行執行
claude --version
claude --help
claude doctor
claude
claude --continue
claude --resume
claude --worktree my-task
claude mcp list
```

版本與診斷看[說明與診斷](article:claude-code-help-status-doctor)，繼續工作看[對話管理](article:claude-code-sessions-resume)，隔離分支看[Worktree](article:claude-code-worktrees-parallel)。continue 與 resume 接續對話，不會自動把別台電腦未提交檔案同步過來。

## 對話內命令速查

| 命令 | 主要用途 | 先注意什麼 |
|---|---|---|
| /help | 查看目前入口的功能 | 平台支援不一定相同 |
| /status | 查看狀態與設定來源 | 不回顯秘密 |
| /context | 觀察上下文使用 | 與磁碟檔案不同 |
| /compact | 整理對話上下文 | 先保留重要決策 |
| /clear | 開始新的對話內容 | 不會還原磁碟變更 |
| /model | 選擇模型 | 以帳號可用選項為準 |
| /usage | 查看使用狀態 | 估計與實際帳務分開 |
| /memory | 管理記憶與規則入口 | 檔案列出不代表已載入 |
| /init | 建立專案指引起點 | 產生後仍需審查 |
| /mcp | 查看工具連線與認證 | 需完成一次實際操作 |
| /chrome | 管理瀏覽器整合 | 有平台與登入條件 |
| /rewind | 檢查點回復 | 不等同 Git 或外部還原 |

上下文差異看[/context、/compact、/clear](article:claude-code-context-compact-clear)，還原限制看[Checkpoint](article:claude-code-checkpoints-rewind)。不要把自訂 Skill 名稱當成所有人都有的內建命令；名稱來自你的安裝與專案檔案。

## 需求提示範本

```text Claude Code 對話框：替換成你的實際需求
目標：完成一個可驗證的小功能。
範圍：只修改指定檔案與必要測試。
限制：保留既有行為，不加入未要求的服務或套件。
先讀：專案指引、入口與相關測試。
驗收：列出具體輸入、操作與預期結果。
交付：實際差異、執行過的檢查、未驗證項目與下一步。
先不要提交、推送或部署，除非本次另有明確要求。
```

把「做得更好」改成可觀察結果，例如篩選後有幾筆、重新整理是否保留資料。更完整的例子在[需求交代](article:claude-code-task-prompts)，除錯時則補上[重現步驟與錯誤](article:claude-code-debug-and-test)。

## CLAUDE.md 起始範本

```markdown 寫入練習專案 CLAUDE.md
# 專案說明
這是 HTML、CSS、JavaScript 待辦網站，不使用資料庫。
## 常用命令
- 啟動：npm start
- 測試：npm test
## 實作規範
介面使用繁體中文；使用者輸入以文字顯示。
資料操作依識別碼處理，避免意外修改原陣列。
## 驗收
修改後執行受影響測試，必要時驗證瀏覽器操作。
清楚區分已執行與未執行的檢查。
```

只有真的適用的命令才保留。這是指引，不能代替工具權限。需要共用 AGENTS.md 時，依[引用規則](article:claude-code-rules-and-imports)加入正確引用；不要假設一般 Markdown 連結就會自動載入內容。

## 手動 Skill 起始範本

```markdown 寫入 .claude/skills/todo-note/SKILL.md
---
name: todo-note
description: 只讀檢查待辦專案並整理短報告。
disable-model-invocation: true
---
讀取 README 與 package.json，確認用途、啟動與測試方式。
回報實際檔名與命令，不修改檔案。
沒有執行測試就明確說明。
```

```text Claude Code 對話框：呼叫上面的專案技能
/todo-note
```

加入參數與範本前，先確認這個最小呼叫真的載入並完成。[技能參數](article:claude-code-skill-arguments-resources)說明 $ARGUMENTS 與附屬材料，[自訂指令移轉](article:claude-code-custom-commands)說明舊 commands 格式。

## JSON 與程式碼範例怎麼保存

JSON 必須保留雙引號、逗號與合法型別，不支援一般註解。下面是空的專案設定起點，不含廣泛授權；依[settings.json 教學](article:claude-code-settings-json)逐項加入需要的欄位，不整份覆蓋已有設定。

```json 寫入新的 .claude/settings.local.json：已有檔案請先閱讀再合併
{}
```

需要 Hook 時使用[入門完整範例](article:claude-code-hooks-getting-started)，其中包含腳本、事件與停用驗證。需要 MCP 時使用[設定排錯篇](article:claude-code-mcp-setup-troubleshooting)，把伺服器宣告與認證分開保存。

## 練習材料與交付範本

下載[起始版](https://mokaair.com/tutorials/claude-code/starter.zip)、[故意錯誤版](https://mokaair.com/tutorials/claude-code/bug-toggle.zip)或[完整參考版](https://mokaair.com/tutorials/claude-code/complete.zip)，各自解壓到獨立資料夾。錯誤版測試預期失敗，目的是練習定位 toggleTodo 的識別碼問題。

```text 填入本次交付紀錄
完成的功能與修改檔案：
實際執行的命令及結果：
瀏覽器驗證操作與畫面寬度：
尚未驗證與已知限制：
Git 提交、PR、合併狀態：
部署與公開發布狀態：
停止服務或回復的方法：
```

使用複製按鈕後，先貼入正確工具或檔案，確認縮排、換行與特殊字元完整。範本是開始工作的材料，最後仍要按[完整實作篇](article:claude-code-build-todo-app)完成測試與畫面驗證，再把結果交給下一位讀者。
