這個教學中心把 Claude Code 分成 96 個可以獨立閱讀的小題目，從桌面、CLI、網頁與手機開始，再學 MD 規則、常用指令、Skills、MCP 與自動化。你可以依推薦路線循序學習，也可以直接搜尋正在遇到的功能、命令或檔名。目錄依目前公開狀態顯示可閱讀文章。

每篇都有先備知識、操作位置、完整範例、成功判準與常見錯誤。需要其他功能時，內文提供文字連結；文章頂部與底部也能回到這份總目錄。先選一個明確的小目標，完成實際操作，再決定下一篇要讀什麼。

## 選擇你的第一條路線

桌面新手先從選資料夾、交代任務與查看差異開始；CLI 新手先練習路徑、安裝與指令分類；手機讀者先辨認雲端任務、Remote Control 與 Dispatch 的執行位置。已經能完成基本任務的人，可以直接走 MD 設定或進階自動化路線。

| 目前的需求 | 從哪裡開始 | 第一個可驗證成果 |
|---|---|---|
| 想用視窗操作 | 桌面新手路線 | 修改一段標題並查看差異 |
| 想學終端機 | CLI 新手路線 | 啟動、命名與找回對話 |
| 想離開電腦接續 | 手機操作路線 | 確認同一 session 與執行位置 |
| 想讓工具懂專案 | MD 設定路線 | 建立並核對 CLAUDE.md 載入 |
| 想重複處理工作 | 進階自動化路線 | 一次有輸入、輸出與停止方式的流程 |

路線是建議順序，不是閱讀門檻。每篇的先備區會連到真正需要的知識，相關練習也提供可獨立開始的材料。若你只想查一個問題，可以先讀[指令分類](article:claude-code-cli-command-guide)或[問題排除](article:claude-code-troubleshooting)，再依連結補足背景。

深入練習可整組下載：[規則材料](https://mokaair.com/tutorials/claude-code/advanced/config-lab.zip)、[Skills 材料](https://mokaair.com/tutorials/claude-code/advanced/skill-kit.zip)、[Hooks 材料](https://mokaair.com/tutorials/claude-code/advanced/hook-lab.zip)、[MCP 材料](https://mokaair.com/tutorials/claude-code/advanced/mcp-lab.zip)、[協作工作台](https://mokaair.com/tutorials/claude-code/advanced/todo-workbench.zip)與[自動化材料](https://mokaair.com/tutorials/claude-code/advanced/automation-lab.zip)。各組內每個 lesson ZIP 都能獨立解壓縮，不必把不同篇章的 starter 覆蓋在一起。

## 使用搜尋與組合篩選

搜尋可以輸入中文功能、英文名稱、斜線指令與檔名。例如 MD、手機、權限、/compact、MCP 或 CLAUDE.md，都有對應的文章與別名。多個搜尋詞會一起縮小結果；找不到時，先用一個關鍵詞，再逐步增加條件。

主題、程度、平台與學習路線可以組合使用，網址會保留目前條件。從結果打開文章後，使用瀏覽器返回即可回到原本的查找位置；清除篩選可以重新查看所有目前可閱讀的篇章。若某個功能依版本或資格尚未開放，文章會說明核對方式與可採用的替代入口。

## 如何判斷自己真的學會

每篇完成後，試著說出「在哪裡操作、輸入什麼、結果在哪裡檢查」三件事。功能教學以實際檔案、測試或畫面為成功判準；設定教學會要求查看載入來源；自動化教學還會要求知道如何停止與查看錯誤紀錄。

> 官方文件核對與實際操作驗證是不同證據。本系列保留來源查證日期；你的裝置、方案與版本仍需依各篇前提確認，不能只因為看過教學就視為自己的環境已驗證。

如果遇到卡住的地方，先保留命令、錯誤與執行位置，再回到[診斷篇](article:claude-code-help-status-doctor)。學習的目標不是背完 96 篇，而是能找到正確入口，完成一個有清楚結果的小任務，並逐步擴展到自己的真實專案。
