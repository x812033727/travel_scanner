自動記憶讓 Claude Code 保存之後可能有用的偏好、回饋與專案決策。本篇會用 /memory 找到記憶位置，建立一則無敏感資訊的練習記憶，再檢查、更正與停用。你會學會把記憶當成可維護的筆記，而不是保證永遠正確的資料庫。

請先了解[CLAUDE.md](article:claude-code-claude-md-guide)與[設定範圍](article:claude-code-settings-json)。本篇以本機 Claude Code 為例；記憶通常保存在本機設定目錄，不會自動同步到另一台電腦或雲端環境。使用多個裝置時，請先確認正在檢查哪台機器的資料。

## 記憶與專案規則有何不同

CLAUDE.md 是你或團隊主動維護的指引，自動記憶則由 Claude 判斷哪些對話資訊值得保存。不是每個 session 都一定寫入記憶，也不是每句話都會變成永久規則。想明確修改 CLAUDE.md，直接指示寫入該檔；只說「記住」可能會走向自動記憶。

| 資訊類型 | 適合保存方式 | 例子 |
|---|---|---|
| 團隊固定測試規範 | CLAUDE.md 或 rules | 行為變更要補測試 |
| 個人回報偏好 | 自動記憶或個人指引 | 先列實際驗證結果 |
| 暫時工作決策 | 任務紀錄，必要時記憶 | 本輪先不做雲端同步 |
| 可直接從程式取得的事實 | 重新讀檔 | 函式目前放在哪個檔案 |

官方目前的記憶分類包含使用者資訊、回饋、專案情境與外部參考。對讀者最有用的判準是「下次是否仍需要這個資訊，而且無法可靠地直接從程式取得」。把容易變動的行號、測試數量或舊錯誤寫死在記憶中，反而可能讓後續工作偏離現況。

## 用 /memory 查看位置

在練習專案啟動 Claude Code，輸入 /memory。介面可列出使用者與專案的指引位置，也提供自動記憶開關與開啟記憶目錄的入口。注意清單可能包含尚未建立的文件位置；要確認本次實際載入哪些內容，另用 /context 查看。

```text Claude Code 對話框：查看記憶管理
/memory
```

本機預設記憶通常在 ~/.claude/projects/對應專案/memory 中，內有 MEMORY.md 索引與主題檔。實際目錄識別可能由儲存庫與設定決定，因此優先從介面取得路徑，不要自己猜測字串。相同儲存庫的 worktree 與子目錄可以共用同一份自動記憶，檢查時要注意影響範圍。

## 建立一則可驗證的練習記憶

先使用不含帳密與私人資料的偏好，例如希望回報先列測試。明確告訴 Claude 這是本次練習要保存的內容，並要求回報實際檔案位置。不要只看它回答「已記住」，要回到 memory 目錄查看寫入結果。

```text Claude Code 對話框：新增練習用偏好
請記住這個待辦專案的回報偏好：先列實際執行的測試結果，再說明修改摘要。
這是偏好記憶，不修改 CLAUDE.md。
保存後告訴我寫入哪個記憶檔，讓我檢查內容。
```

打開指定主題檔，確認文字符合原意，沒有自行加入「永遠不用手動驗證」等額外推論。再查看 MEMORY.md 是否有對應索引。索引主要協助找到主題，不應塞入整份長報告；詳細內容應放到對應檔案，需要時再讀取。

## 重新開啟與更正記憶

開新 session，問它目前有哪些相關回報偏好，再要求說明來源。如果只重複了你剛才問題裡的文字，還不足以證明成功回想；可以用較中性的問題，例如「這個專案的回報有沒有已保存的偏好？」並核對讀取紀錄。

```text 新的 Claude Code 對話框：驗證與更正
請查看這個專案已保存的回報偏好，指出來源檔案。
將練習偏好調整成：先列未通過或未驗證項目，再列通過的測試。
只更新這一則記憶，保留其他既有記憶。
```

更新後再次開檔核對，避免新舊說法同時存在而造成矛盾。刪除不需要的練習記憶時，同時檢查索引是否還指向不存在的檔案。若你直接用編輯器修改，也應保留其他主題與前置資料，並在下次 session 確認載入正常。

## 控制自動記憶與載入量

目前自動記憶預設開啟，可透過 /memory 的開關調整。若只想在這個專案停用，可以在合適範圍的 settings.json 設定 autoMemoryEnabled。先合併到現有 JSON，不要用以下小範例覆蓋整份檔案。

```json 寫入專案 .claude/settings.local.json：與既有設定合併
{
  "autoMemoryEnabled": false
}
```

停用與刪除是不同動作。關閉功能後，既有記憶檔仍可能留在磁碟；若目的是清理某一則錯誤資訊，仍要定位並修改或刪除那則記憶。相反地，刪除一個主題檔也不等於關閉未來的自動保存行為。

官方目前的索引啟動載入上限是前 200 行或 25KB，以先到者為準；超出的索引內容不會在啟動時完整進入上下文。這個限制不代表所有主題檔都自動讀完，也不等於 CLAUDE.md 的建議長度。整理索引時保留短摘要與路徑，詳細背景留給按需讀取。

> 記憶可能過期。使用到模型資格、工具版本、網址狀態或專案現況時，仍要重新查證，不能因為「之前記過」就當成現在已確認。

## 常見問題與小練習

找不到剛才的記憶，先查是否換了機器、儲存庫或設定目錄；新 session 沒有提到偏好，先查索引與開關；回覆一直引用舊資訊，檢查是否有重複主題或 CLAUDE.md 仍保留相反說法。這些問題都需要看來源，而不是無限重複「請記住」。

小練習是新增一則偏好、從新 session 讀回、更正一次，再移除練習用內容。完成判準是每一步都能指出實際檔案與變更，且其他記憶未受影響。接下來可用[上下文整理](article:claude-code-context-compact-clear)理解當前對話與跨 session 記憶如何各自發揮作用。
