# jeonju-bibimbap-food-guide：第二輪獨立查核

查核日期：2026-09-20。撰稿 Sol，第一輪 Terra，本輪 Astra。重開全州市及韓國觀光公社的官方頁，逐項對照料理背景、四家店與圖片。

- [全州市料理頁](https://tour.jeonju.go.kr/index.jeonju?menuCd=DOM_000000104003006000) 可見牛骨湯煮飯、全州豆芽、`황포묵` 與熟成醬料；文中正確限制為城市料理背景，未承諾每店配方相同。
- [한국집 店頁](https://access.visitkorea.or.kr/food/detail.do?cotId=a05f7edc-2269-44cf-a446-e137b3f0fa8c) 可見 `어진길 119` 與全州拌飯；[가족회관 店頁](https://english.visitkorea.or.kr/svc/contents/contentsView.do?vcontsId=192083) 可見生牛肉拌飯與 `전라감영5길 17`。
- [고궁 전주본점](https://access.visitkorea.or.kr/food/detail.do?cotId=7ea991e9-7ffa-4254-996d-47cedbfcfd8e) 可見 `송천중앙로 33`、銅碗／石鍋選項及黃涼粉涼拌料理；沒有套到其他店。
- [KTO 韓屋村旅遊頁](https://access.visitkorea.or.kr/cos/detail.do?cotId=4b3c8cc1-31a0-4765-92ab-07c3f7f1e94a) 可見 `종로회관`、生牛肉拌飯及 `전동성당길 98`。該文自述是 2020 年資料，所以現行時段沒有沿用。
- [KTO 繁中料理頁](https://big5chinese.visitkorea.or.kr/svc/contents/contentsView.do?vcontsId=181515) 把 `황포묵` 正式譯為「黃涼粉」。原 pack 的「黃埔涼粉」誤譯已全部修正於 pack、SVG 及生成腳本，並加入術語來源。

目視 hero、photo-1：兩張是拌飯料理；photo-1 有紅色生牛肉、蛋黃、蔬菜，與 alt 相符，不宣稱是本文店家出品。將更新後 `diagram-1.svg` 以 Chrome 渲染為 1600×900 PNG，兩欄文字清晰且未截斷，城市料理與逐店器皿選項分開；圖片授權已在第一輪 manifest 核對。

結論：四家店的官方點名、門牌與菜名均有可見來源；修正一處中文食材名稱。整批 lint 另記於總驗收紀錄。
