## 3. 留給協調者的事

1. **規格有誤（要回寫）**：하동관那句「단골들은 곰탕에 김치 국물을 타서 먹기도 한다」只存在於

   打架」其實是「同一頁的正文 vs meta」。`SOURCE-TIPS.md` 的「畫面上看得見」一節建議補一句：
   Visit Seoul 的 meta description 是另外寫的行銷文案，比正文多出整句事實，不能當頁面內容。

   地址**沒有經過第二人確認**，兩個網址維持規格／`pool-directory.md` 給的值。這兩筆要人工點一次。

## 4. 我覺得這篇最可能還有問題的地方

1. **Naver 的兩個精確地點頁**（第 3 節第 2 點）。這是全篇唯一沒有第二人核過的外部連結，而且讀者
   最可能直接點它。
2. **營業時間是這批最容易過期的東西**，而這篇六家有五家寫了時間。하동관那則「已被拆」的網友留言
   讓我對「上線前再確認一次」這件事特別不放心。

   官方站內部命名這類對讀者價值低的插敘（例如마포옥那句「網址裡的마포옥1、마포옥55是官方站自己的
   內部編號」）。本批規則禁止刪逐店小節，所以我沒有動；但若之後又要壓字數，**那裡才是該先看的
   地方，不是 FAQ**。

   （서울특별시 문화본부 문화유산보존과），不是內文敘述。它在畫面上看得到，所以合格，但如果協調者
