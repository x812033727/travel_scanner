## 後續收斂（2026-09-20）

README 要求每家咖啡店均有官方文字支持的類型標籤。`카페 477+` 雖由中心頁可見正文點名，卻不足以支持海景、網美、韓屋或咖啡品質任一類型，已由工作 pack、隔離 repo pack、SVG、來源與筆記移除。現稿保留四家，仍在規定的 4–7 家範圍；新的 intake 和收件將由主流程重跑。
