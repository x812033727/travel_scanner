```bash
cd /root/travel_scanner
# 1. 先看：全語系、含影片，只列不寫

  --skip-id eff4dc8f-6ea0-4392-abed-f7bf7d6e0e72 \
  --reject-id 02629694-ed1e-43f9-9e2c-553890c45361 \
  --reject-id 4c8343d1-7665-4679-8ece-cfa4546ce855 \
```

看不到的列或其他語系的列，逐筆看標題確認後一起退。`--reject-id` 只接受規則沒命中的列，已退過的會列在
`already_rejected`，不存在的在 `missing`。
