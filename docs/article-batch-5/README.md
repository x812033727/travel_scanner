## 內容範圍與去重

旅遊篇涵蓋日本行李宅配、置物櫃、訂房方案、餐廳預約、列車停駛、東京雨天博物館、京都單車停車、旅行洗衣、新加坡熟食中心與濱海灣花園、香港渡輪電車與長洲、吉隆坡機場轉乘、清邁與河內散步。

生活篇涵蓋檔案命名、備份還原、照片、郵件、書籤、會議紀錄、每週回顧、通知、家庭庫存、購買憑證、桌面線材、手機掃描、共用行事曆、3C 需求與閱讀筆記。

比對基準為分支起點 `e8a62c94` 中的 70 篇內容包，以及 2026-09-14 以瀏覽器讀取的正式網站目錄。正式繁中攻略兩頁共 41 篇，均對應既有內容包；生活分享兩頁另有 40 篇 AI 主題文章。新批次沒有相同標題、slug、全文或重用主圖；文字五字片段相似度記錄在驗證檔，並另做題目與用途的人工判讀。

容易相近的主題刻意分工如下：

| 本批內容 | 與既有或同批內容的差別 |
| --- | --- |
| 日本訂房方案 | 核對床型、人數、餐食與取消條件；既有住宿篇著重區域選擇，溫泉旅館篇著重入住與泡湯 |
| 行李宅配／置物櫃 | 前者處理跨日跨城交寄，後者處理當日寄放、閘內外與解鎖 |
| 東京雨天博物館／京都單車 | 個別活動選擇與操作；既有文章是多日行程或公車地鐵指南 |
| 郵件整理 | 處理已收到信件的待辦狀態；既有生活篇教用 AI 擬稿 |

比對不涵蓋未公開的後台草稿及查核後新增的文章。發布前若資料庫已有同 slug，應先使用既有匯入工具的 dry-run 檢查，不以強制覆寫處理衝突。

## 圖片與來源

每篇都有一張為本批獨立生成的 AI 主圖：共 30 張，1600 × 900 JPEG、每張小於 200,000 bytes。統一使用紙感插畫風格，但主體構圖不同，沒有使用第三方圖庫照片。另有 30 張編輯自製 SVG 流程圖。

主圖的 alt 與 credit 都清楚寫「AI 生成」「非實拍」，不作地點、店家或設備的實地證明，也不宣稱取得排他著作權。`image-subjects.json` 記錄各圖主題，`image-sources.json` 對應原始生成檔名，`image-provenance.json` 提供原圖與網站成品的 SHA-256。原始 PNG 留在生成工具的本機輸出目錄；專案包含網站使用的 JPEG。

資料來源查核日為 2026-09-14，旅遊資訊採營運方、觀光局與設施官網；生活篇的軟體操作與概念引用官方支援文件或原始機構。文章中的假設情境是編輯建議，沒有捏造親身到訪或產品測試經驗。易變的時刻、票務與條款，保留回到官網確認的入口。

## 重建與驗證

在專案根目錄執行（Python 環境由 `apps/api` 的 `uv sync --frozen` 建立）：

```powershell
apps/api/.venv/Scripts/python.exe docs/article-batch-5/build_content.py
apps/api/.venv/Scripts/python.exe docs/article-batch-5/build_preview.py
apps/api/.venv/Scripts/python.exe docs/article-batch-5/verify_batch.py
npm run check:tasks
```

如需由原始圖片重建 JPEG，再執行以下命令，提供原始 ImageGen PNG 所在目錄：

```powershell
apps/api/.venv/Scripts/python.exe docs/article-batch-5/prepare_assets.py --source-dir <original-image-directory>
```

API 內容包既有測試：在 `apps/api` 執行 `.venv/Scripts/python.exe -m pytest tests/test_guides_content_pack.py -q`。

本次結果：內容包測試 **8 passed、5 skipped**；任務檢查通過（375 個任務檔，僅既有其他任務的過期與重疊警告）。

`verify_batch.py` 檢查全專案 100 個內容包的 schema，並針對本批檢查字數、標題、表格、來源、內鏈、圖片尺寸與雜湊。旅遊正文約 1,800–2,100 字元，生活正文約 1,000–1,110 字元，不含圖片 credit 與來源清單。

匯入驗證只使用程式明確建立的 SQLite 記憶體資料庫：30 篇建立並測試發布成功、30 次公開 API 讀取成功，再次匯入全部 unchanged。不會連線設定中的資料庫，也沒有正式環境寫入。既有測試的 PostgreSQL 變體需要整合服務，本機未執行。

瀏覽器已檢視本機文章目錄、單篇文字與主圖，確認 30 張流程圖均載入；主圖以兩張總覽逐張檢視。獨立預覽的頁面寬度未超過檢視視窗。這些不替代正式 Next.js 頁面部署後的驗證。
