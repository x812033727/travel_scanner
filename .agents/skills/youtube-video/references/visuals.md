# 畫面：字卡、截圖、螢幕錄影、縮圖

## 字卡

- 1920×1080。起手範本 `.agents/skills/youtube-video/references/templates/slide.html`，複製到 `<WORKDIR>/slides/NN-名稱.html` 改字，`video_kit.py render` 出 PNG。
- 一張字卡一個重點：標題 ≤ 16 字，內文最多三行或三列表格。字級不小於 48px，在手機上縮到 1/4 還讀得到。
- 四周留 5% 安全區（YouTube 的播放器控制列與字幕會蓋住下緣）。下緣 15% 不放重要文字，留給字幕。
- 顏色與字型全片一致：範本的 CSS 變數就是色票，改一次全片套用。深色底白字，重點一個強調色。
- 引用別人的數據要在字卡角落標「來源：某某，YYYY-MM」。
- 渲染後每張都打開看：有沒有超框、斷行怪不怪、中英混排的空白。

## 插圖（全自動路線的插圖投影片）

- 一張插圖回答「這一句在講什麼畫面」，照攝影師給插畫家的工單順序寫：景別、地點與時間、一個人在做的一件事（有簡單的臉或背影、剪影，不是無臉人偶）、視線落點的物件與材質、光從哪來；提示詞用英文，≤1000 字，不畫字、不畫 logo、不畫真人的臉（真人與 logo 用剪影、泛稱物件或 `screenshot` 卡片標出處）。
- 每 5–8 秒換一張；遠景、近物、比喻、前後對照輪流；相鄰兩張的提示詞不能像（lint 會警告）、運鏡不跟上一張一樣（連三張同運鏡是 lint 錯誤）；每章一個自己的地點，同一個地點或物件不超過三分之一的圖；主體放在畫面中間三分之一，Shorts 從 16:9 蓋滿 9:16 時只留中間約 32% 寬。
- 運鏡只有七種詞：push in、pull out、pan left、pan right、tilt up、tilt down、drift（沒寫就 drift）；數字、對比、程式碼留給卡片（`stats`、`compare`、`code`）。
- 畫風由 `look.preset` 決定：沒寫時工人依 slug 從五個版畫預設裡挑一個（`riso-teal`／`riso-navy`／`riso-forest`／`riso-plum` 四組雙色 risograph、`linocut-teal` 刻版；`tech-story` 給點名的影片），每支影片先畫一張畫風樣張再當每張圖的參考圖（`keyframes/plate.json`）。不要在提示詞裡另外描述畫風或顏色；比喻用日常的地方與東西，不用筆電、螢幕、機器人、電路、大腦、燈泡、頒獎台、沙漏。
- 一支影片活在一整天裡：夜景與燈下的圖最多一半（lint 會警告），早上、中午、雨天、陰天、白天的人群都要有；每章至少一張兩三個人互相做事的圖、一張手裡拿著東西的特寫，偶爾一個小笑點。
- 設計與規則在 `docs/videos/ILLUSTRATED.md`。

## 截圖

- 瀏覽器用乾淨的 profile：沒有書籤列、擴充功能、其他分頁；視窗 1920×1080，縮放 125–150% 讓字變大。
- 框出重點用字卡範本的 `.mark` 樣式或剪輯軟體的框，不要在截圖上手畫。
- 截圖日期記進 `facts.md`；網頁會改版，說明欄寫「畫面為錄製當時」。

## 圖庫照片（全自動路線的真實照片：Pexels、Pixabay）

旅遊題材要實景（首爾夜景、釜山海邊）時用圖庫照片，不用 AI 畫、不用別人的截圖。金鑰在網站上，工具只帶影片工具權杖；兩家都免費，不記帳。設計與規則在 `docs/videos/ILLUSTRATED.md` §圖庫照片。

1. **搜**：`node tools/video/media/cli.mjs stock search --query "Seoul skyline at night" --orientation landscape --slug <SLUG>`（英文、幾個字就好，≤100 字；`--provider pexels|pixabay` 只問一家；`--per-page` 最多 40）。每個候選印廠商、id、尺寸與方向、廠商要的那句標示、照片頁網址、alt；挑橫向、主體在中間、沒有可辨識的人臉或品牌的那張。Pixabay 的預覽網址一天後失效，挑好就抓。
2. **抓**：`node tools/video/media/cli.mjs stock fetch --slug <SLUG> --provider pexels --id 3573351`。伺服器向廠商要原檔進媒體庫，工具再下載到 `<VIDEO_WORKDIR>/<SLUG>/stock/<sha256>.<jpg|png|webp>`（檔名是內容雜湊，同一張再抓不會重載），並在 `video.json` 的 `assets[]` 寫一筆 `{path, source, license, author, url}`：`source` 是廠商自己的措辭（「Photo by … on Pexels」「Image by … from Pixabay」），不要改寫。這筆就是說明欄標示的來源，不要手刪；`video.json` 會以工具的格式重寫，所以在改稿前先抓，抓完再 `lint`。
3. **放上投影片**：一個 `screenshot` 景，`data.image` 寫 `stock/<sha256>.<ext>`（只有這個寫法），`data.title`／`caption`／`highlight` 照截圖景的用法；`data.credit`（選填，一行、≤60 字，例如「Photo by Lukas Rodriguez on Pexels」）才會把標示畫在照片右下角——站主的規則是影片不燒字，所以預設不寫，標示靠說明欄。直向照片會照高度放、置中；超寬的全景會超出版面，換一張。
4. **標示在說明欄**：`package` 會在參考資料之後加「📷 圖片來源」區塊，一張一行「Photo by … on Pexels（Pexels License）：照片頁網址」，各語系都有。`lint` 不算這幾行的位元組，所以 `youtube.description` 要比 5,000 位元組的上限多留每張約 130 位元組（兩張留 300 就夠）；超過時 `package` 會說是標示把它推過線。
5. **渲染前**：`render` 會拒絕用了 `stock/…` 卻沒在 `assets[]` 裡的景（說明欄會沒有標示）和還沒抓到工作目錄的照片；換了照片（同名不同位元組）只重畫那一景。

不可以：原樣轉售或把照片當獨立檔案再發布、暗示人物或品牌背書、把可辨識的人放進負面情境、熱連結廠商的網址（一定要抓到自己這邊）、刪掉 `assets[]` 的那一筆。正式站的 web app 還沒轉送 `stock/*` 路由時工具會說「要部署會轉送這些路由的版本」（結束碼 3），先把那張票做完。

## 螢幕錄影（示範）

1. **準備示範環境**：一個專用的示範目錄或專案，內容是假的（假公司、假客戶、假資料）。終端機提示字元改短，例如 `PS1='$ '`，不露出使用者名稱與主機名。
2. **秘密清查**（規矩 4）：關掉通知；環境變數與設定檔裡的 key 不在畫面上 `cat` 或 `echo`；瀏覽器不開信箱、不開帳單頁；登入畫面剪掉。錄完用播放器快轉逐段檢查一次，剪完再檢查一次。
3. **可讀性**：終端機與編輯器字級 20pt 以上，深色主題；游標移動慢一點，點擊前停半秒。錄 1920×1080、30fps 以上（OBS 或系統內建錄影）。
4. **照稿錄**：`[錄影]` 指示就是要錄的清單，一個指示一段檔案，檔名用分鏡表的編號（`shot-07.mp4`），剪輯才對得上。
5. **等待的處理**：AI 產生回應、安裝套件這類等待，錄影照錄，剪輯時加速並放字卡「（實際約 40 秒）」，不要假裝瞬間完成。
6. **失敗也是素材**：示範時真的出錯，記下來放進「常見錯誤」章節。

## 鏡頭（有露臉時）

- 眼睛在畫面上三分之一，背景簡單；燈光在正面偏側。
- 露臉段落放在開場、意見、結論；講解與示範時用字卡與錄影，主講者縮成子母畫面或不出現。
- 收音比畫質重要：領夾或指向麥克風，安靜房間，錄一段 10 秒環境音給剪輯降噪。

## 縮圖

- 1280×720，JPG 或 PNG，2MB 以內。範本 `.agents/skills/youtube-video/references/templates/thumbnail.html`，存成 `<WORKDIR>/slides/thumbnail.html`，`render` 會用 1280×720 渲染。
- 最多 6 個字的大字＋一個視覺主體（產品 Logo 只在評論該產品時使用、主講者表情、或一張對比圖）。字要在手機列表的小圖上讀得到：把 PNG 縮到 320 寬看一次。
- 縮圖的字不重複標題，而是補一句標題沒說的（標題「AI 模型怎麼挑」，縮圖「第一名≠最好用」）。
- 做兩到三版給站主選（`thumbnail-a.html`、`thumbnail-b.html`），上架後可用 YouTube 的縮圖測試比較。
- 不用別人的照片或影片截圖；右下角會被影片長度標籤蓋住，不放字。

## 剪輯交接（handover.md）

```markdown
# 剪輯交接：<片名>
- 讀稿機／逐字稿：teleprompter.txt
- 分鏡表：shots.csv（編號、章節、估計時間、類型、內容）
- 字卡：slides/*.png（檔名前的編號對應分鏡表）
- 錄影：shot-NN.mp4（站主錄）
- 音樂：音效庫曲名與授權
- 特別注意：哪幾段要加速、哪幾段要打馬賽克、哪個字卡要跟口播同時出現
```

剪完之後請剪輯交回每一章的實際開始時間，寫成 `chapters.txt`（見 script-format.md），上架包才會有正確的章節。
