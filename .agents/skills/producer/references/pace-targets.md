# 節奏目標：奇聞檔案局與原來如此事務所

`.agents/skills/producer/references/scorecards.md`〈成片〉的「節奏」一項，對這兩個系列用這裡的目標，不用漫劇的規格
（`.agents/skills/youtube-video/references/drama-craft.md` 的鏡長中位數 2.5–3.5 秒是有角色對白的漫劇量出來的）。
兩個系列都是旁白加插圖、畫面一直換的說故事解說片，參考都是黑貓研究院；奇聞的內容另參考馬臉姐。

## 量法

```bash
node .agents/skills/youtube-video/scripts/reference_analysis.mjs --file <final.mp4> --range 0-180 --range 300-480 --out <json>
node .agents/skills/youtube-video/scripts/reference_analysis.mjs --url <YouTube id> --range 0-180 --range 300-480 --out <json>
```

看每段的 `median`、`longest`、`opening_30s`、`motion.mean_difference`、`motion.high_motion_share`、`motion.slow_share`、`sound.silent_share`。
黑貓用連續推移與淡入淡出換圖，場景分數幾乎都低於 0.1，**切點量不出來**（180 秒量成 1 個鏡頭）；它的換圖間隔要用每 2 秒一格的聯絡表人工數：

```bash
ffmpeg -i <檔> -vf "fps=1/2,scale=200:-1,tile=10x3" -frames:v 1 sheet.jpg   # 一張 = 60 秒
```

量不到切點時，淡入淡出會被算進鏡內動態，參考片的 `high_motion_share` 因此偏高一點；比的時候看 `mean_difference` 與 `slow_share` 一起看。

**讀法**：我們換圖不比參考片慢（反而快一點）。差在兩件事：

1. **動的方式**：參考片是「停住 → 重拍一下」（推近一個細節、元素跳進來、換圖），`mean_difference` 5 左右、慢慢飄的比例低；
   我們是整張圖從頭到尾緩慢推移，`slow_share` 高、`mean_difference` 只有一半，看起來像沒在動。
2. **停頓**：參考片幾乎不停（靜音 0–2.5%），我們句子之間的空檔佔 4–7.5%。語速 10-25 已量過：黑貓 5.06 字／秒、我們 3.25（`.agents/skills/curio-episode/SKILL.md` 的〈跟高點閱頻道的差距〉）。

## 目標

| 項目 | 奇聞檔案局 | 原來如此事務所 | 為什麼 |
| --- | --- | --- | --- |
| 換圖間隔中位數 | 5–8 秒 | 6–12 秒 | 參考片的範圍；奇聞的內容參考馬臉姐 6 秒左右，原來如此照黑貓 7–11 秒 |
| 最長一張 | ≤ 18 秒，而且中間至少重拍兩次 | ≤ 20 秒，中間至少重拍兩次 | 參考片最長 16–22 秒，但都有重拍 |
| 每張圖的動法 | 停住 1–3 秒 → 重拍（推近一個細節、元素跳入、換構圖），一張圖 1–2 次；不用整張緩慢飄 | 同左 | 參考片的動態形態 |
| `mean_difference` | ≥ 4.5 | ≥ 4.5 | 參考片 3.9–5.9；我們 2.5–3.5 |
| `slow_share` | ≤ 0.30 | ≤ 0.30 | 參考片開場 0.15–0.25；我們 0.32–0.57 |
| 靜音（`silent_share`） | ≤ 3%，沒有 1.5 秒以上的空檔 | ≤ 3% | 參考片 0–2.5%；我們 4.3–7.5% |
| 語速 | ≥ 4.5 字／秒 | ≥ 4.5 字／秒 | 系列既有規則（10-25 量黑貓 5.06） |
| 開場 30 秒 | ≥ 3 張圖，第一張就是主角或那件怪事 | ≥ 3 張圖，第一張就是問題本身 | 參考片前 30 秒 3–4 張；我們 5 張已達標，但第一張常是旁觀的小孩 |

`mean_difference` 與 `slow_share` 的門檻是從五支參考片推出來的編輯判斷，不是公布的標準；
第一批照這個做的成片上架 28 天後，拿平均觀看百分比與前 30 秒留存回頭校準，不要為了讓一支過而調低。

## 怎麼改進成片

這些是給製作的方向，實作在各系列的 skill 與 `tools/video`（運鏡的寫法在 `.agents/skills/animation-camera/SKILL.md`）：

- 每張插圖畫大一點、細節多一點，讓鏡頭有東西可以推近；一句旁白講到哪個細節，就在那一刻推過去。
- 緩慢的全程推移改成「停住＋一次快的推近或跳入」。
- 拿掉句子之間的固定停頓，只在答案揭曉前留一拍。
