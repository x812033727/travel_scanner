# 短劇：15–30 秒的 AI 角色短劇

`.agents/skills/producer/SKILL.md` §4 的細節。站主 2026-11-03 指定的參考是兩支 Instagram 上的 AI 寵物短劇。

## 兩支參考片的拆解（2026-11-03 讀取）

| | A：狗零食品牌帳號 | B：柴犬帳號 |
| --- | --- | --- |
| 長度與比例 | 13.7 秒，直式 1440×2560 | 15.1 秒，4:3 1440×1080 |
| 數字 | 讚 33.4 萬、留言 8,573 | 讚 11.5 萬、留言 438 |
| 角色 | 擬人化的哈士奇（老公）與穿圍裙的柴犬（老婆），客廳 | 柴犬被蒙面人挾持，另一隻黑柴在對面 |
| 對白 | 沒有，全靠動作 | 中英雙字幕：「你快跑，一個人好好活下去」「一定要一個人嗎」「我再找一個不行嗎」「別」 |
| 節拍 | 0–4 秒日常（吸地、端咖啡）→ 5–6 秒打翻咖啡 → 7–8 秒老婆轉身 → 9–13 秒老公僵住、老婆瞪著 | 0–3 秒犧牲台詞 → 4 秒對方反問 → 5–6 秒「再找一個」→ 7–8 秒槍口轉向 →「別」→ 9–15 秒眨眼停格 |
| 為什麼會傳 | 夫妻日常的認同感，想 tag 另一半 | 灑狗血的期待被一句現實話打破，反差好笑 |
| 製作 | AI 生成，同一場景、固定機位 | 即夢 AI，片角保留「AI 生成」標示 |

共通的公式：**一個場景、兩個角色、一個人人都懂的情境、在最後三分之一反轉、停在反應上**。不用前情、不用旁白。

## 格式

| 項目 | 規格 |
| --- | --- |
| 長度 | 15–30 秒。15 秒是一個梗；25–30 秒是一個梗加第二次反轉 |
| 比例 | 9:16、1080×1920、30 fps（YouTube Shorts 與 Instagram Reels 通用） |
| 鏡頭 | 3–6 鏡，每鏡 2–5 秒；同一場景、同一組角色，機位少換 |
| 對白 | 0–4 句，每句 12 字內；有對白就上繁中＋英文雙字幕 |
| 角色 | 我們自己的角色（擬人動物、頻道的 Q 版角色）；不用既有 IP、名人或真人臉 |
| 標示 | 說明欄與上架設定都標 AI 生成 |

## 節拍表（交分鏡前填）

```
一句話：<誰> 在 <哪裡> 想 <做什麼>，結果 <出錯>，最後 <反轉>
0–2 秒 鉤子：一眼看懂的情境（動作或第一句台詞）
2–8 秒 升高：期待被建立（犧牲、誤會、快完成了）
8–11 秒 反轉：一個動作或一句話打破期待
11–15 秒 停在反應：表情停格或第二個小動作；25–30 秒版在這裡接第二次反轉
封面：反轉前最強的那一格表情
標題：寫情境不寫結局（「老公打翻咖啡的那一秒」，不是「老婆生氣了」）
```

## 製作路線

1. 分鏡與首格：先用 `.agents/skills/animation-preproduction/SKILL.md` 寫分鏡、估價、鎖企劃；要付點數就等站主核准。
2. 片段：Hailuo 網頁、Kling 或 RunPod H3（`.agents/skills/minimax-h3-runpod/SKILL.md`），每鏡 5–6 秒生成再剪。
3. 合成：ffmpeg 接鏡、上字幕、配樂或環境音，輸出 30 fps、48 kHz、−14 LUFS。
4. 上架：`node tools/video/shorts/cli.mjs import --from <資料夾>`，資料夾要有 `final.mp4`、`zh-TW.srt`、`meta.json`（`.agents/skills/youtube-video/references/shorts.md` 的匯入一節）。

## 現有工具的缺口

- Shorts 工具只收 25–55 秒（`tools/video/shorts/core.mjs` 的 `PROFILE.minSeconds`），15 秒成片 `import` 不會過。
  在工具改之前，短劇寫成 25–30 秒的雙反轉版；要做 15 秒單梗版，另開票加一條短劇的長度設定，不要繞過品管。
- `import` 的 `meta.json` 的 `line` 只有現有三條內容線；短劇算哪一條、要不要新的系列，交站主決定後寫進
  `docs/videos/SHORTS.md`。
- 沒有對白的短劇，`zh-TW.srt` 仍要有（品管逐句切音）；可以放一句情境字卡。
